### 踩坑记录
1. **tspan 闭合标签写错**：`<tspan>批复总投资：</text>` 应为 `</tspan>`，导致 XML 解析失败
2. **图标名不存在**：`chunk-filled/currency-dollar` 和 `chunk-filled/file-text` 不在库中，正确名应为 `dollar` 和 `file`
3. **图标嵌入失败** → svg_to_pptx 报 unsupported visual SVG element 错误
   - 临时方案：把 `<use data-icon>` 替换为半透明 `<rect>` 占位符
4. **渐变不被 PPTX 转换器支持**：`url(#coverBg)` 等 linearGradient 报 "Can't handle color"，PPT 中渐变显示为纯色
   - 需要后续研究是否有解决方案
