## 智析Agent第二波修复（22:36-22:40）

### 新发现的问题

1. **MCP原生工具参数不匹配**（🔴 Critical）
   - 6个原生审计工具签名不含`**kwargs`，但LLM通过MCP schema传入额外参数（如`ocr_pages`）
   - 导致TypeError → dispatch_native返回None → 回退到MCP stdio → 传输断裂
   - 日志表现：小请求成功/中请求偶发失败/大请求90%失败

2. **audit_bid_pdf扫描整个uploads**（🟡 Bug）
   - LLM把uploads根目录作为folder_path → 处理50+文件，含损坏的test_bid.pdf
   - 修复：加预过滤，先尝试fit.open再处理，跳过损坏文件

3. **knowledge.py缺少disabled检查**（🟡 Resilient）
   - chat.py已有fallback但knowledge.py的_get_client没有→可能尝试调用已禁用的QWQ-32B

4. **MCP重连次数过低**（🟡 Tuning）
   - _MAX_RECONNECT_ATTEMPTS=1, _RECONNECT_BASE_WAIT=0.5s
   - MCP服务器崩溃后仅重试1次就放弃 → 恢复为3次/2s

### 修复汇总
| 文件 | 修改 | 原因 |
|------|------|------|
| agent/tools_audit.py | 6个函数加`**kwargs` | 原生调度参数兼容 |
| agent/tools_audit.py | audit_bid_pdf预过滤损坏文件 | 防止全目录扫描失败 |
| agent/mcp_manager.py | 重连3次/2s | MCP瞬断恢复 |
| api/knowledge.py | _get_client加disabled检查 | 防QWQ-32B死调用 |
