## 学习：Graph of Skills（GoS）— 依赖感知技能图检索

文章来源：微信公众号「Hyman的杂货铺」2026-04-13
原文链接：https://mp.weixin.qq.com/s/L0JsfDugFzOHgvZ3hs6gdg

### 核心问题
Agent 技能库膨胀（数百到数千），现有检索方案：
- 全量加载：token 爆炸，2000技能要5.84M tokens
- 向量检索：漏掉前置依赖（语义接近≠执行充分）

### GoS 方案
- 把技能库变成类型化有向图，检索时沿依赖传播
- 四种边：Dependency(1.0) > Workflow(0.5) > Semantic(0.2) > Alternative(0.1)
- 三步在线：混合种子 → 反向感知PPR扩散 → 预算重排序
- 结果：奖励+43.6%，Token-37.8%

## 学习 & 安装：Hermes Agent

文章来源：微信公众号「Hyman的杂货铺」2026-04-13
原文链接：https://mp.weixin.qq.com/s/L0JsfDugFzOHgvZ3hs6gdg（下一篇）

### 核心观点
Hermes Agent（Nous Research）= "会学习的 Agent"，6周破43,700 Star。
vs OpenClaw 根本区别：Skill 自动进化 vs 静态不变

### 三层进化机制
1. **Skill 自动生成** — 任务完成后自动分析执行过程，生成可复用 SKILL.md
2. **跨会话持久记忆** — 8种可插拔提供者（Honcho/Mem0等）
3. **GEPA 离线进化** — DSPy + GEPA 系统性优化 Skill 文件，$10 API费超过RL

### GEPA 论文（ICLR 2026 Oral）
- ASI（Actionable Side Information）= 文本空间的"梯度"
- Pareto 前沿候选池保留多样性
- System-Aware Merge 跨候选知识融合
- 样本效率比 RL 高 35 倍

   - Git 2.54.0 ✅（已有，需手动加PATH）
