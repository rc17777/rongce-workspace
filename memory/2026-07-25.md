#### 2. 扫描PDF OCR（qwen-vl-max完成）
**关键发现——3份政策文件逐页OCR提取后的重大发现：**

**发现一：省级和甘孜州政策都是按班次补贴，不是按人头！**
- 川财教〔2025〕78号原文：始发航线每班次≤8万
- 甘办函〔2023〕13号原文：稻城≤8万/班次、格萨尔≤5万/班次
- 报告中"甘孜1200-1600元/人"是逆向折算值，非政策原文

**发现二：省文旅厅通知文件名与内容不符**
- 文件名声称"游客数据反馈通知"
- 实际内容为"补贴申报通知"（川文旅发〔2025〕47号）
- → 人均3,500元消费的一手源文件未能独立核验

**发现三：历史数据严重内部矛盾**
- 可行性报告："历史客座率均超80%"
- 统计表：2023年武汉=九寨实际36.63%

**其他核验发现：**
- 客运量奖励协议未签署（签字页全空白）
- 民航审批文件缺失（协议生效前提未满足）
- 州级航线补贴管理办法不存在（仅一纸说明）
- CCAR-121运行规范：西部航空A319-133获批九黄机场(R/A)
- 利益冲突声明：九黄与西部航无股权关系
