## 核心思路

很多人以为用AI画图表得懂编程，其实不用。通用四步骤：
1. 用大白话告诉DeepSeek你想画什么图、用什么数据
2. DeepSeek生成代码
3. 把代码复制到对应的在线工具或浏览器
4. 导出为PNG/SVG/HTML

## 6种方法

### 1. Mermaid语法：画流程图、思维导图最省事
- **适用**：项目流程、系统架构、组织架构
- **操作**：DeepSeek描述需求 → 提示用Mermaid语法 → 复制代码 → mermaid.live粘贴 → 导出PNG/SVG
- **提示词示例**："用户打开App → 输入账号密码 → 系统验证 → 验证通过进入主页；验证失败提示错误。用Mermaid语法，把代码原样返回给我"

### 2. ECharts统计图：做专业数据图表
- **适用**：销售报告、市场分析、科研数据展示
- **操作**：上传Excel给DeepSeek → 说清楚要什么图 → 生成HTML代码 → 运行预览或存成.html文件
- **示例**："根据我上传的Excel，帮我生成一个交互式旭日图"

### 3. Python代码绘图：适合想自己跑代码的人
- **适用**：Jupyter Notebook / PyCharm用户
- **操作**：上传CSV/Excel → 说需求 → 复制代码到本地运行
- **示例**："帮我绘制销售额与利润趋势折线图"

### 4. Napkin AI：创意趣味图表，不用代码纯靠文字
- **适用**：手绘风流程图、故事板、概念说明
- **操作**：DeepSeek整理成箭头连接的文本 → 复制到napkin.ai → 选风格 → 下载PNG/SVG
- **特点**：目前免费无水印，不用注册；不擅长精确数值，适合趋势和关系表达

### 5. AI智能体/工作流：自动化出图
- **适用**：需要每周自动拉数据、出图表的场景
- **工具**：Coze / Dify
- **流程**：创建工作流 → 开始节点接收Excel → 读取数据 → 大模型节点(DeepSeek)整理为JSON → 图表插件生成
- **门槛**：需要一点技术基础

### 6. Markdown + Xmind：一键把层级变思维导图
- **适用**：读书笔记、项目架构、头脑风暴
- **操作**：DeepSeek用大纲形式描述 → 转为Markdown多级列表(#和-) → 复制到Xmind → 自动生成导图
- **注意**：缩进和列表符号要清楚，Xmind才能正确识别层级
- **备选**：Markmap（markmap.js.org）在线预览后截图

## 四个提醒

1. **从最简单的开始**：画流程图用Mermaid，做数据报告再考虑ECharts
2. **先把数据准备好**：DeepSeek出代码快不快、准不准，取决于数据和需求好不好
3. **不满意就多改几次**：把想怎么改说一遍，它会重新生成
4. **写代码的事扔给AI**：你只需要想清楚要画什么、用什么数据
