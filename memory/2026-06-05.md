## 新建技能：regulatory-audit-response（接审报三字诀）

- 来源：审计实践公众号《监管指定审计不是"命题作文"》— 埃阚步瞰
- 产出：`skills/regulatory-audit-response/SKILL.md`

### 核心框架
- **接得住**：精准理解指令意图（普遍排查/线索核实/数据摸底）+ 向管理层明确刚性约束
- **审得透**：三层穿透（制度→执行→实质），审计标准从内部合规升级为法定监管标准
- **报得准**：措辞铁律（禁模糊评价）+ 已查实/未查实/超出范围三类区分 + 整改责任人/时限/验证标准

### 关键教训
- 替被审计单位"优化"措辞 = 公信力受损
- 仅引用内部制度作依据 = 监管不认可
- 整改建议空泛 = 下次检查无法验证
