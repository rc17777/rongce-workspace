# 关于推动解决政府采购异常低价问题的通知

> 文号：财库〔2026〕2号  
> 签发：财政部，2026年1月14日  
> 施行：2026年2月1日  
> 来源：中国政府采购网、华南理工大学招标中心等

---

## 一、加强政府采购需求管理

- 采购人根据实际工作需要，考虑同类项目中标签约信息、市场供给和产业状况、材料人工等市场价格、行业费用标准等，形成科学完整清晰的采购需求
- 合理设定最高限价（未设定的以预算金额为最高限价）
- 合理设置采购包，可引入**全生命周期成本理念**（运营、维护、升级、专用耗材、处置报废等费用纳入评审）
- **重点管理对象**：信息化建设项目 + 耗材使用量大的复印/打印/实验/医疗等仪器设备采购

## 二、强化政府采购异常低价审查（核心条款）

### 四种触发情形（刚性）

| 序号 | 触发条件 | 阈值 |
|:----:|:---------|:-----|
| 1 | 报价 < 全部通过符合性审查供应商报价平均值 | **50%** |
| 2 | 报价 < 通过符合性审查的次低报价 | **50%** |
| 3 | 报价 < 采购项目最高限价 | **45%** |
| 4 | 评审委员会专业判断报价过低，可能影响质量或不能诚信履约 | 自由裁量 |

> ⚠️ 采购人可将第1-3项阈值提高，但**最高不超过65%**

### 审查程序

1. 触发 → 要求供应商在评审现场合理时间内（**一般≥30分钟**）书面解释 + 成本测算证明材料（原材料、人工、制造费用等）
2. 评审委员会参考同类中标价、市场价格、行业人工标准、行业平均成本等判断合理性
3. **不能证明合理性 → 无效投标（响应）处理**
4. 启动原因、审查意见、结果、供应商说明材料、互联网浏览/查询历史 → **全部归档**

### 法律责任

- 财政部门发现评审委员会未按规定审查 → 依法纠正 + **追究评审专家法律责任**

## 三、加强政府采购履约验收管理

- 验收内容覆盖每一项技术和商务要求
- 触发异常低价审查后仍中标的供应商 → **重点关注**履约承诺和实际履约
- 分期项目 → 分期考核、分期验收、分期支付
- 拒签合同 / 履约不合格 → 依法追究违约责任

---

## 对审计工作的意义

1. **绩效评价新抓手**：异常低价中标 → 履约质量下降 → 绩效评价扣分项
2. **采购审计新标准**：可检查采购人是否按要求在采购文件中载明了异常低价审查标准
3. **监督检查新依据**：评审委员会是否按规定启动审查、是否完整归档 → 可作为审计发现
4. **信息化项目审计**：重点检查供应商是否在合同外违规收费
5. **全生命周期审计**：耗材/运维费用是否超过了投标时的承诺报价
