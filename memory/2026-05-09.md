## 学习：aweskill - 让 AI Agent 学会自己管理 skills

文章来源：微信公众号「北野茶缸子」2026-05-06
原文链接：https://mp.weixin.qq.com/s/Fb0Q7nKEJtORSTz7Ukv_EA

### 核心观点
当前 AI 编码 Agent（Codex、Claude Code、Cursor、Gemini CLI 等）各自有不同的 Skill 目录结构，
管理 Skills 的负担落在人身上。aweskill 的设计目标是让 Agent 自己管理 Skills。

### aweskill 架构
- **中央仓库**：`~/.aweskill/skills/`，所有 Skills 统一存放
- **Agent 投影**：通过 symlink 把中央仓库的 Skills 投射到各 Agent 的目录
- **内置元 Skills**：
  - `aweskill`：搜索、安装、更新、Bundle 管理、Agent 投影
  - `aweskill-doctor`：同步检查、清理、去重、修复异常 SKILL.md、恢复
- **Agent 引导协议**：README.ai.md，告诉 Agent 如何自主完成初始化

### 7 个使用场景
1. **初始化新 Agent**：一句话引导 Agent 完成安装和投影
2. **查找安装 Skill**：自然语言 → aweskill find → 选择 → 安装 → 投影
3. **创建项目 Bundle**：将一组 Skills 打包为可复用 Bundle，跨 Agent 共享
4. **检查更新**：aweskill update --check 先看后改
5. **修复 Skill 状态**：doctor 系列命令，默认 dry-run，确认后才 apply
6. **迁移配置**：一个 Bundle 投影到另一个 Agent，不用手动复制
7. **备份**：aweskill store backup，恢复比重建容易

### Agent 可操作工具的设计原则
- 同时为人和 Agent 写文档
- 通过稳定 CLI 被脚本化调用
- 对破坏性操作保持保守
- 在应用变更前可以检查
- 每一步操作后都容易验证
- 本地状态漂移后可以恢复

### 与 OpenClaw 的对比
- OpenClaw 用 clawhub 做 skill 分发，aweskill 也做类似的事但更强调 Agent 自主操作
- OpenClaw 的 skill 放在 workspace/skills/ 下，aweskill 用中央仓库+投影模式
- aweskill 的 Bundle 概念类似"技能包"，可以跨 Agent 复用——OpenClaw 目前没有这个
- aweskill-doctor 的自动修复思路值得借鉴
