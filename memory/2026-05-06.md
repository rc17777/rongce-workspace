## PaddleOCR安装 — 大工程

### 最终方案
- **Python 3.14 alpha不兼容**所有C扩展包（PyTorch/Paddle/EasyOCR全部0xC0000005 crash）
- 搭建了独立的 **Python 3.13 嵌入式环境**：`D:\openclaw-workspace\tools\python313\`
- 华为云镜像下载Python 3.13.3 embeddable zip → 解压 → 配置site-packages → pip安装

### 安装的包
- PaddleOCR 3.5.0 + PaddlePaddle 3.3.1 (104.8MB) + paddlex 3.5.1
- 4个OCR模型自动下载到 `C:\Users\scrccpa\.paddlex\`：
  - PP-OCRv5_server_det（检测 84MB）
  - PP-OCRv5_server_rec（识别 80MB）
  - PP-LCNet_x1_0_doc_ori（文档方向分类）
  - UVDoc（文档预处理）
- python-bidi用预编译whl（0.6.7），避免需Rust工具链的0.6.9版本

### 使用方式
```powershell
D:\openclaw-workspace\tools\python313\python.exe D:\openclaw-workspace\test_ocr.py 图片路径.jpg
```
