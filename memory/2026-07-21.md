### 券商研报核心设计要素总结

#### 报告结构
1. **封面**：公司Logo + 研报类型 + 主副标题 + 投资摘要（3-4条核心观点）+ 分析师信息
2. **正文**：页眉（Logo+标题）+ 页脚（页码+免责）+ 分级标题（一级用色块/竖线，二级加粗）+ 核心结论高亮
3. **尾部**：投资评级说明 + 免责声明

#### 图表样式
1. **配色**：严格遵循品牌色系（2-3种主色），纯白背景
2. **坐标系**：极简主义，只留必要轴线，浅灰色虚线网格
3. **资料来源**：每个图表底部必有小字灰色脚注（体现权威性）
4. **表格**：三线表变体（顶底加粗+表头底纹+无竖线）

### 日常工作流建议
1. **数据准备** → Excel/CSV整理
2. **图表生成** → `securities_chart.py from-csv` 直接输出券商风PNG
3. **Word排版** → 使用模板，只点预设样式
4. **AI复核** → `audit-report-review`跑一遍

1. **表格表头文字被截断** — Matplotlib对中文自动换行支持差，后续改用python-docx原生表格渲染

3. **Word标题底色** — python-docx对段落底纹支持有限，一级标题目前用深蓝字代替色块白字

### 关键教训
- Matplotlib画表格对中文支持反人类，表头文字硬切一半
- 券商研报的"专业感"本质是：高度结构化排版 + 极简克制的数据可视化 + 资料来源脚注
