### 关键修复
- SQL INSERT_RE 尾部 `;` 被 split_statements 剥离导致不匹配 → 改为 `(.*)$`
- CREATE_RE 终止标记把列级 `DEFAULT NULL` 误判为建表结束 → 只认表级选项（ENGINE=/DEFAULT CHARSET/COLLATE=/CHARSET=/;）

### 技术要点
- base环境已有 pdfplumber 0.11.9 / pymupdf / requests，无需装包
- paddleocr 2.7.3 环境无 PPStructure → 表格重建用 y聚类+x排序（仅多列行输出表格行）
- PDF扫描件支持大文件拆分（--chunk-pages 25默认）+ 断点续跑（--keep-chunks）
- OCR质量分层：≥95%自动入库 / 85-95%抽检 / <85%人工确认
