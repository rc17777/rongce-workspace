## 凌晨排查：OpenClaw + 大模型调用问题（01:47-02:05）

### 结论一（已确诊根因 02:20）：本地后端设备权限不足，scope 升级申请卡在待审批
- 现象：exec/nodes/spawn 默认通道报 `gateway closed (1008): pairing required`
- **根因**：`~/.openclaw/devices/paired.json` 里本地后端设备 `1bc4c01d...`（clientId=gateway-client）只有 `operator.read` 一个 scope；它发起了全权限升级申请（read/write/approvals/pairing/admin），请求 `4a915c18-41cf...`（isRepair=true）正躺在 `pending.json` 等审批，Gateway 拒连接（reason=scope-upgrade）
- 日志佐证：`security audit: device access upgrade requested reason=scope-upgrade ... scopesFrom=operator.read scopesTo=operator.pairing`
- 修复路径：在 Control UI（http://127.0.0.1:18789/）设备/配对页面批准该待审批请求（由平头哥点，AI 不自行改 paired.json 提权）
- 附带发现：版本错位（运行 2026.4.5 / 配置 2026.7.1-beta.1 写入）可能是 scope 不匹配的诱因；旧版 CLI `openclaw devices` 子命令会挂死（因为它自己也用这个残权限设备连网关，鸡生蛋蛋生鸡）
- **临时解法（已验证可用）：exec 加 `host=gateway` + `security=full`**
- 用户重启过 OneClaw，无效 → 不是临时卡死
