### 现象
平头哥反馈 webchat "随时掉线"。

### 根因（反转剧情）
机器上存在**两套 openclaw 打架**：
1. **OneClaw 桌面版**（2026.528.0，已是官网最新）→ 自带 gateway.asar，核心版本 **2026.4.5**
2. **npm 装的 openclaw 2026.7.1-beta.1** —— 装在 `Programs\OneClaw\node_modules`（因为 **npm prefix 被设成了 OneClaw 安装目录**！大概率是之前某次 update.run 干的）

冲突机制：npm 7.1-beta 网关运行时，OneClaw App 自带客户端（4.5 协议）连不上 → `protocol mismatch (1002)` → App 看门狗反复杀/拉网关 → 用户端表现为随时掉线。日志证据：21:01:32、00:13:04 两组 protocol mismatch ERROR；00:04-00:17 网关重启至少2次（PID 3060→17332），非人为。

### 修复动作（平头哥授权）
1. `npm uninstall -g openclaw` 卸掉 7.1-beta（Programs\OneClaw 里的）
2. 手动清掉 Roaming\npm 里的 2026.6.11 孤儿残留
3. 确认 OneClaw 桌面版 2026.528.0 = oneclaw.cn/releases 最新版，**无需更新**
4. 重建丢失的 `~/.openclaw/gateway.cmd`（计划任务 \OpenClaw Gateway 的启动入口），指向 OneClaw 自带 CLI
5. 最终状态：单一版本（app自带 2026.4.5），mismatch 源头消除

### 关键教训
- ⚠️ **npm prefix = `C:\Users\scrccpa\AppData\Local\Programs\OneClaw`**（不是默认的 Roaming\npm）！任何 `npm install -g` 都会装进 OneClaw 目录，可能再次造成版本打架。装全局包前先 `npm config get prefix` 确认
- ⚠️ **不要用 npm/update.run 更新 OneClaw 环境的 openclaw** —— OneClaw 桌面版是一体化打包（app.asar + gateway.asar），版本必须跟 App 走，等 App 官方更新
- gateway 工具的 update.run / config.patch 在此环境会报 "pairing required"，改配置只能直接编辑 openclaw.json + 重启
- 降级副作用：核心从 7.1-beta 回到 4.5，昨晚配的 session.reset(daily 4am) 在 4.5 上可能不生效，观察
