## 模型路由 v6.0 升级（四信号 × 四方法）

**触发**：用户分享微信文章《一篇讲清模型路由》（AURORA视界），要求按文章思路配置路由。

**文章核心**：
- 优化目标 = 单次成功任务总成本（模型+工具+重试+时延），不是 Token 单价
- 四类信号：任务 / 轨迹 / 系统 / 风险
- 四种方法：规则 / 分类 / 级联 / 阶段
- 铁律：验收用确定性检查不靠模型自评；高风险操作不跳过人工审批；升级带交接单（handoff）

**产出**：
- `config/model_routing_v6.py`（新，v5 保留不删）：
  - MODEL_POOL 8 档位（efficient/numerical/strong/chinese_doc/long_context/creative/consulting/safety_net）
  - 决策优先级：风险 > 轨迹级联 > 阶段 > 分类 > 规则 > 系统 fallback
  - RISK_POLICY：high(强制safety_net+人工审批) / medium(强制strong) / low
  - CASCADE_RULES：同错2次/3轮无进展/工具重复3次/失败扩大 → 升级；10分钟冷却，单任务≤2次
  - CASCADE_UPGRADE_MAP：efficient→numerical→strong→safety_net
  - STAGE_ROUTES：explore=efficient / plan=strong / execute=numerical / recover=strong / acceptance=safety_net+确定性检查
  - 轨迹日志：logs/routing_trajectory.jsonl（每笔决策落盘，含 shadow 标记）
  - shadow_compare() 影子评测助手、stats() 统计
  - v5 兼容：get_agent_route / get_scenario_route / get_best_route 行为不变
- `test_router_v6.py`：17 项回归测试全过（风险/级联/冷却/阶段/分类/规则/优先级/系统状态/v5兼容）
