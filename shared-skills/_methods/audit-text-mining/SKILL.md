# 审计文本挖掘 (Audit Text Mining)

对海量审计文档进行批量文本挖掘——从"看不清、抓不住、找不到"到"一键锁定关键事项"。

## 核心理念

审计准备阶段最耗时的不是分析，而是**找到该分析什么**。面对成百上千份会议纪要、合同、报告，传统做法是逐份翻阅——效率低、易遗漏、依赖个人经验。

本技能将 Python 文本挖掘技术封装为可复用工具链，实现：
1. 从海量文档中**自动浮现**关键主题（词云）
2. **精准定位**关键词在哪些文件的哪些段落（批量搜索+上下文）
3. **结构化导出**为 Excel，直接用于下一步审计分析

## 快速开始

### 三步骤

```
Step 1: 格式转换     scripts/doc_to_docx.py       .doc → .docx
Step 2: 词云分析     scripts/wordcloud_audit.py    分词→词频→词云图
Step 3: 关键词定位   scripts/keyword_search.py     多关键词批量搜索→Excel
```

### Step 1：格式转换

将目录中所有 .doc 文件转换为 .docx：

```bash
python scripts/doc_to_docx.py <文档目录路径>
```

> ⚠️ 需要本机安装 Microsoft Word（win32com 依赖）

### Step 2：词云分析

对目录中所有 .docx 文件进行分词+词频统计+词云可视化：

```bash
python scripts/wordcloud_audit.py <文档目录路径> [--top 200] [--output wordcloud.png]
```

输出：
- `wordcloud.png` — 词云图
- `词频统计.xlsx` — 词频排行表
- 控制台打印 Top 20 高频词

### Step 3：关键词定位

基于词云发现的关键词，批量搜索定位：

```bash
python scripts/keyword_search.py <文档目录路径> --keywords "关键词1|关键词2|关键词3" [--context 50] [--output 关键词定位结果.xlsx]
```

输出 Excel：

| 文件名 | 段落号 | 关键词 | 上下文（前后各N字） |
|--------|--------|--------|---------------------|
| 2024-01会议纪要.docx | 15 | 借款 | ...研究同意向XX公司提供借款...用于... |
| 2024-03会议纪要.docx | 8 | 奖励 | ...对园区企业给予税收奖励...按... |

## 停用词管理

词云分析会自动过滤停用词。默认停用词列表见 `assets/stopwords.txt`。

可根据审计场景自定义添加（如：年份、关于、根据、按照、会议、研究、同意等审计文档中常见但无分析价值的词）。

## 典型工作流

```
经济责任审计项目
    ↓
收集所有会议纪要 → 放入 docs/会议纪要/
    ↓
Step 1: doc_to_docx.py（如有.doc格式）
    ↓
Step 2: wordcloud_audit.py → 发现高频词："借款""奖励""土地""规划""安置"
    ↓
Step 3: keyword_search.py --keywords "借款|奖励|土地|规划|安置"
    ↓
导出 关键词定位结果.xlsx → 逐条核查 → 发现问题线索
    ↓
进入现场检查阶段（有的放矢）
```

## 审计场景适配

| 审计类型 | 分析文档 | 重点关注关键词 |
|---------|---------|--------------|
| 经济责任审计 | 会议纪要、工作报告 | 借款、奖励、土地、规划、安置、招商、税收 |
| 绩效评价 | 项目档案、验收报告 | 进度、资金、拨付、完成、验收、绩效 |
| 专项资金 | 合同、付款凭证 | 拨付、验收、变更、追加、结余 |
| 采购审计 | 招标文件、评标记录 | 招标、中标、资质、报价、评分 |
| 工程审计 | 监理日志、签证单 | 变更、签证、延期、追加、质量 |

```bash
pip install python-docx jieba wordcloud pandas openpyxl pywin32
```

- 关键词定位 Excel → 疑点清单 → finding-generator 深度分析
