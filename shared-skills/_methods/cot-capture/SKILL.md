# 审计思维链沉淀 (CoT Capture)

将审计专家的隐性判断逻辑转化为结构化思维链数据集——让"老法师"的经验暗物质变成可训练、可传承、可复制的核心资产。

## 核心价值

审计专家的核心能力不在于掌握了多少查询语法，而在于脑海中历经实战淬炼的思维链：

```
检查事实 → 风险评估 → 排除干扰 → 专业判断 → 问题定性
```

这些思维链极少体现在最终高度凝练的审计报告里——报告只留结论，过程全在脑中。本技能将这套隐性推理链显性化。

## 工作流

### 模式A：复盘录音提取（推荐）

```
项目复盘会 / 疑点讨论
    ↓ 录音（手机/会议录音均可）
语音转文字（whisper / 飞书妙记 / 通义听悟）
    ↓ 转写稿（.txt）
大模型 CoT 提取
    ↓ 结构化思维链
人工审核 + 脱敏
    ↓
存入知识库 / CoT 数据集
```

### 模式B：结构化访谈

```
按 interview-protocol 进行一对一访谈
    ↓ 同步录音+笔记
转写 + 提取 + 审核
    ↓
存入知识库
```

### 模式C：文本直接提取

```
已有的案例文档 / 问题分析报告 / 审计手记
    ↓
大模型 CoT 提取（用 extraction-prompts）
    ↓
审核入库
```

## 快速开始

### 1. 准备素材

将录音文件转写为文本，或准备好已有的文字材料（案例文档、复盘记录等）。

### 2. 执行提取

将转写文本 + 提取提示词一起提交：

```
请使用 cot-capture 技能，从以下审计复盘录音转写稿中提取思维链。

转写稿：
[粘贴转写文本]

请按 cot-schema 格式输出。
```

### 3. 审核入库

检查提取结果的完整性和准确性：
- 五个步骤是否完整（事实检查→风险评估→排除干扰→专业判断→问题定性）
- 推理逻辑是否通顺
- 敏感信息是否已脱敏

确认后保存为 JSON 文件到知识库。

## 输出标准

每条 CoT 记录包含：

```json
{
  "id": "COT-YYYYMMDD-NNN",
  "场景": "审计类型-具体环节",
  "思维链": [
    {"步骤": "事实检查", "内容": "..."},
    {"步骤": "风险评估", "内容": "..."},
    {"步骤": "排除干扰", "内容": "..."},
    {"步骤": "专业判断", "内容": "..."},
    {"步骤": "问题定性", "内容": "..."}
  ],
  "关键发现": "一句话总结核心洞察",
  "专家": "匿名标识",
  "关联政策": ["文件名+条款"],
  "关联审计方法": ["方法1", "方法2"],
  "适用场景标签": ["标签1", "标签2"],
  "置信度": "高/中/低"
}
```

详见 [cot-schema.md](references/cot-schema.md)。

## 审核要点（人工把关）

提取完成后必须由审计专家审核：

- [ ] 五个步骤的逻辑是否真实反映排查过程（非事后编造）
- [ ] 排除干扰步骤是否包含被否定的假设路径（这恰恰是CoT最有价值的部分）
- [ ] 政策引用是否准确
- [ ] 是否涉及被审计单位敏感信息（需脱敏）
- [ ] 置信度标注是否合理
