# 财政监督检查模型 Skill

## 目标

把收集到的电子数据转成可执行成果：数据质量报告、风险画像、疑点清单、现场核查任务单、资料补充清单、问题底稿初稿、报告素材。

优先服务当前场景：四川省交通运输厅 2026 年财会监督专项检查；也可复用于政府部门、事业单位、省属企业专项资金和政府采购监督检查。

## 使用原则

1. 不建“统计型指标库”，只建“识别规则型指标库”。
2. 每条规则必须有：数据来源、必要字段、检测逻辑、阈值、疑点输出、处置建议、误报提示。
3. 先跑 30 条高优先级规则，不追求一次性 200 条。
4. 阈值先用经验值，拿历史数据试跑后用 P95/P99/同比/环比/分位数校准。
5. 所有疑点必须落到责任人、证据资料和核查状态，不允许只输出“异常金额”。

建议目录：

```text
├── 04_疑点清单/

├── 06_问题底稿/

```

### 2. 读取数据标准

需要设计数据模板、校验字段、资料交接口径时，读取：

- `references/data-standard.md`

### 3. 选择规则库

- `references/output-spec.md`

## 场景模块

| 模块 | 场景 | 典型数据 |
|---|---|---|
| A | 过紧日子 | 支出明细、三公经费、会议培训差旅、公车、资产配置 |
| B | 部门预算执行 | 预算指标、支付明细、项目库、绩效目标、预算调整 |
| C | 专项资金 | 资金批复、项目台账、合同、付款、验收、绩效资料 |
| D | 政府采购 | 采购台账、采购需求、采购文件、评审、合同、验收、付款 |
| E | 资金管理 | 银行流水、账户清单、非税收入、往来款、零余额支付 |
| F | 资产管理 | 资产台账、采购合同、处置审批、公车台账、盘点表 |
| G | 内部控制 | 制度、岗位职责、审批流程、会议纪要、系统权限 |
| H | 整改闭环 | 近五年问题台账、整改报告、销号佐证、制度修订 |

## 核心输出

默认输出 Excel 工作簿，至少包含：

1. `数据质量问题清单`
2. `单位风险画像`
3. `疑点清单`
4. `现场核查任务单`
5. `资料补充清单`
6. `问题底稿初稿`
7. `规则命中统计`

## 疑点分级

| 等级 | 含义 | 处置 |
|---|---|---|
| P0 | 重大疑点 | 立即核查，必要时形成专题线索 |
| P1 | 重点疑点 | 现场优先取证，纳入重点问题池 |
| P2 | 一般疑点 | 常规核查，视证据转问题或排除 |
| P3 | 提示事项 | 作为管理建议或补充核验 |

## 调用示例

用户说：

- “调用财政监督检查模型，帮我设计数据模板”
- “把这些电子数据导入财政监督检查模型跑疑点”
- “按交通厅监督检查项目生成首批 30 条识别规则”
- “根据采购台账和付款明细筛政府采购疑点”
- “生成现场核查任务单和资料补充清单”

执行时应先确认数据路径、检查模块、期间范围、是否允许读取本地文件，然后按标准工作流输出。
