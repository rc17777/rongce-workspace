# 输出规范

## 默认 Excel 工作簿

文件名：`财政监督检查模型输出_<项目名>_<日期>.xlsx`

必须包含以下 Sheet：

### 1. 数据质量问题清单

字段：

- 单位名称
- 数据表
- 问题类型
- 问题描述
- 影响字段
- 影响记录数
- 是否阻断分析
- 补正要求
- 责任部门
- 状态

### 2. 单位风险画像

字段：

- 单位名称
- 检查模块
- 数据完整率
- 命中规则数
- 疑点总数
- P0数量
- P1数量
- P2数量
- 涉及金额
- 主要风险领域
- 建议现场关注事项

### 3. 疑点清单

字段：

- 疑点编号
- 单位名称
- 检查模块
- 规则编号
- 规则名称
- 疑点描述
- 涉及金额
- 涉及期间
- 关键对象
- 命中原因
- 风险等级
- 需核资料
- 建议核查程序
- 责任人
- 截止日期
- 核查状态
- 排除/确认理由

### 4. 现场核查任务单

字段：

- 任务编号
- 对应疑点编号
- 单位名称
- 核查事项
- 需访谈人员
- 需调阅资料
- 需现场查看事项
- 责任人
- 截止日期
- 当前状态
- 备注

### 5. 资料补充清单

字段：

- 补充编号
- 单位名称
- 模块
- 缺失资料
- 缺失原因
- 影响分析
- 提交要求
- 责任部门
- 截止日期
- 状态

### 6. 问题底稿初稿

字段：

- 问题编号
- 单位名称
- 问题标题
- 问题事实
- 涉及金额
- 判断依据
- 证据索引
- 问题性质
- 整改建议
- 需补充事项
- 状态

### 7. 规则命中统计

字段：

- 规则编号
- 规则名称
- 检查模块
- 命中次数
- 涉及单位数
- 涉及金额
- P0数量
- P1数量
- 误报数量
- 待核数量
- 规则是否需调参

## 项目日报

当用户要求“日报/今天进度/项目驾驶舱”时，输出：

1. 今日数据接收情况
2. 今日新增疑点
3. 已核实疑点
4. 已排除疑点
5. 转问题底稿事项
6. 缺资料清单
7. 明日重点任务
8. 需领导协调事项

## 项目周报

当用户要求“周报/阶段汇总”时，输出：

1. 总体进度
2. 各模块进度
3. 各单位资料完整率
4. 疑点分布和风险等级
5. 重点问题苗头
6. 逾期任务
7. 下周计划
8. 需协调事项

## 报告素材转换规则

疑点转问题时必须满足：

- 事实清楚
- 金额口径明确
- 证据链至少包含数据记录和原始凭证/制度依据
- 有明确违反政策、制度或管理要求
- 已给单位核实或留有核实状态

问题表述模板：

```text
经检查，XX单位在XX期间存在XX问题，涉及金额XX元。具体表现为：XX。上述事项不符合XX规定/要求。建议XX。
```

## 质量控制

输出前检查：

- 疑点编号不重复
- 风险等级不为空
- 涉及金额为数字
- 每条 P0/P1 疑点有建议核查程序
- 问题底稿初稿不得缺判断依据
- 资料补充清单必须有责任部门和截止日期
