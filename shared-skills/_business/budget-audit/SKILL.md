# budget-audit — 收支审计全流程技能

> 融策12大业务线之「收支审计」+「部门预算执行情况审计」
> 支撑资料：杂志资料库353篇（按类型/财政审计353 + 政监68 + 中国审计59 + 审计案例28）
> 对标审计方法：查阅法、核对法、趋势分析、比率分析、因素分析

## 触发条件
`收支审计` `预算执行` `三公经费` `非税收入` `转移支付` `部门决算` `预算偏差` `budget-audit`

## 模块说明

### dim1 — 预算执行偏差分析
- **输入**: 预算批复表.xlsx + 决算报表.xlsx
- **检测**: 收入偏离 / 支出进度 / 结转结余异常 / 科目间调剂
- **输出**: `budget_variance_result.xlsx` + `budget_variance_anomalies.xlsx`
- **阈值**: 收入偏离>15%🔴 / 支出进度<50%或>120% / 结转规模>上年30%

### dim2 — 三公经费审查
- **输入**: 三公经费明细表.xlsx + 决算报表.xlsx
- **检测**: 超预算 / 隐匿科目（隔壁科目异常增长）/ 人均合理性 / 同比环比
- **输出**: `public_expense_result.xlsx`

### dim3 — 非税收入完整性
- **输入**: 非税收入征缴表.xlsx
- **检测**: 应缴vs实缴 / 缓缴合理性 / 减免合规 / 科目串户
- **输出**: `non_tax_result.xlsx`

### dim4 — 转移支付资金跟踪
- **输入**: 转移支付下达文件.xlsx + 资金拨付流水.xlsx
- **检测**: 下达时效 / 滞留截留 / 挪用 / 结转超2年
- **输出**: `transfer_result.xlsx`

## 使用方式

```bash
# 单模块
python dim1_budget_variance.py -b 预算批复.xlsx -d 决算.xlsx

# 全流程（一键）
python run_all.py --data ./审计数据/ --output ./审计报告/
```
