# 绩效审计发现逻辑检查清单

> 来源：审计署2025年度审计报告揭示的绩效管理问题（贝因绩效）
> 提炼时间：2026-06-26
> 适用：绩效评价、预算执行审计、专项资金审计、监督检查

---

## 一、核心原则：三段式发现逻辑

审计署的绩效管理问题发现，遵循 **"形式vs实质""结果倒推""全链条追踪""数据交叉"** 四大方法论：

| 原则 | 含义 | 操作要点 |
|:---|:---|:---|
| **形式vs实质** | 不看"有没有制度"，看"制度有没有运行" | 评审报告 vs 实际预算、制度文件 vs 执行记录 |
| **结果倒推** | 从项目效益未达预期，回溯目标设定和执行过程 | 现场核查结果 → 逆向查立项论证 |
| **全链条追踪** | 预算安排→资金拨付→实际使用→最终效果，逐环节穿透 | 国库支付→银行流水→合同发票→现场验收 |
| **数据交叉** | 评审结果/预算数据/支付数据/现场核查，多维度比对 | 至少3个独立数据源交叉验证 |

## 二、事前环节检查清单

### 2.1 绩效目标设定 — 零基预算"破基数"流于形式

**定性依据**：
- 《预算法》第三十二条：各级政府预算应按"零基预算"原则编制
- 财政部零基预算改革试点要求：基本支出"从零论证"，不受上年基数约束
- 《项目支出绩效评价管理办法》：绩效目标应明确、可衡量、与预算匹配

**检查步骤**：

```
□ Step 1: 获取"零基预算改革试点部门/项目名单"
  └─ 关键文件：试点通知、纳入试点范围的单位清单

□ Step 2: 调取"评审结果文件"
  └─ 关键文件：基本支出补助水平评审报告（含评审结论、调整建议）
  └─ 关注：哪些项目被建议核减？哪些基数被建议打破？

□ Step 3: 调取"实际预算安排明细"
  └─ 关键文件：预算批复文件、部门预算公开表
  └─ 关注：对比上年基数，看是否"只增不减"

□ Step 4: 交叉比对"评审结论 vs 实际安排"
  ├─ 评审建议核减的项目 → 预算中是否落实？
  ├─ 评审认为不合理的基数 → 是否被打破？
  └─ 关注：是否存在"评审后仍按上年基数安排"

□ Step 5: 金额统计
  └─ 计算"评审未落实金额" = 评审建议调整数 - 实际调整数
  └─ 若金额>0 → 定性："评审结果与预算安排两张皮"

□ Step 6: 延伸访谈
  └─ 访谈预算编制人员：评审结果是否收到？为何未使用？
  └─ 访谈评审人员：评审结论是否明确？是否被理解？
```

**审计证据清单**：
| 证据类型 | 具体内容 | 获取方式 |
|---------|---------|---------|
| 制度依据 | 零基预算试点通知、评审办法 | 财政部门/被审计单位 |
| 过程证据 | 评审报告（含评分、排名、建议） | 评审组织方 |
| 结果证据 | 预算批复文件、预算公开表 | 财政/人大 |
| 访谈记录 | 编制人员、评审人员对未使用原因的说明 | 现场访谈 |

**典型定性表述**：
> "XX部门在零基预算改革试点中，对XX个事业单位开展了基本支出补助水平评审，但未有效使用评审结果，仍按上年基数安排预算XX亿元，导致零基预算改革流于形式。"

### 2.2 立项论证 — "先天缺陷"（目标与条件脱节）

**定性依据**：
- 《政府投资条例》第九条：项目单位应编制可行性研究报告，全面分析技术经济可行性
- 各领域专项规定：如保障性安居工程要求"以需定建"、"三北"工程要求符合水资源禀赋

**检查步骤（通用框架）**：

```
□ Step 1: 获取项目立项文件
  └─ 关键文件：可行性研究报告、绩效目标申报表、立项批复
  └─ 关注：绩效目标是否明确、可衡量？是否与预算匹配？

□ Step 2: 获取客观约束条件数据
  └─ 根据项目类型调取对应约束数据：
    ├─ 工程项目 → 地质条件、水文条件、原材料价格
    ├─ 生态项目 → 水资源数据、降水量、土壤条件
    ├─ 安居工程 → 住房需求登记数据、人口分布、交通便利性
    └─ 产业项目 → 市场需求、原材料供应、劳动力成本

□ Step 3: 交叉验证"目标 vs 条件"
  └─ 绩效目标中的量化指标（如"造林XX万亩"）
  └─ 是否考虑了当地客观约束？
  └─ 是否存在"放卫星"式目标设定？

□ Step 4: 结果验证（如项目已实施）
  └─ 现场核查：实际完成量 vs 目标量
  └─ 质量抽检：实际质量 vs 设计标准
  └─ 效益访谈：受益对象是否达到预期？

□ Step 5: 逆向推理
  └─ 若效益未达预期 → 回溯立项论证是否充分
  └─ 若存在偷工减料 → 回溯设计标准是否合理、监理是否履职
```

**三类典型案例检查要点**：

| 案例类型 | 关键检查点 | 数据来源 | 定性标准 |
|---------|-----------|---------|---------|
| **工程类**（偷工减料） | 设计标准 vs 实际用料 | 设计图纸、竣工验收资料、现场抽检 | 材质降级、规格缩水 |
| **生态类**（条件脱节） | 任务布局 vs 资源禀赋 | 项目任务书、水资源评估报告、GIS叠加分析 | 目标设定与客观条件严重脱节 |
| **民生类**（需求错位） | 建设规模 vs 实际需求 | 建设台账、分配记录、需求登记数据 | "以需定建"目标形同虚设 |

**典型定性表述**：
> "XX项目立项阶段绩效目标论证不充分，未充分考虑当地水资源禀赋/住房实际需求/地质条件，导致项目'先天不足'，建成后大量闲置/质量隐患/效益不达标。"

## 三、事中环节检查清单

### 3.1 资金闲置 — 绩效监控失灵

**定性依据**：
- 《预算法》第五十七条：各级政府、各部门应"及时拨付"预算资金
- 《中央部门预算执行管理办法》：基本支出结转原则上不得超过两年

**检查步骤**：

```
□ Step 1: 获取国库集中支付数据/部门银行账户明细
  └─ 关键字段：指标下达日期、实际支出日期、金额、科目

□ Step 2: 计算"资金沉淀时间"
  └─ 公式：沉淀天数 = 实际支出日期 - 指标下达日期
  └─ 筛选：沉淀天数 > 365天（或超过项目周期50%）

□ Step 3: 分类统计
  ├─ 基本支出结转：上年结转金额 vs 本年再结转金额
  ├─ 项目支出结余：项目完工/到期后剩余资金
  ├─ 基建项目结余：竣工决算后剩余资金
  └─ 转移支付：中央下达日期 vs 省级分配日期 vs 市级使用日期

□ Step 4: 分析闲置原因（区分责任）
  ├─ "钱等项目" → 前期工作滞后（项目单位责任）
  ├─ "项目等钱" → 资金下达慢（财政部门责任）
  ├─ "以拨代支" → 钱拨到下属单位但未实际支出（双方责任）
  └─ "无项目可支" → 目标设定不合理（目标设定环节责任）

□ Step 5: 核查"以拨代支"掩盖闲置
  └─ 获取下属单位银行明细
  └─ 核查：资金到账后是否形成实际支出？
  └─ 异常信号：资金到账后长期停留在账户，无对应支出凭证
```

**数据分析SQL模板**：
```sql
-- 查找沉淀超过1年的资金
SELECT 
    单位名称,
    预算科目,
    指标金额,
    指标下达日期,
    实际支出日期,
    DATEDIFF(day, 指标下达日期, 实际支出日期) AS 沉淀天数,
    CASE 
        WHEN DATEDIFF(day, 指标下达日期, 实际支出日期) > 365 THEN '超1年闲置'
        WHEN DATEDIFF(day, 指标下达日期, 实际支出日期) > 730 THEN '超2年闲置'
        ELSE '正常'
    END AS 闲置标签
FROM 国库支付明细
WHERE 实际支出日期 IS NOT NULL
ORDER BY 沉淀天数 DESC;
```

**典型定性表述**：
> "XX部门基本支出结转XX亿元，按上年申报额安排XX亿元，至年底结转增至XX亿元；XX个基建项目结余XX亿元，时间最长的项目达XX年。资金长期闲置，绩效目标难以实现。"

### 3.2 骗取套取 — 以虚假材料骗取财政资金

**定性依据**：
- 《财政违法行为处罚处分条例》第六条：以虚报、冒领等手段骗取财政资金

**检查步骤**：

```
□ Step 1: 梳理资金拨付链条
  中央财政 → 省级财政 → 市级财政 → 项目实施单位 → 施工单位/供应商

□ Step 2: 末端支付核查（重点：施工单位/供应商）
  ├─ 发票核验：登录全国增值税发票查验平台，批量核验发票真伪
  ├─ 合同审查：合同金额、付款条件、履约期限是否合理
  ├─ 工商核查：供应商是否存在？是否为空壳公司？
  └─ 关联排查：供应商与项目单位是否存在人员/地址/电话关联

□ Step 3: 工程量/工作量复核
  ├─ 工程项目：设计图纸 vs 实际施工 → 现场重新测量
  ├─ 服务项目：合同约定服务内容 vs 实际交付成果
  └─ 采购项目：采购清单 vs 实际入库 → 盘点核对

□ Step 4: 资金流向追踪
  └─ 获取施工单位/供应商银行流水
  └─ 追踪：资金最终去向
  └─ 异常信号：资金回流到项目单位人员账户、分散取现、转入关联账户

□ Step 5: 人员访谈
  └─ 访谈施工单位人员：实际施工内容是否与合同一致？
  └─ 访谈项目管理人员：验收过程是否到场？是否存在虚假验收？
```

**关键审计技术**：

| 技术 | 工具/方法 | 应用场景 |
|-----|----------|---------|
| 发票核验 | 全国增值税发票查验平台 | 批量核验发票真伪 |
| 工商关联 | 天眼查/企查查 API | 核查供应商关联关系 |
| 资金流追踪 | 银行流水分析（Python pandas） | 追踪资金最终去向 |
| 工程量复核 | GIS遥感比对/现场测量 | 核实实际完成量 |
| 文本相似度 | TF-IDF/余弦相似度 | 检测投标文件雷同 |

**典型定性表述**：
> "XX项目施工单位通过虚报工程量/使用假发票/设立空壳公司等方式，骗取套取财政资金XX亿元，资金实际用于XX（如回流私分/偿还债务/其他支出）。"

### 3.3 挤占挪用 — 专项资金用于非指定用途

**定性依据**：
- 《预算法》第六十三条：各级政府、各部门应"按预算科目"执行
- 《财政违法行为处罚处分条例》第六条：截留、挪用财政资金

**检查步骤**：

```
□ Step 1: 明确专项资金"指定用途"
  └─ 获取：专项资金管理办法、项目批复文件、绩效目标表
  └─ 关键：资金用途的"正面清单"和"负面清单"

□ Step 2: 追踪资金流向
  专项资金指标 → 县级财政 → 实际支出 → 对方账户
  
□ Step 3: 核查实际用途
  ├─ 对方账户性质：施工单位？国企？偿债专户？三保专户？
  ├─ 支付事由：与预算科目是否一致？
  ├─ 关联验证：对方账户名称 vs 合同约定收款方
  └─ 延伸核查：对方收到资金后的支出明细

□ Step 4: 识别"虚假拨付"脱离监管
  └─ 资金从财政 → 拨至"乡镇/村集体账户"
  └─ 核查该村集体账户：是否有对应真实项目？
  └─ 资金实际被用于其他用途 → 脱离预算监管

□ Step 5: 责任认定
  ├─ 挪用决策：谁决定挪用？是否有会议纪要？
  ├─ 执行环节：谁具体办理拨付？是否知情？
  └─ 受益方：资金实际用于何处？谁受益？
```

**挤占挪用常见去向**：

| 去向类型 | 典型表现 | 核查方法 |
|---------|---------|---------|
| 偿还债务 | 资金转入"偿债专户""债务化解专户" | 查看对方账户名称 |
| 国企经营 | 资金转入平台公司/国企账户 | 工商查询对方性质 |
| 三保支出 | 用于保基本民生/保工资/保运转 | 查看支付明细摘要 |
| 其他项目 | 用于非指定项目支出 | 对比项目批复与支付记录 |
| 个人使用 | 转入个人账户、分散取现 | 银行流水追踪 |

**典型定性表述**：
> "XX县将XX专项资金XX亿元截留挪用，其中XX亿元用于偿还政府债务、XX亿元用于国企自身经营、XX亿元用于基层'三保'支出，偏离专项资金既定用途。"

## 四、事后环节检查清单

### 4.1 项目效益未达预期 — 评价结果"说了不算"

**定性依据**：
- 《项目支出绩效评价管理办法》：绩效评价应客观反映项目效益
- 各领域专项验收标准

**检查步骤**：

```
□ Step 1: 获取绩效目标设定值
  └─ 立项时的绩效目标表：产出数量、质量、时效、成本、效益指标

□ Step 2: 获取实际完成值
  ├─ 项目验收报告
  ├─ 第三方监测报告
  ├─ 现场核查记录
  └─ 受益对象满意度调查

□ Step 3: 计算偏差率
  └─ 公式：偏差率 = (实际值 - 目标值) / 目标值 × 100%
  └─ 筛选：偏差率超过±20%的指标

□ Step 4: 分析原因
  ├─ 目标设定过高？（立项论证问题）
  ├─ 执行管理不善？（过程管控问题）
  ├─ 外部条件变化？（不可抗力）
  └─ 验收走过场？（监管失效问题）

□ Step 5: 关联预算安排
  └─ 该项目下一年度预算是否调整？
  └─ 绩效评价结果是否被用于预算决策？
```

**典型定性表述**：
> "XX项目绩效评价中，XX%的产出指标未达标、XX%的效益指标未实现，但评价结果未与下年度预算安排挂钩，'评而不改、评而不用'。"

---

### 4.2 评价结果与预算安排"两张皮"

**定性依据**：
- 财政部要求：绩效评价结果作为预算安排的重要依据
- 《中共中央 国务院关于全面实施预算绩效管理的意见》：建立"花钱必问效、无效必问责"机制

**检查步骤**：

```
□ Step 1: 获取绩效评价结果
  └─ 近3年绩效评价报告（含评分、等级、问题建议）

□ Step 2: 获取对应年度预算安排
  └─ 评价对象下一年度预算批复

□ Step 3: 交叉比对
  ├─ 评价为"差"的项目 → 预算是否削减/取消？
  ├─ 评价为"优秀"的项目 → 预算是否奖励/优先安排？
  └─ 评价指出问题 → 下年度是否安排整改资金？

□ Step 4: 访谈核实
  └─ 访谈预算编制人员：绩效评价结果如何被使用？
  └─ 访谈绩效管理人员：评价结果是否反馈到预算环节？

□ Step 5: 制度检查
  └─ 是否存在"绩效评价结果应用办法"？
  └─ 办法中是否有刚性约束条款？
```

**典型定性表述**：
> "XX部门虽按规定开展了绩效评价，但评价结果未有效应用于预算安排，'评而不用'，绩效管理闭环断裂。"

## 五、证据链模板

### 5.1 通用证据链结构

```
制度依据（法规/文件）
    ↓
过程证据（评审/立项/执行记录）
    ↓
结果证据（预算/支付/验收数据）
    ↓
交叉验证（至少3个独立数据源）
    ↓
访谈确认（相关人员说明）
    ↓
问题定性（违规类型+金额+责任主体）
```

### 5.2 各环节关键证据汇总

| 审计环节 | 必取证据 | 辅助证据 | 定性标准 |
|---------|---------|---------|---------|
| **事前：目标设定** | 评审报告、预算批复 | 访谈记录、试点通知 | 评审结果未使用 |
| **事前：立项论证** | 可研报告、绩效目标表 | 约束条件数据、验收记录 | 目标与条件脱节 |
| **事中：资金闲置** | 国库支付数据、银行明细 | 项目进度报告、结转说明 | 沉淀超1年/以拨代支 |
| **事中：骗取套取** | 发票、合同、银行流水 | 工商信息、现场核查 | 虚报冒领/假发票/回流 |
| **事中：挤占挪用** | 专项资金管理办法、支付凭证 | 对方账户明细、会议纪要 | 偏离指定用途 |
| **事后：效益评价** | 绩效目标表、验收报告 | 满意度调查、监测报告 | 目标完成率<80% |
| **事后：结果应用** | 评价报告、下年预算 | 制度文件、访谈记录 | 评而不用 |

## 九、附录：预算执行指标的局限与正确用法

### 一、预算执行指标能看什么、不能看什么

| 维度 | 能看到 | 看不到 |
|:---|:---|:---|
| **钱花没花** | 预算指标下达了、实际支出了、余额剩多少 | 钱实际去了哪 |
| **花快花慢** | 各月支付进度、年末突击花钱 | 支付背后的真实事由 |
| **够不够花** | 执行率是否超100%（追加预算） | 追加预算的合规性 |
| **剩多少** | 结转结余金额、沉淀时间 | 为什么沉淀、谁在沉淀 |

**核心局限**：预算执行指标是**"科目维度"**的统计，不是**"交易维度"**的明细。它告诉你"教育支出科目执行了85%"，但不告诉你"这85%里有多少拨给了学校、有多少拨给了平台公司"。

---

### 二、在财政预算一体化系统中怎么看可执行指标

#### 2.1 系统入口

```
预算管理一体化平台 → 国库集中支付 → 可执行指标查询
                    ↓
              常用查询路径：
              ① 指标综合查询（按单位/科目/项目）
              ② 支付明细查询（逐笔交易）
              ③ 结转结余查询（沉淀资金）
              ④ 预算执行分析（执行率统计）
```

#### 2.2 关键字段及审计用法

| 字段 | 含义 | 审计关注点 |
|:---|:---|:---|
| **预算指标文号** | 资金下达的正式文件编号 | 核对指标文件与支付是否匹配 |
| **预算科目** | 功能分类科目（如"教育支出"） | 是否与专项资金指定用途一致 |
| **项目代码/名称** | 具体项目名称 | 是否存在"项目名实不符" |
| **指标金额** | 下达的预算指标总额 | 与项目批复金额是否一致 |
| **已执行金额** | 已实际支付的金额 | 执行率是否合理 |
| **可执行余额** | 指标金额 - 已执行金额 | 沉淀资金规模 |
| **指标下达日期** | 资金下达时间 | 与项目启动时间是否匹配 |
| **支付日期** | 实际支付时间 | 是否存在年末突击支付 |
| **对方账户名称** | 收款方账户名称 | **挤占挪用的关键字段** |
| **支付摘要** | 支付用途说明 | 是否与预算科目一致 |
| **支付方式** | 直接支付/授权支付/集中支付 | 大额是否走直接支付 |
| **资金性质** | 一般公共预算/政府性基金/专项转移支付 | 是否与专项资金性质匹配 |

#### 2.3 挤占挪用审计中的正确操作

**错误做法**：只看"可执行指标余额"和"执行率"

**正确做法**：从可执行指标→逐笔支付明细→对方账户追踪

```
操作路径：

Step 1: 可执行指标查询
  └─ 筛选：专项资金项目（如"农田水利建设资金"）
  └─ 查看：指标金额、已执行金额、可执行余额
  └─ 记录：预算科目、项目代码

Step 2: 逐笔支付明细查询（关键！）
  └─ 点击该项目 → 查看全部支付记录
  └─ 关键字段：支付日期、对方账户名称、支付摘要、金额
  └─ 导出：Excel（便于后续分析）

Step 3: 对方账户分析（发现挪用的核心）
  └─ 筛选支付明细，按"对方账户名称"汇总
  └─ 异常信号：
    ├─ 对方账户含"偿债""债务化解" → 挪用偿还债务
    ├─ 对方账户是平台公司/国企 → 挪用国企经营
    ├─ 对方账户含"三保""工资" → 挪用保民生
    ├─ 对方账户是乡镇/村集体 → 可能虚假拨付
    └─ 对方账户与合同不一致 → 挪用或套取

Step 4: 支付摘要与预算科目比对
  └─ 支付摘要是否包含"工程""采购""服务"等正常业务？
  └─ 异常信号：摘要含"借款""往来""调剂""暂付" → 可能挪用

Step 5: 时间分布分析
  └─ 按月份统计支付金额
  └─ 异常信号：12月支付占全年50%以上 → 突击花钱/挪用
```

### 三、预算执行指标在挤占挪用审计中的辅助线索

虽然不能直接定性，但执行指标的异常模式可以提示"需要深挖"：

| 异常模式 | 可能含义 | 下一步动作 |
|:---|:---|:---|
| **执行率100%但无验收记录** | 虚列支出或挪用 | 逐笔核查对方账户和发票 |
| **某月执行率突然从30%→90%** | 年底突击花钱，可能挪用填窟窿 | 追踪该月支付明细 |
| **同一笔资金分10次以上小额支付** | 规避审批，可能挪用 | 逐笔核查对方账户 |
| **预算科目A执行率不足，科目B超预算** | 科目间调剂，可能挪用 | 对比预算科目与实际支付科目 |
| **可执行余额长期不动后突然清零** | 沉淀资金被一次性挪用 | 追踪清零当月的支付明细 |
| **专项资金执行率低于同类项目** | 资金被挪用于其他项目 | 对比其他同类项目的执行模式 |
| **直接支付比例异常偏低** | 大量走授权支付，规避国库监控 | 抽查授权支付明细 |

---

### 四、一句话总结

> **预算执行指标是"温度计"——能测出"有没有发烧"（资金闲置、执行异常），但测不出"血液里有啥"（挤占挪用、骗取套取）。**
>
> **看挤占挪用，必须从"科目"钻到"交易"，从"执行率"钻到"对方账户"。**
