# subsidy-audit — 政府补贴审计技能

> 融策12大业务线之「政府补贴审计」
> 支撑资料：按类型/农业农村审计17篇 + 政策法规3篇
> 覆盖：农机补贴 / 耕地地力保护 / 产业扶持 / 秸秆禁烧 / 退耕还林

## 触发条件
`政府补贴` `补贴审计` `农机补贴` `耕地补贴` `产业扶持` `惠农资金` `subsidy-audit`

## 三阶段审计链

```
申报合规性 ──→ 拨付追踪 ──→ 使用核查
(前置闸门)     (资金链路)    (实物+绩效)
```

## 模块

### dim1 — 补贴申报合规性
- **检测项**: 资格重复 / 面积虚报 / 权属不清 / 申报材料雷同 / 时间聚类（集中申报）
- **输入**: 补贴申报清册.xlsx
- **输出**: `subsidy_declaration_anomalies.xlsx`

### dim2 — 补贴资金拨付追踪
- **检测项**: 拨付时效 / 代领集中度 / 账户异常（多人同一账户）/ 拨付金额vs申报金额
- **输入**: 拨付流水.xlsx + 银行回单汇总
- **输出**: `subsidy_disbursement_anomalies.xlsx`

### dim3 — 补贴使用核查
- **检测项**: 面积vs卫星图 / 农机GPS轨迹 / 受益人身份验证 / 实地抽查比对
- **输入**: 使用记录.xlsx + 实地核验数据
- **输出**: `subsidy_usage_anomalies.xlsx`

## 使用方式

```bash
# 单模块
python dim1_declaration.py --data 补贴申报清册.xlsx

# 三阶段联动
python run_all.py --declare 申报.xlsx --disburse 拨付.xlsx --usage 使用.xlsx
```

| 信号 | 阈值 |
