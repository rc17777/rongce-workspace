## 🎯 核心方法论

**五层递进架构：每次深度研究按这五步走**

```
L1 基础数据采集  →  结构化一手数据，每条可追溯
L2 补充信息搜索  →  非结构化上下文，三层来源分级
L3 纵向因果链    →  不是年表，追问"为什么"和"怎么影响后续"
L4 横向证据矩阵  →  多维对标，必须声明可比性限制
L5 交叉洞察预判  →  三情景剧本 + 触发条件 + 可观察信号
```

## 📊 关键原则

| 原则 | 说明 |
|------|------|
| **每步有输出** | 不做"想通了再写"，而是"写了才想通" |
| **纵轴≠年表** | 每个节点必须回答"为什么"和"怎么影响后续" |
| **横轴≠排名** | 必须写可比性声明，不硬排名 |
| **交叉=判断** | 必须有情景剧本和可验证信号，不做模糊建议 |
| **缺口需标注** | 未获取的信息要标注对结论的影响程度 |
