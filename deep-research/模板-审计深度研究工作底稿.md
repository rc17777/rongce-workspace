#### 3.5.3 谈话画像技巧

| 要点 | 说明 |
|------|------|
| **不现场做笔录** | 减轻对方紧张感，谈话结束后再整理 |
| **非正式场合谈话** | 食堂、车上、间隙时间，一句"上周那个事，你们领导当时怎么拍板的"往往比正式访谈更管用 |
| **2对1参与** | 带一名组员共同参与，但控制发问人数 |
| **从具体事件入手** | 不直接问"你们领导风格怎样"，而是"XX项目那次变更，领导当时是怎么说的" |
| **兜圈子信号** | 如果谈话对象长时间给不出实质信息，换人/换话题，不强攻 |

## 附A：审计各类型纵轴关键追问速查

### 绩效评价
- 目标设定是否科学（有无依据）？
- 资金投入与产出是否匹配？
- 未达标的原因是可修正的还是结构性的？
- 受益群体是否精准覆盖？

### 资产清查
- 资产什么时候购置的（是否已超使用年限）？
- 闲置期间有无出租出借（租金去哪了）？
- 处置时是否履行审批（残值是否入账）？

### 专项债审计
- 债券资金到位后停了多久？
- 项目收益是否达到预期（偿债能力）？
- 有无挪用/置换（资金实际流向）？

### 经济责任审计
- 任期内哪些决策？
- 决策用的什么信息？
- 后果谁承担？
- 有无"前任埋雷、后任背锅"的情况？

### 监督检查
- 制度本身有无漏洞？
- 谁在负责执行（能力/意愿）？
- 越过了哪些控制环节？
- 以前发现过吗（屡查屡犯）？

## 附B：经济责任审计画像方法论速查

> 来源：知行之路2020 × 融策整理

### 画像五步法

```
测评（场景选择题）→ 谈话（非正式为主）→ 查阅（会议记录本）
    → 对照（决策清单 × 思维惯性） → 提炼（三句话 + 一个词）
```

### 画像维度速查

| 维度 | 两极 | 观察方法 |
|------|------|---------|
| 决策风格 | 激进 ↔ 保守 | 任期重大决策的发起方式+审批链路 |
| 权力偏好 | 集权 ↔ 分权 | 下属自主决策的事项比例 |
| 时间偏好 | 重短期 ↔ 重长期 | 资源向短期指标倾斜还是向长期能力倾斜 |
| 关注重心 | 重业务 ↔ 重管理 | 会议议题分布、亲自过问的事项类型 |
| 执行风格 | 亲力亲为 ↔ 结果导向 | 对过程管控的精细化程度 |
| 风险态度 | 风险偏好 ↔ 风险规避 | 否决/暂缓事项的数量和理由 |

### 情景测评题库（可复用）

1. 工期严重滞后 → A.亲自驻场 B.调配资源 C.问责整改 D.申请延期
2. 预算出现缺口 → A.逐项审核 B.财务调配 C.向上争取 D.削减范围
3. 关键人员流失 → A.亲自挽留 B.外部挖人 C.限期补人 D.内部消化
4. 突发质量事故 → A.亲自处置 B.成立专班 C.层层追责 D.聘请第三方
5. 政策窗口关闭 → A.快速转向 B.暂缓冲锋 C.等待批示 D.收缩回撤

### 画像使用红线

- 画像必须基于可验证的证据（测评、谈话、会议记录、决策后果），**不做主观臆断**
- 三句话概括必须**有事例支撑**，不能用形容词堆砌
- 画像不计入问题定性，仅作为**理解问题根因和整改路径**的辅助工具
- 对领导干部的负面判断必须有**多重证据交叉验证**
