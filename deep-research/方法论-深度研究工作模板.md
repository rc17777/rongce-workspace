# 深度研究工作模板

> 抽象自 pharma-deep-research 五步工作流，适配审计/咨询/政府服务场景
> 融策业务专用 · 2026-05-11

---

## 方法论总纲：五层递进研究架构

```
┌─────────────────────────────────────────────────────────────────┐
│                   深度研究五层递进架构                            │
├───────────────┬─────────────────────────────────────────────────┤
│  Layer 1      │  基础数据采集层  →  结构化一手数据，可追溯锚点     │
│  Layer 2      │  补充信息搜索层  →  非结构化上下文，补齐盲区       │
│  Layer 3      │  纵向因果链分析  →  时间线上的决策逻辑与演变轨迹   │
│  Layer 4      │  横向证据矩阵    →  多维对标，可比性约束声明       │
│  Layer 5      │  交叉洞察与预判  →  判断、情景、行动建议           │
├───────────────┴─────────────────────────────────────────────────┤
│  核心原则：                                                        │
│  1. 每一步都有明确的输入 / 输出 / 校验标准                         │
│  2. 纵向≠年表，必须追问"为什么"和"怎么影响后续"                    │
│  3. 横向≠排名，必须声明可比性限制与数据口径                        │
│  4. 交叉=判断，必须有情景剧本和可验证信号                           │
└─────────────────────────────────────────────────────────────────┘
```

## Layer 1：基础数据采集层

### 目的
用脚本/工具/手工方式从权威数据源采集结构化数据，建立可追溯的"原始数据层"。

### 通用清单

| 要素 | 说明 |
|------|------|
| **数据源定义** | 列出所有权威数据源（数据库/系统/文件/公开接口） |
| **采集方式** | 脚本自动化 / API调用 / 手工整理 / 爬虫 |
| **结构化字段** | 每条数据必须有：来源、日期、关键数值、可信度标记 |
| **产出物** | 数据摘要表 + 原始数据归档 |

### 审计场景适配

| 数据源 | 采集内容 | 典型产出 |
|--------|---------|---------|
| 被审计单位财务系统 | 科目余额表、凭证表、预算执行表、资产台账 | 结构化数据表 50-200条 |
| 政府采购网/公共资源交易平台 | 招标公告、中标公告、合同备案 | 采购项目清单 10-50条 |
| 财政一体化系统 | 指标下达、支付明细、结转结余 | 资金流数据 |
| 工商/税务/社保外部数据 | 关联企业、人员交叉、纳税申报 | 关联关系图谱 |
| 往期审计报告/整改台账 | 历史问题、整改状态 | 历史问题库 |

**审计场景校验标准：**
- [ ] 数据覆盖审计期间全量
- [ ] 关键字段（金额/日期/科目）无缺失
- [ ] 外部数据已做脱敏和口径对齐
- [ ] 异常值已标记但未剔除

### 咨询场景适配

| 数据源 | 采集内容 | 典型产出 |
|--------|---------|---------|
| 招标文件/技术规范 | 工程量清单、技术参数、评分标准 | 需求矩阵 |
| 市场询价/造价信息网 | 材料价格、设备价格、人工费 | 造价基准表 |
| 项目现场勘查 | 地形地貌、现状条件、限制因素 | 现状评估报告 |
| 地方政策/规划文件 | 用地规划、产业政策、环保要求 | 政策约束清单 |
| 同类型项目案例库 | 工期、造价、方案、问题 | 对标基准数据库 |

## Layer 2：补充信息搜索层

### 目的
结构化数据覆盖了"范围"，但深度研究还需要非结构化信息来理解上下文、动机和约束条件。

### 三层来源分级

| 层级 | 性质 | 示例 | 使用规则 |
|------|------|------|---------|
| **一手信息** | 官方/权威原始信息 | 政府公告、红头文件、官方统计数据、审计底稿 | 可直接引用为结论支撑 |
| **二手信息** | 权威媒体的解读/汇总 | 行业报告、政策解读、专家分析 | 可作为分析线索，需交叉验证 |
| **线索信息** | 非正式但可能有价值 | 媒体报道、举报线索、社区反馈、访谈纪要 | 只能指引方向，不能作为结论 |

### 审计场景搜索清单

```
☐ 被审计单位官网/公众号（自查自纠、重大事项披露）
☐ 当地政府门户（相关政策、规划、批复文件）
☐ 行业主管部门（行业动态、专项整治通知）
☐ 天眼查/企查查（关联企业、股权变更、司法诉讼）
☐ 新闻/舆情监测（负面报道、投诉举报线索）
☐ 前序审计组的访谈纪要/工作底稿
☐ 审计署/财政部发布的同类案例通报
```

### 咨询场景搜索清单

```
☐ 甲方官网（战略规划、年度报告、重大项目公示）
☐ 行业政策动态（新标准、新规范、补贴政策变化）
☐ 竞争对手分析（类似项目的方案、报价、中标情况）
☐ 新技术/新材料动态（可替代方案、成本趋势）
☐ 地方规划（国土空间规划、十四五/十五五专项规划）
☐ 环境和社区影响（环评公示、居民反馈）
```

## Layer 3：纵向因果链分析

### 目的
**不是做时间线，而是追问"为什么"。** 每个关键节点必须回答：
1. 当时为什么做了这个决策/发生了什么变化？
2. 这个节点怎么影响了后面的走向？

### 通用模板

```
节点 N: [时间] [事件]
  ├── 当时为什么发生？
  ├── 谁主导/谁受益？
  ├── 直接后果是什么？
  └── 如何影响了后续 N+1, N+2 节点？
```

### 审计场景：问题演变因果链

**案例：预算执行率偏低问题**

```
2018  ──▶ 项目立项，预算申报 1200 万（依据什么估算的？）
   │
2019  ──▶ 实际执行 380 万（为什么只执行 31%？）
   │         ├── 原因1：前期论证不充分，实施条件不具备
   │         ├── 原因2：配套资金未到位
   │         └── 原因3：项目审批流程拖延
   │
2020  ──▶ 结转 820 万 → 被财政收回 500 万（触发什么机制？）
   │
2021  ──▶ 同类项目再次申报 1500 万（为何继续申报？有无问责？）
   │
2025  ──▶ 审计发现：4年累计预算执行率仅 41%，资金沉淀+重复申报
          → 深层原因：缺乏项目前期论证把关和预算执行问责机制
```

**审计因果链检查要点：**

| 审计主题 | 关键纵轴问题 |
|---------|------------|
| 预算执行 | 钱为什么没花出去？结转后去了哪？下一年又申报了吗？ |
| 专项资金 | 拨付链条上哪个环节断了？资金在哪个账户停了多久？ |
| 政府采购 | 为什么选了这个供应商？合同变更了哪些条款？验收谁签的字？ |
| 资产管理 | 什么时候购置的？什么时候闲置的？期间有没有出租/出借？ |
| 经济责任 | 决策是谁签的字？依据什么信息做的决策？后果谁承担？ |

### 咨询场景：项目全生命周期因果链

**案例：工程咨询项目**

```
规划阶段 ──▶ 立项依据：（为什么上这个项目？政策驱动还是需求驱动？）
   │
设计阶段 ──▶ 方案选择：（为什么要这个方案而不是那个？造价/工期/质量权衡？）
   │
招标阶段 ──▶ 发包策略：（为什么分标段？为什么设这个资质门槛？）
   │
施工阶段 ──▶ 变更管理：（设计变更有多少？谁发起的？增加多少造价？）
   │
竣工阶段 ──▶ 验收结算：（结算超预算多少？分歧点在哪？）
```

## Layer 4：横向证据矩阵

### 目的
**不做硬排名，做可比性约束下的多维证据呈现。** 关键规则：
1. 选 3-5 个对标对象，按固定维度列表
2. **必须写可比性声明**：哪些维度可直接比、哪些不能
3. 数据口径不一致时必须标注

### 通用矩阵模板

```
┌──────────┬──────────┬──────────┬──────────┬──────────┐
│ 维度     │ 对象A    │ 对象B    │ 对象C    │ 对象D    │
├──────────┼──────────┼──────────┼──────────┼──────────┤
│ 维度1    │          │          │          │          │
│ 维度2    │          │          │          │          │
│ 维度3    │          │          │          │          │
│ 维度4    │          │          │          │          │
│ 维度5    │          │          │          │          │
├──────────┴──────────┴──────────┴──────────┴──────────┤
│ 可比性声明：                                          │
│  · 维度X和维度Y可直接比（数据口径一致）               │
│  · 维度Z不宜直接比（原因：数据来源不同/口径不同）      │
│  · 可靠结论：_____                                   │
└──────────────────────────────────────────────────────┘
```

### 审计场景：多单位/多项目横向对比

| 维度 | 被审计单位 | 同类单位A | 同类单位B | 行业基准 |
|------|----------|----------|----------|---------|
| 预算执行率 | 41% | 78% | 85% | ≥70% |
| 三公经费占比 | 6.2% | 3.8% | 4.1% | ≤5% |
| 资产闲置率 | 23% | 8% | 12% | ≤10% |
| 采购节约率 | 2.1% | 8.5% | 7.3% | ≥5% |
| 结转结余消化率 | 31% | 82% | 75% | ≥80% |
| **可比性声明** | | | | |
| · 预算规模和单位类别相近，预算执行率可直接比 | | | | |
| · 资产闲置率受单位成立时间和历史积累影响，部分差异有合理性 | | | | |
| **可靠结论**：预算执行和资产管理明显低于同类单位，存在系统性问题 | | | | |

### 咨询场景：方案比选/对标分析

| 维度 | 方案A（推荐） | 方案B | 方案C | 评分权重 |
|------|------------|-------|-------|---------|
| 技术可行性 | ★★★★★ | ★★★★ | ★★★ | 30% |
| 经济合理性 | ★★★★ | ★★★★★ | ★★★ | 25% |
| 工期 | ★★★★ | ★★★ | ★★★★★ | 20% |
| 运维成本 | ★★★★★ | ★★★ | ★★★ | 15% |
| 环保合规 | ★★★★ | ★★★★ | ★★★ | 10% |
| **可比性声明** | | | |
| · 方案B的造价数据基于2024年定额，其他方案基于2025年定额（口径偏差约3%） | | |
| · 方案C的运维成本估算较粗糙，实际成本可能偏高 | | | |

## Layer 5：交叉洞察与情景预判

### 目的
纵轴让你理解"怎么走到今天的"，横轴让你知道"别人是什么水平"。
**真正值钱的是交汇点：产出判断、情景、行动建议。**

### 通用三情景框架

| 情景 | 概率 | 核心假设 | 关键触发条件 | 90天内可观察信号 |
|------|------|---------|------------|-----------------|
| **基准** | 60% | 趋势延续 | _____ | _____ |
| **悲观** | 20% | 风险兑现 | _____ | _____ |
| **乐观** | 20% | 积极驱动 | _____ | _____ |

### 审计场景：问题定性与整改预判

```
案例：某单位"三公经费"连续3年超预算

【纵轴发现】：2019年开始超支，原因是"招商引资任务加重导致接待费激增"
             → 2021年上级发过整改通知但未见实质性改善
             → 2023年预算编制时仍按"历史基数法"编制，未反映实际精简要求

【横轴发现】：同系统5家单位中，该单位三公经费占比最高（6.2% vs 均值4.2%）
             → 差旅费与同类单位持平，异常集中在"公务接待费"科目
             → 进一步发现接待费凭证中有12笔超出接待标准

【交叉判断】：
┌────────┬──────────┬──────────────────────────────────────┐
│ 情景   │ 概率      │ 判断                                  │
├────────┼──────────┼──────────────────────────────────────┤
│ 基准   │ 55%      │ 属于制度执行偏差，非主观恶意           │
│        │          │ → 建议：规范接待审批流程+预算编制改革  │
│        │          │ 信号：被审计单位是否承认并愿意整改      │
├────────┼──────────┼──────────────────────────────────────┤
│ 严重   │ 30%      │ 超标准接待可能涉及个人消费              │
│        │          │ → 建议：移送纪检进一步核查              │
│        │          │ 信号：凭证中的接待对象/事由是否真实     │
├────────┼──────────┼──────────────────────────────────────┤
│ 系统性 │ 15%      │ 同类问题在同系统其他单位也存在          │
│        │          │ → 建议：提交上级主管部门系统整改        │
│        │          │ 信号：抽查同类单位是否出现相同模式      │
└────────┴──────────┴──────────────────────────────────────┘
```

### 咨询场景：项目可行性/风险预判

```
案例：某市政道路改造项目投标决策

【纵轴】：甲方近年同类项目 → 3个中有2个结算超预算15%以上
         → 超支原因集中在"管线迁改不可预见费"
         → 该区域地下管网资料不完整

【横轴】：竞品分析 → 5家潜在对手，2家有区域深耕经验
         → 低价策略将触发恶性竞争，合理利润率区间8-12%

【交叉判断】：
┌────────┬──────┬──────────────────────────────────────────┐
│ 基准   │ 55%  │ 中标价约3800万，利润率9%，工期可控        │
│        │      │ 信号：投标前能否拿到地下管网物探资料      │
├────────┼──────┼──────────────────────────────────────────┤
│ 风险   │ 30%  │ 管线迁改实际成本超预期300万+，侵蚀利润    │
│        │      │ 信号：前30天施工中管线冲突次数             │
├────────┼──────┼──────────────────────────────────────────┤
│ 机会   │ 15%  │ 甲方追加二期工程，溢价续约                │
│        │      │ 信号：一期施工质量和进度评价              │
└────────┴──────┴──────────────────────────────────────────┘
```

## 配套校验清单（每层完成后的自检）

### Layer 1 数据采集自检
- [ ] 数据源清单是否覆盖了所有应采集的权威来源？
- [ ] 关键字段有无缺失（金额、日期、主体）？
- [ ] 每条数据是否可以追溯到原始出处？

### Layer 2 信息补充自检
- [ ] 是否覆盖了一手/二手/线索三个层级？
- [ ] 是否存在明显的"信息盲区"未覆盖？
- [ ] 线索信息来源是否标注了可信度等级？

### Layer 3 纵向因果自检
- [ ] 每个节点是否回答了"为什么"和"怎么影响后续"？
- [ ] 是否有 5-7 个关键决策节点（不是流水账）？
- [ ] 因果关系是否有证据支撑（不是推测）？

### Layer 4 横向矩阵自检
- [ ] 对标对象是否足够（3-5个）且有代表性？
- [ ] 是否写了可比性声明？
- [ ] 数据口径不一致处是否标注了偏差范围？

### Layer 5 交叉洞察自检
- [ ] 三情景都有触发条件和可观察信号吗？
- [ ] 每个判断都有纵轴+横轴的证据支撑吗？
- [ ] 行动建议是否具体到"谁、什么时候、做什么"？

## 附录：融策业务场景 → 五层框架速查

| 业务场景 | L1 数据 | L2 信息 | L3 纵轴 | L4 横轴 | L5 洞察 |
|---------|--------|--------|--------|--------|--------|
| **绩效评价** | 绩效目标表、自评报告、财务数据 | 公众满意度、上级评价 | 目标→执行→偏差→修正的因果链 | 同类项目绩效横向对比 | 绩效等级判定+改进路径 |
| **资产清查** | 资产台账、财务账、实物盘点 | 资产使用部门访谈 | 资产购置→使用→处置全生命周期 | 同类单位资产配置对标 | 盘盈盘亏定性+闲置盘活方案 |
| **专项债审计** | 债券发行数据、资金拨付流水 | 项目进度报告、主管部门批复 | 资金到位→拨付→使用→收益的链条 | 同类专项债项目进度对比 | 资金沉淀风险+偿债能力预判 |
| **监督检查** | 政策文件、被查单位资料 | 投诉举报、舆情监测 | 制度→执行→效果的问题溯源 | 同行业/同区域横向对比 | 问题严重性分档+追责建议 |
| **经济责任审计** | 任期财务数据、重大决策记录 | 离任交接材料、职工访谈 | 任期内重大决策→后果的因果链 | 前后任/同岗位横向对比 | 责任界定+风险等级判定 |
| **标书撰写** | 招标文件、评分标准、资质要求 | 甲方背景、竞品情报 | 甲方历史项目→偏好→需求的演变 | 竞品方案/报价横向对比 | 中标策略+差异化定位 |
| **预算编制** | 定额标准、历史造价数据 | 材料市场行情、政策变化 | 项目全生命周期成本链 | 同类项目造价对比 | 预算精度预判+风险预留 |
| **工程结算** | 合同文件、变更签证、验收记录 | 施工日志、监理报告 | 施工→变更→结算的全链条 | 同类工程结算偏差率对标 | 争议焦点预判+谈判策略 |
