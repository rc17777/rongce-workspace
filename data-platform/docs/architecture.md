## 2. 四层架构详解

### 2.1 数据采集层
- **财务数据采集**：对接金蝶、用友等财务系统，支持Excel/CSV导入
- **业务数据采集**：对接工程管理系统、项目管理系统
- **外部数据采集**：政策法规、招投标信息、工商信息
- **文件数据解析**：PDF、Word、Excel等非结构化数据解析

### 2.2 数据治理层
- **数据标准管理**：统一数据字典、编码规范、命名规范
- **数据质量监控**：完整性、准确性、一致性、时效性检查
- **元数据管理**：数据血缘、影响分析、资产目录
- **数据安全管控**：分级分类、脱敏、访问控制

### 2.3 数据融合层
- **数据仓库**：面向主题的集成数据存储
- **数据集市**：面向审计场景的专题数据
- **标签体系**：客户标签、项目标签、风险标签
- **知识图谱**：审计知识、法规知识、行业知识

### 2.4 数据服务层
- **审计分析引擎**：多维度分析、趋势分析、对比分析
- **风险预警引擎**：异常检测、风险评分、预警推送
- **报告生成引擎**：自动化报告、智能排版
- **智能检索引擎**：全文检索、语义检索、智能推荐

## 3. 技术栈

| 层级 | 技术选型 |
|------|---------|
| 存储 | PostgreSQL + ClickHouse + MinIO |
| 计算 | Python + Pandas + Spark |
| 调度 | Apache Airflow |
| 缓存 | Redis |
| 消息 | RabbitMQ |
| 监控 | Prometheus + Grafana |
