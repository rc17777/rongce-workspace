# 实施方案生成 (Implementation Plan)

## 元数据

- **类型**：interactive（交互式）
- **命令**：`/audit:implementation-plan`
- **前置条件**：需先运行 policy-digest（需有政策知识库）
- **输入**：CLAUDE.md + 业主需求 + 审计目的
- **输出**：结构化实施方案草稿（DRAFT）

---

## 目标

基于政策要求和审计目的，自动生成结构化实施方案。

不是套模板。是 **政策→目的→重点→方法→风险的逻辑推导**。

---

## 工作流程

### 第一步：读取上下文
从 CLAUDE.md 读取：
- 项目标识和审计类型
- 政策知识库（关键要求、红线）
- 审计目的

### 第二步：业主需求结构化

```
/audit:implementation-plan

AI 依次提问：
1. 业主的审计目的是什么？重点关注什么？
2. 审计范围？（时间范围、单位范围、资金范围）
3. 业主最担心的风险是什么？
4. 有没有特殊性要求？（如保密、时间紧迫等）
5. 被审计单位的基本情况？（规模、管理模式、以往问题）
```

### 第三步：审计重点推导

基于政策知识库 + 审计目的 → 推导审计重点：

```
政策要求          业主关注         → 审计重点
─────────────────────────────────────────────
资金专款专用      资金安全问题      资金流向追踪
按时拨付到位      项目进度缓慢      拨付时限核查
配套资金落实      地方财政困难      配套到位核查
招投标合规        廉政风险关注      采购程序审查
绩效目标完成      项目实效          产出效益评价
```

### 第四步：审计方法匹配

根据审计重点自动匹配合适的方法组合：

| 审计重点 | 推荐方法 | 原因 |
|---------|---------|------|
| 资金流向 | 财务核查+数据分析 | 需要逐笔追踪 |
| 程序合规 | 查阅法+穿行测试 | 需要验证流程 |
| 实施效果 | 实地考察+访谈 | 需要现场验证 |
| 绩效达标 | 对比分析+复核计算 | 需要量化比较 |
| 政策执行 | 查阅法+访谈 | 需要对比政策与执行 |

### 第五步：风险点预判

基于政策红线 + 行业常见问题 + 项目特点 → 预判风险：

```markdown
## 关键风险点预判

| 风险领域 | 具体风险 | 风险等级 | 政策依据 | 检查方法 |
|---------|---------|---------|---------|---------|
| 资金管理 | 挪用专项资金 | 高 | 《[文件]》第X条 | 资金流水穿行测试 |
| 采购程序 | 规避招标 | 高 | 《招标投标法》第X条 | 合同+采购记录查阅 |
| 项目进度 | 资金闲置 | 中 | 《[文件]》第X条 | 拨付记录+实地核查 |
| 绩效目标 | 虚报完成 | 中 | 《[文件]》绩效指标 | 产出数据复核 |
```

### 第六步：生成完整方案

```markdown
# XX项目审计实施方案

⚠️ **DRAFT — 需CPA复核确认**

## 一、审计背景
[自动生成项目背景概述]

## 二、审计目的与依据
[审计目的 + 依据的政策文件列表]

## 三、审计范围
### 时间范围
### 单位/项目范围
### 资金范围

## 四、审计重点
[优先级排序的审计重点列表]

## 五、审计方法
[方法组合 + 每种方法的具体应用说明]

## 六、审计程序与时间安排
| 阶段 | 工作内容 | 方法 | 时间 | 责任人 |
|------|---------|------|------|--------|

## 七、关键风险点
[风险点预判表]

## 八、预期成果
- 审计报告
- 审计底稿
- 问题清单
- 管理建议

## 九、人员分工
[人员安排建议]

## 十、注意事项
[保密要求、沟通机制、特殊安排]
```

---

## 参数

```
/audit:implementation-plan                    → 基于 CLAUDE.md 生成
/audit:implementation-plan --detailed         → 详细版（含具体检查步骤）
/audit:implementation-plan --outline          → 大纲版（框架级）
/audit:implementation-plan --update           → 更新已有方案
```

---

## 方案质量标注

- 📌 每个审计重点必须标注对应的政策依据
- 🔍 风险预判标注来源（政策条款 vs AI经验推断）
- ⚠️ 整体标注 DRAFT — 需CPA复核确认后方可作为正式方案
