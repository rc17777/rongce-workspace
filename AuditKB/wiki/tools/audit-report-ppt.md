# 审计报告PPT生成技能 (audit-report-ppt)

> 来源：《我把花叔的女娲 Skill 装进了我的 PPT 工作流》（萤火杂谈记公众号）
> 整合时间：2026-06-03
> 技能位置：`C:\Users\Admin\.aweskill\skills\audit-report-ppt\`

## 核心理念

**先蒸馏受众，再生成表达** — 不是先写内容再找模板，而是先搞清楚"领导脑子怎么转"再决定每页放什么。

## 工作流程（5阶段）

```
阶段A：蒸馏受众（女娲6 Agent并行）
  ↓ audience-card.md
阶段B：蒸馏评审专家（审查逻辑+否决习惯）
  ↓ reviewer-card.md
阶段C：内容规划（受众×评审×素材=每页内容）
  ↓ delivery-doc.md
阶段D：代码生成（python-pptx直接输出.pptx）
  ↓ presentation.pptx
阶段E：评审验证（P0/P1/P2修改清单）
```

## 三种预设受众

| 受众类型 | 决策框架 | 核心特征 |
|----------|---------|----------|
| 地方政府领导 | 袁家军式 | 系统工程+数据闭环+可复制 |
| 被审单位一把手 | 问责防御型 | 责任边界+历史成因+整改可行性 |
| 上级审计机关 | 专业审慎型 | 法规依据充分+逻辑链完整 |

## 9种核心页型

| 页型 | 代码 | 审计报告示例 |
|------|------|------------|
| 封面页 | T01 | 某区20XX年度财政收支审计报告 |
| 目录页 | T02 | 审计范围/内容/主要发现 |
| 章节过渡页 | T03 | "一、审计发现" |
| 原因分析页 | T04 | 问题成因深度分析 |
| 对比页 | T06 | 整改前后对比（左灰右蓝） |
| 证据链页 | T07 | 资金流向/审批流程 |
| 数字突出页 | T10 | 违规金额856.3万（大数字冲击） |
| 问题清单页 | T14 | 问题分类汇总 |
| 时间轴页 | T16 | 审计时间线/违规行为时间线 |
| 整改建议页 | T17 | P0/P1/P2+责任单位+完成时限 |

## 风格卡（蓝色汇报）

| 元素 | 颜色 | 用途 |
|------|------|------|

## 关键规则

- 每页文字不超过50字（审计报告尤忌堆砌）
- 法规依据必须标注（P0必须）
- 数字>100万用红色加粗
- 整改率<80%用橙色（不用绿色）
- 不超过20页（政府汇报标准上限）

## 🔗 发现问题逻辑链

本文逻辑链是"归纳总结型"型：

```
女娲方法论（公众号文章）
  ↓ 解构
受众蒸馏+评审卡+页型映射三大核心理念
  ↓ 适配审计场景
9种审计报告页型 + 蓝色风格卡 + 预设受众卡
  ↓ 技能化
audit-report-ppt SKILL.md + 3个references + python-pptx脚本
  ↓ 自动化
py -3 generate_audit_ppt.py → 审计报告_演示.pptx
```

**关键特征**：从"人做PPT"到"AI按受众逻辑自动生成PPT"的方法论迁移
**与相似条目的区别**：与audit-report-writer互补——文字版报告→PPT汇报，受众蒸馏是独有亮点
