# 采购文件合规审查 — 产品说明

> 产品编号：RONGCE-WIKI-PROC-002
> 版本：v1.0 | 最后更新：2026-07-14
> 来源：knowledge/articles/政府采购资格条件合规审查-2026.md + 采购文件编制十必审.md

## 产品定位

面向采购人/代理机构的**招标文件发布前合规审查服务**，聚焦《政府采购法实施条例》第二十条8种差别歧视情形+87号令3个禁区，帮助客户规避质疑投诉和行政处罚风险。

## 核心依据

### 8种法定差别歧视情形（实施条例第20条）

| # | 情形 | 典型违规操作 | 识别方法 |
|:--|:-----|:------------|:---------|
| ① | 信息差别待遇 | 向"内定"供应商单独发送技术参数 | 技术要求过于精准，仅1家满足 |
| ② | 资格条件与项目无关 | 300万办公家具要求ISO 14064认证 | 资格必须与"具体特点和实际需要相适应" |
| ③ | 技术参数指向特定供应商 | CPU参数只匹配某一型号 | 电商搜仅1-2家满足→量身定制 |
| ④ | **特定区域/行业业绩** | 要求"本省同类项目业绩" | **最常见违规，明文禁止** |
| ⑤ | 不同供应商不同标准 | 对A只看报价，对B细查方案 | 较难察觉，一旦发现即是违法 |
| ⑥ | 限定专利/商标/品牌 | "某品牌或同等档次" | "同等档次"是变相指定 |
| ⑦ | 限定所有制/所在地 | "须为国企""须本地注册" | 政府采购不问所有制 |
| ⑧ | 其他不合理条件 | 过高保证金、报名时交全部投标文件 | 兜底条款 |

### 87号令三个特别禁区

| 禁区 | 条款 | 禁止内容 | 常见违规示例 |
|:-----|:-----|:---------|:------------|
| **禁区一** | 第17条 | 不得以规模条件作为资格/评审因素 | 注册资本≥5000万、营收≥2亿 |
| **禁区二** | 第17条 | 不得将厂家授权作为资格要求（进口除外） | "须提供生产厂家针对本项目的授权书" |
| **禁区三** | 第55条 | 资格条件不得作为评审因素 | 资格要求ISO 9001，评分项又给它加分 |

## 十必审清单

| 审次 | 审查项 | 重点 |
|:-----|:-------|:-----|
| 第一审 | 资格条件是否合法合规 | 查条例第20条8种情形 |
| 第二审 | 采购需求是否完整明确 | 1000万以上货物/服务需需求调查 |
| 第三审 | 技术参数有无倾向性、排他性 | 参数须标注来源，非标需3家对照表 |
| 第四审 | 评审标准是否量化细化 | 禁止"优良好差"等模糊表述 |
| 第五审 | 价格分权重是否合法 | 货物≥30%，服务≥10% |
| 第六审 | 合同条款是否完整公平 | 不得改变采购文件实质性要件 |
| 第七审 | 政策功能是否落实 | 中小企业预留+价格评审优惠 |
| 第八审 | 实质性条款是否醒目标明 | 带"★"条款集中列明 |
| 第九审 | 保证金等商务条件是否合理 | 不得设定不合理金额或退还条件 |
| 第十审 | 采购实施计划是否完整可执行 | 明确采购方式+评审规则+定价方式 |

2026年6月，财政部+公安部+市监局联合印发《关于开展2026年政府采购领域"四类"违法违规行为专项整治工作的通知》，聚焦：

2. 代理机构乱收费
3. 供应商提供虚假材料
4. 供应商围标串标

专项整治时间：2026年6月中旬至12月底，分7个阶段推进
