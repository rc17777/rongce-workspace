# 围标串标全维度检测体系 — 产品说明

> 产品编号：RONGCE-WIKI-PROC-001
> 版本：v3.7 | 最后更新：2026-07-14
> 来源：procurement-audit-models skill + knowledge/articles/ 入库文章

## 产品定位

面向政府审计、国企采购监督场景的**围标串标检测工具包**，覆盖23层检测维度+9层纵深防御，从报价规律到硬件指纹，从单项目分析到跨项目围标集团识别。

## 检测维度一览

### 核心23层（标准检测）

| 层级 | 检测维度 | 数据源 | 证据强度 |
|:----|:---------|:-------|:--------|
| **L1** | 报价规律性 | 开标一览表/分项报价表 | 🔴铁证 |
| **L2** | 投标IP/MAC | 系统日志+标书加密元数据 | 🔴铁证 |
| **L3** | 文本雷同(TF-IDF) | 技术标/商务标全文 | 🔴铁证 |
| **L4** | 图片/资源哈希 | PDF嵌入图片→感知哈希 | 🔴铁证 |
| **L5** | 元数据交叉 | PDF Author/Creator/Producer | 🔴铁证 |
| **L6** | 文档结构/字体 | PDF页面字体span统计 | 🟡强信号 |
| **L7** | 生成设备信息 | PDF Producer/扫描仪型号 | 🟡强信号 |
| **L8** | 工商关联穿透 | 多层股权穿透+中心性+派系发现 | 🔴铁证 |
| **L9** | 保证金/资金链 | 银行汇款凭证+电子保函编号 | 🔴铁证 |
| **L10** | 评标打分异常 | 评分汇总表/评委逐项打分 | 🔴铁证 |
| **L11** | 供应商伴随投标 | 频繁项集挖掘+关联规则 | 🔴铁证 |
| **L12** | 历史投标异常关联 | 异常标记库 | 🔴铁证 |
| **L13** | 节资率分析 | 招标台账(控制价+中标价+投标人) | 🟡强信号 |
| **L14** | 最优围标人数 | 投标单位数=3~4 | 🟡强信号 |
| **L15** | 历史中标模式分析 | 陪标+中标专业户双向识别 | 🔴铁证 |
| **L16** | 保证金同时缴纳 | 同项目时间差<10分钟 | 🟡强信号 |
| **L17** | 经办人一致性 | 项目负责人姓名/身份证相同 | 🟡强信号 |
| **L18** | 硬件指纹检测 | 硬盘/MAC/CPU/主板/机器码 | 🔴铁证 |
| **L19** | 评标专家违规 | 未回避/跨项目一致/签到异常 | 🔴铁证 |
| **L20** | 发票Benford分析 | 发票金额首位数字分布 | 🔴铁证 |
| **L21** | 供应商行为指纹 | 7维特征向量→余弦相似度 | 🔴铁证 |
| **L22** | 先付款后签合同 | 时序倒挂+经办人集中度 | 🔴铁证 |
| **L23** | 合同变更轨迹 | 验收后金额调减→虚高信号 | 🔴铁证 |

### 纵深9层（数字取证级）

| 层级 | 检测维度 | 工具/方法 | 适用场景 |
|:----|:---------|:---------|:--------|
| D1 | WPS签名残留 | PDF全文搜索 | 元数据被清除时 |
| D2 | JPEG量化表指纹 | DQT表提取+哈希比对 | 扫描件PDF图像分析 |
| D3 | JPEG文件完整性 | FFD8/FFD9标记验证 | 检测PDF是否"重新封装" |
| D4 | 像素分布统计 | RGB均值/标准差/偏度 | 检测扫描来源一致性 |
| D5 | 文件系统时间线 | stat(ctime/mtime/atime) | 还原文件制作时序 |
| D6 | 节资率箱线图 | IQR异常检测 | 竞争不足围标信号 |
| D7 | 支持度/置信度矩阵 | 投标人共现网络 | 长期联手围标集团 |
| D8 | 提升度(Lift)分析 | 区分随机共现vs人为操纵 | Lift>800为强关联 |
| D9 | 评标专家社交图谱 | 专家-投标单位雇佣关系 | 利益冲突挖掘 |

## 用法

### 标准流程
```
1. 获取数据 → 投标文件/开标记录/评分表/台账
2. 按项目类型选择检测策略
3. 逐层执行检测脚本
4. 交叉验证 → 输出《疑点清单》
```

### 项目类型策略
| 类型 | 特征 | 优先检测层 |
|:-----|:-----|:----------|
| 小额服务采购 | 预算<100万,3-5家 | L5元数据 → D1-D5 → L4图片 |
| 货物采购(公开招标) | 100-500万,3-6家 | L5元数据 → L1报价 → L3文本 → L4图片 |
| 大型工程监理 | 预算大,10-30家,标书极长 | L3 TF-IDF → L5元数据 → L1报价 → L8工商 |

## 输出物

《围标串标疑点检测报告》（Excel格式，10 Sheet标准模板）
