在现实中，审计员要面对成千上万条交易记录。如果完全靠人工，一定会遗漏风险点。这时候，Python 就能派上用场。

我们用 报销/付款数据 来模拟，检查以下几类风险：

- 金额异常：超过阈值的大额交易。
- 重复报销：同一人、同一金额、多次出现。
- 拆分支付：同一人短期内多笔小额，但累计超过限额。
- 高风险对象：特定供应商/个人频繁出现。

示例数据：

| 姓名 | 金额 | 日期 | 供应商 | 票据号 |
|------|------|------|--------|--------|
| 张三 | 4800 | 2023-03-01 | A公司 | 001 |
| 张三 | 4900 | 2023-03-02 | A公司 | 002 |
| 李四 | 12000 | 2023-03-05 | B公司 | 010 |
| 王五 | 3000 | 2023-03-05 | C公司 | 011 |
| 张三 | 4800 | 2023-03-10 | A公司 | 012 |
| 李四 | 12000 | 2023-03-15 | B公司 | 020 |
| 赵六 | 50000 | 2023-03-18 | D公司（高风险）| 021 |

Python代码演示：

```python
import pandas as pd

# 模拟数据
data = {
    "name": ["张三","张三","李四","王五","张三","李四","赵六"],
    "amount": [4800,4900,12000,3000,4800,12000,50000],
    "date": ["2023-03-01","2023-03-02","2023-03-05","2023-03-05",
             "2023-03-10","2023-03-15","2023-03-18"],
    "vendor": ["A公司","A公司","B公司","C公司","A公司","B公司","D公司"],
    "bill_no": ["001","002","010","011","012","020","021"]
}
df = pd.DataFrame(data)

# 1. 大额交易
large_txn = df[df["amount"] > 10000]

# 2. 重复报销（同一人、同一金额多次出现）
duplicate = df[df.duplicated(subset=["name","amount"], keep=False)]

# 3. 拆分支付：张三的多笔小额合计超过10000
sum_by_person = df.groupby("name")["amount"].sum()
split_pay = sum_by_person[sum_by_person > 10000]

# 4. 高风险供应商
risky_vendors = ["D公司"]
vendor_risk = df[df["vendor"].isin(risky_vendors)]

print("大额交易：\n", large_txn)
print("重复报销：\n", duplicate)
print("拆分支付：\n", split_pay)
print("高风险供应商：\n", vendor_risk)
```

输出结果：

- 大额交易：李四（12000）、赵六（50000）
- 重复报销：张三 4800 两次，李四 12000 两次
- 拆分支付：张三累计 14500（明显超过1万）
- 高风险供应商：赵六的 D公司
