## 为什么Excel是审计人的必修课？

作为审计人员，我们使用Excel的场景无处不在：
- • 科目余额表的数据清洗与整理

## 一、数据透视表：审计分析的利器

数据透视表是Excel中最强大的功能之一，也是审计人员必须掌握的核心技能。

### 1.1 基本操作

创建数据透视表只需三步：
- 1. 选中数据区域
- 2. 点击插入 → 数据透视表**
- 3. 选择放置位置（新工作表或现有工作表）

### 1.2 审计应用场景

场景一：科目余额表分析**

假设你有一张科目余额表，包含科目代码、科目名称、期初余额、期末余额、借方发生额、贷方发生额等字段。

| 科目代码 | 科目名称   | 期初余额 | 期末余额 | 借方发生额 | 贷方发生额 ||----------|------------|----------|----------|------------|------------|| 1001     | 库存现金   | 5,000    | 3,000    | 20,000     | 22,000     || 1002     | 银行存款   | 800,000  | 850,000  | 1,200,000  | 1,150,000  || 1122     | 应收账款   | 200,000  | 250,000  | 300,000    | 250,000    |`
```

通过数据透视表，你可以快速：
- • 按资产、负债、所有者权益大类汇总
- • 分析各类科目余额的变动情况
- • 计算关键比率（如流动比率）

场景二：费用明细分析**

对于管理费用、销售费用等明细项目，数据透视表可以帮你快速识别异常：
- • 哪类费用占比最高？
- • 哪些明细项目波动最大？
- • 各部门的费用结构有何差异？

### 1.3 高级技巧

计算字段与计算项**

数据透视表不仅仅能汇总数据，还能进行计算。

例如，在费用分析中，你可以添加一个"费用率"计算字段：

费用率 = 费用金额 / 营业收入 × 100%`
```

添加步骤：
- 1. 点击数据透视表 → 分析 → 字段、项目和集 → 计算字段
- 2. 输入名称和公式
- 3. 确定

值显示方式**

数据透视表的值显示方式非常丰富：
- • 总计的百分比**：方便查看各项目占总体的比重
- • 行汇总的百分比**：方便查看明细项目占小计的比重
- • 累计百分比**：用于帕累托分析
- • 差异**：方便比较不同期间的变动

## 二、Power Query：数据清洗神器

Power Query是Excel 2016及以上版本内置的ETL工具，被称为"数据清洗神器"。

### 2.1 什么是Power Query？

Power Query（中文名：Power Query for Excel）是一种数据连接技术，可用于发现、连接、合并和细化数据源，以满足数据分析需求。

简单来说，Power Query就是数据清洗和转换**的利器。

### 2.2 核心功能

数据获取**

Power Query可以连接多种数据源：
- • Excel文件、CSV文件
- • 数据库（SQL Server、MySQL等）
- • 网页数据
- • JSON/XML文件
- • 甚至是文件夹（批量导入）

基本清洗操作**
| **| 操作 | 说明 | 审计应用 
| 更改数据类型 | 将文本转为数字/日期 | 统一数据格式 
| 删除重复项 | 去除重复记录 | 识别虚假交易 
| 筛选行 | 按条件过滤数据 | 只保留本期数据 
| 替换值 | 批量替换内容 | 统一摘要表述 
| 逆透视 | 宽表转长表 | 准备数据可视化 

### 2.3 审计实战案例

案例：银行流水整理**

审计中，我们经常需要整理银行流水数据。通常会遇到这些问题：
- • 日期格式不统一（2024-01-01 vs 2024/1/1 vs 20240101）
- • 金额包含千分位符号或货币符号
- • 存在空行或标题行
- • 借贷方向标记不统一（银行 vs 借/贷）

使用Power Query，这些问题可以一键解决：

// M语言示例：统一日期格式Table.TransformColumns(源, {"交易日期", each Date.FromText(_, [Format="yyyyMMdd"])})// M语言示例：清理金额Table.TransformColumns(源, {"金额", each Number.FromText(Text.Remove(_, {",", "¥"}))})`
```

案例：多表格合并**

当你需要将多个Excel文件的sheet合并时，Power Query的文件夹功能简直是救星：
- 1. 将所有文件放入一个文件夹
- 2. 数据 → 获取数据 → 从文件 → 从文件夹
- 3. 选择文件夹路径
- 4. 合并并编辑

系统会自动读取所有文件并合并成一个表。

### 2.4 Power Query的优势

- 1. 可重复**：所有操作都会记录为步骤，下次只需刷新即可
- 2. 大数据支持**：可以处理上百万行数据
- 3. 不破坏原数据**：清洗结果在新表中呈现
- 4. 参数化**：可以创建参数表，实现动态数据刷新

## 三、VBA基础：自动化办公

VBA（Visual Basic for Applications）是Excel的编程语言，可以帮你实现自动化操作。

### 3.1 什么时候用VBA？

VBA适合的场景：
- • 重复性操作（如每月都要做的报表）
- • 复杂的逻辑判断
- • 需要与其他Office应用交互
- • 自动化报告生成

### 3.2 基础语法

录宏与查看代码**

Excel的"开发工具"选项卡中，有一个"录制宏"功能。它可以记录你的操作并生成VBA代码。

通过查看录制的代码，你可以学习VBA的基本语法。

简单示例：自动发送邮件**

Sub SendAuditReport()    Dim OutlookApp As Object    Dim Mail As Object    Dim wb As Workbook        '创建Outlook应用对象    Set OutlookApp = CreateObject("Outlook.Application")    Set Mail = OutlookApp.CreateItem(0)        '设置邮件内容    Mail.To = "manager@company.com"    Mail.Subject = "审计报告_" & Format(Date, "yyyyMMdd")    Mail.Body = "各位领导，同事：\n\n请查收附件中的审计报告。"        '添加附件（当前工作簿）    Set wb = ThisWorkbook    Mail.Attachments.Add wb.FullName        '发送邮件    Mail.Send        '清理对象    Set Mail = Nothing    Set OutlookApp = Nothing        MsgBox "邮件已发送！"End Sub`
```

### 3.3 审计工作中的应用

应用一：自动生成审定表**

Sub GenerateReconciliation()    Dim ws As Worksheet    Dim lastRow As Long    Dim i As Long        Set ws = ThisWorkbook.Sheets("科目余额表")    lastRow = ws.Cells(ws.Rows.Count, 1).End(xlUp).Row        '在每个科目后插入审定数（账龄数×调整系数）    For i = 2 To lastRow        If ws.Cells(i, 1).Value <> "" Then            ws.Cells(i, 7).Value = ws.Cells(i, 4).Value * 1.0 '假设调整系数为1        End If    Next i        MsgBox "审定表生成完成！"End Sub`
```

应用二：一键格式标准化**

审计工作底稿需要统一的格式，使用VBA可以一键完成：
- • 统一字体和字号
- • 设置边框和对齐
- • 添加页眉页脚
- • 冻结首行
