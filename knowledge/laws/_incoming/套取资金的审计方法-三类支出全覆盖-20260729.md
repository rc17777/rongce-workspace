# 套取资金的审计方法

> 来源：微信公众号「财审知库」 | 入库日期：2026-07-29

## 核心框架：三类支出 × 套取手法 × 审计方法

### 一、专项资金支出

| 套取手法 | 信号 | 审计方法 |
|:--|:--|:--|
| **加大工程量** | 预算与决算数据相差大，增加理由不充分 | 看隐蔽工程（完工后无法验证）、会计算工程量、看懂预决算表 |
| **以拨代支转移** | 拨款到个体私营企业/基层村所 | 看是否带帽拨款→拨付单位是否合规→跟踪延伸审计→是否专款专用 |
| **虚列救灾救济资金** | 一卡通资金截留/虚报冒领/改变姓名 | 核对申请与批复→实有人数与发放金额→一卡通到位情况 |

### 二、人员经费支出（吃空饷）

**五对照法**：

| 对照项 | 操作 |
|:--|:--|
| 人员编制对照 | 领工资清册 vs 编制部门核定 |
| 岗位责任制对照 | 是否纳入单位分工、有岗有责、有年度目标 |
| 工作安排对照 | 是否有具体工作任务和阶段性考核记录 |
| 考勤记录对照 | 是否正常上班、天天考勤、有事请假 |
| 群众言论对照 | 走访职工/周边群众，听群众呼声 |

### 三、公用经费支出（四类高危科目）

| 科目 | 作案手法 | 审计方法 |
|:--|:--|:--|
| **会议费** | 虚增会议套取、列支非会议开支 | 查地点/时间/人数→定额标准→开支逻辑一致性 |
| **培训费** | 同会议费 | 参照会议费审计方法 |
| **劳务费** | 发票随意性大、评审费扩大发放对象 | 查附件（用途/范围/发放单位/人员/金额/评审项目） |
| **维修费** | 虚增维修套取 | 查维修时间/项目/工程量→大额付款是现金还是转账 |

## 融策业务适用

- **业务线**：收支审计、经责审计、专项审计全覆盖
- **直接使用**：五对照法可嵌入经责审计方案；三类支出检查清单可标准化为审计底稿模板
