# 电子投标必知|八项投标电子指纹证据（防串标、防同机痕迹）

> 来源: https://mp.weixin.qq.com/s/khYxUJa9dOMedCkz10R2ew

文末领取“投标设备及网络隔离操作检查表”

八项投标电子指纹证据：

IP 地址：可通过切换热点 / 宽带更换；
MAC 地址：网卡硬件（换网卡才能清除）；
CPU ID、硬盘序列号（SSD/HDD SN）、主板序列号、整机机器码：底层硬件固化（永久不变，换整机才能消除）；
文件 GUID、图片哈希：文件痕迹，复制文件即携带，清理难度极高。
一、IP 地址

互联网 / 局域网分配给设备的网络地址，分为内网局域网 IP、公网出口 IP；电脑连宽带、手机热点上网都会产生公网 IP，平台记录上传标书时的出口 IP。

多家投标人报名、上传、解密标书使用同一公网 IP，监管直接判定多单位在同一网络环境操作，高度涉嫌串标；IP 归属地集中同一写字楼 / 商铺也会预警。

怎么查看：方法 1（公网 IP）：浏览器搜索 “IP”，页面直接显示本机对外公网 IP；方法 2（内网 IP）：Win+R 输入 cmd，执行 ipconfig，IPv4 地址为局域网 IP。
投标留痕位置：交易平台操作日志：报名、下载招标文件、上传投标文件、CA 解密全流程均记录当时公网 IP。

二、MAC 地址（物理网卡地址）

网卡（有线 / 无线）出厂固化的 12 位十六进制物理地址，一块网卡永久唯一；一台笔记本有线、无线网卡各有独立 MAC。

不同投标人上传记录出现相同 MAC 地址，证明使用同一台电脑 / 同一张网卡操作，属于高频串标线索；更换宽带、换 IP 无法改变 MAC。

怎么查看：Win+R 输入 cmd，执行 ipconfig /all，找到「物理地址」即为 MAC 地址。
投标留痕位置：平台上传日志、客户端设备采集日志，上传标书时自动读取网卡 MAC 上传后台存储。

三、CPU序列号（CPU ID）

CPU出厂固化的唯一硬件编码，每一颗处理器全球唯一，终身不变。属于电脑最底层硬件指纹，不受系统、硬盘、网络更换影响。

不同投标人的投标文件，检测出相同CPU ID，直接判定：多份标书由同一台物理电脑制作，构成疑似串标铁证。

怎么查看（Windows原生，无需软件）
1. 键盘按下 Win+R，输入 cmd 打开命令提示符；
2. 输入命令：wmic cpu get processorid；
3. 回车后显示的一串字符，即为本机唯一CPU ID。投标留痕位置：投标客户端、造价软件、标书加密包底层XML文件，制作标书时自动写入，永久留存。

四、硬盘序列号（SSD/HDD SN）

电脑内置固态硬盘/机械硬盘、外接U盘、移动硬盘的出厂唯一序列号，每一块存储设备独立唯一。

两台看似不同的电脑，若共用过同一个硬盘、U盘制作标书，硬盘SN一致，监管系统直接判定文件制作设备同源。

怎么查看（Windows原生）：
1. 打开 cmd 命令框；
2. 输入命令：wmic diskdrive get serialnumber；
3. 回车显示的编码，即为本地硬盘SN；插入U盘可同步读取U盘序列号。投标留痕位置：标书制作日志、计价XML元数据、投标客户端设备采集记录。

五、主板序列号

电脑主板出厂唯一编码，是整机核心硬件标识，更换CPU、硬盘、网卡、系统均不会改变。
主板序列号+CPU ID+硬盘SN，三项任意重合1-2项，即可锁定同一制作终端，证据链闭环。怎么查看（Windows原生）：
1. 打开 cmd 命令框；
2. 输入命令：wmic baseboard get serialnumber；
3. 回车获取主板唯一序列号。投标留痕位置：电子投标客户端设备指纹库、标书打包底层参数。

六、整机文件制作机器码
（招投标专属核心指纹）

招投标平台/造价软件专属生成的综合复合指纹，由系统自动聚合：CPU ID+硬盘SN+主板信息+设备特征，生成一串专属机器识别码，是目前招投标判定同机制标最核心、最常用的依据。

监管优先比对此项！不同投标人标书机器码一致=100%认定同一终端制作，无需其他佐证，可直接定性视同串标。

怎么查看（专属渠道，无法用系统命令查看）：
方式1：打开【新点/广联达/各地公共资源投标客户端】，进入系统设置/设备信息，直接查看本机机器码；
方式2：标书导出文件夹中，找到设备日志、打包日志文件，可查询本次制标机器码；
方式3：开标后，监管后台、交易平台后台可直接抓取比对所有投标人机器码。投标留痕位置：标书加密包、投标回执、平台上传日志、开标比对数据库（公开评标比对核心项）。

七、文件创建GUID / 创建标识码

文件首次新建、生成时，系统自动生成的全局唯一ID。属于文件原生底层编码，和设备绑定，具备极强同源识别性。

哪怕修改文件名、另存为、删除内容、修改排版，原始GUID不会变。多份标书GUID一致，证明全部由同一源头文件复制修改而来，属于文件同源串标铁证。

怎么查看：普通电脑无法直接可视化查看，仅可通过专业工具解析：
1. 解析Word/Excel/PDF底层元数据工具；
2. 招投标监管系统、交易平台后台自动抓取比对；
3. 造价XML清单文件可通过记事本打开，检索GUID字段查看。投标留痕位置：所有投标文件底层二进制数据、XML清单、文档元数据，永久留存、不可清除。

八、图片哈希特征码

AI图像识别技术对图片生成的唯一数字指纹。针对标书内所有图片：资质扫描件、营业执照、人员证件、施工图纸、流程图、现场示意图、水印图等。

普通修改无效：裁剪图片、缩放尺寸、调整亮度对比度、加水印、压缩大小、改格式，AI仍能匹配原始哈希值。多家标书出现大量同源图片哈希，直接判定素材共用、标书同源。

怎么查看：无普通查看方式，仅监管系统AI批量自动比对、生成相似度报告，是目前智能查串标的核心手段。投标留痕位置：标书内嵌图片底层数据，平台自动批量哈希比对、全网检索。
