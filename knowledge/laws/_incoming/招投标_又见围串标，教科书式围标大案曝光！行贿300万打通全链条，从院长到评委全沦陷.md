# 又见围串标，教科书式围标大案曝光！行贿300万打通全链条，从院长到评委全沦陷

这个医院分院建设项目总造价2.33亿，从头到尾一套完整的围标链条，送礼、改招标条件、安插评委、定向做标书，所有环节全部打通，堪称行业反面教材。

 
先说整个案子完整套路，一步都没落下：
 
1. 基金会会长王某乙想拿工程，先捐物资搭上医院一把手，分三次送300万现金行贿，拿到项目入场资格；

2. 院长收钱之后，直接给基建科、招标办负责人打招呼，全程开绿灯；

3. 基建科长亲自出面协调发改、招标办，把招标门槛改成适配中铁某局的条件，还特意用费率招标规避正常审核；

4. 内部提前泄露评分细则、项目业绩要求，投标方拿着内部数据针对性写标书；

5. 最关键一步：专门安排自己人作为业主代表进评标委员会，开会时暗示其他评委，人为操控打分，确保指定单位稳稳中标。
 
从甲方一把手、科室负责人、招标代理、投标经办人、现场评委，整条链条全部被收买，外人根本没有任何竞争机会。
 
以前大家眼里的串标，大多是几家施工单位互相陪标、互换报价，这种打通甲方管理层、从招标文件源头量身定做门槛、安插评委操盘的玩法，才是最恶劣的围标操作。
 
很多做工程的老板总觉得，只要没人举报就不会出事，现在裁判文书网上这类案子越来越多，这条灰色路的代价根本承担不起。
 
一、这条产业链上所有人，全部要负刑事责任
 
别以为只是罚点钱了事，本案里牵扯到的每一个人，最后都以串通投标罪、受贿罪追责判刑：
医院原书记收300万贿赂，受贿犯罪；
基建科长、招标办主任利用职权修改招标规则，配合围标；
招标代理、投标方操盘人员定制标书、安插评委；
业主方评委在评标现场刻意引导打分。
 
没有一个人能摘干净，不只是企业罚钱，个人案底终身留存，建造师、招标从业人员直接吊销从业资格，以后再也没法碰工程行业。
 
像这种上亿的公建医院项目，资金全是财政拨款，现在纪检、住建、公共资源交易中心多部门联合核查，聊天记录、转账流水、评标录音全部存档，但凡有一点异常，立马立案调查。
 
二、现在的监管手段，彻底堵死这种暗箱操作
 
这套教科书式围标放在几年前或许还有操作空间，放到现在完全行不通：
 
1. 招标文件线上全流程公示，量身定制的排他性条件会被系统自动预警，第三方随时可以提出异议投诉；

2. 评标专家随机抽取，业主代表名额严格限制，全程录音录像，私下打招呼、暗示打分全部留痕；

3. 社保、公积金双重核验关键岗位人员，挂靠、临时拼凑投标团队一查就露馅；

4. 行贿、串标案件终身录入信用平台，国企、政府项目直接永久限制投标，企业基本等于失去市场。
 
不少央企、大企业也栽在串标上，之前民航项目中铁建大桥局串标被罚六百多万，连大型国企都扛不住处罚，中小私企更不要心存侥幸。
 
三、给所有投标、工程老板几句实在忠告
 
1. 不要想着靠送礼打通甲方领导，现在公职人员追责力度极大，大额行贿一旦查实，双方都要坐牢，得不偿失；

2. 别找人安插评委操控评标，评标全程留痕，打分偏差过大直接启动复核，一查一个准；

3. 拒绝定制化招标文件，遇到甲方要求量身定做门槛的项目，尽量远离，一旦事发所有参与人员连带追责；

4. 老老实实走合规投标路线，靠自身业绩、技术方案竞争，细分专业、本地小型项目才是普通人安稳赚钱的赛道。
