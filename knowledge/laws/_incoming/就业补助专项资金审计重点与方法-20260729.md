# 就业补助专项资金审计重点、方法

> 来源：微信公众号「审天审地审空气」| 入库日期：2026-07-29

## 一、审计的内容

就业补助资金分为两类：对个人和单位的补贴、公共就业服务能力建设补助。

**对个人和单位的补贴资金审计**：职业培训补贴（支付培训学校职业培训补贴和支付园区企业职业培训补贴）、职业介绍补贴、高校毕业生求职补贴、职业技能鉴定补贴、社会保险补贴、公益性岗位补贴、就业见习补贴、创业孵化基地补助资金、特定就业政策补助和扶持公共就业服务，重点关注小额贷款担保基金和小额担保贷款贴息。

**公共就业服务能力建设补助资金审计**：就业创业服务补助和高技能人才培养补助资金。

坚持专款专用的原则，严格按照规定的范围、标准和程序使用，不得用于部门或单位人员经费、公用经费、差旅费、会议费等，严禁用于或变相用于房屋建筑物购建、租赁、交通工具购置等各项支出。

## 二、审计的重点（9项）

### 1. 重复领取就业补助资金
同一人在同一年度多次享受职业介绍补贴、职业技能鉴定补贴、职业培训补贴和就业见习补贴。其中职业技能鉴定补贴和就业见习补贴只能享受一次。

**核查方法**：身份证号在各项补贴发放明细表中同一年度出现≥2次。

### 2. 超法定劳动年龄人员享受补贴
未满16周岁和超过60周岁的人员（企业女职工超50周岁）享受职业介绍补贴、职业技能鉴定补贴、职业培训补贴。

**核查方法**：享受补贴日期 − 身份证号出生日期 > 60岁（女50岁）或 < 16岁。

### 3. 死亡人员享受补贴
死亡人员享受公益性岗位补贴。

**核查方法**：关联民政死亡人员信息表，筛选死亡后仍有补贴发放记录的人员。

### 4. 非定点培训机构和非园区企业获取职业培训补贴
当地人社局没有审批的培训机构、非园区企业和非当地支柱产业企业违规获取职业培训补贴。

**核查方法**：关联定点培训机构名单、园区企业名单和职业培训补贴发放明细表，筛选不在名单中的机构。

### 5. 培训机构利用虚假劳动合同骗取套取补贴
享受职业培训补贴的学员在培训期间用工单位与实际缴纳的社会保险参保单位不一致；公益性岗位补贴和就业见习补贴在享受期间用工单位与实际缴纳的社会保险参保单位不一致。

**核查方法**：关联养老保险缴存明细表，比对用工单位与参保单位是否一致。

### 6. 培训机构多头获取补贴
培训机构利用同一批培训学员在就业、残联、工会等部门多头申报培训补贴。

**核查方法**：关联就业、残联、工会三个部门的职业培训补贴发放明细表，筛选同一身份证号在多部门出现的情况。

### 7. 不符合就业补助对象违规享受补贴
- 就业见习补贴人员在其单位申报就业见习期之前已经实现就业并缴纳社保
- 公益性岗位补贴和社会保险补贴人员不属于就业困难人员
- 培训机构和职业介绍机构利用在校学生身份信息获取补贴

**核查方法**：关联养老保险、公积金、城乡居民医保（筛选在校学生）与各项补贴明细。

### 8. 超期限支付
社会保险补贴和公益性岗位补贴，除距法定退休年龄不足5年的可延长至退休外，其余最长不超过3年。

**核查方法**：筛选享受补贴时长 > 3年的人员（距退休不足5年除外）。

### 9. 多支付补贴
- 社会保险补贴享受时间 > 实际缴纳社保时间
- 公益性岗位补贴享受时间 > 实际在岗工作时间

**核查方法**：关联养老保险缴存明细，比对补贴时长与实际参保/在岗时长。

## 三、审计的步骤及主要思路

### 步骤1：收集和查阅相关财务、业务文件资料
到各就业局收集各项就业补助资金相关政策文件、补贴资金发放程序等。

### 步骤2：采集业务数据和关联的外部数据

**业务数据（就业局取得）**：

| 补贴类型 | 关键字段 |
|:--|:--|
| 职业培训补贴 | 培训学校名称、实际支付补贴年度、享受补贴年度、学员姓名、身份证号、补贴金额、培训时间、用工单位 |
| 职业介绍补贴 | 职业介绍单位名称、实际支付补贴年度、享受补贴年度、人员姓名、身份证号、补贴金额、是否有劳动合同、是否交社保 |
| 高校毕业生求职补贴 | 享受补贴年度、人员姓名、身份证号、补贴金额、是否城市低保、是否农村低保、低保证号 |
| 公益性岗位补贴 | 享受补贴年度、用工单位、人员姓名、身份证号、补贴金额、上岗时间、离岗时间、是否交社保 |
| 社会保险补贴 | 补贴年度、用工单位、人员姓名、身份证号、补贴金额、上岗时间、离岗时间 |
| 就业见习补贴 | 享受补贴年度、用工单位、人员姓名、身份证号、补贴金额、见习开始时间、见习结束时间 |
| 职业技能鉴定补贴 | 享受补贴年度、职业技能鉴定机构名称、人员姓名、身份证号、补贴金额 |

**所需关联的外部数据（7类）**：

1. **财政供养人员名单**：单位名称、身份证号码、人员姓名
2. **养老保险缴存明细**：人员姓名、身份证号码、所在单位名称、参加工作时间、账户设立时间、缴费基数
3. **公积金缴存明细**：人员姓名、身份证号码、所在单位名称、账户设立时间、缴费基数
4. **民政死亡人员信息**：死者姓名、死者身份证号、火化时间
5. **城乡居民医保明细**：姓名、身份证号、参保组织名称、参保状态
6. **人社部门批准的定点培训机构名单**：机构名称、批复年度
7. **当地园区企业名单**：企业名称

### 步骤3：数据比对，找出审计疑点

9项比对规则与"审计重点"一一对应，每项均为：计算机筛选 → 锁定疑点 → 进一步调查取证。

### 步骤4：走访核实
到就业局等部门，针对疑点查阅档案，收集相关资料取证。

## 五、融策业务适用

- **业务线**：专项资金审计
- **适用场景**：就业补助资金审计项目，可直接作为审计方案中的重点关注清单和数据分析方法
- **数据准备**：需取得就业局业务数据（7张表）+ 外部关联数据（7类）
- **分析方法**：9项计算机比对规则均可SQL化
