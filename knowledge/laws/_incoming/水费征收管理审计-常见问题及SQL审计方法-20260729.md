# 水费征收管理审计：常见问题及计算机数据审计方法

> 来源：内审网 → 微信公众号「审天审地审空气」| 适用：供水企业领导干部经济责任审计

## 背景

审计组对县供水企业主要领导干部经济责任审计中，采集用户用水抄表数据135万条、水费收费清单131万条，通过计算机审计分析精准定位问题。

## 数据准备

| 表名 | 关键字段 |
|:--|:--|
| 水费收费清单 | 用户编号（唯一）、用户名称、抄表日期、水量、实收金额、自来水费、违约金、收费月份 |
| 用户用水抄表数据 | 用户编号、用户名称、抄表月份、起度、止度、水量 |

## 审计方法一：未征收违约金

依据：《福建省城乡供水条例》规定逾期未缴水费应征收违约金

**SQL步骤**：

```sql
-- 步骤1：计算时间跨度
create view 逾期未征收违约金 as
select *, datediff(mm, cast(抄表月份+'01' as DATE), 收费日期) 时间跨度
from 收费清单;

-- 步骤2：筛选逾期超半年且违约金为0
create view 逾期超半年且未收违约金 as
select *
from 逾期未征收违约金
where 时间跨度 > 6 and 违约金 = '0'
order by 实收金额, 自来水费 desc;
```

## 审计方法二：未按规定执行阶梯式计量水价

假设水价规则：第一级0-20吨/户月→1.8元/吨；第二级20-30吨→2.7元/吨；第三级>30吨→3.6元/吨

**SQL步骤**：

```sql
-- 步骤1：两表关联，取水量匹配的记录
create view 未执行阶梯价格中间表 as
select a.用户编号, a.用户名称, a.起度 抄表起度, a.止度 抄表止度,
       a.水量 抄表水量, b.费用金额 实收总额, b.自来水 实收自来水费用,
       b.水量 实收水量, b.收费日期, b.收费月份
from 抄表数据 a full join 收费清单 b
on a.用户编号 = b.用户编号 and a.抄表月份 = b.抄表月份
where cast(a.水量 as decimal(20,2)) = CAST(b.水量 as decimal(20,2));

-- 步骤2：计算实收单价与应收单价
create view 未执行阶梯价格中间表2 as
select *,
  case when 实收水量 <> 0 then 实收自来水费用 / 实收水量
       when 实收水量 = 0 then null
  end 实收单价,
  case when 实收水量 <= 20 then 1.8
       when 实收水量 <= 30 and 实收水量 > 20 then 2.7
       when 实收水量 > 30 then 3.6
  end 应收单价
from 未执行阶梯价格中间表;

-- 步骤3：筛选实收与应收不一致的记录
select * from 未执行阶梯价格中间表2
where 实收单价 <> 应收单价;
```

## 审计方法三：少收水量

```sql
create view 少收水量 as
select a.*, b.费用金额 实收总额, b.自来水 实收自来水费用, b.水量 实收水量,
       (cast(a.水量 as decimal(20,2)) - CAST(b.水量 as decimal(20,2))) 差量,
       收费日期, 收费月份
from 抄表数据 a full join 收费清单 b
on a.用户编号 = b.用户编号 and a.抄表月份 = b.抄表月份
where cast(a.水量 as decimal(20,2)) > CAST(b.水量 as decimal(20,2));
```

## 融策业务适用

- **业务线**：经济责任审计（供水企业）、专项资金审计
- **方法复用**：阶梯价格检查逻辑可迁移至其他按量计费审计（电费、燃气费等）
- **数据准备**：需取得抄表数据和收费清单两张核心表
- **技术要点**：full join + 水量decimal比对 + 单价公式计算
