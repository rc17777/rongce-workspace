## 一、迁移前准备（Windows 侧）

### 1.1 备份核心数据

```powershell
# 1. Git push 所有变更到 GitHub
cd C:\Users\scrccpa\.openclaw\workspace
git add -A
git commit -m "迁移前备份 2026-07-30"
git push origin main  # ⚠️ 需要开代理

# 2. 备份 openclaw 配置
Copy-Item "$env:USERPROFILE\.openclaw\openclaw.json" "D:\backup\openclaw.json.bak"

# 3. 备份 API Key 环境变量（注册表）
reg export "HKEY_CURRENT_USER\Environment" "D:\backup\env_vars.reg" /y

# 4. 打包大文件目录（RAG索引、OCR结果等）
# 用 7-Zip 压缩到 D 盘，后续拷到移动硬盘
```

## 二、Mac 基础环境搭建

### 2.1 系统设置

```bash
# 1. 安装 Homebrew（macOS 包管理器）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 配置 Homebrew 镜像（国内加速）
echo 'export HOMEBREW_API_DOMAIN="https://mirrors.tuna.tsinghua.edu.cn/homebrew-bottles/api"' >> ~/.zshrc
echo 'export HOMEBREW_BOTTLE_DOMAIN="https://mirrors.tuna.tsinghua.edu.cn/homebrew-bottles"' >> ~/.zshrc
source ~/.zshrc

# 3. 安装基础工具
brew install git node python@3.12 wget curl jq

# 4. 验证
node --version   # 应该 >= 20
python3 --version  # 应该 3.12+
git --version
```

### 2.2 Node.js 环境

```bash
# 安装 OpenClaw
npm install -g openclaw

# 验证

# 配置 npm 镜像（国内加速）
npm config set registry https://registry.npmmirror.com
```

## 三、OpenClaw 迁移

### 3.1 Workspace 迁移

```bash
# 方式 A：Git clone（推荐）
cd ~
git clone https://github.com/你的用户名/openclaw-workspace.git .openclaw/workspace

# 方式 B：移动硬盘拷贝
# 1. Windows 侧：打包 .openclaw/workspace 到移动硬盘
# 2. Mac 侧：解压到 ~/.openclaw/workspace
cp -r /Volumes/你的移动硬盘/workspace-backup ~/.openclaw/workspace
```

### 3.2 Skills 迁移

```bash
# 拷贝自定义 skills
cp -r /Volumes/你的移动硬盘/skills ~/.openclaw/skills

# 验证
ls ~/.openclaw/skills/
# 应该看到：procurement-audit-models/ zhixi-v2-enhanced/ 等
```

### 3.3 配置文件迁移

```bash
# 1. 拷贝 openclaw.json（需要修改路径）
cp /Volumes/你的移动硬盘/openclaw.json ~/.openclaw/openclaw.json

# 2. 修改路径（Windows → Mac）
# 用 sed 批量替换
sed -i '' 's|C:\\\\Users\\\\scrccpa|/Users/你的用户名|g' ~/.openclaw/openclaw.json
sed -i '' 's|D:\\\\|/Volumes/数据盘/|g' ~/.openclaw/openclaw.json

# 3. 或手动编辑
nano ~/.openclaw/openclaw.json
# 重点修改：
# - workspace 路径
# - skills 路径
# - 日志路径
# - 临时文件路径
```

### 3.4 API Key 配置

```bash
# 方式 A：环境变量（推荐，更安全）
nano ~/.zshrc

# 添加：
export DEEPSEEK_API_KEY="sk-xxx"
export OPENAI_API_KEY="sk-xxx"
export ANTHROPIC_API_KEY="sk-ant-xxx"
# ... 其他 key

source ~/.zshrc

# 方式 B：写入 openclaw.json（明文，方便但不安全）
# 直接编辑 openclaw.json 的 providers 部分
```

### 3.5 启动验证

```bash
# 启动 OpenClaw
openclaw gateway start

# 检查状态
openclaw status

# 测试对话
openclaw chat "你好，测试一下"

# 如果报错，看日志
openclaw gateway logs
```

## 九、常见问题

### Q1: Windows 的 .bat 脚本在 Mac 上怎么办？

A: 改写成 shell 脚本（.sh），或直接写成 Python 脚本（跨平台）。

### Q2: PaddleOCR Mac 上很慢？

A: Mac 没有 NVIDIA GPU，只能用 CPU。速度约 5 页/秒（Windows GPU 约 30 页/秒）。批量 OCR 建议：
- 少量文件：Mac 直接跑
- 大量文件：用台式机/服务器跑，或云端 API

### Q3: 企业微信/微信插件能用吗？

A: 能。OpenClaw 的 wecom 插件跨平台，配置迁移即可。

### Q4: Git push 还是不通？

A: Mac 上也需要代理。配置 Git 代理：
```bash
git config --global http.proxy http://127.0.0.1:7890
git config --global https.proxy http://127.0.0.1:7890
```

### Q5: 双系统同步怎么办？

A: 用 Git 同步 workspace，大文件用 iCloud / 坚果云 / 移动硬盘。不建议同时跑两套 OpenClaw（配置冲突）。
