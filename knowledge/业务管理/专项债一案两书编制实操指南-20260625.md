# 专项债"一案两书"编制实操指南

> 核心三词：**真实、合规、闭环**。找对人、早动手、留余量。

## 一、三份文件的角色定位

| 文件 | 评审方 | 核心命题 | 评审视角 |
|:--|:--|:--|:--|
| 实施方案 | 财政 | 项目值不值得做、能不能做 | 政策合规+技术可行+经济合理 |
| 财务评估报告 | 财政+券商 | 项目能不能还上钱 | 收益真实+现金流稳定+偿债能力 |
| 法律意见书 | 财政+司法 | 项目合不合法、有没有后遗症 | 主体合规+手续合规+债务边界清晰 |

**逻辑关系**：实施方案定框架 → 财务评估算账 → 法律意见书守底线。三份文件独立审查、交叉比对，**核心数据不一致直接扣分**。

## 二、实施方案编制要点

### 项目概况
- 项目名称必须与立项批复一致，格式"行政区划+行业+建设内容+项目性质"
- 项目代码须来自全国投资项目在线审批监管平台且状态正常
- 常见雷区：名称与立项不一致、代码过期、建设地点模糊

### 建设内容：投资-收益三角闭环
建设内容上连投资估算、下连收益来源，三者严丝合缝：
- 标准厂房 → 建安费+设备费 → 厂房租金
- 配套道路 → 市政工程费 → 无直接收益（公益性）
- 停车场 → 交通设施费 → 停车费
- 污水处理站 → 设备+建安费 → 污水处理费

⚠️ **有投入要有产出，公益性内容占比过高不建议申报专项债**

### 资本金要求（国发〔2019〕26号 + 国办发〔2024〕52号）
- 基础设施项目最低资本金 **20%**（机场25%）
- 专项债作资本金：**正面清单22个行业**（新能源、产业园区、城市更新、保障性住房等）
- 省级上限：该省项目建设专项债规模的 **30%**
- 省重点项目优先

### 风险分析
别只写"风险可控"——须列具体风险点（收入不及预期/投资超支/政策变动），评估概率与影响，定措施，判等级。**风险越具体，专家越放心。**

## 三、财务评估报告编制要点

### 收入测算依据等级（每笔收入要有依据）

| 依据类型 | 等级 | 说明 |
|:--|:--:|:--|
| 政府定价收费 | ★★★★★ | 污水处理费、垃圾处理费，最硬 |
| 实际运营数据 | ★★★★☆ | 已运营项目按达产率折算 |
| 同类项目对比 | ★★★☆☆ | 需具体案例 |
| 行业平均水平 | ★★☆☆☆ | 说服力一般 |
| 主观推测 | ★☆☆☆☆ | "预计""估计"基本不被认可 |

**三原则**：谨慎性（就低不就高，专家核减是常态）、渐进性（运营前期爬坡，不能上来按100%）、相关性（收入对应建设内容）

### 成本测算4个高频漏点
1. **大修理费**：固定资产原值2%-3%/年，或每10年一次大修
2. **工资福利费**：含五险一金+工会经费+职教经费，约工资总额40%
3. **管理费**：收入5%-10%
4. **营销费**：产业园/商业类项目，收入2%-5%

### 覆盖倍数三层面（不是凑够1.3就行）
1. 全生命周期总覆盖倍数 ≥ **1.3倍**（高风险地区1.4倍）
2. 年度最低覆盖倍数 ≥ **1.1倍**（"J型曲线"前低后高易出问题）
3. 累计盈余资金不能为负（不能靠后几年补前面窟窿）

### 敏感性分析
至少做"收入-10% + 成本+10%"双因素测试，**极端情景覆盖倍数仍≥1.0**。
测试变量：运营收入(-5%/-10%)、运营成本(+5%/+10%)、建设投资(+5%/+10%)、利率(+0.5%/+1%)、达产率(-10%/-20%)

### 5个低级错误
建设期利息算错 / 折旧摊销政策不一致 / 现金流表与利润表对不上 / 增值税计算错误 / 还本付息表与资金筹措表不一致

## 四、法律意见书审查要点

### 主体资格
不止营业执照：注册资本到位、经营范围含建设内容、同类项目经验、内部决策程序（董事会/股东会决议、国资审批）

### 审批手续（不仅要有，还要有效）

| 手续 | 常见问题 | 后果 |
|:--|:--|:--|
| 立项批复 | 过期、层级不够 | 立项无效需重报 |
| 用地预审与选址 | 过期（有效期3年）、范围不一致 | 项目无法落地 |
| 土地使用权证 | 只有划拨决定书、集体土地 | 产权不清晰 |
| 规划许可证 | 只有选址意见缺"两证" | 未批先建风险 |
| 环评批复 | 等级不够（报告书做报告表） | 环评无效 |

⚠️ **用地手续是重灾区**。只有预审没土地证，严格评审会被打回。划拨用地至少要县级以上政府用地批复，出让土地要有出让合同。

### 收益来源合法性
- **政府付费/补贴**：须有政策依据、纳入同级财政预算、对应政府性基金或专项收入，**不能一般公共预算兜底**
- **土地出让收入**：须明确地块位置/面积/性质/规划用途+出让时序价格测算+分配机制；属政府性基金用于偿债合规，但必须对应具体地块

### 隐性债务红线
法律意见书必须明确出具"**不新增地方政府隐性债务**"结论。
认定四标准：政府兜底偿还 / 政府提供担保 / 还款主要靠财政资金 / 政府通过企事业单位违规举借。
⚠️ 专项债本身是法定债务不算隐性债务，但**配套市场化融资有政府隐性兜底即形成隐性债务**。

## 五、双平台填报

| 系统 | 主管部门 | 填报重点 |
|:--|:--|:--|
| 国家重大建设项目库 | 发改委 | 基本信息、建设内容、投资、资金来源、开工计划 |
| 地方政府债务管理系统 | 财政厅/局 | 债务信息、收益平衡、还本付息、债券需求 |

**两个系统项目名称、总投资、建设内容、收益数据必须完全一致，差一个字都退回。**

### 时间轴
- 上年8-9月：项目谋划、前期手续
- 上年10月：下年度集中申报
- 当年1-2月：财政部下达额度、省级分配
- 当年3-6月：第一批发行
- 当年6-9月：第二批发行（如有）

### 补正技巧
先确认：发改还是财政的问题、实质还是形式问题、截止时间。逐条回复+附佐证，收益被核减该调就调（硬扛大概率过不了）。**补正窗口通常15个工作日，逾期视为放弃。**

## 六、八大驳回原因与避坑

| 驳回原因 | 占比 | 避坑指南 |
|:--|:--:|:--|
| 投向偏离重点领域/触碰负面清单 | 23% | 申报前对照负面清单排查，拿不准提前沟通 |
| 收益覆盖不足、测算缺依据 | 19% | 收入留余地，不卡1.2倍做，每笔有佐证 |
| 核心手续缺失或过期 | 17% | 申报前手续全面体检，过期提前延期 |
| 建设内容与投资、收益不匹配 | 13% | 建"建设内容→投资→收益"三角对应 |
| 一案两书与可研数据不一致 | 11% | 定稿前全面数据交叉核对 |
| 隐性债务风险 | 8% | 严格区分政府与企业债务 |
| 资本金不足或来源不合规 | 5% | 20%底线，专项债作资本金须在正面清单 |
| 补正超时 | 4% | 留足时间，专人盯进度 |
