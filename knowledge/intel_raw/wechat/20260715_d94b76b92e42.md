同一批内容套上两套不同主题，左为深色、右为浅色（图源：项目仓库示例页。左=主题 01「轻拟态风」，右=主题 07「冷白调研风」，同一批内容换两套主题）用 AI 一句话生成一份 PPT，这两年冒出来一堆工具。多数是同一个路子：你给要求，它生成一份幻灯，好看，但生成完基本就定死了——想调某一页的布局、少放两个要点、把柱状图换成雷达图，往往只能改提示词让它整份重新生成，或者导出一个没法编辑的图片版。大师 PPT（dashiAI-ppt-skill）想动的就是这一步。它是一个 AI Agent skill，npx 一行装上，目前 2.5k 星、AGPL-3.0 开源。它生成的不是一张定死的图，而是一份每一页都带着编辑控制台的网页幻灯——不满意的地方直接在浏览器里拖、点、改，改完再一键导出成真实的、可编辑的 PPTX。把文档丢给你的 AI Agent，每一页都自带编辑控制台的 PPT Skill——不满意的地方直接在浏览器里改，改完还能一键导出成真实的、可编辑的 PPTX。核心：生成完，每页带一个控制台大师 PPT 的四步：喂文档 → 生成带控制台的网页幻灯 → 浏览器里逐页精调 → 导出可编辑 PPTX普通 AI PPT 工具是「生成即交付」：出完就是最终稿，要改就回头重生成。大师把它拆开了——AI 生成的是一份网页幻灯，每一页上都焊着一个控制台，20 多个编辑维度：内容、布局、模块数量、页面重点、预设配色、翻页动画。作者给的数字是 12 套主题、1020 个版式页面、8576 个可调控件。也就是说，生成只是给你一个起点，之后每一页你都还能自己拧。控制台能拧到什么程度最直观的是滑杆。一页里放几条要点、目录列几项、表格几行、配几张图，直接拖：拖动滑杆调整某页里目录、表格、条目、图片的数量（图源：项目仓库）其余几种改法：• 一句话换布局、换图表：跟 Agent 说一句，把这一页换个版式，或把柱状图换成雷达图、瀑布图、桑基图。• 点字就地改：直接点页面上的文字编辑，装饰元素会随字数自适应，不会因为你多打几个字就撑破排版。• 图片占位符一键填：预留的图位点一下就能塞图，也能往页面里另外插图。• 局部换配色：每套主题内部还能调局部的颜色搭配。• 翻页动画：9 种过渡效果可选。有一点作者说得直白：自定义样式是有意限制在特定范围内的——「稳定的产出比自由的选色更重要」。所以它不是给你一张全自由的画布，而是在一个被框好的范围里让你快调。内置一堆专业版式，连分析模型都排好了除了常规的图文版式，它把一批做汇报常用的分析模型也做成了现成版式，套内容就能用：内置的分析模型版式：SWOT、波特五力、PEST、商业画布、投资决策双钻等（图源：项目仓库。SWOT、波特五力、PEST、商业模式画布、投资决策双钻，以及桑基图等）图表类型也备了一排：雷达、瀑布、树图、漏斗、热力图、桑基、甘特。做行研、竞品、融资复盘这类需要「结构」的材料时，不用自己从零摆框。导出：一份真能编辑的 PPTX网页幻灯再好看，最后多数人还是要一份能进 PowerPoint 改的文件。大师的导出是逐节点还原，文字保持可编辑，不是把每页截成图片贴进去：同一页在 HTML 渲染与导出后的 PPTX 之间切换对比，左上角标签在 HTML / PPTX 间跳（图源：项目仓库。左上角标签在 HTML 与 PPTX 之间切换）作者也把话说在前面：「虽然 PPT 无法拥有 HTML 的全量能力，但我们尽最大可能保留了可编辑性。」除了 PPTX，还能导出 PDF 和离线 HTML 包。要注意：导出 PPTX / PDF 需要本机装了 Chrome、Chromium 或 Edge，靠它们来完成渲染。怎么装、要什么• 装：npx dashiai-ppt-skill@latest；国内网络可以走镜像 npx --registry=https://registry.npmmirror.com dashiai-ppt-skill@latest。• 环境：Node.js 20+ 和 npm；导出 PPTX / PDF 还要本机有 Chrome / Chromium / Edge。• 在哪用：作为 Agent skill，支持 Claude Code、Codex、豆包、Marvis / Workbuddy / Dumate / Qclaw，Cursor 和本地 Agent 也能用。• 流程：把带要求的文档丢进去 → 从 12 套风格里挑一套 → 自动排出结构化内容 → 在浏览器里逐页改 → 导出你要的格式。几条要注意的• 导出引擎不开源。 App 本体 AGPL-3.0，但负责把网页转成 PPTX 的那个子包 html-deck-to-pptx 是闭源的，AGPL 里单列了例外条款：只能作为这个 skill 的一部分使用，不能单独抽出来或再分发。它能免费用，但不属于可审计、可自己改的那部分。• 自定义是被框住的。 前面说过，配色和样式的自由度被有意收窄，换的是产出稳定。要逐像素手工定制视觉的场景，作者自己也写了「不适合」。• token 不算省。 作者实测一套 10 页的 PPT 约 10 万 token，量不小。• 导出依赖本机浏览器。 没装 Chrome 系浏览器就导不出 PPTX / PDF。• 它的定位是「快速成稿」。 适合行业研究、融资复盘、竞品分析、项目汇报、路演、内部培训这类要快速出一份结构完整、视觉统一、还能继续改的材料；不适合当精修设计工具用。写在最后能用 AI 生成 PPT 的工具已经很多了，大师 PPT 的差异不在「能不能生成」，而在生成之后：它把可编辑性一路保留到底——每一页带控制台让你在浏览器里逐页调，最后再导出成文字仍可编辑的 PPTX，而不是给你一份改不动的成品。代价是导出引擎那部分闭源、自定义被有意框住、导出还得依赖本机浏览器。能接受这几点，它把「AI 生成」和「生成后还能改」这两件事接上了，对做汇报的人是实打实省事。AGPL-3.0，2.5k 星。仓库地址：github.com/chuspeeism/dashiAI-ppt-skill。 近期文章推荐开源版 Typeless：Mac 语音输入
