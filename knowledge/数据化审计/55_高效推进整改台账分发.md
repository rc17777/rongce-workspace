## 整改三部曲

1. **整改台账分发**：按机构拆分总台账，发送给被检查机构
2. **整改资料回收**：收回各机构台账和整改证明材料
3. **整改结果评估**：分析验证，确认整改效果

本文实现第一篇：自动拆台账+生成证明材料文件夹+压缩打包。

## 核心代码

```python
import pandas as pd
import zipfile, os, glob

df_source = pd.read_excel('台账.xlsx', parse_dates=['问题日期','上次报告日期'])
df_source[['最新整改状态','最新整改情况','整改完成日期','证明材料清单']] = None

# 提取机构清单
df_br = df_source.drop_duplicates(subset=['问题机构'])

# 按机构拆分台账 + 生成证明材料文件夹 + 压缩
for i in range(len(df_br)):
    pdsub = df_source[df_source['问题机构'] == brname]
    with pd.ExcelWriter(f'{brname}-问题台账.xlsx') as writer:
        pdsub.to_excel(writer, index=False)
    # 生成证明材料目录 + 压缩
    for j, record in pdsub.iterrows():
        os.makedirs(f'{brname}/{brname}_{record["序号"]:04d}号整改材料')
    # 压缩成zip
    with zipfile.ZipFile(f'{brname}.zip', 'w', zipfile.ZIP_DEFLATED) as zf:
        for f in glob.glob(f'{brname}/**'):
            zf.write(f)
```
