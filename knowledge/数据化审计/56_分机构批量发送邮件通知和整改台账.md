## 需求

已按机构拆分生成了N个整改台账压缩包，需要分别发送邮件给各机构，每个机构正文不同+附件不同。

## 方案：zmail库

```python
import pandas as pd
import zmail
import glob, os

def SendNoticMail(df_info, attachfile):
    content_html = f'<html><body><b>{df_info.iloc[0,0]}:</b><br>请在收到通知30日内更新整改台账...</body></html>'
    curmail = {
        'subject': f'{df_info.iloc[0,0]}问题整改跟踪台账',
        'content_html': content_html,
        'attachments': attachfile
    }
    server = zmail.server('发件邮箱', '密码', smtp_host='smtp.xxx.com', smtp_port=25, smtp_ssl=False)
    return server.send_mail(df_info.iloc[0,1], curmail)

# 主程序
df = pd.read_excel('各机构联系信息.xlsx')
for f in glob.glob('整改资料收集/*.zip'):
    curbr = f.split('\\')[-1][:-4]
    df_br = df[df['机构名称'] == curbr]
    SendNoticMail(df_br, f'{os.getcwd()}/{f}')
```

环境：Python 3.8 / Pandas 1.1.3 / zmail 0.2.8
安装：`pip install zmail`（仅支持Python3）
