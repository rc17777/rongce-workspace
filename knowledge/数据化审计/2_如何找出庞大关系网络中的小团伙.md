## 面临的问题

看了关于社交网络分析的相关文章（比如《Python应用 | 利用社交网络分析（SNA）挖出"围标"线索》），学习了复杂网络分析相关的技术和工具，总有一试身手的想法。

在实际业务中，对银行这样交易量比较大的机构，一段时间的交易关系只会比这个图还密集。

看是展现了关系，却还是无从下手。

**俗话说"物以类聚，人以群分"，社交网络很复杂，但根据日常交往、共同爱好、相近空间，总有团团伙伙的存在。**

比如，一个庞大的洗钱网络，从控制账户、吸收客户、转移资金等等，参与的节点会构成一个大网络，但这个网络中控制账户的群体、转移资金的群体还是具有一定的聚类分布，群体内关系密切，群体间关系较弱。

面对一个庞大的关系网络，找出这些群体，对理解网络的结构、功能特性和演化过程，推测特定节点的性质都很有帮助。**也有利于在有限的资源配置下，尽快抓住检查重点，精确制导，提高数据分析和检查效率**。

## 社区发现（community detection）

从复杂网络（complex network）研究的角度，看似**错综复杂的网络是由相互独立而又相互交错的社区（community）组成的**，同一社区内的节点与节点之间的连接很紧密，而社区与社区之间的连接比较稀疏。**社区发现（community detection）又被称为社区检测，是用来揭示网络聚集行为的一种技术。**

社区发现中的社区，都是属于同一个复杂网络，社区中的节点关系比较紧密，社区之间通过较弱的链接而连接起来。**通过社区发现可以找出庞大关系网中的"小团伙"**。在业务实践中，就可以将这些"小团伙"作为一个整体进行分析和研究。

## 社区发现的技术

常用的社区发现方法主要有如下几种：
- 基于图分割的方法，如Kernighan-Lin算法，谱平分法等；
- 基于层次聚类的方法，如GN算法、Newman快速算法等；
- 基于模块度优化的方法，如贪婪算法、模拟退火算法、Memetic算法、PSO算法、进化多目标优化算法等。

python 中的网络分析库 **networkx 2.2** 中的社区发现模块 **algorithms.community**，提供如下社区发现算法：
- 贪婪算法 greedy_modularity_communities
- 子空间聚类算法 k_clique_communities
- 标签传播算法 asyn_lpa_communities
- Fluid Communities 算法 asyn_fluidc

## 社区发现的实例

### 1.环境初始化

```python
# -*- coding:utf-8 -*-
import networkx as nx
from networkx.algorithms import community
import matplotlib.pyplot as plt
import matplotlib.colors as colors
import pandas as pd
```

### 2.数据预处理

由于社交网络分析处理的是一对对节点之间的关系，而投标人信息数据中，同一个投标人有多个信息点，需要分别提取，最终形成每对节点"投标公司名称-公司信息点"一一对应的唯一数据集合，将数据处理为三个字段"投标公司名称、信息点、关系描述"的对照表。

```python
## 读取数据文件生成节点数据
df = pd.read_excel(r"投标公司信息.xlsx", dtype = {'联系电话':str}, encoding='gbk')
dfdetail = pd.DataFrame(columns=['投标公司名称','信息点','关系描述'])
curdf = df[['投标公司名称','联系人姓名']]
curdf['关系描述'] = '联系人姓名'
curdf.columns = dfdetail.columns
dfdetail = dfdetail.append(curdf,ignore_index=True)
curdf = df[['投标公司名称','联系电话']]
curdf['关系描述'] = '联系电话'
curdf.columns = dfdetail.columns
dfdetail = dfdetail.append(curdf,ignore_index=True)
curdf = df[['投标公司名称','银行账号']]
curdf['关系描述'] = '银行账号'
curdf.columns = dfdetail.columns
dfdetail = dfdetail.append(curdf,ignore_index=True)
curdf = df[['投标公司名称','联系邮箱']]
curdf['关系描述'] = '联系邮箱'
curdf.columns = dfdetail.columns
dfdetail = dfdetail.append(curdf,ignore_index=True)
```

### 3.对最大的子网络中进行社区发现并不同颜色标注

```python
## 初始化图（关系网络）
G = nx.DiGraph()
## 加载关系数据
for i in range(0,dfdetail.count(0)[0]):
    G.add_edge(dfdetail.iloc[i,0], dfdetail.iloc[i,1], attrtype=dfdetail.iloc[i,2])
## 从大网络中识别出所有的子网络
sub_graphs = nx.weakly_connected_component_subgraphs(G)
## 提取最大的子网络
G0 = next(sub_graphs)
## 社区发现可以不考虑方向，将有向图转换为无向图
G0 = nx.Graph(G0)
## 使用贪婪算法进行社区发现
com = community.greedy_modularity_communities(G0)
c = list(com)
## 初始化结果可视化图的绘制环境 比如支持中文显示
plt.clf()
plt.rcParams['font.sans-serif']=['SimHei']
plt.figure(figsize=(10,10))
pos = nx.spring_layout(G0)
## 可视化社区发现结果
nx.draw(G0,pos = pos, with_labels=True)
## 不同的社区节点用不同的颜色显示
for i in range(len(c)):
    nx.draw_networkx_nodes(G0, pos=pos, nodelist=c[i], node_color= colors.cnames.values()[i*3])
## 显示结果
plt.axis("off")
plt.show()
```
