## 用图数据视角理解数据

在"Neo4j：善于处理关系，所以强大（一）"分析过，图数据存储的是各类关系表现的最小单元三元组（triple）："实体1-关系-实体2"。

在Neo4j图数据中，定义了四种核心要素：
- **实体（Nodes）**：比如实例数据中的投标公司、人、电话等都可以作为实体。在Neo4j中场景中一般用圆括号()表示。
- **标签（Labels）**：比如实例数据中，实体有投标公司、人、电话、账号等不同种类，这可以通过赋予不同的标签来进行区分。实体可以有一个或多个标签。
- **关系（Relationships）**：比如实例数据中"电话"和"投标公司"之间前者是后者的联系方式关系，在Neo4j中场景中一般用方括号[]表示，和实体的关系用->表示从属方向。
- **属性（Properties）**：比如实例数据中的实体投标公司的名字就是其重要属性，关系也有不同的属性，比如交易关系可以有交易日期、金额等属性。

## Cypher 语言

Cypher 语言是neo4j官方推出的neo4j图数据查询语言。Cypher 语言风格比较接近自然语言。

### 1.用create语句创建数据

用如下语句，创建一个"实体1-关系-实体2"的三元组关系：

```cypher
create (acui_yahoo_com:邮箱 {name:"acui@yahoo.com"})-[:联系邮箱]->(阳市南康信息有限公司:公司 {name:"阳市南康信息有限公司"})
```

其中，实体（Node）的标志值ID，Neo4j数据库内部会自动生成一个<id>作为相应的唯一标志。在不建立UNIQUE约束规则的前提下，CREATE命令始终会创建新的节点或关系。

### 2.用match语句查询数据

```cypher
// 查询name属性为"阳市南康信息有限公司"的公司，并将返回数据集命名为a
match (a:公司 {name:"阳市南康信息有限公司"}) return *

// 也可以写成带where条件的语句
match (a:公司) where a.name="阳市南康信息有限公司" return *
```
