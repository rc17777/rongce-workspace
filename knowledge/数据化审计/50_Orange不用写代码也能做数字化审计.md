## Orange简介

开源可视化数据分析工具，Python开发，通过"拖拉拽"实现所见即所得的数据分析。提供数据预处理、探索性分析、建模、评估、无监督机器学习、可视化等功能。

安装：`pip install orange3 --user` 或官网下载。启动：`python -m Orange.canvas`

## 五大组件集

| 组件集 | 功能 |
|--------|------|
| Data | 数据导入/读取/保存/透视表/抽样/Python脚本 |
| Visualize | 箱体图/散点图/直方图/热图等 |
| Model | KNN/随机森林/SVM/逻辑回归/神经网络等 |
| Evaluate | 交叉验证/ROC曲线等 |
| Unsupervised | PCA/t-SNE/K-Means/层次聚类等 |

## 使用方式

拖放组件 → 链接组件 → 双击编辑参数 → 结果自动展示。功能类似SPSS Modeler。支持插件扩展，也支持Python非可视化调用。

## 对审计的价值

- **零代码门槛**：业务人员不需要学SQL/Python，拖拽即可完成数据分析
- **快速探索**：选数据→拖图表组件→直观看到分布和异常
- **机器学习内置**：K-Means聚类、异常检测、关联规则等无需手写代码
