## 桑基图（Sankey）

桑基图（Sankey），也叫桑基能量分流图，是流程图的一种。"桑基图"的命名来自于爱尔兰船长里亚尔·桑基（Riall Sankey），他因在展示蒸汽的能源效率时使用了该类型图表而闻名。

桑基图在遵循守恒定律的前提下，能形象地展示能量、资金、人员、资源等数据的流转。桑基图有三个基本要素：节点（Nodes）、边（Links）和流量。边的宽度和流量大小成正比例。

最著名的桑基图是查尔斯·约瑟夫·米纳德在1869年绘制的《1812－1813对俄战争中法军人力持续损失示意图》，展现了拿破仑军队从波兰到莫斯科的军力损失情况。开始向莫斯科进军有42万人，到达莫斯科只有10万人，最后撤退回来只剩下1万人。

## 实战案例：费用分析

使用 Python + pyecharts 绘制桑基图，需要解决：
- Excel文件中合并单元格的数据读取
- 生成和匹配出桑基图三个基本要素：节点、边和流量
- 根据pyecharts格式要求生成底层数据

核心代码：
```python
# 引入相关的python库
from openpyxl import load_workbook
from pyecharts.charts import Sankey
from pyecharts import options as opts

# 读取合并单元格
mcells = sorted(ws.merged_cell_ranges, key=lambda mc: mc.min_row)

# 生成桑基图的边数据
for mc in mcells[1:]:
    r1, r2, c1, c2 = mc.min_row, mc.max_row, mc.min_col, mc.max_col
    for i in range(r1, r2+1):
        dic = {}
        if c1 == 1:
            dic['source'] = '已使用费用'
            dic['target'] = ws.cell(r1, c1).value
            dic['value'] = ws.cell(r1, c1+1).value
        else:
            dic['source'] = ws.cell(r1, c1-1).value
            dic['target'] = ws.cell(i, c1+1).value
            dic['value'] = ws.cell(i, c1+2).value
        if links.count(dic) == 0:
            links.append(dic)

# 根据echarts语法设置桑基图的参数
pic = (
    Sankey()
    .add('', nodes, links,
         linestyle_opt=opts.LineStyleOpts(opacity=0.3, curve=0.5, color='source'),
         label_opts=opts.LabelOpts(position='top'),
         node_gap=30)
    .set_global_opts(title_opts=opts.TitleOpts(title='XX公司年费用使用情况', pos_left='center'))
)
pic.render('XX公司年费用使用情况.htm')
```
