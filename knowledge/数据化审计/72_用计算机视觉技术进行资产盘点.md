## 引子

无论是内审、外审还是国审，对资产、商品等进行数量盘点、信息摘录往往是必备动作。对于大量堆积、散放的资产和商品如何快速盘点？还有那著名的梗："四大审计师是如何审计太平湖里的王八数量的？"

从技术角度，无论是资产、商品还是王八，都是一个个物体（object）。需要做的就是让程序像人的眼睛一样：检测物体（object detection）、区分出物体（object recognition）。随着计算机视觉、深度学习等技术的发展，从图像、视频中进行物体的检测、识别的难度不断降低、准确率不断提高。

## OpenCV

业界最强大的计算机视觉库，Intel开源，1999年创立。免费开源，支持C++、Python、Java等多语言，可跨平台。适用领域：人机互动、物体识别、图像分割、人脸识别、动作识别、运动跟踪、机器人、自动驾驶。

OpenCV-Python：通过 `pip3 install opencv-python` 安装，建议4.X版本。引入时库名为cv2：`import cv2`。

## 案例背景

居家抗疫期间，志愿者需要帮居民代购药品。通过照片传递药品药盒、医保卡，志愿者再进行人工识别、信息摘录。类似审计中的资产盘点，可细分为三个子任务：
1. **有条码物件识别**：药盒都有商品条码（唯一标识）
2. **无条码同类型物件识别**：医保卡外观固定但无条码
3. **物件信息采集**：药品名称、规格等（通过OCR）

## 有条码物件识别

使用pyzbar库进行条码识别：
```python
import cv2
import pyzbar.pyzbar as pyzbar

img_gray = cv2.cvtColor(img_org, cv2.COLOR_BGR2GRAY)
barcodes = pyzbar.decode(img_gray)
for barcode in barcodes:
    print(barcode.data.decode('utf8'))
    (x, y, w, h) = barcode.rect
    cv2.rectangle(img_cp, (x, y), (x + w, y + h), (255, 255, 0), 2)
```

扩展：小程序调用 `wx.scanCode` 接口进行条码识别 → 移植到审计移动工作终端。

## 同类型物件识别（医保卡）

OpenCV轮廓检测一般步骤：
1. 读取原图 → 2. 滤波处理 → 3. 转灰度 → 4. 二值化 → 5. 边缘检测 → 6. 膨胀+腐蚀闭合边缘 → 7. 轮廓检测 → 8. 按特征筛选 → 9. 截取物件

关键代码：
```python
# 二值化
ret, img_bi = cv2.threshold(img_gray, 110, 255, cv2.THRESH_BINARY_INV)
# 边缘检测
img_edged = cv2.Canny(img_bi, 30, 100)
# 膨胀+腐蚀
img_edged2 = cv2.dilate(img_edged, None, iterations=5)
img_edged2 = cv2.erode(img_edged2, None, iterations=4)
# 轮廓检测
(contours, _) = cv2.findContours(img_edged2.copy(), cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
# 按宽高比筛选（医保卡宽高比1.55~2.0）
lrect = cv2.minAreaRect(cnt)
ratio = lrect[1][0]/lrect[1][1]
if ratio > 1.55 and ratio < 2.0:
    rect_box = cv2.boundingRect(cnt)
    img_crop = img_cp[rect_box[1]:rect_box[1]+rect_box[3], rect_box[0]:rect_box[0]+rect_box[2]]
```

## 延伸思考

- 一般物件识别用OpenCV通用步骤即可解决
- 特定行业物件可通过深度学习训练自定义识别模型
- OpenCV可处理摄像头实时视频，用于监控录像人脸/物体检测
- 实际应用需注意透视变换纠偏
