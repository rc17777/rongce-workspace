# 德勤宣布将新一代 AI Agent 正式部署至全球审计平台

> 来源：Bloomberg 2026-06-29 | 搬运：审计犟驴

## 核心内容

德勤将新一代 AI Agent 正式部署至全球审计平台，不再只是聊天机器人，而是真正参与审计工作流：

| 能力 | 说明 |
|:--|:--|
| 自动分析交易 | 交易数据自动识别异常模式 |
| 自动筛选异常事项 | 风险事项自动标记 |
| 自动阅读合同 | 合同条款自动提取/比对 |
| 自动生成审计Memo初稿 | 减少手工撰写 |
| 自动跟踪客户回复 | 审计确认函/客户沟通自动化 |

## 关键观点

**最大的变化不是 AI 更聪明，而是 AI 已经进入审计工作流（Workflow）。**

## 对融策的启示

- 德勤走的是"AI嵌入审计作业流"路线——与融策 workflow-embedder 技能 + audit-blackboard 多Agent平台方向一致
- 区别：德勤服务全球上市公司审计（数据量大、标准化高）；融策服务政府审计/工程咨询（场景碎片化、非结构化多）
- 但底层逻辑相同：AI不是辅助工具，而是工作流中的一环
- 融策7Agent协作架构（data_scout→contract_hound→bid_hunter→law_inspector→workpaper_crafter→report_writer→review_sentinel）= 同一套逻辑的中国本土版
