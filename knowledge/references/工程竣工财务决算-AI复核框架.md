## 一、工程竣工财务决算·AI复核总览

工程竣工财务决算审计的复核与一般财务审计报告有显著差异——它涉及**工程造价、财务决算、概算执行**三条线的交叉验证。

```
财务数据线：资金来源→资金占用→交付使用资产→结余资金
     ↕ 交叉验证
工程造价线：概算→预算→合同价→结算价→决算价
     ↕ 交叉验证
项目管理线：立项→招标→施工→验收→决算
```

## 二、AI复核15维适配（工程竣工财务决算版）

### 10维正文复核

| # | 维度 | 工程竣工财务决算专属检查项 |
|:--|:-----|:-----|
| 1 | **格式规范性** | 决算报表是否完整（资金平衡表/交付使用资产表/待摊投资明细表/转出投资表）；签章是否齐全 |
| 2 | **数字一致性** | 概算数↔批复数↔合同数↔结算数↔决算数，同一数字在不同表中必须一致 |
| 3 | **合计校验** | 资金来源合计=资金占用合计（资金平衡表）；交付使用资产合计=建筑安装工程+设备购置+待摊投资分配+其他 |
| 4 | **单位一致性** | 概算→万元、决算→元的单位陷阱（经典错误）；面积单位（㎡/亩） |
| 5 | **日期逻辑** | 开工日期≤竣工日期≤决算基准日；验收日期不早于竣工日期 |
| 6 | **法规引用** | 《基本建设财务规则》81号令·《基本建设项目建设成本管理规定》·《基本建设项目竣工财务决算管理暂行办法》 |
| 7 | **投资概算执行** | 概算执行率=实际投资/批复概算，超概10%以上需说明+审批 |
| 8 | **待摊投资分摊** | 待摊投资分摊方法是否合理（按概算比例/实际建筑面积/实际投资比例） |
| 9 | **交付使用资产** | 是否按单项工程列示；不应计入交付使用资产的费用是否剔除 |
| 10 | **结余资金处理** | 结余资金=资金来源-投资总额；结余处置是否符合规定 |

### 5维交叉比对

| # | 维度 | 比对内容 |
|:--|:-----|:-----|
| 11 | **决算↔概算** | 投资完成额 vs 批复概算·超概是否有审批 |
| 12 | **决算↔结算** | 建筑安装工程投资是否基于结算审核结果 |
| 13 | **财务账↔决算报表** | 在建工程科目余额 vs 决算报表·差异原因说明 |
| 14 | **合同台账↔决算明细** | 合同金额+变更+签证 vs 决算金额·未签订合同直接实施 |
| 15 | **全链路金额追踪** | 概算→预算→招标控制价→合同价→结算审核价→决算价，每一步差异记录 |

## 三、四分类输出（工程竣工财务决算版）

AI复核报告强制按以下四类输出：

### ✅ 已确认事实（证据充分）

```
条件：数值差异有合同/签证/审批文件佐证
示例：
- 建筑安装工程投资超概算280万元（概算批复1200万，实际1480万），
  超概批复文件：[文号]，审批日期：2025-XX-XX
- 待摊投资-建设单位管理费超支36万元（限额45万，实际81万），
  已取得超支说明及审批，但在建工程明细账中仍有5笔计入了该项科目
```

### ⚠️ 风险提示（需进一步核实）

```
- 设备投资概算500万，实际支出230万，节余54%。
  → 注意：节余过大可能说明概算编制不实，或存在应采购未采购
- 勘察设计费支出120万元，占建筑安装工程投资比例8.5%（行业通常3-5%）
  → 注意：需核实设计合同是否包含非本项目的设计内容
- 交付使用资产中"其他"项占比21%（通常应<5%）
  → 注意：可能存在不应计入交付使用资产的费用被归集
```

### ❓ 待核实事项（证据不足/需补充资料）

```
- 资金来源中"自筹资金"280万元 → 无银行进账单佐证
- 征地拆迁费310万元 → 未见拆迁协议及付款凭证
- 竣工图与施工图差异 → 30项变更中15项无设计变更通知单
- 甲供材料 → 无完整的收发存台账，无法核实实际领用量
```

### 📚 历史相似线索（仅供参考）

```
[相似案例#2022-工程-07] 某市政道路竣工决算：招标代理费重复计入待摊投资
  → 提示方向：检查招标代理服务费是否同时出现在前期费用和待摊投资中

[相似案例#2023-工程-03] 某医院建设项目：设备安装费与土建工程重复计算
  → 提示方向：检查设备安装费是否已包含在建筑安装工程合同总价中

[相似案例#2024-工程-02] 某学校建设项目：超概23%未经审批即办理竣工决算
  → 提示方向：核对投资概算执行率，检查超概审批程序
```

## 四、规则引擎专项规则（工程竣工财务决算版）

在通用规则引擎基础上，新增工程专项规则：

```python
# R07 投资概算执行偏差
条件：ABS(实际完成投资/批复概算 - 1) > 0.1
输出：投资概算执行率{rate:.1%}，超概{excess:.0f}万元。请核实超概审批。
需核实：超概原因+审批程序+是否履行调整程序

# R08 资金来源占用平衡
条件：ABS(资金来源合计 - 资金占用合计) > 0.01
输出：资金平衡表不平衡！来源合计{src:.2f} vs 占用合计{dst:.2f}，差额{diff:.2f}。
需核实：报表编制是否准确，科目归集是否正确

# R09 待摊投资分摊比例异常
条件：待摊投资总额/建筑安装工程投资 > 0.15
输出：待摊投资占建安投资{ratio:.1%}，超过15%阈值。
需核实：是否有多计待摊投资，分摊方法是否合理

# R10 交付使用资产-其他占比异常
条件：交付使用资产-其他/交付使用资产总计 > 0.1
输出：交付使用资产中"其他"占比{ratio:.1%}。
需核实：其他项的具体构成，是否有不应计入的支出

# R11 建设单位管理费超限额
条件：建设单位管理费 > 按财建[2016]504号计算的管理费限额
输出：管理费{actual:.0f}万元，限额{limit:.0f}万元，超支{excess:.0f}万元。
需核实：超支审批+是否有不应计入的支出被归集到管理费
```

## 六、人工确认点（工程竣工财务决算专属）

- [ ] 概算批复文件是否原件？（复印件需核对印章）
- [ ] 结算是基于审计局/财政评审中心的审核结果还是施工单位申报数？
- [ ] 征地拆迁费是否取得被拆迁人签字的补偿协议？
- [ ] 甲供材料清单是否与施工合同约定一致？（防止甲供材被重复计入施工单位结算）
- [ ] 竣工图是否经监理和建设单位签章？
- [ ] 项目是否已取得竣工验收备案？
- [ ] 尾工工程是否单独列示并预留资金？

---

> ⚠️ 工程竣工财务决算审计的AI复核最核心问题是：AI无法判断现场实际情况。
> 例如"在建工程是否已完工投入使用"必须实地查看。规则引擎只能告诉你"数据不对"，
> 不能告诉你"为什么不对"——原因必须由人去找。
