## 逐层详解

### 第一层：法律 — 《社会保险法》（2010 / 2018修正）

**定位**：医保制度的总章程，所有下位法的授权依据。

**核心条款（审计相关）**：

| 条款 | 内容 | 审计关注点 |
|:-----|------|-----------|
| **第28条** | 医保基金支付限于目录内药品/诊疗/设施 | 目录外串换报销即为违规 |
| **第30条** | 四类不支付：工伤/第三人/公共卫生/境外 | 交叉混入其他保险是常见问题 |
| **第31条** | 经办机构与医疗机构签服务协议 | 协议管理是审计切入点 |
| **第64条** | 基金专款专用，不得侵占挪用 | 挪用即违法 |
| **第78条** | **审计机关对基金收支、管理、投资运营实施监督** | ⚠️ 审计法定职权来源 |
| **第87条** | 机构骗保：退回 + 2-5倍罚款 + 解除协议 + 吊销执业 | 行政处罚上限 |
| **第88条** | 个人骗保：退回 + 2-5倍罚款 | 个人骗保行政处罚 |
| **第94条** | 构成犯罪的，依法追究刑事责任 | 与刑法衔接 |

### 第二层：行政法规 — 735号令《医保基金使用监管条例》（2021.5.1）

**定位**：从"基金管理"到"使用监管"的范式转换。首次把**定点机构的每一条行为红线**写入国务院法规。

**定点医药机构禁止行为（审计必查清单）**：

```
第15条 行为禁区（11项）：
  □ 分解住院              □ 挂床住院
  □ 过度诊疗/检查         □ 分解处方
  □ 超量开药/重复开药     □ 重复收费
  □ 超标准收费            □ 分解项目收费
  □ 串换药品/耗材/诊疗项目 □ 诱导/协助冒名就医
  □ 虚假就医/购药
```

**法律责任梯度**（执法→刑事的渐进升级）：

| 等级 | 条款 | 行为 | 后果 |
|:-----|:-----|------|------|
| ⚠️ 一般违规 | 第38条 | 分解住院、过度诊疗、重复收费、串换药品等 | 退回 + 1-2倍罚款 + 约谈 |
| 🔴 严重违规 | 第40条 | 诱导冒名、伪造变造、虚构服务（骗保） | 退回 + 2-5倍罚款 + 暂停6-12月 + 解除协议 + 吊销执业 |
| 🔴 个人违规 | 第41条 | 冒名使用、重复享受、转卖药品 | 退回 + 暂停联网3-12月 + 2-5倍罚款 |
| 💀 追责底线 | 第43条 | 造成重大损失 | 法人/负责人5年禁业 |
| 💀 刑事衔接 | 第48条 | 构成犯罪 | 移送追究刑事责任 |

**审计工具条款**：

- 第16条：机构须保存财务账目/处方/病历/出入库记录 → **审计数据来源**
- 第16条：通过医保信息系统全面准确传送数据 → **数据真实性可验证**
- 第27条：7项监督检查措施（现场检查/询问/复制资料/封存等）
- 第27条第6项：**可聘请会计师事务所协助检查** → 融策的法定参与依据
- 第35条：举报奖励制度

### 第三层：部门规章 — 医保局2号令 & 3号令（2021.2.1）

**定位**：定点管理的操作细则。

| 文件 | 管辖对象 | 核心制度 |
|:-----|:---------|---------|
| **2号令** | 定点医疗机构 | 准入6条件、评估3个月、协议管理、动态考核、退出机制 |
| **3号令** | 定点零售药店 | 准入7条件、执业药师在岗、医保用药标识、信息系统对接 |

**审计切入点**：
- 定点准入是否合规（有没有带病定点？）
- 协议考核记录是否走过场？
- 信息系统是否按要求传送全部就诊人员信息？（数据完整性）

### 第四层：规范性文件 — 集采 & DRG/DIP

**国办发〔2021〕2号：药品集采常态化**

| 机制 | 内容 |
|:-----|------|
| 量价挂钩 | 以全量换最低价 |
| 医保预付 | 年度约定量30%预付给医院 |
| 优先使用 | 信息系统设定优先推荐集采品种 |
| 结余留用 | 集采降价后的结余医保基金留给医院 |
| 覆盖范围 | 所有公立医院 + 医保定点民营/零售 |

**医保发〔2021〕48号：DRG/DIP三年行动计划**

| 阶段 | 目标 |
|:-----|------|
| 2022 | 启动不少于40%统筹区 |
| 2023 | 累计不少于70% |
| 2024 | 100%统筹区全覆盖 |
| 2025 | 所有住院医疗机构+病种90%+基金70%覆盖 |

**审计新风险点**：
- DRG下**推诿重症患者**（选轻不选重）
- DRG下**分解住院**变种（一个病分两次住院）
- DRG下**编码高套**（把小病填成大病编码）
- 集采下**用高价非中选药品替代中选药品**

### 第五层：刑事司法解释 — 法发〔2024〕6号

**定位**：医保骗保入刑的"操作手册"，两高+公安部联合印发，2024年2月施行。

**定罪标准（刑法第266条诈骗罪）**：

| 主体 | 行为类型（7+6项） | 罪名 |
|:-----|:-----------------|:-----|
| **定点机构** | ①诱导冒名就医 ②伪造变造资料 ③虚构服务 ④分解住院/挂床 ⑤重复收费/串换 ⑥串换药品 ⑦目录外纳入结算 | 诈骗罪 |
| **个人** | ①伪造变造资料 ②冒名就医购药 ③虚构服务 ④重复享受 ⑤转卖药品套现 ⑥其他 | 诈骗罪 |
| **医保经办工作人员** | 利用职务便利骗保 | 贪污罪（刑法第382条） |
| **倒卖药品者** | 明知骗保购买药品而收购销售 | 掩饰隐瞒犯罪所得罪（第312条） |

**量刑加重情节**（第10条，从重处罚）：

1. 组织、指挥犯罪团伙
2. 曾因医保骗保受过刑事追究
3. 拒不退赃退赔或转移财产
4. 造成其他严重后果或恶劣社会影响

**对审计的关键意义**：

- 第15条：**全面收集处方、病历等原始证据 + 核心证据材料**
- 第18条：**医保行政部门监督检查中收集的证据可以直接作为定案根据**（行政取证→刑事转化通道打通）
- 第19条：可以用银行流水、审计报告、医保系统数据等综合认定诈骗数额
- 第12条：对认罪认罚的医务人员可从宽 → 审计取证时可做政策宣讲

**⚠️ 融策审计实践中可直接引用**：
- 法发〔2024〕6号将"分解住院、挂床住院"明确列为刑事诈骗行为 → 不再是行政违规
- 第18条打通行政取证→刑事证据的桥梁 → 审计工作底稿可能就是日后刑事判决的定案证据

### 第六层：审计实践 — 审计署2017-1号公告

**定位**：全国医保基金专项审计的标杆性成果，审计方案设计可直接参照。

**审计覆盖面**：
- 28个省本级 + 166市 + 569县
- 抽查3433.13亿元
- 延伸3715家医疗机构 + 2002家药店

**五大类问题及金额**：

| 问题类别 | 问题金额 | 典型手段 |
|:---------|:--------|:---------|
| 基金筹集不到位 | 101.14亿（少缴少征+未拨付+未上缴） | 用人单位少缴、财政未足额拨付 |
| 基金支出不规范 | 24.06亿（挪用+扩大范围支出） | 挪用于对外借款、扩大支付范围 |
| 制度衔接不到位 | 14.57亿（重复参保补贴）+ 0.13亿（重复报销） | 305万人重复参保、5124人重复报销 |
| 骗取套取 | 2.17亿 | 923家机构 + 少数自然人 |
| 违规加价/收费 | 12.41亿 | 474家加价销售 + 1330家违规收费 |

**若尔盖等县级案例参考**：
- 铁岭市中心医院：分解住院30.2万
- 华宁县：204位病人分解住院33.41万
- 定西市：394人次分解住院61万
- 违规率参照：约0.46%（全国）→ 可按此比例初估同类审计的问题规模

## 审计实操：从法规到取证的路径

```
┌────────────────┐
│  发现异常数据   │ ← 审计分析模型（分解住院/重复报销/高频就医/聚类）
└───────┬────────┘
        ▼
┌────────────────┐
│  对照行为红线   │ ← 735号令第15条/第38条/第40条/第41条
└───────┬────────┘
        ▼
┌────────────────┐
│  固定原始证据   │ ← 处方/病历/结算单/出入库记录（735号令第16条要求保存）
│  + 系统数据     │ ← 医保信息系统传送记录（第16条）+ 信息系统数据（法发6号第19条）
└───────┬────────┘
        ▼
┌────────────────┐
│  量化违规金额   │ ← 多收/多报金额 → 决定处罚档次（退回 vs 1-2倍 vs 2-5倍）
└───────┬────────┘
        ▼
┌────────────────┐
│  分级处理建议   │
│  ～50万以下     │ → 行政处理（退回+罚款+暂停/解除协议）
│  ～50万以上     │ → 移送刑事（法发6号第23条：医保局→公安移送）
│  重大/恶劣      │ → 即时移送 + 追缴违法所得（法发6号第22条：应追尽追）
└────────────────┘
```
