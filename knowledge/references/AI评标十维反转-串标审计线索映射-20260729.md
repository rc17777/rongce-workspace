# AI评标系统十维检测→串标审计线索反转映射

> 编制：融策右护卫 | 日期：2026-07-29 | 版本：v1.0
> 
> **核心命题**：2026年AI评标辅助系统（广联达清标、国泰新点等）在暗标评审中检测的10个维度，反转后即为10条独立的串标审计线索。

---

## 一、背景与逻辑

### 1.1 行业背景

- 2026年全国依法必招项目平均废标率：**22.1%**（国家发改委公共资源交易司一季度行业运行报告）
- 投标文件编制类问题占废标原因：**26.3%**
- AI暗标评审已在以下省份推进：云南（2026年7月1日起全省房建市政）、宁夏（"机器管招投标"）、甘肃、内蒙古、新疆

### 1.2 反转逻辑

AI评标系统对暗标的检测逻辑是：

```
逐维扫描（10维） → 发现违规标记 → 判定废标（单份文件）
```

反转后的审计逻辑是：

```
逐维扫描（10维） → 多份标书中同一违规模式 → 判定同源（多份文件关联）
```

**一句话**：AI判断的是"这份标书格式违规"，审计判断的是"为什么三家标书的违规方式一模一样"。

## 二、十维→串标线索映射总表

### 2.1 完整映射

| 1 | 文档元数据 | Word属性：作者/公司/修订人/编辑时间 | 多份标书属性中**同一作者名/公司名/修订人**→同人制作多份标书 | 提取docProps/core.xml中dc:creator/cp:lastModifiedBy | **L5升级** | 🔴铁证 |

### 2.2 十维→五级映射树

```
AI评标十维
├─ 维度1(文档元数据)                                  → L5 元数据交叉（扩展属性字段）
├─ 维度2(字体颜色)+3(页面设置)+4(正文格式)+5(表格)+7(页码)
│                                                      → L5 元数据交叉（格式指纹扩展）
├─ 维度6(图片EXIF)                                    → L4 图片哈希（设备溯源升级）
├─ 维度8(敏感词/NLP)+部分维度10(规律性同源词)          → L3 文本雷同（笔误指纹增强）
├─ 维度2(颜色RGB通道)                                 → 新增 L6a 页面格式指纹
└─ 维度10(空行/标点/段长)                             → 新增 L6b 排版行为指纹
```

## 三、逐维详细分析

### 3.1 维度1：文档元数据 → L5升级（铁证）

**AI检测逻辑**：Word属性中自动保存的作者、公司、修订人，在暗标中构成身份泄露→废标。

**反转审计逻辑**：如果三家公司的技术标，Word属性中**作者都是"张三"、公司都是"XX建设集团"**——无论正文怎么替换公司名，属性暴露了真实的制作者。

**取证规则**：
```python
# 从docx提取核心元数据
from docx import Document
doc = Document("技术标.docx")
props = doc.core_properties
# 关键字段：props.author, props.last_modified_by, props.company
```

**判定标准**：任一字段跨文件完全匹配→铁证。不依赖其他层级。

---

### 3.2 维度6：图片EXIF → L4升级（铁证）

**AI检测逻辑**：图片EXIF中的设备型号/GPS坐标/软件名在暗标中构成身份泄露→废标。

**反转审计逻辑**：三家公司的技术标，嵌入图片的EXIF显示：
- 同一相机型号（如iPhone 15 Pro）
- 同一GPS坐标（同一栋写字楼）
- 同一软件名（同一截图工具版本）
- 拍摄时间间隔在合理范围内

→ **同一个人在同一地点用同一台设备，为三家公司做了标书**。

**取证规则**：
```python
from PIL import Image
img = Image.open("extracted_image.jpg")
exif = img._getexif()
# 关键标签：
# 271: Make (制造商)
# 272: Model (型号)
# 34853: GPSInfo (GPS坐标)
# 305: Software (软件)
# 36867: DateTimeOriginal (拍摄时间)
```

**判定标准**：3+字段同时跨文件匹配→铁证。与L4图片哈希互补：L4检测"同一张图"，EXIF检测"同一个人的不同图"。

---

### 3.3 维度9：共同错别字/NLP → L3升级（铁证）

**AI检测逻辑**：敏感词库扫描企业名/地名/人名→废标。

**反转审计逻辑**：三份标书出现**相同的错别字、相同的不规范缩写、相同的术语偏好**，不是模板化套话（模板不会写错别字），是**人的语言习惯**。

**取证规则**：

| 信号类型 | 示例 | 为何不是模板 |
|:--|:--|:--|
| 共同错别字 | "截至"写成"截止"（三份都一样） | 模板不会带错别字 |
| 不规范缩写 | "工民建"vs"工业与民用建筑" | 模板用标准术语 |
| 术语偏好 | "砼"vs"混凝土"全篇一致 | 不同人习惯不同 |
| 量词习惯 | "3600万元"vs"3600万" | 同人统一写法 |

**判定标准**：交集≥3个非模板化词汇→铁证。关键是与现有L3 TF-IDF互补：TF-IDF被模板化套话冲淡信号，笔误指纹是独立强信号。

---

### 3.4 维度2+3+4+5+7：格式指纹 → L5增强（强信号）

五维合流为**格式同源指纹**：页边距（毫米级）+ 字体RGB + 行距/缩进 + 表格样式 + 页码标签。单独一维匹配可能是巧合，五维同时匹配→同模板/同人制作的概率极高。

| 维 | 取证字段 | 精度 | 判定阈值 |
|:--|:--|:--|:--|
| 页面设置 | 四边页边距差值 | 0.1mm | 四边差值均<0.5mm |
| 字体颜色 | span["color"] RGB | 通道级(R,G,B) | R±1, G±1, B±1 |
| 正文格式 | font+size+leading | 精确匹配 | 三参数完全相同 |
| 表格 | borderWeight+cellShading+colWidth | 精确匹配 | 三参数组完全相同 |
| 页码 | 正则提取标签格式 | 字符串匹配 | 格式模式完全相同 |

---

### 3.5 维度10：排版行为指纹 → 新增L6b（强信号）

**AI检测逻辑**：文本指纹/特征比对→检测文档同源→废标。

**反转审计逻辑**：排版习惯是**肌肉记忆**，不是模板规范的产物——

| 特征 | 度量方式 | 意义 |
|:--|:--|:--|
| 空行分布 | 标题后空1行 vs 空2行 | 长期习惯，非模板控制 |
| 标点习惯 | 全角/半角混用比例 | 输入法习惯 |
| 段落长度CV | std/mean | 行文节奏 |
| 表格后习惯 | 表后空行频率 | 排版肌肉记忆 |

**取证规则**：
```python
import pandas as pd
# 段落长度变异系数
df['段长'] = df['paragraph'].apply(len)
cv = df['段长'].std() / df['段长'].mean()
# 空行间距模式
blank_pattern = [p.is_empty for p in paragraphs]  # bool序列
# 标点全半角比
quanjiao = sum(1 for c in text if 0xFF00 <= ord(c) <= 0xFFEF)
banjiao = sum(1 for c in text if 0x0020 <= ord(c) <= 0x007E)
ratio = quanjiao / (banjiao + 1)
```

## 四、对现有L3-L5体系的升级影响

| 现有层级 | 原检测内容 | 十维反转增强 | 升级效果 |
|:--|:--|:--|:--|
| **L3** | TF-IDF文本相似度 | +共同错别字/笔误指纹 +共同术语偏好 | 去噪增强：排除模板套话干扰，保留人的语言习惯信号 |
| **L4** | 图片SHA256/感知哈希 | +EXIF设备/GPS/软件/时间溯源 | 覆盖升级："同一张图"→"同一个人拍的不同的图" |
| **L5** | PDF Author/Creator/Producer | +Word属性(作者/修订人/公司) +页边距/RGB/行距/表格样式/页码标签 | 字段扩展：从3字段到10+字段；精度升级：到毫米级/通道级 |
| **新增L6a** | — | +字体RGB通道值跨文件比对 | 独立检测维度，5项强信号可组合为铁证 |
| **新增L6b** | — | +排版行为指纹（空行/标点/段长） | 独立检测维度，人的排版肌肉记忆 |

## 五、检测优先级与铁证组合

### 5.1 直接铁证（单维命中即可定案）

| 维 | 信号 | 解释 |
|:--|:--|:--|
| 1 | 文档属性中同一作者名/公司名 | 无论正文如何替换，属性暴露真实制作者 |
| 6 | EXIF中3+字段同时匹配（相机+GPS+软件） | GPS坐标精确到同栋建筑，排除随机巧合 |
| 9 | 共同错别字≥3个 + 排除模板词 | 错别字是个人习惯，模板不传染 |

### 5.2 组合铁证（5项强信号≥3项同时命中）

| 组合 | 命中条件 |
|:--|:--|
| 格式同源 | 页边距+RGB+行距+表格+页码中≥3项跨文件精确匹配 |
| 排版同人 | 空行模式+标点比+段长CV+段长分布+表后习惯中≥3项一致 |

| 优先级 | 检测项 | 理由 | 依赖 |
