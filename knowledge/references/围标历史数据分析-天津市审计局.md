# 基于招标投标历史数据揭示围标行为的审计方法

> 来源: 黄晶 王鋆（天津市审计局），《中国审计》2023年第20期
> 转载: 数智审Lab，2026-05-26

## 围标表现形式

1. **轮流坐庄**: 围标团伙成员轮流以高于市场的不合理报价中标
2. **价格联盟**: 围标团伙一致抬高报价，达到高价中标
3. **陪伴补偿**: 内部事先指定中标人，中标人给予"陪伴者"补偿

## 影响因素

- **项目竞争性**: 专业性强的领域，投标人业务关联度高，围标隐蔽性更高
- **投标人数**: 最佳规模3-4个主体。获利性最高，可控性最好；能规避"黑马"风险

## 三类分析方法

### 1. 节资率分析

**公式**: 节资率 = (招标控制价 - 中标价格) / 招标控制价

节资率越低 → 招标节省的资金越少 → 竞争越弱 → 围标概率越高

**操作**: 按节资率从低到高排列 → 箱线图标记异常值 → 低于下界(Q1-1.5×IQR)的项目为疑点

### 2. 支持度分析

**公式**: 支持度 = AB两个投标主体同时投标次数 / 该类别招标项目总次数

支持度>0.5 → 二者在所有项目中同时出现的比例过半 → 行为高度一致

### 3. 置信度分析

**公式**: 置信度(A→B) = A与B同时出现次数 / A投标总次数

置信度>0.6 → A投标时B也随之投标的概率>60% → 联手围标可能

## 交叉研判

综合节资率低项目疑点表 + 高关联性项目疑点表：
- 重点分析投标参与主体为3-4个的项目
- 考虑行业覆盖面和采购金额大小
- 对标《招投标法实施条例》第40条进行现场核实

## 现场核实要点

1. 核实投标参与人劳动关系（社保/公积金/亲属关系）
2. 核查电子投标文件"最后编制人"是否为同一人
3. 核查MAC地址是否相同（同一台电脑编制）
4. 比对代理人/项目经理/法人是否为同一人
