# TF-IDF文本相似度分析查处围标串标 — 阜新市审计局实战案例

- **来源**：数智审Lab公众号（2026-05-23转载）
- **原文**：《中国审计》2023年第19期
- **作者**：辽宁省阜新市审计局 胡云波、褚万江、丁乙
- **项目背景**：某市老旧小区改造项目审计（多标段/多投标人/标段间重复出现）
- **存入日期**：2026-05-27
- **关联技能**：procurement-audit-models (L3-TFIDF, L5-元数据)

## 一、审计背景与问题

老旧小区改造项目标段多、投标单位多，且**不同标段重复出现相同投标单位**，围标串标高发。人工逐份比对投标文件费时费力。

## 二、审计方法（两个维度）

### 维度1：TF-IDF文本相似度比对

**工具链**：Python + jieba + numpy + pandas + pdfminer + PyQt5(UI封装)

**流程**：
1. 整理同一标段多家投标文件放入同一文件夹
2. TF-IDF算法计算两两相似度
3. 结果按相似度降序排列
4. 导出Excel，重点关注高相似度结果

**判断标准**：相似度比值高 → 审查是否同一家单位制作标书 → 围标串标

### 维度2：文件属性比对（元数据）

**工具链**：Python + python-docx (Document库) + properties功能

**提取字段**：作者、创建时间、最后一次保存者、公司信息

**判断逻辑**：
- 作者相同 → 同一人编制
- 创建时间相近 → 同批次制作
- 不同公司但属性相同 → 同源嫌疑

**深度验证**：中标单位管理人员社保缴纳信息交叉比对

## 三、三种误判排除情况（⚠️ 重要）

作者特别强调以下三种情况**不能直接定性为串标**：

1. **引用招标文件**：投标人编制技术标时使用招标文件内容 → 各投标人部分内容完全一致，甚至错误一致
2. **公开渠道来源**：公开渠道能搜到的内容 → 不能直接定性
3. **公开发布的文件**：某章节内容一致 → 需核实是否为单位官网/公示栏公开过的文件

> "以上三种情况表面上符合招标投标法关于定性为串标的条件，实质各投标人标书相同内容均是通过公共、公开渠道获得，各投标人未参与围标。"
