# 审计人的三层修炼：微观·中观·宏观

## 一、核心观点

审计发现的差距不在"捡豆子"多少，而在**认知层次**：

> 同样一份报告——新人只看到"发票没签字"，高手能看穿"制度在养蛀虫"。

领导三连问（审计报告价值的终极拷问）：
1. 这些问题的**根源**是什么？
2. 是**制度设计缺陷**还是**管控机制系统性失效**？
3. **换了这个人**，这些问题还会不会再犯？

**冰山模型**：
| 层次 | 视角 | 看到什么 | 对应动作 |
|:----|:----|:--------|:--------|
| 微观 | 审"点" | 操作失误、程序瑕疵、单据缺失 | 个别问题中查蛛丝马迹 |
| 中观 | 审"线" | 流程断点、控制盲区、制度不合理 | 串点成线、优化流程 |
| 宏观 | 审"面" | 治理缺陷、文化积弊、系统性风险 | 从点到面、审视治理机制 |

**核心判断**：微观→中观→宏观不是职级差异，是**认知跃迁**。三重穿透的报告 = 治理诊断书，不是碎片问题清单。

## 二、三个案例（原文）

### 案例1：差旅费——微观追出利益链条（微观→中观）
- 表象：销售经理报销单反复出现同一家酒店，发票全真、金额合规
- 追问："他为什么每次都住这家？"
- 穿透：酒店实控人是该经理连襟 → "差旅费"实为套取公司资金补贴亲属生意
- 教训：只盯发票数字，永远发现不了利益链条

### 案例2：拆单采购——制度倒逼违规（中观）
- 表象：多名采购员年度内规律性拆分大额采购为小额订单，单笔都在审批权限内
- 穿透：全年数据横向对比 → 拆分痕迹一目了然
- 根因：单笔超5万需上级审批、流程慢 → 制度倒逼拆单绕行
- 报告动作：不追责业务员，推动审批流程重构 + 信用授权 + 紧急采购通道 → 同类问题大幅减少

### 案例3：子公司违规拆借——治理缺陷（宏观）
- 表象：连年查出各子公司违规拆借资金，每次追责但此起彼伏
- 穿透：所有案例串起来分析 → 根因是集团资金集中管理制度缺陷（要求全部上存又没留足周转金）
- 报告动作：推动集团资金管控模式结构性变革
- 教训：不改革治理机制，漏洞持续制造违规 = 永远当"救火队员"

### 实战范本：虚列运费审计（三重穿透）
1. **微观查异常**：运输费报销单缺明细和签收记录（凭证附件不全）
2. **中观追关联**：全年结算数据 → 月度金额高度一致、淡旺季规律异常 → 运输公司法人是市场部前员工、注册时间与离职时间吻合
3. **宏观推改革**：汇总各子公司报告 → 物流费全集团多年异常偏高 → 根因是缺乏统一供应商准入和比价机制 → 推动物流采购体系全面改革

## 三、对融策的启示

1. **审盾复核逻辑升级**：AI不能只捡"发票没签字"的微观豆子，要能识别"现象背后是不是制度性缺陷"。三层穿透逻辑作为复核维度固化进清单（见下）。
2. **发现归类强制标注层次**：每个问题必须标注所属层次（点/线/面），P0级问题必须追问到中观以上，否则报告就是碎片清单。
3. **整改建议层级匹配**：建议层级必须≥问题层级——微观问题给整改动作，中观问题给流程重构，宏观问题给治理改革。建议层级低于问题层级 = 整改靶心偏移。
4. **屡审屡犯问题专项审查**：报告中出现"历年审计都发现同类问题"的表述时，必须强制追问宏观归因，禁止只追责当事人。

## 四、提炼的复核规则（已入 audit-report-review 技能）

### 新维度 ⑯ 认知层次穿透检查

| 规则ID | 检查内容 | 触发条件 | 风险等级 |
|:--|:--|:--|:--:|
| L-1 | **根源追问**：报告每个P0问题是否回答了"偶然单点 or 失效系统的必然产物"？ | P0问题无根源分析 | 🔴 P0 |
| L-2 | **微观→中观跃迁**：≥2个同类问题指向同一流程/环节时，是否上升审视流程断点/控制盲区/制度缺陷？ | 同类问题只做单点罗列 | 🟡 P1 |
| L-3 | **中观→宏观跃迁**：同类问题跨主体/跨年度反复出现（含"屡审屡犯"表述）时，是否做治理层面归因？ | 屡犯问题只追责当事人 | 🟡 P1 |
| L-4 | **建议层级匹配**：整改建议层级是否≥问题层级？（微观→整改动作；中观→流程重构；宏观→治理改革） | 建议层级低于问题层级 | 🟡 P1 |
| L-5 | **利益链条敏感**：同一供应商/同一对象/同一地点高频重复出现时，是否追问关联关系（实控人/亲属/前员工）？ | 高频重复但只查单据 | 🟡 P1 |
| L-6 | **穿透举证**：中观/宏观结论是否有微观证据支撑（≥2个具体案例+数据横向对比）？ | 宏观结论无微观支撑（空谈） | 🔴 P0 |

### 误报抑制 FP-14（三层穿透误报抑制）

| 规则ID | 规则内容 | 说明 |
|:--|:--|:--|
| FP-14A | **报告类型分级**：操作型报告（收支/专项/往来款）以微观为主，宏观归因仅在有跨期跨主体证据时启用；治理型报告（经责/绩效/国企）必须到中观以上。禁止"为赋新词强说愁"式强行上升到宏观 | 防止过度解读 |
| FP-14B | **无证据不升维**：中观/宏观结论必须引用报告内的具体案例或数据；无引用即标记"建议补充穿透举证"，不直接判错 | 防止AI凭空升维 |
| FP-14C | **领导追问模拟**：对每个P0问题用"根源是什么？制度还是管控？换人还犯不犯？"三连问做最终质检，答不上来的问题退回 | 终极质检 |
