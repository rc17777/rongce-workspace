# 小金库三种情形—案例深度解剖分析

> 分析日期：2026-07-29 | 分析人：融策右护卫

## 前言：为什么这篇文章值得深度解剖

来源是中央纪委国家监委网站，作者方弈霏——这不是自媒体解读，是纪检监察机关对执纪标准的正式表述。三个案例不是虚构的说教，而是**经过执纪审查并已定性的真实案件**。解剖它们，可以直接还原纪检监察机关在"小金库"问题上的取证逻辑、定性标准和量纪尺度。

## 案例一解剖：张某12万账外账——"公用"为什么不是辩护

### 案件事实还原

| 要素 | 内容 |
|:--|:--|
| 当事人 | 某区农业技术推广中心主任 张某（中共党员） |
| 手法 | 授意财务人员截留单位技术服务收入 |
| 金额 | 12万余元 |
| 账外管理方式 | 另设"账外账" |
| 资金用途 | 支付未纳入财政预算、缺乏正规票据、不便报销的开支 |
| 个人侵占 | 无 |
| 当事人认知 | "钱一分没进自己腰包，是为了给单位留机动经费" |
| 处理结果 | 党纪处分 + "小金库"被依规处理 |

### 纪检监察机关的取证逻辑（逆向还原）

```
Step 1: 发现技术服务收入与入账金额不符
  → 外部数据（技术服务合同/收款记录）vs 财务账 → 差额12万
  ↓
Step 2: 追踪12万去向
  → 发现另设的"账外账" → 证实公款"脱离监管"
  ↓
Step 3: 查资金用途
  → 用于单位开支 → 排除个人侵占（不等于不违纪！）
  ↓
Step 4: 查谁授意
  → 张某授意财务人员 → 直接责任者
  ↓
Step 5: 定性
  → 违反国家财经纪律 → 《条例》第30条第2款 → 党纪处分
```

### 关键判断：两个"不是"击穿两个错误认知

| 错误认知 | 击穿逻辑 |
|:--|:--|
| "钱没进腰包就不是事" | 违纪判定核心是**公款是否脱离监管**，与资金去向无关。化公为私→涉嫌犯罪；用于违规消费→廉洁纪律；全盘公用→财经纪律。三种都是违纪，只是条款不同。 |
| "为了单位方便" | 预算控制/审批/票据核销是制度屏障。绕开监管=拆除安全屏障。"机动经费"意味着"随性花钱"——今天用于单位开支，明天就可能给个人买单。 |

### 对审计的启示

这个案例揭示了一个重要的审计陷阱：**审计人员最容易漏掉的就是"全部用于公用"的小金库**——因为钱没进私人腰包，容易产生"情有可原"的心理。但纪检监察的标准是：脱离监管本身就是违纪，不需要等钱被挪走才认定。

**审计实操**：收入完整性测试是锁定的第一工具。技术服务收入/租金收入/资产处置收入——这三类最容易"遗漏"，也是小金库最常见的资金来源。

## 案例二解剖：林某28万套取+滥发福利——"为大家谋福利"为什么是双重违纪

### 案件事实还原

| 要素 | 内容 |
|:--|:--|
| 当事人 | 某县直单位负责人 林某（中共党员） |
| 手法 | 授意财务人员**虚构合同**套取项目资金 |
| 金额 | 28万元 |
| 账外管理方式 | 设立"小金库"（"备用资金池"模式） |
| 资金用途 | ①单位不便报销的日常开支 ②节假日"过节福利""加班补贴" |
| 动机 | "关心干部职工""为大家谋福利" |
| 处理结果 | 党纪政务处分 + 违规发放款项被责令清退 + 账外资金被依规处理 |

### 纪检监察机关的取证逻辑（逆向还原）

```
Step 1: 发现"虚构合同"
  → 合同×付款×供应商三点一线 → 合同对应的项目不存在 → 套取
  ↓
Step 2: 追踪28万去向
  → 账外资金池 → 多用途混杂
  ↓
Step 3: 分别统计各用途金额
  → 用途A：单位日常开支（金额X）
  → 用途B：节假日福利补贴（金额Y）
  ↓
Step 4: 分别定性
  → 设立行为 → 违反财经纪律（《条例》第30条）
  → 滥发福利 → 违反廉洁纪律（《条例》第114条）
  → 判定：**两个行为性质不同、各自独立，分别认定、合并追责**
  ↓
Step 5: 福利合规性检验（四把尺子）
  → 有政策依据？无 → 不符合
  → 符合发放范围标准？无依据 → 不符合
  → 履行规定程序？未 → 不符合
  → 资金来源合法？套取资金 → 不合法
  → 四把尺子全部不通过 → 违规滥发
```

### 最关键的法律判断："分项算账、分别定性"

这是全文最有价值的法律规则：

> "私设'小金库'后又将其作为用途多样的'备用资金池'，设立行为与使用行为**不存在吸收或牵连关系**，一般'分项算账''分别定性'。"

翻译成审计语言：

```
小金库的设立 → 一个违纪行为 → 《条例》第30条
小金库的钱用于滥发福利 → 另一个违纪行为 → 《条例》第114条
小金库的钱用于公款吃喝送礼 → 又一个违纪行为 → 《条例》第113条
```

**在审计报告中，这三个不能写成一个"私设小金库问题"，必须分三段写。**

### 对审计的启示

这个案例纠正了审计实务中一个常见错误：把"私设小金库"当成一个笼统的问题，结案了事。纪检监察的标准是——设立是一个问题，每一类不合规的用途是独立的问题。审计报告必须**逐用途分类、逐类定性、逐类引用法规**。

**审计实操**：发现小金库后，不能只做"资金池总额"的统计，必须做**资金流向的用途分类表**——这是后续定责的刚需。

## 案例三解剖：周某百万"接力"小金库——"沿用惯例"为什么是自欺欺人

### 案件事实还原

| 要素 | 内容 |
|:--|:--|
| 当事人 | 某国企负责人 周某（中共党员） |
| 前任违法手段 | 虚构工程项目截留资金 |
| 金额 | 近百万元 |
| 周某发现时 | 履新后知晓 |
| 周某的行为 | **未上报、未清退归公，循惯例继续使用** |
| 资金用途 | 违规宴请、高档烟酒礼品、娱乐开支 |
| 周某的辩护 | "'小金库'是前任设的，规矩是以前定的，我只是照着惯例用" |
| 处理结果 | 党纪政务处分 + 违规资金被追缴 |

### 纪检监察机关的定性逻辑

```
事实A：周某"知晓"账外资金性质违规
  +
事实B：周某"继续管理、支配、使用"账外资金
  ↓
结论：构成主动参与、持续实施违反财经纪律行为
  ↓
"前任设立"不是后任使用的免责理由
```

两个击穿：

| 辩护 | 击穿 |
|:--|:--|
| "谁设立谁担责" | 后任明知违规仍继续使用 = **主动参与**，不适用"只接摊子不担责" |
| "沿用惯例" | "一直这么干" ≠ "可以这么干"；惯例 = 长期突破纪律形成的**潜规则** |

### 对审计的启示：经责审计的四个关键时间点

这个案例对经责审计的时间切分有直接指导意义：

```
前任任期结束 ─────── 周某到任 ─────── 周某发现小金库 ─────── 审计进场
    │                    │                    │                      │
    │← 设立责任 →│                    │                      │
    │              │← 未及时报告 →│                      │
    │              │              │← 继续使用责任 →│
    │              │              │                 │← 审计发现 →│
```

| 责任类型 | 归属 | 依据 |
|:--|:--|:--|
| 设立小金库 | 前任 | 虚构工程截留资金 |
| 未及时报告/清退 | 周某（上任后至发现时） | 明知后未予纠正 |
| 继续使用 | 周某（发现后至审计进场） | 持续管理支配使用 |
| 公款宴请送礼 | 周某 | 《条例》第113条独立追责 |

**审计实操**：经责审计发现小金库时，必须区分**设立时点**与**使用期间**，建立精确的时间线——谁设立、谁报告、谁继续使用、谁从中获益——四个问题四人可能不同，四人的责任各自独立。

## 四、三案串联：小金库审计的三层定性框架

```
第一层：资金来源定性
  → 截留收入（张某） / 虚构合同套取（林某） / 虚构工程截留（周某）
  → 手段越恶劣，量纪越重

第二层：账外管理定性
  → 资金是否脱离单位账簿监管？
  → 是 → 违反财经纪律（《条例》第30条）
  → 无论资金去向如何，这一条已经成立

第三层：资金去向定性
  → "全部公用" → 仅财经纪律
  → "滥发福利" → +廉洁纪律（第114条）
  → "公款吃喝送礼" → +廉洁纪律（第113条）
  → "个人侵占" → +涉嫌贪污犯罪
  → 每一类去向独立定性，合并处理
```

## 六、一句话总结

> 这篇文章的审计价值在于——纪检监察机关用三个已定性的真实案例，把"小金库"定责的底层规则讲透了：①违纪看"脱离监管"，不看"钱去哪"；②设立和每一类用途是独立违纪行为，分别定性合并追责；③后任明知不报=主动参与。这三条可以直接写进审计报告的定责依据——不是参考，是引用。
