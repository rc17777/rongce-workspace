## 一、核心定位

- **狭义建议**：审计报告中针对具体问题的整改建议
- **广义建议**：审计综合报告/审计要情/审计专报/审计信息等多载体，面向党委政府/行业主管部门；含单项建议（一事一单位）、综合性建议（多事多单位）、专项整治建议（行业领域）
- **本质**：借助发现的问题 + 政策背景 + 行业规律 + 改革方向，挖掘深层次矛盾，层层扩展、步步提升，提炼普遍性/规律性/倾向性/苗头性隐患，追根溯源，系统性解决问题
- **一句话**：由具体问题的微观层面上升到治理体系宏观层面，由一个单位扩展到行业领域

## 二、提炼路径一：层层构建监管体系（针对单位内部问题）

**上升阶梯**：具体问题 → 制度制定执行 → 管理运行体系 → 权力监督制约

| 层级 | 关注点 | 建议指向 |
|:--|:--|:--|
| ① 具体问题 | 化整为零规避招标/违规指定供应商/坐支租金等 | 就事论事整改（操作层） |
| ② 制度制定执行 | 单位制度建设漏洞、管理混乱、无章可循 | 建立健全制度体系并严格执行（制度层） |
| ③ 管理运行体系 | 上下级联动制约机制缺失、监管缺位 | 常态化监管机制+追责问责机制（管理层） |
| ④ 权力监督制约 | "一把手"利用漏洞插手事务 | 细化"三重一大"刚性约束、权力清单、公开公示（权力层） |

**案例**：办公楼维修1600万项目 → 规避400万招标限额指定供应商（关联一级单位"一把手"）→ 结余资金签证维修 → 功能调整出租坐支租金 → 小金库30余万。问题源头：二级单位制度空白 + 一级单位监管缺失 + "一把手"权力无制约。建议按四层递进：建制度体系 → 建联动监管机制 → 细化集体决策+权力清单。

**判定要点**：问题不孤立，从具体问题逐层上溯，每上升一层建议对象就换一级（单位→上级主管→权力机制）。

## 三、提炼路径二：步步推进深化改革（针对行业领域问题）

**上升阶梯**：企业/单位问题 → 现代企业/治理体系 → 主管部门监管问效 → 地方党委政府改革谋划

| 层级 | 关注点 | 建议指向 |
|:--|:--|:--|
| ① 企业发展问题 | 内控不健全、管理架构不合理、理念不足 | 现代企业/治理体系框架（企业层） |
| ② 管理体系 | 总公司与子公司各自为政、无指导无问效 | 主管部门绩效考核+指导监督（主管层） |
| ③ 主管部门监管问效 | 考核考评机制不健全、缺乏关键指标 | 完善监管问效机制（监管层） |
| ④ 改革谋划部署 | 改革方案不细化、业务重叠无序扩张 | 地方党委政府政策引领+布局优化（决策层） |

**案例**：22家国企整合为9家，3家代表性国企共性：主营投入多盈利少、子公司各自为政、亏损仍发绩效、内控缺失、部门负责人兼任子公司法人。建议按四层递进：建现代企业体系 → 主管绩效考核办法 → 地方政府优化改革方案、产业集中度、战略产业培育。

**判定要点**：行业共性需多个类似单位关联分析后才成立；建议对象逐层上移（企业→主管→政府），最终落到改革谋划。

## 四、两条路径共性规律（可复用模板）

```
分析：问题 → 关联事件系统分析（审深审透、一挖到底、追根溯源）
提炼：逐层上溯，每层换建议对象：
  单位内部问题：具体问题 → 制度 → 管理运行 → 权力制约
  行业领域问题：企业问题 → 治理体系 → 主管部门 → 政府谋划
输出：合理、具体、可操作，标本兼治，从"被动整改"到"主动治理"
```

## 五、可直接嵌入 report_writer 的 Prompt 片段

```
【审计建议提炼路径规则】
1. 禁止孤立看待问题：将发现置于因果关系链中系统分析，追根溯源。
2. 按"层层构建监管体系"路径提炼（单位内部问题）：
   具体问题→制度制定执行→管理运行体系→权力监督制约，逐层上溯，
   每上升一层建议对象升一级（单位→上级主管→权力机制）。
3. 按"步步推进深化改革"路径提炼（行业领域问题）：
   企业问题→现代治理体系→主管部门监管问效→地方党委政府改革谋划。
4. 建议载体分层：操作层就事论事整改，制度层建章立制，管理层建机制，
   权力层刚性约束；对应"政策层面→制度完善/管理层面→流程优化/
   操作层面→具体整改"分层分类框架。
5. 每层建议必须"合理、具体、可操作"，杜绝空洞表述；
   最终指向标本兼治，推动被审计单位从被动整改转向主动治理。
```
