## 二、海南穿透式审计案例（核心实战）

**背景**：某省2025年家电以旧换新补贴审计，400余万台家电、近20亿资金、全链条碎片化数据。

### 四个数据模型

| 模型 | 逻辑 | 发现 |
|:---|:---|:---|
| **价格异常模型** | 申报价 vs 实际售价 | 企业按最高限价申报，实售价远低于申报价，差价套走 |
| **消费行为模型** | 消费者购买模式分析 | 某县2000+人购买金额完全一致；近5000人一次性买5类以上家电 |
| **SN码身份模型** | 机身序列号唯一性核验 | 大量SN码重复/格式不对/跨地区复用；部分企业伪造比例高达20%+ |
| **安装真实性模型** | 安装照片场景比对 | 不同订单安装照片场景一模一样（摆拍） |

### 资金闭环追踪

```
虚假支付 → 公户入账 → 私户转出（"备用金""返利"名义） → 全额回流
```

家电未交付，交易是假的，补贴真的领了。最终数十条线索移送公安，抓获嫌疑人数十名，追缴资金近千万元。

## 三、地方经验

### 湖南："全链条联动"

| 维度 | 做法 |
|:---|:---|
| 纵向 | 省-市-县三级联动，资金拨付到哪里监管跟到哪里 |
| 横向 | 主动对接省财政厅、交通运输厅等，跨部门联席会议、信息共享 |
| 穿透核查 | 资金流向穿透 + 项目建设穿透 + 数据质量穿透 |
| 整改闭环 | 问题清单→整改台账→销号管理，整改不力约谈通报 |

### 泰兴："全周期"三维管控

> **资金是底线，项目是抓手，效益是目标。**

| 维度 | 检查重点 |
|:---|:---|
| 资金流向 | 国库→收款单位全过程；以旧换新资金筛查重复申报、虚假冒领 |
| 项目落地 | 立项→招投标→施工→竣工验收全流程；查虚报工程量、偷工减料 |
| 政策实效 | 民生项目是否契合需求、工程建成后是否投入使用、产业创新有无有效产出 |

## 四、2026年审计"打法"三升级

1. **跟踪审计常态化**：边实施、边审计、边整改，不等项目做完，当场整改
2. **从"资金流"扩展到"信息流"**：不仅查账本，更要查项目库数据真实性、安装照片真伪、SN码联网核验
3. **从"查问题"到"建机制"**：海南推动全省统一SN码数据库+扫码核验+真伪联网+重复图片智能识别；湖南推动省级专项清理和制度完善

## 五、四大实战经验

1. **别只盯着账本**：造假不在账上，在业务逻辑里。走出办公室到现场
2. **数据能力是基本功**：百万级数据量人工查不过来，审计人员至少能看懂数据模型、提出分析需求
3. **整改比查问题重要**：盯到问题改了、漏洞堵了、制度建了才算完
4. **别怕"得罪人"**：1.3万亿是全国人民的钱，不是哪个部门的"私房钱"
