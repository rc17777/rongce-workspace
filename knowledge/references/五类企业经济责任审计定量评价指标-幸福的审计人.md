## 一、核心观点

**不能用一把尺子量所有企业。** 不同类型企业功能定位不同、目标导向不同、风险特征不同，定量评价指标如果不分类设置，不仅评价结果失真，还可能误导组织决策。

2019年两办规定明确要求"坚持定量与定性相结合"——但实务中很多单位至今仍是一套指标套所有。

## 二、五类企业分类体系

### 2.1 商业竞争类企业

**核心逻辑**：市场化程度高，评价以财务绩效和市场竞争力为主。

| | | 总资产报酬率(10%) | 息税前利润/平均总资产×100% |
| | | 营业收入利润率(10%) | 利润总额/营业收入×100% |
| 发展能力 | 20% | 营业收入增长率(10%) | (本期-上期)/上期×100% |
| | | 利润增长率(10%) | (本期-上期)/上期×100% |
| 资产质量 | 15% | 资产负债率(8%) | 总负债/总资产×100% |
| | | 应收账款周转率(7%) | 营业收入/平均应收账款 |
| 风险控制 | 15% | 重大损失金额(8%) | 审计认定的重大损失绝对值 |
| | | 违规经营投资损失率(7%) | 违规损失/净资产×100% |

## 三、评分方法

### 3.1 基准分+加减分

- 每个指标设基准分（按权重百分比）
- 达到行业平均水平=基准分，高于=加分，低于=扣分
- 加减分幅度不超过基准分的20%

### 3.2 一票否决情形

- 发生重大国有资产流失事件
- 发生重大安全生产责任事故
- 存在重大违法违纪问题
- 审计发现重大财务造假

### 3.3 等级划分

| 等级 | 分数区间 | 含义 |
|:----|:-------|:----|
| 优秀 | ≥90分 | 全面履职，成效显著 |
| 良好 | 75-89分 | 较好履职，基本达标 |
| 合格 | 60-74分 | 基本履职，存在不足 |
| 不合格 | <60分 | 履职不到位，问题严重 |

## 四、权重设置通用原则

1. **核心指标权重不得低于模板建议值的80%**（保证不同评价之间的可比性）
2. **合规风险类指标任何类型企业不低于10%**（底线思维）
3. **单项指标调整幅度不超过±5%**（防止人为操纵）
4. **定量指标权重不低于总分的70%**（落实"定量为主"要求）
5. **定性评分需区分四类调整因素**：
   - 历史遗留因素：前任遗留且已努力解决
   - 不可抗力因素：自然灾害/政策突变
   - 战略调整因素：上级统一部署的战略转型
   - 特殊使命因素：承担的非常规政治任务

## 五、常见误区

| 误区 | 表现 | 正确做法 |
|:----|:----|:--------|
| 一张表审所有 | 用商业竞争类的利润指标考核公益类企业 | 按企业类型选择对应指标体系 |
| 权重分散化 | 每个指标都设5%-8%，没有重点 | 核心权重项必须突出（≥15%） |
| 忽略行业对标 | 只看企业自身数据不看行业水平 | 引入行业平均、优秀值做参照 |
| 定性评分随意 | "综合考虑""酌情判断"无标准 | 定性四类因素有明确的评分规则 |
| 历史问题混为一谈 | 将前任遗留问题计入现任评分 | 历史遗留单独列示并标注 |

## 六、与融策现有经责审计体系的结合

> 结合「芮听柠说」五维模型 + 六类企业指标体系 = 完整的经责审计量化评价体系

```
被审计对象分类
  ├── 商业竞争类 → 盈利能力为主(35%)
  ├── 公益功能类 → 服务效能为主(35%)
  ├── 特定功能类 → 任务完成度为主(30%)
  ├── 金融类     → 资产质量为主(30%)
  ├── 科技创新类 → 创新产出为主(30%)
  └── 工程项目负责人 → 五维模型(A30/B25/C25/D12/E8) ← 芮听柠说

统一执行
  ├── 基准分+加减分
  ├── 一票否决
  ├── 四等级划分(优秀/良好/合格/不合格)
  └── 三类责任认定(直接/领导/免责)
```
