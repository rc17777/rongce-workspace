# 高质量审计建议撰写要点（研究型审计）

## 一、核心定位

审计建议要突破传统"纠错式"局限，向**建设性、预防性**转变。研究贯穿审计立项、实施、报告、整改全流程，以"研"的深度提升"建议"的精度。

## 二、审前定方向（3要）

| 要点 | 操作 |
|:--|:--|
| 吃透政策意图 | 沿"政治—政策—项目—资金"主线，研究决策部署的出台背景、战略意图、改革目标，站在决策层高度提建议 |
| 摸清行业规律 | 依托政策库/案例库/法规库，搜集业务数据与法规，研究被审计对象历史沿革、现状、趋势 |
| 锁定审计重点 | 大数据精准画像，结合历年普遍性、典型性问题，明确重点防跑偏 |

## 三、深挖问题根源（3招）

| 招式 | 操作 |
|:--|:--|
| 穿透表象看本质 | 从制度适用→运行→设计逐层上溯，区分**管理不当/制度缺陷/政策偏差**三种成因 |
| 跳出个案看全局 | 立足体制机制优化，提炼普遍性、规律性问题，铲除问题土壤 |
| 逆向逻辑深研 | 沿"资金—项目—政策—政治"自下而上追溯，形成"由表及里、由下至上"完整链条 |

## 四、打磨建议质量（3标准）

1. **具体可操作**：紧密围绕问题核心，分门别类、精准施策，直击要害，杜绝"大而化之、笼而统之"的空洞表述
2. **分层分类**（核心框架）：
   - **政策层面** → 指向制度完善
   - **管理层面** → 指向流程优化
   - **操作层面** → 指向具体整改
   - 层次分明，被审计单位才能对号入座
3. **换位思考**：充分听取被审计单位意见，坚持**"三个区分开来"**——既要坚决纠正违规行为，也要促进体制机制健全、推动源头治理

## 五、拓展成果应用（3机制）

1. **多维转化**：审计报告/审计综合报告/审计专报/审计信息多载体；单项建议（一事一单位）+ 综合性建议（多事多单位）+ 专项整治建议并用
2. **闭环管理**："审、研、改、治"闭环，推动"当下改"与"长久立"结合，同步跟踪整改成效
3. **跨越升级**：以建议为纽带，推动被审计单位从"被动整改"转向"主动治理"，促进风险防范与治理水平同步提升

## 六、可直接嵌入提示词的撰写规则（Prompt 片段）

```
【审计建议撰写规则】
1. 每条建议必须"具体可操作"，紧扣问题核心，禁止大而化之的空洞表述。
2. 建议按"政策层面→制度完善 / 管理层面→流程优化 / 操作层面→具体整改"分层分类，
   让被审计单位对号入座。
3. 分析问题成因时，区分"管理不当/制度缺陷/政策偏差"，穿透表象找根源。
4. 坚持"三个区分开来"：区分无意过失与明知故犯、区分探索性失误与违纪违法、
   区分体制机制问题与个人责任问题；既纠违规、又促机制健全。
5. 建议要有前瞻性和全局性：跳出个案，指向体制机制优化，而非仅指某个具体问题。
6. 用"资金—项目—政策—政治"逆向链条校验建议逻辑：微观针对性 + 宏观建设性并重。
7. 每条建议表述：问题定性 → 成因分析 → 具体措施 → 预期效果，四要素齐全。
```

## 附：三个区分开来（原文引用口径）

在尊重客观事实的基础上，坚持"三个区分开来"，既要坚决纠正违规行为，也要注重促进体制机制健全，推动加强源头治理。确保建议可行，才是有效的建议。
