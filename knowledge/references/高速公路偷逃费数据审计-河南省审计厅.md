# 揭示偷逃高速公路通行费问题的数据审计方法

> 来源: 李东苇 童珂（河南省审计厅/新乡市凤泉区审计局），《中国审计》2023年第8期
> 转载: 数智审Lab，2025-11-13
> 领域: 国企/交通基础设施专项审计

## 背景

2020年1月全国高速公路"一张网"运行后，跨省单次通行费大增，部分车主利用非法手段偷逃通行费。

## 业务流程

高速公路收费四大环节：
1. **客户服务**: ETC新办/售后/应用
2. **收费业务**: 按实际路径分段计费
3. **清分结算**: ETC交易清分/省际拆分/退费/资金结算
4. **稽核管理**: 通行费追缴

## 数据标准表设计

三张核心标准表：

| 标准表 | 来源 | 关键字段 |
|:------|:-----|:--------|
| ETC发行系统 | ETC办理数据 | 车牌号、定载人数、总轴数、ETC设备信息 |
| 收费系统 | 收费站数据 | 车牌号、上下站点、收费金额、收费车型 |
| 结算数据 | ETC门架 | 车牌号、门架数据、拆分清算数据 |

数据清洗要点：剔除同归属地通行数据、车牌识别错误、冗余数据。

## 三种偷逃费手法及检测方法

### 1. 大车小标 — 改变车型少交费

**手法**: 修改ETC标识车型（修改行驶证/人工收费车型判断不准）
- ETC发行车型 < 实际车型 → 少交通行费
- 重点：牵引车和快递物流车

**检测**: 
- ETC发行系统车型 vs 车辆实际登记车型(核定载人数/总轴数/车长) → 提取差异
- 运管收费车型 vs 实际车型 → 提取差异
- 结合ETC门架+图像现场核实

### 2. 跑长买短 — 隐藏路径按最小费额收费

**手法**: 屏蔽设备使门架无法获取通行信息 → 按"最小费额"收费

**检测**:
- 筛选按"最小费额"收费的车辆 → 无门架分段计费信息 → 还原真实路径
- 筛选"有入无出"异常轨迹 → 收费金额=0 + 超时通行
- 注意排除车牌识别错误造成的误判

### 3. 违规优免 — 蹭免费政策

**手法**:
- 8座以上客车利用节假日"不抬杆"直接通行蹭免费
- 运管/养护单位车辆以"应急车辆"为由长期免费

**检测**:
- 节假日收费=0 → 关联车辆登记信息 → 筛选不符免费政策的车型
- 应急车辆免费 → 分析行驶轨迹规律 → 关注交费比例低的车辆
- 结合稽核系统识别跨省路径和图片

## 融策适用场景

- **国企审计**: 交通投资集团/高速公路运营公司专项审计
- **绩效评价**: 高速公路收费管理绩效评价
- **资产清查**: 高速公路收费系统数据资产核查
- **监督检查**: 收费合规性专项检查
