# 融策政府审计AI能力概览

> 用途：投标方案、商务洽谈、能力展示
> 版本：v1.0 | 创建日期：2026-07-14

## 一、核心定位

**政府审计专属AI作业平台**——不是通用AI工具，而是深植于政府审计12条业务线、覆盖审计全流程的领域AI能力集合。

## 二、能力矩阵（审计全流程覆盖）

### 审前阶段

| 能力 | 说明 | 对应业务线 | 案例 |
|:----|:----|:---------|:----|
| 审计方案自动生成 | 基于12条业务线标准文件，自动生成项目实施方案模板 | 全部 | 输入项目类型→输出方案框架 |
| 历史数据预分析 | 从RAG知识库检索类似项目案例，预判风险点 | 全部 | 同类项目历史问题清单 |
| 取数清单自动生成 | 根据项目类型，自动生成应取数据清单 | 全部 | 12条线各有标准取数清单 |

| 专项资金穿透审计 | 社保/教育/民政/保障房四类资金全量异常检测 | 专项资金审计 | 参保资格→待遇发放→资金流向 |
| 工程审计四维检测 | 变更签证/造价偏差/进度款/合规性 | 工程审计 | 四维模型→疑点清单 |
| 补贴审计三阶段链 | 申报合规→拨付追踪→使用核查 | 政府补贴审计 | 申报→拨付→卫星图比对 |

| 碳排放数据核查 | 能耗vs行业基准/碳排放报告vs能耗推算 | 能源审计 | 能耗数据→碳排放数据交叉验证 |

## 三、核心壁垒（竞品不具备的）

### 领域知识壁垒

| 壁垒 | 内容 | 来源 |
|:----|:----|:----|
| 12条业务线标准文件 | 每条线含：法规依据→取数清单→识别规则→底稿模板→报告框架 | 融策多年实战沉淀 |
| 串标检测23层体系 | 全国最完整的电子招投标串标检测体系 | 4个实战项目验证 |

| 审计报告15维复核模型 | 四层十五维、三类证据、四级风险、五张底稿 | 融策自研模型 |

| 壁垒 | 内容 |
|:----|:----|

| 过程留痕 | 每条分析记录可追溯，满足新注册会计师法要求 |
| 全量分析 | 非抽样，全量数据覆盖，满足新会计法要求 |

## 四、适用场景（投标方案用语）

### 场景一：审计局外聘审计服务

```
我们提供的不只是审计人员，而是"AI审计作业平台+专业审计团队"的复合能力。
每个项目进场前，我们的AI平台已完成：
- 数据预分析（基于历史案例）
- 风险预判（基于12条业务线规则）
- 取数清单生成（基于标准模板）

进场后，AI平台辅助完成全量数据筛查，审计人员聚焦于：
- 异常线索人工复核
- 问题定性法条匹配
- 整改建议专业判断
```

### 场景二：财政监督检查

```
融策财政监督检查模型支持：
- 30条识别规则自动跑疑点
- 数据标准模板一键导入
- 疑点→核查任务→底稿初稿全流程
```

### 场景三：专项资金审计

```
四类资金（社保/教育/民政/保障房）全量数据一次性筛查，
AI自动输出：
- 异常发放清单
- 资格不符疑点
- 资金流向追踪图
- 法条对应定性依据
```

## 五、合规声明（投标方案必备）

> 融策AI审计平台严格遵守：
> - **《数据安全法》**：全部本地化部署，涉密数据不联网、不上传
> - **新《注册会计师法》**：全过程留痕，数据分析记录自动归档为法定底稿
> - **新《会计法》**：全量数据核查，不做抽样替代
> - **四川省审计厅2024版文书格式标准**：审计报告/底稿/取证单格式对齐官方标准
