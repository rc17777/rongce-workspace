## 一、第一层：三篇是生产链的三段工序，不是三种写法

| | 文献1 江夏审计 | 文献2 林红（广东厅） | 文献3 审计观察 |
|:--|:--|:--|:--|
| 管的是 | **表达**：怎么写好建议 | **发现**：怎么穿透问题 | **提炼**：怎么上升高度 |
| 生产阶段 | ③ 输出端（后端） | ① 输入端（前端） | ② 加工端（中端） |
| 核心动作 | 打磨建议之质 | 全数据穿透三层 | 两条上升阶梯 |
| 视角 | 审计项目全流程 | 审计范式体系 | 建议形成机制 |
| 层次 | 操作法（怎么干） | 世界观（怎么想） | 方法论（怎么转化） |

**关键判断**：文献2 提供"穿透力"（深度），文献3 提供"高度"（层次），文献1 提供"精度"（质量）。深度 × 高度 × 精度 = 高质量建议。三篇缺一不可，且顺序不能乱——**先要发现得深，才能提炼得高，最后表达得准**。

## 二、第二层：三篇共享同一认知路径——"上升"，但方向不同

三篇都在讲"从具体到抽象、从个案到全局、从治标到治本"，但**归纳上升之外，还有一条演绎下沉**，两篇合起来才是完整回路：

```
        【下行：理解政策意图】（文献1 审前 · 先研后审）
   政治 ──→ 政策 ──→ 项目 ──→ 资金
    ▲                              │
    │                              ▼
    │                    （文献2 数据穿透：全量证据底座）
    │                              │
    │                              ▼
   政治 ←── 政策 ←── 项目 ←── 资金
        【上行：提炼治理建议】（文献3 · 系统思维）
```

- **下行（文献1）**："政治—政策—项目—资金"——把党中央决策意图翻译成审计重点，确保建议的政治性和前瞻性
- **上行（文献3）**："资金—项目—政策—政治"——从具体资金问题逐层上溯到制度、体制、权力制约
- **中段（文献2）**：全量数据穿透提供证据支撑，保证上行的每一层都有数据锚点

**这就是"U型生产回路"**：先自上而下理解政策意图（定方向），再自下而上提炼建议（出成果）。单有下行会沦为"背政策"的空洞建议；单有上行会停留在"纠错"层面。三篇合起来才闭合。

## 三、第三层：三个分类框架是同构的——同一问题的三种切法

这是最容易被忽略的深层关系。三篇各有一套分类，粗看是不同体系，细看是**同一实体的三个切面**：

| 切面 | 框架 | 切的是什么 | 回答的问题 |
|:--|:--|:--|:--|
| 文献2 成因三辨 | 执行偏差 / 体制缺陷 / 机制缺陷 | 问题**为什么发生** | 根源在哪 |
| 文献3 上升阶梯 | 具体问题→制度→管理→权力 | 建议**提给谁、多高** | 往哪上升 |
| 文献1 分层分类 | 政策层面→制度完善 / 管理层面→流程优化 / 操作层面→具体整改 | 建议**落在哪层** | 怎么写 |

**勾稽关系**：
```
cause_type（成因） ──决定──→ 上升阶梯（路径） ──决定──→ 分层分类（落点）
   执行偏差 ───────────→ 操作层整改 ───────────→ 操作层面建议（就事论事）
   机制缺陷 ───────────→ 管理/监管层 ───────────→ 管理层面建议（流程优化）
   体制缺陷 ───────────→ 制度/权力层 ───────────→ 政策层面建议（制度完善）
```

即：**分析时定成因（文献2）→ 提炼时走阶梯（文献3）→ 表达时分层级（文献1）**。三者是同一分析链的连续三段，这也是我把 cause_type 字段嵌入 finding_schema、让 data_scout 输出→report_writer 消费的底层依据。

## 六、边界与局限（批判性视角）

1. **文献1、3 均出自地方审计机关实务总结**，案例规模（百人团队、22家国企）对融策中小项目需降维适配——不能机械套用"权力监督制约"层级的建议高度，要看项目层级匹配度
2. **文献2 的数据底座要求高**（8系统多源汇聚），融策本地项目数据条件有限时，可降级为"现有数据全量扫描+关键外源补充"，避免为穿透而穿透
3. **三篇均未解决"建议被采纳后如何验证效果"**——需要融策自建：整改跟踪闭环（现状已有 Phase⑥ 雏形）+ 建议采纳率回测
4. **"三个区分开来"在 Agent 语境下易被误用为"从轻定性"**——需在 prompt 中强调：区分的是责任性质，不是放过违规事实
