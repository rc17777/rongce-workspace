# 融策绩效评价满意度问卷设计SOP（v1.0）

> 适用：财政支出绩效评价、部门整体支出绩效评价、政策/项目绩效评价中"社会公众或服务对象满意度"指标取数环节（指标体系中通常占5~10分）。
> 铁律：满意度是要写进报告、给分数的关键结论——**计算口径必须写明，汇总数字必须重新核算，不得凭心算填数**。

---

## 一、总体流程（四步走）

| 步骤 | 做什么 | 产出物 | 时限建议 |
|------|--------|--------|---------|
| ① 探索 | 读实施方案和指标体系，明确满意度指标的定义、权重、调查对象；现场踏勘+非结构访谈5~10名典型对象，摸清本地语境 | 调查对象清单、访谈要点记录 | 进场后3日内 |
| ② 初稿 | 按本SOP第五节模板改写，逐题过第三节八原则 | 问卷初稿 | 1~2日 |
| ③ 预调查 | 非随机抽10~20人试填，检查回收率、填答错误、填答不完整、平均用时 | 预调查小结（含修改点） | 1日 |
| ④ 定稿 | 项目负责人+质控复核人**双人复核**后定稿发放 | 定稿问卷+复核记录 | 发放前完成 |

> 预调查不可省略。试填平均用时>20分钟、或某题空白率>20%，必须回炉。

## 二、问卷结构四件套

1. **封面信**——身份、内容、目的、选样方法、保密承诺、致谢（模板见第五节）
2. **指导语**——卷首"填表说明"+卷中跳答提示
3. **问题与答案**——主体，遵循第三、四节规范
4. **编码与登记项**——问卷编号、调查员编号、日期、地点（首页右上角，事前编码）

## 三、提问八原则（每题过一遍）

| # | 原则 | 绩效评价场景示例 |
|---|------|-----------------|
| 1 | 形式合适 | 态度类用陈述+等级选择；事实类用直接提问 |
| 2 | 问题清楚，参考框架明确 | ❌"您对补贴发放是否满意" → ✅"2025年度您家领取的耕地地力保护补贴，发放是否及时？" |
| 3 | 被调查者必须能胜任 | 不问农户"资金绩效目标设置是否科学"——他答不了，这题给主管部门版 |
| 4 | 越短越好 | 单题一行内说完 |
| 5 | 语言简单，不用术语 | ❌"绩效目标""专项转移支付" → ✅"这笔钱办的事""上面拨下来的钱" |
| 6 | 避免否定句 | ❌"您是否不赞成……" |
| 7 | 避免倾向性 | ❌"政府大力推进的XX工程，您满意吗" → ✅"XX工程实施后，您的评价是？" |
| 8 | 避免双重含义 | ❌"食堂饭菜的质量和分量您满意吗" → 拆成质量、分量两题 |

## 四、答案与题型规范

**两条硬规则：穷尽 + 互斥。** 选项须覆盖所有可能（加"其他___"兜底）；选项间不得交叉重叠。若回收后"其他"占比>15%，说明漏了重要类别，下次必须单列。

**满意度主观题统一五级量表**（全所口径统一，便于跨项目比对）：
非常满意 / 满意 / 基本满意 / 不满意 / 非常不满意（另设"不了解/未使用"独立项，不计入满意度分母）

**题型选用速查：**

| 题型 | 适用 | 注意 |
|------|------|------|
| 是否式 | 知晓度、是否受益、是否参与 | 用作关联题的入口题 |
| 等级式（五级） | 各维度满意度 | 主力题型 |
| 排序式 | "最需要改进的方面"（选3项排序） | 全卷≤1题，费脑 |
| 主观评分式（1~10分） | 总体满意度 | 与五级题互为校验 |
| 矩阵式 | 多个同类维度打分 | ≤6行，交叉放置正反陈述防惯性作答 |
| 情景构想式 | 敏感问题（如是否被吃拿卡要） | 用第三人称故事引入 |
| 开放式 | 意见建议 | 放最后，全卷≤2题 |

**敏感问题三技巧**：①多角度交叉提问验证（收入类）；②生活化措辞，不用带意识形态色彩的语气；③正反陈述交替，破答题惯性。

**题序六规则**：简单在前→行为在前、态度在后→同主题集中→时间顺序不打乱→敏感题、开放题放最后→背景资料放卷尾（自填式）或卷首（访谈式）。

**关联题**：跳答提示必须写在选项后（"→请跳答第X题"），复杂跳转画流程框。

## 五、问卷模板

### 5.1 封面信模板（受托绩效评价版）

> 尊敬的先生/女士：
> 您好！受【委托方：XX市/县财政局】委托，四川融策会计师事务所正在对【XX年度XX项目/政策】开展绩效评价。为了解项目实施的实际效果，我们随机选取了包括您在内的部分【服务对象/受益群众】进行问卷调查。
> 本问卷**匿名填写**，答案没有对错之分，请按您的真实感受作答。您提供的信息将严格保密，仅用于汇总统计分析，评价结果不会呈现任何个人信息，请放心填写。
> 填写约需【5~8】分钟。感谢您的支持与配合！
> 四川融策会计师事务所　XX绩效评价项目组
> 联系电话：XXX-XXXXXXXX　　20XX年X月

**要点**：①署名必须落到具体单位，不得只写"调查组"；②说明内容范围一两句即可，不夸大不隐瞒；③保密承诺+匿名声明是回收率的生命线。

### 5.2 A版：服务对象/社会公众满意度问卷（骨架，12题内）

| 题号 | 题目 | 题型 | 考察点 |
|------|------|------|--------|
| 1 | 您是否知道【XX项目】？（不知道→跳答第9题） | 是否+跳答 | 知晓度（关联题入口） |
| 2 | 您或您的家人是否从【XX项目】中受益？（如领取补贴/使用设施/接受服务） | 是否 | 受益覆盖 |
| 3 | 您通过什么渠道了解到该项目？（可多选） | 多选 | 政策宣传 |
| 4 | 项目【服务/补贴/设施】的**及时性**，您的评价是？ | 五级 | 时效维度 |
| 5 | 项目【服务/补贴/设施】的**质量**，您的评价是？ | 五级 | 质量维度 |
| 6 | 办理/申领过程的**便捷程度**，您的评价是？ | 五级 | 便捷维度 |
| 7 | 工作人员的**服务态度**，您的评价是？ | 五级 | 作风维度 |
| 8 | 总体而言，您对【XX项目】打几分？（1~10分） | 主观评分 | 总体满意度（与4~7题交叉校验） |
| 9 | 您认为该项目最需要改进的方面是？（选3项并排序） | 排序 | 改进方向 |
| 10 | 您对该项目还有什么意见或建议？ | 开放 | 定性补充 |
| 11~12 | 性别/年龄段/身份类别（村民/城镇居民/个体户…） | 背景 | 分组分析用 |

> 使用时替换【】内容，删除不适用维度。**维度题（4~7题）必须与指标体系中满意度指标的二级维度一一对应**，否则回收了也对不上分。

### 5.3 B版：被评价单位内部人员问卷（要点）

对象：项目实施单位经办人员。重点问：资金到位及时性、管理制度可操作性、部门协同、实施障碍（开放题）。**不问总体满意度**（自己评自己没有意义），问"堵点"。

### 5.4 C版：主管部门/关联单位问卷（要点）

对象：行业主管、乡镇经办、代管单位。重点问：目标设置合理性、报送负担、监督检查频次与实效、政策衔接问题。可用矩阵式一题打包。

## 六、抽样与发放

| 事项 | 规范 |
|------|------|
| 对象界定 | 直接受益人优先；受益人<30人的全覆盖 |
| 样本量 | 总体N很大：≥384份（95%置信度、±5%误差）；小总体：n = N×384 ÷ (N+383)；**实务底线：每类对象有效问卷≥30份** |
| 抽样方式 | 从受益人名册（发放台账/参保名单等）随机抽取；**严禁由被评价单位自行挑人**（防样本筛选） |
| 发放方式 | 现场发放回收 > 电话访谈 > 网络问卷；网络问卷须控制链接转发范围 |
| 回收率红线 | **<70%视为问卷设计或组织有重大问题**，须分析原因并补充调查 |

## 七、满意度计算（统一口径）

**赋分法（全所默认）：**
非常满意=100，满意=80，基本满意=60，不满意=30，非常不满意=0

满意度得分 = Σ(各档人数 × 对应赋分) ÷ (有效问卷数 × 100) × 100%

**辅助口径——满意率** =（非常满意+满意人数）÷ 有效问卷数，报告中可并列披露。

**报告披露最低要求**（对应报告结论复核铁律）：
> 发放XX份，回收XX份，回收率XX%；剔除废卷XX份，有效问卷XX份，有效率XX%；满意度得分XX%（赋分法：非常满意X人×100+…÷X份÷100）；对应指标得分=满意度×指标分值。

计算底稿（Excel）归入工作底稿，复核人重算签字。

## 八、质量检查清单

### 8.1 设计阶段（定稿前逐项打勾）

- [ ] 封面信含：单位署名、调查内容、目的、选样说明、保密承诺、致谢
- [ ] 有卷首填表说明；跳答题有清晰指示
- [ ] 每题过了八原则（无术语/无否定句/无倾向性/无双重含义）
- [ ] 所有选项穷尽且互斥，有"其他___"兜底
- [ ] 五级量表口径统一，设"不了解/未使用"独立项
- [ ] 维度题与指标体系满意度二级维度一一对应
- [ ] 敏感题在后、开放题在最后、背景资料按发放方式定位置
- [ ] 预调查试填平均用时≤20分钟
- [ ] 矩阵题≤6行且正反陈述交叉
- [ ] 设置1对逻辑校验题（如第8题总分与4~7题均值应同向）
- [ ] 样本量测算写入调查方案
- [ ] 双人复核签字

### 8.2 回收阶段（废卷剔除规则）

- [ ] 网络问卷：填答时长<90秒 → 废卷
- [ ] 全卷同一选项直线作答（含正反陈述矛盾）→ 废卷
- [ ] 逻辑校验题矛盾（总分≥8但各维度全"不满意"，或反之）→ 废卷
- [ ] 同一IP/设备重复提交 → 保留首份
- [ ] 关键题（总体满意度）空白 → 废卷
- [ ] 回收率、有效率复核并写入底稿
- [ ] "其他"选项占比>15% → 在底稿中说明漏项情况

## 九、常见错误对照表

| 错误示例 | 毛病 | 修正 |
|---------|------|------|
| "您对政府宏观政策是否满意" | 超出认知范畴 | 落到具体可感知的事项 |
| "您是否不赞成取消补贴" | 否定句易漏"不"字 | "取消补贴，您赞成吗" |
| "财政大力支持的民生工程您满意吗" | 倾向性措辞 | "XX工程实施后，您的评价是" |
| "补贴金额和发放时间您满意吗" | 双重含义 | 拆两题 |
| 职业选项：工人/农民/专业人员/教师/医生 | 不互斥 | 教师、医生并入专业人员或单独分层 |
| 满意度只报"满意率98%" | 口径不明+样本不明 | 按第七节披露最低要求写全 |
| 被评价单位帮忙发问卷给"重点群众" | 样本筛选 | 从台账随机抽样，评价组自行发放 |

## 十、归档

问卷定稿、原始问卷（扫描件/导出数据）、废卷剔除记录、满意度计算Excel、复核记录 → 全部归入项目工作底稿。报告引用满意度结论时脚注标明调查时间、样本量、计算口径。
