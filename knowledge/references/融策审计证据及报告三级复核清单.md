**版本：V1.0｜适用：四川融策会计师事务所政府审计、绩效评价及专项检查项目**

> 使用规则：逐项勾选“√通过 / ×不通过 / N/A不适用”，所有“不通过”必须填写整改责任人、期限和复核结论。P0未关闭不得出具报告；P1原则上关闭后出具，确因客观原因未关闭须经质控负责人书面批准；P2纳入修改台账。

## 二、缺陷分级与处置规则

| 级别 | 判断标准 | 典型情形 | 处置要求 |
|---|---|---|---|
| **P0 致命** | 可能导致结论实质错误、重大法律/政治/执业风险 | 关键事实无证据；金额或责任主体错误；法规失效；程序违法；报告与附表重大矛盾；重大问题遗漏 | 立即退回，全部关闭后方可出具；合伙人及质控负责人复核 |
| **P1 重大** | 明显影响报告可信度、完整性或可执行性 | 证据链缺口；定性偏重/偏轻；汇总数字无法勾稽；建议不可执行；征求意见未闭环 | 限期整改并二次复核，原则上关闭后出具 |
| **P2 一般** | 不改变核心结论，但影响规范性和专业形象 | 格式、措辞、编号、引用、个别附件索引错误 | 修改并留痕，可由复核人抽查关闭 |

# 第一关：项目组自查（第一道防线）

**责任主体：各事项主审、报告撰写人、项目负责人**  
**完成节点：问题提交部门复核前；报告送审前再执行一次。**

## 1. 程序与范围

- [ ] 审计通知、委托范围、实施方案、人员分工及调整审批齐全。
- [ ] 实际实施范围与方案一致；未实施事项、范围调整及原因有书面记录。
- [ ] 资料交接、数据采集、查询、函证、延伸调查等程序在授权范围内。
- [ ] 重要会议、现场盘点、谈话、征求意见均形成记录并签字留痕。
- [ ] 被审计单位反馈意见逐条登记，采纳或不采纳均说明理由和依据。

## 2. 每个问题“七要素”自查

对报告每一项问题逐条检查：

- [ ] **主体**准确：单位、部门、人员名称与证据一致。
- [ ] **时间**准确：发生期间、审计期间和政策适用期间无混淆。
- [ ] **事项**清楚：业务背景、行为、过程和结果完整。
- [ ] **金额/数量**准确：口径明确，逐笔清单可追溯。
- [ ] **后果/影响**有证据：不得将可能后果写成已发生事实。
- [ ] **原因/责任**区分主客观因素，符合“三个区分开来”。
- [ ] **法规/标准**有效、适用，条款内容与定性之间存在直接逻辑联系。

## 3. 证据“四性”检查

### 3.1 合法性

- [ ] 证据由有权主体按法定或约定程序取得，不存在越权取证。
- [ ] 银行账户、电子数据、外部调查等需要审批或函件的，审批手续齐全。
- [ ] 复印件注明来源并由提供单位/人员签章；未签章的已注明原因并采取替代验证。
- [ ] 取证单有提供者、取证人、日期和页码；修改处履行确认手续。
- [ ] 涉及个人信息、商业秘密和敏感数据的采集、使用、存储符合权限要求。

### 3.2 可靠性

- [ ] 优先取得原始证据、外部独立证据和系统原始记录。
- [ ] 复印件、截图、导出表已与原件或系统核对。
- [ ] 同一事实的不同证据不存在无法解释的冲突。
- [ ] 同时收集支持和不支持审计判断的证据，不存在选择性取证。
- [ ] “情况属实”取证单有原始凭证支撑，不单独作为关键定性依据。

### 3.3 相关性

- [ ] 每份证据与具体审计目标、问题事实或责任认定有实质联系。
- [ ] 证据所属单位、期间、项目和责任主体与报告表述一致。
- [ ] 任期外事项未错误归入被审计领导责任。
- [ ] 非被审计单位原因造成的后果已合理区分责任。
- [ ] 背景材料、旁证与核心事实证据在索引中明确区分。

### 3.4 充分性

- [ ] 证据数量和质量足以支持事实、金额、定性、责任和影响。
- [ ] 对关键事实存在的其他合理解释已调查并排除。
- [ ] 抽样结论仅覆盖抽样范围；推断总体时有合适方法和依据。
- [ ] 间接证据形成相互印证的闭环，不依赖单一推测。
- [ ] 关键证据缺失、矛盾或无法补证的事项已降级表述或从报告删除。

## 4. 不同证据类型专项检查

### 4.1 直接证据
- [ ] 合同、凭证、批复、会议记录、系统记录等能直接证明报告事实。
- [ ] 原始证据与取证单、底稿、报告表述相互一致。

### 4.2 间接证据
- [ ] 每份间接证据的证明对象明确。
- [ ] 多项间接证据能够相互补强，推理链条无断点。
- [ ] 已排除与现有事实同等合理的替代解释。

### 4.3 电子证据
- [ ] 记录数据来源系统、提取时间、提取人、字段说明、筛选条件及文件哈希（适用时）。
- [ ] 原始数据只读留存，清洗、转换、去重过程可复现。
- [ ] 总量与财务报表、业务台账或系统控制数核对一致。
- [ ] SQL、Python、Excel公式及参数留档并经第二人复算。
- [ ] 异常疑点经原始凭证或现场程序核实，不以模型输出直接定性。
- [ ] 抽审结果未被不当外推为全量结论。

### 4.4 言词证据
- [ ] 谈话由不少于两名工作人员实施，时间、地点、人员和权利义务告知完整。
- [ ] 无诱导性提问；被谈话人核对、修改并逐页签字。
- [ ] 陈述中的猜测、评论、推断未直接作为定性依据。
- [ ] 多份谈话笔录之间及与书证之间的矛盾已核查解释。

### 4.5 专家意见及外部专业成果
- [ ] 专家/机构资质、独立性和业务范围符合要求。
- [ ] 鉴定对象、样本、方法、假设和限制条件清楚。
- [ ] 专家结论与其他证据交叉验证，未以单一专家意见直接定案。
- [ ] 引用监管或专业部门数据已经核实并注明来源。

## 5. 证据链与“排除合理怀疑”反向测试

对每项拟写入报告的问题回答：

- [ ] 如果我是被审计单位，最有力的反驳是什么？现有证据能否回应？
- [ ] 是否存在另一种同样符合证据的合理事实解释？
- [ ] 删除任一关键证据后，结论是否仍成立？如不成立，该证据是否合法可靠？
- [ ] 问题事实、法规要件和证据之间是否逐项对应？
- [ ] 证据索引能否在5分钟内定位到原件和计算底稿？

## 6. 数据、金额和关键结论重算（强制）

> 不得凭心算填写汇总行。每条关键结论须附“数据来源＋计算方法＋交叉验证结果”。

- [ ] 报告每个金额已与问题明细表逐笔汇总重算。
- [ ] 分项合计=小计，小计合计=总计；报告=附表=底稿=取证单。
- [ ] 比例的分子、分母、期间、单位和四舍五入口径明确。
- [ ] 同一金额在摘要、正文、附表、建议和整改清单中一致。
- [ ] “截至”“期间”“累计”“余额”等时点/时期口径使用准确。
- [ ] 万元、元、亿元等单位换算正确，负数、零值、空值处理一致。
- [ ] 关键样本数量、覆盖率、完成率、节约/损失金额由第二人独立复算。
- [ ] 报告结论所称“全部、均、普遍、主要、个别”等量词有数据支撑。

| 结论/金额 | 数据来源 | 计算公式/脚本 | 复算结果 | 交叉验证来源 | 复算人 |
|---|---|---|---|---|---|
|  |  |  |  |  |  |

## 7. 报告文本与建议

- [ ] 报告范围、对象、期间与委托书/实施方案一致。
- [ ] 审计评价有依据，不超越审计范围，不用无证据的绝对化表述。
- [ ] 问题标题准确概括事实，不先入为主或夸大后果。
- [ ] 每项问题按照“标准—事实—原因—影响—结论”形成闭环。
- [ ] 法规名称、文号、条款、施行和失效日期核对无误。
- [ ] 建议对应问题根因，明确责任主体、动作、期限和验收标准。
- [ ] 报告不存在错别字、歧义、重复、编号跳号、附件漏引。
- [ ] 涉及宏观政策时检查目标协同、工具兼容、执行贯通和实际效果。

# 第二关：部门复核（第二道防线）

**责任主体：部门经理/非项目组复核人**  
**复核原则：不重复机械打勾，重点验证重大事项、逻辑链和项目组自查的真实性。**

## 1. 审计目标与实施充分性

- [ ] 重大风险领域均纳入方案并实际实施，删除或调整事项有批准依据。
- [ ] “政治—政策—项目—资金”自上而下主线贯通，审计重点未偏离委托目标。
- [ ] 从资金和项目问题向政策执行及治理层面提炼时，不存在无证据拔高。
- [ ] 宏观政策一致性判断考虑目标、工具、节奏和预期四个维度。

## 2. 重大问题逐项“过证据”

对P0、P1问题及随机抽取不少于30%的P2问题执行：

- [ ] 直接查看原始证据，不仅阅读底稿摘要。
- [ ] 核对事实七要素与报告逐字一致。
- [ ] 验证证据合法、可靠、相关、充分。
- [ ] 检查有利和不利证据是否完整披露。
- [ ] 对替代解释进行反向推演，确认已排除合理怀疑。
- [ ] 核对法规构成要件、效力层级、时效和适用主体。
- [ ] 责任认定区分决策、执行、监督责任及主客观原因。
- [ ] 重大问题的金额、比例、样本和影响由复核人独立重算。

## 3. 报告与附表交叉复核

- [ ] 报告目录、摘要、正文、附表、取证单和底稿形成双向索引。
- [ ] 每项报告问题均能追溯至取证单；每张重大取证单均有处理去向。
- [ ] 问题总数、分类数量、金额总额在各载体一致。
- [ ] 审计评价与问题部分无逻辑矛盾。
- [ ] 建议与问题一一对应，无“万能建议”和超越权限的要求。
- [ ] 征求意见及修改痕迹完整，重大调整重新履行复核。

## 4. 部门复核退回标准

出现以下任一情形，直接退回项目组：

1. 任一P0事项未关闭；
2. 关键证据来源或取得程序不合法；
3. 问题金额无法从明细重算，或报告与附表不一致；
4. 关键事实仅靠“情况属实”或单一言词证据；
5. 法规已失效、适用对象错误或定性明显偏离构成要件；
6. 证据存在重大矛盾且未解释；
7. 重大问题、重大损失风险或重要政策执行偏差遗漏；
8. 被审计单位实质性异议未核查处理；
9. 报告结论超越委托范围或存在政治政策方向风险。

# 第三关：质控终审（第三道防线）

**责任主体：质控部/合伙人或授权终审人**  
**完成节点：正式报告签发前。**

## 1. 政治政策与执业风险

- [ ] 审计结论与党中央重大决策部署、现行法律政策方向一致。
- [ ] 对改革探索、历史遗留和客观条件作辩证分析，落实“三个区分开来”。
- [ ] 不以部门制度替代上位法，不以一般管理瑕疵拔高为重大违法。
- [ ] 涉及敏感主体、重大损失、移送线索、舆情风险事项已履行升级报告。
- [ ] 报告措辞审慎，事实与价值判断分开，无不当政治或法律结论。

## 2. P0/P1事项终审

- [ ] P0、P1问题均附“事实—证据—法规—责任—建议”对照表。
- [ ] 关键事实已排除合理怀疑；如仍有不确定性，已降级或删除。
- [ ] 重大金额及关键结论有两次独立复算记录。
- [ ] 可能移送事项的主客观要件、资金去向和责任主体证据充分。
- [ ] 处理处罚或整改建议有权限和法律依据，可执行、可验收。

## 3. 全链路一致性终检

- [ ] 委托书/通知书 → 实施方案 → 底稿 → 证据 → 报告 → 附表 → 建议全链条一致。
- [ ] 报告中的全部金额、日期、比例、人名、单位名完成机器检索和人工抽核。
- [ ] 取证单、底稿、报告三者的事实描述未发生实质漂移。
- [ ] 问题层级和篇幅与重要性匹配，重点突出而非问题堆砌。
- [ ] 建议从个案上升到机制时有充分共性证据，不作无依据泛化。
- [ ] 报告签发、盖章、附件、分送和保密等级符合程序。

## 4. 终审否决条件

满足任一条件，终审不得通过：

- 仍有未关闭P0；
- 重大结论无原始证据或无法复算；
- 关键证据违法取得、真实性不能确认；
- 重大矛盾未解释或合理怀疑未排除；
- 法规、责任主体、审计期间、金额存在实质错误；
- 报告与附表或征求意见处理结果存在重大冲突；
- 超越权限提出处理处罚，或存在重大政治政策风险；
- 前两级复核未实质执行、签字代签或整改无闭环。
