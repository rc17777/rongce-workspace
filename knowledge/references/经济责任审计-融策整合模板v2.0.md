### 评分标准详解

**A1 项目立项决策合规率（8分）**
- 满分8分：任期内所有工程项目均完成可研论证、集体决策、报批备案
- 扣分：每发现1项违规立项/未批先建/擅自变更建设规模 = 扣3分
- 红线：造成重大损失的，直接0分并触发一票否决

**A2 招投标管理合规率（8分）**
- 满分8分：无规避招标、虚假招标、围标串标、拆分项目
- 扣分：每发现1项违规 = 扣2分
- 红线：发现围标串标实质性证据 = 直接0分

**A3 重大工程变更决策规范率（8分）**
- 满分8分：超限额变更全部履行集体审批+造价复核
- 扣分：每发现1项擅自变更/无依据签证 = 扣2分

**A4 重大投资风险管控成效（6分）**
- 满分6分：无决策失误导致项目停滞/烂尾/投资闲置
- 扣分：每发现1个问题项目 = 扣2分

**B1 内控制度健全及执行率（7分）**
- 满分7分：工程管理/造价管控/合同管理/变更签证/竣工验收制度健全且落地
- 扣分：每缺1个领域制度或制度空转 = 扣1.5分

**B2 合同管理规范率（6分）**
- 满分6分：合同签订/备案/履约/变更/终止全流程合规
- 扣分：每发现1项无合同施工/合同漏洞/私自变更价款 = 扣1.5分

**B3 工程过程管控合格率（6分）**
- 满分6分：施工监管/隐蔽验收/进度管控到位
- 扣分：每发现1次监管缺位导致质量问题 = 扣2分

**B4 竣工验收及决算合规率（6分）**
- 满分6分：项目完工及时验收、按时办理决算
- 扣分：每发现1个项目长期不决算/拖延结算 = 扣2分

**C1 工程资金使用合规率（7分）**
- 满分7分：工程款支付/预付款/质保金全部合规
- 扣分：每发现1项超进度付款/挤占挪用 = 扣2分

**C2 造价管控成效（7分）**
- 满分7分：结算审减率控制在合理区间（≤5%）
- 扣分：发现虚高结算/重复计费 = 每项扣2分

**C3 资产交付及利用率（6分）**
- 满分6分：完工及时转固/资产入账，无闲置
- 扣分：每发现1项资产闲置/未入账 = 扣1.5分

**C4 项目绩效完成率（5分）**
- 满分5分：项目达标，实现既定使用效益
- 扣分：发现低效投资/无效工程 = 每项扣2分

**D1 财经法规执行合规度（5分）**
- 满分5分：无违规违纪行为
- 扣分：每发现1项违规 = 扣1分

**D2 审计问题整改闭环率（4分）**
- 满分4分：历次审计/巡查问题全部整改闭环
- 扣分：整改率每低10% = 扣1分

**D3 风险隐患排查处置率（3分）**
- 满分3分：主动排查并化解风险隐患
- 扣分：存在存量风险未处理 = 扣1分

**E1 个人廉洁从业情况（5分，一票否决）**
- 满分5分：无利用职权谋取私利、违规插手干预工程
- 红线：发现1次违规即0分，触发一票否决

**E2 一岗双责落实情况（3分）**
- 满分3分：分管领域无违纪违法问题
- 扣分：分管人员出现工程领域违纪 = 扣2分

# 统一评分规则

## 一、基准分 + 加减分机制

- 每个指标设基准分（即表中分值）
- 达到行业平均/制度要求 = 得满分
- 发现问题/未达标 = 按评分标准扣分
- 扣至0分为限（不产生负分）

## 二、一票否决情形

出现以下任一情形，综合评定直接降为「不合格」：

1. 发生重大国有资产流失事件
2. 发生重大安全生产责任事故（经责范围内）
3. 存在重大违法违纪问题（被纪检监察立案）
4. 审计发现重大财务造假
5. 个人廉洁违规（一票否决指标得0分）
6. 发现小金库/账外账

## 三、等级划分（统一）

| 综合得分 | 评价等级 | 对应表述 |
|:--------|:--------|:--------|
| 90～100分 | **优秀** | 全面履行经济责任，业绩突出，未发现重大问题 |
| 75～89分 | **良好** | 较好履行经济责任，个别问题需要关注 |
| 60～74分 | **合格** | 基本履行经济责任，存在一定问题需整改 |
| 60分以下 | **不合格** | 未能有效履行经济责任，存在严重问题 |

## 四、权重设置通用原则

1. **核心权重不得低于模板建议值的80%**（保证可比性）
2. **合规风险类指标任何类型不低于10%**（底线思维）
3. **单项指标调整幅度不超过±5%**（防人为操纵）
4. **定量指标权重不低于总分70%**（落实"定量为主"）
5. **定性评分需区分四类调整因素**：
   - 历史遗留因素
   - 不可抗力因素
   - 战略调整因素
   - 特殊使命因素

# 统一责任认定规则

## 三级责任体系

| 责任类型 | 定义 | 判定要点 | 证据标准 |
|:--------|:----|:--------|:--------|
| **直接责任** | 干部直接参与/授意/批准/操作，或未履行审批程序、擅自决策、违规干预，直接造成损失/违规 | 主观故意或明知违规仍为之 | 签字文件/会议记录/批示/证人证言 |
| **主管责任** | 虽非直接操作，但对分管领域未能有效监管、制度建设有缺陷、审批把关流于形式，导致普遍性问题 | 失察失管但非主观故意，属履职不力 | 制度缺失证据/审批流程漏洞/系统性统计数据 |
| **领导责任** | 作为单位主要负责人，对整体管理负总责，虽未直接干预、分管到位，但单位层面存在系统性风险/普遍性问题 | 宏观层面履职不到位 | 系统性数据分析/上级通报/巡视巡察报告 |

> **来源整合**：幸福的审计人5.18使用三级制（直接/主管/领导），芮听柠说使用三级制（直接/领导/免责），整合后采用三级制并增加免责情形作为判定排除条件。

### 免责排除条件

同时满足以下条件的，可排除责任：
1. 问题属于历史遗留（前任任职期间形成）
2. 本人已履行正常程序且留痕
3. 不存在失职渎职行为
4. 本人已积极采取措施推动解决

| 红线 | 违规范例 | 合规替换 | 检查方式 |
