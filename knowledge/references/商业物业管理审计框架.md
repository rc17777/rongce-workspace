## 三、各领域详细审计内容

### （一）商业/物业经营管理

**制度依据**：P1A《商业（非线网）业务经营管理制度》+ P1B《物业经营管理制度》+ P1G《经营管理制度总纲》
**行业对标**：深圳万象城2000+条SOP管理体系、上海恒隆广场"15分钟保洁巡查"标准

**审计检查要点：**

1. **经营台账完整性** 🔴
   - 是否建立商户经营台账（含商户名称、租赁位置、面积、租赁期限、租金标准、物业费标准）
   - 台账与财务收入系统数据是否一致
   - 行业对标：头部企业要求台账-财务-银行流水三向核对，差异率<1%

2. **商户入驻流程合规性** 🔴
   - 入驻审批是否经招租决策流程（参照P1D空间开发管理制度）
   - 商户资质审查是否到位
   - 行业警示：警惕"人情入驻"——上海恒隆采用"选租户非招租户"策略，深圳部分项目因此出过问题

3. **租金收缴对账** 🔴
   - 是否存在"应收未收"或"已收未入账"情况
   - 欠租催缴记录是否完整、是否按制度追索

4. **租金调整与优惠审批** 🟡
   - 租金标准调整有无审批依据
   - 关联商户是否存在异常优惠（低于正常标准30%以上需特别关注）
   - 制度要求：参照P1G总纲的定价决策流程

5. **商户装修管理** 🟡
   - 装修押金收退是否规范
   - 装修期间消防审核是否到位
   - 施工时间限制是否执行

6. **租户关系管理** 🟡
   - 定期满意度调查是否执行
   - 不满意项是否形成闭环整改记录
   - 行业对标：深圳万象城、北京国贸满意度常年>95%

7. **制度更新执行情况** 🟡
   - 制度文件多为2024-2025年更新，旧版是否已废止
   - 新制度有无书面传达记录

8. **自助设备管理**（参照P1F）
   - 自助设备租户是否有统一租户手册
   - 设备布局是否符合消防和安全要求
   - 收益是否全额入账

### （二）物业用房管理

**制度依据**：P1B《物业经营管理制度》+ P1D《空间开发业务管理制度》+ P2F《资产招商管理办法》
**行业对标**：北京占比，国贸83万㎡自管运营，物业用房全部登记入账

**审计检查要点：**

1. **物业用房底数台账** 🔴
   - 是否建立完整的物业用房台账（位置、面积、用途、使用部门、状态）
   - **审计方法**：必须现场核实台账与实物一致性，逐房走访、开门检查
   - 行业警示：多地审计发现"账外房"——有房无台账、有台账无房

2. **物业用房出租管理** 🔴
   - 已出租：有无书面依据？审批流程是否完整？（参照P2F招商管理办法）
   - 租金是否入账？与合同约定是否一致？
   - 行业警示：上海审计曾发现——物业用房租金直接归个人账号

3. **商家使用合规性** 🔴
   - 商户是否超合同约定范围占用物业用房
   - **重点检查**：消防通道是否被占用做仓库、杂物间

4. **"无台账"用房排查** 🔴
   - **审计方法**：对照建筑图纸+现场逐间核对，查找未登记用房
   - 重点区域：地下室、设备层夹层、屋顶搭建

5. **未出租用房的处置方案** 🟡
   - 闲置物业用房有无定期巡检记录
   - 有无计划纳入招租流程

### （三）设施设备管理

**制度依据**：P3A《设施设备管理办法》+ P3B《设施设备故障管理办法》+ P3C《设施设备检修计划管理办法》+ P3I《工程及设备设施维修项目验收管理细则》
**行业对标**：平安金融中心AI电梯调度（候梯时间28s）、深圳湾万象城数字孪生系统

**审计检查要点：**

1. **设施设备台账完整性** 🔴
   - 是否建立覆盖全部自管设施设备的台账（分类参照P3A第4条第1款：商业类/广告类/餐食类）
   - 核心设备清单：电扶梯、空调主机、消防系统、变配电系统、安防监控系统
   - 台账是否注明设备编号、位置、型号、投运日期、维保单位、最近检修日期

2. **维保制度执行** 🔴
   - 维保合同是否按时续签？维保记录是否完整？
   - **审计方法**：抽取3-5台核心设备，核对实际维保记录与合同约定频次是否一致
   - 行业对标：深圳万象城设备维保KPI体系执行到每个点位

3. **检修计划执行** 🔴
   - 是否按P3C制度制定了年度/月度检修计划
   - 实际执行与计划偏差是否在合理范围
   - 未按期执行的有无说明和补修记录

4. **故障报告处理** 🟡
   - 设施设备故障是否按P3B制度流程报告
   - 重大故障有无根因分析和预防措施

5. **维修项目验收** 🟡
   - 设备设施维修项目完工后是否按P3I验收细则执行
   - 验收资料是否完整归档（含施工过程资料、竣工图、验收单）

6. **设备更新改造资金** 🟡
   - 大修/更新资金是否有专项审批
   - 费用是否在预算内，超过预算的补充审批是否齐全

### （四）能耗管理

**制度依据**：制度体系中无专项能耗管理制度（信息待补充）
**行业对标**：北京国贸冰蓄冷技术+惩罚性电价、深圳万象城"酬金制+能耗对赌"机制

**审计检查要点：**

1. **水电气费用分担合规性** 🔴
   - 费用在不同业态间的分摊方式是否有合同依据
   - 行业对标：广州珠江新城推行"租金能耗一票制"简化操作，可参考
   - **审计方法**：选取3-5户商户，验算实际分摊金额与合同约定是否一致

2. **查表跟岗制度** 🔴
   - 是否建立定期查表制度
   - 关键控制点：数据采集是否由**双人操作并签字确认**
   - **审计方法**：**建议突击跟岗一次实际查表过程**，核对抄表记录与系统读数

3. **能耗费用差异分析** 🟡
   - 不同业态间计价标准差异是否合理
   - 有无制度依据支撑计价差异

4. **能耗异常监控** 🟡
   - 是否有同期能耗数据对比机制
   - 异常波动有无分析记录
   - 行业对标：北京要求公共建筑能耗限额管理，超限额惩罚电价

5. **商户能耗透明度** 🟡
   - 商户是否收到清晰的分摊明细单
   - 有无因分摊不清导致的纠纷记录

### （五）停车场管理

**制度依据**：制度体系中无专项停车场管理制度（信息待补充）
**行业对标**：深圳万象城2017年实现"无感停车"、平安金融中心AI电梯系统

**审计检查要点：**

1. **收费收入完整性** 🔴
   - 停车费收入台账与系统记录是否一致
   - **审计方法**：对比道闸系统抬杆记录与收费记录，识别异常放行事件
   - 行业警示：停车场是资金"跑冒滴漏"高风险领域

2. **私收费/私抬杆风险** 🔴
   - **审计方法**：现场突击检查现金收费岗位
   - 核对交接班记录、抽查监控录像
   - **重点时段**：夜班和节假日（管理薄弱时段）

3. **免费/优惠停车管理** 🟡
   - 免费停车权限审批是否有据可查
   - 行业警示：这部分"隐形损失"容易被忽视但累计金额可观

4. **收费标准执行** 🟡
   - 实际执行标准是否与物价部门/业主方备案标准一致
   - 有无系统跑冒滴漏导致收入流失

### （六）合同管理

**制度依据**：P2C《合同管理制度》
**行业对标**：华润万象生活统一合同范本、五大行标准化合同条款

**审计检查要点：**

1. **合同台账完整性** 🔴
   - 是否建立覆盖全部在管项目的合同台账
   - 有无"无合同管理"的高风险情况
   - 行业警示：北京国贸项目审计发现个别服务外包长达数月无书面合同

2. **合同范本与备案** 🟡
   - 是否使用统一范本
   - 关键条款（服务范围、收费标准、违约责任）是否明确

3. **续签/变更流程** 🟡
   - 续签和变更是否有完整审批链条
   - 是否存在"事实合同"状态（到期后继续服务但未续签）

4. **合同用印管理** 🟡
   - 合同用印是否经制度规定的审批流程
   - 有无预先盖章或未按流程用印的情况

5. **关联交易披露** 🟡
   - 供应商是否存在关联关系
   - 关联交易是否经过公平性评审
   - 定价是否偏离市场公允价格

6. **合同违约追责** 🟡
   - 是否建立了违约追究的记录
   - 追索过程是否有完整档案

### （七）资产/招租管理

**制度依据**：P2D《资产管理制度》+ P2E《资产评估管理办法》+ P2F《资产招商管理办法》+ P1D《空间开发业务管理制度》
**行业对标**：华润万象生活招商品牌组合管理、上海恒隆"选租户"策略

**审计检查要点：**

1. **资产底数台账** 🔴
   - 是否建立完整的经营性资产台账
   - 包含：场地位置、面积、用途、权属证明、出租状态、租金标准、租期
   - 行业对标：深圳物业协会要求资产台账纳入不动产登记信息

2. **出租审批合规性** 🔴
   - 招租过程是否按P2F招商管理办法执行
   - 新增出租是否有资产评估依据（参照P2E）
   - 定向出租（无公开招租）是否有充分理由和专项审批

3. **租金定价合理性** 🔴
   - 租金定价是否经过市场调研和评估
   - 关联方租金是否存在明显偏离市场价的异常优惠
   - 行业警示：国有资产流失风险评估——出租价格显著低于同区域同类物业市场价30%以上

4. **租赁专项管理**（参照P1D空间开发管理制度）🟡
   - 空间开发业务是否有专项作业流程
   - 租户入驻交接是否有完整记录

5. **资产处置合规性** 🟡
   - 资产处置是否按P2E办法执行
   - 评估-审批-交易-注销的闭环是否完整

6. **资产招商过程透明度** 🟡
   - 意向承租方的登记、评审、定标过程是否留痕
   - 有无"围标、串标"嫌疑

7. **公共收益管理** 🟡
   - 广告位出租（参照P1C广告经营管理办法）、场地临时租赁、通信基站、快递柜合作等公共收益是否全部入账
   - 收益分配方案是否明确

### （八）广告经营

**制度依据**：P1C《广告经营管理办法》
**行业对标**：北京国贸广告位系统化管理、深圳地铁商业广告运营模式

**审计检查要点：**

1. **广告位资源台账** 🟡
   - 所有广告位（平面/电子屏/灯箱等）是否登记在册
   - 广告位数量、位置、尺寸、使用状态是否完整

2. **广告位出租收入完整性** 🔴
   - 广告合同金额与收款记录是否一致
   - 有无"广告位免费赠送"的情况（如作为商户优惠条件未入账）

3. **广告内容合规管理** 🟡
   - 上刊广告有无内容审核记录
   - 公益广告占比是否满足P1C制度及相关法规要求

4. **到期广告位管理** 🟡
   - 到期是否及时清刊或续签
   - 空置期有无合理性说明

---

### （九）安全管理

**制度依据**：P3D《消防安全管理细则》+ P3E《安全管控制度》+ P3F《安全生产责任制》+ P3G《安全教育培训管理办法》+ P3H《突发事件综合应急预案》+ P3J《安全风险分级管控》+ P3K《安全监督检查及绩效考核细则》+ P3L《施工安全管理办法》
**行业对标**：北京甲级写字楼安全合规管理、上海恒隆15分钟保洁+安防巡查

**审计检查要点：**

1. **消防安全合规性** 🔴
   - 消防设施是否按规定年检
   - 疏散通道是否畅通、标识是否清晰
   - 商户装修期间消防审核是否到位
   - 制度依据：P3D消防安全管理细则（2025版，48页详细规定）

2. **安全管控制度执行** 🔴
   - P3E安全管控制度是否落实到日常运营各环节
   - 安全巡查记录是否完整
   - 隐患整改闭环情况

3. **应急预案演练** 🟡
   - P3H突发事件应急预案是否组织过演练
   - 演练记录和整改措施是否完整
   - 行业警示：某些项目应急预案停留在纸面，从未实际演练

4. **风险分级管控** 🟡
   - P3J安全风险分级管控是否覆盖全部经营场景
   - 高风险点位有无专项管控措施

5. **安全教育培训** 🟡
   - 员工安全培训是否按P3G办法执行
   - 新入职员工岗前安全培训是否到位

6. **施工安全管理** 🟡
   - 商户装修施工是否按P3L施工安全管理办法执行
   - 动火作业是否有审批和现场监护

### （十）新增审计建议

基于行业实践对比和制度覆盖缺口，建议增加以下审计范围：

1. **数字化系统审计** 🟡
   - 现有物业管理系统功能是否满足管理需求
   - 系统数据安全、备份和访问权限管理是否到位
   - 操作日志是否可追溯
   - 行业对标：万物云"灵石"AI平台、华润"智慧商管平台2.0"——线上数据与线下实物是否一致

2. **保险覆盖审计** 🟡
   - 是否购买足额公众责任险、财产一切险
   - 保险理赔流程是否清晰

3. **供应商及第三方管理审计** 🟡
   - 保洁、安保、维保等外包服务是否按合同执行
   - 服务质量和履约考核结果是否与费用挂钩

4. **公共收益完整性审计** 🔴
   - 广告位、场地临时租赁、通信基站、快递柜等收益是否全覆盖
   - 对比行业水平评估是否存在明显遗漏

5. **突发事件应急管理** 🟡
   - 火灾、停电、漏水、治安事件：应急预案是否覆盖
   - 是否按要求定期演练
   - **制度明确**：P3H已出台但内容仅2页，建议检查实际演练执行情况

## 四、审计方法建议

### 4.1 优先检查顺序（按风险等级）

**第一梯队（必须检查）：**
1. 物业用房底数核实 → 现场逐间核对图纸（涉及资产安全）🔴
2. 停车场收入完整性 → 突击检查现金岗（涉及资金安全）🔴
3. 设施设备台账+维保执行 → 抽取3-5台核心设备核验（涉及运营安全）🔴
4. 租金收缴三向对账 → 台账-财务-流水（涉及收入完整性）🔴
5. 能耗分摊查表跟岗 → 突击参与一次查表（涉及费用公平性）🔴

**第二梯队（建议检查）：**
6. 合同管理台账+续签合规
7. 资产出租审批合规
8. 消防安全执行
9. 广告/公共收益完整性
10. 安全管理体系执行
11. 采购和合同关联交易
