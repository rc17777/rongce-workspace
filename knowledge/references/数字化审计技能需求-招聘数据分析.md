## 核心发现

### 一、硬技能高频需求（数据分析工具）

| 技能 | 重要性 |
|:-----|:-----|
| SQL | 🔴 最基础 |
| Python | 🔴 最基础 |
| 数据分析 | 🔴 通用能力 |
| 审计模型搭建 | 🔴 把业务风险转化为模型规则 |
| IT审计/信息系统审计 | 🟡 系统层面 |
| Power BI / ACL / TeamMate | 🟡 可视化+审计工具 |
| 数据库 | 🟡 底层能力 |
| ETL / OCR | 🟢 数据采集 |

### 二、审计专业能力（底层基本功）

核心定位：**"用数据服务审计判断"** — 不是纯数据岗

- 内部审计、财务审计、内控、风险管理
- 合规、舞弊识别
- 审计方案设计、审计底稿、审计报告
- 整改跟踪、问题库管理

### 三、岗位核心要求

岗位不只是"会写代码"，更强调：
- 搭建审计模型 → 把业务风险转化为规则
- 建设数据资产 → 可持续的数据积累
- 非现场预警 → 主动发现而非被动审计
- 异常交易识别 → 反舞弊能力
- 形成审计线索 → 从数据到疑点
- 编制预警核查报告 → 可交付成果

### 四、证书

审计人逃不开的"考证"宿命（虽然实践中未必发挥）
