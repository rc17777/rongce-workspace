## 质量标准

- **完整性**：所有required字段非空，optional字段填充率≥80%
- **一致性**：关联ID双向可解析
- **准确性**：案例严重程度经2人交叉标注，Kappa≥0.75
- **时效性**：法规标注生效日期/修订日期/状态
- **唯一性**：同类型条目基于title+key_facts的simhash去重
