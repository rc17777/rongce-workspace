# 评标专家打分异常检测

## 方法描述
获取所有评委对所有投标人的逐项打分表。计算每个评委对每个投标人的Z-score（偏离该评委平均分的标准差数）。如果某评委对特定投标人的Z-score系统性偏高（≥2.0）或偏低，且其他评委评判正常→评标不公。组合检测：检查该评委与受益投标人是否存在利益关联。

## 检测逻辑
对每个评委j，计算其对投标人i的Z-score: z_ij = (score_ij - mean_j) / std_j。|z|≥2.0为异常。进一步检测该评委是否在多个评分项上对同一投标人持续偏高（≥3项）。

## 输入数据
- 必须：评委逐项打分表（评委×投标人×评分项）
- 可选：评委个人简历/工作单位, 评委与投标人关联关系

## 技术参数
```python
from scipy import stats
z = stats.zscore(scores, axis=1)
biased = np.abs(z) >= 2.0
```

## 误报风险
- 评分项主观性强（如技术方案创新性）→正常差异可能较大
- 评委专业背景差异→某些评委天然偏向某些技术路线

## 组合规则
- 与L8工商关联组合→评委与受益投标人有关联→利益输送铁证
