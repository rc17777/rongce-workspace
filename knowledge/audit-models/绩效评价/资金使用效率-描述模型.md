# 资金使用效率评价 — 描述模型

## 审计问题
财政资金是否及时到位、及时支出？是否存在大量资金沉淀、预算执行缓慢的问题？

## 核心逻辑
资金"到位率"和"支出率"是绩效评价的基础指标。资金到了花不掉、花不掉还不调整，就是典型的效率低下。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 项目名称 | 被评价项目 | 项目库 |
| 预算批复 | 年初预算批复金额 | 预算文件 |
| 资金到位 | 实际拨付到位金额 | 国库支付系统 |
| 累计支出 | 截至评价日累计支出 | 国库支付系统 |
| 评价时点 | 评价日期 | — |
| 项目周期 | 项目起止时间 | 立项文件 |

## 检测逻辑

```
Step 1: 计算 资金到位率 = 到位金额 / 预算批复 × 100%
       支出进度率 = 累计支出 / 到位金额 × 100%
Step 2: 分月/季统计支出进度曲线
Step 3: 标记问题：
  - 资金到位率 < 80% → 资金保障不足
  - 支出进度率 < 50%（已过半周期）→ 严重滞后
  - 支出进度率 < 30%（已过3/4周期）→ 几乎停滞
Step 4: 按项目类型分组统计，识别哪类项目效率最低
```

## 阈值/参数
- 资金到位率 < 80%：资金保障不足
- 时间过半支出 < 50%：进度滞后
- 时间过3/4支出 < 30%：严重停滞，建议收回资金

## 典型发现
- 某项目年初预算1000万，8月到位仅300万 → 资金到位率30%，项目实质停摆
- 5个项目资金到位率100%但支出率均 < 20% → 大量资金沉淀

## 局限性
- 支出率低未必是问题（如按进度付款的工程），需结合项目特点判断
- 需区分资金到位率和支出率低的原因：是上级未拨付还是本级不支出
