# 投入产出效率评价 — 对比模型

## 审计问题
财政资金投入是否产生了相应的产出？单位成本是否合理？有无低效投资？

## 核心逻辑
用"单位产出成本"作为核心效率指标，横向与同类项目对比、纵向与历史对比、对标行业标准，发现低效项目。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 项目名称 | 被评价项目 | 项目库 |
| 总投资 | 项目总投入 | 预算/决算 |
| 产出数量 | 可量化的产出（公里/平方米/人次等） | 验收报告 |
| 产出质量 | 合格率/优良率 | 验收报告 |
| 同类项目均值 | 同类项目单位成本 | 行业数据/历史数据 |
| 标杆值 | 行业最优水平 | 行业标准 |

## 检测逻辑

```
Step 1: 计算 单位产出成本 = 总投资 / 产出数量
Step 2: 横向对比：
  - vs 同类均值：偏离 > 30% → 异常
  - vs 标杆值：差距 > 50% → 严重低效
Step 3: 质量修正：质量不达标的项目，即使成本低也是低效
Step 4: 分层分析：按项目类型/地区/规模分层对比，避免大小项目混比
```

## 阈值/参数
- 横向偏离阈值：30%（超同类均值1.3倍）
- 标杆差距阈值：50%
- 质量门槛：合格率 < 90% 自动标记为问题项目

## 典型发现
- 某道路工程单位成本为同类项目均值的2.1倍 → 造价虚高或低效
- 某培训项目人均成本500元，同类仅150元 → 严重浪费

## 局限性
- 同类项目定义需谨慎，规模/地理/时间差异需控制
- 产出难以量化的项目（如政策研究）不适用
