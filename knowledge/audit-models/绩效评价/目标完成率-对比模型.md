# 绩效目标完成率评价 — 对比模型

## 审计问题
年初设定的绩效目标是否完成？未完成的原因是什么？目标设定本身是否合理？

## 核心逻辑
逐项对比"实际完成值"与"绩效目标值"，计算完成率。同时评估目标值本身是否合理（太容易完成=目标偏低，全部完不成=目标过高或执行严重偏差）。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 绩效指标 | 具体指标名称 | 绩效目标申报表 |
| 目标值 | 年初设定目标 | 绩效目标申报表 |
| 实际值 | 年度实际完成 | 自评报告/数据核实 |
| 指标类型 | 产出/效益/满意度 | 绩效目标申报表 |
| 偏差原因 | 未完成原因的说明 | 自评报告 |

## 检测逻辑

```
Step 1: 计算 完成率 = 实际值 / 目标值 × 100%
Step 2: 分级标记：
  - 完成率 ≥ 100% → 达标
  - 80% ≤ 完成率 < 100% → 基本达标
  - 完成率 < 80% → 未达标
Step 3: 目标合理性检验：
  - 全部指标完成率 > 120% → 目标设定偏低
  - 全部指标完成率 < 60% → 目标过高或执行严重问题
Step 4: 分类汇总：产出指标 vs 效益指标 vs 满意度指标分别汇总完成率
```

## 阈值/参数
- 未达标线：80%
- 目标偏低信号：全部 > 120%
- 需确认实际值数据来源是否可靠（不能只看自评）

## 典型发现
- 10个指标9个完成率150%+ → 目标形同虚设，绩效自评走过场
- 效益指标完成率30%，产出指标完成率100% → 东西做了但没效果

## 局限性
- 自评数据可能失真，需抽样核实
- 跨项目对比需同一指标口径
