# 资产质量变化检测 — 对比模型

## 审计问题
领导干部任期内，国有资产是否保值增值？是否存在资产流失、虚增资产的问题？

## 核心逻辑
比较任期初和任期末两个时点的资产质量，看"账面资产"是否变成"真实资产"。关键不是看资产总额增减，而是看不良资产占比变化。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 资产类别 | 固定资产/无形资产/在建工程/长期投资 | 资产负债表 |
| 账面原值 | 入账原值 | 资产台账 |
| 累计折旧/摊销 | 已计提 | 资产台账 |
| 净值 | 原值-折旧 | 资产台账 |
| 减值准备 | 已计提减值 | 资产台账 |
| 盘亏/待报废 | 实际已损失未核销 | 盘点记录 |
| 任初/任末时间 | 任期起止日期 | 任命文件 |

## 检测逻辑

```
Step 1: 计算 不良资产 = 减值准备 + 盘亏待报废 + 账龄>10年无使用记录资产
Step 2: 计算 不良资产率(任初) vs 不良资产率(任末)
       不良资产率 = 不良资产 / 资产总额 × 100%
Step 3: 对比变化：
  - 不良率上升 > 5个百分点 → 资产管理不善
  - 不良率下降但资产总额暴增 → 可能突击入账掩盖
Step 4: 分类别对比：关注在建工程长期挂账不转固
```

## 阈值/参数
- 不良率上升阈值：5个百分点
- 在建工程挂账 > 3年未转固 → 异常
- 减值准备充足率 < 50%（该提不提）

## 典型发现
- 任初不良率3%，任末12% → 任期内在建工程大量烂尾未处理
- 资产总额增长40%但主要为在建工程挂账 → 虚增资产

## 局限性
- 需完整的资产盘点数据，账实不符时需实物核查
- 无形资产评估主观性强
