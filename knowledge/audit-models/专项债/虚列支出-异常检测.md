# 虚列支出检测 — IQR异常检测

## 审计问题
是否存在通过虚增工程量、虚构合同套取专项债资金的行为？

## 核心逻辑
大额支付给关联方、金额接近整数的异常交易、付款节奏不合理（集中度异常）等，都是虚列支出的常见指纹。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 项目名称 | 债券项目 | 专账 |
| 收款方名称 | 收款单位 | 银行流水 |
| 支出金额 | 单笔金额 | 银行流水 |
| 支出日期 | 支出日期 | 银行流水 |
| 合同金额 | 对应合同总额 | 合同台账 |
| 合同内容 | 采购/施工内容 | 合同台账 |

## 检测逻辑

```
Step 1: IQR检测单笔大额异常：
  Q1、Q3、IQR → 上界 = Q3 + 1.5×IQR → 超出上界标记
Step 2: 金额特征检测：
  金额为整数（万/十万为单位）= 非真实工程结算
  付款进度 > 实际进度 + 20% = 提前套取
Step 3: 关联方检测：
  收款方名称包含"商贸""贸易""科技" 但 合同内容是工程 → 可疑
  收款方与项目单位法人/股东同名/关联 → 关联交易
Step 4: 付款节奏检测：
  同一收款方连续多笔等额付款 → 非正常工程付款节奏
```

## 阈值/参数
- IQR系数：1.5
- 整数金额阈值：以万元为单位（> 10万）
- 关联方关键词：商贸、贸易（工程类项目中）
- 付款-进度差 > 20%

## 典型发现
- 某工程项目的收款方为某"商贸公司"，累计付款800万 → 追查发现为空壳公司
- 连续12个月每月等额支付某施工方100万 → 工程款变为每月固定拨款

## 局限性
- 关联关系需工商数据验证（需L8级数据）
- 部分正常工程款确为整数（合同约定）
