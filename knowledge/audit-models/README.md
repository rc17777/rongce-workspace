## 方法选择速查

| 你想知道什么 | 用什么方法 | 哪些卡片用了 |
|:-----------|:----------|:-----------|
| 一件事是否合理（跟标准比） | 对比分析 | 三公经费、资产质量、目标完成率、投入产出、专项资金挪用、收益不达标、进度滞后 |
| 有什么趋势/规律 | 时间序列 | 跨年调节、负债增长、资金闲置、药品用量 |
| 哪些是异常值/异常个体 | 异常检测 | 支出集中度、分解住院、高频就医、虚列支出 |
| 哪些因素经常一起出现 | 关联规则 | 重大决策合规、重复报销、挪用风险 |
| 整体情况是什么样 | 描述统计 | 往来款挂账、资金使用效率、受益对象覆盖 |
| 什么因素驱动了结果 | 回归分析 | 收入完整性、费用增长 |
| 对象可以分几类 | 聚类分析 | 满意度异常、机构费用异常 |
