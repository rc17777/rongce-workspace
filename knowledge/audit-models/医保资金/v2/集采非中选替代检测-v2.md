# 集采非中选药品替代检测

## 政策背景
- 国办发〔2021〕2号要求所有公立医院优先使用集采中选药品，按采购合同完成约定量
- 将中选药品使用情况纳入公立医院绩效考核
- 集采中选药品价格（平均降幅53%）vs 非中选同通用名药品 → 价差可达数倍
- 医院/医生存在动力推非中选药品（药企回扣、品牌惯性等）

## 审计问题
医疗机构是否以非中选高价药品取代集采中选低价药品，侵蚀集采降费效果、额外消耗医保基金？

## 核心逻辑
集采"以量换价"的前提是医疗机构真正使用约定量的中选药品。如果表面签了采购协议，实际处方大量开非中选同通用名药品，集采降费就被架空。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 药品通用名 | 同通用名可比较 | 医保目录 |
| 集采中选标识 | 是否集采中选 | 集采目录 |
| 月度使用量 | 按数量/按金额 | 医保结算 |
| 处方医生 | 开方医生 | HIS |
| 约定采购量 | 集采合同约定的年度采购量 | 集采协议 |
| 中选价 | 集采中选价格 | 集采结果 |
| 非中选品牌价 | 同通用名非中选价格 | 采购平台 |

## 检测逻辑

### 子模型1：中选/非中选用量结构对比

```
Step 1: 按药品通用名+医院汇总：
  中选占比 = 中选药品使用量 / (中选+非中选)总使用量
  （可按盒数或金额分别算——按盒数看处方行为，按金额看基金消耗）

Step 2: 规则：
  规则1: 中选占比 < 70% → 未完成约定量、过度使用非中选
  规则2: 中选占比 < 50% → 严重的非中选替代
  规则3: 月度中选占比持续下降（连续3月↓超10个百分点）→ 趋势恶化
```

### 子模型2：约定采购量完成率

```
Step 1: 计算每个集采品种的完成率 = 累计使用量 / 约定采购量
Step 2: 规则：
  规则4: 完成率 < 约定进度（如半年<40%）→ 未按进度履约
  规则5: 完成率 < 50% 但同通用名非中选用量 > 中选用量 → 以非中选替代
```

### 子模型3：医生偏好检测

```
Step 1: 按医生+通用名统计中选/非中选处方占比
Step 2: 规则：
  规则6: 某医生非中选处方占比 > 80%（同级医生均值30%）→ 高度疑似有回扣
  规则7: 医生处方变化趋势：集采前主要开某品牌 → 集采后继续开该品牌(非中选) → 故意回避中选
```

### 子模型4：基金超额消耗计算

```
Step 1: 计算替代行为的基金损失
  超额消耗 = (非中选用量 × 非中选单价) - (如果这些量用中选药品的价格)
  
Step 2: 规则：
  规则8: 单院单品种超额消耗 > 10万/年 → P1
  规则9: 全区超额消耗汇总 → 评估集采效果被侵蚀的程度
```

## 阈值/参数
- 中选占比 < 70% → P2（关注）
- 中选占比 < 50% → P1（重点）
- 完成率 < 50% + 大量非中选 → P1
- 单医非中选 > 80%且远超同级 → P0（疑似回扣）
- 超额消耗 > 10万/品种/年 → P1

## 典型发现
- 某三甲医院某集采降压药约定量10万盒，全年仅采购了3.2万盒中选药品，却同时采购了7.8万盒同通用名非中选（单价3倍）→ 集采降费被完全架空
- 该院心内科某主任全年处方中，集采中选药使用量仅占12%，同一通用名非中选占88% → 高度疑似药企回扣驱动
- 全区各医院中选占比中位数72%，但3家医院低于35% → 重点延伸

## 局限性
- 非中选替代不同于串换——药品确实用了非中选品牌，只是违反了集采优先使用政策，不是骗保
- 部分非中选药品使用具有临床合理性（如患者过敏/不耐受中选品牌），需允许例外
- 医生偏好检测对非回扣动机（如用药习惯、学术观点）无法区分
- 约定采购量数据通常只能在集采执行层面获取，审计时可能不完整

## 与串换的区别
- 串换：报销A、实际用B（编码造假）
- 非中选替代：确实用了非中选药品，合法报销，但违反集采优先使用政策
