# 串换药品/耗材/诊疗项目检测

## 法规依据
- **735号令第15条**：不得"串换药品、医用耗材、诊疗项目和服务设施"
- **735号令第38条**：串换→退回+1-2倍罚款
- **法发〔2024〕6号第5条**：串换属于骗保，以诈骗罪定罪

## 审计问题
是否存在欺诈骗保中最常见的"串换"行为——报销的是A（高价、目录内），实际使用的是B（低价、目录外）？

## 核心逻辑
医保结算必须真实反映实际发生的医药服务。串换的三条路径：
1. **药品串换**：目录内高价药报账，实际发目录外低价药或非药品
2. **耗材串换**：进口高价耗材报账，实际用国产/无证耗材
3. **诊疗串换**：复杂诊疗项目报账，实际做简单项目

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 结算项目编码 | 医保结算的项目编码 | 医保结算 |
| 结算项目名称 | 医保目录名称 | 医保目录 |
| 结算数量 | 报销数量 | 结算数据 |
| 药品入库记录 | 医院药库入出库明细 | HIS药库 |
| 耗材入库记录 | 医院耗材入出库明细 | HIS耗材库 |
| 诊疗执行记录 | 实际执行的诊疗项目 | HIS/LIS/PACS |
| 药品/耗材库存 | 月末盘点库存 | 库存台账 |

## 检测逻辑

### 子模型1：药品串换（医保结算 vs 药库出入库）

```
Step 1: 按医院+药品编码+月份汇总：
  结算数量 = 医保系统该院该药当月报销总数量
  采购数量 = 药库系统该院该药当月入库总数量
  
Step 2: 计算 串换指数 = 结算数量 / (入库数量 + 期初库存 - 合理损耗)

Step 3: 标记规则：
  规则1: 串换指数 > 1.0 → 报了比实际进的多 → 数量异常
  规则2: 结算数量 > 0 AND 入库数量 = 0 AND 库存 = 0 → 报了没进过 → 高度疑似串换
  规则3: 同一时间段，高价药结算暴增 + 低价/目录外药入库暴增 → 交叉印证
```

### 子模型2：耗材串换（结算清单 vs 实际使用记录）

```
Step 1: 对比：
  医保结算耗材清单 vs 手术室/导管室实际领用记录
  高价进口耗材结算数量 vs 同规格国产耗材入库数量

Step 2: 标记规则：
  规则4: 结算某进口支架50个，但手术室同期只领用国产支架 → 串换
  规则5: 某耗材报销单价 > 该院同规格耗材平均采购价2倍 → 高价串换
  规则6: 耗材报销数量 > 领用数量×150% → 数量异常
```

### 子模型3：诊疗项目串换

```
Step 1: 对比：
  医保结算诊疗项目 vs LIS/PACS执行记录
  结算的"大项目" vs 对应的"小项目"实际执行

Step 2: 标记规则：
  规则7: 结算"CT增强扫描"但PACS无增强期影像 → 串换为平扫
  规则8: 结算"心脏彩超全套"但报告仅有单项 → 串换
  规则9: 高频结算某高价项目但设备检查日志无对应记录 → 虚构
```

## 阈值/参数
- 串换指数 > 1.0 → P1
- 结算>0且入库=0 → P0（直接确认）
- 耗材报销价 > 采购价2倍 → P1
- 诊疗结算 vs 设备日志不一致 → P0

## 典型发现
- 某民营医院全年报销"白蛋白"3200支，药库进货仅800支 → 差额2400支来源不明
- 某骨科结算进口关节假体，手术室实际全部领用国产 → 差价3倍
- 某医院CT增强扫描结算量=设备扫描总次数×1.5（增强不可能超过总扫描）→ 平扫冒充增强

## 局限性
- 需要药库/耗材库系统数据打通（HIS系统不完整的是最大盲区）
- 民营医院入库记录可能本身造假（双套账）
- 中药饮片/院内制剂无条码追踪，串换更难检测
