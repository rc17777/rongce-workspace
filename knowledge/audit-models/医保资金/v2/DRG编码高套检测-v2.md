# DRG编码高套检测 (Upcoding Detection)

## 法规与政策背景
- DRG/DIP改革后，医保不再按项目付费，而是**按病组打包付费**
- 同一病组内无论实际花费多少，医保支付固定金额
- 编码高套（upcoding）= 把轻病填成重病编码 → 骗取更高支付标准
- **医保发〔2021〕48号**要求2025年完成全覆盖 → 编码高套将成为审计核心风险

## 审计问题
医疗机构是否故意将患者诊断编码上调至高权重/高支付病组，以获取超额医保支付？

## 核心逻辑
DRG分组由主要诊断(MDC) + 手术操作 + 并发症(MCC/CC)决定。编码高套有3条路径：
1. **主诊断升级**：轻症诊断 → 重症诊断（肺炎→重症肺炎）
2. **虚增并发症**：无并发症 → 填一个有并发症（MCC编码）
3. **手术操作升级**：简单操作 → 复杂操作

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 病案号 | 住院病案唯一标识 | HIS病案 |
| 主要诊断编码 | ICD-10 | 病案首页 |
| 次要诊断编码 | 并发症/合并症 ICD-10 | 病案首页 |
| 手术操作编码 | ICD-9-CM-3 | 病案首页 |
| DRG分组结果 | 实际入组编码 | 医保结算 |
| DRG权重 | 该组RW值 | 医保DRG目录 |
| 主要诊断依据 | 检验/检查/病理报告 | HIS/LIS/PACS |
| 手术记录 | 手术记录单 | 病案 |
| 实际费用 | 住院总费用 | 结算 |
| DRG基准支付 | 该组标准支付额 | DRG费率表 |

## 检测逻辑

### 子模型1：主诊断编码高套

```
Step 1: 对每条住院记录，对比主诊断编码 vs 支撑证据
Step 2: 规则：
  规则1: 主诊断含"重症/重度/急性"但无ICU记录 → 诊断过高
  规则2: 主诊断=肺炎J18但化验无感染指标升高 → 实际为J06（上感）→ 编码高套
  规则3: 主诊断=心梗I21但心肌酶谱+心电图均正常 → 编码高套
  
Step 3: 看证据链是否完整——三条线交叉验证：
  临床路径线：医嘱→检查→用药→是否匹配诊断？
  检验线：关键化验指标是否支持诊断？
  影像线：关键影像报告是否支持诊断？
```

### 子模型2：虚增并发症(MCC/CC)

```
Step 1: 提取次要诊断中影响DRG分组的MCC/CC编码
Step 2: 规则：
  规则4: 次要诊断含严重并发症(MCC)但该并发症无任何治疗记录 → 虚增MCC
  规则5: 某医院MCC填报率 > 同级均值2倍 → 系统性问题
  规则6: 次要诊断含"高血压"但住院全程血压记录正常 → 虚构
  规则7: 次要诊断含"糖尿病"但住院期间未测血糖 → 虚构
```

### 子模型3：手术操作编码高套

```
Step 1: 对比手术操作编码 vs 手术记录
Step 2: 规则：
  规则8: 填写"腹腔镜胆囊切除术"但手术记录为"开腹" → 操作升级
  规则9: 填写复杂手术编码但手术时长 < 该手术常规时长50% → 疑似不实
  规则10: 填写"多部位手术"但手术记录仅涉及单一部位 → 编码高套
```

### 子模型4：费用-权重偏离检测

```
Step 1: 计算每条记录的 费用效率 = 实际费用 / DRG基准支付
Step 2: 规则：
  规则11: 费用效率 < 60% 且有MCC编码 → 高度疑似高套编码
          （病组支付标准1万，实际只花了5千，说明病情远没到报的那个编码）
  规则12: 某医院费用效率 < 70%的占比 > 同级均值2倍 → 系统性高套
```

## 阈值/参数
- 费用效率 < 60% + 有MCC → P1
- MCC填报率 > 同级2倍 → P1
- 主诊断与检验/影像冲突 → P0
- 手术编码与手术记录不符 → P0

## 典型发现
- 某三甲医院"重症肺炎"DRG占比是同级的3.2倍，但ICU使用率仅为同级0.3倍 → 系统性将普通肺炎编码为重症
- 某科100%病例填报"高血压"作为MCC（副诊断），但血压监测记录缺失率78% → 虚增并发症套取高权重组
- 某医院DRG平均权重1.8（同级1.1），但实际费用/支付标准比仅0.65 → 编码全面高套，多拿35%的支付

## 局限性
- 需要完整的检验/影像/手术记录数据，部分医院信息系统不完善
- 编码高套与编码差错（非故意）难以区分——需证明"故意"才能入刑
- DRG分组规则本身复杂，部分编码歧义（如"肺炎"vs"重症肺炎"的实验室指标边界模糊）
- 费用效率低也可能是合理情况（如临终关怀、短期住院死亡）

## DRG高套 vs 传统过度医疗区别
| | DRG编码高套 | 传统过度医疗 |
|:--|:--|:--|
| 获利方式 | 填大病编码拿固定高支付 | 多做项目逐项累加 |
| 检测方法 | 编码 vs 证据链 | 人均费用聚类 |
| 危害 | 系统性骗取DRG支付 | 单次服务过度 |
| 政策背景 | DRG改革后新风险 | 按项目付费时期旧风险 |
