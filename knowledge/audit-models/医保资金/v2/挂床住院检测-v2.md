# 挂床住院检测

## 法规依据
- **735号令第15条**：定点医药机构不得"挂床住院"
- **735号令第38条**：挂床住院造成基金损失的，退回+1-2倍罚款
- **法发〔2024〕6号第5条**：挂床住院属于骗保，以诈骗罪定罪

## 审计问题
是否存在"住院登记、人不在院"的假住院——患者办了住院手续但未实际接受住院治疗，套取医保基金？

## 核心逻辑
挂床住院的核心特征是：**有住院记录但无住院行为**。通过交叉比对住院登记、护理记录、检查检验记录、药品消耗等数据，发现"空床位"。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 身份证号 | 患者唯一标识 | 医保结算 |
| 住院号 | 住院流水号 | HIS/结算 |
| 入院日期 | 入院时间 | 结算 |
| 出院日期 | 出院时间 | 结算 |
| 住院天数 | 出院-入院 | 计算 |
| 护理记录条数 | 住院期间护理记录总数 | HIS护理模块 |
| 检查次数 | 住院期间检查检验次数 | HIS/LIS/PACS |
| 药品记录条数 | 住院期间用药记录 | HIS药房 |
| 日均费用 | 总费用/住院天数 | 计算 |

## 检测逻辑

```
Step 1: 基础筛选 — 挂床四大特征
  规则1: 住院天数 ≥ 3天 AND 护理记录条数 = 0 → 高度疑似（办了住院无护理）
  规则2: 住院天数 ≥ 3天 AND 日均费用 < 区域同级医院均值的30% → 疑似
  规则3: 住院天数 ≥ 7天 AND 检查次数 = 0 → 高度疑似（长住院零检查）
  规则4: 药品记录条数 = 0 AND 住院天数 ≥ 2天 → 疑似（住院不用药）

Step 2: 行为印证 — 夜间不在院
  规则5: 住院期间在院外有门诊/购药/其他医院记录 → 确认挂床
  规则6: 住院期间在其他医疗机构有就诊记录 → 双挂床

Step 3: 金额追踪
  规则7: 总费用集中在"床位费+护理费"，治疗/检查/药品费占比<10% → 空挂收费
```

## 阈值/参数
- 护理记录=0 + 住院≥3天 → P1（高可疑）
- 日均费用 < 同级30% + 检查=0 → P2
- 需排除：日间手术（住院≤24h）、临终关怀（护理记录少但合理）

## 典型发现
- 某医院内三科47人"住院"，仅8人有护理记录 → 39人挂床
- 某患者"住院15天"，同期在隔壁药店刷卡购药6次 → 确认挂床
- 某乡镇卫生院日均费用26元（同级均值218元），床位全部"满员" → 群体性挂床

## 局限性
- 护理记录缺失也可能是HIS系统记录不完整或手工补录延迟，需排除技术原因
- 部分基层医院护理记录本身不规范（手工记录未录入系统），不能简单等同于挂床
- 日均费用极低也可能是基层医院正常收费水平（如乡镇卫生院常规住院）
- 日间病房/日间手术等新型住院模式介于住院和门诊之间，需单独设定判断标准

## 与分解住院的区别
| | 挂床住院 | 分解住院 |
|:--|:--|:--|
| 本质 | 住院是假的，人不在 | 住院是真的，但拆成多次 |
| 关键指标 | 无护理/无检查/极低日均费 | 短间隔重复入院 |
| 法规条款 | 第15条+第38条第1款 | 第15条+第38条第1款 |
