# 医保目录外费用纳入结算检测

## 法规依据
- **社会保险法第28条**：医保基金支付范围限于药品目录、诊疗项目、医疗服务设施标准
- **735号令第38条第6款**：将不属于医保支付范围的费用纳入结算 → 退回+1-2倍罚款
- **法发〔2024〕6号第5条第7款**：目录外纳入结算 → 以诈骗罪定罪

## 审计问题
是否存在将医保不予支付的药品/诊疗/耗材/服务，通过篡改编码或信息的方式纳入医保结算？

## 核心逻辑
目录外纳入结算的核心手法是**编码伪装**——给目录外的项目编一个目录内的编码，或者将一个合法的目录内编码拆分出多个项目来套取。

三条路径：
1. **目录外药品伪装报销**：将营养品/保健品/目录外药品套用目录内编码报销
2. **非医疗项目打包报销**：体检/美容/生活用品冒充医疗项目
3. **公共卫生/工伤/第三方费用转嫁医保**：社会保险法第30条明确不支付的四类

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 结算项目编码 | 医保结算项目编码 | 医保结算 |
| 结算项目名称 | 对应名称 | 结算/目录 |
| 医保目录 | 完整三大目录（药品/诊疗/设施） | 医保局 |
| 目录限定支付范围 | 每个项目的限定条件 | 医保目录 |
| 入院诊断 | 入院诊断ICD | 病案首页 |
| 费用类别 | 工伤/第三方/自费等标记 | HIS收费 |
| 实际使用记录 | 护理/检查/治疗执行记录 | HIS |

## 检测逻辑

### 子模型1：目录外项目直接纳入

```
Step 1: 将结算数据中的项目编码与医保三大目录比对
Step 2: 规则：
  规则1: 结算项目编码不在医保三大目录中 → 目录外 → 直接确认
  规则2: 结算项目名称含"美容""保健""营养""生活用品"等关键词 → 目录外
  规则3: 结算药品为"国药准B"（保健品批号）→ 目录外 → 不应报销
```

### 子模型2：限定支付范围超范围报销

```
Step 1: 对照医保目录的"限定支付范围"字段
Step 2: 规则：
  规则4: 某药品限定"限二级以上医院"但一级医院报销 → 超限定范围
  规则5: 某检查限定"限恶性肿瘤"但诊断非肿瘤 → 超适应症报销
  规则6: 某药品限定"限工伤保险"但在医保中报销 → 渠道错配
  规则7: 某药品限定"限急救/抢救"但门诊慢病使用 → 超限定场景
```

### 子模型3：不应由医保支付的费用

```
Step 1: 根据社会保险法第30条排查四类
Step 2: 规则：
  规则8: 诊断含工伤ICD(V01-Y98)但由医保支付 → 应由工伤保险支付
  规则9: 诊断明确为第三方责任(交通事故等)但医保支付 → 应由第三人负担
  规则10: 预防接种/健康体检费纳入医保报销 → 应由公共卫生负担
```

### 子模型4：非医疗项目伪装报销

```
Step 1: 检查高频结算项目的实际执行记录
Step 2: 规则：
  规则11: 结算"理疗""康复"项目但无对应执行记录 → 虚假项目
  规则12: 药店医保刷卡购买"日用品""保健品"（通过销售小票比对）→ 目录外串换
```

## 阈值/参数
- 编码不在目录中 → P0（直接确认违规）
- 编码不在目录中 + 金额 > 5万 → 触发法发6号移送标准
- 超限定范围使用（规则4-7）：单笔退回差额 → P1；同机构超限占比 > 20% → P1（系统性违规）
- 工伤费用转嫁医保 → P0（直接确认+移交）
- 非医疗项目报销 → P0（直接确认）
- 三级医院超限定范围率 > 10% → P1（需系统性整改）
- 目录外编码检出率 > 5% → P1（该机构目录管理严重缺陷）

## 典型发现
- 某医院全年报销"白蛋白"(人血白蛋白)超过该院ICU+急诊+手术用量3倍 → 大量用于营养补充（目录限定支付范围：限抢救/重症）
- 某药店医保刷卡记录中"某保健品"以"某中成药"编码报销 → 目录外伪装
- 某医院将健康体检套餐（合计180万）以"诊疗费"编码纳入医保结算 → 公共卫生费用转嫁
- 某县医院工伤患者103例全由医保支付（应由工伤保险）→ 合计多报280万

## 局限性
- 医保三大目录编码频繁更新（国家医保局年度调整），需保持目录版本与结算数据时间段一致
- 部分医院HIS编码与医保编码映射不准确，可能导致误报（技术性编码错误≠骗保）
- 限定支付范围的判断需要临床专业知识（如"限抢救/重症"的界定标准）
- 药店串换保健品/日用品取证难度极高——需实地暗访或调取销售小票
- 工伤/第三方费用转嫁需跨部门数据比对（人社/公安），数据壁垒是主要障碍

## 与其他模型的关系
- 与**串换检测**：目录外→目录内用假编码，本质也是串换的一种
  - 区别：串换侧重药品/耗材A换B，目录外纳入侧重"根本不该报的报了"
- 与**重复报销**：目录外纳入是单渠道超范围；重复报销是多渠道重复
