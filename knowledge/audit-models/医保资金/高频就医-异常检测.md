# 高频就医检测 — Z-Score异常检测

## 审计问题
是否存在个人异常高频就医，涉嫌套取医保基金或倒卖药品？

## 核心逻辑
统计每个参保人的年度就诊次数，用Z分法找出远高于正常人群的极端值。高频就医可能是真实的重病患者，也可能是套保的"药贩子"。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 身份证号 | 患者唯一标识 | 医保结算 |
| 年度 | 结算年度 | 医保结算 |
| 就诊次数 | 门诊+住院总次数 | 汇总计算 |
| 总费用 | 年度医保报销总额 | 汇总计算 |
| 就诊机构 | 涉及的就医机构列表 | 结算数据 |
| 疾病诊断 | 诊断列表 | 结算数据 |

## 检测逻辑

```
Step 1: 计算全人群 年均就诊次数、标准差
Step 2: Z-Score = (个人次数 - 均值) / 标准差
Step 3: Z ≥ 3 → 异常高频（统计上概率<0.3%）
Step 4: 进一步分层分析异常人群：
  - 诊断集中（单一病种）→ 可能是真重病，需排除
  - 诊断分散 + 多医院 + 药品多 → 药贩子嫌疑
  - 费用与次数不成比例（次数多但费用低）→ 套保嫌疑
Step 5: 按年龄/性别分层重算Z值，排除老龄高就医合理情况
```

## 阈值/参数
- Z-Score ≥ 3：异常高频（99.7%置信）
- Z-Score ≥ 4：极端异常
- 费用/次数比 < 均值的30%：低成本高频 → 套保嫌疑

## 典型发现
- 某人年就医287次，Z=8.2 → 几乎每天看病，药贩子
- 分层后发现60岁以上人群Z正常，30-50岁有异常尖峰 → 青壮年套保群体

## 局限性
- 需按年龄分层，老年人正常就医次数也高
- 异地就医数据可能不完整
