# 药品用量异常检测 — 时间序列

## 法规依据
- **735号令第15条**：不得"超量开药、重复开药"
- **735号令第38条第2款**：超量开药/重复开药/提供不必要医药服务 → 退回+1-2倍罚款
- **735号令第40条**：虚构医药服务项目 → 退回+2-5倍罚款+暂停6-12月+吊销执业（以骗保论处）
- **社会保险法第87条**：机构骗保 → 退回+2-5倍罚款+吊销执业资格

## 审计问题
是否存在某些药品用量异常飙升，暗示带金销售、不合理用药或套取？

## 核心逻辑
正常药品用量应有平稳的季节波动和年度增长。某药品用量短期暴涨（超过季节波动范围），需要追查原因。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 药品编码 | 药品唯一编码 | 医保结算 |
| 药品名称 | 通用名 | 医保目录 |
| 月度用量 | 每月消耗量（数量或金额） | 汇总统计 |
| 医疗机构 | 使用该药的机构 | 结算数据 |
| 年度 | 至少2年数据 | — |

## 检测逻辑

```
Step 1: 建立季节基准
  规则1: 季节基准 = (去年同期用量 + 前3月均值) / 2

Step 2: 计算偏离度
  规则2: 偏离度 = (当月用量 - 季节基准) / 季节基准 × 100%

Step 3: 单月异常检测
  规则3: 偏离度 > 50% → 异常增长 → P1
  规则4: 偏离度 > 100% → 极端异常 → P0

Step 4: 持续性异常检测
  规则5: 连续3个月偏离度 > 30% → 持续性异常（非偶发波动）→ P1

Step 5: 交叉分析 — 异常药品 × 异常机构
  规则6: 某药在某个医院用量暴增，其他医院用量正常 → 该医院问题（带金销售/不合理用药）
  规则7: 某药在所有医院同时暴增 → 可能是政策变化（新纳入医保目录）或流行病 → 需排除

Step 6: 关联用药分析
  规则8: 某药用量暴增 + 关联检查/检验项目未同步增长 → 药量异常但无病情支持 → 疑似虚假处方
```

## 阈值/参数
- 单月偏离 > 50%：P1（异常增长）
- 单月偏离 > 100%：P0（极端异常）
- 连续3月偏离 > 30%：P1（持续性异常）
- 需至少24个月数据（太少无法建立可靠基准）
- 新纳入医保目录的药品需单独标记（排除政策驱动的正常增长）

## 典型发现
- 某抗生素在某医院月用量从100盒暴增至800盒 → 追查发现带金销售
- 某中成药在全区域同步暴增300% → 查政策发现新纳入医保目录（排除异常）
- 某辅助用药连续6个月偏离度60-120%但对应科室就诊人次无增长 → 虚假处方套取

## 局限性
- 需排除政策变化（目录调整）、季节流行病等合理因素
- 新上市药品无历史基准，需累积6个月以上数据后才能纳入检测
- 基层医疗机构用量基数小，轻微波动即可能导致高偏离度（假阳性）
- 带金销售取证需外部线索（医药代表账本、银行转账记录等）
