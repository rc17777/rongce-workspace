# 分解住院检测 — 异常检测

## 审计问题
医疗机构是否将一次完整的住院拆分为多次，以规避单次费用上限或套取更多医保支付？

## 核心逻辑
同一患者在极短间隔内（通常<24小时）在同一医院或不同医院再次入院，且两次住院的疾病相关，高度疑似将一次住院拆分为多次。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 身份证号 | 患者唯一标识 | 医保结算系统 |
| 住院号 | 住院流水号 | HIS系统/结算数据 |
| 入院日期 | 入院时间 | 结算数据 |
| 出院日期 | 出院时间 | 结算数据 |
| 主要诊断 | ICD编码 | 结算数据 |
| 医院编码 | 就诊医院 | 结算数据 |
| 总费用 | 住院总费用 | 结算数据 |

## 检测逻辑

```
Step 1: 按身份证号排序，找出相邻两次住院记录
Step 2: 计算 间隔天数 = 后次入院日 - 前次出院日
Step 3: 标记规则：
  规则1: 间隔天数 ≤ 1天（24h内） → 疑似分解住院
  规则2: 间隔 ≤ 3天 AND 主要诊断前3位ICD相同 → 高度疑似
  规则3: 间隔 ≤ 7天 AND 同一医院 AND 诊断相关 → 中度疑似
Step 4: 排除合理情况：化疗/透析等计划内重复入院（需白名单病种）
```

## 阈值/参数
- 核心间隔：24小时
- 扩展间隔：3天（同期诊断相关）
- 需排除的病种：恶性肿瘤化疗、尿毒症透析（计划内重复入院）

## 典型发现
- 某患者一周内同一医院住院3次，诊断均为J18（肺炎）→ 分解住院
- 某医院分解住院率8.2%，远超同级医院1.5% → 系统性违规

## 局限性
- 需准确的入院/出院日期，手工录入可能有天级误差
- 慢性病急性发作的合理短期再入院需区分
