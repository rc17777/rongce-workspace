# 三公经费异常检测 — 对比模型

## 审计问题
三公经费（因公出国、公务用车、公务接待）是否存在超标、超预算、异常增长？

## 核心逻辑
三公经费有明确的人/车/次配比标准，同类同级单位应有相似的支出水平。横向对比找异常，纵向对比看趋势。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 单位名称 | 被审计单位 | 决算报表 |
| 科目 | 因公出国/公务用车/公务接待 | 明细账 |
| 年度金额 | 全年支出 | 决算 |
| 在编人数 | 编制内人员数 | 编办核定 |
| 公务车数量 | 保有车辆数 | 资产管理 |
| 同级同类均值 | 同级别单位该项平均值 | 财政汇总数据 |

## 检测逻辑

```
Step 1: 计算 人均支出 = 科目金额 / 在编人数
       计算 车均支出 = 公车费用 / 车数
Step 2: 横向对比：人均/车均 vs 同级同类均值，偏差 > 50% 为异常
Step 3: 纵向对比：本年 vs 上年，增长率 > 10%（非特殊情况）为异常
Step 4: 预算对比：实际支出 vs 预算批复，超支标记
```

## 阈值/参数
- 横向偏差阈值：50%（超同级均值1.5倍）
- 纵向增长阈值：10%（无特殊事由）
- 预算执行率超100%自动标记

## 典型发现
- 某局公务接待费人均为同级的3倍 → 存在超标准接待嫌疑
- 公车运行费同比下降但维修费飙升 → 可能将运行费转入维修科目规避

## 局限性
- 需有同级同类单位数据对比，小单位无对照组时参考意义下降
- 合并报表口径不一可能导致偏差
