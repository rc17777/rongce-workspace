## 一、核心主线：智能化穿透式监管重构内控体系

### 1. 党委（党组）全面领导

- 企业党委（党组）对内控工作负总责
- 智能化穿透式监管 = 衡量内控体系有效性的核心依据
- 四大方面全面落实：体制机制、监管系统、监督追责、制度体系

### 2. 内控部门数智化转型路径

```
技术赋能 → 闭环管理 → 价值升级
   │            │           │
   ▼            ▼           ▼
AI+大数据    自动采集→    被动合规→
重构控制    分析→预警    主动防控、
流程         →派单→      赋能经营
            跟踪闭环
```

**五步闭环**：
```
数据自动采集 → 模型自动分析 → 风险自动预警 → 核查自动派单 → 整改自动跟踪
```

## 二、关键任务：2年攻坚穿透监管测试

| 要素 | 内容 |
|:-----|:-----|
| **时间窗口** | 2年左右，完成全级次穿透测试 |
| **核心目标** | 全级次覆盖 + 全业务在线 + 全系统联通 + 全要素监管（"四全"） |
| **测试重点①** | 信息系统穿透性：数据是否实时采集、横向关联、纵向贯通 |
| **测试重点②** | 10+核心领域穿透缺陷：产权、投资、财务、资金、薪酬、金融、采购供应链、军品、合同、境外 |

### 制度刚性嵌入

穿透式监管要求写入：公司章程、投资协议、业务合同，从源头保障监管效力，避免"上热中温下冷"。

## 三、重点突破：风控规则模型

### 聚焦11个突出问题

系统开展内控监管规则模型研究与开发，聚焦巡视和审计关注重点。

### 三大转变

| 从 | 到 | 手段 |
|:---|:---|:-----|
| 人防 | 技防 | 技术替代人工排查 |
| 模糊 | 精准 | 数据画像定位风险点 |
| 抽样 | 全量 | 全业务、全流程、全数据覆盖 |

### 风险"全息画像"

- 常态化筛查 → 问题台账 + 风险全息画像
- 自动化分级派单督办机制（标准化、可追溯）

## 五、监督评价：三年全覆盖

### 2026-2028 三年规划

系统谋划集团监督评价三年全覆盖。

### 四级评价等级

| 等级 | 结果应用 |
|:-----|:---------|
| 控制有效 | 正常 |
| 控制较好 | 优化提升 |
| 控制较弱 | 限制经营授权 |
| 控制失效 | 🔴 直接影响：资源配置、经营授权、业绩考核、干部任免、奖惩考核 |

**评价结果直接作为五大决策依据**，实现"以评促建、以评促治"。

## 六、对国企内审/审计机构的启示

### 企业层面

1. **数智化是必答题**：内控智能化必须纳入数字化转型整体规划，打破数据烟囱，建设 AI 驱动的风控中枢
2. **穿透是核心能力**：从集团到基层末梢，实现业务、数据、责任全链条穿透
3. **制度是保障**：穿透要求固化到公司章程、合同等核心文件

### 审计从业者层面

- 需快速掌握：大数据风控、AI 预警模型、自动化流程
- 转型方向：从"合规检查者"→"风险洞察者、经营赋能者"
- 用数据说话，为业务创造价值
