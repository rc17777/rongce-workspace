# 看图反推 Prompt：把图片发给 AI 就够了

> 来源：微信公众号「居咪」| 抓取日期：2026-07-06
> 原文链接：https://mp.weixin.qq.com/s/MxaBUMKjSO87PaBE8iPpBA
> 核心：一套完整的图片→Prompt 反推指令，上传参考图 + 粘贴指令 = 得到可直接复制的正反向 Prompt

---

## 一句话用法

上传参考图 + 粘贴下方完整指令给 GPT Image2/ChatGPT → AI 内部分析 → 只输出**正向 Prompt（450-700字中文）** + **Negative Prompt（12-20条英文）**

---

## 十步内部分析框架

| 步骤 | 分析维度 | 关键方法 |
|:--:|------|------|
| 1 | 判断用途类型 | 广告/游戏美宣/社媒/商拍/人像/剧照/插画/3D角色/电商/建筑室内/食物/动物/风景城市/海报/抽象 等 16 类 |
| 2 | 判断媒介类型 | 摄影/写实3D/半写实3D/二次元/厚涂/扁平矢量/产品渲染/UI平面/混合媒介 → 明确边界，排除易混淆媒介 |
| 3 | 判断主体类型 | 人物/产品/动物/食物/建筑/风景/城市/交通工具/植物/海报/抽象/多主体 |
| 4 | 分析技法层 | 构图+镜头视角+光线+色调+材质+景深背景+后期画质 |
| 5 | 分析内容层 | 主体外观/辅助元素/场景地点/时间感/情绪及其视觉来源 |
| 6 | 主体专项分析 | 按步骤3的类型，进行专项深度分析（如人物：年龄/发型/表情/视线/姿态/重心/服装） |
| 7 | IP/Logo/文字处理 | 不依赖具体IP名/品牌名，转写为外观特征，不要求生成可读文字 |
| 8 | 提炼复现关键要素 | 提取最不能丢的 3-5 个视觉锚点，放入 Prompt 前1/3位置 |
| 9 | 生成 Negative Prompt | 按媒介/风格/主体类型生成英文排除词 12-20 条 |
| 10 | 最终自检 | 检查正向 Prompt 是否包含 15 项核心要素 |

### 观察纪律

- 能直接看到的→描述视觉结果
- 只能推断的→描述视觉效果而非断言真实参数
- 例：写"柔和圆形光斑"而非"f/1.8"；写"中长焦压缩感"而非"85mm"

### 最终输出格式

```
正向 Prompt：[450-700字连续自然语言中文，不得写成关键词列表]
Negative Prompt：[12-20条英文负面词，逗号分隔]
```

---

## 两个使用建议

1. **做成 Skill**：将指令复制给 AI，让其改写为可调用的 Skill，后续一键调用
2. **做成人设**：将指令改写为"Prompt 反推专家"人设，与该人设对话即可
