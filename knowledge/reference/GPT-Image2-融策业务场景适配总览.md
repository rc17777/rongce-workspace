### ✅ 适配场景 2：Logo 与品牌视觉全案 → 企业品牌提案板

**融策玩法**：用于制作公司简介画册、企业宣传册、投标文件中"公司概况"章节的品牌视觉页。

**提示词框架**：
```
你是一位「B2B专业服务品牌设计总监」与「政府机构宣传册设计师」。

生成一张四川融策会计师事务所/工程咨询公司的品牌视觉系统展示图。
左侧纵向排列：公司Logo + 标准色色卡（深蓝/青绿/铜金/暖灰）+
标准字规范（中文宋体/微软雅黑 + 英文Serif）。
右侧展示品牌应用触点：报告封面、标书封面、名片、PPT模板首页、公司官网首页缩略图。
整体风格：专业、权威、品质感，类似四大会计师事务所的品牌规范手册内页。

16:9 横版，4K。
```

### ✅ 适配场景 5：文创周边 → 公司物料/会议物料

**融策玩法**：审计进点会会议手册封面、培训证书、宣传折页、公司礼品袋/笔记本设计。

**提示词框架**：
```
制作一套政府审计项目进点会的会议物料设计展示图。
包含：会议手册封面（A4 深蓝底铜金文字）、桌牌（暖灰底深蓝字）、
资料袋封面（青绿条带+白底）、培训证书（铜金边框深蓝印章）。
整体统一视觉，政府会议端庄风格。
16:9 横版展示所有物料排列，4K。
```

## 三、内容创作 → 融策审计传播/政策图解

### ✅ 适配场景 14：公众号封面图 → 审计政策解读头图

**融策玩法**：四川融策公众号/企业微信推送的政策解读文章封面。

**提示词框架**：
```
请生成一张公众号封面图，比例 2.35:1。
主题：「[政策名称] 核心要点解读」。
画面主体为大号政策关键词字体设计，背景为深蓝渐变叠加
政府公文纸纹理，右侧放置抽象化的政策条文卡片（半透明层叠效果），
铜金色高亮标注关键数字或日期。
轻科技+政务感，适合专业机构公众号传播。
```

### ✅ 适配场景 17：文章配图 → 审计报告摘要配图

**融策玩法**：把审计报告的核心发现转化成一张视觉摘要图。

**提示词框架**：
```
生成一张审计发现问题摘要配图，用于报告正文前页或汇报PPT。
画面以深蓝色圆环图为核心，将[发现大类数量]类问题按比例排布，
每类问题用不同铜金/青绿色块标注。环形中心放置"本次审计发现问题X类共Y项"。
下方横向排列三个关键数据卡片：涉及金额、整改率、制度建议数。
风格：政务审计报告配图，简洁权威，16:9 横版。
```

### ✅ 适配场景 18：条漫与长图 → 审计流程长图/政策解读长图

**融策玩法**：把"预算绩效管理全流程""政府审计程序"做成向下滑动的科普长图。

**提示词框架**：
```
生成一张纵向信息长图，主题为「政府审计全流程」，比例 9:16 适合手机滑动阅读。
从上到下分为 6 个段落：审计计划→审前调查→现场审计→取证核验→报告撰写→整改跟踪。
每段左侧放置阶段编号圆形图标（深蓝底铜金数字），右侧为3-4行要点文字说明。
段与段之间用深蓝到铜金的渐变分隔线区分。
顶部大标题"[XX]审计流程全景图"，底部注脚"四川融策会计师事务所出品"。
整体风格像政府部门的政务信息公开长图，清爽、专业、易读。
```

### ✅ 适配场景 19：社媒模板与栏目视觉系统 → 审计知识栏目模板

**融策玩法**：做一套可复用的审计知识分享栏目视觉模板。

**提示词框架**：
```
生成一套审计知识分享栏目的视觉模板系统，包含4张卡片布局图：
1.「每日一题」——知识问答卡片（问题+四个选项+答案折叠区）
2.「案例解析」——审计案例剖析卡片（背景+发现+定性+启示）
3.「政策速递」——新规解读卡片（发布日期+核心条款+影响分析）
4.「数据说话」——数据可视化卡片（一个核心数字+简短注释）
四张卡片排列在同一画面上，展示统一的深蓝底+铜金点缀的栏目视觉识别。
16:9 横版，4K。
```

## 六、教育与科研 → 融策审计培训/知识管理

### ✅ 适配场景 33：教学信息图 → 审计知识信息图

**融策玩法**：把"经济责任审计评价体系""政府采购六种方式""专项债申报流程"变成课堂培训信息图。

**提示词框架**：
```
生成一张关于「[审计知识点]」的中文教学信息图。
画面中央为主体概念的结构化图解（如金字塔/闭环/漏斗/矩阵），
四周围绕关键要点卡片、典型案例缩略、法规依据编号。
风格参考注册会计师考试培训教材的信息图，专业、清晰、便于打印。
深蓝+青绿+铜金配色，16:9 横版。
```

### ✅ 适配场景 34：知识卡片 → 审计要点速查卡

**融策玩法**：一张卡片=一个审计要点，可收藏转发，适合内部培训和新员工带教。

**提示词框架**：
```
生成一张审计知识卡片，主题为「[知识点，如：经济责任审计四道关]」。
卡片为 A4 横版三分之二大小，深蓝色渐变底，铜金色边框。
顶部：知识点标题（微软雅黑 Bold）
中部：3-5 个要点条列，每点配一个微型图标
底部：法规依据标注行 + "融策审计知识库"标识
整体像高端财经培训机构的知识卡片，适合收藏和打印。
```

### ✅ 适配场景 35：流程图与框架图 → 审计工作流程图

**融策玩法**：审计方法论的所有流程都适合。

已部分覆盖于 `GPT-Image2-融策叙事型配图框架.md`（场景七-十二）。

**补充提示词框架（采购审计流程）**：
```
生成一张横版 16:9 的「政府采购六种方式选择决策流程」专业信息图。

中心为决策树：从"采购预算金额"开始，依次分叉为——
公开招标（>400万工程/>200万货物服务）→
邀请招标（特殊/少量供应商）→

竞争性磋商（服务类/需要协商方案）→
询价（标准化货物/价格为主）→

每种方式旁标注适用条件、时限要求和常见违规点（红色小标签）。
深蓝+青绿+铜金+暖灰配色，中文为主。
```

### ✅ 适配场景 36：论文配图 → 审计方法论机制图

**融策玩法**：审计理论文章、课题研究报告的配图，接近学术论文级别。

**提示词框架**：
```

从左到右五阶段水平箭头串联：
数据采集（多源异构数据→ETL清洗）→
数据分析（SQL查询+Python建模+关联规则）→
疑点识别（异常检测算法→风险评分）→
证据核验（交叉比对+穿透测试→证据链）→
报告生成（发现摘要+建议矩阵）。
每个阶段下方标注技术工具和关键产出物。
底部标注"Fig.1 大数据驱动的审计方法论框架"。
```

## 八、图片编辑 → 融策审计实务

### ✅ 适配场景 44：去水印与消除杂物 → 审计底稿图片清理

**融策玩法**：被审计单位提供的扫描件带着水印和杂物，清理后存档。

**提示词框架**：
```
去掉这张扫描件上的所有水印、印章污渍和多余的边线标记。
保留文件主体内容和印章文字，让扫描件干净清晰适合审计底稿归档。
不要改变原文内容和布局。
```

### ✅ 适配场景 45：老照片/档案修复 → 历史档案修复

**融策玩法**：被审计单位提供的老旧档案（泛黄、虫蛀、字迹模糊），修复后便于审阅。

**提示词框架**：
```
修复这张老旧档案照片。去除泛黄、斑点、折痕和虫蛀痕迹，
增强文字对比度使模糊字迹可读，保持原始纸张纹理的历史感。
不要改变原始内容和印章的任何信息。修复后适合审计电子档案存档。
```
