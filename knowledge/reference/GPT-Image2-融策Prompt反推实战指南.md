# GPT Image2 融策 Prompt 反推实战指南

> 基于「看图反推 Prompt」的十步分析法，适配融策三大场景：
> **标书封面克隆 / 报告版式反推 / 甲方参考图迁移**
>
> 核心能力：告别"看着别人的好封面瞎猜提示词"→ 上传图+粘贴指令 = 得到完整正反向 Prompt

---

## 零、完整反推指令（融策定制版）

```
请分析我发给你的这张图，帮我反推出一段可以直接用于 AI 生图工具的 prompt。
你的目标不是简单描述图片，而是还原这张图在工程咨询/政府审计专业场景下的视觉要素。

请在内部完成以下完整分析，但不要展示分析过程。
最终只输出可直接复制到生图工具里的结果。

---

## 内部分析要求

### 1. 判断用途类型
判断这张图属于：标书封面 / 审计报告封面 / 工程方案图 / PPT标题页 / 数据分析看板 / 政府公文内页 / 宣传海报 / 其他

### 2. 判断媒介与风格
判断：写实摄影 / 3D渲染 / 建筑效果图 / 手绘线稿 / 数据可视化 / 混合媒介
最终 Prompt 必须明确媒介边界，排除易混淆媒介。

### 3. 技法层分析
- 构图：主体位置、占比、前景中景背景、留白、视觉结构
- 镜头视角：平视俯视仰视、特写中景远景、透视关系
- 光线：主光方向、硬柔光类型、光比、光线情绪
- 色调：主色/辅色/点缀色、冷暖、饱和度、配色体系
- 材质：表面质感、反光/粗糙/半透明/金属/纸张/布料
- 景深与背景：虚实度、背景几何结构、叙事还是氛围
- 后期与画质：精修程度、胶片/清透/雾感、清晰度

### 4. 内容层分析（融策专项）
- 主体识别：建筑/数据图表/文字排版/地图/流程图/机构名称
- 场景地点：城市/工地/办公室/自然/抽象空间
- 时间季节：白天/黄昏/夜晚/无时间感
- 情绪调性：权威/专业/科技/庄重/温暖/现代/古典
- 如果有文字：分析排版层级、字体风格、位置关系（最终不要求AI生成可读文字）

### 5. IP/Logo/品牌处理
不依赖具体机构名和Logo，转写为外观特征。

### 6. 提炼 3-5 个复现关键要素
选出最不能丢的视觉锚点，优先写入 Prompt 前1/3。

### 7. 生成 Negative Prompt
覆盖：错误媒介、多余主体、杂乱背景、低质画面、乱码文字、水印

---

## 输出要求

最终只输出以下两项：

1. 正向 Prompt（300-500字中文连续自然语言，非关键词列表）
   - 必须包含：主体/构图/镜头/光线/色彩/材质/背景/空间层次/情绪/媒介边界
   - 必须优先描述最影响相似度的视觉锚点
   - 融策配色关键词：深蓝(#0A1F3F)、青绿(#1A5C6E)、铜金(#C5955C)、暖灰(#F5F2EC)

2. Negative Prompt（8-15条英文，逗号分隔）

不要输出分析过程和任何额外解释。
```

## 一、三大融策实战场景

### 场景一：竞品标书封面克隆

**痛点**：看到同行或大咨询公司的标书封面做得漂亮，想模仿风格但不知道提示词怎么写。

**操作流**：
1. 截取或保存参考封面图
2. 上传参考图到 GPT Image2/ChatGPT
3. 粘贴上方融策定制版反推指令
4. AI 输出正向 Prompt + Negative Prompt
5. 将正向 Prompt 中的项目名称替换为自己的
6. 在融策适配提示词库中检查/替换配色为融策标准色
7. 生成 → 微调 → 定稿

**示例**：假设参考图是「某四大咨询公司的工程咨询标书封面」，AI 会反推出：
- 封面采用中轴对称构图，左上角为公司Logo区域，建筑3D线框从右下角向上辐射
- 配色为深蓝底金色点缀，背景有微网格纹理
- 标题区位于中下段，底部为机构信息

实测后你得到的是**可复用的标书封面提示词**而不是一次性的模仿品。

### 场景二：甲方参考图迁移

**痛点**：甲方领导甩过来一张别人家的报告封面说"照这个感觉做"，但颜色主题和公司品牌不搭。

**操作流**：
1. 上传甲方提供的参考图
2. 粘贴反推指令 → 得到原始 Prompt
3. 在原始 Prompt 中批量替换：
   - 配色 → 融策深蓝+青绿+铜金+暖灰
   - 机构名/Logo → 四川融策相关描述
   - 行业元素 → 审计/工程咨询相关元素
4. 生成 → 甲方确认

**关键**：反推工具给你的是**结构模板**，你可以替换任意元素而保持版式骨架。

### 场景三：内部风格参考库建设

**痛点**：公司积累了不少好的封面/内页设计，但无法描述"我们公司的风格是什么"。

**操作流**：
1. 收集公司已完成的优秀标书/报告封面（5-10张）
2. 逐一使用反推指令得到 Prompt
3. 提取 5 张图的共同要素 → 形成《融策视觉风格规范》
4. 这些共同要素（深蓝底、铜金点缀、中轴对称、留白大气）可以直接写入新建提示词中

## 二、反推 Prompt 评级标准

拿到反推结果后，快速判断质量：

| 评级 | 标准 | 处理 |
|:----:|------|------|
| ⭐⭐⭐ | 450字以上，包含全部10项要素，主体专项分析精准 | 直接使用 |
| ⭐⭐ | 300-400字，缺少2-3项要素 | 手动补全后使用 |
| ⭐ | 少于300字，只有简单描述 | 重新上传更高清晰度的图重试 |
| ❌ | 出现乱码、编造事实、无视关键视觉元素 | 换一张图或用文字补充描述 |

## 三、融策反推快捷指令库

### A. 标书封面专用反推指令（精简版）

```
分析这张标书/报告封面图，反推Prompt。
重点分析：构图方式（居中/左对齐/对称）、配色方案（标注主色辅色）、
图文排布关系、标题区位置、装饰元素类型、整体风格倾向。
输出：完整正向Prompt + Negative Prompt。
```

### B. 工程方案图专用反推指令（精简版）

```
分析这张工程设计方案图，反推Prompt。
重点分析：图纸类型（平面/剖面/效果图/流程图）、标注体系、色彩编码规则、
空间层次、视角、专业符号使用。
输出：完整正向Prompt + Negative Prompt。
```

### C. 数据看板/审计图表专用反推指令（精简版）

```
分析这张数据可视化/审计图表，反推Prompt。
重点分析：图表类型（柱状/折线/饼图/雷达/流程图）、配色与数据映射、
信息层级、标注方式、数据密度、版式结构。
输出：完整正向Prompt + Negative Prompt。
```

## 四、与现有融策提示词库的关系

| 建库方式 | 适用场景 | 反向工程？ |
|---------|---------|:--------:|
| 微信文章迁移（前6篇） | 空白创作——自己从零写提示词 | ❌ |
| **看图反推（本篇）** | **参考驱动——有图但不知道怎么描述** | **✅** |

两者互补：
- 前期用反推积累风格素材 → 录入提示词库
- 后期直接从库中调取模板 → 省去每次反推的步骤
