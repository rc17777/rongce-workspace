# 融策品牌产品化指南 v2.0

> 从"你们公司有什么服务"到"我就要这个"的桥梁

---

## 核心理念

**客户看到的不是"技术"，是"解决方案"。**
**客户听的不是"我们有72个技能"，是"我们能帮你省多少钱"。**

---

## 产品化三步走

### 第一阶段：3个核心产品（7天）

#### 产品1：「融策智能审计速查」服务包

**一句话卖点：** 输入数据，30分钟出审计初稿。

| 项目 | 内容 |
|:--|:--|
| 目标客户 | 政府审计项目、财政监督检查 |
| 交付物 | 审计报告初稿（Word/PDF）+ 发现问题清单（Excel） |
| 定价 | 基础版¥3,000/项目 · 标准版¥8,000/项目 · 旗舰版¥20,000/项目 |
| 技术栈 | 7Agent审计平台 + RAG知识库 + 模型路由 |
| 人工介入 | 基础版→AI全自动；标准版→AI+人工复核；旗舰版→AI+资深审计师背书 |

**客户能看到的：**
> 「我们上传了察隅县4个Excel文件，7分钟后系统自动生成了9条审计发现、4条交叉碰撞线索，包括资金汇总表空字段、合同违规线索、内控漏洞。传统审计需要3天才能到这个程度。」

#### 产品2：「围标串标AI检测」服务

**一句话卖点：** 投进去看文件，1小时出检测报告。

| 项目 | 内容 |
|:--|:--|
| 目标客户 | 政府采购代理机构、纪委监委、审计局 |
| 交付物 | 串标检测报告（L1-L11分色标注）+ 铁证打包 |
| 定价 | 单项目¥5,000 · 年度框架¥50,000（不限项目数） |
| 技术栈 | 19层检测体系（L3文本雷同+L4图片哈希+L5元数据） |

**客户能看到的：**
> 「我们分析了XX项目8家投标人的标书，发现3家供应商的Word文档GUID高度关联，Lock作者为同一人，PDF打印机型号完全一致。三证据链闭合，可定案。」

#### 产品3：「专项资金穿透审计」服务

**一句话卖点：** 从指标文到资金使用末端，全链条穿透。

| 项目 | 内容 |
|:--|:--|
| 目标客户 | 财政局、专项资金主管部门 |
| 交付物 | 穿透审计报告 + 资金流向图 + 问题底稿 |
| 定价 | 按项目规模，¥10,000起 |
| 技术栈 | 专项资金审计Agent + 数据分析 |

**客户能看到的：**
> 「我们追踪了XX县2,000万专项资金从指标文下达到项目单位使用的全过程，发现3笔资金拨付与使用进度不匹配、2个项目程序违规、1个乡镇资金沉淀超过6个月。」

### 第三阶段：持续运营

- **每月**: 更新服务包内容，新增1个案例
- **每季**: 产出1个完整客户案例（含客户可见证数据）
- **每半年**: 产品迭代 + 定价调整

---

## 关键原则

1. **客户看到的是"解决方案"，不是"技术工具"**
2. **每个产品必须有明确的交付物定义**
3. **定价透明，避免"看人下菜"**
4. **产品化 = 可复制 ≠ 标准化**
5. **AI是第一稿，人工是最后一稿**
