# 董事/监事履职审计要点 — 9篇论文综述

> 基于9篇学术论文的综合提炼 | 2026年6月 | 融策审计研究

---

## 一、外派董事履职制约与对策

**（韩庆东、骆琼琳）**

### 1.1 六大制约因素（韩庆东）

韩庆东系统梳理了国企兼职外派董事面临的六大制约：

1. **知识因素**：缺乏清晰选聘标准和岗位说明书，"具有履行岗位职责所必需的专业知识"表述模糊；多数外派董事上岗前无系统性培训。
2. **权力因素**：两极分化——要么所有事项均需股东审批、董事表决流于形式；要么缺乏必要制约，董事仅发表附同性意见。
3. **沟通因素**：同一单位派出的多名外派董事无固定沟通机制，无法形成团队协作。
4. **决策因素**：股东领导班子依赖"二手信息"做决策，外派董事跟随表决，难以保证效果。
5. **管理因素**：大股东直接插手子公司管理，与法人主体独立运作原则冲突。
6. **法律因素**：外派董事流于形式的表决需承担法律责任，实际决策者却不担责——**权责严重分离**。

### 1.2 三大致命缺陷（骆琼琳）

骆琼琳直指现行外派董事决策模式的三大缺陷：

- **缺陷一—影响子公司独立运营**：外派董事兼具双重身份（在股东单位领薪、接受领导），在派驻公司担任董事不领薪，容易利益倾斜；控股股东通过外派董事实质操控子公司董事会。
- **缺陷二—降低子公司决策效率**：两套决策体系并行——对外依法开董事会，对内沿袭"请示-批复"模式；多层控股需逐级上批下达，可能错失市场良机。
- **缺陷三—权责不对等**：外派董事被剥夺独立表决权，却面临《公司法》规定的法定个人责任，导致董事怠于履职、过度依赖上级指令。

### 1.3 共同对策

两篇论文一致建议：**以公司治理取代股东管理**，在章程中明确划分股东会/董事会/管理层职责权限；**建立重大事项分类决策机制**（非重大事项董事自主表决，重大事项先报后决）；**建立职业董事制度**，辅以配套的考核激励与责任豁免机制。

## 二、外部董事履职能力提升

**（刘颖、王帆、谢秀玲）**

### 2.1 能力框架与培训体系（刘颖）

刘颖界定董事五大关键能力：**战略规划、重大决策、风险防范、财务管理、社会责任**。提出"组织需求—岗位需求—个人需求"三层培训需求分析模型，培训内容涵盖七方面（党的理论、行业政策、功能定位、资本运作、市场化意识、领导力、企业文化），要求培训制度化常态化（每年≥1次系统性培训+2-3次专题培训，建立培训档案）。

### 2.2 外部董事的四个作用与三个短板（王帆）

王帆归纳外部董事四大作用：**辅助决策、监督经营、统筹兼顾、改善治理**。指出三大短板：信息获取不充分（不对称+专业知识结构不合理）、履职时间不足（年龄偏大或同期兼职多家）、激励机制不健全（兼职不兼薪，有责无利）。

### 2.3 四类难点与四项改进（谢秀玲）

谢秀玲从实操层面罗列四类难点：**董事会运行不规范**（临时送材料、议题材料缺失、记录不规范）、**履职支撑不足**（把外部董事当"外人"）、**治理结构不健全**（法律地位不明确、信息渠道不畅）、**决策研究深度不够**（书面材料依赖症）。

四项改进措施：**建专门委员会、规范会议程序**（提前通知+完整议案）、**保障调研工作**、**建立考核评价机制**。

### 2.4 三篇共识

三篇论文共同指向：**信息获取渠道**是外部董事履职的头号障碍；**激励机制**（物质+声誉）是调动积极性的关键；**培训体系**是能力提升的基础设施。三篇合力构建了一个"选—训—激—评"的完整能力提升闭环。

## 三、新公司法下的董事履职变化与风险

**（刘力达）**

### 3.1 新法重大变化

2024年7月1日施行的新《公司法》第173条首次将"外部董事占多数"写入法律（国有独资公司董事会成员中应当过半数为外部董事），标志着外部董事制度从政策要求上升为法律强制。

### 3.2 现存四大问题

1. **聘任机制不健全**：选聘渠道单一（"就近选择"倾向），以同级别国企领导和党政机关人员为主，来源单一、质量良莠不齐。
2. **激励机制不完善**：2017年出台的薪酬管理办法已不满足当前需求；声誉激励缺失——退休领导和专家更看重名声。
3. **履职保障不足**：兼职为主，"空壳董事"现象——身兼数职，实际工作时间短。
4. **法律责任界定不清晰**：新法第188条、191条加重董事责任，但未区分内外部董事，外部董事作为"外来人"与内部董事承担相同责任是否合理存疑。

### 3.3 应对措施

- **优化队伍建设**：拓宽选聘渠道，打破行业壁垒和地域限制，建立"精干多元、能力互补、专兼结合"的选任机制。
- **健全激励评价**：物质激励（基本薪酬+与业绩挂钩的浮动薪酬）+声誉激励（评优表彰、邀请授课）。
- **强化履职保障**：优化会前联络沟通机制、加强培训、**完善容错纠错机制**。
- **合理界定法律责任**：以民事责任为主、行政责任为辅；无故意或重大过失时赔偿设上限；新法第193条首次明确公司投保董事责任保险，但需严格区分故意与过失。

## 四、监事履职责任风险与三会管理

**（周涛、王宇）**

### 4.1 外派监事四大责任风险（周涛）

周涛系统梳理了外派监事面临的四大责任风险：

1. **违反忠实勤勉义务的风险**：以消极不作为为主——应当发现而未发现、发现后不揭示、疏忽大意。已有司法判例（〔2019〕浙0282民初1214号）判决监事承担赔偿责任。
2. **被限制高消费的风险**：法院可将监事认定为"影响债务履行的直接责任人员"而采取限高措施。
3. **信息披露违规风险**：《证券法》第82条要求监事签署书面确认意见，否则承担赔偿责任。
4. **国资监管追责风险**：未尽职导致国有权益受损，面临组织处理、扣薪、纪律处分乃至辞退。

**特别警示**：在国有参股企业任职的外派监事风险更大——信息不对称更突出、履职支持度更低、无法与集团审计/纪检/风控协同。

### 4.2 风险成因与对策（周涛）

**四大成因**：信息不对称→履职能力不足→履职意愿低→制度保障不足。

**对策要点**：
- 提高履职意愿与能力：优先选任审计、法务部门人员；加强培训；适当增加外派兼职监事人数
- 加强制度保障：完善监事会议事规则；丰富履职手段（查阅资料、个别约谈、实地调研、聘请第三方等）
- 加强履职协同：与审计部门、纪检、法务风控形成合力
- **完善尽职合规免责机制**：明确哪些情形可申请免责、减责
- **履职留痕**：任何履职活动均应留痕，固定履职资料

### 4.3 三会管理（王宇）

王宇聚焦省管国企对再投资企业的治理：**三会权责不清**（越位、缺位）、**监事会形同虚设**、**选任机制行政化**（按行政级别而非专业匹配度选人）、**信息不对称**（母公司与子企业间信息传递不畅）。

对策：建立董监事人才库+资格认证制度；统一信息共享平台；建立健全三会议事规则和配套制度；推动"决策—执行—监督"闭环管理。

## 五、董事监事综合履职管理

**（蔡闻一）**

蔡闻一的论文是唯一同时深入分析董事和监事履职管理的，可视为方法论总纲：

### 5.1 四维问题框架

| 维度 | 董事方面问题 | 监事方面问题 |
|------|-------------|-------------|
| 成员结构 | 多为内部董事，甚至全部为内部 | 多为兼职，与专职化要求有差距 |
| 履职作用 | 知识结构不完善，缺少公司治理/财金/法务知识 | 研究调查不足，表决意见缺乏深度 |
| 评价方式 | 薪酬未与经营风险挂钩，约束力有限 | 绩效考核指标不完善，无"能上能下"机制 |
| 支撑服务 | 无专门支撑机构，沟通平台缺乏 | 无专门对接部门或人员 |

### 5.2 四项系统措施

1. **优化结构**：外部董事占多数+建立专职董监事人才库
2. **加强培训**：持证上岗+定期专题培训
3. **完善考核**：行为操守+履职业绩+经营业绩三维评价+年度述职
4. **强化支撑**：设立董办或专门机构+开放办公系统权限+安排调研培训

## 六、审计关注要点汇总 ⭐

> 从9篇论文中提取的全部可落地的审计检查项，按维度系统整理。

### 6.1 董事履职合规性检查清单（18条）

**人员选聘与资格**
- [ ] 1. 外部董事人数是否占董事会成员的半数以上？（新《公司法》第173条强制性要求）
- [ ] 2. 是否建立了外部董事人才库？选聘来源是否单一（仅内部体系人员）？
- [ ] 3. 外派董事是否有明确的岗位说明书（含职责权限义务表述）？
- [ ] 4. 是否存在董事同时在3家以上企业兼职的情况？（关注履职时间不足风险）
- [ ] 5. 董事上岗前是否经过系统性培训？有无持证上岗制度？

**决策机制**
- [ ] 6. 是否建立了重大事项分类决策机制？非重大事项董事能否自主表决？
- [ ] 7. 董事会表决是否存在"先内部审批、后形式上开会"的流程？（流于形式风险）
- [ ] 8. 会议通知是否提前发送？议案材料是否完整规范？
- [ ] 9. 董事是否就表决事项进行了充分的会前调研？（有无调研记录）

**履职记录**
- [ ] 10. 董事是否有完整的履职工作记录（出席情况、表决意见、调研报告等）？
- [ ] 11. 是否建立了董事年度述职制度？述职报告是否存档？
- [ ] 12. 是否建立了董事履职台账（参会次数、发言内容、表决记录）？

**考核与激励**
- [ ] 13. 是否建立了董事考核评价机制？评价维度是否包含忠实勤勉、专业性、独立性？
- [ ] 14. 考核结果是否与薪酬、续聘挂钩？（关注"干好干坏一个样"）
- [ ] 15. 外派董事是否在任职企业领取报酬？是否存在"兼职不兼薪、有责无利"？
- [ ] 16. 是否有容错纠错机制？对非主观性错误的免责标准是否明确？

**法律合规**
- [ ] 17. 公司是否投保了董事责任保险？（新《公司法》第193条）
- [ ] 18. 股东单位是否越权直接干预子公司经营管理？（检查章程中职权划分）

### 6.2 监事履职检查清单（12条）

**任职资格与独立性**
- [ ] 1. 监事是否由董事、高管兼任？（《公司法》第117条明令禁止）
- [ ] 2. 外派监事是否有财务、法务或审计专业背景？
- [ ] 3. 外派监事是否岗前培训？是否清楚自身责任风险？

**履职保障**
- [ ] 4. 监事会是否制定了议事规则？议事规则是否有具体可操作的条款？
- [ ] 5. 是否有专门对接监事工作的部门或人员？
- [ ] 6. 履职企业是否按规定及时向监事提供财务会计、决策和经营管理活动资料？
- [ ] 7. 涉及"三重一大"的会议是否提前通知监事参加并送达文件？

**履职记录与成效**
- [ ] 8. 监事是否有完整的履职工作底稿？（查阅资料记录、约谈记录、调研报告、书面质询等）
- [ ] 9. 监事是否在证券发行文件/定期报告上签署了书面确认意见？
- [ ] 10. 监事发现的问题是否形成书面报告并提交股东？有无整改跟踪记录？

**制度与追责**
- [ ] 11. 是否建立了外派监事职责清单？清单内容是否可量化、可操作？
- [ ] 12. 是否建立了监事尽职合规免责机制？免责申请、受理与认定的程序是否清晰？

### 6.3 三会运作规范性检查（10条）

- [ ] 1. 股东会、董事会、监事会是否有明确的议事规则且归档备查？
- [ ] 2. 三会是否有年度会议计划？会议频次是否达标？（重点：监事会有无长期不开会现象）
- [ ] 3. 会议通知时间是否符合章程规定？议案资料是否提前送达？
- [ ] 4. 会议记录是否完整（含出席情况、表决过程、异议意见、决议内容）？
- [ ] 5. 决议执行是否有跟踪机制？决议落实情况是否定期向董事会/监事会反馈？
- [ ] 6. 是否存在"未开会但有决议"或"传签替代会议"且无合理记录的情况？
- [ ] 7. 股东会/董事会/监事会之间是否存在越权决策？（重点：股东越过董事会直接发指令）
- [ ] 8. 是否设立了董事会专门委员会（审计、薪酬、提名等）？运作是否正常？
- [ ] 9. 会议频率与质量是否匹配企业规模和业务复杂度？
- [ ] 10. 对国有参股企业，是否在投资协议和章程中预先约定了董监事席位和行权方式？

### 6.4 外派董事/监事特殊风险点（8个）

1. **双重身份利益冲突**：外派人员在股东单位领薪、在派驻企业任董事/监事不领薪 → 利益天然向派出单位倾斜。
2. **权责不对等**：表决权被股东实质性剥夺，但法律追责时承担同等于独立决策董事的责任。
3. **"空壳董事/监事"**：身兼数职，实际投入时间远不达履职要求 → 主张"不知情"不能免责。
4. **多层管控延迟**：多层控股子公司逐级上批下达 → 董事会会议时效性无法保证 → 紧急事项错失时机。
5. **信息壁垒**：外派人员不参与日常经营，重大事项不告知或事后告知 → 监督滞后。
6. **参股企业风险放大**：国资监管规定不适用参股企业，审计/纪检手段无法介入 → 外派监事是唯一监督力量却势单力薄。
7. **监事限高风险**：公司作为被执行人时，监事可能被法院认定为"影响债务履行的直接责任人员"而限高。
8. **集体懈怠**：制度上无有效激励（兼职不兼薪）、考核上无刚性追责 → 整体履职意愿低下。

### 6.5 审计取证路径与方法

| 审计目标 | 取证方法 | 关键证据材料 |
|----------|----------|-------------|
| 董事任职合规 | 查阅+比对 | 公司章程、董事名册、聘任文件、外部董事人才库名单 |
| 董事会运作规范性 | 抽样+穿行测试 | 董事会会议通知、签到表、会议记录、决议文件、表决票 |
| 外部董事独立性 | 访谈+问卷 | 外部董事访谈记录、利益冲突声明、任职企业关联方清单 |
| 信息传递有效性 | 时间比对 | 会议通知日期 vs 实际送达日期、议案材料完整性 |
| 履职勤勉程度 | 量化分析 | 履职台账（出席率、发言次数、调研天数）、年度述职报告 |
| 考核激励机制 | 制度审查 | 考核办法、薪酬发放记录、奖惩文件 |
| 监事监督实效 | 正向追踪+反向验证 | 监事工作报告、质询函、整改通知书、审计发现问题与监事知晓时间的比对 |
| 三会权责边界 | 制度比对 | 三会议事规则、章程职权条款、实际决策事项清单与权限对照 |
| 外派人员权责对等 | 制度审查+访谈 | 外派管理办法、内部审批流程记录、董事表决与股东指令的对应关系 |
| 责任保险覆盖 | 查阅+确认 | 董事责任保险保单、保费支付记录、股东会告知记录（新法第193条） |

**取证技巧**：
- **"反向追踪法"**：先锁定子公司实际发生的重大决策事项，倒查这些事项是否经过了规定的董事会/监事会程序。
- **"时间链比对法"**：将股东内部审批日期与董事会会议日期进行比对——审批在前、会议在后且有完全一致的结果，是"流于形式"的强证据。
- **"信息落差测试"**：同时访谈外派董监事和内部高管，对同一重大事项的了解程度进行比对，差距悬殊则证明信息壁垒存在。

## 七、对融策业务的启示

### 7.1 经责审计中嵌入董监事履职检查

经责审计的传统框架侧重"三重一大"和经营绩效，9篇论文提示应新增以下检查维度：

- **"一人一档"履职核查**：要求被审计企业提供全部董监事的履职台账（出席记录、表决意见、调研报告），作为经责审计的必查材料。
- **"权责匹配度测试"**：对外派董监事，实质审查其表决行为是否具有独立性——比对董事会决议与股东内部审批的时间、内容一致性。
- **"监督闭环"审查**：监事会发现的问题→是否报告→是否整改→整改是否验证？断链处即为审计发现。
- **参股企业专项延伸**：经责审计中对参股企业的外派董监事履职，因其是国有出资人了解参股企业经营状况的"唯一正式通道"，应作为高风险领域单独延伸审计。

### 7.2 国企审计中法人治理结构的审计方法

- **制度层面**：先梳理三会议事规则→章程→外派管理办法→考核激励制度的完整性和衔接性。
- **执行层面**：按"决策—执行—监督"三环节分别穿行测试，重点验证是否存在"制度一套、执行一套"的双轨制。
- **效果层面**：选取3-5个重大决策事项，全程追踪从议案提出→调研论证→会议表决→执行落实→效果评估的完整链条。
- **对标层面**：以新《公司法》第173条（外部董事过半数）、第188条（赔偿责任）、第191条（第三人责任）、第193条（责任保险）为硬性标尺，逐条对照。

### 7.3 投标方案中展示专业能力

在投标融策的审计/咨询类项目时，可从以下角度展示董监事履职审计的专业能力：

1. **方法论亮点**：展示"反向追踪+时间链比对+信息落差测试"的审计取证方法论，体现专业深度。
2. **法规准备**：展示对新《公司法》关键条款（第173、188、191、193条）的准确理解和审计应用。
3. **风险地图**：以本文第六部分为核心，展示系统化的董监事履职风险识别框架——从18条董事检查项+12条监事检查项+10条三会运作检查项覆盖所有治理风险点。
4. **案例加持**：可参考周涛论文中的司法判例（如〔2019〕浙0282民初1214号监事被判赔偿案），展示对实践风险的透彻了解。
5. **差异化定位**：强调融策同时具备"财务审计+法人治理审计"的双重资质，在经责审计中嵌入法人治理结构检查是区别于纯财务审计机构的核心竞争力。
