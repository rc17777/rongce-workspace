# 融策 AI 审计知识库（RAG）搭建方案

## 一、预期效果

审计人员打开一个网页/本地工具，输入问题：
- "串标围标的取证要点有哪些？"
- "竣工财务决算审核的流程是什么？"
- "经责审计中一票否决的情形有哪些？"

**系统自动从融策的 all knowledge base 中检索相关文档，结合AI给出带引用的答案。**

## 二、技术架构（完全本地化，无需外网API）

```
用户提问 → 本地嵌入模型(bge-small-zh-v1.5) → 向量检索(FAISS) 
         → 检索到Top-K相关段落 → 本地LLM(Qwen2.5-7B/Ollama) 
         → 带引用的答案
```

## 三、搭建步骤

### Step 1：安装依赖

```bash
pip install sentence-transformers faiss-cpu ollama-python
```

### Step 2：向量化知识库

把 `D:\openclaw-workspace\knowledge\` 下所有 .md 文件读取、分段（每段512字符）、用 bge-small-zh-v1.5 生成向量，存入 FAISS 索引。

### Step 3：检索 + 生成

查询时，问题向量化 → FAISS 搜索最相关段落（Top 5）→ 拼接到 prompt → 发给本地 Ollama 上的 Qwen2.5（或直接调用 DeepSeek API）→ 输出答案。

### Step 4：使用方式

- **命令行**：`python rag_query.py "串标围标取证要点"`
- **本地网页**：用 Gradio 做个简单界面，`python rag_web.py`
- **我集成到 OpenClaw**：问我的时候自动检索知识库 + 回答

## 四、融策用这个能做什么

| 用途 | 说明 |
|:----|:------|
| **项目交付** | 审计人员问法规条款，5秒出答案带出处 |
| **培训材料** | RAG + 融策案例库 = 自动生成培训问答 |
| **投标加分** | "我方拥有AI智能知识库，可快速查询300+法规和案例" |
| **内部效率** | 新员工不用翻纸质资料，直接问系统 |
| **卖给客户** | 给国企客户搭私有化RAG知识库（收费服务） |
