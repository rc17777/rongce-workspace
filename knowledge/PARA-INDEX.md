# 知识库 PARA 分类体系

> 基于 PARA 方法（Projects / Areas / Resources / Archives）对融策知识库的结构化映射。
> 此文件为叠加层——不改变现有目录结构，而是在逻辑上给每个内容区域打 PARA 标签。
> 创建：2026-07-09 | 参考：公众号「AI产品方舟」知识库搭建指南

## PARA 四层定义

| 层级 | 英文 | 含义 | 融策对应 | 更新频率 |
|:--|:--|:--|:--|:--|
| **P** | Projects | 正在进行的、有明确截止时间的任务 | 当前审计项目 | 项目结束时归档 |
| **A** | Areas | 持续关注的、没有截止时间的领域 | 12大业务线 | 持续维护 |
| **R** | Resources | 参考资源、未来可能用到的资料 | 政策法规/案例库/工具资料 | 按需补充 |
| **A** | Archives | 已完成/不再活跃的内容 | 已交付项目、过期政策 | 定期清理 |

## 入库门槛（新增）

参照文章"三天内会用上才存"的原则，融策知识库入库规则：

| 内容类型 | 入库规则 | PARA 标签 |
|:--|:--|:--|
| 新政策/法规（国家级/省级） | ✅ 直接入库 | **R** |
| 公众号文章/行业分析 | ⚠️ AI提取要点→卡片→存 | **R** |
| 审计项目中间文件 | ✅ 项目目录 | **P** |
| 随手看到的好文章 | ❌ 不入库（先存微信收藏，确认有用再搬） | — |
| 过时的政策/已废止法规 | 🔄 标注废止 → 移入 Archives | **Archives** |
| 项目交付物（报告/底稿） | ✅ 项目完成后移入 Archives | **Archives** |

## 输入工作流（5分钟闭环）

```
看到好内容 → AI提取要点（2min）→ 打 PARA 标签（30s）→ 存入对应目录（30s）→ 加双向链接（1min）
```

工具链：
1. 浏览器/微信 → 复制文章内容
2. RAG CLI：`python scripts/rag_query.py "提取这篇文章的3个核心要点和2条行动建议：[内容]"`
3. 手动整理成卡片 → 放入 knowledge/对应PARA目录
4. 任意编辑器写双向链接：`[[相关笔记名]]`
