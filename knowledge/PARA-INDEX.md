# 知识库 PARA 分类体系

> 基于 PARA 方法（Projects / Areas / Resources / Archives）对融策知识库的结构化映射。
> 此文件为叠加层——不改变现有目录结构，而是在逻辑上给每个内容区域打 PARA 标签。
> 创建：2026-07-09 | 参考：公众号「AI产品方舟」知识库搭建指南

## PARA 四层定义

| 层级 | 英文 | 含义 | 融策对应 | 更新频率 |
|:--|:--|:--|:--|:--|
| **P** | Projects | 正在进行的、有明确截止时间的任务 | 当前审计项目 | 项目结束时归档 |
| **A** | Areas | 持续关注的、没有截止时间的领域 | 12大业务线 | 持续维护 |
| **R** | Resources | 参考资源、未来可能用到的资料 | 政策法规/案例库/工具资料 | 按需补充 |
| **A** | Archives | 已完成/不再活跃的内容 | 已交付项目、过期政策 | 定期清理 |

## 入库门槛（新增）

参照文章"三天内会用上才存"的原则，融策知识库入库规则：

| 内容类型 | 入库规则 | PARA 标签 |
|:--|:--|:--|
| 新政策/法规（国家级/省级） | ✅ 直接入库 | **R** |
| 公众号文章/行业分析 | ⚠️ AI提取要点→卡片→存 | **R** |
| 审计项目中间文件 | ✅ 项目目录 | **P** |
| 随手看到的好文章 | ❌ 不入库（先存微信收藏，确认有用再搬） | — |
| 过时的政策/已废止法规 | 🔄 标注废止 → 移入 Archives | **Archives** |
| 项目交付物（报告/底稿） | ✅ 项目完成后移入 Archives | **Archives** |

## 输入工作流（5分钟闭环）

```
看到好内容 → AI提取要点（2min）→ 打 PARA 标签（30s）→ 存入对应目录（30s）→ 加双向链接（1min）
```

工具链：
1. 浏览器/微信 → 复制文章内容
2. RAG CLI：`python scripts/rag_query.py "提取这篇文章的3个核心要点和2条行动建议：[内容]"`
3. 手动整理成卡片 → 放入 knowledge/对应PARA目录
4. 任意编辑器写双向链接：`[[相关笔记名]]`

## 知识体系方法论层

> 补充自：公众号「乌昂汪」《搭建自己的可自行生长的知识体系》（2026-07-19入库）

### DIKW 金字塔（知识消化路径）

```
Wisdom（智慧）  ← "我该怎么做？" → 审计建议的形成
Knowledge（知识）← "我该怎么知道？" → 审计方法的内化
Information（信息）← "发生了什么？" → 审计发现的记录
Data（数据）    ← 原始事实 → 凭证/账表/业务系统数据
```

**每读一篇文章/法规，追问自己**：
1. 这改变了我的什么认知？
2. 我能把它用在哪个审计场景？

### CODE 四步法（知识流动）

| 步骤 | 操作 | 融策对应 |
|:--|:--|:--|
| **C**apture 捕捉 | 只保存让你心动的信息 | 入库门槛（三天内会用上） |
| **O**rganize 组织 | 按行动方向分类 | PARA 四层结构 |
| **D**istill 提炼 | 用自己的话说出核心 | AI提取要点 → 打标签 → 写卡片 |
| **E**xpress 表达 | 用知识做点什么 | 审计报告/案例分析/培训材料 |

> 每一层都在"减"：海量信息 → 精选笔记 → 核心洞见 → 行动输出

### Zettelkasten 卡片盒原则

三条核心规则：
1. 每次有新想法，写一张卡片
2. 这张卡片必须和已有的卡片建立连接
3. 卡片之间可以互相引用、形成网络

**审计适配**：每发现一个审计疑点/方法/案例，不只要记录下来，还要问——"这和之前的什么东西有关？"

### 五步启动法

| 步骤 | 行动 | 审计人员适配 |
|:--|:--|:--|
| 1. 克制捕捉 | 每天最多5条 | 每次项目后只留3个核心发现 |
| 2. 自己的话重述 | 不复制粘贴 | 审计案例用自己的语言改写 |
| 3. 追问关联 | 这和什么有关？ | 这个发现和方法论/法规/其他项目有关吗？ |
| 4. 定期回顾 | 每月30分钟 | 每月整理当月审计发现的共性规律 |
| 5. 强制输出 | 不输出=白存 | 每个项目至少产出1篇可复用的方法总结 |

### 常见误区

| ❌ 错误做法 | ✅ 正确做法 |
|:--|:--|
| 建完美的体系再开始 | 先粗糙地开始，边用边改 |
| 把所有东西都存下来 | 只存三天内会用上的 |
| 等有时间再整理 | 不整理=没存，超过一个月就废了 |
| 纠结工具选得不对 | 已经在用的工具就是最好的工具 |
