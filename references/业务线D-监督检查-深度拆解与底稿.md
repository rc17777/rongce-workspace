### 案例1：某国有能源集团 · 违规发放奖金1837万元

**违规手法还原**

```
┌─────────────────────────────────────────────────────┐
│                    资金流向图                         │
│                                                       │
│  集团本部工资总额账户 ──→ 正常工资发放（合规）         │
│                                                       │
│  集团本部 + 3家子公司                                 │
│       │                                               │
│       ├── "专项奖励"名目 ──→ 班子成员12人，合计1837万  │
│       │   （无批复、无审批、绕过工资总额）              │
│       │                                               │
│       └── "考核兑现"名目 ──→ 同上                      │
│           （以绩效考核为幌子，实为固定发放）            │
│                                                       │
│  资金来源：管理费用/营业外支出科目列支                   │
│  审批路径：分管领导直接签批，未经工资总额审核流程        │
└─────────────────────────────────────────────────────┘
```

**违规链条拆解**

| 环节 | 正常做法 | 实际操作 | 漏洞 |
|------|---------|---------|------|
| 制度层面 | 工资总额由国资委核定批复 | 在总额外另设名目，绕开批复 | 子公司资金支出缺乏集团层面总额监控 |
| 审批层面 | 薪酬委员会审议→董事会批准 | 分管领导签字即发放 | "专项奖励"名目无明确定义，自由裁量权过大 |
| 核算层面 | 奖金通过"应付职工薪酬"核算 | 混入管理费用/营业外支出 | 科目滥用掩盖薪酬性质 |
| 发放层面 | 纳入工资总额台账 | 单独制表、单独发放，不计入总额 | 两套工资表并行 |

**审计如何发现**

1. **工资总额 vs 实际发放 差异分析**：获取国资委批复的工资总额，与应付职工薪酬贷方发生额比对，发现差异1,837万
2. **科目追溯**：从管理费用中提取摘要含"奖励""兑现""津贴"的凭证，逐笔穿透
3. **个人账户核对**：将12名班子成员的全部收入加总，与个税申报比对，发现"第二张工资表"

**关键证据**
- 国资委工资总额批复文件
- "专项奖励"发放明细表（含签收记录）
- 管理费用/营业外支出明细账（奖励类摘要）
- 12名班子成员个税申报记录

### 案例3：某省属建筑企业 · 挂靠项目私设小金库2800万

**违规手法还原**

```
┌─────────────────────────────────────────────────────┐
│                  资金截留路径图                        │
│                                                       │
│  业主（建设单位）                                     │
│       │ 支付工程款                                    │
│       ▼                                               │
│  省属建筑企业（总包）                                 │
│       │ 按合同拨付分包款                               │
│       ▼                                               │
│  挂靠施工队（实际施工方）                             │
│       │                                               │
│       ├── 正常支出：材料、人工、机械 → 入账            │
│       │                                               │
│       └── 截留部分（约15%-20%）→ 不入账               │
│               │                                       │
│               ├── "管理费" → 项目部账外账户             │
│               ├── "协调费" → 关系维护、请客送礼         │
│               └── "备用金" → 项目部日常开支             │
│                                                       │
│  小金库规模：累计2800万元                              │
│  存在形式：个人银行卡 + 现金 + 第三方账户              │
└─────────────────────────────────────────────────────┘
```

**违规链条拆解**

| 环节 | 正常做法 | 实际操作 | 漏洞 |
|------|---------|---------|------|
| 项目承接 | 企业自有资质投标 | 挂靠方以企业名义投标，缴纳"管理费" | 挂靠本身违规，管理费成为小金库源头 |
| 资金拨付 | 总包按进度拨付，全部入账 | 拨付时分两笔：入账款 + 截留款 | 总包未监控分包方资金使用 |
| 成本归集 | 所有支出凭发票入账 | 截留部分无发票、无凭证 | 以"管理费""协调费"名义代替真实票据 |
| 资金存放 | 对公账户统一管理 | 个人卡、现金、第三方账户 | 项目经理个人控制资金，无人制衡 |

**审计如何发现**

1. **合同金额 vs 实际到账 差异追踪**：对比业主付款→总包→分包的完整链条，发现分包实际收款 < 合同约定
2. **发票与付款脱节**：大量付款无对应发票，摘要均为"管理费""协调费"
3. **举报线索**：项目部基层财务人员匿名举报
4. **个人卡排查**：项目经理名下发现大额异常资金往来

**关键证据**
- 挂靠协议/内部承包协议
- 项目部分包付款台账 vs 银行流水
- 项目经理及相关人员个人银行账户流水
- 无发票支出明细

### 案例5：某市属医院 · 耗材采购吃回扣370万

**违规手法还原**

```
┌─────────────────────────────────────────────────────┐
│                    回扣操作流程                        │
│                                                       │
│  耗材供应商                                           │
│       │                                               │
│       ├── 按中标价供货 → 医院公账付款（合规路径）      │
│       │                                               │
│       └── 按采购额3%-5%返点 → 设备科科长（回扣路径）   │
│               │                                       │
│               ├── 个人账户：约280万                    │
│               └── 科室聚餐等：约90万                   │
│                                                       │
│  持续周期：2018-2023年（5年）                         │
│  回扣比例：3%-5%（随采购量递增）                      │
│  供应商配合方式：现金 + 转账至亲属账户                │
└─────────────────────────────────────────────────────┘
```

**违规链条拆解**

| 环节 | 正常做法 | 实际操作 | 漏洞 |
|------|---------|---------|------|
| 供应商选择 | 公开招标，采购委员会集体决策 | 科室推荐供应商，招标流于形式 | 设备科同时负责需求提出和供应商推荐，缺乏分离 |
| 价格谈判 | 多家比价，公开竞价 | 选定供应商后谈"返点"，价格虚高 | 返点前置导致中标价已包含回扣空间 |
| 验收环节 | 使用科室+设备科+纪委三方验收 | 设备科单独验收 | 缺乏验收制衡 |
| 付款环节 | 按合同进度付款 | 回扣按采购额同步结算 | 付款与回扣形成闭环节奏 |

**审计如何发现**

1. **采购价格异常**：将5年耗材采购单价与同期市场公开报价/其他医院对比，发现系统性偏高8%-15%
2. **供应商集中度过高**：3家供应商占全部耗材采购额85%，且长期未轮换
3. **个人资产排查**：设备科科长及其亲属银行账户大额资金流入时间与采购付款高度吻合
4. **科室消费异常**：科室聚餐频次、人均消费远超同院其他科室

**关键证据**
- 耗材采购合同及价格对比分析表
- 供应商股权穿透图（查关联关系）
- 设备科科长及其亲属银行流水
- 供应商销售人员证言

### 案例6：某市属国有企业 · 违规对外担保8.9亿元

**违规手法还原**

```
┌─────────────────────────────────────────────────────┐
│                  违规担保结构图                        │
│                                                       │
│  某市属国企（担保方）                                 │
│       │                                               │
│       ├── 未经董事会审议                              │
│       ├── 未上报国资监管部门                           │
│       ├── 未在财务报表附注披露                         │
│       │                                               │
│       └── 为3家民营关联企业提供连带责任担保             │
│               │                                       │
│               ├── 民企A：担保4.2亿 → 已代偿2.3亿       │
│               ├── 民企B：担保3.1亿 → 到期未还（关注类） │
│               └── 民企C：担保1.6亿 → 正常               │
│                                                       │
│  合计担保金额：8.9亿                                  │
│  已代偿：2.3亿（无法追回）                             │
│  担保余额占净资产比：高达65%（远超国资委50%红线）      │
└─────────────────────────────────────────────────────┘
```

**违规链条拆解**

| 环节 | 正常做法 | 实际操作 | 漏洞 |
|------|---------|---------|------|
| 决策审批 | 董事会审议→国资监管部门审批/备案 | 主要领导个人拍板 | 印章管理失控，担保合同未经法务审核即用印 |
| 信息披露 | 财务报告附注披露担保事项 | 担保事项不入账、不披露 | 或有负债未在报表反映，财务监督失效 |
| 风险评估 | 对被担保方尽职调查 | 未做实质尽调，基于私人关系担保 | 3家被担保企业均为民营企业，与国企领导存在关联 |
| 事后管理 | 跟踪被担保方经营、定期风险评估 | 无人跟踪，代偿发生后才发现风险 | 缺乏担保后管理机制 |

**审计如何发现**

1. **银行函证**：向所有合作银行发函询证，银行回函揭示担保信息
2. **企业信用报告**：人民银行征信中心查询，发现对外担保记录
3. **用印记录排查**：调取印章使用登记簿，发现未经审批的担保合同用印
4. **反担保为零**：8.9亿担保无任何反担保措施，明显异常

**关键证据**
- 银行函证回函（担保信息）
- 企业信用报告
- 担保合同原件
- 用印登记簿（相关日期页）
- 被担保方工商登记/股权结构（关联关系证明）

### 案例8：某教育集团 · 违规收费账外管理6800万

**违规手法还原**

```
┌─────────────────────────────────────────────────────┐
│                  账外收费路径图                        │
│                                                       │
│  5所民办学校                                          │
│       │                                               │
│       ├── 合规收费 → 学校公账 → 纳入财务核算           │
│       │   （学费、住宿费等批准项目）                    │
│       │                                               │
│       └── 违规收费 → 不入公账 → 账外循环               │
│               │                                       │
│               ├── "赞助费"    ──→ 存入个人账户         │
│               ├── "培训费"    ──→ 存入第三方账户       │
│               ├── "校服费"    ──→ 现金收取             │
│               └── "择校费"等  ──→ 家长转账至指定账户   │
│                                                       │
│  累计金额：6,800万元                                   │
│  存在形式：个人卡、第三方支付、现金                     │
│  用途：账外发放补贴、基建支出、关系维护                 │
└─────────────────────────────────────────────────────┘
```

**违规链条拆解**

| 环节 | 正常做法 | 实际操作 | 漏洞 |
|------|---------|---------|------|
| 收费标准 | 经物价/教育部门批准/备案 | 批准项目之外另立名目收费 | 监管只查批准项目，不查"赞助""捐赠"类 |
| 收费渠道 | 学校公账统一收取 | 指定个人账户或第三方账户收取 | 家长缺乏辨别能力，学校说往哪转就往哪转 |
| 票据管理 | 开具财政票据/税务发票 | 不开票或开自制收据 | 无票据即无监管痕迹 |
| 资金核算 | 全额纳入学校财务统一核算 | 公账之外的资金另立账册 | 两套账并行，法定账套不反映真实财务状况 |

**审计如何发现**

1. **在校人数 × 收费标准 ≠ 账面收入**：根据学籍人数和批准收费标准测算应收学费，与账面入账数对比，发现缺口
2. **家长访谈/问卷**：抽查学生家长实际缴费金额和收费项目，发现大量未入账项目
3. **个人账户排查**：学校负责人/财务人员个人账户发现大额、高频收款
4. **资产购置与账面资金不匹配**：学校新建设施金额远超公账可支付范围，资金必有其他来源

**关键证据**
- 物价/教育部门收费标准批复
- 学籍系统在校人数
- 家长缴费凭证（银行转账记录、收据）
- 学校负责人/财务人员个人账户流水
- 第三方支付平台收款记录

### 操作卡D-B：小金库核查七步法

```
① 全账户函证 → 找出账外银行账户
② 收入完整性测算 → 业务量×单价 vs 账面收入
③ 支出真实性检查 → 大额无票支出追踪
④ 个人卡排查 → 关键岗位人员银行流水
⑤ 突击盘点 → 保险柜现金+存放物品
⑥ 供应商/分包方延伸 → 向对方核实实际收款金额
⑦ 员工访谈/举报 → 财务人员+离职人员
```

### 操作卡D-C：回扣发现五线索

```
线索① 价格异常 → 采购价持续高于市场价10%以上
线索② 供应商锁定 → 同一供应商多年未轮换，市占率>50%
线索③ 采购量异常 → 采购量不随业务量变化（刚需采购）
线索④ 资金回流 → 供应商→采购人员/亲属账户资金往来
线索⑤ 生活消费异常 → 个人消费水平与收入明显不匹配
```
