# 融策公司绩效激励方案（2026年4月版）

## 一、方案目标
1. 激励团队实现业绩目标：会计师事务所3000万，造价咨询3000万
2. 提升项目质量和利润率
3. 加速回款，改善现金流
4. 促进新业务开拓和转型

## 二、适用对象
- **四川融策会计师事务所**：30名员工
- **四川融策工程咨询公司**：12名员工

## 三、核心原则
1. **回款为王**：所有激励以实际回款为基础
2. **质量导向**：鼓励高利润、高质量项目
3. **团队协作**：个人与团队激励结合
4. **透明公平**：计算简单，规则清晰

## 四、绩效激励结构

### 4.1 总预算分配
- **绩效奖金总预算**：公司总收入的15%
- **分配原则**：个人绩效70% + 团队激励20% + 专项奖励10%
- **发放节奏**：月度发放80%，季度发放15%，年度发放5%

### 4.2 基础薪酬结构
```
总薪酬 = 底薪 + 绩效奖金 + 专项奖励 + 年度分红
```

### 4.2 绩效奖金计算（核心）

#### 个人绩效奖金公式：
```
个人奖金 = 个人回款业绩 × 提成比例 × 质量系数 × 回款系数
```

**各参数说明：**

1. **个人回款业绩**：个人负责项目实际到账金额
2. **提成比例**（根据职级和项目类型）：

| 职级 | 会计所项目 | 造价咨询项目 | 新业务项目 |
|------|------------|--------------|------------|
| 初级员工 | 3-5% | 4-6% | 6-8% |
| 中级员工 | 4-6% | 5-7% | 7-9% |
| 高级员工 | 5-7% | 6-8% | 8-10% |
| 项目经理 | 6-8% | 7-9% | 9-11% |

3. **质量系数**（基于项目利润率）：
   - 利润率 > 25%：系数 1.2
   - 利润率 15-25%：系数 1.0
   - 利润率 10-15%：系数 0.8
   - 利润率 < 10%：系数 0.5（不鼓励）

4. **回款系数**（基于回款速度）：
   - 30天内回款：系数 1.2
   - 31-60天回款：系数 1.0
   - 61-90天回款：系数 0.8
   - 超过90天：暂不计提（回款后按0.6计算）

### 4.3 团队激励

#### 部门业绩奖：
```
部门奖金 = (部门实际回款 - 部门目标) × 超额奖励比例
```
- 超额完成10%以内：奖励超额部分的10%
- 超额完成10-20%：奖励超额部分的15%
- 超额完成20%以上：奖励超额部分的20%

#### 团队协作奖：
- 跨部门合作项目：额外增加2%提成
- 老客户续约项目：额外增加3%提成
- 新客户开拓：首单额外增加5%提成

### 4.4 专项奖励

#### 1. 回款加速奖：
- 提前完成回款（比合同约定早30天以上）：奖励提前回款金额的1%

#### 2. 优质项目奖：
- 利润率超过30%的项目：额外奖励项目利润的5%

#### 3. 新业务开拓奖：
- 成功开拓数据分析/碳中和业务：首年利润的15%作为团队奖励

#### 4. 客户满意度奖：
- 客户评价优秀（评分>90）：奖励项目金额的1%

### 4.5 年度分红
- 公司年度净利润的10-15%作为分红池（独立于15%绩效预算）
- 分配依据：个人年度绩效得分 + 司龄系数 + 职级系数

## 五、实施流程

### 5.1 数据记录
1. **项目登记表**：记录合同金额、利润率、回款条件
2. **回款跟踪表**：实时更新回款状态
3. **绩效计算表**：每月自动计算绩效奖金

### 5.2 发放规则
1. **月度发放**：基础提成（回款后次月发放）
2. **季度发放**：团队奖金和专项奖励
3. **年度发放**：年度分红（次年第一季度）

### 5.3 特殊情况处理
1. **坏账项目**：不计提成，分析原因，改进风控
2. **跨年度项目**：按回款进度分阶段计提
3. **团队项目**：由项目经理分配，报部门审批
