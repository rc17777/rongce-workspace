## 二、分业务线审计关注要点与检查程序

### 1. 绩效评价

#### 对应案例
- **案例4**：科技集团研发费用造假，虚拟在研项目、伪造研发辅助账套取高新补贴1.2亿
- **案例10**：公交集团虚报运营里程、伪造GPS数据套取燃油补贴3100万

#### 审计关注要点

| 风险点 | 具体表现 | 严重程度 |
|--------|---------|---------|
| 项目真实性 | 已量产产品包装为在研项目申报补贴 | 🔴高 |
| 人员真实性 | 研发人员名单造假，非研发人员挂名 | 🔴高 |
| 数据真实性 | 运营里程、GPS数据伪造 | 🔴高 |
| 费用归集 | 非研发费用混入加计扣除 | 🟡中 |

#### 检查程序

```
一、补贴申报材料核验
1. 获取被评价单位近3年申报的各类财政补贴清单
2. 逐项核对申报材料与实际业务匹配性：
   - 研发项目：查验立项文件、研发日志、成果产出
   - 运营数据：比对GPS系统原始数据与申报数据
   - 人员名册：社保缴纳记录 vs 申报的研发人员名单
3. 重点抽查金额最大的前3笔补贴

二、数据交叉验证
1. 将申报数据与税务申报数据比对
2. 将产量/销量数据与补贴申报的消耗量比对
3. 现场查看"在研项目"的实际状态

三、资金流向追踪
1. 补贴资金到账后的使用去向
2. 是否存在补贴资金回流至关联方

四、绩效指标核验（适用于绩效评价项目）
1. 补贴资金对应的产出指标是否达成
2. 是否存在"只拿钱不出活"的情况
```

### 2. 资产清查

#### 对应案例
- **案例7**：粮食储备库亏库1.8万吨（5400万元），以虚增损耗、以旧顶新掩盖
- **案例11**：地方AMC以"协议转让"代替"公开挂牌"，低价处置不良资产损失7.2亿

#### 审计关注要点

| 风险点 | 具体表现 | 严重程度 |
|--------|---------|---------|
| 账实不符 | 账面库存与实际库存长期不一致 | 🔴高 |
| 虚假损耗 | 以虚增损耗掩盖亏库 | 🔴高 |
| 以旧顶新 | 轮换时以次充好、以旧顶新 | 🔴高 |
| 低价处置 | 协议转让替代公开挂牌，向关联方输送 | 🔴高 |
| 或有负债 | 未披露的对外担保 | 🟡中 |

#### 检查程序

```
一、实物盘点比对
1. 获取最新库存台账/资产台账
2. 现场抽盘，样本量不低于账面价值的60%
3. 重点关注：
   - 大宗物资（粮食、建材等可消耗品）
   - 三年以上未变动的固定资产
   - 已处置但未销账的资产

二、出入库/变动记录核验
1. 调取近3年所有出入库单据
2. 与财务账面逐月比对，找差异月份
3. 重点核查"损耗率异常偏高"的期间

三、资产处置合规性审查
1. 获取近3年资产处置清单
2. 逐项检查：
   - 是否有评估报告（评估基准日是否合理）
   - 处置方式是否经审批（协议转让 vs 公开挂牌）
   - 受让方是否为关联方
   - 成交价 vs 评估价的偏离度

四、账外资产与或有负债排查
1. 查询企业信用报告，核对担保信息
2. 向银行函证，核实对外担保情况
3. 访谈资产管理部门负责人，询问账外资产线索
```

### 3. 专项债申报

#### 对应案例
- **案例2**：城投公司虚构购销合同，虚增应收账款4.6亿骗取银行贷款
- **案例4**：科技集团虚报研发费用套取补贴（同理适用于虚增项目投资额）

#### 审计关注要点

| 风险点 | 具体表现 | 严重程度 |
|--------|---------|---------|
| 虚构收入/资产 | 关联企业间虚构合同做大资产规模 | 🔴高 |
| 项目投资虚增 | 虚增项目投资总额，骗取更多债券资金 | 🔴高 |
| 资金用途偏离 | 债券资金未按申报用途使用 | 🔴高 |
| 偿债能力包装 | 虚增收益预测，掩盖真实偿债风险 | 🔴高 |

#### 检查程序

```
一、申报材料真实性核验
1. 获取专项债申报全套材料
2. 重点核实：
   - 项目可研报告 vs 实际建设内容
   - 投资估算 vs 已签订合同金额
   - 收益预测 vs 同类项目历史数据

二、上下游合同穿透核查
1. 选取申报项目中金额最大的前5笔合同
2. 向合同相对方发函询证
3. 查验合同对应的发货单、验收单、发票
4. 识别关联交易——查股权穿透，确认双方是否存在关联关系

三、资金使用跟踪
1. 获取债券资金专户银行流水
2. 逐笔追踪大额支出（>100万）的最终去向
3. 防止：债券资金→施工方→回流至申报单位或其关联方

四、收益实现验证（事后评价）
1. 比对申报时的收益预测与实际运营数据
2. 差距超过30%的，追溯原因
```

### 4. 监督检查

#### 对应案例
- **案例1**：能源集团工资总额外违规发放奖金1837万
- **案例3**：建筑企业挂靠项目私设小金库2800万
- **案例5**：医院耗材采购吃回扣370万
- **案例6**：国企违规对外担保8.9亿（其中代偿2.3亿）
- **案例8**：教育集团违规收费6800万账外管理

#### 审计关注要点

| 风险点 | 具体表现 | 严重程度 |
|--------|---------|---------|
| 薪酬违规 | 工资总额外另设名目发放 | 🔴高 |
| 小金库 | 账外资金循环，截留项目款 | 🔴高 |
| 采购回扣 | 供应商按比例返点 | 🔴高 |
| 违规担保 | 未经审批对外提供连带责任担保 | 🔴高 |
| 账外收费 | 收费不入法定账簿 | 🔴高 |

#### 检查程序

```
一、薪酬合规检查
1. 获取被检查单位工资总额批复文件
2. 调取近3年全部工资奖金发放明细
3. 交叉比对：
   - 工资总额批复数 vs 实际发放数
   - 工资表 vs 银行代发流水（查是否存在"第二张工资表"）
   - 奖金名目 vs 审批文件
4. 注意"专项奖励""考核兑现""特别贡献"等非常规名目

二、小金库排查
1. 获取全部银行账户清单（含已销户）
2. 向所有开户银行发函询证
3. 检查项目部、分公司层级的资金收支
4. 重点关注：
   - 以"管理费""协调费"名义的收款
   - 现金收款未入账
   - 个人账户大额资金往来
   - 员工举报线索

三、采购合规检查
1. 选取近3年采购金额最大的前10家供应商
2. 检查：
   - 供应商遴选程序是否合规
   - 采购价 vs 市场同期价格
   - 付款节奏是否异常（预付比例过高、付款过快）
3. 关联关系排查：供应商股东/实际控制人是否与被检查单位人员有关联
4. 关键岗位人员（采购、设备科等）个人账户大额资金排查

四、对外担保检查
1. 获取企业信用报告
2. 向银行函证担保信息
3. 检查担保合同、董事会/股东会决议
4. 评估被担保方偿债能力
5. 计算担保余额占净资产比例

五、收费合规检查
1. 获取收费许可证/备案文件
2. 比对收费标准与实际收费
3. 追踪所有收费资金去向
4. 重点排查：以"赞助费""培训费""材料费"等名义的额外收费
```

### 5. 工程结算 / 财政评审

#### 对应案例
- **案例9**：水务集团监理与施工单位串通，虚报工程结算款1.4亿
- **案例3**：建筑企业挂靠项目，管理费截留形成小金库

#### 审计关注要点

| 风险点 | 具体表现 | 严重程度 |
|--------|---------|---------|
| 虚报工程量 | 多报土方、钢筋、混凝土等工程量 | 🔴高 |
| 高套定额 | 高套或错套计价定额子目 | 🔴高 |
| 材料价差 | 虚高材料单价 | 🟡中 |
| 监理串通 | 监理与施工方合谋签认虚假工程量 | 🔴高 |
| 挂靠截留 | 挂靠方截留项目资金不入账 | 🔴高 |

#### 检查程序

```
一、工程量核实
1. 获取竣工图纸、施工日志、监理日志
2. 选取结算金额占比最大的3-5个分部工程
3. 现场随机抽测：
   - 道路工程：钻芯取样测厚度
   - 管网工程：抽段开挖核实长度、管径
   - 房建工程：抽测建筑面积、钢筋含量
4. 比对结算量、预算量、实际完工量三方数据

二、计价审核
1. 核对定额套用是否正确
2. 检查取费标准、取费基数是否合规
3. 材料价格与同期信息价/市场询价比对

三、监理独立性审查
1. 获取监理日志、旁站记录
2. 比对监理记录与施工日志的一致性
3. 关注：工程量签证单签认日期是否集中、签认人是否异常
4. 延伸检查监理公司与施工单位是否存在关联关系或利益往来

四、资金流向追踪
1. 追踪工程款支付链条：业主→总包→分包→实际施工方
2. 比对合同约定付款比例与实际付款比例
3. 关注以"管理费""配合费"名义的截留

五、变更与签证核查
1. 统计变更金额占合同金额的比例（>30%重点查）
2. 逐项检查设计变更、现场签证的合理性
3. 关注"先干后批""边干边批"的签证
```

## 三、通用进场检查清单（快速版）

入场第一周快速扫描，48小时内形成初步风险判断：

```
□ 获取近3年审计报告、巡视整改报告
□ 获取组织架构图、子公司/分公司清单
□ 获取银行账户清单（含已销户），向主要银行发询证函
□ 获取近3年工资总额批复及实际发放汇总
□ 获取关联方清单及关联交易明细
□ 获取对外担保台账
□ 获取近3年大额采购/工程合同清单（前20大）
□ 获取财政补贴申报及到账情况汇总表
□ 抽查最近一个月的库存盘点记录
□ 访谈财务负责人、内审负责人各不少于1小时
□ 建立举报渠道并公告
```
