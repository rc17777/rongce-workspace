# 审计报告质量检查清单（十大维度）

> 来源：浙江省审计厅《撰写出彩的审计报告，应重点关注的十项内容》
> 转载：东营审计（2026-06-09）
> 用途：报告复核模块（ReviewFilter / ReviewReportGenerator）质量评分参考

---

## 一、审计评价的恰当性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 1.1 | 评价围绕审计目标，不涉及未审计事项 | ☐ | ☐ |
| 1.2 | 未对党建、人事任命等超越审计职责范围的事项发表评价 | ☐ | ☐ |
| 1.3 | 正面评价与问题概括并存，且不前后矛盾 | ☐ | ☐ |
| 1.4 | 定性评价与定量评价相结合 | ☐ | ☐ |
| 1.5 | 未用静态/历史指标做简单定量评价 | ☐ | ☐ |
| 1.6 | 未用单个事实或几个指标评价整体情况 | ☐ | ☐ |
| 1.7 | 考虑了投入产出的滞后性、打基础利发展的复杂性 | ☐ | ☐ |
| 1.8 | 评价证据适当充分，无"全心全意""千方百计"等难于取证的主观评价 | ☐ | ☐ |

**常见问题：** 评价不恰当、与问题前后矛盾、证据不充分、超越审计职责

## 二、问题定性的准确性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 2.1 | 定性围绕审计目标和被审计对象 | ☐ | ☐ |
| 2.2 | 定性不模棱两可、不含糊其词、不似是而非 | ☐ | ☐ |
| 2.3 | 未超越审计职权定性（如与预算无关的超编问题等） | ☐ | ☐ |
| 2.4 | 无不与审计目标无关的揭示范例（如测试数据未删除纳入同级审报告） | ☐ | ☐ |
| 2.5 | 无小题大做、避重就轻、以偏概全 | ☐ | ☐ |
| 2.6 | 大数据筛选信息已核实取证并签证 | ☐ | ☐ |
| 2.7 | 审前自查/内审自纠、已全部整改、已无法整改的问题，风险可控的不作问题定性 | ☐ | ☐ |
| 2.8 | 定性小标题采用"性质+数量金额比例"写实表述 | ☐ | ☐ |
| 2.9 | 未用不定量词、主观结论词、"建议式"定性 | ☐ | ☐ |
| 2.10 | 数据无逻辑错误（余额≠发生额、总计≠分项合计、比例计算正确） | ☐ | ☐ |
| 2.11 | 未出现"不到位""不够到位""还不够到位"等无实质区别的定性 | ☐ | ☐ |

**禁止词清单：** 不到位 / 不够到位 / 还不够到位 / 建议式定性 / 主观结论词

---

## 三、事实表述的清晰性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 3.1 | 六要素齐全：时间、地点、起因、经过、结果、涉及人员 | ☐ | ☐ |
| 3.2 | 复杂问题已过滤无关干扰因素，关键信息突出 | ☐ | ☐ |
| 3.3 | 相关人员身份、职务、责任明确（国家工作人员/国家机关工作人员；主体责任/直接责任/监督责任/管理责任） | ☐ | ☐ |
| 3.4 | 能定量表述的未用定性表述，多用数据"说话" | ☐ | ☐ |
| 3.5 | 无"审计认为"等主观判断词 | ☐ | ☐ |
| 3.6 | 无"严重亏损""非常缓慢"等强调程度的词 | ☐ | ☐ |
| 3.7 | 无"看起来好像是""可能是由于"等模棱两可表述 | ☐ | ☐ |
| 3.8 | 无"没有""所有"等绝对化表述 | ☐ | ☐ |
| 3.9 | 表述事实与定性小标题匹配 | ☐ | ☐ |
| 3.10 | 事实有相关证据支撑 | ☐ | ☐ |

**禁止词清单：** 审计认为 / 严重 / 非常 / 极其 / 好像 / 可能 / 没有（绝对化）/ 所有（绝对化）

## 四、依据引用的合理性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 4.1 | 依据层次正确（法律→行政法规→部门规章→规范性文件） | ☐ | ☐ |
| 4.2 | 遵循上位法优于下位法、特殊法优于普通法、后法优于前法 | ☐ | ☐ |
| 4.3 | 依据适用对象、范围、内容正确 | ☐ | ☐ |
| 4.4 | 未用现行依据衡量过去事项 | ☐ | ☐ |
| 4.5 | 未用与现行改革不符的旧依据衡量新事项 | ☐ | ☐ |
| 4.6 | 多依据不一致时选用了权威公认程度最高的 | ☐ | ☐ |
| 4.7 | 同类问题依据引用一致（原因不同则依据可不同） | ☐ | ☐ |
| 4.8 | 多违规时主次清楚，未引用多个关联性低的依据 | ☐ | ☐ |
| 4.9 | 引用"参照执行"条款时已甄别前提条件 | ☐ | ☐ |
| 4.10 | 未将处理处罚种类条文/原则性规定作为定性依据 | ☐ | ☐ |
| 4.11 | 未将审计机关非执法主体的法规作为处理处罚依据 | ☐ | ☐ |
| 4.12 | 处理处罚依据不能作为定性依据（特殊例外除外） | ☐ | ☐ |

**关键规则：**
- 处罚处分条例/规定 → 只能作处理处罚依据，不能作定性依据
- 只有定性依据、无处理处罚依据 → 定性依据可作处理处罚依据
- 处理处罚依据 → 绝不能作定性依据

## 五、处理处罚的合法性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 5.1 | 限于审计法第45条种类（责令改正、收缴、退还、警告、罚款、没收违法所得） | ☐ | ☐ |
| 5.2 | 未行使责令停业、暂扣/吊销许可证等超职权处罚 | ☐ | ☐ |
| 5.3 | 未作出"降低收费标准""追究责任人党纪政务责任"等超出审计职权的决定 | ☐ | ☐ |
| 5.4 | 审计报告征求意见稿中已提出具体明确的处理处罚意见 | ☐ | ☐ |
| 5.5 | 未用"将出具审计决定"代替处理处罚意见 | ☐ | ☐ |
| 5.6 | 已考虑从轻/减轻/免于处理处罚的情节（及时整改、情节轻微等） | ☐ | ☐ |
| 5.7 | 不属于法定职权范围的问题已移送相关职能部门 | ☐ | ☐ |
| 5.8 | 处罚意见符合行政处罚法（2年追诉期、无重复罚款、听证权利告知、15日缴纳期） | ☐ | ☐ |
| 5.9 | 未以审计处理代替审计处罚，或以审计处罚代替审计处理 | ☐ | ☐ |
| 5.10 | 最终处理意见加重时已告知被审计对象并听取陈述申辩 | ☐ | ☐ |
| 5.11 | 救济途径和期限表述准确 | ☐ | ☐ |

## 六、责任界定的科学性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 6.1 | 遵循权责一致、实事求是原则 | ☐ | ☐ |
| 6.2 | 符合"三个区分开来"要求 | ☐ | ☐ |
| 6.3 | 考虑了历史背景、决策程序、实际决策过程 | ☐ | ☐ |
| 6.4 | 遵循实质重于形式原则 | ☐ | ☐ |
| 6.5 | 未简单以主持会议/签批文件/直接分管/具体知悉作为界定标准 | ☐ | ☐ |
| 6.6 | 既关注显性后果（资金损失），也关注隐性后果（影响持续发展） | ☐ | ☐ |
| 6.7 | 有充分证据，有由事及人的说理性表述 | ☐ | ☐ |
| 6.8 | 厘清了集体决策与个人主张的界限 | ☐ | ☐ |
| 6.9 | 厘清了决策与监管的界限 | ☐ | ☐ |
| 6.10 | 厘清了决策失误与管理不力的界限 | ☐ | ☐ |
| 6.11 | 厘清了决策责任和执行责任的界限 | ☐ | ☐ |
| 6.12 | 厘清了工作失职与工作失误的界限 | ☐ | ☐ |
| 6.13 | 厘清了主观故意与客观制约无意过失的界限 | ☐ | ☐ |
| 6.14 | 厘清了党委与行政的界限 | ☐ | ☐ |
| 6.15 | 厘清了前任与后任的界限 | ☐ | ☐ |
| 6.16 | 最终界定为直接责任或领导责任 | ☐ | ☐ |

**八大界限速查：** ①集体决策/个人主张 ②决策/监管 ③决策失误/管理不力 ④决策责任/执行责任 ⑤工作失职/工作失误 ⑥主观故意/客观过失 ⑦党委/行政 ⑧前任/后任

## 七、审计建议的操作性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 7.1 | 针对具体问题及原因提出具体措施 | ☐ | ☐ |
| 7.2 | 未以应知应会内容（如"遵守财经纪律"）代替建议 | ☐ | ☐ |
| 7.3 | 需要多单位共同整改的，已建议商有关单位共同解决 | ☐ | ☐ |
| 7.4 | 针对共性问题/新问题，从体制、制度、机制角度提出治本建议 | ☐ | ☐ |
| 7.5 | 未用审计建议代替揭示问题 | ☐ | ☐ |
| 7.6 | 未用审计建议代替处理处罚 | ☐ | ☐ |
| 7.7 | 建议不超越审计和被审计对象职权范围 | ☐ | ☐ |
| 7.8 | 未突破现有政策规定（如增加编制、增加投资） | ☐ | ☐ |
| 7.9 | 无违反财经政策规定的建议 | ☐ | ☐ |
| 7.10 | 建议数量3-5条 | ☐ | ☐ |

## 十、报告格式的规范性 ✅

| # | 检查项 | 合格 | 不合格 |
|---|--------|------|--------|
| 10.1 | 以第三人称撰写 | ☐ | ☐ |
| 10.2 | 同类问题按性质归类，按重要性排序 | ☐ | ☐ |
| 10.3 | 架构层次合理，点面结合，不重复不漏项不交叉 | ☐ | ☐ |
| 10.4 | 国有资产流失/财政资金损失等问题在前 | ☐ | ☐ |
| 10.5 | 拟实质处理处罚的问题在前 | ☐ | ☐ |
| 10.6 | 拟移送追究刑责/党纪政务责任的问题在前 | ☐ | ☐ |
| 10.7 | 本级问题在前，下属单位/延伸问题在后 | ☐ | ☐ |
| 10.8 | 共性问题在前，个性问题在后 | ☐ | ☐ |
| 10.9 | 定责问题在前，督查整改问题在后 | ☐ | ☐ |
| 10.10 | 未按被审计对象、资金种类、会计要素分类 | ☐ | ☐ |
| 10.11 | 简称、数量金额单位、问题日期表述前后一致 | ☐ | ☐ |
| 10.12 | 小数点后保留2位 | ☐ | ☐ |
| 10.13 | 复杂问题可视情况一段或多段反映（事实+定性+依据+处理+整改+定责） | ☐ | ☐ |
| 10.14 | 基本情况、审计评价、问题、建议之间不矛盾 | ☐ | ☐ |
| 10.15 | 结尾含整改和公告相关表述 | ☐ | ☐ |
| 10.16 | 经济责任/自然资源资产离任审计报告含救济途径和期限 | ☐ | ☐ |

**排序规则速查：**
```
①国有资产流失/财政损失 → ②实质处理处罚 → ③移送追责
  ↓
④本级问题 → ⑤下属/延伸问题
  ↓
⑥共性问题 → ⑦个性问题
  ↓
⑧定责问题 → ⑨督查整改问题
```

## 综合评分计算

| 维度 | 权重 | 满分 | 得分 |
|------|------|------|------|
| 一、审计评价恰当性 | 10% | 8 |  |
| 二、问题定性准确性 | 15% | 11 |  |
| 三、事实表述清晰性 | 12% | 10 |  |
| 四、依据引用合理性 | 12% | 12 |  |
| 五、处理处罚合法性 | 12% | 11 |  |
| 六、责任界定科学性 | 12% | 16 |  |
| 七、审计建议操作性 | 10% | 10 |  |
| 八、采纳意见合理性 | 5% | 10 |  |
| 九、同类问题一致性 | 5% | 8 |  |
| 十、报告格式规范性 | 7% | 16 |  |
| **合计** | **100%** | **112** |  |

**评分公式：** 综合得分 = Σ(各维度得分 / 该维度满分 × 权重) × 100

**等级：**
- ≥90：优秀
- 80-89：良好
- 70-79：合格
- 60-69：需修改
- <60：退回重写

## 集成到 ReviewFilter 模块

本清单可直接映射为 ReviewFilter 的检测规则：

1. **硬规则（一票否决）：** 定性无依据、无证据支撑事实、处理处罚越权、救济途径缺失
2. **禁止词规则（自动扫描）：** 主观评价词、程度强调词、模糊词、绝对化词
3. **一致性规则（交叉校验）：** 定性标题 vs 事实表述、同类问题横向对比、数据逻辑校验（余额/发生额/比例）
4. **结构规则（格式校验）：** 第三人称、问题排序、小数位、前后术语一致
5. **权重评分规则：** 按上述权重综合打分，<0.85 触发三级复核
