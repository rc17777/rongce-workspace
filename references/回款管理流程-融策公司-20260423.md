# 融策公司回款管理流程与工具

## 一、管理目标
1. 缩短回款周期，改善现金流
2. 降低坏账风险
3. 提升客户付款配合度
4. 与绩效激励有效结合

## 二、核心原则
1. **事前预防**：合同条款设计
2. **事中跟踪**：过程管理
3. **事后处理**：逾期应对
4. **数据驱动**：持续优化

## 三、回款管理全流程

### 3.1 签约前阶段（预防）

#### 客户信用评估
```
信用等级 = 客户类型 + 历史记录 + 付款能力
```

**客户分类标准：**
- **A类客户**（优质）：政府机构、大型国企、上市公司
  - 付款条件：预付款30%，进度款40%，验收后30%
  - 信用额度：可适当放宽
  
- **B类客户**（良好）：中型企业、事业单位
  - 付款条件：预付款30-50%，余款分期
  - 信用额度：适度控制
  
- **C类客户**（谨慎）：小微企业、新客户
  - 付款条件：预付款50%以上，余款验收前付清
  - 信用额度：严格限制

#### 合同条款设计（标准模板）
1. **付款条款**：
   ```
   第一期：合同签订后3个工作日内支付30%
   第二期：项目中期报告提交后支付40%
   第三期：项目验收合格后7个工作日内支付30%
   ```

2. **逾期条款**：
   - 逾期30天内：按日收取0.05%滞纳金
   - 逾期30-60天：暂停后续服务
   - 逾期60天以上：法律途径解决

3. **保障条款**：
   - 发票开具与付款分离
   - 保留项目成果所有权直至全款付清

### 3.2 项目执行阶段（跟踪）

#### 回款跟踪表（Excel/系统模板）

| 项目编号 | 客户名称 | 合同金额 | 应收金额 | 应收日期 | 实际回款 | 回款日期 | 逾期天数 | 责任人 | 状态 |
|---------|---------|---------|---------|---------|---------|---------|---------|--------|------|
|          |          |          |          |          |          |          |          |        |      |

**状态标签：**
- 🟢 正常（未到期）
- 🟡 预警（到期前7天）
- 🟠 逾期（1-30天）
- 🔴 严重逾期（31-60天）
- ⚫ 坏账风险（60天以上）

#### 回款提醒流程
```
到期前15天 → 首次提醒（邮件/微信）
到期前7天 → 正式催款函
到期当天 → 电话确认
逾期7天 → 项目经理上门
逾期15天 → 部门负责人介入
逾期30天 → 公司管理层处理
```

### 3.3 逾期处理阶段（应对）

#### 逾期账款分级处理

**一级逾期（1-30天）：**
- 责任人：项目经理
- 措施：电话沟通、发送催款函
- 目标：30天内解决90%以上

**二级逾期（31-60天）：**
- 责任人：部门负责人
- 措施：上门拜访、协商还款计划
- 目标：60天内解决80%以上

**三级逾期（61-90天）：**
- 责任人：公司管理层
- 措施：法律咨询、律师函
- 目标：控制损失，部分回收

**四级逾期（90天以上）：**
- 责任人：法务/外部律师
- 措施：法律诉讼、资产保全
- 目标：最大限度减少损失

### 3.4 数据分析与优化

#### 关键指标监控
1. **回款周期**：平均回款天数（目标：<60天）
2. **逾期率**：逾期金额/应收金额（目标：<5%）
3. **坏账率**：坏账金额/营业收入（目标：<1%）
4. **回款成本**：催收成本/回款金额

#### 月度回款分析报告
- 回款情况总结
- 问题客户分析
- 流程改进建议
- 团队绩效评估

## 五、与绩效激励的衔接

### 5.1 回款绩效计算
```
回款绩效得分 = 基础分 × 回款速度系数 × 回款质量系数
```

**回款速度系数：**
- 提前回款：1.2
- 按时回款：1.0
- 轻微逾期（<15天）：0.8
- 严重逾期（>15天）：0.5

**回款质量系数：**
- 全额回款：1.0
- 部分回款：按比例计算
- 坏账：0（且可能倒扣）

### 5.2 团队回款奖励
- **部门回款达标奖**：部门回款率>95%，奖励部门5000-10000元
- **季度回款冠军**：回款金额最高且逾期率最低的员工，奖励2000元
- **年度回款优秀团队**：奖励团队旅游或奖金
