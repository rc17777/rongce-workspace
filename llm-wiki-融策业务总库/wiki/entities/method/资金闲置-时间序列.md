# 专项债资金闲置检测 — 时间序列

## 审计问题
专项债资金到位后是否长期闲置未使用？是否存在资金沉淀浪费（利息照付、资金不用）？

## 核心逻辑
追踪专项债资金从到账到支出的时间间隔。资金到位后长时间未支出 = 项目未实质开工或进度严重滞后，产生空转利息成本。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 债券名称 | 专项债项目名称 | 债券发行文件 |
| 到账日期 | 资金拨付到项目单位日期 | 国库支付/银行流水 |
| 支出日期 | 每笔支出的日期 | 专账/序时账 |
| 支出金额 | 每笔支出金额 | 专账 |
| 债券余额 | 截至期末未支出余额 | 专账 |
| 债券利率 | 年利率 | 发行文件 |

## 检测逻辑

```
Step 1: 计算 资金闲置天数 = 支出日期 - 到账日期
       计算 资金闲置率 = 截至期末余额 / 到账总额 × 100%
Step 2: 标记规则：
  到账后30天内无任何支出 → 资金未启用
  到账后90天支出率 < 30% → 严重闲置
  到账后180天支出率 < 50% → 项目实质停滞
Step 3: 计算闲置成本：
  空转利息 = 平均闲置余额 × 利率 × 闲置天数/365
Step 4: 批量统计：所有专项债项目的闲置率排名
```

## 阈值/参数
- 30天零支出 → 资金未启用
- 90天支出率 < 30% → 严重闲置
- 180天支出率 < 50% → 实质停滞

## 典型发现
- 某项目债券资金1.2亿到账9个月，支出仅800万 → 支出率6.7%，空转利息约400万
- 5个项目闲置率超70%，合计闲置资金3.5亿 → 系统性沉淀

## 局限性
- 部分资金可能已拨付到施工单位但未确认支出（预付账款）
- 需区分"项目未开工"和"按进度付款"两种闲置原因
