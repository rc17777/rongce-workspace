# GPT Image2 融策方案快速原型工作流

> 基于「GPT Image2 考研快题方案生成」的五步加速法，适配为：
> **标书版式 / 审计报告结构 / 工程方案图 / PPT 汇报版式** 四大融策场景的快速原型工作流。
>
> 核心迁移逻辑：考研生用 AI 跑 50 个构图 → 融策用 AI 跑 50 个版式/结构/方案

---

## 零、方法论对比

| 考研快题方法 | 融策场景映射 | 价值 |
|-------------|-------------|------|
| 方法一：批量构图方向 | 标书封面/内页版式规模生成 | 一小时的工作变十秒 |
| 方法二：抽象主题拆解 | 审计发现→可视化元素映射 | 把"内控缺陷"变成可画的图形 |
| 方法三：风格碰撞定调 | 政府严肃+企业现代混搭 | 找到合规与美观的平衡点 |
| 方法四：元素替换一变三 | 工程方案图多版本对比 | 甲方三选一，AI 三秒出 |
| 方法五：情绪板反推 | 从参考案例提炼设计语言 | 把"领导喜欢的那个风格"变成可复用的提示词 |

## 一、标书版式快速原型（对应方法一+四）

### 场景：标书封面/内页版式规模生成

**痛点**：手动调一个封面版式要半小时，甲方要三版对比就是半天。

**AI 加速法**：

```
我是一个标书编制人员，需要为「XX项目工程咨询服务」制作标书封面。
请给我 10 个完全不同的封面版式方案，用简洁的视觉关键词描述每一个：
- 构图方式（居中/左对齐/分割线/框式等）
- 图形元素（建筑线稿/数据折线/抽象几何/地图轮廓等）
- 图文排布关系（上图下文/左图右文/全图叠字等）
- 风格倾向（政务庄重/科技现代/国风典雅/极简留白）
```

### 场景：元素替换快速变体

选好一个版式后：

```
保持以下封面构图不变，把主体图形依次换成：
1. 项目所在城市的地标建筑剪影
2. 工程结构 BIM 线框透视图
3. 抽象折线组成的数据山脉
生成三个版本，保留相同的标题区域位置和配色方案。
```

## 二、审计报告结构可视化（对应方法二+三）

### 场景：把抽象审计概念变成可呈现的视觉元素

**痛点**："内部控制薄弱""资金管理不规范"这些抽象结论，怎么画成图？

**AI 拆解法**：

```
请把以下审计概念拆解成可用于信息图设计的视觉元素：
概念：「内部控制薄弱」
- 图形方向：破裂的盾牌？漏水的桶？有缺失环节的链条？
- 质感倾向：金属锈蚀？玻璃裂缝？纸张破损？
- 色彩倾向：警示红+灰底 or 暗金褪色？
- 可用的象征符号：断裂的锁链、缺页的文件、空洞的保险箱
- 适合的信息图类型：流程图/对比图/热力图/雷达图
```

### 场景：审计报告风格定调（风格碰撞）

**痛点**：政府审计报告太僵硬像法院判决书，太活泼领导说不够严肃。

**风格碰撞法**：

```
请混合以下两种风格生成审计报告封面/内页版式：
- 60% 政府公文正式感的清晰布局 + 40% 商业咨询报告的现代信息图表质感
- 配色保留政府蓝的庄重基调，加入少量铜金色作为数据高亮色
- 字体排布：标题用政府公文规格，数据板块用商业报告卡片式布局
```

## 三、工程方案图多版本对比（对应方法四）

### 场景：施工组织设计 / 平面布置图的多方案比选

**痛点**：施工总平布置、临时设施布局，通常要画三四版给甲方挑。

**AI 加速法**：

```
基于以下基础描述生成 5 个不同的施工现场总平面布置方案图：
「某中学新建教学楼项目，用地面积 12000㎡，拟建一栋 5 层教学楼、
一栋 3 层实验楼，需要布置塔吊 2 台、材料堆场、钢筋加工棚、
办公生活区、施工道路——所有元素不得超出用地红线。」

每个方案用不同的布局逻辑：
1. 塔吊居中覆盖全场的集中式
2. 分区施工的东西分区式
3. 沿道路线性展开的条带式
4. 以材料堆场为核心的辐射式
5. 预留二期用地的退让式
```

### 场景：方案对比决策图

生成一张施工方案比选决策矩阵图。3 方案（左中右三列）× 5 评价维度（工期/成本/质量/安全/环保，从上到下五行），每个单元格铜金色=优、青绿色=中、暖灰色=差。顶部放置推荐方案标签。9:16 竖版。

## 四、PPT 汇报版式快速定稿（对应方法三+五）

### 场景：从"领导喜欢的参考案例"反推提示词

**痛点**：领导丢过来几张别人家的 PPT 说"就按这个风格做"，但说不清到底喜欢什么。

**情绪板反推法**：

```
请分析以下我描述的参考 PPT 风格，提炼出可复用的设计语言：
- 封面是大面积深蓝色 + 一张项目现场航拍图半透明叠加
- 内页左侧始终有一根金色竖线贯穿，右侧排布图表
- 数据页用深色卡片承载白色数字，关键数据用金色
- 流程图节点是 3D 立体方块，用青绿色做进度高亮

请输出：
1. 这个风格的三个核心设计原则
2. 可复用的配色参数
3. 三个不同场景下（封面/数据页/流程图）的 GPT Image2 提示词
```

## 五、融策五大场景的标准 AI 加速指令模板

### 模板 A：批量版式生成（标书/报告封面）

```
我需要为 [项目类型] 设计 [封面/内页] 版式。
请给我 10 个完全不同的版式方案，用简洁的关键词描述每一版：
- 构图方式：______
- 图形元素：______
- 图文关系：______
- 风格倾向：______
配色约束：深蓝#0A1F3F 为主调，铜金#C5955C 为点缀
目标受众：[评审专家/政府领导/企业高管]
```

### 模板 B：抽象概念视觉化（审计/管理报告）

```
请把以下专业概念拆解成可视化设计元素：
概念：「[抽象概念，如资金沉淀/绩效偏差/内控漏洞]」
请输出：
- 3 个图形隐喻方向
- 推荐信息图类型（柱状/流程/雷达/桑基/矩阵）
- 配色倾向和象征符号
- 一个可直接使用的 GPT Image2 提示词
```

### 模板 C：多方案比选（工程/设计方案）

```
基于以下约束条件生成 [N] 个不同方案：
项目：[一句话描述]
约束：[用地/预算/工期/规范要求]
每个方案描述不超过 50 字，标注核心差异点和适用场景。
然后生成一张方案比选矩阵图提示词。
```

---

## 六、使用说明

- 所有加速指令模板可直接向 GPT Image2 或 ChatGPT 对话使用
- "方法一"到"方法五"是思考框架，模板 A/B/C 是操作工具
- 配色默认融策体系，可根据项目调整
- 生成的提示词可进一步让 GPT Image2 出图
