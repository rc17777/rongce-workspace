# 项目进度滞后检测 — 对比模型

## 审计问题
专项债项目建设进度是否严重滞后？支出进度与形象进度是否匹配？

## 核心逻辑
对比"计划进度""实际支出进度""实际工程进度"三者关系。支出快但工程慢=资金可能被挪用；支出慢工程也慢=项目停摆。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 项目名称 | 债券项目名称 | 一案两书 |
| 计划工期 | 计划开工-竣工时间 | 实施方案 |
| 实际开工日期 | 实际开工 | 项目台账 |
| 计划进度% | 截至当前计划完成% | 实施方案 |
| 实际进度% | 实际工程完成% | 监理报告 |
| 支出进度% | 累计支出/总投资 | 专账 |
| 总投资 | 项目总投资额 | 一案两书 |

## 检测逻辑

```
Step 1: 三级对比：
  支出进度% vs 计划进度% vs 实际进度%
Step 2: 异常模式识别：
  模式A: 实际进度 << 计划进度 AND 支出进度正常 → 施工单位问题
  模式B: 实际进度 << 计划进度 AND 支出进度也低 → 资金未到位/项目停摆
  模式C: 支出进度 >> 实际进度 → 按进度付款异常，资金去向可疑
  模式D: 三者都低但工期已过半 → 几乎确定无法按期完工
Step 3: 按滞后程度排名，最严重的项目重点延伸
```

## 阈值/参数
- 进度滞后 > 30%：严重滞后
- 支出-实际进度差 > 20%：资金去向异常
- 工期过半实际进度 < 20%：大概率烂尾

## 典型发现
- 某项目工期2年，已过18个月，计划进度75%，实际进度15% → 几乎烂尾
- 支出进度65%，实际工程进度10% → 资金已大部分支出但工程未动 → 挪用

## 局限性
- 实际进度数据依赖监理报告，可能被美化
- 需现场核实形象进度
