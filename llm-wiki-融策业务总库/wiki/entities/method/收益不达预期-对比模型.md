# 收益不达预期检测 — 对比模型

## 审计问题
专项债项目实际收益是否达到申报时承诺的水平？收益缺口是否影响偿债能力？

## 核心逻辑
逐项对比"申报预测收益"与"实际实现收益"，计算偏差。收益严重不达标意味着项目可行性论证失真或执行偏差，最终影响偿债。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 债券项目名称 | 项目名称 | 一案两书 |
| 预测年收益 | 申报时预测的年度净收益 | 实施方案 |
| 实际年收益 | 实际产生的净收益 | 项目财务报表 |
| 预测覆盖倍数 | 预测收益/年度本息 | 实施方案 |
| 项目状态 | 在建/完工/运营 | 项目台账 |
| 运行年度 | 投入运营第几年 | — |

## 检测逻辑

```
Step 1: 筛选已进入运营期的项目
Step 2: 计算 收益达成率 = 实际年收益 / 预测年收益 × 100%
Step 3: 分级标记：
  达成率 ≥ 80% → 基本达标
  50% ≤ 达成率 < 80% → 收益偏弱，关注
  达成率 < 50% → 🔴 严重不达标
Step 4: 计算 实际覆盖倍数 = 实际收益 / 年度本息
  覆盖倍数 < 1 → 收益无法覆盖本息，偿债风险
Step 5: 与同类型项目横向对比，看是单项问题还是系统性问题
```

## 阈值/参数
- 达标线：80%
- 严重不达标线：50%
- 覆盖倍数 < 1 → 偿债风险
- 仅统计已投入运营满1年的项目

## 典型发现
- 某停车场项目预测年收益600万，实际120万 → 达成率20%，可行性论证严重失真
- 8个运营项目中5个覆盖倍数 < 1 → 系统性收益高估问题

## 局限性
- 仅适用于有收益的专项债项目（公益性项目无收益指标）
- 新投入运营项目需给爬坡期
