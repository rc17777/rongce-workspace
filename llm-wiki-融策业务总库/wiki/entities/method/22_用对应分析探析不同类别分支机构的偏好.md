内容导读：在数据分析过程中，不仅仅要关注行、列变量，还要考虑行变量和列变量的相互关系，这才符合认知事物规律的常识。

## 面临的问题

每年初在对公司不同类型的分支机构进行风险评估时，往往需要了解各分公司的经营管理偏好。但在分公司情况差异较大、指标较多的情况下，并不能判断这些公司具有相类似的偏好。

## 对应分析（Correspondence Analysis）

对应分析是一种降维分析方法，通过行列变量构成的交叉表，揭示数据整体的内在联系、同一变量在不同类别上的差异、不同变量与类别之间的对应关系。由法国统计学家 J.P.Benzenci 提出。

## R语言对应分析功能包

- **MASS包**：提供 corresp()、mca() 函数
- **ca包**：提供 ca()、mjca()、plot.ca() 等函数

```r
# 直接从剪切板读取数据
df <- read.table("clipboard", header = TRUE)

# 引入ca包
library(ca)
# 进行简单对应分析
cal <- ca(df)
cal

# 基于距离的可视化
plot(cal, mass = TRUE)
```
