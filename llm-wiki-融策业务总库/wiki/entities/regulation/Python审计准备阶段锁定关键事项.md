# 运用Python技术在审计准备阶段锁定关键事项的方法

## 场景

某国家级经济技术开发区领导干部经济责任审计，体量庞大、区属二级机构和国企众多、时间跨度大、资料类型复杂（合同/会议纪要/工作报告/财务报表）。

## 痛点

审计准备阶段三大难点：**看不清审计对象、抓不住审计重点、找不到审计疑点**。

## 技术路线

```
.doc文档 → win32com转.docx → python-docx提取段落
    ↓
Jieba分词 → 停用词过滤 → 词频统计
    ↓
WordCloud词云 → 可视化锁定关键事项
    ↓
正则多关键词批量搜索 → 上下文提取 → 导出Excel
```

## 技术栈

| 库 | 用途 |
|----|------|
| `win32com` | .doc → .docx 格式转换 |
| `python-docx` | 提取.docx段落文本 |
| `jieba` | 中文分词 |
| `re` | 正则表达式多关键词匹配 |
| `pandas` | 数据结构化+导出Excel |
| `wordcloud` | 词云可视化 |
| `glob` | 遍历目录批量处理 |

## 两步法详解

### 第一步：词云锁定关键事项

1. 遍历会议纪要目录 → 提取所有段落文本
2. Jieba分词 → 过滤长度≤2的词 → 停用词过滤
3. 词频排序 → 取Top 200 → WordCloud词云
4. 从词云中识别审计重点：**"奖励""借款""规划""安置""税收""土地""协议"**

### 第二步：正则批量定位线索

1. 设置多关键词：`kw = "奖励|借款|规划|安置|税收|土地|协议"`
2. 正则匹配：关键词前后各取50字作为上下文摘要
3. 批量输出Excel：`文件名 | 段落号 | 关键词 | 上下文(前后50字)`

## 审计成效

揭示了该开发区五大问题：

| 问题 | 关键词来源 |
|------|-----------|
| 对外出借财政资金 | "借款" |
| 以奖励形式返还税收 | "奖励"+"税收" |
| 未按规定改变规划 | "规划" |
| 违规调整土地用途 | "土地" |
| 拆迁安置严重滞后 | "安置" |

结合会议纪要研究内容，准确界定了领导干部经济责任。

## 对融策的参考价值

1. **可直接复用**：技术栈简单（Python标准库+3个第三方库），Windows环境完全支持
2. **适用场景广**：
   - 经济责任审计 → 会议纪要+工作报告分析
   - 绩效评价 → 政策文件+项目档案关键词提取
   - 专项资金审计 → 合同文档+验收报告批量检索
3. **与现有技能互补**：
   - 配合 `multi-source-analysis` 作为非结构化数据预处理步骤
   - 配合 `finding-generator` 提供关键词→问题发现的线索链
4. **可技能化**：做成 `audit-text-mining` 技能，封装 doc转换→分词→词云→关键词定位→Excel 完整链路
