# 基于Apriori算法规则核查群体骗保问题

> 来源: 罗鑫（江苏省沭阳县审计局），《中国审计》2023年第16期
> 转载: 数智审Lab，2025-12-20

## 算法原理

Apriori算法是经典的关联规则算法，核心思想：找出事务数据集中最大的频繁项集，利用预设的最小置信度阈值生成强关联规则。

**关键概念**：
- **事务标识**: 一次事务的ID（如住院登记日期、投标项目编号）
- **项**: 事务中的元素（如患者编号、投标单位）
- **项集**: 零个或多个项的集合
- **支持度**: 项集在数据集中出现的频率
- **置信度**: 条件概率 P(Y|X)，即X出现时Y也出现的概率

## 两种审计应用方向

### 方向一：不应形成关联却形成

找出频繁共同出现的项（患者/供应商），即异常结队行为。

**医保案例**：不相关的多名患者出现3次以上同天住院 → 集体骗保疑点

**招投标对应**：不相关的投标人多次共同出现在同一项目中 → 围标疑点

### 方向二：应形成关联却未形成

找出应该同时出现但缺失的项，即缺失必要的关联。

**医保案例**：心脏搭桥手术用了电子输注泵却没用PTCA导丝 → 违规收费

**审计对应**：同一类项目中应有的标准流程/文件缺失 → 程序违规

## 实现步骤

### Step 1: 数据格式转换
HIS系统结构化数据 → Apriori半结构化格式
```python
# 以住院登记日期为事务标识，患者编号为项
result = {
    '2023-01-01': ['P001', 'P002', 'P003'],
    '2023-01-02': ['P001', 'P004'],
    ...
}
```

### Step 2: 求频繁1项集
单个项支持度 ≥ 阈值（如3次）

### Step 3: 求频繁2项集 + 置信度
两个项共同出现的支持度 ≥ 阈值 → 频繁2项集
置信度 = 2项集支持度 / 单项支持度

### Step 4: 求频繁3项集
同上逻辑递推，发现3人结队模式

## 实战成果

- **方向一**: 发现13名患者通过2-3人结队方式频繁住院，骗保170余万元
- **方向二**: 发现14例心脏搭桥缺必要项目，违规结算34.7万元

## 参数建议

| 参数 | 医保审计 | 招投标审计 |
|:------|:--------|:----------|
| 支持度阈值 | ≥3次 | ≥2次(项目数少时) |
| 置信度阈值 | ≥80% | ≥60% |
| 频繁项集深度 | 2-3项集 | 2-4项集 |
