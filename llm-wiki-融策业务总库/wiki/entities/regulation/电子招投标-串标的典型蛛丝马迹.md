# 电子招投标："串标"的典型蛛丝马迹（收藏）

## 一、电子标"串标"嫌疑点解析汇总

| # | 嫌疑点 | 原因 |
|:--|:------|:-----|
| ① | IP地址一致 | 同一IP地址报名、上传、解密投标文件 |
| ② | 文件用户名一致 | 用了别人的软件会员（如WPS会员） |
| ③ | 预算锁锁号一致 | 同一预算编制软件做的预算 |
| ④ | 网卡MAC地址一致 | 同一台电脑上传、解密投标文件 |
| ⑤ | 文件属性一致 | 同一台电脑、同一人制作的文件 |
| ⑥ | 文件创建标识码一致 | 同一原文件修改制作而成 |
| ⑦ | 机器码一致 | 同一台电脑制作的标书 |

## 二、法律分析探讨

### 核心论点

《招标投标法实施条例》第39条（属于串标）和第40条（视为串标）**并未明确**将上述7种情形列为法定认定标准。

**关键分论点**：
1. **如果招标文件未注明**7种情形=串标 → 评委会不应直接认定，应给澄清说明机会
2. **如果招标文件直接注明** → 招标文件存在违法风险
3. **实践现状**：平台自动报警后，评委会一般直接认可，不给投标人解释机会

## 业务启示

1. **采购文件合规审查**：查招标文件是否有"非法扩大串标认定范围"的条款
2. **投标人权益保护**：审计中不应直接定性，应给澄清机会
3. **审计报告书写**：区分"串标嫌疑点"和"法定认定标准"
