# 医疗机构费用异常检测 — 聚类模型

## 审计问题
哪些医疗机构存在人均费用异常、费用结构异常的问题？

## 核心逻辑
将医疗机构按"人均费用、人次、费用结构（药占比/检查占比）、增长率"多维度聚类，找出偏离正常群体的异常机构。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 医院编码 | 机构唯一标识 | 医保结算 |
| 年结算人次 | 年度门诊+住院总人次 | 汇总 |
| 人均费用 | 总费用/人次 | 计算 |
| 药占比 | 药品费/总费用 | 计算 |
| 检查占比 | 检查费/总费用 | 计算 |
| 费用增长率 | 同比上年 | 计算 |
| 医院级别 | 三级/二级/一级/社区 | 机构信息 |

## 检测逻辑

```
Step 1: 标准化：人均费用、人次、药占比、检查占比、增长率 → Z-Score
Step 2: K-Means聚类（k=5），按医院级别分别聚类
Step 3: 识别异常群：
  - 人均费用远高于同级 → 过度医疗
  - 药占比异常高 → 以药养医
  - 增长率异常高 → 突然膨胀
Step 4: 对异常群机构重点抽查病历，验证合理性
```

## 阈值/参数
- 聚类数 k=5，按级别分层
- 人均费用 > 同级均值1.5倍 → 标记异常
- 药占比 > 45%（同级）→ 以药养医嫌疑
- 年增长率 > 30% → 异常膨胀

## 典型发现
- 某一级医院人均费用高于三级医院均值 → 严重异常，抽查发现虚假住院
- 某机构药占比75%，同级均值35% → 以药养医的典型

## 局限性
- 专科医院（肿瘤/精神病）费用结构天然不同，需单独分组
- 需足够的同级机构数量（至少10家以上）
