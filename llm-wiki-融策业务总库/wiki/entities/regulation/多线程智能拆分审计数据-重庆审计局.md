# 利用多线程技术智能拆分海量审计数据的方法

- **来源**：数智审Lab公众号（2026-01-29）
- **原文**：《中国审计》2023年第18期
- **作者**：重庆市审计局 黎强
- **类型**：技术方法
- **存入日期**：2026-05-27

---

## 一、应用场景

某市医疗保险基金审计：
- 原始数据：Oracle数据库 **~100亿条**
- 分析结果：**425项**（基础类/线索类/问题类）
- 需拆分至 **40个区县**审计组分散核实
- 单表最大：**1178万条**

## 二、技术方案

### 核心：多线程智能拆分

| 维度 | 单线程 | 多线程 |
|:-----|:------|:-----|
| 1178万条拆分 | ~7小时 | 大幅缩短 |
| 425项全量拆分 | ~1周 | <1天 |
| 人工介入 | 每次拆分需手动 | **0人工** |

### 智能判定：自动选择输出格式

```
数据量 < 104万行 → xlsx (易读)
104万 ~ 1000万   → csv (兼容)
> 1000万         → dmp (备份格式)
```

### 技术栈

C# / .NET 4.0 / Visual Studio 2015 / Oracle.ManagedDataAccess / Aspose.cell / Thread多线程 / StreamWriter / Process

## 三、成果

- 生成Excel **1.2万余张**，csv **19张**，dmp **7个**
- 数据量约 **20GB**
- 统计自动化：区县医疗机构数量+患者数量+问题金额自动汇总

## 四、对融策的启示

### 直接类比：招投标大样本分析

| 文章场景 | 融策场景 |
|:--------|:--------|
| 425项分析结果拆40区县 | 22家投标人×3000页→TF-IDF文本提取 |
| 单线程7小时 | 宿舍监理文本提取用时~20分钟（已可接受） |
| 多线程加速 | 可进一步用Python multiprocessing/joblib并行 |

### 借鉴"智能判定"思路

当前融策脚本输出格式固定。可借鉴：

```python
if rows < 1_040_000:
    输出 xlsx  # 直观
elif rows < 10_000_000:
    输出 csv   # 大数据量
else:
    输出 pickle/parquet  # 超大数据
```

### 借鉴"统计自动化"思路

每次分析完成后自动生成统计摘要：投标人数量/疑点数量/异常层数/高风险对数量→无需人工汇总。
