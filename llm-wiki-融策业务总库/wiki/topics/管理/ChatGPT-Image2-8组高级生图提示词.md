## 核心理念

真正好用的提示词，不是越玄越好，而是能把 **画面主体、场景、构图、光线、质感、限制条件** 一次性交代清楚。

---

## 01｜公众号封面图 · 科技感教程类 (16:9)

```
生成一张适合微信公众号文章封面的16:9横版图片。
主题是"【替换为你的主题】"。
画面主体是一台打开AI作图界面的笔记本电脑，屏幕中展示简洁清晰的图像生成工作流界面。电脑周围漂浮着几张风格不同的视觉作品缩略图，包括：公众号封面、商品海报、短视频封面、信息图。
整体风格要有高级科技感，但不要冰冷。画面干净、清晰、有商业设计质感。
构图要求：笔记本电脑位于画面右侧偏中间，左侧保留大面积干净留白，方便后期添加文章标题。
光线要求：柔和的蓝紫色氛围光，桌面有真实材质，画面层次丰富。
不要出现任何文字、水印、二维码、品牌Logo。不要让界面过度复杂，不要堆满元素。
```

**适合场景**：AI工具教程封面 / 科技类公众号文章 / 软件产品介绍图 / 知识付费课程头图

## 02｜小红书封面图 · 情绪冲击型 (3:4)

```
生成一张适合小红书发布的3:4竖版封面图。
画面主体是一位20多岁的年轻人，晚上独自坐在出租屋书桌前，盯着电脑屏幕发呆。电脑上隐约显示多个副业项目页面和待办事项，但不要出现清晰可读文字。
人物表情要有"想改变现状，但又不知道从哪里开始"的真实迷茫感。不是夸张崩溃，而是安静、压抑、让人有代入感。
桌面上有笔记本、手机、咖啡杯、几张随手写过的便签，环境真实生活化，不要豪华办公室。
构图要求：人物位于画面右侧，左侧和上方留出干净区域，方便后期放大标题。
光线要求：房间整体偏暗，桌面有一盏暖黄色台灯，电脑屏幕发出微弱冷光，形成冷暖对比。
整体风格是真实摄影感，高级但不过度修饰。自然皮肤纹理，真实阴影，略带电影感。
```

**适合场景**：焦虑感标题封面 / 副业、成长、职场类内容 / "这说的不就是我吗"型情绪图

## 03｜抖音短视频封面 · 真人挑战系列 (9:16)

```
生成一张适合抖音短视频封面的9:16竖版图片。
画面主体是一位普通创作者，正在居家环境里录制口播视频。人物正面对镜头，身前有手机支架，旁边有补光灯和打开的电脑。
人物表情要有一点懊恼、一点不服输，像是今天做内容遇到了问题，但还想继续坚持下去。整体状态真实，不要表演过度。
背景是简洁的家庭工作区，可以看到书架、桌面、设备，但不要太乱。
构图要求：人物半身近景，位于画面中下区域。画面顶部预留明显空白，方便后期放置大标题。
光线要求：脸部明亮干净，有短视频封面的视觉冲击力，但不要廉价滤镜感。
整体风格：真实摄影质感，轻微美颜但保留真人感，肤色自然，细节清晰。
```

**适合场景**：挑战100天系列 / 日更记录类短视频 / 创作者成长内容 / 个人IP封面

## 04｜商品主图 · 数字产品/U盘资料包 (1:1)

```
生成一张可用于电商商品主图的1:1正方形图片。
画面主体是一枚银色金属U盘，放置在干净高级的浅色桌面上，产品角度为45度斜放，主体占据画面中心。
U盘周围以半透明悬浮光效的形式，展示多个数字内容元素：电子书封面、文件夹、视频课程图标、模板页面、图片素材缩略图。所有元素都只表现为抽象视觉符号，不要出现真实文字。
整体要传达"一个U盘里装着系统化数字资料"的感觉。
构图要求：画面简洁，商品绝对是视觉中心，周围元素起辅助作用，不要喧宾夺主。
光线要求：高级商业棚拍光，金属反射自然，桌面有柔和阴影，产品边缘清晰。
风格要求：接近高端3C数码产品广告图，可直接用于商品详情页首图。
```

**适合场景**：数字产品实物载体 / U盘资料包 / 课程资料商品图 / 电商详情页首屏

## 05｜海报级人物图 · 普通人逆袭感 (16:9)

```
生成一张具有电影海报质感的16:9横版人物场景图。
画面主体是一位普通年轻人，站在夜晚城市高楼的天台边缘，背对镜头，微微侧脸，看向远处灯火通明的城市。
他穿着简单日常，不要西装，不要成功人士精英感。要呈现"还没赢，但决定开始改变"的状态。
天空略暗，城市灯光在远处铺开，风轻轻吹动衣角。整体画面要有希望感，但不鸡汤，不夸张。
构图要求：人物位于画面左下区域，右侧是辽阔城市夜景，留出视觉空间。
光线要求：城市霓虹和微弱侧逆光勾勒人物轮廓，氛围克制、有情绪。
整体风格：真实电影剧照感，色彩沉稳，细节丰富，画面有命运感。
不要出现文字、水印、Logo。不要过度英雄化，不要超级大片感，不要让人物变成模特硬照。
```

**适合场景**：成长类公众号配图 / "普通人改变命运"类文章 / 情绪型文章头图

## 06｜知识卡片 · 高级教程信息图 (3:4)

```
生成一张3:4竖版知识卡片式信息图。
主题是"【替换为你的主题】"。
整体采用清爽、高级、适合知识类账号发布的视觉设计。画面中心是一个简洁标题区，周围分成6个信息模块，分别代表：主体、场景、构图、光线、风格、限制。
每个模块都使用简单清晰的小图标辅助表达，例如：人物图标、房间图标、取景框、灯光、调色板、禁止符号。
整体布局要规整，信息结构要一眼看懂，模块之间有轻微的逻辑连接线或箭头。
配色以浅米色背景、深蓝文字区域、少量橙色强调为主。画面要高级，不要幼稚。
如果生成文字，文字必须简洁、准确、清晰；如果文字表现不稳定，则优先保留清晰版式和空白标题区域，不要生成乱码。
不要水印，不要二维码，不要过度复杂。
```

**适合场景**：教程总结图 / 小红书知识卡片 / 公众号正文配图 / 社群资料图

## 07｜历史叙事插画 · 高质量剧情画面 (16:9)

```
生成一张16:9横版的中国历史叙事动画插画。
场景是古代大殿内部，空间高耸、空旷、压抑。殿门正在缓缓关闭，一束外面的冷白色光从门缝中越来越窄地照进来。
画面中央是一位古代将领，身穿暗色战袍，站在大殿中央，缓缓回头望向即将闭合的大门。人物神情克制，但能看出他已经意识到自己退路断绝。
大殿两侧有模糊的青铜器、长帷幔和低垂阴影，空气中有细微尘埃漂浮。
整体风格：2D国风历史叙事动画插画，柔和水彩手绘质感，宣纸纹理，线条细腻，色彩压低，冷暖对比自然，带有强烈宿命感。
构图要求：人物居中略偏下，门缝光形成画面最强视觉引导线。
不要出现文字、水印、现代元素。不要Q版，不要油画，不要写实3D渲染风。
```

**适合场景**：历史解说视频画面 / 公众号历史配图 / YouTube剧情叙事类素材

## 08｜品牌氛围图 · 高端工作室感 (16:9)

```
生成一张16:9横版的高级品牌氛围图。
场景是一个简洁、现代、略带科技感的个人内容工作室。桌面上有笔记本电脑、麦克风、相机、平板、手写笔记本，所有物品摆放自然，有真实使用痕迹。
画面中没有人物，但要让人感觉这里属于一个长期创作、持续输出的人。
构图要求：桌面从左下延伸到右侧，电脑屏幕作为视觉中心，背景有虚化的书架和柔和灯光。
光线要求：傍晚室内自然光加暖色辅助灯光，氛围安静、有质感、有长期主义的感觉。
整体风格：真实摄影感，类似高端创作者工作室纪录片截图，而不是商业样板间。
不要文字、水印、Logo。不要过度奢华，不要杂乱，不要霓虹赛博朋克风。
```

**适合场景**：创作者品牌图 / 个人IP介绍页 / 社群介绍图 / 自媒体工作流文章配图

## 🔧 万能模板

如果你不想每次都从头写，可以直接套用这个结构：

```
生成一张适合【发布平台/用途】的【比例】图片。
画面主体是【人物/物体】，正在【动作或状态】。
场景位于【具体环境】，包含【辅助元素】。
整体想传达【情绪/主题】。
构图要求：【主体位置】【留白位置】【镜头远近】。
光线要求：【光线氛围】。
风格要求：【真实摄影/商业广告/手绘插画/电影海报等】。
质感要求：【材质、皮肤、空间、细节】。
不要出现【文字/水印/二维码/Logo/多余元素】。
不要【你最不想要的错误效果】。
```

**模板要素拆解**：主体 → 场景 → 情绪 → 构图 → 光线 → 风格 → 质感 → 限制条件

这8组模板可以直接改造成审计业务场景：

|---------|-------------|
| 01 科技感封面 | 审计报告封面图、业务宣传封面 |
| 02 情绪冲击 | 审计案例警示教育配图 |
| 03 短视频封 | 审计知识科普短视频封面 |
| 06 知识卡片 | 审计流程图/工作底稿模板说明图（高价值！） |
| 08 品牌氛围 | 事务所品牌宣传/官网配图 |

> 提示词结构（主体+场景+构图+光线+风格+限制）对AI生图的质量控制至关重要，这一方法论同样适用于审计业务的可视化表达。
