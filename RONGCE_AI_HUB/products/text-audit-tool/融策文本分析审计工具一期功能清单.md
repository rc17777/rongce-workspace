# 融策文本分析审计工具一期功能清单

## 一、一期定位

一期不做“大而全”的审计智能体，也不追求复杂语义理解。目标是把审计项目中最耗人工的文本翻阅、关键词定位、条款抽取、名单碰撞、文本相似度比对，封装成可解释、可复核、可导出的标准工具。

核心原则：

- 先解决“今天能不能出线索”，再解决“未来能不能深度理解”。
- 所有疑点必须可回溯到原文、文件、页码或段落。
- 模型输出只作为审计线索，不直接替代人工判断。
- 一期优先采用关键词、规则、正则、相似度、名单碰撞等可解释方法。
- 输出结果必须能进入审计底稿、现场核查清单或项目问题台账。

## 二、通用工作流

```text
资料导入
  ↓
文件解析/OCR/文本抽取
  ↓
按资料类型分类
  ↓
选择审计场景与规则库
  ↓
批量文本分析
  ↓
生成疑点清单
  ↓
人工复核、确认、排除、备注
  ↓
导出底稿附件/核查清单/问题线索表
```

## 三、通用输入资料

一期支持以下资料类型：

| 资料类型 | 文件格式 | 处理方式 |
|---|---|---|
| Word 文档 | .docx / .doc | 直接解析；.doc 可先转换为 .docx |
| PDF 文档 | 可复制 PDF / 扫描 PDF | 可复制 PDF 直接抽取；扫描 PDF 走 OCR |
| Excel 台账 | .xlsx / .xls / .csv | 读取指定字段或整表文本 |
| 图片资料 | .jpg / .png | OCR 识别后进入文本分析 |
| 文本文档 | .txt / .md | 直接读取 |

## 四、通用输出字段

所有模块统一输出 Excel 疑点清单，字段如下：

| 字段 | 说明 |
|---|---|
| 项目名称 | 当前审计项目名称 |
| 模块名称 | 会议纪要/合同/凭证/人员/相似度 |
| 文件名 | 命中的原始文件 |
| 文件路径 | 原始文件相对路径 |
| 页码/段落/行号 | 可回溯位置 |
| 命中规则 | 关键词、正则、名单碰撞、相似度等 |
| 原文摘录 | 命中内容上下文 |
| 风险类型 | 资金、程序、合同、绩效、人员、采购等 |
| 风险等级 | P0/P1/P2/P3 |
| 疑点描述 | 自动生成的简要说明 |
| 建议核查动作 | 查凭证、调合同、访谈、发函、现场核验等 |
| 人工复核结论 | 待核实/已确认/已排除/转其他线索 |
| 复核备注 | 审计人员补充说明 |

## 五、风险等级标准

| 等级 | 含义 | 处理建议 |
|---|---|---|
| P0 | 明显违反合同、政策、制度或金额重大 | 优先核实，必要时直接纳入取证计划 |
| P1 | 高风险异常，具备明确核查价值 | 进入现场核查清单 |
| P2 | 一般疑点，需要结合其他资料判断 | 作为扩展检查线索 |
| P3 | 提示性信息或背景线索 | 用于审前了解和方向判断 |

# 模块一：会议纪要重点事项分析

## 1. 适用场景

适用于经济责任审计、预算执行审计、专项资金审计、国企审计等项目中的会议纪要、党组会纪要、主任办公会纪要、班子会纪要、专题会议纪要分析。

目标是快速识别重大决策、高频事项、异常议题、疑似绕程序事项，辅助审前调查和现场核查重点确定。

## 2. 输入资料

| 资料 | 说明 |
|---|---|
| 会议纪要全文 | Word/PDF/扫描件/OCR 文本 |
| 会议目录清单 | 可选，用于识别会议日期、会议类型 |
| 三重一大制度 | 可选，用于比对重大事项决策要求 |
| 项目台账/资金台账 | 可选，用于与会议事项交叉验证 |

## 3. 一期识别规则

### 3.1 高频主题识别

按会议纪要全文进行分词、停用词过滤、词频统计、TF-IDF 计算，输出高频事项词。

重点词类：

| 类别 | 示例关键词 |
|---|---|
| 资金事项 | 借款、垫付、拨付、补助、奖励、返还、统筹、调剂 |
| 工程事项 | 工程、建设、施工、变更、签证、结算、验收、增补 |
| 采购事项 | 采购、招标、询价、比选、单一来源、供应商、服务外包 |
| 资产事项 | 资产处置、出租、出借、划转、报废、租赁、房屋、土地 |
| 人事事项 | 招聘、任免、借调、临聘、劳务派遣、绩效工资 |
| 决策事项 | 三重一大、集体研究、班子会、党组会、专题研究 |

### 3.2 异常表达识别

| 规则 | 示例 |
|---|---|
| 先实施后补议 | 已实施、已支付、补充研究、补充审议 |
| 程序弱化 | 原则同意、抓紧办理、按程序办理但无具体程序 |
| 反复研究同一事项 | 同一项目/供应商/资金事项多次出现 |
| 大额资金事项 | 金额达到阈值且无明确审批依据 |
| 供应商高频出现 | 同一单位名称在多次会议中出现 |

### 3.3 事项链条识别

一期做轻量级事项聚类：同一关键词、同一项目名称、同一供应商名称在不同会议中重复出现时，形成事项链。

## 4. 输出表格

| 输出表 | 内容 |
|---|---|
| 会议纪要高频词表 | 关键词、出现次数、涉及文件、风险类别 |
| 重点事项清单 | 事项名称、首次出现时间、末次出现时间、涉及会议、原文摘录 |
| 异常表达清单 | 命中表达、原文、风险等级、建议核查动作 |
| 供应商/项目高频出现表 | 名称、出现次数、涉及会议、关联事项 |

## 5. 一期边界

一期不判断会议决策是否合法，只输出重点事项和异常线索。是否违反“三重一大”、是否存在程序倒置，需要结合制度、审批资料、合同和付款记录人工核验。

# 模块二：合同条款抽取与付款异常比对

## 1. 适用场景

适用于工程项目审计、采购审计、服务外包审计、资产租赁审计、专项资金审计中的合同、补充协议、变更协议、验收资料分析。

目标是批量抽取合同关键字段，并与付款台账、验收资料、审批文件交叉比对，发现提前付款、超合同付款、无依据变更、履约期限异常等问题。

## 2. 输入资料

| 资料 | 说明 |
|---|---|
| 合同/协议文本 | Word/PDF/OCR 文本 |
| 补充协议/变更协议 | 可选 |
| 付款台账 | 必需，至少包含付款对象、金额、日期、摘要 |
| 验收资料 | 可选，用于判断付款节点 |
| 招标采购文件 | 可选，用于比对合同主体和服务内容 |

## 3. 一期识别字段

| 字段 | 抽取方式 | 示例 |
|---|---|---|
| 合同名称 | 文件名/标题识别 | XX 项目施工合同 |
| 甲方 | 规则/关键词抽取 | 甲方、委托方、采购人 |
| 乙方 | 规则/关键词抽取 | 乙方、承包方、供应商 |
| 签订日期 | 日期正则 | 2024年1月10日、2024-01-10 |
| 合同金额 | 金额正则 | 人民币 xxx 元 |
| 服务/施工周期 | 日期区间正则 | 自 x 年 x 月至 x 年 x 月 |
| 付款条件 | 关键词段落抽取 | 付款、支付、结算、验收合格后 |
| 验收条件 | 关键词段落抽取 | 验收、成果交付、竣工验收 |
| 违约责任 | 关键词段落抽取 | 违约、逾期、赔偿、罚款 |
| 变更条款 | 关键词段落抽取 | 变更、补充协议、调整 |

## 4. 一期识别规则

### 4.1 付款异常

| 规则 | 判断逻辑 |
|---|---|
| 提前付款 | 合同约定验收后付款，但付款日期早于验收日期 |
| 超合同付款 | 累计付款金额大于合同金额 |
| 无合同付款 | 付款台账中存在供应商付款，但未匹配到合同 |
| 合同签订前付款 | 付款日期早于合同签订日期 |
| 付款比例异常 | 预付款、进度款、尾款比例超过合同约定 |

### 4.2 履约异常

| 规则 | 判断逻辑 |
|---|---|
| 履约超期 | 验收日期晚于合同约定完成日期 |
| 超期未追责 | 履约超期但未命中违约扣款、处罚、说明等文本 |
| 变更无依据 | 出现变更/增补/调整，但未匹配审批或补充协议 |
| 主体不一致 | 合同乙方、付款对象、发票单位不一致 |

## 5. 输出表格

| 输出表 | 内容 |
|---|---|
| 合同字段抽取表 | 合同名称、甲乙方、金额、日期、周期、付款条件等 |
| 合同付款比对表 | 合同金额、累计付款、付款日期、验收日期、异常类型 |
| 合同履约异常表 | 超期、变更、无验收、无追责等线索 |
| 主体不一致清单 | 合同乙方、付款对象、发票单位差异 |

## 6. 一期边界

一期以规则抽取为主，对复杂扫描件、表格嵌套合同、非标准合同条款可能存在漏识别。系统只提示异常，不直接认定违规。

# 模块三：凭证摘要合规关键词筛查

## 1. 适用场景

适用于预算执行审计、财务收支审计、专项资金审计、经责审计中的凭证摘要、报销说明、支付用途、项目备注分析。

目标是批量筛查高风险支出摘要、疑似超标准支出、专项资金用途偏离、违规报销、隐性福利发放等问题。

## 2. 输入资料

| 资料 | 说明 |
|---|---|
| 凭证序时账 | 必需，至少包含日期、摘要、科目、金额、对方单位 |
| 支付明细 | 可选，用于核对资金流向 |
| 报销附件 OCR 文本 | 可选 |
| 预算指标/项目台账 | 可选，用于判断用途偏离 |
| 相关制度限额 | 可选，用于超标准判断 |

## 3. 一期关键词库

### 3.1 高风险支出关键词

| 类别 | 示例关键词 |
|---|---|
| 接待类 | 接待、餐费、宴请、工作餐、陪餐、烟酒、土特产 |
| 福利类 | 慰问、补助、津贴、奖金、福利、购物卡、节日 |
| 交通类 | 租车、加油、维修、私车、公车、停车、过路费 |
| 办公采购 | 办公用品、耗材、电脑、家具、设备、礼品 |
| 专项资金 | 挪用、借用、调剂、统筹、垫付、暂付 |
| 培训会议 | 培训、会议、考察、学习、调研、差旅 |

### 3.2 异常表达关键词

| 类别 | 示例 |
|---|---|
| 用途模糊 | 其他支出、相关费用、工作经费、综合服务费 |
| 规避痕迹 | 拆分、分批、暂列、代付、转付、补发 |
| 资金用途偏离 | 专项资金用于日常办公、项目资金用于人员经费 |
| 敏感对象 | 协会、工会、个人、村委会、平台公司、劳务公司 |

## 4. 一期识别规则

| 规则 | 判断逻辑 |
|---|---|
| 敏感词命中 | 摘要或附件文本命中高风险关键词 |
| 金额阈值异常 | 同类支出超过配置阈值 |
| 频繁小额支出 | 同一对象、同类摘要多次小额支付 |
| 专项用途偏离 | 专项项目名称与摘要用途不一致 |
| 科目摘要矛盾 | 会计科目与摘要内容明显不匹配 |
| 供应商异常 | 供应商名称与支出类型不匹配 |

## 5. 输出表格

| 输出表 | 内容 |
|---|---|
| 凭证敏感词命中表 | 凭证号、日期、摘要、金额、关键词、风险类型 |
| 支出频次异常表 | 同一对象、同类摘要、次数、累计金额 |
| 用途偏离疑点表 | 项目名称、资金用途、摘要、疑似偏离原因 |
| 科目摘要矛盾表 | 科目、摘要、金额、疑点说明 |

## 6. 一期边界

关键词命中不等于违规。该模块只做线索筛查，必须结合发票、审批单、合同、制度限额、资金性质进行人工复核。

# 模块四：人员名单身份碰撞

## 1. 适用场景

适用于惠农补贴、民生资金、公益性岗位、困难救助、学生资助、养老医保、财政供养人员违规领取补贴等审计项目。

目标是将申报领取人员与各类限制性名单、身份台账进行碰撞，发现重复领取、违规领取、死亡人员领取、财政供养人员领取、亲属关系异常等问题。

## 2. 输入资料

| 资料 | 说明 |
|---|---|
| 补贴申报/发放名单 | 必需，姓名、身份证号、金额、补贴类型、年度 |
| 财政供养人员名单 | 常用限制性名单 |
| 死亡/注销人员名单 | 常用限制性名单 |
| 低保/特困/残疾/退役军人等名单 | 按项目需要导入 |
| 村干部/单位干部名单 | 可选 |
| 亲属关系表 | 可选，有则碰撞 |
| 工商登记/社保/房产车辆 | 可选，按数据权限使用 |

## 3. 一期识别规则

| 规则 | 判断逻辑 |
|---|---|
| 财政供养人员领取 | 申领人身份证号命中财政供养人员名单 |
| 死亡人员领取 | 申领人身份证号命中死亡/注销名单 |
| 重复领取 | 同一身份证号同年度多次领取同类或互斥补贴 |
| 一户多人异常 | 同一地址/户号多人集中领取 |
| 干部或亲属领取 | 命中干部名单或亲属关系表 |
| 身份条件不符 | 申报身份与限制性名单冲突 |
| 金额异常 | 同类补贴金额明显高于平均值或政策上限 |

## 4. 匹配优先级

| 优先级 | 匹配字段 | 说明 |
|---|---|---|
| 1 | 身份证号 | 最可靠，优先使用 |
| 2 | 姓名+手机号 | 身份证缺失时使用 |
| 3 | 姓名+地址/单位 | 用于辅助识别 |
| 4 | 姓名模糊匹配 | 仅作为提示性线索 |

## 5. 输出表格

| 输出表 | 内容 |
|---|---|
| 违规身份碰撞表 | 姓名、身份证号、补贴类型、命中名单、金额 |
| 重复领取疑点表 | 姓名、身份证号、补贴类型、领取次数、累计金额 |
| 干部亲属异常表 | 申领人、关联干部、关系类型、补贴金额 |
| 金额异常表 | 申领人、补贴类型、金额、均值/上限、偏离程度 |

## 6. 一期边界

名单碰撞质量取决于基础台账完整性。身份证号缺失、姓名重名、数据更新滞后可能导致误判或漏判。系统只输出疑点，最终以政策条件和现场核实为准。

# 模块五：投标/报告/验收文本相似度比对

## 1. 适用场景

适用于采购审计、招投标审计、绩效评价、工程验收、第三方服务质量复核等项目。

目标是发现投标文件雷同、验收报告套模板、绩效自评报告复制粘贴、项目总结高度相似、供应商响应内容异常一致等问题。

## 2. 输入资料

| 资料 | 说明 |
|---|---|
| 投标文件 | Word/PDF/OCR 文本 |
| 响应文件 | 可选 |
| 评分表/评审记录 | 可选，用于交叉分析 |
| 验收报告 | Word/PDF/OCR 文本 |
| 绩效自评报告 | Word/PDF/OCR 文本 |
| 项目总结/成果报告 | 可选 |

## 3. 一期相似度方法

| 方法 | 用途 |
|---|---|
| Jaccard 相似度 | 短文本、名称、标题、摘要比对 |
| TF-IDF 余弦相似度 | 长文档整体相似度比对 |
| 段落级相似度 | 定位具体雷同段落 |
| 关键词重合度 | 技术方案、服务承诺、验收结论等重点段落比对 |

## 4. 一期识别规则

| 规则 | 判断逻辑 |
|---|---|
| 投标文件整体高度相似 | 不同供应商文本整体相似度超过阈值 |
| 关键段落雷同 | 技术方案、服务承诺、人员配置、售后服务段落高度相似 |
| 错别字/格式雷同 | 相同错别字、相同异常标点、相同格式残留 |
| 验收报告套模板 | 不同项目验收报告核心内容高度相似 |
| 绩效报告复制 | 自评报告、总结报告之间高度相似 |
| 名称微调 | 项目名称、药品名称、采购品目局部相似但不一致 |

## 5. 阈值建议

| 场景 | 建议阈值 | 说明 |
|---|---|---|
| 投标文件整体相似 | 0.80 以上 | 进入高风险线索 |
| 关键段落相似 | 0.85 以上 | 优先核查 |
| 验收/总结报告相似 | 0.90 以上 | 判断是否套模板 |
| 名称微调 | 0.70 以上且文本不完全相同 | 作为提示性线索 |

## 6. 输出表格

| 输出表 | 内容 |
|---|---|
| 文档整体相似度矩阵 | 文件 A、文件 B、相似度、风险等级 |
| 段落雷同清单 | 文件 A 段落、文件 B 段落、相似度、原文摘录 |
| 投标雷同疑点表 | 供应商 A、供应商 B、雷同位置、疑点说明 |
| 报告套模板疑点表 | 项目名称、报告名称、相似内容、涉及文件 |

## 7. 一期边界

文本相似不必然等于串标或造假。招标文件格式要求、统一模板、政策条款引用都会造成高相似度。系统必须区分模板性相似和实质性相似，最终结合报价、IP/MAC、文件元数据、保证金、人员关系等资料综合判断。

# 六、一期产品页面建议

## 1. 项目首页

展示项目名称、资料数量、已解析文件数、疑点总数、待复核数量、已确认数量。

## 2. 资料管理页

支持上传资料、文件分类、OCR 状态查看、解析失败提示。

## 3. 模块运行页

支持选择模块、选择规则库、设置阈值、启动分析、查看运行日志。

## 4. 疑点复核页

支持按风险等级、文件类型、命中规则筛选疑点；支持查看原文、确认、排除、备注。

## 5. 导出中心

支持导出 Excel 疑点清单、Word 核查清单、底稿附件目录。

# 七、一期不做事项

为控制范围，一期暂不做以下功能：

- 不做全自动审计结论生成。
- 不做复杂法律定性。
- 不做黑箱深度学习模型作为主要判断依据。
- 不做跨系统自动取数，先支持人工上传资料包。
- 不做行政复议级别的证据效力判断。
- 不做复杂权限系统，先满足本地或内网单项目使用。

## 十、最小可用版本建议

最小可用版本可以先实现以下 3 个功能：

1. 凭证摘要合规关键词筛查。
2. 人员名单身份碰撞。
3. 会议纪要重点事项分析。

这三个模块数据结构相对简单、结果最容易解释、现场价值最直接，适合作为融策文本分析工具的第一批试点能力。
