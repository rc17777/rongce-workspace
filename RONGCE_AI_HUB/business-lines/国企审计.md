# 国企审计

> 融策12大业务线之「国企审计」
> 支撑资料：企业国有资产法/审计署企业审计报告/国企改革政策
> 定位：对国有及国有控股企业的财务收支、经营绩效、重大决策、国资保值增值的全面审计

---

## 一、业务概述

### 定义

国企审计是对国有及国有控股企业财务收支的真实性、合法性和效益性，以及国有资产保值增值情况、重大经济决策合规性、内部控制和风险管理有效性进行的审计监督。

### 法规依据

| 法规 | 关键条款 | 适用场景 |
|:----|:--------|:---------|
| 《企业国有资产法》 | 第十至三十四条 | 国资监管、重大决策、关联交易 |
| 《企业国有资产监督管理暂行条例》 | 全文 | 国资监管体制 |
| 《公司法》 | 第一百六十四条 | 财务会计报告 |
| 《企业会计准则》 | 全文 | 会计核算规范 |
| 各行业国企监管规定 | 视行业而定 | 金融/建筑/交通等国企专项规定 |
| 《国有企业领导人员廉洁从业若干规定》 | 全文 | 领导人员履职 |

### 审计范围

- **财务收支**：收入确认、成本费用、利润核算、税务合规
- **资产质量**：应收账款、存货、固定资产、无形资产、投资
- **重大决策**：对外投资、资产处置、担保、融资、关联交易
- **内部控制**：资金管理、采购管理、合同管理、风险管理
- **国资保值增值**：净资产变化、资产负债率、利润总额、EVA
- **薪酬管理**：工资总额、领导人员薪酬、福利待遇

## 三、识别规则（核心疑点）

### R1：收入成本不匹配 — 利润操控

**问题表现**：提前确认收入、延迟确认成本、关联交易调节利润、跨期调节

**检测方法**：
```
收入确认核查：
  合同约定交付条件 → 实际验收日期 → 收入确认日期
  → 收入确认早于验收 = 提前确认收入
  
毛利率分析：
  各期毛利率对比 → 异常波动（>20%）
  → 可能通过收入/成本调节利润
```

### R2：资产减值不足 — 资产虚高

**问题表现**：应收账款坏账准备计提不足、存货跌价准备未计提、长期投资减值未确认

**检测方法**：
```
应收账款账龄：
  3年以上应收款 / 应收账款总额 > 30%
  → 应计提坏账准备但未足额计提

存货周转：
  存货周转率同比下降 > 50%
  → 可能存货积压但未计提跌价
```

### R3：关联交易非公允 — 利益输送

**问题表现**：关联方交易价格偏离市场价、关联方占用资金、无商业实质的关联交易

**检测方法**：
```
定价比对：
  关联交易价格 vs 同期非关联交易价格
  → 偏差 > 20% = 非公允交易
  
资金占用：
  其他应收款-关联方 → 金额大/时间长/无利息
  → 实质为关联方资金占用
```

### R4：重大决策违规 — 国资流失

**问题表现**：对外投资未经决策程序、资产处置未评估/未进场交易、违规担保

**检测方法**：
```
决策程序：
  投资金额 vs 公司章程规定的决策权限
  → 超权限但无董事会/股东会决议 = 违规决策
  
资产评估：
  资产处置涉及金额 > 规定标准 → 是否经评估/备案
  → 未经评估或评估值低于市场价 = 国资流失
```

### R5：工资总额超提超发

**问题表现**：超工资总额计划发放工资、违规发放津补贴、领导人员薪酬未按规定列支

**检测方法**：
```
工资总额核验：
  实际发放工资总额 vs 上级批复的工资总额计划
  → 超计划部分 = 超提超发
  
领导薪酬：
  领导人员薪酬明细 → 是否在工资总额内？
  → 是否经上级主管部门审批？
```

## 四、底稿模板

### 国企审计底稿（通用程序）

```
## 国企审计底稿

### 财务收支审计程序
- [ ] 核对财务报表与总账一致性
- [ ] 抽查大额收入确认时点（合同vs验收vs开票）
- [ ] 抽查大额成本费用原始凭证
- [ ] 核查资产减值准备计提是否充分

### 重大决策审计程序
- [ ] 获取董事会/总经理办公会会议纪要
- [ ] 核对重大投资/担保/资产处置有无决策记录
- [ ] 核查资产评估是否按规定进行

### 关联交易审计程序
- [ ] 获取关联方清单（含实际控制人/子公司/参股公司）
- [ ] 逐笔核查大额关联交易定价合理性
- [ ] 核查关联方资金往来是否合规

### 国资保值增值审计程序
- [ ] 计算净资产变化率、资产负债率、EVA
- [ ] 核查利润分配是否合规
- [ ] 核查国有资本收益上缴情况
```

## 五、报告框架

```
一、企业基本情况
二、审计评价
三、审计发现的问题
  ├── 财务收支方面（收入不实/成本虚增/资产不实）
  ├── 重大决策方面（违规投资/违规担保/资产处置）
  ├── 关联交易方面（非公允交易/资金占用）
  ├── 国资保值增值方面（利润不实/亏损未揭示）
  └── 薪酬管理方面（超提超发/违规发放）
四、审计建议
五、需披露事项
```
