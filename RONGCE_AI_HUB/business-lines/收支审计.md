# 收支审计

> 融策12大业务线之「收支审计」
> 支撑资料：政府审计实务 / 财政违法行为处罚条例 / 审计署年度报告
> 定位：基本盘业务，融策开展最多的审计类型之一

---

## 一、业务概述

### 定义

收支审计是对被审计单位财政财务收支活动的真实性、合法性和效益性进行的审计监督。包括收入审计和支出审计两大板块，覆盖预算内收支、预算外收支、非税收入、专项资金收支等。

### 法规依据

| 法规 | 关键条款 | 适用场景 |
|:----|:--------|:---------|
| 《审计法》 | 第十六条、第十八条 | 审计机关对财政收支、财务收支的审计监督权 |
| 《预算法》 | 第五十七、六十三条 | 预算执行、科目调整、资金拨付 |
| 《财政违法行为处罚处分条例》 | 第三至九条 | 收入不入账、虚列支出、违规收费等 |
| 《会计法》 | 第九、十四、二十五条 | 会计核算真实性、原始凭证合规性 |
| 各行业财务制度 | 视行业而定 | 教育、卫生、交通等行业专项财务规定 |

### 审计范围

- **收入类**：财政拨款收入、非税收入（行政事业性收费/罚没收入/国有资源有偿使用收入）、经营收入、其他收入
- **支出类**：基本支出（人员经费/公用经费）、项目支出、转移性支出
- **往来款项**：暂付款、暂存款、应收应付款项
- **资产类**：货币资金、固定资产、无形资产

## 三、识别规则（核心疑点）

### R1：收入不入账 — 账外资金

**问题表现**：非税收入未上缴财政专户、经营性收入未入账、往来款长期挂账形成隐性收入

**检测方法**：
```
收入端核验：
  银行流水收入总额 vs 账面收入总额
  → 差额>0 → 可疑未入账收入
  
票据核验：
  领用票据数 × 收费标准 vs 账面收入
  → 领用票据多而收入少 → 收入未入账
```

**证据链**：银行流水 + 账面收入 + 票据领用记录 → 三方交叉

### R2：虚列支出 — 套取资金

**问题表现**：无真实业务的虚假发票、虚构劳务费/咨询费、虚假合同套取资金

**检测方法**：
```
供应商核验：
  同一供应商频繁收款 → 工商查询是否空壳
  发票开票方 vs 合同签订方 vs 资金收款方 不一致
  
金额特征：
  大额整数发票（如10万、50万整）
  发票连号、同一天开票
  发票日期早于合同签订日期（倒签）
```

**证据链**：发票真伪核验 + 合同比对 + 资金流向追踪

### R3：违规收费 — 超标准/超范围

**问题表现**：超标准收费、无依据收费、已取消项目继续收费、搭车收费

**检测方法**：
```
收费标准核验：
  实际收费金额 vs 收费许可证核定标准
  → 超出部分 = 违规收费
  
收费项目核验：
  实际收费项目 vs 财政部/发改委公布的收费目录清单
  → 不在清单内 = 违规收费
```

**证据链**：收费许可证/目录清单 + 实际收费台账 + 收款凭证

### R4：资金挪用 — 科目混用

**问题表现**：专项资金用于日常经费、项目经费用于人员支出、不同项目间资金调剂

**检测方法**：
```
科目追踪：
  专项资金拨付 → 实际支出科目
  → 若专项资金实际支出在"日常公用经费"科目 → 挪用
  
项目追踪：
  A项目资金 → 实际支付B项目支出
  → 预算科目与支出科目不一致
```

**证据链**：预算批复 + 支付明细 + 对方账户追踪

### R5：往来款长期挂账 — 潜亏风险

**问题表现**：三年以上应收应付款未清理、其他应收款挂账无法收回、预付账款无对应项目

**检测方法**：
```
账龄分析：往来明细账 → 按账龄分组
  → 3年以上挂账 = 重点关注
  → 1年以上挂账且金额>50万 = 预警

关联分析：其他应收款借方 → 收款方身份
  → 如果收款方是个人/关联企业 → 可能为挪用或变相借款
```

**证据链**：往来明细账 + 账龄分析表 + 催收记录/清理方案

```markdown

- 审计人员：__________
- 复核人员：__________

### 审计程序

**程序1：收入完整性核查**
- [ ] 获取银行对账单，核对收入总额与账面收入

- [ ] 获取收费许可证/收费目录

### 发现汇总

|:----|:--------|:---------|:----|:----|

### 审计结论
□ 无重大异常
□ 存在XX问题，需进一步核实
□ 发现XX违规事项
```

### 4.2 支出审计底稿

```markdown
## 支出审计底稿

### 审计程序

**程序1：支出真实性核查**
- [ ] 核对大额支出（>XX万元）的合同、发票、验收单

- [ ] 检查政府采购流程是否合规

[同上]
```

## 五、报告框架

### 报告结构

```
一、基本情况
  ├── 被审计单位概况
  ├── 审计范围和时间
  └── 审计实施情况

二、审计评价
  ├── 收入方面评价
  └── 支出方面评价

三、审计发现的问题
  ├── 收入方面（按问题类型分类）
  │   ├── 收入未入账/未及时上缴
  │   ├── 违规收费
  │   └── 其他收入问题
  ├── 支出方面（按问题类型分类）
  │   ├── 虚列支出套取资金
  │   ├── 超预算/超标准支出
  │   ├── 挤占挪用专项资金
  │   └── 政府采购不合规
  └── 其他问题（往来款/资产管理等）

四、审计建议
  ├── 加强收入管理
  ├── 规范支出行为
  └── 完善内控制度

五、以前年度审计整改情况（如适用）
```

### 问题定性表述模板

| 问题类型 | 定性表述模板 |
|:--------|:------------|
| 收入未入账 | "XX单位XX收入XX万元未纳入单位财务统一核算，在账外收付，形成'小金库'" |
| 违规收费 | "XX单位在无收费依据/已取消项目的情况下，继续收取XX费用XX万元" |
| 虚列支出 | "XX单位以虚假合同/虚假发票/虚列劳务费等方式，套取资金XX万元" |
| 挤占挪用 | "XX单位将XX专项资金XX万元用于XX（非指定用途），偏离专项资金用途" |
| 往来款挂账 | "XX单位往来款项长期挂账，其中XX笔超3年未清理，涉及金额XX万元，存在潜亏风险" |
