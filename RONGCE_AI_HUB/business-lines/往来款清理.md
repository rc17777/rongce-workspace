# 往来款清理

> 融策12大业务线之「往来款清理」（含资金清理）
> 支撑资料：政府会计制度/行政事业单位资产清查/审计实务
> 定位：专项清理业务，常与资金清收、资产清查打包执行

---

## 一、业务概述

### 定义

往来款清理是对被审计单位应收及预付款项、应付及预收款项、其他应收款、其他应付款等往来款项进行逐笔核对、账龄分析、原因认定、分类处理的全过程审计。核心目标是"摸清底数、认定责任、推动清理、防范风险"。

### 法规依据

| 法规/文件 | 关键条款 | 适用场景 |
|:---------|:--------|:---------|
| 《政府会计制度》 | 应收账款/其他应收款/应付账款/其他应付款科目 | 核算规范 |
| 《行政事业单位资产清查核实管理办法》 | 全文 | 资产清查、往来款清理 |
| 《财政违法行为处罚处分条例》 | 第八条 | 擅自处理国有资产 |
| 各级政府往来款清理专项通知 | 视地方而定 | 专项清理行动 |
| 《政府会计准则第7号》 | 会计调整、差错更正 | 历史遗留问题处理 |

### 清理范围

- **应收类**：应收账款、其他应收款、预付账款、应收票据
- **应付类**：应付账款、其他应付款、预收账款、应付票据
- **暂存暂付**：暂存款、暂付款、代管款项
- **特殊项**：长期挂账的个人借款、借出资金、关联方往来

## 三、识别规则（核心疑点）

### R1：长期挂账 — 3年以上未清理

**问题表现**：应收款项超3年未收回、应付款项超3年未支付、个人借款长期未还

**检测方法**：
```
账龄分组：
  往来明细账 → 按借/贷方发生日期计算账龄
  → 3年以上 = 红色预警
  → 1-3年 = 黄色预警

金额排序：
  按账龄分组后 → 按金额降序排列
  → 重点关注前10大长期挂账项
```

**证据链**：明细账 + 账龄分析表 + 催收记录/清理方案

### R2：挂账原因不明 — 历史遗留

**问题表现**：摘要不清、无对应原始凭证、经办人已离职/调岗、账面金额与实际情况不符

**检测方法**：
```
凭证核查：
  逐笔追查原始凭证 → 无法提供凭证 = 挂账原因不明
  
访谈确认：
  访谈经办人/财务人员 → 无人能说明来源 = 历史遗留
```

**定性标准**：挂账时间>5年 + 无原始凭证 + 无人能说明来源 = 建议核销/追责

### R3：关联方往来的经济实质

**问题表现**：与关联单位/个人的大额往来、无合同支撑的借出资金、实质为投资/捐赠却挂往来

**检测方法**：
```
关联分析：
  对方单位名称 → 工商查询是否有关联关系
  → 关联方 + 大额 + 长期挂账 = 重大疑点

实质重于形式：
  借出资金 → 无合同/无利息/无还款计划
  → 实质为投资或挪用
```

### R4：虚挂往来调节收支

**问题表现**：年末大量挂账虚增/虚减收入、通过往来科目转移资金

**检测方法**：
```
时序分析：
  12月挂账金额 vs 其他月份 → 异常放大

对方追踪：
  挂账对方 → 资金去向 → 是否回流
```

### R5：个人借款长期未还

**问题表现**：职工借款超规定期限未还、借据不规范、无审批手续

**检测方法**：
```
内部往来核验：
  "其他应收款-个人"明细 → 按人汇总
  → 借款金额/借款时间/还款期限

处理核查：
  超期未还 → 是否从工资扣回？
  离职人员 → 借款是否已追回？
```

## 四、底稿模板

### 往来款清理底稿

```
## 往来款清理底稿

### 基本信息
- 被审计单位：__________
- 清理基准日：__________
- 清理人员：__________

### 清理程序

**程序1：全面摸底**
- [ ] 获取全部往来科目明细账
- [ ] 逐笔核对余额与对方单位
- [ ] 标记账龄（1年内/1-3年/3年以上/5年以上）
- [ ] 汇总各科目余额（借/贷方分别汇总）

**程序2：原因分析**
- [ ] 逐笔核查长期挂账（>3年）的原始凭证
- [ ] 访谈经办人，确认挂账原因
- [ ] 分类标注：可收回/可支付/需核销/需追责

**程序3：清理建议**
- [ ] 可收回的 → 制定催收计划
- [ ] 可支付的 → 安排支付方案
- [ ] 需核销的 → 准备核销材料（审批流程）
- [ ] 需追责的 → 移交纪检监察
```

## 五、报告框架

### 清理报告结构

```
一、清理工作基本情况
  ├── 清理范围与基准日
  ├── 清理方法
  └── 总体情况（各科目余额汇总表）

二、各类往来款明细
  ├── 应收账款（按对方单位+金额+账龄列表）
  ├── 其他应收款（含个人借款明细）
  ├── 应付账款
  ├── 其他应付款
  └── 预付/预收账款

三、长期挂账原因分析
  ├── 历史遗留问题
  ├── 合同纠纷/涉诉
  ├── 经办人离职/单位撤销
  ├── 账务处理错误
  └── 其他原因

四、清理建议
  ├── 催收类（可收回的债权）
  ├── 支付类（应支付的债务）
  ├── 核销类（需报批核销的呆坏账）
  └── 追责类（需追究责任的违规事项）

五、相关附件
  ├── 往来款清理台账
  ├── 催收函/回函
  ├── 核销审批材料
  └── 会议纪要/决策文件
```

### 问题定性表述

| 问题类型 | 定性表述 |
|:--------|:--------|
| 长期挂账 | "XX单位往来款长期挂账，其中XX笔超3年未清理，涉及金额XX万元，存在资金损失风险" |
| 个人借款 | "XX职工借款XX万元超XX年未归还，未按规定从工资扣回，存在国有资产流失风险" |
| 虚挂往来 | "XX单位通过往来科目虚列支出XX万元，实际资金被用于XX" |
| 关联往来 | "XX单位与关联方XX之间往来款XX万元，无合同支撑，实质为XX" |
