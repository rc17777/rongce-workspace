# 成本效益审计

> 融策12大业务线之「成本效益审计」
> 支撑资料：政府投资项目成本管理办法/绩效评价/审计实务
> 定位：🟡拓展业务，与绩效评价、工程审计交叉

---

## 一、业务概述

### 定义

成本效益审计是对政府投资项目、公共支出、专项资金的成本投入与产出效益进行对比分析，评价资金使用效率、经济性、效果性和公平性的审计活动。核心是回答"钱花得值不值"。

### 法规依据

| 法规/文件 | 关键条款 | 适用场景 |
|:---------|:--------|:---------|
| 《政府投资条例》 | 第九条、第十八条 | 项目可行性论证、投资概算 |
| 《项目支出绩效评价管理办法》 | 全文 | 成本指标、效益指标设定 |
| 《基本建设财务规则》 | 第二十五至三十二条 | 工程成本核算 |
| 财政部《预算绩效评价共性指标体系框架》 | 全文 | 成本效益评价指标 |
| 各行业投资估算/概算编制办法 | 视行业而定 | 行业成本标准 |

### 审计范围

- **成本端**：建设成本、运营成本、维护成本、管理成本
- **效益端**：经济效益（直接/间接）、社会效益、环境效益
- **效率端**：单位成本产出比、投入产出比、边际效益
- **对比端**：预算vs实际、同类项目对标、行业基准比对

## 三、识别规则（核心疑点）

### R1：投资超概严重 — 成本失控

**问题表现**：实际投资远超批复概算、变更签证大量增加成本、未严格执行概算管理

**检测方法**：
```
概算执行率 = 实际投资 / 批复概算 × 100%
  → >100% = 超概
  → >120% = 严重超概（需重点分析原因）

变更签证率 = 变更签证金额 / 中标合同金额 × 100%
  → >15% = 成本控制存在问题
  → >30% = 可能为低价中标高价结算
```

**证据链**：概算批复 + 结算书 + 变更签证台账

### R2：单位成本偏离行业基准

**问题表现**：单位建设成本/运营成本显著高于同类项目

**检测方法**：
```
单位成本比对：
  本项目单位成本（元/㎡、元/吨、元/人次）
  vs 行业基准/同类项目平均值
  → 偏离 > 30% = 成本异常

结构分析：
  成本构成（人工/材料/机械/管理费/其他）
  vs 行业典型成本结构
  → 某类费用占比异常偏高
```

### R3：效益未达预期 — 投入产出不匹配

**问题表现**：实际效益远低于可研报告预测、项目建成后闲置/低效运营

**检测方法**：
```
效益实现率 = 实际效益 / 可研预测效益 × 100%
  → <80% = 效益未达标
  → <50% = 严重不达标

利用率 = 实际使用量 / 设计产能 × 100%
  → <60% = 产能利用率低
  → <30% = 项目基本闲置
```

### R4：运营成本高于收益 — 净亏损

**问题表现**：项目投产后运营成本持续高于运营收入，需要财政持续补贴

**检测方法**：
```
盈亏分析：
  运营收入 - 运营成本（含折旧/维护/人工）
  → 连续3年亏损 → 项目可持续性存疑

补贴依赖度 = 财政补贴 / 运营成本 × 100%
  → >50% = 严重依赖补贴
```

### R5：成本效益分析脱离实际 — 可研造假

**问题表现**：可研报告中的效益预测过于乐观、成本预估偏低、关键参数不实

**检测方法**：
```
可研参数核验：
  预测使用量/价格/增长率 vs 实际数据
  → 偏差 > 50% = 可研参数不实

敏感性分析：
  关键参数变化 ±10% → 内部收益率变化
  → 如果关键参数微调导致IRR为负 → 可研结论不可靠
```

## 五、报告框架

```
一、项目基本情况
二、成本分析
  ├── 投资概算执行情况
  ├── 单位成本与行业对标
  └── 成本异常原因分析
三、效益分析
  ├── 经济效益实现情况
  ├── 社会效益/环境效益评价
  └── 效益未达标原因分析
四、成本效益综合评价
  ├── 投入产出比
  ├── 投资回收期/内部收益率
  └── 与可研预测对比
五、问题与建议
  ├── 成本控制方面
  ├── 效益提升方面
  └── 制度完善方面
```
