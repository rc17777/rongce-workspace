# 预算执行审计

> 融策12大业务线之「预算执行审计」
> 支撑资料：预算法/审计署年度报告/预算执行审计实务
> 定位：政府审计基本盘，每年必做

---

## 一、业务概述

### 定义

预算执行审计是对政府及各部门预算编制、批复、执行、调整、决算全过程的真实性、合法性和效益性进行的审计监督。核心是"钱花得合不合规、花得有没有效果、预算编制有没有依据"。

### 法规依据

| 法规 | 关键条款 | 适用场景 |
|:----|:--------|:---------|
| 《预算法》 | 第十三、三十二、五十五、六十三、七十二条 | 预算编制、执行、调整全流程 |
| 《预算法实施条例》 | 第二、三、四章 | 预算执行的具体规定 |
| 《财政违法行为处罚处分条例》 | 第三至七条 | 违规行为认定与处罚 |
| 《政府会计制度》 | 收入/费用/预算会计科目 | 会计核算合规性 |
| 各级预算执行监督条例 | 视地方而定 | 地方预算监督 |

### 审计范围

- **预算编制**：收入预算编制是否完整、支出预算是否细化、"零基预算"是否落实
- **预算执行**：收入是否及时足额入库、支出是否按预算科目执行、预算调整是否合规
- **决算编制**：决算数据是否真实、结转结余是否准确
- **预算绩效**：绩效目标是否实现、评价结果是否应用

## 三、识别规则（核心疑点）

### R1：预算编制不完整 — 少编漏编

**问题表现**：部分收入未纳入预算、年初预算预留比例过高、部分支出通过追加预算而非年初预算安排

**检测方法**：
```
收入完整性：实际收入 vs 年初预算收入
  → 差额超过20% → 预算编制不准确
  
预留比例：年初预算中"预留""待分配"金额 / 总预算
  → 比例>10% → 预算编制不细化
```

### R2：无预算/超预算支出

**问题表现**：无预算安排的支出、超预算科目支出、先支出后追加预算

**检测方法**：
```
科目核验：国库支付明细 → 预算科目 vs 预算批复
  → 支出科目不在预算批复范围内 → 无预算支出
  
金额核验：各科目累计支出 vs 预算批复金额
  → 超支部分 → 超预算支出
```

### R3：预算调整不合规

**问题表现**：未按规定程序报批调整、科目间自行调剂、超预算调整幅度

**检测方法**：
```
调整程序：预算调整文件 → 是否有人大/财政审批
  → 无审批文件 → 违规调整
  
调整幅度：单项科目调整幅度 > 30%
  → 属于重大调整 → 应报人大审批
```

### R4：资金闲置沉淀

**问题表现**：预算资金下达后长期未使用、结转结余逐年增大、以拨代支掩盖闲置

**检测方法**：详见 `perf-audit-checklist` 3.1节

### R5：决算不真实

**问题表现**：虚列支出冲减指标、应付未付挂账、跨期记账调节收支

**检测方法**：
```
12月支出异常：12月支出占全年比例 > 30%
  → 可能突击花钱/虚列支出
  
应付挂账：年末大量"应付账款""其他应付款"增加
  → 可能虚列支出制造余额
```

## 四、底稿模板

### 预算执行审计底稿（通用）

```
## 预算执行审计底稿

### 程序1：预算编制完整性
- [ ] 获取年初预算批复，核对预算科目/金额
- [ ] 检查是否存在"预留""待分配"等不细化科目
- [ ] 核对实际收入与年初预算差异

### 程序2：预算执行合规性
- [ ] 逐科目核对支出与预算批复是否一致
- [ ] 抽查大额支出（>XX万元）的审批手续
- [ ] 检查预算调整是否经规定程序审批
- [ ] 检查是否存在无预算安排支出

### 程序3：决算真实性
- [ ] 核对决算报表与总账/明细账是否一致
- [ ] 检查12月支出是否异常集中
- [ ] 检查往来款科目是否存在虚列挂账
```

## 五、报告框架

```
一、基本情况和审计评价
二、预算编制方面存在的问题
  ├── 预算编制不完整/不细化
  └── 零基预算流于形式
三、预算执行方面存在的问题
  ├── 无预算/超预算支出
  ├── 预算调整不合规
  ├── 挤占挪用专项资金
  └── 资金闲置沉淀
四、决算方面存在的问题
  ├── 虚列支出
  └── 往来款挂账不实
五、审计建议
六、以前年度整改情况
```
