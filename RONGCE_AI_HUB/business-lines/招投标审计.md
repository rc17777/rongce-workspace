> 定位：核心业务，与经责审计、工程审计密切协同

---

## 一、业务概述

### 定义

招投标审计是对政府采购、工程建设项目招标投标活动的合规性、公平性和有效性进行的审计监督。核心是"程序是否合规、有无围标串标、有无利益输送、有无低价中标高价结算"。

### 法规依据

| 法规 | 适用场景 |
|:----|:--------|
| 《招标投标法》 | 工程建设招标 |
| 《政府采购法》 | 政府采购 |
| 《招标投标法实施条例》 | 招标投标具体规定 |
| 《政府采购法实施条例》 | 政府采购具体规定 |
| 财政部《政府采购领域专项整治通知》 | 2026年四类违法违规整治 |

## 四、底稿模板

```
## 招投标审计底稿

### 程序1：投标IP/MAC核查
- [ ] 获取投标记录（含IP地址、MAC地址、投标时间）
- [ ] 汇总同一IP下投标单位数量
- [ ] 汇总同一MAC下投标单位数量
- [ ] 标记异常IP/MAC → 导出疑点清单

### 程序2：标书雷同检测
- [ ] 收集各投标单位技术标文件
- [ ] 运行TF-IDF文本相似度检测
- [ ] 标记相似度≥90%的投标单位对
- [ ] 人工复核雷同部分（确认是否为模板化内容）

### 程序3：报价规律分析
- [ ] 获取开标一览表
- [ ] 计算各投标报价偏差率
- [ ] 检测报价是否呈等差/阶梯分布
- [ ] 标记异常报价模式

### 程序4：供应商关联穿透
- [ ] 获取投标单位工商信息（股东/法人/董监高）
- [ ] 运行股权穿透分析
- [ ] 检测关联关系（共同股东/共同法人/人员交叉）
- [ ] 标记关联集团
```

## 五、报告框架

```
一、招投标项目基本情况
二、审计评价
三、审计发现的问题
  ├── 围标串标方面（IP一致/标书雷同/报价规律）
  ├── 供应商关联方面（股权穿透/人员交叉/共同中标）
  ├── 评标方面（打分异常/倾向性照顾）
  ├── 合同履约方面（低价中标高价结算/变更签证异常）
  └── 程序合规方面（未招标/违规分包/应招未招）
四、审计建议
五、移送线索（如有）
```
