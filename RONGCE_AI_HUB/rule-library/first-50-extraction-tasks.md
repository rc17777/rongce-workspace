# 回填要求

每条任务完成后必须回填：

| 字段 | 要求 |
|---|---|
| case_source | 至少 1 个 Obsidian 文件、历史底稿、公开案例或法规依据 |
| case_summary | 100-300 字，说明案例中真实问题 |
| detection_logic | 必须能转成程序逻辑或人工复核步骤 |
| evidence_chain | 必须说明从线索到证据需要哪些材料 |
| false_positive_note | 必须说明常见误报 |
| rule_level | 明确 A/B/C，不允许空缺 |
| status | 初始为“草稿”，试运行后再升级 |
