## 二、新案例分析 → E规则体系映射

### 文章1：围标大案全链条还原（医院2.33亿项目）

**五步围标流程**：

```
行贿300万 → 改招标条件（费率招标避审核）→ 泄露评分细则
    → 安插业主代表进评标委员会 → 操控打分 → 中标
```

**映射到现有E规则**：

| 步骤 | 对应E规则 | 检测方法 |
|:--|:--|:--|
| 改招标条件（量身定制） | **E05**（投标文件元数据同源）+ **新E25**（招标文件排他性条件检测） | 比对招标文件与中标人资质/业绩的精确匹配度，检测"度身定做"特征 |
| 费率招标规避审核 | **新E26**（招标方式异常检测） | 同一项目多次采用费率招标/竞争性谈判等非公开方式，且中标人固定 |
| 泄露评分细则 | **E05**（元数据同源）+ **新E27**（标书撰写时间异常） | 中标人标书创建时间早于招标文件发布时间 |
| 安插业主代表操控打分 | **L10**（评标打分异常）⭐现有23层体系 | 检测某评委打分与最终排名的高度相关性，以及与其他评委的打分离散度 |
| 全链条行贿 | **E15**（经办人×收款方关联）+ **新E28**（评标专家×投标人关系图谱） | 评标专家与中标人的社保/任职/股权历史关联 |

## 三、新增E规则建议（E25-E33）

基于4篇文章识别的检测模式，建议新增9条规则：

### ⭐ 难度（数据易获取）

| 规则 | 名称 | 数据要求 | 检测逻辑 |
|:--|:--|:--|:--|
| **E25** | 招标文件排他性条件检测 | 招标文件正文 + 全部投标人资质 | 提取招标文件中"注册资金≥X""N个以上案例""本系统优先"等条件 → 检测是否恰好只有中标人满足 |
| **E26** | 招标方式异常检测 | 招标方式台账 | 同一采购人多次采用费率招标/竞争性谈判/单一来源，且中标人固定 → 疑似规避公开招标 |
| **E29** | 关键人员资质真实性核验 | 投标文件中的资格证书 | 批量提取建造师/造价师/安全工程师证书编号 → 对接住建部四库一平台在线核验 |
| **E31** | 中标价×合同价×结算价三价比对 | 中标通知书 + 合同 + 结算报告 | 中标价 < 合同价 < 结算价 的递增幅度≥5% → 疑似低价中标高价结算 |

### ⭐⭐ 难度（需要额外数据）

| 规则 | 名称 | 数据要求 | 检测逻辑 |
|:--|:--|:--|:--|
| **E27** | 标书撰写时间异常 | 投标文件电子版（.docx/.pdf） | 标书创建时间早于招标文件发布时间 → 内幕信息泄露 |
| **E28** | 评标专家×投标人关系图谱 | 评标专家库 + 投标人社保/任职数据 | 评标专家与中标人法人/高管存在历史共职、同社保单位 → 利益冲突 |
| **E30** | 转包/挂靠检测 | 施工日志 + 实际施工方 + 中标人 | 现场施工人员社保不属于中标人 → 疑似转包或挂靠 |
| **E32** | 投标承诺×实地验证 | 投标文件承诺 + 现场核查 | 关键承诺指标（场地面积/营业额/设备数量）×实地核查 → 虚假应标 |

### ⭐⭐⭐ 难度（需多部门数据）

| 规则 | 名称 | 数据要求 | 检测逻辑 |
|:--|:--|:--|:--|
| **E33** | 联合体成员隐含关联检测 | 联合体协议 + 工商数据 | 联合体成员之间的股权/人员交叉 → 疑似虚假联合体规避资质 |

## 四、法规分析：《信用管理办法》对审计的影响

**核心条款（审计必查）**：

### 强制否决投标的5种情形（第9条）
```
评标委员会应当依法否决其投标：
1. 串通投标/行贿 → 投标资格被取消且期限未满
2. 弄虚作假骗取中标 → 投标资格被取消且期限未满
3. 拒不履约 → 投标资格被取消且期限未满
4. 被列为失信被执行人
5. 法律、行政法规规定的其他
```

**审计应用**：审计时应查询"信用中国"网站，核验中标人在中标时点是否存在以上5种情形。如果存在但未被否决 → 评标委员会违规。

### 禁止委托招标代理的7种情形（第10条）

**审计应用**：审计时应核验委托的招标代理机构在委托时是否存在以上情形。

### 评标专家出库的8种情形（第12条）

**审计应用**：获取评标专家名单 → 查询信用中国 → 如在库专家存在以上情形 → 评标专家库管理违规。

### 地方不得自行开展信用评价（第20条）

**审计应用**：如发现招标文件引用地方信用评价结果而非全国统一评价 → 违规。

## 六、审计行动清单

### 接到招投标审计项目后，立即执行：

1. **[信用中国查询]** — 查中标人/代理机构/评标专家是否存在第9-12条情形
2. **[E25检测]** — 提取招标文件排他性条件，比对中标人资质匹配度
3. **[E31检测]** — 中标价→合同价→结算价三价追踪
4. **[E26检测]** — 同一采购人的招标方式异常分析
5. **[L10增强]** — 评委会构成合规性 + 打分偏差检测
6. **[E29检测]** — 关键人员资格证书批量在线核验
7. **[E05检测]** — 全部投标文件元数据同源检测
8. **[E20检测]** — 报价规律异常检测

### 《信用管理办法》2027年1月1日生效后的新增项：
- 审计时"信用中国"查询成为**法定审计程序**（依据第8-9条）
- 评标专家名单必须与信用中国交叉核验（第12条）
- 地方信用评价结果使用必须核查合规性（第20条）
