## 第一章 总则

**第一条** 为规范公司采购行为，控制采购成本，保证采购质量，防范采购风险，根据公司财务管理要求，制定本制度。

**第二条** 本制度适用于公司所有采购活动，包括但不限于办公用品、IT设备、专业软件、外部咨询服务、装修维修工程、培训服务、固定资产等。

**第三条** 采购管理基本原则：
1. **集中管理**：由行政部统一归口管理，各部门不得自行组织实施须审批的采购；
2. **预算控制**：采购须在年度预算范围内执行，无预算不采购；
3. **阳光透明**：采购过程留有记录，接受财务部和监事监督；
4. **质优价廉**：在保证质量和服务的前提下，选择性价比最优方案；
5. **廉洁从业**：采购相关人员不得收受供应商任何形式的回扣、礼品或其他利益。

**第四条** 本制度不适用于以下情形：
1. 人力资源招聘费用（按RC-HR-004执行）；
2. 差旅费用（按RC-FIN-001财务报销管理制度执行）；
3. 业务招待费用（按RC-FIN-001执行）；
4. 员工薪酬福利发放。


## 第二章 采购分类

**第五条** 公司采购按标的物分类：

| 类别 | 内容 | 预算管理部门 |
|------|------|------------|
| A类：办公消耗品 | 文具、纸张、墨粉、饮用水、茶叶/咖啡、清洁用品等 | 行政部 |
| B类：办公设备 | 电脑、打印机、投影仪、电话、家具、空调等 | 行政部 |
| C类：IT软件与服务 | 审计软件、造价软件、OA系统、云服务、网站维护 | 行政部/IT负责人 |
| D类：外部专业服务 | 法律顾问、税务顾问、IT外包、审计/造价外聘人员 | 归口业务部门 |
| E类：工程类 | 办公室装修、维修工程、弱电工程 | 行政部 |
| F类：培训与会议 | 外部培训、会议场地、培训讲师 | 人力资源部 |
| G类：其他 | 保险、快递、宣传物料等 | 行政部/相关部门 |


## 第三章 采购审批权限

**第六条** 采购实行分级审批制，根据单次采购金额（含税）划分审批权限：

| 单次采购金额 | 审批人 | 备注 |
|------------|-------|------|
| ≤2,000元 | 部门负责人 | 行政部统一采购的日常消耗品由行政部负责人审批 |
| 2,001元 ~ 10,000元 | 分管副总经理 | 须附至少2家比价资料 |
| 10,001元 ~ 50,000元 | 总经理 | 须附至少3家询价/比选资料 |
| >50,000元 | 总经理（重大采购须报股东会） | 须采用比选或招标方式，附评审报告 |

**第七条** 同一采购项目不得拆分规避审批权限。以同一供应商、同一类物品、同一时期为判断标准。拆单规避审批的行为，一经发现，按违反财务制度处理。

**第八条** 单次采购金额超过50,000元的重大采购，须由使用部门提出《采购申请单》，经分管领导、财务部、总经理逐级审批。金额超过100,000元的采购，原则上应纳入年度采购计划，经总经理（或股东会）批准后执行。

**第九条** 紧急采购（指因业务急需无法按常规流程审批的采购），单次金额不超过3,000元的，可先采购再在三个工作日内补办审批手续；超过3,000元的，须电话请示分管领导获得口头批准后先行采购，事后五个工作日内补全审批手续。


## 第四章 采购方式

**第十条** 公司采购方式分为询价采购、比选采购和单一来源采购三种。

### 第一节 询价采购

**第十一条** 适用于单次采购金额10,000元以下且市场供应充分的标准品采购。

**第十二条** 询价采购要求：
1. 至少向3家供应商询价（单价低于100元且总额低于500元的零星采购可2家）；
2. 询价记录（供应商名称、报价、联系方式等）须书面留存；
3. 原则上选择报价最低的合格供应商，选择非最低价须说明理由。

### 第二节 比选采购

**第十三条** 适用于单次采购金额10,000元以上或专业性较强的非标准品采购（如IT软件、外部咨询服务等）。

**第十四条** 比选采购要求：
1. 使用部门编制采购需求书（技术参数、服务要求、验收标准）；
2. 向至少3家合格供应商发出比选邀请；
3. 成立不少于3人的评审小组（含使用部门代表、行政部门代表、财务代表），对方案和报价综合评审；
4. 形成《比选评审报告》，评审小组成员签字确认。

### 第三节 单一来源采购

**第十五条** 单一来源采购指向唯一供应商直接采购的方式，仅限以下情形：
1. 专利、专有技术或独家代理的产品/服务；
2. 原采购的后续配套、升级、维护，只能由原供应商提供；
3. 紧急情况无法通过其他方式采购；
4. 金额在500元以下的零星采购。

**第十六条** 单一来源采购须在《采购申请单》中说明理由，经分管领导审批后执行。


## 第五章 供应商管理

**第十七条** 行政部建立《合格供应商名录》，实行准入管理和年度评估。

**第十八条** 供应商准入条件：
1. 具有合法经营资质（营业执照、相关行业许可证）；
2. 产品或服务符合国家/行业标准；
3. 具有稳定供货能力和良好售后服务；
4. 近三年无重大经营异常或失信记录；
5. 价格合理，有一定市场竞争力。

**第十九条** 合格供应商名录维护：
1. 新供应商经试用期（至少一次交易）评价合格后纳入名录；
2. 行政部每年12月对名录内供应商进行年度评估；
3. 出现重大质量问题、交付严重延迟、商业贿赂等情形的，直接移出名录。

**第二十条** 年度供应商评估内容：
1. 产品质量/服务满意度（权重40%）；
2. 价格竞争力（权重25%）；
3. 交付及时性（权重20%）；
4. 售后响应速度（权重15%）。

评估结果分"优秀、合格、基本合格、不合格"四档。基本合格的给予半年整改期；不合格的从名录中移除。

**第二十一条** 供应商黑名单：有下列情形之一的供应商，永久不得合作：
1. 提供虚假资质或虚假产品；
2. 商业贿赂公司员工；
3. 严重违约给公司造成重大损失；
4. 侵犯公司商业秘密。


## 第六章 采购流程

**第二十二条** 标准采购流程：

```
需求提出 → 审批 → 询价/比选 → 确定供应商 → 签订合同/下单 
→ 货物交付/服务提供 → 验收 → 入库登记 → 财务付款
```

**第二十三条** 需求提出与审批：
1. 使用部门填写《采购申请单》，明确品名、规格、数量、预算、用途、期望到货时间；
2. 按第三章审批权限逐级审批；
3. 预算外采购须同时附预算追加审批。

**第二十四条** 合同管理：
1. 单次采购金额超过10,000元或涉及服务期限超过一个月的，须签订书面采购合同；
2. 合同内容至少包括：双方名称、标的、数量、质量、价款、履行期限、验收标准、违约责任、争议解决方式；
3. 合同由行政部门或使用部门草拟，经财务部审核后由授权人签署；
4. 合同正本由行政部存档（参照RC-ADM-005档案管理制度）。

**第二十五条** 已签订合同的采购，如需变更标的、数量、金额或交付时间等关键条款，须重新按审批流程报批，并签订补充协议。


## 第七章 验收与付款

**第二十六条** 验收：
1. 物品类采购到货后，由使用部门和行政部联合验收，核对品名、规格、数量、外观、合格证等；
2. 服务类采购完成后，由使用部门验收服务质量并出具《服务验收单》；
3. 软件类采购须进行安装调试和基本功能测试；
4. 验收不合格的，拒绝接收并通知供应商限期整改或换货；
5. 验收合格的，在送货单/服务验收单上签字确认。

**第二十七条** 入库登记：
1. A类（办公消耗品）验收合格后，由行政部登记入库台账，按需发放；
2. B类（办公设备）验收合格后，行政部登记固定资产台账（参照RC-FIN-005固定资产管理制度），张贴资产标签后交付使用人；
3. C类至G类由归口部门登记管理。

**第二十八条** 付款：
1. 凭审批完整的《采购申请单》、合同（如有）、验收单、发票，按RC-FIN-001财务报销管理制度办理付款；
2. 大额采购（10,000元以上）原则上采用分期付款方式：验收合格后支付90%-95%，剩余5%-10%作为质保金在质保期满后支付；
3. 预付款原则上不超过合同金额的30%，特殊情形须经总经理批准。

**第二十九条** 供应商开具的发票须真实、合法、有效，票面信息与采购合同及验收单一致。财务部在审核中发现发票问题的，有权拒绝付款并要求采购经办人更正。


## 第八章 采购廉洁纪律

**第三十条** 参与采购活动的员工须遵守以下纪律：
1. 不得接受供应商的宴请、礼品、礼金、有价证券；
2. 不得在供应商处兼职或持有股份；
3. 不得为关联关系供应商提供便利或特殊照顾；
4. 不得泄露采购预算、其他供应商报价等保密信息；
5. 不得与供应商串通抬高价格或降低质量要求。

**第三十一条** 采购经办人员的直系亲属经营的公司原则上不得作为公司供应商。确有必要且其他供应商无法替代的，须书面申报并经总经理批准，且该经办人员不得参与该宗采购的评审和决策。

**第三十二条** 违反廉洁纪律的，视情节轻重：追缴不当所得、通报批评、罚款、降级降薪，情节严重者解除劳动合同，涉嫌违法的移送司法机关。
