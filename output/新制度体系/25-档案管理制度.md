> **制度编号**：RC-ADM-005

## 第一章 总则

**第一条** 为规范档案管理，保障档案安全完整，便于档案利用，满足法律法规和执业规范要求，根据《中华人民共和国档案法》《中国注册会计师审计准则第1131号——审计工作底稿》《建设工程造价咨询规范》及相关法律法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司全部档案的管理，包括业务档案、行政档案和电子档案。

**第三条** 档案管理基本原则：

1. **齐全完整**：归档资料齐全、编号清晰、装订规范
2. **安全保管**：防火、防盗、防潮、防虫、防篡改
3. **便于利用**：分类科学、索引清晰、借阅便利
4. **依法保管**：严格按法定保管期限保管和销毁
5. **双备份**：纸质档案+电子档案双重保障

---

## 第二章 档案分类

**第四条** 公司档案分为三大类：

```
公司档案体系
├── 业务档案（审计/造价/咨询项目档案）
│   ├── 审计工作底稿
│   ├── 审计报告及附件
│   ├── 造价成果文件及计算书
│   ├── 咨询报告及过程文件
│   └── 业务合同
│
├── 行政档案
│   ├── 人事档案（劳动合同、绩效考核、培训记录等）
│   ├── 财务档案（会计凭证、账簿、报表、税务资料等）
│   └── 综合档案（制度文件、会议纪要、证照资料、收发文等）
│
└── 电子档案
    ├── 业务档案扫描件
    ├── 行政档案电子版
    └── 其他电子化资料
```

**第五条** 业务档案按项目立卷，一个项目一个案卷，按年份+业务类型+序号编号。编号规则：

`RC-[公司代码]-[年份]-[业务类型]-[序号]`

示例：`RC-KJS-2026-SJ-001` = 融策会计师事务所2026年审计类第001号案卷

## 第三章 业务档案归档

**第六条** 业务档案归档标准——"五齐"：

| 标准 | 要求 |
|------|------|
| **材料齐** | 项目执行过程中形成的全部应归档文件材料均已收集齐全，无遗漏 |
| **编号齐** | 档案目录与案卷内实际文件一一对应，无缺号、跳号 |
| **装订齐** | 按规定格式装订成册，封面、目录、正文、附件顺序完整 |
| **索引齐** | 档案目录（卷内文件目录）编制完整，便于检索 |
| **备份齐** | 同步完成电子扫描存档（PDF格式），纸质+电子双套保存 |

## 第四章 保管期限

**第十一条** 各类档案保管期限：

| 档案类别 | 保管期限 | 起算时间 | 法律/规范依据 |
|---------|---------|---------|-------------|
| 审计工作底稿 | ≥10年 | 审计报告日起 | 《审计准则第1131号》 |
| 审计报告 | ≥10年 | 审计报告日起 | 行业惯例 |
| 造价成果文件 | ≥10年 | 成果交付日起 | 行业规范 |
| 业务合同 | ≥10年 | 合同履行完毕日起 | 业务惯例 |
| 会计凭证 | ≥30年 | 会计年度终了日起 | 《会计档案管理办法》 |
| 会计账簿 | ≥30年 | 会计年度终了日起 | 《会计档案管理办法》 |
| 财务报告 | 永久 | 年度终了日起 | 《会计档案管理办法》 |
| 人事档案（劳动合同） | 离职后≥2年 | 离职日起 | 《劳动合同法》 |
| 人事档案（其他） | 长期 | — | 公司规定 |
| 证照原件 | 永久 | — | 公司规定 |
| 制度文件（现行版） | 永久 | — | 公司规定 |
| 制度文件（历史版） | ≥5年 | 废止日起 | 公司规定 |
| 会议纪要 | ≥5年 | 会议日起 | 公司规定 |
| 电子档案 | 与对应纸质档案同期限 | — | 公司规定 |

**第十二条** 涉及法律诉讼、行政调查的档案，在相关程序终结前不得销毁。涉及国有资产的审计/造价档案，按委托方要求可能需延长保管期限。

## 第五章 档案保管

**第十三条** 档案室配备基本设施：
1. 专用档案柜/密集架，按年份和类别排列
2. 消防器材（灭火器，禁止使用喷淋系统）
3. 温湿度计（温度14-24℃，相对湿度45-60%）
4. 防虫防鼠措施（定期检查、投放防虫剂）
5. 门禁管理（非档案管理人员不得随意进入）

**第十四条** 档案按"年份→业务类型→序号"排列上架，档案盒侧面标注案卷编号和项目名称，便于查找。

**第十五条** 档案管理员每月对档案室进行一次巡查，检查：
1. 温湿度是否在正常范围
2. 有无霉变、虫蛀、鼠咬迹象
3. 有无档案错位、丢失
4. 消防器材是否完好

巡查结果记录在《档案室巡查登记表》上。

**第十六条** 发生火灾、水淹等紧急情况时，优先抢救永久保存档案和当年归档档案。

## 第六章 档案借阅

**第十七条** 档案借阅审批流程：

```
借阅人填写《档案借阅审批单》（见附件2）
  ↓
部门负责人审批
  ↓
（涉密档案须经分管副总审批）
  ↓
档案管理员登记后借出
  ↓
限时归还
  ↓
档案管理员核对归还的档案完整性和状态
```

**第十八条** 借阅管理要求：

| 要求 | 说明 |
|------|------|
| **审批先行** | 先审批后借阅，未经审批不得出借 |
| **限时归还** | 借阅期限一般不超过5个工作日，到期可续借一次 |
| **限期催还** | 超期未还的，档案管理员主动催还；超期15天的，报告借阅人部门负责人 |
| **原貌归还** | 不得涂改、勾画、拆散、污损档案；不得私自复印"机密"级以上档案 |
| **登记完整** | 借出和归还均须在《档案借阅登记簿》上记录 |

**第十九条** 外部人员（客户、监管部门、外审人员等）需查阅档案的：
1. 须经总经理审批
2. 只能在档案室现场查阅，不得外借
3. 查阅时须有公司人员在场陪同
4. 涉及客户商业秘密的，须取得该客户书面同意

## 第七章 档案销毁

**第二十条** 档案销毁仅适用于保管期限已满且无继续保存必要的档案。

**第二十一条** 档案销毁流程：

```
档案管理员编制《到期档案清单》
  ↓
档案管理部门会同业务部门鉴定
  ↓
确认无继续保存价值
  ↓
填写《档案销毁审批单》（见附件3）
  ↓
总经理审批
  ↓
两人以上在场监督销毁
  ↓
制作《档案销毁记录》归档
```

**第二十二条** 档案销毁方式：
1. **纸质档案**：使用碎纸机粉碎，或交由有资质的保密销毁公司处理
2. **电子档案**：彻底删除（清空回收站+多次覆写），不可恢复

**第二十三条** 以下档案即使到期也不得销毁：
1. 涉及未结诉讼或行政调查的
2. 涉及国有资产且在审计/检查期内的
3. 委托方明确要求延长保管的
4. 管理层认定有长期保存价值的

## 第八章 电子档案管理

**第二十四条** 电子档案管理目标：实现"纸质→电子"双套保存，提高档案利用效率。

**第二十五条** 电子档案归档要求：

| 要求 | 说明 |
|------|------|
| **同步归档** | 纸质档案归档时同步完成电子化扫描，扫描件为PDF格式，分辨率≥300dpi |
| **命名规范** | 文件名与案卷编号一致，便于检索关联 |
| **双份备份** | 电子档案至少保存于两个不同物理位置（如公司服务器+云存储/移动硬盘） |
| **格式统一** | 扫描件统一为PDF/A格式（适合长期保存）；原始电子文件（Word/Excel等）同步保存 |
| **索引管理** | 建立电子档案检索目录，可按年份、业务类型、客户名称、项目名称等条件检索 |

**第二十六条** 电子档案安全：
1. 电子档案存放服务器设置访问权限，非授权人员不可访问
2. 电子档案存储区设置防病毒、防勒索软件保护
3. 定期（每季度）对电子档案进行完整性校验，确保可正常打开
4. 存储介质（硬盘/光盘等）定期检测，发现损坏及时迁移

**第二十七条** 电子档案保管期限与对应纸质档案一致。纸质档案销毁时，电子档案一并进行，不留副本。
