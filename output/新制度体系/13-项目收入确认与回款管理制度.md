## 第一章 总则

**第一条** 为规范公司项目收入确认和回款管理，加速资金回笼，降低坏账风险，依据《企业会计准则》及相关法规，结合公司实际，制定本制度。

**第二条** 本制度适用于四川融策会计师事务所有限公司（以下简称"事务所"）和四川融策工程咨询有限公司（以下简称"工程公司"）全部业务项目的收入确认与回款管理。

**第三条** 基本原则：

1. **权责发生制**：收入按实际完成情况确认，不以收款为准；
2. **谨慎性**：收入确认需有充分依据，不得提前或虚增；
3. **及时性**：项目进展达到确认条件时及时确认；
4. **回款跟踪**：谁签约谁负责回款，项目经理为回款第一责任人。

## 第二章 收入确认原则

**第四条** 公司项目收入按以下方法确认：

### 一、完工百分比法

适用于审计类、造价咨询类等持续提供服务的项目，按项目完工进度确认收入。

**完工进度确定方法**：

1. **工作量比例法**（首选）：已发生工作量 ÷ 预计总工作量 × 100%
2. **时间比例法**：已投入工时 ÷ 预计总工时 × 100%
3. **里程碑法**：按合同约定的里程碑节点确认

**收入确认公式**：
```
当期确认收入 = 合同总收入 × 完工进度 - 以前期间已确认收入
```

### 二、交付验收法

适用于一次性交付成果的项目（如专项报告、评估报告等），在客户验收确认后一次性确认收入。

**验收确认标准**：

1. 项目成果已提交客户；
2. 客户已出具书面验收确认（含邮件、签章确认函等）；
3. 或合同约定的验收视同条件已满足（如提交后N个工作日未提出异议）。

**第五条** 合同总收入确定：

1. 固定总价合同：以合同金额为准；
2. 按实结算合同：以预计可收回金额为准，预计金额不确定的，按已发生成本确认收入；
3. 合同变更：经双方确认的变更金额计入合同总收入。

**第六条** 收入确认时点：

| 项目类型 | 确认方法 | 确认时点 |
|---------|---------|---------|
| 年度审计 | 完工百分比法 | 按月/季确认 |
| 专项审计 | 完工百分比法 | 按里程碑确认 |
| 绩效评价 | 完工百分比法 | 按里程碑确认 |
| 预算编制 | 交付验收法 | 成果交付并验收 |
| 工程结算审核 | 完工百分比法 | 按里程碑确认 |
| 全过程咨询 | 完工百分比法 | 按月确认 |

## 第三章 开票管理

**第七条** 开票流程：

```
项目经理提交开票申请 → 部门负责人审核 → 财务部审核 → 开具发票 → 项目经理送达客户
```

**第八条** 开票申请条件：

1. 项目已签订正式合同；
2. 已达到合同约定的付款节点；
3. 开票金额不超过合同约定金额；
4. 客户信息准确完整（名称、税号、地址、开户行等）。

**第九条** 开票申请材料：

1. 《开票申请单》（载明合同编号、客户名称、开票金额、发票类型、开票内容）；
2. 合同相关付款条款页复印件；
3. 已达付款节点的证明材料（如验收确认、里程碑完成证明等）。

**第十条** 财务部审核要点：

1. 合同金额与开票金额是否匹配；
2. 是否已达合同约定的付款节点；
3. 客户信息与合同是否一致；
4. 发票类型是否正确（增值税专用发票/普通发票）。

**第十一条** 发票开具后，项目经理应在5个工作日内将发票送达客户并取得签收确认。

**第十二条** 发票作废或红冲：因开票错误需作废或红冲的，由项目经理说明原因，财务部审核后处理。作废发票联次齐全方可作废。

## 第四章 回款跟踪

**第十三条** 建立项目回款台账，由财务部统一管理，项目经理配合维护。

**回款台账内容**：

| 字段 | 说明 |
|------|------|
| 合同编号 | 项目唯一编号 |
| 客户名称 | — |
| 合同金额 | — |
| 付款节点 | 合同约定的各期付款时间和比例 |
| 已开票金额 | 累计已开票金额 |
| 已回款金额 | 累计已收到款项 |
| 应收余额 | 已开票未回款金额 |
| 账龄 | 自开票日起至当前的天数 |
| 责任人 | 项目经理 |
| 状态 | 正常/预警/逾期/催收 |

**第十四条** 回款预警机制：

| 预警级别 | 条件 | 措施 |
|---------|------|------|
| 🟢 正常 | 账龄≤30天 | 常规跟踪 |
| 🟡 关注 | 30天＜账龄≤60天 | 项目经理电话/微信催收，每周更新进展 |
| 🟠 预警 | 60天＜账龄≤90天 | 项目经理上门催收，部门负责人介入协调 |
| 🔴 逾期 | 账龄＞90天 | 启动催收程序（见第五章） |

**第十五条** 财务部每月5日前编制上月《应收账款账龄分析表》，发送总经理和各部门负责人。

**第十六条** 每月经营例会设置回款通报环节，由财务部通报各部门回款完成情况。

## 第五章 应收账款管理

**第十七条** 超过90天未回款的，启动催收程序：

### 催收流程

```
第一阶段（91-120天）：
  项目经理 + 部门负责人联合催收
  → 书面催收函送达客户
  → 了解未付款原因，协商付款计划

第二阶段（121-180天）：
  总经理介入
  → 与客户高层沟通
  → 必要时暂停后续服务
  → 发送律师函

第三阶段（181-365天）：
  法律手段
  → 委托律师提起诉讼或仲裁
  → 报总经理及股东会决策
```

**第十八条** 催收过程中，项目经理应保持完整的催收记录（催收函、沟通记录、客户承诺等），交财务部存档。

**第十九条** 因项目经理未及时跟踪回款、未按时催收导致坏账的，追究项目经理责任，扣减相应项目奖金。

## 第六章 坏账处理

**第二十条** 符合以下条件之一的应收账款，可申请坏账处理：

1. 超过1年未回款，经多次催收无果，且有充分证据证明无法收回的；
2. 客户已注销、破产、失联的；
3. 经法律诉讼/仲裁后仍无法收回的。

**第二十一条** 坏账审批流程：

```
项目经理提交坏账申请 → 部门负责人审核 → 财务部核实 → 总经理审批
  → 金额≥5万元的，报股东会审批
```

**第二十二条** 坏账申请材料：

1. 《坏账核销申请表》；
2. 应收账款明细及账龄分析；
3. 催收记录（催收函、沟通记录等）；
4. 客户注销/破产证明（如适用）；
5. 法律意见书（如适用）。

**第二十三条** 坏账核销后，财务部应建立"账销案存"台账，保留继续追索的权利。

**第二十四条** 坏账计提：年末按应收账款余额的账龄分析计提坏账准备：

| 账龄 | 计提比例 |
|------|---------|
| 1年以内 | 5% |
| 1-2年 | 20% |
| 2-3年 | 50% |
| 3年以上 | 100% |

## 第七章 项目奖金与回款挂钩

**第二十五条** 项目奖金发放与回款情况挂钩，具体规则：

1. **回款到账后发放**：项目奖金在项目回款到账后，按回款比例发放对应奖金；
2. **分期回款的**：按每期回款占合同总额的比例，分期发放项目奖金；
3. **回款率≥90%**：全额发放项目奖金；
4. **回款率＜90%**：按实际回款比例发放，剩余部分待后续回款后补发；
5. **形成坏账的**：对应项目奖金不予发放，已发放的予以追回。

**第二十六条** 项目奖金计算基数以实际回款金额为准，不以合同金额或开票金额为准。

---

## 第八章 附则

**第二十七条** 财务部应建立项目收入与回款的月度报表体系，每月向管理层报告：

1. 各项目收入确认情况；
2. 应收账款余额及账龄分析；
3. 回款完成率；
4. 坏账风险预警。

**第二十八条** 本制度未尽事宜，依照《企业会计准则》及国家相关法规执行。

**第二十九条** 本制度由财务部负责解释和修订，经总经理批准后施行。
