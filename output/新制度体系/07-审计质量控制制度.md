## 第一章 总则

**第一条** 为建立健全审计质量控制体系，保证审计工作质量，防范执业风险，根据《会计师事务所质量管理准则第5101号——业务质量控制》《中国注册会计师审计准则第1121号——对财务报表审计实施的质量管理》及相关法律法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司承接的全部审计业务，包括：
1. 财务报表审计
2. 财政收支审计、财务收支审计
3. 经济责任审计
4. 专项资金审计
5. 绩效评价
6. 资产清查
7. 专项债相关审计
8. 其他鉴证业务

**第三条** 质量控制目标：
1. 审计工作严格遵守审计准则和职业道德要求
2. 出具的审计报告真实、客观、完整
3. 审计工作底稿规范、充分、可追溯
4. 重大执业风险得到有效识别和应对
5. 客户合理需求得到及时响应

**第四条** 质量控制基本原则：
1. **全员参与**：质量不是质控部门一家的事，从项目经理到审计助理，每个环节都有质量责任
2. **过程控制**：质量不是事后检查出来的，而是在每个工作环节中控制出来的
3. **风险导向**：将更多质控资源投向高风险领域和高风险项目
4. **实质重于形式**：复核不是走过场签字，要真正发现问题、解决问题
5. **持续改进**：每次质量检查和事故都是改进机会，不浪费一次教训

## 第二章 质量控制组织体系

**第五条** 公司建立"项目组→部门→公司"三级质量控制体系：

```
┌──────────────────────────────────────────────────────┐
│              第三级：公司层面                          │
│   质控负责人（主任会计师）/ 质量控制部                   │
│   职责：终审签发、质量检查、制度建设、培训指导            │
├──────────────────────────────────────────────────────┤
│              第二级：部门层面                          │
│   部门负责人（部门主任）                               │
│   职责：二级复核、日常质量督导、资源调配                  │
├──────────────────────────────────────────────────────┤
│              第一级：项目组层面                         │
│   项目经理                                           │
│   职责：一级复核、现场质量把控、底稿审核                  │
└──────────────────────────────────────────────────────┘
```

**第六条** 各级质量职责：

### 2.1 主任会计师/质控负责人

| 职责 | 具体内容 |
|------|---------|
| 最终责任 | 对公司出具的审计报告质量承担最终责任 |
| 制度制定 | 组织制定和完善质量控制制度 |
| 报告签发 | 终审签发审计报告 |

| 重大判断 | 对审计中的重大专业判断事项进行指导和决策 |
| 独立性监控 | 确保公司层面独立性政策和程序得到有效执行 |

### 2.2 部门负责人

| 职责 | 具体内容 |
|------|---------|
| 部门质控 | 对本部门审计质量负管理责任 |
| 二级复核 | 执行二级复核，确保复核覆盖率和质量 |
| 资源保障 | 确保项目组配置适当的人员和资源 |
| 日常督导 | 对项目实施过程中的重大问题进行指导和决策 |
| 人才培养 | 组织部门内业务学习和案例研讨 |

### 2.3 项目经理

| 职责 | 具体内容 |
|------|---------|
| 现场质控 | 对项目现场工作质量负直接责任 |
| 一级复核 | 执行100%底稿复核 |
| 团队指导 | 指导项目组成员正确执行审计程序 |
| 进度把控 | 合理安排工作进度，避免因赶工影响质量 |
| 问题上报 | 及时发现和上报重大审计问题 |

## 第三章 业务分类与风险管控

**第七条** 审计业务按风险等级分为三类，实施差异化管理：

### 3.1 业务分类

| 类别 | 风险等级 | 业务类型 | 管理要求 |
|------|---------|---------|---------|
| A类 | 高风险 | 国有企业审计、专项债审计、经济责任审计、上市公司审计（如有）、涉及重大公共利益的审计 | 质控负责人全程参与，三级复核全覆盖 |
| B类 | 中等风险 | 绩效评价、财政收支审计、财务收支审计、专项资金审计、资产清查 | 部门负责人重点把控，三级复核重点覆盖 |
| C类 | 一般风险 | 民营企业财务报表审计、常规专项审计、小型审计项目 | 项目经理负责，二级复核为主 |

### 3.2 分类管理措施

**A类项目（高风险）：**
1. 项目承接须经质控负责人审批
2. 项目计划须经部门负责人和质控负责人双重审核
3. 质控负责人至少参加一次项目现场工作（或远程参与关键节点讨论）
4. 审计中发现的所有重大问题须当日报告质控负责人
5. 审计报告须经质控负责人终审签发
6. 三级复核覆盖率：底稿100%、报告100%

**B类项目（中等风险）：**
1. 项目承接须经部门负责人审批
2. 部门负责人对重要审计领域和关键判断进行重点把控
3. 审计中发现的重大问题须在2个工作日内报告部门负责人
4. 审计报告须经部门负责人审核、质控负责人签发
5. 三级复核覆盖率：重要底稿≥80%、报告100%

**C类项目（一般风险）：**
1. 项目承接由部门负责人审批
2. 项目经理对审计质量负主要责任
3. 审计中发现的重大问题须及时报告部门负责人
4. 审计报告须经部门负责人审核签发
5. 二级复核覆盖率：重要底稿≥60%、报告100%

## 第四章 三级复核制度

**第八条** 公司实行三级复核制度。本制度与 RC-BIZ-001《项目管理规范》第五章"项目质量控制"中的三级复核要求互为补充，本制度侧重审计业务质量标准，RC-BIZ-001 侧重流程规范。

### 4.1 一级复核（项目经理）

**第九条** 一级复核是基础复核，由项目经理执行，要求100%覆盖全部工作底稿。

**复核内容：**

| 复核维度 | 复核要点 | 覆盖要求 |
|---------|---------|---------|
| 审计程序执行 | 是否按审计计划执行了全部必要程序 | 100% |
| 底稿完整性 | 底稿是否完整记录了审计过程和结论 | 100% |
| 证据充分性 | 审计证据是否充分、适当，能支撑审计结论 | 100% |
| 数据准确性 | 金额计算是否正确，勾稽关系是否成立 | 100% |
| 法规引用 | 引用法规是否准确、是否现行有效 | 100% |
| 逻辑一致性 | 审计发现→审计结论→报告表述是否逻辑一致 | 100% |
| 报告初稿 | 报告初稿格式规范、事实清楚、表述准确 | 100% |

**第十条** 一级复核要求：
1. 复核必须在底稿上留痕（签字+日期，或电子复核记录）
2. 发现问题的，退回编制人修改，修改后重新复核
3. 复核记录应载明：复核人、复核日期、复核范围、发现问题、处理意见
4. 一级复核是二级复核的前提，未完成一级复核不得提交二级复核

### 4.2 二级复核（部门负责人）

**第十一条** 二级复核是重点复核，由部门负责人执行，聚焦重要领域和关键判断。

**复核内容：**

| 复核维度 | 复核要点 | 覆盖要求 |
|---------|---------|---------|
| 重大风险领域 | 高风险领域的审计程序是否充分、结论是否恰当 | 关键科目100% |
| 重要判断事项 | 重要性水平、审计抽样、会计估计等判断是否合理 | 100% |
| 审计调整 | 审计调整是否恰当、金额是否准确 | 100% |
| 客户沟通 | 与管理层和治理层沟通的重大事项是否恰当 | 100% |
| 底稿规范性 | 底稿整体质量是否达到标准 | 抽查≥50% |
| 报告审核 | 报告整体逻辑、关键表述、审计意见类型 | 100% |

**第十二条** 二级复核覆盖率要求：

| 项目类别 | 底稿抽查比例 | 关键科目 | 报告 |
|---------|-----------|---------|------|
| A类项目 | ≥80% | 100% | 100% |
| B类项目 | ≥60% | 100% | 100% |
| C类项目 | ≥40% | 100% | 100% |

**关键科目**包括但不限于：货币资金、应收账款（坏账准备）、存货、固定资产、收入确认、重大关联交易、或有事项、期后事项。

**第十三条** 二级复核要求：
1. 部门负责人应亲自执行复核，不得委托他人代行
2. 复核中发现系统性问题的，应要求项目组全面修改后重新提交
3. 二级复核意见应以书面形式反馈项目组，项目组须逐条回复

### 4.3 三级复核（质控负责人/主任会计师）

**第十四条** 三级复核是终审复核，由质控负责人或主任会计师执行，是报告签发前的最后质量关卡。

**复核内容：**

| 复核维度 | 复核要点 | 覆盖要求 |
|---------|---------|---------|
| 重大事项 | 审计中发现的重大问题处理是否恰当 | 100% |
| 审计意见 | 拟出具的审计意见类型是否恰当 | 100% |
| 报告终审 | 报告整体质量、关键表述、风险提示 | 100% |
| 程序合规 | 一二级复核是否执行到位、问题是否全部解决 | 100% |
| 独立性 | 项目层面独立性是否得到维护 | 100% |
| 法规遵循 | 审计工作是否符合审计准则和法规要求 | 100% |

**第十五条** 三级复核覆盖率要求：

| 项目类别 | 复核范围 |
|---------|---------|
| A类项目 | 100%全面复核 |
| B类项目 | 报告100%复核，底稿抽查≥50% |
| C类项目 | 报告100%复核，底稿抽查≥20% |

**第十六条** 三级复核要求：
1. 三级复核是报告签发的前提，未通过三级复核的报告不得签发
2. 三级复核意见为最终意见，项目组必须执行（如有异议可书面陈述，由主任会计师最终决定）
3. 三级复核应关注整体质量，不重复一二级复核已解决的问题

### 4.4 复核记录管理

**第十七条** 三级复核全程留痕，复核记录包括：
1. 《三级复核记录表》（每级复核单独填写）
2. 复核意见及修改建议
3. 项目组回复及修改情况
4. 复核结论（通过/退回修改/有条件通过）

**第十八条** 复核记录作为审计档案的组成部分，按 RC-BIZ-001《项目管理规范》第八章"项目档案归档"的要求归档保存。

## 第五章 工作底稿质量标准

**第十九条** 审计工作底稿是审计工作的核心载体，应满足以下质量标准：

### 5.1 完整性要求

1. 底稿应完整记录审计计划、审计程序执行、审计证据获取、审计发现、审计结论的全过程
2. 每项审计程序均应有对应底稿，不得有"无异常"而不做记录的情况
3. 底稿应包括：编制人、编制日期、复核人、复核日期、索引编号

### 5.2 规范性要求

1. 底稿格式统一使用公司标准模板
2. 底稿索引编号按统一规则编排
3. 底稿表述清晰、逻辑严谨、用词准确
4. 电子底稿使用公司统一命名规则
5. 底稿修改须保留修改痕迹，不得覆盖原始记录

### 5.3 证据充分性要求

1. 审计结论必须有充分、适当的审计证据支撑
2. 证据应注明来源、获取方式、获取时间
3. 外部证据优于内部证据，书面证据优于口头证据
4. 重要审计结论应取得两个或两个以上来源的证据相互印证

**第二十条** 底稿质量评分标准（用于质量检查）：

| 评分维度 | 权重 | 满分标准 |
|---------|------|---------|
| 完整性 | 30% | 全部必要程序有底稿记录，无遗漏 |
| 规范性 | 25% | 格式统一、索引清晰、表述规范 |
| 证据充分性 | 25% | 结论有据、证据充分适当 |
| 逻辑性 | 20% | 过程→发现→结论→建议逻辑自洽 |

## 第六章 审计报告质量标准

**第二十一条** 审计报告应满足以下质量标准：

### 6.1 格式规范

1. 报告格式符合审计准则和公司模板要求
2. 报告要素齐全（标题、收件人、引言段、管理层责任段、注册会计师责任段、审计意见段、签章、日期、事务所名称地址等）
3. 报告编号规范，页码连续

### 6.2 数字准确

1. 报告中引用的财务数据与被审计单位财务报表一致
2. 审计调整后的数字计算准确
3. 金额单位统一（元/万元），前后一致
4. 百分比计算准确，合计无误

### 6.3 结论有据

1. 审计意见类型与审计证据和审计发现相匹配
2. 报告中的每一项审计发现都有充分的工作底稿支撑
3. 保留意见、否定意见、无法表示意见的，应详细说明形成该意见的具体原因

### 6.4 建议可行

1. 管理建议应针对具体问题，不空泛
2. 建议应具有可操作性，考虑被审计单位的实际情况
3. 建议应区分轻重缓急，重要问题优先

**第二十二条** 报告质量检查清单（签发前必检）：

| 序号 | 检查项目 | 检查标准 |
|------|---------|---------|
| 1 | 报告格式 | 符合模板要求，要素齐全 |
| 2 | 被审计单位名称 | 全文一致，无错别字 |
| 3 | 审计期间 | 准确无误 |
| 4 | 财务数据 | 与审定数一致 |
| 5 | 审计意见 | 与审计工作结论一致 |
| 6 | 法规引用 | 准确、现行有效 |
| 7 | 日期 | 报告日期不早于获取充分证据的日期 |
| 8 | 签章 | 注册会计师签章齐全 |
| 9 | 附件 | 附件清单与实际附件一致 |
| 10 | 页码 | 连续、无缺页 |

## 第七章 重大问题报告机制

**第二十三条** 审计过程中发现以下重大问题的，须在24小时内逐级上报：

1. 被审计单位存在重大舞弊或违法行为嫌疑
2. 被审计单位持续经营能力存在重大不确定性
3. 发现前期出具的审计报告存在重大错误
4. 审计范围受到重大限制，可能影响审计意见
5. 与管理层或治理层存在重大分歧
6. 可能对公司声誉或执业资格产生不利影响的事项
7. 监管部门关注的敏感事项
8. 涉及关联方交易、资金占用等敏感领域

**第二十四条** 重大问题报告流程：

```
发现人 → 项目经理（即时）→ 部门负责人（2小时内）→ 质控负责人（24小时内）
```

**第二十五条** 重大问题报告要求：
1. 报告形式：先口头报告，后补书面报告
2. 书面报告内容：问题描述、涉及金额、可能影响、已采取的措施、建议处理方案
3. 质控负责人接到报告后，应在24小时内做出处理指示
4. 需要向监管部门报告的，由质控负责人决定并组织实施

**第二十六条** 对隐瞒不报或延迟报告的处理：
1. 隐瞒重大问题不报的，给予记过处分
2. 延迟报告导致公司被动或损失的，加重处理
3. 造成严重后果的，按质量事故处理

## 第八章 质量检查与考核

**第二十七条** 公司建立定期质量检查制度：

### 8.1 检查频次与范围

| 检查类型 | 频次 | 范围 | 执行人 |
|---------|------|------|--------|
| 项目复核检查 | 每个项目 | 三级复核执行情况 | 质控负责人/部门负责人 |
| 季度底稿抽查 | 每季度 | 已完成项目的底稿质量 | 质控负责人组织 |
| 年度质量评估 | 每年 | 全年质控体系运行效果 | 管理层 |

### 8.2 季度底稿抽查

1. 每季度从已完成项目中随机抽取不少于20%的项目进行底稿质量检查
2. A类项目每季度100%检查
3. 检查内容包括：底稿完整性、规范性、证据充分性、三级复核执行情况
4. 检查结果形成《季度质量检查报告》，向管理层汇报

### 8.3 质量评分与考核

**第二十八条** 质量检查结果纳入绩效考核，与 RC-HR-002《绩效考核管理制度》衔接：

1. **项目质量维度**（占绩效考核权重30%）：以三级复核记录和质量检查结果为依据
2. **季度质量扣分**：季度检查中发现问题的，按以下标准扣分：

| 问题等级 | 扣分标准 | 责任人 |
|---------|---------|--------|
| 底稿格式不规范 | 每处扣1分 | 编制人 |
| 审计程序执行不完整 | 每项扣3分 | 编制人+项目经理 |
| 审计证据不充分 | 每项扣5分 | 编制人+项目经理 |
| 复核流于形式（签字不复核） | 每次扣5分 | 复核人 |
| 报告存在事实性差错 | 每处扣10分 | 编制人+项目经理+复核人 |

3. **年度质量评级**：根据全年质量检查结果，对项目团队和个人进行质量评级（A/B/C/D），作为晋升和培训的重要参考

## 第九章 质量事故分级与处理

**第二十九条** 质量事故按严重程度分为三级：

### 9.1 一级事故（特别严重）

**认定标准：**
1. 出具虚假审计报告的
2. 审计报告存在重大遗漏，导致报告使用者做出错误决策的
3. 因审计质量问题被监管部门吊销执业资格或暂停业务的
4. 因审计质量问题被追究刑事责任的

**处理措施：**
1. 直接责任人：解除劳动合同，公司保留追究法律责任和经济赔偿的权利
2. 项目经理：记过处分，扣减当年全部绩效工资，降级使用
3. 部门负责人：警告处分，扣减当年50%绩效工资
4. 质控负责人：向管理层做出检讨，承担管理责任

### 9.2 二级事故（严重）

**认定标准：**
1. 审计报告存在重大错误，被监管部门通报批评的
2. 审计程序严重缺失，底稿质量严重不达标的
3. 因审计质量问题被客户起诉（未造成重大损失的）
4. 隐瞒重大问题不报，导致公司被动的

**处理措施：**
1. 直接责任人：记过处分，扣减当季绩效工资的50%~100%，当年不得晋升
2. 项目经理：警告处分，扣减当季绩效工资的30%
3. 复核人（未尽复核责任的）：警告处分，扣减当季绩效工资的20%

### 9.3 三级事故（一般）

**认定标准：**
1. 审计报告存在一般性差错，被客户指出并要求修改的
2. 底稿质量不达标，被质量检查发现较多问题的
3. 审计程序执行不完整，但不影响审计结论的
4. 复核流程执行不规范的

**处理措施：**
1. 直接责任人：书面警告，限期整改（5个工作日内完成修改）
2. 项目经理：提醒谈话
3. 纳入当季度绩效考核扣分

**第三十条** 质量事故认定程序：
1. 质控负责人或部门负责人提出质量事故认定建议
2. 听取当事人陈述和申辩
3. 管理层集体研究决定
4. 处理结果书面通知当事人

**第三十一条** 质量事故记录：
1. 所有质量事故均须记录在案
2. 质量事故记录作为员工年度考核、晋升、续聘的重要参考
3. 一级事故记录永久保存，二三级事故记录保存5年

## 第十章 继续教育与培训

**第三十二条** 公司保障审计人员接受继续教育的权利和时间：
1. 注册会计师每年完成规定的继续教育学时
2. 公司每年组织不少于40学时的内部业务培训
3. 鼓励员工参加行业协会组织的专业培训和研讨

**第三十三条** 培训内容应包括：
1. 最新审计准则和法规更新
2. 质量检查发现的共性问题和改进措施
3. 典型审计案例研讨
4. 行业专项知识更新
5. 信息技术在审计中的应用

**第三十四条** 质量事故案例纳入培训教材，做到"处理一个、教育一片"。

**第三十六条** 本制度经管理层审议通过后发布施行，修改时同。

**第三十七条** 本制度自2026年__月__日起施行，原审计质量控制制度同时废止。
