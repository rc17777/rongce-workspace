# 四川融策业务分包管理制度

> **制度编号**：RC-BIZ-004  
> **版本**：V1.0  
> **编制日期**：2026年7月22日  
> **适用范围**：四川融策工程咨询有限公司（仅工程咨询业务）  
> **优先级**：P2  
> **审核人**：________ | **批准人**：________

---

**适用范围说明**：本制度仅适用于工程咨询公司业务分包。会计师事务所不适用本制度——审计鉴证业务依法不得分包。

---

## 第一章 总则

**第一条** 为规范工程咨询业务分包管理，确保分包工程质量和进度，防范分包风险，根据《民法典》《建筑法》《建设工程质量管理条例》《工程造价咨询企业管理办法》及相关法律法规，结合公司实际情况，制定本制度。

**第二条** 本制度所称"业务分包"，是指在工程咨询业务执行过程中，将部分非核心、专业性强的业务内容（如地质勘察、检测试验、BIM建模、特殊专业造价等）委托给具有相应资质的第三方完成的经营行为。

**第三条** 业务分包基本原则：

1. **合法合规**：分包方必须具备相应资质，分包不改变公司对委托方的总包责任
2. **总量控制**：分包金额不超过合同总额的30%，严禁整体转包
3. **质量可控**：公司对分包成果质量承担连带责任，必须实施过程管控
4. **择优选用**：从合格分包商名录中择优选择，保证分包质量
5. **书面为凭**：所有分包合作必须以书面合同为依据

---

## 第二章 分包商准入管理

**第四条** 公司建立《合格分包商名录》，实行准入审批制度。所有分包合作方须先通过准入审批，方可纳入名录。

**第五条** 分包商准入条件：

| 审查项目 | 具体要求 |
|---------|---------|
| **主体资格** | 依法设立、具有独立法人资格，存续3年以上 |
| **资质证书** | 具备分包业务要求的相应资质等级，资质在有效期内 |
| **业绩经验** | 近3年完成同类项目不少于3项，提供合同或验收证明 |
| **财务状况** | 无重大债务纠纷，未被列入失信被执行人 |
| **信用记录** | 近3年无行业行政处罚、无重大质量安全事故 |
| **专业团队** | 关键岗位人员具备相应执业资格和注册证书 |

**第六条** 分包商准入流程：

```
业务部门推荐分包商
  ↓
分包商提交资质材料
  ↓
业务部门初审（资质/业绩/信用）
  ↓
必要时实地考察
  ↓
质控部门评估（技术能力/质量体系）
  ↓
分管副总审批
  ↓
纳入《合格分包商名录》
```

**第七条** 对于以下情形，应组织实地考察：
1. 首次合作的陌生分包商
2. 承接专业性强、技术复杂的分包内容
3. 分包金额≥10万元
4. 分包商近3年内有质量投诉记录

**第八条** 《合格分包商名录》由业务部门维护，每年12月进行一次年度复审。出现以下情形的，从名录中移除：
1. 资质证书到期未续期的
2. 发生重大质量事故或安全事故的
3. 履约过程中出现严重违约或失信行为的
4. 年度评价不合格的
5. 分包商自行申请退出的

## 第三章 分包审批

**第九条** 分包比例控制：

| 指标 | 上限 |
|------|------|
| 单项目分包金额占合同总额比例 | ≤30% |
| 单项目分包商数量 | ≤3家 |
| 同一分包商年累计分包金额 | ≤100万元（需分散风险） |

**第十条** 分包审批流程：

```
项目负责人提出分包申请
  ↓
填写《业务分包审批单》（见附件1）
  ↓
部门负责人审核（必要性/合理性/分包商选择）
  ↓
质控部门审核（分包商资质/质量风险）
  ↓
财务审核（分包价格/预算控制）
  ↓
审批（按分包金额分级）
```

**第十一条** 分包审批层级：

| 分包金额 | 审批人 |
|---------|--------|
| ≤5万元 | 部门负责人 |
| 5~20万元 | 分管副总 |
| >20万元 | 总经理 |

**第十二条** 严禁下列行为：
1. 将承接的业务整体转包给第三方
2. 将核心业务内容（方案编制、成果审核、报告签发）分包
3. 选用不在《合格分包商名录》内的分包商（紧急情况除外，需先报批后补入名录）
4. 拆分合同以规避审批层级
5. 与分包方串通损害客户利益

## 第四章 分包合同管理

**第十三条** 所有分包业务必须签订书面分包合同，合同内容至少包括：
1. 分包范围和具体工作内容
2. 质量标准和验收要求
3. 工期要求和关键节点
4. 分包价格和付款条件
5. 保密条款（分包方对客户信息和工作成果保密）
6. 违约责任条款
7. 争议解决方式

**第十四条** 分包合同付款条件应与总包合同付款条件相匹配。原则上，分包款项的支付节点不早于总包合同的收款节点，避免垫资风险。

**第十五条** 分包合同按《合同审批单》流程审批后签订，审批流程参照RC-BIZ-002《业务承接与合同管理制度》执行。

**第十六条** 分包合同签订后，纳入合同台账统一管理。合同台账应标注"分包"标签，便于统计和风险监控。

---

## 第五章 分包过程管控

**第十七条** 项目负责人对分包过程管控负主要责任，应制定分包管理计划，明确管控节点和检查频次。

**第十八条** 分包过程管控要点：

| 管控环节 | 管控内容 | 频次 |
|---------|---------|------|
| **进度跟踪** | 核查分包方是否按合同约定的时间节点推进工作 | 每周 |
| **质量检查** | 对分包方的阶段性成果进行质量抽查 | 重要节点必查 |
| **人员核实** | 确认分包方投入的人员与投标/合同承诺一致 | 开工时+过程抽查 |
| **资料审查** | 审查分包方是否按规范编制和留存过程资料 | 阶段性审查 |
| **问题纠偏** | 发现偏差及时与分包方沟通，下达整改要求 | 发现问题即处理 |

**第十九条** 分包方提交的阶段性成果或最终成果，必须经项目负责人审核确认后，方可对外或纳入项目最终成果。

**第二十条** 分包过程中出现以下情形，应立即暂停合作，并报告部门负责人：
1. 分包方人员能力或投入严重不足，影响成果质量或进度
2. 分包方擅自再次分包或转包
3. 分包方出现重大信用风险或经营异常
4. 分包成果连续两次审查不达标

## 第六章 分包结算

**第二十一条** 分包结算执行"双验收"原则：

```
总包客户验收（我司向客户交付的成果通过客户验收）
  ↓
分包成果验收（项目负责人对分包部分的成果进行最终验收）
  ↓
分包结算（按验收合格的工作量和合同单价进行结算）
```

**第二十二条** 分包结算条件：
1. 总包客户已完成对我司整体项目成果的验收
2. 分包方交付的成果经项目负责人验收合格
3. 分包方提交的结算资料齐全、合规
4. 分包方已修正所有审核意见指出的问题

**第二十三条** 分包结算流程：
1. 分包方提交结算报告和相关证明材料
2. 项目负责人确认工作量、复核造价
3. 部门负责人审批
4. 财务审核、支付

**第二十四条** 分包方年度评价：每年12月对名录中所有分包商进行年度综合评价，评价内容包括质量、进度、配合度、价格合理性等方面，作为续用和调整的依据。
