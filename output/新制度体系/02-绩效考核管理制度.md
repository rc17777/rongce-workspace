# 四川融策绩效考核管理制度

> **制度编号**：RC-HR-002  
> **版本**：V1.0  
> **编制日期**：2026年7月22日  
> **适用范围**：四川融策会计师事务所有限公司、四川融策工程咨询有限公司全体在职员工  
> **优先级**：P0  
> **审核人**：________ | **批准人**：________

## 第一章 总则

**第一条** 为建立客观、公正的绩效评价体系，激励员工持续提升工作质量和效率，根据《中华人民共和国劳动合同法》及相关法规，结合公司实际情况，制定本制度。

**第二条** 绩效考核目的：
1. 客观评价员工工作表现，为薪酬分配提供依据
2. 发现员工优势和不足，为培训发展提供方向
3. 促进部门和个人目标与公司战略对齐
4. 为晋升、调岗、续聘提供决策依据

**第三条** 绩效考核原则：
1. **量化为主**：能用数据衡量的指标必须量化，减少主观判断
2. **过程透明**：考核标准事前公开，考核过程可追溯
3. **双向沟通**：考核不是单向评判，必须有反馈和沟通环节
4. **申诉保障**：员工对考核结果有异议有权申诉，公司必须受理

**第四条** 本制度适用于公司全体在职员工（试用期员工参加考核但不与绩效工资挂钩，作为转正参考）。

## 第二章 考核周期与组织

**第五条** 考核周期：

| 考核类型 | 周期 | 时间 | 用途 |
|---------|------|------|------|
| 季度考核 | 每季度一次 | 季度结束后10个工作日内完成 | 绩效工资清算 |
| 年度考核 | 每年一次 | 次年1月31日前完成 | 年终奖/晋升/培训 |

**第六条** 考核组织：

| 角色 | 职责 |
|------|------|
| 管理层 | 审批考核方案、审批考核结果、处理申诉 |
| 人力资源部 | 制定考核方案、组织考核实施、汇总统计结果、受理申诉 |
| 部门负责人 | 对本部门员工进行考核评分、进行绩效面谈 |
| 项目经理 | 提供项目维度的考核数据（质量、进度、客户反馈） |
| 员工本人 | 填写自评、参与绩效面谈、提出申诉（如有） |

## 第三章 审计业务线考核指标

**第七条** 审计业务线（含绩效评价、资产清查、专项债、经责审计、收支审计等全部审计类项目）员工考核维度及权重：

### 3.1 项目质量（30%）

| 指标 | 计算方式 | 数据来源 |
|------|---------|---------|
| 底稿合格率 | 一次审核通过率 = 一次通过底稿数 / 提交底稿总数 × 100% | 三级复核记录 |
| 报告差错率 | 报告中发现的实质性差错数量（个） | 质控部复核记录 |
| 审计程序执行完整率 | 实际执行审计程序数 / 应执行审计程序数 × 100% | 项目工作底稿 |

**评分标准：**

| 得分区间 | 标准 |
|---------|------|
| 90~100分 | 底稿一次通过率≥90%，报告零差错，程序完整率100% |
| 80~89分 | 底稿一次通过率≥80%，报告差错≤1处，程序完整率≥95% |
| 70~79分 | 底稿一次通过率≥70%，报告差错≤3处，程序完整率≥90% |
| 60~69分 | 底稿一次通过率≥60%，报告差错≤5处，程序完整率≥85% |
| 60分以下 | 底稿一次通过率<60%，或报告差错>5处，或程序完整率<85% |

### 3.2 项目进度（25%）

| 指标 | 计算方式 | 数据来源 |
|------|---------|---------|
| 里程碑按时完成率 | 按时完成的里程碑数 / 总里程碑数 × 100% | 项目管理系统 |
| 项目平均超期天数 | ∑各项目超期天数 / 参与项目数 | 项目管理系统 |

**评分标准：**

| 得分区间 | 标准 |
|---------|------|
| 90~100分 | 里程碑按时完成率≥95%，平均超期≤1天 |
| 80~89分 | 里程碑按时完成率≥85%，平均超期≤3天 |
| 70~79分 | 里程碑按时完成率≥75%，平均超期≤5天 |
| 60~69分 | 里程碑按时完成率≥65%，平均超期≤7天 |
| 60分以下 | 里程碑按时完成率<65%，或平均超期>7天 |

### 3.3 客户满意度（20%）

| 指标 | 计算方式 | 数据来源 |
|------|---------|---------|
| 客户评分 | 项目结束后客户填写满意度问卷（100分制） | 客户满意度调查表 |
| 客户投诉次数 | 考核期内收到的有效投诉次数（次） | 行政部记录 |

**评分标准：**

| 得分区间 | 标准 |
|---------|------|
| 90~100分 | 客户平均评分≥90分，零投诉 |
| 80~89分 | 客户平均评分≥80分，投诉≤1次 |
| 70~79分 | 客户平均评分≥70分，投诉≤2次 |
| 60~69分 | 客户平均评分≥60分，投诉≤3次 |
| 60分以下 | 客户平均评分<60分，或投诉>3次 |

### 3.4 专业能力（15%）

| 指标 | 计算方式 | 数据来源 |
|------|---------|---------|
| 继续教育完成率 | 实际完成继续教育学时 / 要求学时 × 100% | 培训记录 |
| 执业资格考试/通过 | 考核期内是否通过相关科目 | 个人申报 |
| 专业知识测试 | 公司内部专业知识测试成绩（如有） | 人力资源部 |

**评分标准：**

| 得分区间 | 标准 |
|---------|------|
| 90~100分 | 继续教育100%完成，通过执业资格考试或内部测试≥90分 |
| 80~89分 | 继续教育≥90%完成，内部测试≥80分 |
| 70~79分 | 继续教育≥80%完成，内部测试≥70分 |
| 60~69分 | 继续教育≥70%完成，内部测试≥60分 |
| 60分以下 | 继续教育<70%完成，或内部测试<60分 |

### 3.5 团队协作（10%）

| 指标 | 计算方式 | 数据来源 |
|------|---------|---------|
| 360度协作评分 | 由项目经理、同组同事、配合部门评分（取平均） | 360度评价表 |
| 知识分享贡献 | 考核期内进行内部培训/分享次数 | 培训记录 |

**评分标准：**

| 得分区间 | 标准 |
|---------|------|
| 90~100分 | 360度评分≥90分，内部分享≥2次 |
| 80~89分 | 360度评分≥80分，内部分享≥1次 |
| 70~79分 | 360度评分≥70分 |
| 60~69分 | 360度评分≥60分 |
| 60分以下 | 360度评分<60分 |

## 第四章 造价业务线考核指标

**第八条** 造价业务线（含预算编制、财政评审、全过程工程咨询、工程结算等全部造价类项目）员工考核维度及权重：

| 60~69分 | 误差率≤5%，一次通过率≥65%，返工率≤20% |

## 第六章 考核等级与结果应用

**第十条** 考核结果分为四个等级：

| 等级 | 名称 | 得分区间 | 比例控制 | 说明 |
|------|------|---------|---------|------|
| A | 优秀 | 90~100分 | ≤15% | 表现突出，超额完成目标 |
| B | 良好 | 75~89分 | 40%~50% | 达到并部分超出目标要求 |
| C | 合格 | 60~74分 | 30%~40% | 基本达到岗位要求 |
| D | 待改进 | 60分以下 | ≤10% | 未达到岗位基本要求 |

**第十一条** 比例控制说明：
- A等比例不超过部门参评人数的15%
- D等比例原则上按客观评分确定，不设强制最低比例；当季度全员评分均达标时，允许无D等；年度累计两次D等视为不胜任，按第十三条处理
- 部门人数少于5人的，可跨部门合并排名
- 比例控制为指导性要求，如全员表现确实突出或确实不足，经管理层审批可适当突破

**第十二条** 考核结果应用：

| 应用事项 | A（优秀） | B（良好） | C（合格） | D（待改进） |
|---------|---------|---------|---------|-----------|
| 绩效工资系数 | 1.3 | 1.0 | 0.8 | 0.5 |
| 年终奖系数 | 1.5 | 1.0 | 0.6 | 0 |
| 晋升资格 | 优先晋升 | 可参与晋升 | 暂不考虑 | 不具备 |
| 培训安排 | 外部高端培训 | 内部进阶培训 | 岗位技能强化 | 强制辅导培训 |
| 薪酬调整 | 优先调薪 | 正常调薪 | 不调薪 | 不调薪 |
| 连续两次D | — | — | — | 调岗/培训/协商解除 |

**第十三条** 连续两个季度考核为D等的员工，公司应：
1. 进行绩效面谈，分析原因
2. 制定改进计划（PIP），期限不超过3个月
3. 提供必要的培训或调岗支持
4. 改进期满仍为D的，可依法协商解除劳动合同

## 第七章 考核流程

**第十四条** 季度考核流程：

```
第1~5个工作日：员工填写自评表
第6~8个工作日：项目经理/部门负责人评分
第9~10个工作日：人力资源部汇总统计
第11~12个工作日：部门负责人进行绩效面谈
第13~15个工作日：员工确认签字（如有异议启动申诉）
第16~20个工作日：申诉处理（如有）
```

**第十五条** 年度考核流程：

```
1月1日~10日：员工填写年度自评
1月11日~15日：360度评价（同事/上下级/客户）
1月16日~20日：部门负责人综合评分
1月21日~25日：人力资源部汇总、校准排名
1月26日~31日：年度绩效面谈、结果确认
```

**第十六条** 绩效面谈要求：
1. 面谈由直接上级进行，每次不少于30分钟
2. 面谈内容：本期工作回顾、成绩肯定、不足分析、下期目标设定
3. 面谈记录双方签字，人力资源部存档
4. 员工拒绝签字的，由面谈人注明情况，不影响考核结果生效

## 第八章 申诉机制

**第十七条** 员工对考核结果有异议的，有权提出申诉。

**第十八条** 申诉流程：

1. **申诉提出**：员工在收到考核结果后 **5个工作日内**，向人力资源部提交书面申诉表（一式两份）
2. **申诉受理**：人力资源部在收到申诉后 **3个工作日内** 决定是否受理并通知申诉人
3. **调查核实**：受理后 **5个工作日内** 完成调查（查阅原始数据、约谈相关人员）
4. **申诉裁决**：人力资源部提出处理建议，报管理层审批，**10个工作日内** 出具书面裁决
5. **结果执行**：如裁决变更考核结果，人力资源部在3个工作日内调整相关数据并补发差额

**第十九条** 申诉期间，原考核结果暂按执行（绩效工资暂按原结果发放），裁决后多退少补。

**第二十条** 申诉人如对裁决结果仍有异议，可依法向劳动争议仲裁委员会申请仲裁。

**第二十一条** 公司不得因员工提出申诉而对其进行打击报复或不利对待。如有违反，该管理人员予以警告直至解除劳动合同。

## 第九章 考核数据管理

**第二十二条** 考核数据来源必须可追溯、可验证：
1. 项目质量数据：质控部三级复核记录
2. 项目进度数据：项目管理系统（或项目管理台账）
3. 客户满意度：客户满意度调查表原件
4. 继续教育：培训签到表、证书复印件
5. 360度评价：匿名评价表原件

**第二十三条** 考核资料保存期限：
- 考核评分表、自评表：保存3年
- 申诉材料：保存5年
- 绩效面谈记录：保存2年

**第二十四条** 考核数据涉及员工个人隐私，参与考核工作的人员不得向无关人员泄露。
