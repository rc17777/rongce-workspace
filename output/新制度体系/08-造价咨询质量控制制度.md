## 第一章 总则

**第一条** 为建立健全工程造价咨询质量控制体系，保证造价咨询成果质量，维护委托方合法权益，根据《工程造价咨询企业管理办法》（住建部令第50号）《建设工程造价咨询规范》（GB/T 51095）《四川省建设工程工程量清单计价定额》及相关法律法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司承接的全部工程造价咨询业务，包括：
1. 建设工程预算编制
2. 招标控制价编制
3. 工程结算审核
4. 竣工决算编制与审核
5. 财政评审（财政支出项目评审）
6. 全过程工程造价咨询
7. 工程造价鉴定
8. 其他造价咨询业务

**第三条** 质量控制目标：
1. 造价成果文件编制准确、依据充分、格式规范
2. 工程量计算偏差控制在±3%以内
3. 综合单价偏差控制在±5%以内
4. 定额套用合理，材料价格时效准确
5. 成果文件经得起委托方、审计机关和社会各方的检验

**第四条** 质量控制基本原则：
1. **准确性优先**：造价成果的核心是准确，不因赶进度牺牲精度
2. **依据充分**：每一项计算都有明确的定额、图纸或合同依据
3. **过程可溯**：计算过程完整记录，任何人可以复核验证
4. **三级把关**：编制→复核→审核，层层负责
5. **持续改进**：每次质量检查和问题反馈都是改进机会

## 第二章 质量控制组织体系

**第五条** 公司建立"编制人→项目负责人→技术负责人"三级质量控制体系：

```
┌──────────────────────────────────────────────────────┐
│              第三级：技术负责人审定                     │
│   职责：重大偏差检查、成果文件签发、技术标准把控          │
├──────────────────────────────────────────────────────┤
│              第二级：项目负责人复核                      │
│   职责：关键工程量抽检、综合单价审核、整体协调            │
├──────────────────────────────────────────────────────┤
│              第一级：编制人自检                         │
│   职责：工程量100%复核、定额套用100%检查、计算书编制      │
└──────────────────────────────────────────────────────┘
```

**第六条** 各级质量职责：

### 2.1 技术负责人

| 职责 | 具体内容 |
|------|---------|

| 质量检查 | 组织定期质量检查，审视质控体系运行效果 |
| 人才培养 | 组织业务学习、定额培训、案例研讨 |

### 2.2 项目负责人

| 职责 | 具体内容 |
|------|---------|
| 项目质控 | 对项目造价成果质量负管理责任 |
| 二级复核 | 执行关键工程量抽检和综合单价审核 |
| 进度协调 | 合理安排工作进度，确保复核时间充足 |
| 客户沟通 | 与客户就造价成果进行专业沟通和对账 |

## 第三章 业务分类与质量重点

**第七条** 造价咨询业务按类型实施差异化的质量控制：

### 3.1 预算编制

| 质量控制重点 | 具体要求 |
|------------|---------|
| 工程量准确性 | 严格按计算规则逐项计算，100%自检 |
| 定额套用 | 正确选用定额子目，换算合理有据 |
| 材料价格 | 采用编制期信息价或市场询价，注明来源和时效 |
| 取费标准 | 按工程类别和合同约定确定费率 |
| 编制说明 | 完整说明编制依据、假设条件、特殊处理 |

**预算编制质量检查要点：**
1. 工程量计算是否按定额计算规则执行
2. 有无漏项、重项
3. 定额套用是否正确，换算是否合理
4. 材料价格是否采用编制期有效价格
5. 取费基数和费率是否正确
6. 税金计算是否符合现行规定

### 3.2 财政评审

| 质量控制重点 | 具体要求 |
|------------|---------|
| 合规性审查 | 审查项目是否符合财政资金使用规定 |
| 节约率分析 | 分析送审金额与审定金额的差异原因 |
| 政策适用 | 正确适用财政评审政策和标准 |
| 依据完整 | 评审依据完整、充分、有效 |
| 报告规范 | 评审报告格式规范、数据准确 |

**财政评审质量检查要点：**
1. 评审程序是否合规
2. 核减/核增依据是否充分
3. 节约率是否在合理范围内（异常节约率需说明原因）
4. 评审报告表述是否准确、客观
5. 是否存在应核未核或不应核而核减的情况

### 3.3 全过程工程造价咨询

| 质量控制重点 | 具体要求 |
|------------|---------|
| 过程签证管理 | 及时记录、核实工程签证的真实性和合理性 |
| 变更审核 | 审核设计变更的合规性和造价影响 |
| 进度款审核 | 审核进度款申报的准确性 |
| 结算依据完整 | 确保结算所需全部资料完整收集 |
| 台账管理 | 建立完整的造价控制台账 |

**全过程咨询质量检查要点：**
1. 现场踏勘记录是否完整
2. 签证变更是否及时确认、手续是否齐全
3. 进度款审核是否有据可查
4. 造价控制台账是否动态更新
5. 结算资料是否完整移交

### 3.4 工程结算

| 质量控制重点 | 具体要求 |
|------------|---------|
| 现场核实 | 对关键工程量进行现场踏勘核实 |
| 签证有效性 | 审核签证手续是否齐全、签章是否有效 |
| 合同执行 | 审核结算是否严格按合同约定执行 |
| 争议处理 | 对争议事项有理有据地提出处理意见 |
| 对账记录 | 完整记录与施工单位的对账过程和结论 |

**工程结算质量检查要点：**
1. 结算资料是否完整（合同、图纸、签证、变更、竣工图等）
2. 工程量是否与竣工图一致，是否现场核实
3. 签证变更手续是否齐全有效
4. 定额套用和材料价格是否按合同约定
5. 核减/核增是否有充分依据
6. 对账记录是否完整，争议处理是否合理

## 第四章 三级审核制度

**第八条** 公司实行三级审核制度。本制度与 RC-BIZ-001《项目管理规范》第五章"项目质量控制"中的三级复核要求互为补充，本制度侧重造价业务质量标准，RC-BIZ-001 侧重流程规范。

### 4.1 一级审核（编制人自检）

**第九条** 编制人完成成果编制后，须进行100%自检：

| 自检内容 | 自检要求 | 覆盖比例 |
|---------|---------|---------|
| 工程量计算 | 逐项复核计算过程和结果 | 100% |
| 定额套用 | 逐项检查定额子目选用和换算 | 100% |
| 材料价格 | 检查材料价格来源和时效 | 100% |
| 费率取费 | 检查取费基数和费率 | 100% |
| 汇总计算 | 复核汇总计算和税金 | 100% |
| 编制说明 | 检查编制说明的完整性 | 100% |

**第十条** 自检要求：
1. 自检不是走形式，要真正逐项复核
2. 自检发现错误的，立即修改后重新自检
3. 自检完成后填写《编制人自检记录表》，随底稿提交
4. 自检记录应载明：自检日期、自检范围、发现问题、修改情况

### 4.2 二级审核（项目负责人复核）

**第十一条** 项目负责人对成果文件进行重点复核：

| 复核内容 | 复核要求 | 覆盖比例 |
|---------|---------|---------|
| 关键工程量 | 对造价影响大的工程量项目重点复核 | 抽检≥50% |
| 综合单价 | 审核综合单价的合理性 | 抽检≥50% |
| 大额子目 | 金额占比前20%的子目逐项复核 | 100% |
| 定额争议 | 审核有争议的定额套用是否合理 | 100% |
| 材料调差 | 审核材料调差计算是否正确 | 100% |
| 整体合理性 | 分析造价指标是否在合理范围内 | 100% |

**第十二条** 关键工程量判定标准：
1. 单项金额占总分部分项工程费5%以上的
2. 工程量计算复杂的（如土方、钢筋、混凝土等）
3. 定额套用存在争议的
4. 涉及变更签证的

**第十三条** 二级审核要求：
1. 项目负责人应亲自执行复核，不得委托他人代行
2. 复核中发现系统性问题的，应要求编制人全面修改后重新提交
3. 复核意见以书面形式反馈编制人，编制人须逐条回复
4. 复核完成后填写《项目负责人复核记录表》

### 4.3 三级审核（技术负责人审定）

**第十四条** 技术负责人对成果文件进行终审：

| 审定内容 | 审定要求 | 覆盖比例 |
|---------|---------|---------|
| 重大偏差 | 检查是否存在重大计算偏差 | 重点检查 |
| 政策合规 | 检查是否符合相关政策法规要求 | 100% |
| 成果完整性 | 检查成果文件是否完整、格式是否规范 | 100% |
| 争议事项 | 审定重大技术争议的处理意见 | 100% |
| 审核报告 | 审定审核报告的表述和结论 | 100% |
| 风险事项 | 评估成果文件可能存在的风险 | 100% |

**第十五条** 三级审核要求：
1. 三级审核是成果文件签发的必要前提
2. 技术负责人审定意见为最终意见，项目组必须执行
3. 审定通过后，技术负责人在成果文件上签字并加盖执业印章
4. 审定完成后填写《技术负责人审定记录表》

### 4.4 审核记录管理

**第十六条** 三级审核全程留痕，审核记录包括：
1. 《编制人自检记录表》
2. 《项目负责人复核记录表》
3. 《技术负责人审定记录表》
4. 各级审核发现的问题及修改情况
5. 争议事项的处理记录

**第十七条** 审核记录作为项目档案的组成部分，按 RC-BIZ-001《项目管理规范》第八章"项目档案归档"的要求归档保存。

## 第五章 造价成果文件质量标准

**第十八条** 造价成果文件应满足以下质量标准：

### 5.1 精度标准

| 质量指标 | 允许偏差 | 说明 |
|---------|---------|------|
| 工程量偏差 | ≤±3% | 与正确计算结果对比 |
| 综合单价偏差 | ≤±5% | 与合理单价对比 |
| 总价偏差 | ≤±3% | 与正确总价对比 |
| 费率取费 | 0偏差 | 必须严格按合同和政策执行 |
| 税金计算 | 0偏差 | 必须按现行税率计算 |

**说明：**
- 偏差率 = |（成果值 - 正确值）/ 正确值| × 100%
- "正确值"指经三级审核确认后的最终审定值
- 精度标准适用于内部质量检查，不作为对客户的承诺

### 5.2 格式标准

1. 成果文件格式符合行业规范和公司模板
2. 封面要素齐全（项目名称、委托方、编制单位、日期等）
3. 编制说明完整（编制依据、工程概况、特殊处理说明等）
4. 表格格式统一、数据清晰
5. 电子文件与纸质文件内容一致

### 5.3 依据标准

1. 每项计算都有明确的依据（图纸、定额、合同、签证等）
2. 依据文件现行有效，不使用已废止的定额或文件
3. 依据文件编号准确，可以查证

**第十九条** 成果文件质量评分标准（用于质量检查）：

| 评分维度 | 权重 | 满分标准 |
|---------|------|---------|
| 计算准确性 | 40% | 工程量偏差≤±2%，综合单价偏差≤±3%，总价偏差≤±2% |
| 依据充分性 | 20% | 每项计算有明确依据，依据现行有效 |
| 格式规范性 | 15% | 格式完全符合模板要求 |
| 审核执行 | 15% | 三级审核全部执行到位、记录完整 |
| 编制说明 | 10% | 说明完整、清晰、有针对性 |

## 第六章 重大问题报告机制

**第二十条** 造价咨询过程中发现以下重大问题的，须在24小时内逐级上报：

1. 委托方或施工方要求出具不实造价成果的
2. 发现送审资料存在重大虚假或伪造嫌疑的
3. 造价偏差超过精度标准且无法在限期内修正的
4. 发现前期出具的成果文件存在重大错误的
5. 涉及重大争议事项（争议金额超过项目总金额10%的）
6. 发现公司内部人员与客户串通损害第三方利益的
7. 可能对公司执业资格或声誉产生不利影响的事项
8. 监管部门关注的敏感事项

**第二十一条** 重大问题报告流程：

```
发现人 → 项目负责人（即时）→ 技术负责人（2小时内）→ 管理层（24小时内）
```

**第二十二条** 重大问题报告要求：
1. 报告形式：先口头报告，后补书面报告
2. 书面报告内容：问题描述、涉及金额、可能影响、已采取的措施、建议处理方案
3. 技术负责人接到报告后，应在24小时内做出处理指示
4. 需要向委托方或监管部门报告的，由管理层决定并组织实施

**第二十三条** 对隐瞒不报或延迟报告的处理：
1. 隐瞒重大问题不报的，给予记过处分
2. 延迟报告导致公司被动或损失的，加重处理
3. 造成严重后果的，按质量事故处理

## 第七章 质量检查与考核

**第二十四条** 公司建立定期质量检查制度：

### 7.1 检查频次与范围

| 检查类型 | 频次 | 范围 | 执行人 |
|---------|------|------|--------|
| 项目审核检查 | 每个项目 | 三级审核执行情况 | 技术负责人/项目负责人 |
| 季度成果抽查 | 每季度 | 已完成项目的成果质量 | 技术负责人组织 |
| 年度质量评估 | 每年 | 全年质控体系运行效果 | 管理层 |

### 7.2 季度成果抽查

1. 每季度从已完成项目中随机抽取不少于20%的项目进行成果质量检查
2. 大型项目（合同金额≥30万元）每季度100%检查
3. 检查方式：指定独立复核人重新计算关键工程量，与成果文件对比
4. 检查结果形成《季度质量检查报告》，向管理层汇报

### 7.3 质量评分与考核

**第二十五条** 质量检查结果纳入绩效考核，与 RC-HR-002《绩效考核管理制度》衔接：

1. **成果质量维度**（占绩效考核权重30%）：以三级审核记录和质量检查结果为依据
2. **季度质量扣分**：季度检查中发现问题的，按以下标准扣分：

| 问题等级 | 扣分标准 | 责任人 |
|---------|---------|--------|
| 计算书不完整 | 每处扣1分 | 编制人 |
| 定额套用错误 | 每处扣3分 | 编制人 |
| 工程量偏差>±3% | 每项扣5分 | 编制人 |
| 工程量偏差>±5% | 每项扣10分 | 编制人+项目负责人 |
| 材料价格明显失实 | 每项扣5分 | 编制人 |
| 审核流于形式 | 每次扣5分 | 复核人/审定人 |
| 成果文件存在事实性差错 | 每处扣10分 | 编制人+项目负责人+审定人 |

3. **年度质量评级**：根据全年质量检查结果，对项目团队和个人进行质量评级（A/B/C/D），作为晋升和培训的重要参考

## 第八章 质量事故分级与处理

**第二十六条** 质量事故按严重程度分为三级：

### 8.1 一级事故（特别严重）

**认定标准：**
1. 出具虚假造价成果文件的（故意高估冒算或低估少算）
2. 造价成果存在重大遗漏，导致委托方或第三方做出错误决策并造成重大经济损失的
3. 因造价质量问题被监管部门吊销执业资格或暂停业务的
4. 因造价质量问题被追究刑事责任的
5. 与客户或施工方串通，损害国家利益或第三方利益的

**处理措施：**
1. 直接责任人：解除劳动合同，公司保留追究法律责任和经济赔偿的权利
2. 项目负责人：记过处分，扣减当年全部绩效工资，降级使用
3. 技术负责人：警告处分，扣减当年50%绩效工资
4. 向行业协会和监管部门报告

### 8.2 二级事故（严重）

**认定标准：**
1. 造价成果存在重大错误，被委托方投诉或监管部门通报的
2. 工程量偏差超过±5%或总价偏差超过±5%的
3. 因造价质量问题被客户起诉（未造成重大损失的）
4. 隐瞒重大问题不报，导致公司被动的

**处理措施：**
1. 直接责任人：记过处分，扣减当季绩效工资的50%~100%，当年不得晋升
2. 项目负责人：警告处分，扣减当季绩效工资的30%
3. 复核人/审定人（未尽审核责任的）：警告处分，扣减当季绩效工资的20%

### 8.3 三级事故（一般）

**认定标准：**
1. 造价成果存在一般性差错，被委托方指出并要求修改的
2. 工程量偏差在±3%~±5%之间的
3. 计算底稿不完整、不规范的
4. 审核流程执行不规范的

**处理措施：**
1. 直接责任人：书面警告，限期整改（5个工作日内完成修改）
2. 项目负责人：提醒谈话
3. 纳入当季度绩效考核扣分

**第二十七条** 质量事故认定程序：
1. 技术负责人或项目负责人提出质量事故认定建议
2. 听取当事人陈述和申辩
3. 管理层集体研究决定
4. 处理结果书面通知当事人

**第二十八条** 质量事故记录：
1. 所有质量事故均须记录在案
2. 质量事故记录作为员工年度考核、晋升、续聘的重要参考
3. 一级事故记录永久保存，二三级事故记录保存5年

## 第九章 技术标准与工具管理

**第二十九条** 公司建立统一的技术标准体系：
1. 现行有效的定额库（四川省定额+补充定额）
2. 材料价格信息库（各市州信息价+市场询价记录）
3. 造价指标数据库（各类工程单方造价指标）
4. 标准模板库（成果文件模板、计算书模板）

**第三十条** 造价软件管理：
1. 公司统一采购正版造价软件，不得使用盗版或破解版
2. 软件版本统一升级，确保计算规则一致
3. 电子成果文件应同时保存软件源文件和通用格式文件
4. 软件计算结果应能导出完整的计算过程

**第三十一条** 材料价格管理：
1. 优先采用工程所在地造价管理部门发布的信息价
2. 无信息价的材料，应进行市场询价（至少3家供应商报价）
3. 市场询价应记录询价日期、供应商名称、联系方式、报价内容
4. 材料价格采用截止时点在编制说明中明确注明

---

## 第十章 继续教育与培训

**第三十二条** 公司保障造价人员接受继续教育的权利和时间：
1. 注册造价工程师每年完成规定的继续教育学时
2. 造价员按规定参加岗位培训
3. 公司每年组织不少于40学时的内部业务培训

**第三十三条** 培训内容应包括：
1. 最新定额和计价规范更新
2. 质量检查发现的共性问题和改进措施
3. 典型造价案例研讨
4. 造价软件操作技能
5. 法律法规和职业道德

**第三十四条** 质量事故案例纳入培训教材，做到"处理一个、教育一片"。
