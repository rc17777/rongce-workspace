## 第一章 总则

**第一条** 为规范公司业务承接和合同管理流程，防范业务风险和合同风险，保障公司合法权益，根据《中华人民共和国民法典》《会计师事务所执业许可和监督管理办法》《工程造价咨询企业管理办法》及相关法律法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司承接的全部业务，涵盖业务承接评估、客户准入、合同审批、合同签订、合同履行管理和合同档案管理全过程。

**第三条** 业务承接与合同管理基本原则：

1. **风险可控**：不承接超出执业能力或存在重大执业风险的业务
2. **程序合规**：所有业务承接和合同签订必须履行规定的审批程序
3. **书面为凭**：所有业务合作必须以书面合同为依据，禁止无合同先干活
4. **分级审批**：根据项目风险和规模实行分级审批，权责对等
5. **台账管理**：所有合同纳入台账统一管理，电子归档，到期提醒

## 第二章 业务承接评估

**第四条** 承接任何新项目或新客户业务前，项目承接部门须完成《项目承接评估表》（见附件1），评估内容包括：

| 评估维度 | 评估内容 | 风险等级 |
|---------|---------|---------|
| **客户信誉** | 客户过往履约记录、行业口碑、信用状况、是否存在行政处罚或诉讼 | 高/中/低 |
| **客户背景** | 客户单位性质（政府/国企/民企）、行业、规模、管理层诚信状况 | 高/中/低 |
| **项目难度** | 项目技术难度、所需专业人员、时间紧迫程度、资料可得性 | 高/中/低 |
| **利润预期** | 预计收入、预计成本、毛利率、付款方式与周期 | 高/中/低 |
| **执业能力** | 公司是否具备相应执业资质、专业人员配置是否充足、是否需要分包 | 高/中/低 |
| **独立性** | 是否存在利益冲突、是否符合独立性要求（审计类项目必评） | 高/中/低 |
| **法规合规** | 项目是否合法合规，是否存在政策红线，是否为禁入领域 | 高/中/低 |

**第五条** 评估结果分为三个等级：

| 评级 | 条件 | 承接决策 |
|------|------|---------|
| **可承接** | 七个维度均无高风险，低风险不超过2项 | 正常承接，进入合同流程 |
| **有条件承接** | 存在1~2项高风险，或3项以上中风险 | 需制定风险应对措施后承接 |
| **不予承接** | 存在3项及以上高风险，或存在独立性障碍、法律红线 | 退回，不承接 |

**第六条** 对于以下特殊情形，无论评估结果如何，须报总经理审定：

补充设置项目毛利率预警：预计项目毛利率低于15%的，原则上不予承接；确有战略价值、示范价值或重大客户价值的，须由项目承接部门提交书面说明，列明亏损上限、质量资源、回款保障和退出条件，经总经理特别批准后方可承接。

1. 合同金额超过100万元的重大项目
2. 涉及政府重大专项、社会敏感度高的项目
3. 需要联合投标或业务分包的复杂项目
4. 其他管理层认为需要特别关注的项目

## 第三章 新客户准入

**第七条** 新客户（首次合作客户）准入执行以下流程：

```
背景调查 → 业务评估 → 风险评级 → 审批
```

**第八条** 背景调查：

业务承接部门应对新客户进行必要的背景调查，内容包括：
1. **工商信息**：通过国家企业信用信息公示系统查询客户工商登记信息、股东结构、经营异常、行政处罚等情况
2. **信用状况**：通过中国裁判文书网、中国执行信息公开网查询是否存在重大诉讼、失信被执行记录
3. **行业声誉**：通过行业协会、既往合作方了解客户业务口碑和信用情况
4. **管理层诚信**：了解客户主要负责人是否存在违法违规记录

政府机关、事业单位等客户可适当简化背景调查，以合规性核实为主。

**第九条** 背景调查完成后，填写《新客户准入审批表》（见附件2），连同业务评估结果，按风险评级提交相应层级审批。

## 第四章 合同审批

### 4.1 审批层级

**第十条** 根据项目风险等级和合同金额，实行三级审批：

| 项目类型 | 审批层级 | 审批人 |
|---------|---------|--------|
| A类项目（高风险/大额，合同金额≥50万） | 三级审批 | 业务部门→财务审核→法务审核→总经理审批 |
| B类项目（中等，合同金额10~50万） | 二级审批 | 业务部门→财务审核→法务审核→分管副总审批 |
| C类项目（常规，合同金额<10万） | 一级审批 | 业务部门→财务审核→法务审核→部门负责人审批 |

**第十一条** A类项目特指以下情形：
1. 合同金额≥50万元
2. 首次合作的陌生客户，合同金额≥20万元
3. 涉及政府重大专项、社会敏感度高
4. 需要出具专业意见且可能产生重大社会影响
5. 管理层认定的其他高风险项目

### 4.2 审批流程

**第十二条** 合同审批标准流程：

```
业务部门起草合同草案
  ↓
部门负责人初审（业务可行性/技术方案/资源配置）
  ↓
财务负责人审核（收费价格/付款条件/开票要求/成本核算）
  ↓
法务审核（合同条款/法律风险/违约责任/争议解决）
  ↓
对应层级审批人批准
  ↓
盖章签订
```

**第十三条** 财务审核重点：
1. 收费价格是否合理，是否低于公司最低收费标准
2. 付款方式和时间节点是否有利于公司现金流
3. 发票类型和开票时间要求是否可满足
4. 差旅费、交通费等垫付费用是否明确由客户承担
5. 违约金的额度是否合理

**第十四条** 法务审核重点：
1. 合同主体资格审查
2. 权利义务是否对等，有无明显不公平条款
3. 违约责任条款是否合理
4. 争议解决条款是否对公司有利
5. 保密条款是否完备
6. 知识产权归属是否明确（咨询类项目重点审查）

**第十五条** 合同审批使用公司标准格式合同模板的，可适当简化审批；使用客户提供的格式合同，或修改标准合同核心条款的，必须严格逐条审核。

### 4.3 特殊情形

**第十六条** 紧急签约：因投标截止等原因需要紧急签约的，经部门负责人确认后，可先通过微信/邮件等方式逐级报批，事后3个工作日内补签书面审批单。

**第十七条** 框架合同：与政府机关、大型国企签订的年度框架合同，按单次任务书/委托书逐单审批，框架合同本身按最高审批层级审批一次。

## 第五章 合同签订

**第十八条** 所有业务必须以书面合同为依据。合同须至少一式两份，双方各执一份，公司留存原件归档。

**第十九条** 签订合同前须确认：
1. 合同审批流程已完成，审批单签字齐全
2. 客户方签约人具有合法授权（非法定代表人签字须有授权委托书）
3. 合同文本与审批通过的文本一致
4. 合同编号已按规则编制

**第二十条** 合同编号规则：`RC-[公司代码]-[年份]-[序号]`

| 字段 | 说明 |
|------|------|
| 公司代码 | KJS=会计师事务所 / GCZ=工程咨询公司 |
| 年份 | 4位年份，如2026 |
| 序号 | 3位流水号，如001 |

示例：`RC-KJS-2026-001` = 融策会计师事务所2026年第1号合同

**第二十一条** 合同专用章由办公室指定专人保管，合同盖章须凭已完成审批的《合同审批单》方可办理，不得先盖章再补流程。

## 第六章 合同台账管理

**第二十二条** 办公室（或指定合同管理部门）建立《合同管理台账》，对全部合同进行登记管理。台账至少包含以下信息：

| 字段 | 内容说明 |
|------|---------|
| 合同编号 | 按编号规则编制 |
| 合同名称 | 项目全称 |
| 客户名称 | 委托方全称 |
| 合同金额 | 含税金额 |
| 签订日期 | 合同签署日期 |
| 承办部门 | 业务承接部门 |
| 项目负责人 | 指定项目经理 |
| 合同期限 | 起止日期 |
| 付款方式 | 分期/一次性，各阶段金额和时间 |
| 履约状态 | 在行/已完成/已终止 |
| 归档状态 | 已归档/未归档 |
| 到期提醒 | 距合同到期日的提醒设置 |

**第二十三条** 合同台账实行电子化管理，使用公司指定软件或Excel表格维护。每周由合同管理员核对更新一次，确保台账与实际一致。

**第二十四条** 合同到期前30日，合同管理员应提醒承办部门负责人，判断是否续约或启动新合同流程。

**第二十五条** 合同原件应在签订后7个工作日内完成扫描归档，电子版存入公司合同管理系统/共享文件夹，纸质版移交档案室保管。

## 第七章 合同履行管理

**第二十六条** 项目负责人对合同履行负主要责任，应定期对照合同条款检查：
1. 工作进度是否符合合同约定的时间节点
2. 工作成果是否符合合同约定的质量标准
3. 客户付款是否按期到账
4. 是否存在需要变更合同的情形

**第二十七条** 财务部门应跟踪合同回款情况：
1. 按月编制《合同回款跟踪表》
2. 对超过约定付款日期30天未到账的，向项目负责人发出催款提醒
3. 对超过60天未到账的，报部门负责人和分管副总，启动催款程序

**第二十八条** 合同履行过程中出现下列情形的，应及时向分管副总报告：
1. 客户要求改变合同约定的主要工作内容或验收标准
2. 客户出现重大经营异常或管理层变更
3. 项目预计成本将超出合同金额的80%
4. 因不可抗力或其他原因可能导致无法按期完成
5. 客户出现拖欠行为或其他违约迹象

## 第八章 合同变更与解除

**第二十九条** 合同变更适用情形：
1. 工作范围增减
2. 合同金额调整
3. 完成期限调整
4. 付款方式变更
5. 其他双方协商一致需要变更的内容

**第三十条** 合同变更流程：
1. 项目负责人提出变更申请，填写《合同变更审批单》
2. 部门负责人审核变更必要性和可行性
3. 财务审核变更对项目收益的影响
4. 按原合同审批层级报批
5. 与客户签订书面《补充协议》或变更确认函
6. 更新合同台账

**第三十一条** 在收到客户正式变更要求或公司书面变更确认前，不得先行执行变更后的工作内容。

**第三十二条** 合同解除适用情形：
1. 双方协商一致解除
2. 客户单方违约（如长期拖欠费用、不提供必要资料等）
3. 不可抗力导致合同无法继续履行
4. 法律法规或政策变化导致合同无法履行

**第三十三条** 合同解除流程：
1. 项目负责人提交《合同解除申请》，说明解除原因
2. 法务审核解除依据和潜在法律风险
3. 总经理审批（A类项目须报股东会知悉）
4. 以书面形式通知客户，留存送达凭证
5. 做好已完成工作的交接和费用结算
6. 更新合同台账，标注"已终止"

**第三十四条** 本制度由办公室会同财务部门共同制定，经总经理批准后施行。
