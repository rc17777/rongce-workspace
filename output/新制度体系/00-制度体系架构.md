## 一、体系设计原则

1. **合法合规**：所有制度以《劳动合同法》《住房公积金管理条例》及四川省地方法规为底线，不设置任何违法条款
2. **业务导向**：制度服务于审计+造价双主业运营，不为制度而制度
3. **精简可执行**：中小事务所不搞大企业官僚化，每条制度都要能落地
4. **双公司适用**：会计师事务所与工程咨询公司共用制度体系，特殊事项单独标注适用范围
5. **数智化友好**：制度设计预留信息化接口，便于后续上线OA/项目管理系统

## 六、制度编号规则

```
RC - [类别码] - [序号]

RC        = 融策（RongCe）
类别码：
  GOV  = 公司治理（Governance）
  HR   = 人力资源（Human Resources）
  FIN  = 财务管理（Finance）
  BIZ  = 业务运营（Business）
  QC   = 质量控制（Quality Control）
  ADM  = 行政管理（Administration）
  SPL  = 专项制度（Special）
序号：
  001~999，按类别内编制顺序递增
```

示例：`RC-HR-001` = 融策-人力资源-第001号制度
