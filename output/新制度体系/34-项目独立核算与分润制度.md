# 四川融策项目独立核算与分润制度

> **制度编号**：RC-BIZ-006  
> **版本**：V1.0  
> **编制日期**：2026年7月22日  
> **适用范围**：四川融策会计师事务所有限公司、四川融策工程咨询有限公司业务部门  
> **优先级**：P1  
> **引用制度**：RC-FIN-002（项目收入确认与回款管理制度）、RC-FIN-006（可分配利润核算细则）、RC-BIZ-001（项目管理规范）

## 第一章 总则

**第一条** 为建立项目独立核算机制，实现"多劳多得、优质优得"的激励目标，同时确保公司整体利益与个人利益的平衡，特制定本制度。

**第二条** 本制度适用于公司所有以项目制运作的业务，包括：
1. 审计类项目（财务审计、绩效评价、专项审计、资产清查等）
2. 工程咨询类项目（预算编制、结算审核、全过程咨询等）
3. 其他经公司批准实行项目核算的业务

**第三条** 核心原则：
1. **项目独立核算**：每个项目单独建账，独立计算收入、成本、利润
2. **利润分享制**：分润性质为"经营利润分享"，非固定薪酬组成部分，需员工签字确认
3. **风险共担**：项目盈利时分享利润，项目亏损时按责任承担损失
4. **核算透明**：项目负责人有权查阅本项目全部核算数据

**第四条** 核算基础：本制度以 RC-FIN-006《可分配利润核算细则》定义的"可分配利润"为分润计算基础。

---

## 第二章 分润比例与分配规则

**第五条** 项目可分配利润的分配比例：

| 分配对象 | 分配比例 | 说明 |
|---------|---------|------|
| 公司留存 | **55%** | 用于公司运营、资质维护、风险储备 |
| 项目负责人 | **25%** | 含管理责任、客户关系维护、技术指导 |
| 项目组员池 | **20%** | 由项目负责人在组内进行二次分配 |

**第六条** 阶梯分润机制：

根据项目毛利润率设定分润门槛，未达门槛不分润：

| 项目毛利润率 | 分润系数 | 说明 |
|------------|---------|------|
| < 15% | 0 | 不分润，利润全额归公司 |
| 15% ~ 25% | 0.8 | 按标准比例的80%分润 |
| 25% ~ 40% | 1.0 | 按标准比例全额分润 |
| > 40% | 1.1 | 按标准比例的110%分润（超额激励） |

**计算公式**：
```
实际分润总额 = 可分配利润 × 对应比例 × 分润系数
```

**第七条** 项目组员池的二次分配：
1. 项目负责人拥有组员池（20%部分）的二次分配权
2. 二次分配方案须在项目结项后15个工作日内提交财务部
3. 分配依据：个人工时占比、工作质量评分、贡献度
4. 分配方案须经部门主任审核确认
5. 若项目负责人未按时提交方案，由部门主任代为分配

**第八条** 分润发放方式：
1. **里程碑预发**：报告交付并经客户签收时，预发应得分润的 **40%~50%**
   - 审计类项目：预发40%
   - 工程咨询类项目：预发50%
2. **回款清算补足**：项目尾款到账后30个工作日内，清算补足剩余分润
3. **发放条件**：预发时项目须通过三级复核，无重大质量问题

## 第三章 亏损承担机制

**第九条** 项目亏损（可分配利润为负）时，按以下规则区分责任：

### 3.1 责任分类

| 责任类型 | 认定标准 | 承担比例 |
|---------|---------|---------|
| 主观过失 | 报价失误、工期失控、质量返工、客户投诉导致扣款 | 亏损额的 **30%~50%** |
| 客观因素 | 政策变化、客户破产、不可抗力、公司决策失误 | 亏损额的 **≤10%** |
| 混合责任 | 主客观因素交织 | 按责任比例分摊 |

### 3.2 责任认定程序

1. **发起**：财务部在项目核算显示亏损后10个工作日内出具《亏损分析报告》
2. **初评**：部门主任在5个工作日内提出责任认定意见
3. **复核**：质量管理部对质量相关因素出具意见
4. **审定**：总经理在10个工作日内最终审定责任比例
5. **告知**：书面告知项目负责人，项目负责人有5个工作日申诉期

### 3.3 个人保护机制

1. **年度扣款上限**：个人年度累计扣款不超过其当年分润总额的 **50%**
2. **分期扣减**：单次扣款超过月工资30%的，可分3~6个月从工资中扣减
3. **最低保障**：扣减后月收入不低于成都市最低工资标准
4. **豁免情形**：新入职员工（入职不满6个月）首次担任项目负责人的，亏损承担比例减半

**第十条** 亏损承担的执行：
1. 主观过失部分：从项目负责人分润中直接扣减；分润不足的，从绩效工资中扣减
2. 客观因素部分：公司承担主要损失，项目组承担不超过10%
3. 扣减须书面通知员工，员工签字确认

## 第四章 离职人员分润处理

**第十一条** 分润归属按里程碑节点确定：

| 里程碑节点 | 分润归属比例 | 节点定义 |
|-----------|------------|---------|
| 立项完成 | 10% | 合同签订、项目启动会完成 |
| 执行阶段 | 40% | 现场工作完成、底稿编制完成 |
| 结项交付 | 50% | 报告交付、客户验收、归档完成 |

**第十二条** 离职人员分润结算规则：

| 离职时项目状态 | 结算方式 |
|--------------|---------|
| 已完成立项，执行中 | 按已完成节点结算（最高10%+已完成执行部分按比例） |
| 已完成执行，待结项 | 按立项10%+执行40%=50%结算 |
| 已结项未回款 | 按全额50%+结算，回款后支付 |
| 已结项已回款 | 全额结算，离职前发放 |

**第十三条** 离职分润的特别规定：
1. 已结项项目的离职人员分润**不低于50%**（对应其已完成的全部工作）
2. 分润性质为"经营利润分享"，员工入职时须签署《项目分润确认书》，明确知悉分润规则
3. 因严重违纪被辞退的，未发放分润按已完成节点结算额的50%发放（非全额取消）
4. 主动离职且未完成工作交接的，扣减10%作为交接补偿

**第十四条** 接替人员的分润：
1. 接替离职人员工作的员工，从后续里程碑节点开始享有分润权
2. 接替人员分润总额不超过原项目负责人应得总额
3. 具体分配由部门负责人协调确定

## 第五章 核算管理

**第十五条** 项目核算台账：
1. 财务部为每个项目建立独立核算台账
2. 台账内容包括：合同金额、收入确认、直接成本、公摊成本、毛利润、分润计算
3. 项目负责人每月可查阅一次台账（每月15日后）

**第十六条** 核算周期：
1. **月度**：归集直接成本，更新项目进度
2. **季度**：复盘公摊率，更新项目利润预估
3. **里程碑**：交付确认后15个工作日内出具利润结算单
4. **年度**：次年1月31日前完成全年项目利润终审

**第十七条** 争议处理：
1. 项目负责人对核算数据有异议的，在收到结算单后10个工作日内书面申请复核
2. 财务部在15个工作日内完成复核并书面答复
3. 对复核结果仍有异议的，提请总经理裁定

---

## 第六章 特殊情形处理

**第十八条** 联合项目（跨部门协作）：
1. 两个及以上部门参与的项目，在立项时确定各部门工作量和成本分担比例
2. 各部门分别核算各自成本和分润
3. 具体规则参见 RC-BIZ-007《跨部门协同与交叉营销奖励办法》

**第十九条** 分包项目：
1. 分包部分的收入和成本单独核算
2. 分包管理费（如有）计入项目直接成本
3. 分包商费用不计入项目组分润基数

**第二十条** 跨年项目：
1. 按年度分段核算，每年末进行阶段性结算
2. 预发分润按当年已完成工作量计算
3. 项目终结时进行总清算

---

## 第七章 监督与责任

**第二十一条** 禁止以下行为：
1. 虚报项目成本（含工时虚报）
2. 隐瞒项目收入或延迟确认收入
3. 将非本项目成本计入本项目
4. 利用分润机制进行利益输送

**第二十二条** 违规处理：
1. 一般违规：追回违规分润，取消当年分润资格
2. 严重违规：追回全部违规分润，给予行政处分，降级或调岗
3. 涉嫌违法的：移交司法机关处理
