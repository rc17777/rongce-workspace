## 第三章 入职与试用期

**第七条** 入职手续：
新员工报到时需提供以下材料：
1. 身份证原件及复印件
2. 学历学位证书原件及复印件
3. 执业资格证书（如有）
4. 前单位离职证明（应届毕业生除外）
5. 近期一寸免冠照片2张
6. 银行卡信息（用于工资发放）
7. 体检报告（3个月内有效）

公司提供材料不全的，给予5个工作日补正期限。

**第八条** 试用期：
1. 劳动合同期限1年以上不满3年的，试用期不超过2个月
2. 劳动合同期限3年以上的，试用期不超过6个月
3. 试用期包含在劳动合同期限内
4. 试用期工资不低于转正工资的80%，且不低于成都市最低工资标准

**第九条** 试用期考核与转正：
1. 试用期满前15天，由部门负责人进行转正考核
2. 考核内容包括：工作能力、工作态度、团队融入、岗位匹配度
3. 考核合格的，按期转正
4. 考核不合格的，公司可延长试用期（总试用期不超过法定上限）或依法解除劳动合同
5. 转正结果书面通知员工

**第十条** 岗位调动：
1. 因工作需要调整员工岗位的，公司与员工协商一致后执行
2. 调岗涉及薪酬变化的，按薪酬管理制度执行
3. 调岗双方未达成一致的，维持原岗位安排

## 第四章 离职管理

**第十一条** 辞职：
1. 试用期员工辞职：提前3天书面通知
2. 正式员工辞职：提前30天书面通知
3. 辞职申请提交后，员工应配合完成工作交接
4. 公司应在离职当日出具离职证明、办理社保和档案转移手续

**第十二条** 工作交接：
1. 离职员工应在最后工作日前完成以下交接：
   - 在手项目工作交接（含项目资料、进度说明、客户对接情况）
   - 公司财物归还（电脑、门禁卡、钥匙等）
   - 财务借款清算
   - 电子账号及权限移交
2. 交接清单由交接双方及监交人签字确认

**第十三条** 离职结算：
1. 工资结算至最后工作日，在下一个发薪日发放
2. 绩效工资按已完成工作量比例结算
3. 未休年休假按日工资300%折算支付（含已支付的100%正常工资，额外支付200%）
4. 公司不得以离职为由扣减已劳动对应的工资和绩效

**第十四条** 公司解除劳动合同的情形：
1. 协商一致解除
2. 试用期被证明不符合录用条件
3. 严重违反公司规章制度（见第十一章）
4. 严重失职、营私舞弊，给公司造成重大损害
5. 被依法追究刑事责任
6. 医疗期满后不能从事原工作也不能从事另行安排的工作
7. 不能胜任工作，经培训或调岗后仍不能胜任

公司依据上述第2~7项解除劳动合同的，应事先通知工会并说明理由。

## 第五章 考勤管理

**第十五条** 工作时间：
- 标准工时制：周一至周五，上午9:00~12:00，下午13:30~17:30
- 午休时间：12:00~13:30
- 因项目需要弹性工作的，由部门负责人在合理范围内灵活安排

**第十六条** 考勤方式：
- 公司采用电子考勤（打卡/人脸识别/OA系统）
- 员工应如实考勤，不得代打卡
- 因外勤、出差等原因无法正常考勤的，应在OA系统提交外勤/出差申请

**第十七条** 迟到与早退：
- 迟到/早退30分钟以内：每月累计3次以内不扣减工资
- 迟到/早退30分钟以上：按事假半天处理
- 每月累计迟到/早退超过5次：超出部分按事假处理
- 公司不以考勤扣款作为管理手段，考勤记录作为工作纪律的参考依据

**第十八条** 旷工：
- 未经请假或请假未获批准而缺勤的，视为旷工
- 旷工期间不发放工资
- 连续旷工3天或年度累计旷工5天的，视为严重违反规章制度

## 第六章 休假制度

**第十九条** 法定节假日：
按国务院公布的法定节假日安排执行。

**第二十条** 带薪年休假：

| 累计工作年限 | 年休假天数 |
|------------|----------|
| 满1年不满10年 | 5天 |
| 满10年不满20年 | 10天 |
| 满20年 | 15天 |

- 累计工作年限含入职公司前的社会工龄（员工提供社保缴费证明或前单位工作证明）
- 年休假可分段使用，最小单位0.5天
- 确因工作需要不能休假的，按日工资300%支付未休年休假工资报酬
- 公司福利年假：司龄满3年的员工，额外享受2天公司福利年假

**第二十一条** 病假：
1. 员工因病或非因工负伤需要治疗的，凭医疗机构证明请病假
2. 3天以内病假不扣减工资
3. 超过3天的，按薪酬管理制度病假工资标准执行
4. 紧急情况下可先电话请假，事后2个工作日内补交证明

**第二十二条** 婚假：
- 法定婚假3天
- 晚婚（男25周岁/女23周岁以上初婚）增加7天（参照四川省规定）
- 婚假期间工资全额发放

**第二十三条** 产假/陪产假：
- 女员工产假158天（含四川省延长产假60天）
- 男员工陪产假20天（四川省规定）
- 产假期间享受生育津贴（由生育保险支付），不足部分由公司补足

**第二十四条** 丧假：
- 直系亲属（父母、配偶、子女、祖父母、外祖父母）去世：3天
- 需异地奔丧的：增加2天路程假
- 丧假期间工资全额发放

**第二十五条** 其他假期：
- 工伤假：按《工伤保险条例》执行
- 计划生育假：按国家和四川省规定执行

## 第七章 薪酬福利概述

**第二十六条** 公司薪酬体系详见《薪酬管理制度》（RC-HR-001），主要包括：
- 基本工资 + 岗位工资 + 绩效工资（月度）
- 项目奖金（按项目结算）
- 年终奖（按年度发放）

**第二十七条** 法定福利：
- 五项社会保险（养老、医疗、失业、工伤、生育）
- 住房公积金（公司和个人各7%）

**第二十八条** 公司福利：
1. **节日慰问**：春节、中秋等重大节日发放节日慰问金或礼品
2. **生日关怀**：员工生日当月发放生日礼金
3. **健康体检**：每年一次免费健康体检
4. **团建活动**：每季度一次部门团建，每年一次公司团建
5. **学习补贴**：通过执业资格考试的，报销考试费用并给予一次性奖励
6. **午餐补贴**：工作日提供午餐补贴（具体标准由管理层确定）

## 第八章 行为规范

**说明**：公司各项制度中使用的"综合管理部"与"人力资源部"，在公司内部指同一管理部门或同一管理职能（根据公司规模及岗位设置可合并为"综合管理部"或指定专人履职），制度条款中对上述两个名称的引用应作统一理解，不影响相关审批、复核等程序的效力。

**第二十九条** 公司倡导以下行为：

1. **专业敬业**：认真对待每一项工作，按时保质完成任务
2. **诚实守信**：对客户、对同事、对公司坦诚相待
3. **尊重他人**：尊重同事的人格、隐私和工作成果
4. **积极沟通**：有问题及时沟通，不积压不回避
5. **持续学习**：主动学习新知识、新技能，提升专业能力
6. **爱护公物**：珍惜公司设备和资源，节约办公成本
7. **维护形象**：对外交往中维护公司形象和专业形象

**第三十条** 职业操守（审计/造价从业人员特别要求）：

1. 保持职业独立性，不受利益关系影响专业判断
2. 对执业过程中知悉的客户信息严格保密
3. 不得利用职务之便谋取个人私利
4. 不得出具虚假报告或隐瞒重要事实
5. 不得接受可能影响独立性的礼品或宴请
6. 发现违法违规行为应及时向项目负责人或管理层报告

## 第九章 奖惩制度

**第三十一条** 奖励：

公司对以下行为予以表彰和奖励：

| 奖励类型 | 适用情形 | 奖励方式 |
|---------|---------|---------|
| 通报表扬 | 工作表现突出、获得客户书面好评 | 全公司通报 |
| 专项奖金 | 为公司赢得重要客户、提出有效管理改进建议 | 500~5,000元奖金 |
| 年度优秀 | 年度考核A等 | 荣誉证书 + 奖金 |
| 晋升推荐 | 连续两次考核B等以上 | 优先晋升机会 |

**第三十二条** 违纪处理原则：
1. 以教育为主、惩戒为辅
2. 违纪行为与处理措施相当，不过度惩戒
3. 处理前给予员工陈述和申辩的机会
4. 同一违纪行为不重复处理

**第三十三条** 一般违纪及处理：

以下行为属于一般违纪，首次给予口头提醒，再次发生给予书面警告：

1. 月度迟到/早退累计超过5次
2. 工作时间从事与工作无关的活动（经提醒不改）
3. 未经批准擅自调班
4. 不配合工作交接（情节较轻）
5. 未按规定着装（如有着装要求）

**第三十四条** 书面警告：

以下行为给予书面警告（全公司通报），同时影响当季绩效考核：

1. 季度内累计3次一般违纪
2. 工作中弄虚作假（情节较轻，如虚报少量工时）
3. 泄露公司一般性内部信息（非客户秘密）
4. 不服从合理工作安排（经沟通后仍不执行）
5. 因个人疏忽导致工作差错（未造成重大损失）

**第三十五条** 严重违纪（可解除劳动合同）：

以下行为属于严重违反公司规章制度，公司可依法解除劳动合同且不支付经济补偿：

1. **连续旷工3天或年度累计旷工5天**
2. **提供虚假入职材料**（学历造假、资格证书造假、隐瞒竞业限制等）
3. **利用职务之便贪污、挪用公款或收受客户回扣**
4. **故意泄露客户商业秘密或审计/造价工作秘密，造成实际损失**
5. **出具虚假审计/造价报告**
6. **私自承接业务或在外兼职影响本职工作（经提醒不改）**
7. **故意损坏公司重要财物或数据，造成重大损失（直接经济损失5,000元以上）**
8. **被依法追究刑事责任**
9. **威胁、恐吓、殴打同事或客户**
10. **年度内累计收到3次书面警告**

**第三十六条** 违纪处理程序：
1. 发现违纪行为后，由部门负责人或人力资源部调查核实
2. 给予员工陈述和申辩的机会（书面或口头）
3. 一般违纪：部门负责人处理，报人力资源部备案
4. 书面警告：人力资源部处理，报管理层审批
5. 解除劳动合同：人力资源部提出，经管理层审批，通知工会后执行
6. 处理结果书面通知员工，员工签字确认

## 第十章 违纪追溯期

**第三十七条** 违纪行为追溯期为 **1年**（与劳动仲裁时效一致）：
1. 违纪行为发生超过1年的，不再作为处理依据
2. 连续性的违纪行为，从行为终了之日起计算
3. 追溯期内再次违纪的，前次违纪可作为累计依据

**第三十八条** 涉及经济利益损害（贪污、挪用、回扣等）的违纪行为，不受追溯期限制，公司保留追究法律责任的权利。

## 第十一章 培训与发展

**第三十九条** 公司支持员工职业发展：

1. **入职培训**：新员工入职时进行公司文化、制度、业务流程培训
2. **在岗培训**：部门内部的业务指导和传帮带
3. **外部培训**：根据工作需要和个人发展需要，安排参加外部培训
4. **继续教育**：支持员工完成执业资格继续教育要求
5. **执业资格考试**：鼓励员工考取CPA、造价师等执业资格

**第四十条** 培训费用：
1. 公司统一安排的培训，费用由公司承担
2. 员工个人申请的外部培训，经审批后公司承担全部或部分费用
3. 公司出资超过5,000元的专项培训，可约定服务期（按《劳动合同法》第22条执行）

**第四十一条** 职业发展通道：
- **专业序列**：助理 → 初级 → 中级 → 高级 → 资深 → 专家
- **管理序列**：项目成员 → 项目经理 → 部门副主任 → 部门主任 → 副总经理 → 总经理
- 双通道并行，专业序列高级别享受管理序列同等待遇

## 第十二章 安全与保密

**第四十二条** 办公安全：
1. 遵守办公场所消防安全规定
2. 下班时关闭电脑、空调等电器设备
3. 个人贵重物品自行保管
4. 发现安全隐患及时报告

**第四十三条** 信息安全：
1. 工作电脑设置密码保护，定期更换密码
2. 不得将工作文件存储在个人设备（未经批准）
3. 不得将公司账号密码告知他人
4. 离职时交还所有公司信息和数据

**第四十四条** 保密义务：
1. 员工对在工作中知悉的客户信息、公司商业秘密负有保密义务
2. 保密义务不因劳动合同解除或终止而免除
3. 保密范围：客户财务数据、审计工作底稿、造价成果文件、公司经营数据、薪酬信息等
4. 违反保密义务造成损失的，公司有权追究赔偿责任

**第四十五条** 公司不监控员工个人通讯内容。因业务需要，公司可以对工作邮箱、工作电脑中的工作文件进行合理管理，但应事先告知员工。
