# 四川融策薪酬管理制度

> **制度编号**：RC-HR-001  
> **版本**：V1.0  
> **编制日期**：2026年7月22日  
> **适用范围**：四川融策会计师事务所有限公司、四川融策工程咨询有限公司全体在职员工  
> **优先级**：P0  
> **替代说明**：本制度替代原薪酬管理制度（已废止），自发布之日起执行  
> **审核人**：________ | **批准人**：________

---

## 第一章 总则

**第一条** 为建立科学合理的薪酬体系，体现按劳分配、多劳多得原则，吸引和留住优秀人才，根据《中华人民共和国劳动法》《中华人民共和国劳动合同法》《住房公积金管理条例》及四川省、成都市相关法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司与员工建立劳动关系的全体员工（含试用期员工）。

**第三条** 薪酬管理基本原则：
1. **合法合规**：不低于成都市最低工资标准，依法缴纳社会保险和住房公积金
2. **内部公平**：同岗同酬，薪酬与岗位价值、个人能力、工作贡献相匹配
3. **外部竞争**：参考成都地区同行业薪酬水平，保持合理竞争力
4. **激励导向**：绩效导向，鼓励多劳多得、优质优得
5. **透明可预期**：薪酬结构清晰，计算规则明确，员工可自行核算

---

## 第二章 薪酬结构

**第四条** 员工薪酬由以下部分构成：

```
月度薪酬 = 基本工资 + 岗位工资 + 绩效工资
项目奖金 = 按项目结算（非月度发放）
年终奖 = 按年度经营情况和个人考核发放
福利 = 法定福利 + 公司福利
```

### 2.1 基本工资

**第五条** 基本工资是员工的基础保障性收入，不低于成都市当年度最低工资标准。

- 2025年度基本工资标准：**2,100元/月**（如遇成都市调整最低工资标准，自动跟随调整）
- 基本工资按月固定发放，不与绩效考核挂钩
- 试用期基本工资不低于转正后基本工资的80%

### 2.2 岗位工资

**第六条** 岗位工资体现岗位价值和职责差异，按岗位等级确定。

**岗位等级与薪酬带宽：**

| 岗位等级 | 岗位类别 | 岗位工资区间（元/月） | 典型岗位 |
|---------|---------|-------------------|---------|
| G1 | 初级执行层 | 2,000 ~ 3,000 | 审计助理、造价员 |
| G2 | 中级执行层 | 3,000 ~ 5,000 | 审计员、造价师 |
| G3 | 高级执行层 | 4,500 ~ 7,000 | 高级审计员、高级造价师 |
| G4 | 项目负责人层 | 6,000 ~ 9,000 | 项目经理、项目总监 |
| G5 | 部门管理层 | 8,000 ~ 12,000 | 部门主任、副主任 |
| G6 | 高管层 | 10,000 ~ 18,000 | 总经理、副总经理、首席合伙人 |

**说明：**
- 同一岗位等级内设若干薪档，员工在岗位等级内按年度调薪晋档
- 新员工入职时，由人力资源部根据学历、经验、执业资格等确定初始薪档
- 岗位工资在员工晋升/降级/调岗时相应调整

### 2.3 绩效工资

**第七条** 绩效工资与员工绩效考核结果挂钩，按月预发、季度清算。

**绩效工资基数：**

| 岗位等级 | 绩效工资基数（元/月） |
|---------|-------------------|
| G1 | 1,500 ~ 2,000 |
| G2 | 2,000 ~ 3,500 |
| G3 | 3,000 ~ 5,000 |
| G4 | 4,000 ~ 7,000 |
| G5 | 5,000 ~ 9,000 |
| G6 | 8,000 ~ 15,000 |

**绩效工资计算方式：**
- 月度预发：绩效工资基数 × 60%（每月固定发放）
- 季度清算：根据季度考核结果，当季绩效系数高于0.6的部分补发差额；当季绩效系数不高于0.6的，不回溯追回已发部分，当期不补发

| 考核等级 | 绩效系数 | 说明 |
|---------|---------|------|
| A（优秀） | 1.3 | 季度补发 = 基数 ×（1.3 - 0.6）|
| B（良好） | 1.0 | 季度补发 = 基数 ×（1.0 - 0.6）|
| C（合格） | 0.8 | 季度补发 = 基数 ×（0.8 - 0.6）|
| D（待改进） | 0.5 | 不补发，预发的60%不追回，下季度预发基数按基数×50%执行 |

**离职结算**：员工离职时，绩效工资按实际已完成工作量占考核周期总工作量的比例结算，不因离职而扣减已劳动对应的绩效工资。

### 2.4 项目奖金

**第八条** 项目奖金按项目完成情况发放，体现多劳多得。

**项目奖金计算：**
```
项目奖金总额 = 项目净收入 × 项目奖金提取比例
个人项目奖金 = 项目奖金总额 × 个人贡献系数 / ∑个人贡献系数
```

**项目奖金提取比例：**

| 项目类型 | 提取比例 | 说明 |
|---------|---------|------|
| 审计类项目 | 15% ~ 25% | 根据项目复杂度和利润率确定 |
| 造价类项目 | 12% ~ 20% | 根据项目规模和利润率确定 |
| 咨询类项目 | 18% ~ 28% | 根据项目附加值确定 |

**发放条件：**
- 项目已完成并交付成果
- 项目回款率达到70%以上
- 项目质量复核通过
- 项目奖金在项目回款后30日内发放

**个人贡献系数**由项目经理根据成员实际参与工时、工作难度、成果质量提出分配方案，经部门负责人审核后执行。

### 2.5 年终奖

**第九条** 年终奖根据公司年度经营业绩和员工年度考核结果发放。

**年终奖计算：**
```
年终奖 = 年终奖基数 × 公司年度经营系数 × 个人年度绩效系数
```

- **年终奖基数**：员工12月份基本工资 + 岗位工资
- **公司年度经营系数**：由执行董事/股东会根据年度利润目标完成情况确定（0.5 ~ 1.5）
- **个人年度绩效系数**：

| 年度考核等级 | 个人年度绩效系数 |
|------------|---------------|
| A（优秀） | 1.5 |
| B（良好） | 1.0 |
| C（合格） | 0.6 |
| D（待改进） | 0 |

年终奖于次年春节前发放。年度中途入职的员工按实际在岗月数折算。年度中途离职的员工，年终奖按实际在岗月数÷12×年终奖基数×个人年度绩效系数折算，于次年春节前与其他员工同期发放。

## 第三章 薪酬调整

**第十条** 薪酬调整分为以下类型：

1. **年度普调**：每年4月，根据公司经营状况和市场薪酬水平，对全员进行薪酬审视和调整。调整幅度由管理层确定。
2. **晋升调薪**：员工岗位等级晋升时，岗位工资调整至新等级对应区间。
3. **转正调薪**：试用期员工转正后，薪酬按转正标准执行。
4. **特殊调薪**：因市场薪酬变化、特殊贡献等原因，由部门负责人申请，经管理层审批后可进行个别调整。

**第十一条** 薪酬调整审批权限：

| 调整类型 | 审批权限 |
|---------|---------|
| 年度普调方案 | 执行董事/股东会批准 |
| G1~G3晋升调薪 | 部门负责人申请 → 管理层审批 |
| G4及以上晋升调薪 | 管理层提名 → 执行董事审批 |
| 特殊调薪 | 部门负责人申请 → 管理层审批 |

## 第四章 社会保险与住房公积金

**第十二条** 公司依法为员工缴纳五项社会保险（养老、医疗、失业、工伤、生育），个人承担部分从工资中代扣代缴。

**第十三条** 住房公积金缴存规定：

1. **缴存基数**：员工上年度月平均工资总额（含基本工资+岗位工资+绩效工资+月均项目奖金）。新入职员工以当月工资为基数。
2. **缴存比例**：公司和个人各缴 **7%**（在5%~12%法定范围内）
3. **基数调整**：每年7月调整一次，以上年度月均工资为依据
4. **基数上限**：不超过成都市上年度职工月平均工资的3倍
5. **基数下限**：不低于成都市最低工资标准

**第十四条** 社会保险和住房公积金的个人缴存部分，由公司从员工工资中代扣代缴，在工资条中单独列示。

## 第五章 特殊情形薪酬

### 5.1 试用期薪酬

**第十五条** 试用期薪酬标准：
- 基本工资：转正标准的100%（不低于最低工资标准）
- 岗位工资：转正标准的80%
- 绩效工资：转正基数的80%
- 不参与项目奖金分配
- 试用期期限按劳动合同约定（合同1~3年试用期不超过2个月，3年以上不超过6个月）

### 5.2 病假薪酬

**第十六条** 员工因病或非因工负伤需要休病假的：

1. **3天以内（含）**：工资全额发放，不扣减
2. **4天至规定医疗期内**：按以下标准发放病假工资

| 工龄 | 病假工资标准 |
|------|-----------|
| 不满2年 | 本人工资的70% |
| 满2年不满4年 | 本人工资的80% |
| 满4年不满6年 | 本人工资的90% |
| 满6年不满8年 | 本人工资的100% |
| 满8年及以上 | 本人工资的100% |

3. **保底标准**：病假工资最低不低于成都市最低工资标准的80%（即1,680元/月，随最低工资标准调整）
4. "本人工资"指病假前12个月的月平均工资

### 5.3 工伤薪酬

**第十七条** 员工因工受伤的，按《工伤保险条例》及四川省实施办法执行。停工留薪期内原工资福利待遇不变。

### 5.4 事假薪酬

**第十八条** 员工请事假期间不发放工资（日工资 = 月工资 ÷ 21.75天）。

### 5.5 加班薪酬

**第十九条** 公司提倡高效工作，减少不必要的加班。确需加班的：

1. **工作日延时加班**：按小时工资的150%支付加班费，或经员工同意安排补休
2. **休息日加班**：优先安排补休，不能补休的按小时工资的200%支付
3. **法定节假日加班**：按小时工资的300%支付加班费（不得以补休替代）
4. 小时工资 = 月工资 ÷ 21.75 ÷ 8
5. 加班须经部门负责人事先审批，未经审批的自行延长工作时间不计为加班

### 5.6 带薪休假薪酬

**第二十条** 员工依法享受带薪年休假、婚假、产假、陪产假、丧假等，休假期间工资按国家规定全额发放。

## 第六章 薪酬发放

**第二十一条** 薪酬发放：
1. **发放日期**：每月15日发放上月工资（遇节假日提前至最近工作日）
2. **发放方式**：银行转账至员工指定账户
3. **工资条**：每月发放工资时同步提供工资明细（电子或纸质），列明各项构成及扣款
4. **薪酬保密**：公司实行薪酬保密制度，员工不得向他人打听、泄露薪酬信息。但本制度规定的薪酬结构和计算规则对全员公开

**第二十二条** 工资扣除限制：
- 除法律法规规定（个税、社保、公积金、法院执行等）外，公司不得随意扣减员工工资
- 因员工原因造成公司经济损失需要赔偿的，每月扣减金额不超过当月工资的20%，且扣减后剩余工资不低于最低工资标准

## 第七章 附则

**第二十三条** 本制度由人力资源部负责解释和执行。如遇制度条款与法律法规冲突，以法律法规为准。

**第二十四条** 本制度经管理层审议通过后发布施行，修改时同。

**第二十五条** 本制度自2026年__月__日起施行，原薪酬管理制度同时废止。
