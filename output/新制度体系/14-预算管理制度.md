## 第一章 总则

**第一条** 为加强公司预算管理，合理配置资源，提高经营效率，依据《企业财务通则》及相关法规，结合公司实际，制定本制度。

**第二条** 本制度适用于四川融策会计师事务所有限公司（以下简称"事务所"）和四川融策工程咨询有限公司（以下简称"工程公司"）的年度预算管理。

**第三条** 预算管理原则：

1. **战略导向**：预算服务于公司年度经营目标和发展战略；
2. **全员参与**：各部门共同参与预算编制，非财务部门单独的事务；
3. **量入为出**：支出预算以收入预测为基础，不搞赤字预算；
4. **刚性约束**：预算一经批准，严格执行，非经审批不得突破。

---

## 第二章 预算组织与职责

**第四条** 预算管理组织架构：

| 角色 | 职责 |
|------|------|
| **总经理** | 预算最终审批人，对预算执行负总责 |
| **财务部** | 预算归口管理部门，负责汇总、审核、跟踪、分析 |
| **各部门** | 编制本部门预算，执行预算，分析偏差 |
| **股东会** | 审批年度预算方案及重大预算调整 |

**第五条** 财务部在预算管理中的具体职责：

1. 制定预算编制指引和模板；
2. 汇总各部门预算，编制公司预算草案；
3. 组织预算审议会议；
4. 月度跟踪、季度分析预算执行情况；
5. 编制预算执行报告。

## 第三章 预算编制

**第六条** 预算周期：每年1月1日至12月31日为一个预算年度。

**第七条** 预算编制时间表：

| 时间节点 | 工作内容 | 责任人 |
|---------|---------|--------|
| 11月上旬 | 财务部发布下一年度预算编制指引 | 财务部 |
| 11月中旬 | 各部门编制部门预算草案 | 各部门负责人 |
| 11月下旬 | 财务部汇总审核，编制公司预算草案 | 财务部 |
| 12月上旬 | 管理层审议预算草案 | 总经理+各部门负责人 |
| 12月中旬 | 修改完善，形成正式预算方案 | 财务部 |
| 12月下旬 | 总经理审批 / 股东会审批（重大预算） | 总经理/股东会 |
| 12月底 | 下达各部门执行 | 财务部 |

**第八条** 预算编制内容：

### 收入预算

| 项目 | 编制依据 |
|------|---------|
| 审计业务收入 | 存量合同+新增业务预测 |
| 造价咨询收入 | 存量合同+新增业务预测 |
| 其他业务收入 | 历史数据+市场判断 |

### 支出预算

| 项目 | 编制方法 |
|------|---------|
| 人工成本 | 现有人员薪酬+预计增员+调薪 |
| 办公租金 | 合同金额+预计调整 |
| 办公费用 | 历史数据×调整系数 |
| 差旅费 | 项目计划×人均标准 |
| 培训费 | 按薪酬总额3%-5%（参照RC-HR-005） |
| 折旧摊销 | 现有资产+预计采购 |
| 税费 | 收入预测×税率 |
| 其他 | 逐项编制 |

### 资本支出预算

| 项目 | 说明 |
|------|------|
| 固定资产采购 | 电脑、办公家具、软件等 |
| 装修改造 | 办公场所改善 |
| 其他大额支出 | 单项≥2万元 |

**第九条** 预算编制方法：

1. **增量预算法**：以历史数据为基础，结合业务增长预期进行调整（适用于稳定业务）；
2. **零基预算法**：不参考历史数据，逐项论证支出必要性（适用于新项目、新业务）；
3. **弹性预算法**：设定不同业务量情景下的预算方案（适用于收入不确定性较大的情况）。

## 第四章 预算审批

**第十条** 预算审批权限：

| 审批层级 | 权限 |
|---------|------|
| 总经理 | 审批年度预算方案（总额不变前提下内部调整） |
| 股东会 | 审批涉及总额变动、重大投资的预算方案 |

**第十一条** 预算方案经批准后，由财务部以《年度预算通知书》形式下达各部门，明确各部门预算额度和执行要求。

---

## 第五章 预算执行

**第十二条** 各部门应严格按照批准的预算执行，不得擅自突破。

**第十三条** 预算执行跟踪：

| 频次 | 内容 | 责任人 |
|------|------|--------|
| **月度** | 各部门实际支出与预算对比，偏差分析 | 财务部 |
| **季度** | 季度预算执行分析报告，管理层审议 | 财务部+总经理 |
| **半年度** | 半年度预算执行总结，评估调整需求 | 财务部 |
| **年度** | 年度预算执行总结，纳入年终考核 | 财务部 |

**第十四条** 月度预算执行报告应于次月10日前完成，内容包括：

1. 各部门本月预算执行情况（预算数/实际数/偏差率）；
2. 累计预算执行情况；
3. 重大偏差说明及改进建议。

**第十五条** 偏差管理：

| 偏差幅度 | 处理要求 |
|---------|---------|
| ≤10% | 正常波动，部门自行控制 |
| 10%-15% | 部门负责人需向财务部书面说明原因 |
| ≥15% | 部门负责人需向总经理书面说明原因，并提出改进措施 |
| ≥20% | 总经理约谈部门负责人，必要时启动预算调整 |

## 第六章 预算调整

**第十六条** 预算调整原则：严格控制，非必要不调整。

**第十七条** 预算调整类型：

### 一、半年度调整

每年6-7月，各部门可申请半年度预算调整，调整范围：

1. 部门内部预算科目间调剂（总额不变）：部门负责人审批，报财务部备案；
2. 部门预算总额增加≤10%：总经理审批；
3. 部门预算总额增加＞10%：股东会审批。

### 二、临时调整

发生重大变化时可申请临时预算调整：

1. 新增重大项目（合同金额≥50万元）；
2. 政策变化导致业务大幅波动；
3. 不可抗力事件；
4. 其他经总经理认定的重大变化。

**第十八条** 预算调整审批流程：

```
部门提交调整申请（说明原因、调整内容、影响分析）
  → 财务部审核
  → 总经理审批（或股东会审批）
  → 财务部更新预算并通知执行
```

## 第七章 预算考核

**第十九条** 预算执行情况纳入部门负责人年度绩效考核（参照 RC-HR-002 绩效考核管理制度），考核指标：

| 指标 | 权重 | 评分标准 |
|------|------|---------|
| 收入预算完成率 | 30% | 实际/预算×100%，≥100%满分 |
| 支出预算控制率 | 30% | 实际/预算×100%，≤100%满分 |
| 预算偏差率 | 20% | |偏差|≤10%满分，每增5%扣10分 |
| 预算编制质量 | 20% | 编制及时性、数据准确性、说明完整性 |

**第二十条** 预算考核结果与部门负责人年终奖金挂钩：

1. 预算考核≥90分：全额发放绩效奖金；
2. 预算考核80-89分：按考核得分比例发放；
3. 预算考核＜80分：扣减绩效奖金20%。

---

## 第八章 附则

**第二十一条** 财务部应逐步推进预算信息化建设，实现预算编制、执行跟踪、分析报告的线上化管理。

**第二十二条** 预算相关档案（预算方案、执行报告、调整审批等）由财务部保存，保存期限不少于五年。

**第二十三条** 本制度未尽事宜，依照国家相关法规及公司财务制度执行。

**第二十四条** 本制度由财务部负责解释和修订，经总经理批准后施行。
