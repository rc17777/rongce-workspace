> **制度编号**：RC-FIN-001

## 第一章 总则

**第一条** 为规范公司财务报销管理，加强费用控制，提高资金使用效率，根据《中华人民共和国会计法》《企业财务通则》《发票管理办法》及国家税务法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司全体员工因公发生的各类费用报销，包括：
1. 差旅费（交通、住宿、餐饮补贴、市内交通等）
2. 业务招待费
3. 办公采购费
4. 私车公用补贴
5. 其他因公发生的合理费用

**第三条** 报销管理基本原则：
1. **真实性**：报销事项必须真实发生，严禁虚报、冒领
2. **合理性**：费用标准合理，与业务需要相匹配
3. **及时性**：费用发生后及时报销，不跨年度积压
4. **凭证合规**：报销必须取得合法有效的原始凭证
5. **先批后支**：大额支出和可预见的支出应事先审批

**第四条** 本制度与 RC-HR-001《薪酬管理制度》中差旅补贴标准有关联的，以本制度为准。

## 第二章 报销流程与审批权限

### 2.1 报销基本流程

**第五条** 费用报销标准流程：

```
经办人填单 → 附原始凭证 → 部门负责人审核 → 财务复核 → 审批人审批 → 出纳付款
```

**各环节时限要求：**

| 环节 | 责任人 | 时限要求 | 工作内容 |
|------|--------|---------|---------|
| 填单 | 经办人 | 费用发生后30日内 | 填写报销单、粘贴票据、附证明材料 |
| 部门审核 | 部门负责人 | 收到后2个工作日内 | 审核业务真实性、合理性 |
| 财务复核 | 财务人员 | 收到后2个工作日内 | 审核票据合规性、金额准确性、标准符合性 |
| 审批 | 审批人 | 收到后1个工作日内 | 审批是否同意报销 |
| 付款 | 出纳 | 审批通过后1个工作日内 | 银行转账或现金支付 |

### 2.2 审批权限

**第六条** 费用报销审批权限：

| 费用类型 | 金额范围 | 审批人 |
|---------|---------|--------|
| 差旅费 | 不限 | 部门负责人审核 → 财务复核 → 分管副总审批 |
| 业务招待费 | ≤500元/次 | 部门负责人审核 → 财务复核 → 部门负责人审批 |
| 业务招待费 | 500~2,000元/次 | 部门负责人审核 → 财务复核 → 分管副总审批 |
| 业务招待费 | >2,000元/次 | 部门负责人审核 → 财务复核 → 总经理审批 |
| 办公采购 | ≤2,000元/次 | 部门负责人审核 → 财务复核 → 部门负责人审批 |
| 办公采购 | 2,000~10,000元/次 | 部门负责人审核 → 财务复核 → 分管副总审批 |
| 办公采购 | >10,000元/次 | 部门负责人审核 → 财务复核 → 总经理审批 |
| 私车公用 | 不限 | 部门负责人审核 → 财务复核 → 分管副总审批 |

**第七条** 总经理本人的费用报销，由执行董事/股东会指定人员审批。

**第八条** 项目费用报销，除上述审批流程外，还须经项目经理确认该费用属于项目预算范围。

## 第三章 差旅费报销标准

### 3.1 出差审批

**第九条** 员工出差须事先填写《出差审批单》，经部门负责人批准后方可出差。紧急出差的，可先电话请示，出差后2个工作日内补办手续。

**第十条** 《出差审批单》应载明：出差事由、目的地、出差天数、预计费用、交通方式等。

### 3.2 住宿费标准

**第十一条** 住宿费按出差目的地和职级执行限额标准，在限额内凭发票据实报销，超标准部分自理。

**四川省内住宿费标准（元/间·天）：**

| 职级 | 成都市 | 省内其他市州 |
|------|--------|------------|
| 总经理/执行董事 | 400 | 350 |
| 副总经理 | 350 | 300 |
| 部门负责人（中层） | 300 | 260 |
| 一般员工 | 260 | 220 |

**省外住宿费标准（元/间·天）：**

| 职级 | 一线城市 | 二线城市 | 三线及以下城市 |
|------|---------|---------|-------------|
| 总经理/执行董事 | 600 | 450 | 380 |
| 副总经理 | 500 | 400 | 340 |
| 部门负责人（中层） | 450 | 350 | 300 |
| 一般员工 | 380 | 300 | 260 |

**城市分类说明：**
- **一线城市**：北京、上海、广州、深圳
- **二线城市**：杭州、南京、武汉、重庆、天津、苏州、西安、郑州、长沙、青岛、大连、宁波、厦门、合肥、昆明、贵阳、南宁、福州、济南、哈尔滨、沈阳等省会及经济较发达城市
- **三线及以下城市**：除上述城市以外的其他城市

**说明：**
- 住宿标准为单间/标准间限额。两人同行且为同性别的，鼓励合住标准间，住宿标准上浮20%
- 出差期间由接待单位或客户安排住宿的，不报销住宿费
- 参加会议、培训由主办方统一安排住宿的，按实际发生费用报销，不受上述标准限制

### 3.3 交通费标准

**第十二条** 城市间交通费按出差实际需要和以下标准报销：

| 职级 | 飞机 | 高铁/动车 | 火车 | 轮船 |
|------|------|----------|------|------|
| 总经理/执行董事 | 商务舱/经济舱 | 一等座 | 软卧 | 一等舱 |
| 副总经理 | 经济舱 | 一等座/二等座 | 软卧/硬卧 | 一等舱/二等舱 |
| 部门负责人 | 经济舱 | 二等座 | 硬卧 | 二等舱 |
| 一般员工 | 经济舱 | 二等座 | 硬卧/硬座 | 二等舱/三等舱 |

**说明：**
- 飞机出行须事先在《出差审批单》中注明原因，经部门负责人批准
- 4小时以内高铁可达的目的地，原则上应乘坐高铁
- 因航班取消、延误等不可抗力原因产生的额外交通费用，凭相关证明据实报销
- 出差途中因工作需要产生的改签费，据实报销；因个人原因产生的改签费，自理

### 3.4 出差餐饮补贴

**第十三条** 出差期间餐饮补贴按天计算，包干使用，无需提供发票：

| 职级 | 四川省内（元/天） | 省外（元/天） |
|------|----------------|-------------|
| 总经理/执行董事 | 120 | 150 |
| 副总经理 | 100 | 130 |
| 部门负责人（中层） | 80 | 110 |
| 一般员工 | 70 | 100 |

**说明：**
- 出差当天按实际出差天数计算（出发日和返回日各按半天计算）
- 由接待单位或客户安排餐饮的，相应扣减补贴（安排一餐扣减当日补贴的40%，安排两餐及以上扣减当日全部补贴）
- 餐饮补贴含途中伙食补助

### 3.5 市内交通补贴

**第十四条** 出差目的地市内交通按天包干：

| 职级 | 四川省内（元/天） | 省外（元/天） |
|------|----------------|-------------|
| 总经理/执行董事 | 80 | 100 |
| 副总经理 | 60 | 80 |
| 部门负责人（中层） | 50 | 60 |
| 一般员工 | 40 | 50 |

**说明：**
- 包干使用，无需提供发票
- 如出差期间由客户或接待单位提供市内交通的，不发放当日市内交通补贴
- 往返机场、火车站的出租车/网约车费用可据实报销，不占用包干额度

### 3.6 出差综合补贴

**第十五条** 出差综合补贴为出差期间的通讯、洗衣等杂费补贴，按天包干：

| 职级 | 省内（元/天） | 省外（元/天） |
|------|-------------|-------------|
| 总经理/执行董事 | 50 | 60 |
| 副总经理 | 40 | 50 |
| 部门负责人（中层） | 30 | 40 |
| 一般员工 | 30 | 30 |

**第十六条** 出差补贴汇总：

| 职级 | 四川省内合计（元/天） | 省外合计（元/天） |
|------|-------------------|-----------------|
| 总经理/执行董事 | 250 | 310 |
| 副总经理 | 200 | 260 |
| 部门负责人（中层） | 160 | 210 |
| 一般员工 | 140 | 180 |

> 注：合计 = 餐饮补贴 + 市内交通补贴 + 综合补贴，均为包干，无需发票。

### 3.7 特殊出差情形

**第十七条** 长期驻场及偏远地区出差：

1. 连续驻场15日及以上的，经项目负责人和财务负责人事前批准，可采用月租房或协议住宿方式，月度住宿费用原则上不超过对应职级日住宿标准×30×60%；已由客户或接待单位提供住宿的，不重复报销。
2. 前往县城以下乡镇、村组等偏远地区，确因当地消费和交通条件导致正常就餐困难的，餐饮补贴可在标准基础上上浮30%，由项目负责人在出差审批或报销单中说明地点和事由。
3. 投标保证金、履约保证金等项目性资金，不作为个人报销处理，按《投标管理制度》和《资金管理制度》办理申请、支付、登记、退回及核销。

**第十八条** 以下特殊情形按相应规定处理：

1. **常驻外地项目组**：经批准在固定城市连续工作超过30天的，住宿费标准可上浮10%，出差补贴按标准的70%发放
2. **参加外部会议/培训**：由主办方统一安排食宿的，仅报销往返交通费和主办方收取的会议/培训费
3. **客户现场出差**：在客户现场工作的，如客户提供免费工作餐，扣减当日餐饮补贴的50%
4. **节假日出差**：因项目紧急需要在法定节假日出差的，出差补贴按标准的120%发放

## 第四章 私车公用补贴

**第十九条** 员工因工作需要使用私人车辆的，须事先填写《私车公用审批单》，经部门负责人和财务负责人或总经理指定审批人批准后方可执行。

**第二十条** 私车公用补贴标准：

| 车辆类型 | 补贴标准（元/公里） | 说明 |
|---------|------------------|------|
| 燃油车 | 0.8 | 含油费、折旧、保养、保险等综合成本 |
| 新能源车（纯电/插混） | 0.6 | 含电费、折旧、保养、保险等综合成本 |

**第二十一条** 私车公用管理要求：
1. 每次私车公用须记录：出发地、目的地、里程数、事由，由部门负责人签字确认
2. 行驶里程以导航软件记录为准
3. 途中产生的停车费、过路过桥费据实报销（需提供票据）
4. 私车公用期间发生交通事故的，由保险公司理赔，公司不承担额外责任
5. 员工应确保车辆保险齐全（交强险+商业三者险+车损险），保险过期不得私车公用

**第二十二条** 以下情形不享受私车公用补贴：
1. 日常上下班通勤
2. 未经审批自行驾车的
3. 办理纯私人事务绕道的

## 第五章 业务招待费

**第二十三条** 业务招待费是指因业务需要招待客户、合作伙伴等发生的餐饮、礼品等费用。

**第二十四条** 业务招待费实行事前审批制度：

| 预计金额 | 审批权限 |
|---------|---------|
| ≤500元 | 部门负责人审批 |
| 500~2,000元 | 分管副总审批 |
| >2,000元 | 总经理审批 |

**第二十四条** 业务招待费报销须提供：
1. 正规餐饮发票（发票抬头为公司全称）
2. 《业务招待审批单》（载明招待对象、人数、事由）
3. 如有礼品费用，须附礼品清单

**第二十五条** 业务招待费年度控制：
- 公司年度业务招待费总额不超过当年营业收入的合理比例（具体比例由管理层根据税务筹划确定）
- 各部门业务招待费实行预算控制，超预算须总经理特别审批

## 第六章 办公采购报销

**第二十六条** 办公用品、设备采购报销流程：

1. **日常办公用品**（≤2,000元）：由行政部统一采购，部门负责人审批
2. **专业工具/软件**（2,000~10,000元）：使用部门申请，分管副总审批
3. **大型设备/批量采购**（>10,000元）：使用部门申请，总经理审批

**第二十七条** 办公采购报销须附：
1. 正规发票（发票抬头为公司全称，税号准确）
2. 购物清单或明细
3. 审批通过的采购申请单
4. 实物验收入库单（固定资产类须附资产登记表）

**第二十八条** 员工个人垫付办公采购的，须事先获得审批同意，事后凭票报销。未经事先审批的个人垫付，原则上不予报销。

## 第七章 发票管理

**第二十九条** 报销发票基本要求：
1. 发票抬头必须为公司全称，不得使用简称
2. 发票内容与实际消费一致，不得变更品名
3. 发票须在有效期内（自开票日起6个月内报销）
4. 发票联次齐全，加盖发票专用章

**第三十条** 增值税专用发票管理：
1. 能取得专票的，应当取得专票（可抵扣进项税额）
2. 专票信息：公司名称、统一社会信用代码、地址电话、开户行及账号——须完整准确
3. 专票应在认证期限内（360天）送交财务部门认证抵扣
4. 因个人原因导致专票无法认证的，相应税额由经办人承担

**第三十一条** 以下情形不予报销：
1. 虚假发票、伪造发票
2. 抬头错误或内容不实的发票
3. 过期发票（超过开票日期6个月）
4. 白条、收据（除政府非税收入收据等合法凭证外）
5. 涂改、挖补的发票

## 第八章 报销时限与跨年费用

**第三十二条** 报销时限：
1. **日常费用**：费用发生后30个自然日内提交报销，逾期须书面说明原因，经部门负责人和财务负责人共同签字后方可报销
2. **差旅费用**：出差结束后15个工作日内提交报销
3. **跨年费用**：当年发生的费用，最迟在次年3月31日前报销完毕。超过次年3月31日的，原则上不予报销（因审计业务年底集中出报告的特殊情况，可适当放宽至4月30日，但须经总经理审批）

**第三十三条** 禁止条款：
1. **不得设置"超期扣减报销金额"等克扣条款**。员工因公发生的合理费用，即使超期提交，经书面说明原因后应全额报销，不得按比例扣减
2. 不得以"预算不足"为由拒绝已审批的合理费用报销
3. 不得要求员工自行承担应由公司负担的业务费用

**第三十四条** 超期报销处理：
1. 超期30日以内的：经办人书面说明原因，部门负责人审批
2. 超期30~90日的：经办人书面说明原因，分管副总审批
3. 超期90日以上的：经办人书面说明原因，总经理审批
4. 无正当理由超期的，给予提醒；年度内累计超期3次以上的，纳入绩效考核扣分项

## 第九章 项目费用管理

**第三十五条** 项目费用管理遵循 RC-BIZ-001《项目管理规范》的相关规定。

**第三十六条** 项目费用预算：
1. 项目经理在项目立项时编制项目费用预算
2. 项目费用预算经部门负责人审批后执行
3. 项目费用超预算10%以上的，须报部门负责人追加审批

**第三十七条** 项目费用归集：
1. 项目组成员出差至项目现场的费用，直接归集到对应项目
2. 无法直接归属的费用，按合理方法在项目间分摊
3. 财务部门按项目建立费用台账，定期与项目经理核对

**第三十八条** 项目费用控制：
- 审计类项目：差旅费+招待费合计不超过项目收入的15%
- 造价类项目：差旅费+招待费合计不超过项目收入的12%
- 超出比例的，须总经理特别审批

## 第十章 监督与违规处理

**第三十九条** 财务部门有权对报销事项进行核查，对不符合规定的报销申请有权退回或拒绝。

**第四十条** 违规报销处理：

| 违规情形 | 处理方式 |
|---------|---------|
| 票据不合规（非主观故意） | 退回补正，限期重新提交 |
| 超标准报销（未经审批） | 超出部分不予报销 |
| 虚报冒领（金额≤500元） | 全额退回报销款 + 书面警告 |
| 虚报冒领（金额>500元） | 全额退回报销款 + 记过处分 + 扣减当季绩效工资 |
| 伪造票据/虚构业务 | 全额退回报销款 + 解除劳动合同 + 保留追究法律责任的权利 |

**第四十一条** 审批人责任：
1. 审批人未尽审核责任，导致违规报销通过的，承担连带管理责任
2. 年度内所审批的报销出现3次以上违规的，取消该审批人相应审批权限，限期整改

## 第十一章 附则

**第四十二条** 本制度由财务部门负责解释和执行。如遇制度条款与法律法规冲突，以法律法规为准。

**第四十三条** 本制度经管理层审议通过后发布施行，修改时同。

**第四十四条** 本制度自2026年__月__日起施行，原财务报销管理制度同时废止。

**第四十五条** 费用标准调整：本制度中的费用标准由管理层根据公司经营情况和物价水平适时调整，调整后的标准以书面通知形式发布，与本制度具有同等效力。
