## 第一章 总则

**第一条** 为建立公平、透明的人才晋升机制，打通员工职业发展通道，激励员工持续成长，制定本制度。

**第二条** 本制度适用于四川融策会计师事务所有限公司（以下简称"事务所"）和四川融策工程咨询有限公司（以下简称"工程公司"）全体正式员工（不含试用期员工）。

**第三条** 晋升原则：

1. **业绩导向**：以工作业绩为核心依据，不唯资历、不唯关系；
2. **能力为本**：注重专业能力和综合素质的持续提升；
3. **公开透明**：晋升标准、流程、结果公开，接受全员监督；
4. **双通道发展**：专业序列与管理序列并行，员工可根据自身优势选择发展方向。

## 第二章 职级体系

**第四条** 公司设置专业序列和管理序列双通道职级体系：

### 专业序列

| 职级 | 名称 | 典型岗位 | 说明 |
|------|------|---------|------|
| P1 | 审计助理 / 造价助理 | 审计助理、造价助理 | 入门级，在指导下开展工作 |
| P2 | 审计员 / 造价员 | 审计员、造价员 | 独立承担基础工作 |
| P3 | 高级审计员 / 高级造价员 | 高级审计员、高级造价员 | 独立承担复杂工作，可带教新人 |
| P4 | 项目经理 | 审计项目经理、造价项目经理 | 独立负责项目管理 |
| P5 | 高级项目经理 | 高级项目经理 | 负责重大项目，指导项目经理 |

### 管理序列

| 职级 | 名称 | 典型岗位 | 说明 |
|------|------|---------|------|
| M1 | 部门副经理 | 审计部副经理、造价部副经理 | 协助部门管理 |
| M2 | 部门经理 | 审计部经理、造价部经理 | 部门全面管理 |
| M3 | 总监 | 审计总监、技术总监 | 跨部门业务统筹 |
| M4 | 合伙人 | 合伙人 | 参与公司重大决策 |

**第五条** 专业序列与管理序列的对应关系：

| 专业序列 | 管理序列 | 薪酬带宽对应 |
|---------|---------|------------|
| P3 高级审计员 | M1 部门副经理 | 同档 |
| P4 项目经理 | M2 部门经理 | 同档 |
| P5 高级项目经理 | M3 总监 | 同档 |
| — | M4 合伙人 | 单独设定 |

**第六条** 员工可在专业序列和管理序列之间转换，转换条件：

1. 专业序列→管理序列：P3及以上，具备管理能力，有管理岗位空缺；
2. 管理序列→专业序列：本人申请，经总经理批准。

## 第三章 晋升条件

**第七条** 各职级晋升基本条件：

### P1 → P2（审计助理/造价助理 → 审计员/造价员）

| 条件 | 要求 |
|------|------|
| 工作年限 | 在P1岗位工作满1年 |
| 业绩评级 | 最近一次年度绩效考核B级及以上 |
| 执业资格 | 无硬性要求 |
| 项目经验 | 参与完成≥3个项目 |
| 360评估 | 直接上级评价合格 |

### P2 → P3（审计员/造价员 → 高级审计员/高级造价员）

| 条件 | 要求 |
|------|------|
| 工作年限 | 在P2岗位工作满2年 |
| 业绩评级 | 最近两次年度绩效考核均B级及以上，且至少一次A级 |
| 执业资格 | 通过CPA/造价师部分科目或持有相关证书 |
| 项目经验 | 作为主要成员参与完成≥5个项目，其中至少1个独立负责 |
| 360评估 | 直接上级+同事评价良好 |

### P3 → P4（高级审计员/造价员 → 项目经理）

| 条件 | 要求 |
|------|------|
| 工作年限 | 在P3岗位工作满2年 |
| 业绩评级 | 最近两次年度绩效考核均B级及以上，且至少一次A级 |
| 执业资格 | 持有CPA或造价工程师证书（或已通过全部科目） |
| 项目经验 | 作为项目负责人完成≥3个项目，无质量事故 |
| 360评估 | 上级+同事+客户评价良好 |

### P4 → P5（项目经理 → 高级项目经理）

| 条件 | 要求 |
|------|------|
| 工作年限 | 在P4岗位工作满3年 |
| 业绩评级 | 最近三次年度绩效考核均B级及以上，且至少两次A级 |
| 执业资格 | 持有CPA或一级造价工程师证书 |
| 项目经验 | 作为项目负责人完成≥8个项目，含≥2个大型项目 |
| 360评估 | 上级+同事+客户评价优秀 |
| 带教成果 | 成功带教≥2名项目经理 |

### M1 → M2（部门副经理 → 部门经理）

| 条件 | 要求 |
|------|------|
| 管理年限 | 在M1岗位工作满2年 |
| 业绩评级 | 所在部门最近两次年度考核达标 |
| 个人评级 | 最近两次个人绩效考核B级及以上 |
| 管理能力 | 团队管理能力评估合格 |
| 360评估 | 上级+下属+同级评价良好 |

### M2 → M3（部门经理 → 总监）

| 条件 | 要求 |
|------|------|
| 管理年限 | 在M2岗位工作满3年 |
| 业绩评级 | 所在部门最近三次年度考核达标 |
| 业务贡献 | 在业务拓展或技术提升方面有突出贡献 |
| 360评估 | 上级+下属+同级评价优秀 |

**第八条** 各晋升条件中"工作年限"为最低要求，满足年限不代表自动晋升，需经评审通过。

## 第四章 晋升评审周期与流程

**第九条** 晋升评审每年进行一次，于每年第一季度（1-3月）进行。

**第十条** 晋升评审流程：

```
1. 发布通知（1月初）
   综合管理部发布年度晋升评审通知，明确时间安排和申报要求

2. 个人申报 / 部门推荐（1月中旬）
   员工填写《职级晋升申报表》，或部门负责人推荐

3. 资格初审（1月下旬）
   综合管理部审核申报人是否满足基本条件

4. 评审委员会评审（2月）
   评审委员会对通过初审的候选人进行综合评审

5. 结果公示（2月下旬）
   评审结果公示5个工作日

6. 批准生效（3月）
   总经理批准后，自当年4月1日起执行新职级
```

**第十一条** 评审委员会组成：

| 成员 | 人数 | 说明 |
|------|------|------|
| 总经理 | 1人 | 主任委员 |
| 副总经理/总监 | 1-2人 | 委员 |
| 部门负责人 | 2-3人 | 委员 |
| 综合管理部负责人 | 1人 | 秘书（无表决权） |

**第十二条** 评审维度及权重：

| 维度 | 权重 | 说明 |
|------|------|------|
| 工作业绩 | 40% | 近1-2年绩效考核结果、项目贡献 |
| 专业能力 | 25% | 执业资格、专业水平、技术能力 |
| 综合素质 | 20% | 沟通能力、团队协作、学习能力 |
| 发展潜力 | 15% | 成长空间、创新意识 |

## 第五章 破格晋升

**第十三条** 符合以下条件之一的，可申请破格晋升（不受工作年限限制）：

1. 年度绩效考核连续两年A级，且对公司有重大贡献（如开拓重要客户、完成重大项目等）；
2. 取得关键执业资格（CPA/一级造价工程师），且已展现出超越当前职级的能力；
3. 在行业竞赛、评优中获得省级及以上荣誉；
4. 为公司带来显著经济效益或社会效益的其他突出贡献。

**第十四条** 破格晋升需满足：

1. 除工作年限外，其他晋升条件均已满足；
2. 部门负责人书面推荐并说明破格理由；
3. 评审委员会三分之二以上委员同意；
4. 总经理批准。

---

## 第六章 薪酬调级

**第十五条** 员工晋升后，薪酬按 RC-HR-001 薪酬管理制度中对应的薪酬带宽进行调整：

1. 每晋升一级，薪酬带宽上调一档；
2. 晋升后薪酬调整自新职级生效月起执行；
3. 如当前薪酬已在新职级带宽范围内，可按新职级带宽的适当比例上调（一般不低于10%）。

**第十六条** 管理序列与专业序列同级对应薪酬带宽一致（参照第四条对应关系）。

---

## 第七章 降级与退出

**第十七条** 有下列情形之一的，可予以降级处理：

1. 年度绩效考核为D级的；
2. 连续两年绩效考核为C级的；
3. 发生重大质量事故，负有直接责任的；
4. 严重违反公司规章制度的。

**第十八条** 降级由部门负责人提出，综合管理部审核，总经理批准。降级后薪酬按新职级带宽重新核定。

**第十九条** 管理人员因管理不善被免去管理职务的，可转回专业序列，按对应职级执行。

---

## 第八章 附则

**第二十条** 综合管理部应建立员工职级档案，记录每位员工的职级变动历史、评审结果等。

**第二十一条** 员工对晋升评审结果有异议的，可在公示期内向综合管理部提出书面申诉。综合管理部应在5个工作日内组织复核并答复。

**第二十二条** 本制度未尽事宜，依照国家法律法规及公司相关规定执行。

**第二十三条** 本制度由综合管理部负责解释和修订，经总经理批准后施行。
