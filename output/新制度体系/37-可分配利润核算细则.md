# 四川融策可分配利润核算细则

> **制度编号**：RC-FIN-006  
> **版本**：V1.0  
> **编制日期**：2026年7月22日  
> **适用范围**：四川融策会计师事务所有限公司、四川融策工程咨询有限公司  
> **优先级**：P1  
> **定位**：本细则为项目分润、跨部门协同奖励、高管绩效考核的统一核算基础  
> **引用制度**：RC-BIZ-006（项目独立核算与分润制度）、RC-BIZ-007（跨部门协同与交叉营销奖励办法）、RC-HR-007（高管经营目标责任与绩效考核办法）

## 第一章 总则

**第一条** 为统一公司各项经营激励制度的利润核算口径，确保分润、奖励、绩效考核的数据基础一致、透明、可验证，特制定本细则。

**第二条** 本细则定义以下核心概念，作为 RC-BIZ-006、RC-BIZ-007、RC-HR-007 等制度的核算基础：
1. **项目收入**：按本细则确认的项目营业收入
2. **项目直接成本**：可直接归属到具体项目的人力及非人力成本
3. **项目公摊成本**：无法直接归属、需按规则分摊的间接成本
4. **项目毛利润**：项目收入减去直接成本和公摊成本后的余额
5. **可分配利润**：项目毛利润经调整后，可用于分润/奖励分配的利润额度

**第三条** 核算原则：
1. **收付实现制为主**：以实际回款为收入确认的基本依据（里程碑预发除外）
2. **配比原则**：收入与对应成本在同一核算周期内匹配
3. **谨慎性原则**：不计未到账收入、不低估已知成本
4. **透明可查**：项目负责人有权查阅本项目全部核算数据

---

## 第二章 收入确认口径

**第四条** 项目收入确认标准：

| 确认节点 | 确认条件 | 确认金额 |
|---------|---------|---------|
| 合同签订 | 合同生效且项目立项 | 合同金额（暂估） |
| 里程碑交付 | 提交阶段性成果并经客户签收 | 对应里程碑金额 |
| 最终验收 | 客户出具验收确认/结算审定 | 结算金额（调整暂估） |
| 实际回款 | 款项到达公司账户 | 实际到账金额 |

**第五条** 收入确认的具体规则：
1. **合同金额调整**：签订补充协议导致合同金额变更的，在补充协议生效时调整
2. **折扣与折让**：商务折扣在确认收入时直接扣除；期后折让在实际发生时冲减当期收入
3. **多期项目**：跨年度项目按里程碑节点分期确认收入，不按时间进度平均分摊
4. **争议款项**：客户对部分金额存在争议的，仅确认无争议部分；争议解决后补确认
5. **坏账处理**：已确认收入但超过12个月未回款且催收无果的，经总经理审批后核销，同时冲减对应项目利润

**第六条** 以下情形不计入项目收入：
1. 客户预付但尚未满足里程碑交付条件的款项（计入预收账款）
2. 代垫代付性质款项（如代客户支付的评审费、检测费）
3. 政府补贴、税收返还等非经营性收入

## 第三章 直接成本清单

**第七条** 项目直接成本是指能够明确归属到具体项目的成本，包括：

### 3.1 直接人力成本

| 成本项 | 计算方式 | 说明 |
|--------|---------|------|
| 项目人员人力成本 | 实际工时 × 有效小时成本率 | 有效小时成本率 =（月工资+公司承担的社保公积金及法定用工成本）÷（月标准工时×有效工时系数）；首期有效工时系数按0.75执行，每年依据实际项目工时数据复盘调整 |
| 社保公积金 | 项目人员工资 × 公司缴纳比例 | 按实际缴纳金额计算 |
| 加班费 | 实际发生额 | 须经项目负责人审批 |
| 外聘专家费 | 实际支付金额 | 含咨询费、评审费 |

### 3.2 直接非人力成本

| 成本项 | 包含内容 | 归集方式 |
|--------|---------|---------|
| 差旅费 | 交通、住宿、出差补贴 | 按项目报销单直接归集 |
| 业务招待费 | 项目相关客户接待 | 按报销单归集，上限为合同额的2% |
| 资料费 | 购买标准、图纸、软件等 | 按发票归集 |
| 印刷装订费 | 报告印刷、标书装订 | 按发票归集 |
| 检测鉴定费 | 委托第三方检测/鉴定 | 按合同/发票归集 |
| 其他直接费用 | 投标保证金（损失部分）、快递费等 | 按实际发生归集 |

**第八条** 以下支出**不得**计入项目直接成本：
1. 与项目无关的招待费、礼品费
2. 未经审批的超标准差旅费
3. 项目结束后30天以外补报的费用
4. 罚款、滞纳金等违规支出
5. 员工个人消费性质的支出

## 第四章 公摊成本分摊规则

**第九条** 公摊成本是指为多个项目共同发生、无法直接归属的间接成本，按以下规则分摊：

### 4.1 公摊成本范围

| 类别 | 包含项目 |
|------|---------|
| 办公场地 | 租金、物业费、水电费、装修折旧 |
| 行政支持 | 行政人员工资、办公用品、清洁费 |
| 设备折旧 | 办公设备、软件许可年费 |
| 公共平台 | OA系统、财务系统、RAG知识库运维 |
| 资质维护 | 行业会费、资质年检、继续教育 |
| 市场费用 | 品牌建设、招投标平台费（非特定项目） |

### 4.2 分摊方法

**分类定率法**：按业务类型设定不同公摊提取率，以项目收入为基数提取。

| 业务类型 | 公摊提取率 | 说明 |
|---------|-----------|------|
| 审计类 | **8%** | 含财务审计、绩效审计、专项审计等 |
| 工程咨询类 | **12%** | 含预算编制、结算审核、全过程咨询等 |
| 其他类 | **10%** | 含咨询顾问、培训服务等 |

**第十条** 公摊提取率的调整机制：
1. **季度复盘**：每季度末，财务部计算实际公摊成本 ÷ 实际项目收入总额，得出实际公摊率
2. **偏差调整**：若实际公摊率与定率偏差超过2个百分点，下季度调整提取率
3. **年度清算**：年度终了，各项目已提公摊与实际公摊的差额，在多退少补后计入当年损益
4. **调整审批**：公摊率调整由财务部提出方案，经总经理批准后执行

**第十一条** 公摊成本分摊公式：
```
某项目应分摊公摊成本 = 该项目收入 × 该类业务公摊提取率
```

## 第五章 项目毛利润与可分配利润计算

**第十二条** 项目毛利润计算：
```
项目毛利润 = 项目收入 - 项目直接成本 - 项目公摊成本
```

**第十三条** 项目毛利润率：
```
项目毛利润率 = 项目毛利润 ÷ 项目收入 × 100%
```

**第十四条** 可分配利润计算：
```
可分配利润 = 项目毛利润 - 质量准备金 - 风险准备金
```

其中：
1. **质量准备金**：按项目毛利润的 **10%** 提取，用于覆盖项目质量风险
   - 阶梯解冻：项目交付后6个月无质量事故解冻50%，12个月无事故解冻全部剩余
   - 冻结期间按银行活期利率计息，利息归项目负责人/团队所有
2. **风险准备金**：按项目毛利润的 **5%** 提取，用于覆盖坏账及经营风险
   - 年度终了，未发生坏账的风险准备金全额返还，计入当年可分配利润

**第十五条** 可分配利润为负数时（即项目亏损），按 RC-BIZ-006 的亏损承担规则处理，不影响其他盈利项目的分润。

## 第六章 核算流程与时效

**第十六条** 核算流程：

```
项目立项 → 建立项目核算台账（财务部）
    ↓
月度归集 → 每月10日前归集上月直接成本
    ↓
季度复盘 → 每季度末计算公摊率、更新项目利润
    ↓
里程碑结算 → 交付确认后15个工作日内出具项目利润结算单
    ↓
年度清算 → 次年1月31日前完成全年项目利润终审
```

**第十七条** 项目利润结算单须包含：
1. 项目基本信息（编号、名称、合同额、负责人）
2. 收入确认明细（已确认/已回款/未回款）
3. 直接成本明细（按科目列示）
4. 公摊成本计算过程
5. 毛利润及毛利润率
6. 质量准备金、风险准备金提取额
7. 可分配利润
8. 分润/奖励分配计算

**第十八条** 项目负责人对核算数据有异议的，可在收到结算单后10个工作日内向财务部提出复核申请。财务部应在15个工作日内完成复核并书面答复。

## 第七章 监督与责任

**第十九条** 财务部对核算数据的真实性、准确性负责。禁止以下行为：
1. 虚增或隐瞒项目收入
2. 将非本项目成本计入项目直接成本
3. 擅自调整公摊提取率
4. 延迟或提前确认收入以操纵利润

**第二十条** 违反核算规则的，视情节轻重给予以下处理：
1. 一般差错（计算错误等）：限期更正，不影响分润
2. 故意违规（虚报/隐瞒）：取消当期分润资格，给予行政处分
3. 造成重大损失的：追究经济赔偿责任
