# 四川融策执业责任追究制度

> **制度编号**：RC-QC-004  
> **版本**：V1.0  
> **编制日期**：2026年7月22日  
> **适用范围**：四川融策会计师事务所有限公司、四川融策工程咨询有限公司全体执业人员  
> **优先级**：P1  
> **关联制度**：RC-QC-001《审计质量控制制度》、RC-QC-002《造价咨询质量控制制度》、RC-HR-003《员工手册》

## 第一章 总则

**第一条** 为强化执业质量意识，明确质量责任，规范执业行为，根据《中国注册会计师法》《注册造价工程师管理办法》《会计师事务所执业许可和监督管理办法》及相关法律法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司全体执业人员，包括注册会计师、造价工程师、审计助理、造价员及其他参与业务执行的人员。

**第三条** 责任追究基本原则：

1. **谁签字谁负责**：签字注册会计师/造价工程师对报告/成果的真实性、合法性承担法定责任
2. **分级担责**：根据质量事故的严重程度，分级追究相关人员的责任
3. **过罚相当**：处罚力度与事故等级、过错程度、损害后果相匹配
4. **程序正当**：按程序调查、听取陈述、公正处理，保障当事人合法权益
5. **教育为主**：不以惩罚为目的，通过责任追究促进质量意识提升

## 第二章 责任认定

**第四条** 责任认定遵循"谁主管谁负责、谁执行谁负责、谁签字谁负责"的原则，按以下路径追责：

| 责任人 | 责任类型 | 责任范围 |
|--------|---------|---------|
| **编制人**（审计员/造价员） | 直接责任 | 对底稿/计算书的数据真实性、逻辑完整性、程序执行到位性负直接责任 |
| **项目经理**（主审/项目负责人） | 管理责任 | 对现场工作组织、底稿编制质量、执业程序执行、一级复核负管理责任 |
| **部门负责人**（部门主任） | 督导责任 | 对二级复核质量、执业标准执行、重大事项处理、资源保障负督导责任 |
| **复核人**（各级复核/签字人） | 复核责任 | 对本人复核环节未发现应发现的问题承担相应责任 |
| **签字人**（签字注册会计师/造价工程师） | 最终责任 | 对签署的报告/成果文件质量承担法定最终责任 |

**第五条** 多人共同负责的，根据各人的过错程度和职责分工确定各自责任比例。受上级指令违规操作的，执行人承担执行责任，指令人承担主要责任。

**第六条** 以下情形可酌情减轻或免除责任：
1. 当事人已按制度要求履行了应有的复核、报告程序，但问题未被上级发现或采纳
2. 因客观条件限制（如被审计单位拒绝配合、资料缺失严重），当事人已尽到合理努力但仍无法避免问题的
3. 问题系外部因素导致（如法规政策突然变化），且当事人无过错的
4. 当事人在问题被发现前主动报告并积极整改的

**第七条** 以下情形应加重处理：
1. 明知存在质量问题仍签字出具的
2. 故意隐瞒、销毁或篡改底稿证据的
3. 一年内重复发生同类质量问题的
4. 拒不配合调查或串通他人作伪证的
5. 因质量问题造成客户重大经济损失或公司声誉严重损害的

## 第三章 质量事故分级

**第八条** 质量事故分为三级，与RC-QC-001/RC-QC-002中的质量等级保持一致：

### 3.1 一级事故（重大质量事故）

**第九条** 一级事故包括：
1. 出具**虚假报告**或**虚假成果文件**（明知内容虚假仍签字出具）
2. 出具的报告或成果存在**重大遗漏**，导致使用者作出错误判断并造成严重后果
3. 因执业质量问题被主管部门处以**责令停业、吊销执业许可、撤销资质**等行政处罚
4. 因执业质量问题被客户或其他方追究**经济赔偿责任≥50万元**的
5. 因执业质量问题被**刑事追诉**的
6. 其他经管理层认定的同等严重质量问题

**第十条** 一级事故处理：

| 责任主体 | 处理措施 |
|---------|---------|
| **直接责任人** | ①符合《劳动合同法》第三十九条等法定条件的，依法解除劳动合同 ②依法承担应由本人承担的赔偿责任 ③按规定向行业主管部门报告 ④涉嫌犯罪的移送司法机关 |
| **项目负责人** | ①按公司员工奖惩及绩效制度进行责任认定 ②取消当年度未发放的激励性绩效奖金评定资格（不得追溯扣减已形成的工资性收入） ③降级或解除相关职务 ④涉嫌违法犯罪的依法处理 |
| **部门负责人** | ①按公司员工奖惩及绩效制度进行责任认定 ②取消当年度未发放的激励性绩效奖金评定资格（不得追溯扣减已形成的工资性收入） ③在公司管理层会议上作书面检讨 |
| **签字人** | ①如签字人自身即为直接责任人的按直接责任人处理 ②其他签字人按"过罚相当"原则处理 |

### 3.2 二级事故（较大质量事故）

**第十一条** 二级事故包括：
1. 出具的报告或成果存在**重大错误**（存在2处以上关键数据错误或意见类型错误），被监管机构**通报批评**或客户**重大投诉**的
2. 因执业质量问题被主管部门处以**警告、罚款**等行政处罚的
3. 因执业质量问题被监管机构**谈话提醒、下发关注函**的
4. 因执业质量问题导致客户**重大投诉**（按RC-BIZ-003定义的重大投诉），造成客户关系严重受损的
5. 省级以上行业协会执业质量检查中被评为**不合格**的
6. 因质量问题被媒体曝光，造成公司**声誉受损**的

**第十二条** 二级事故处理：

| 责任主体 | 处理措施 |
|---------|---------|
| **直接责任人** | ①记过 ②取消当年度尚未发放的激励性绩效奖金评定资格（不得追溯扣减已形成的工资性收入） ③降级或调岗 ④参加脱岗培训≥40学时 |
| **项目负责人** | ①警告 ②取消当年度尚未发放的激励性绩效奖金相应评定资格（不得追溯扣减已形成的工资性收入） ③暂停担任项目负责人资格6~12个月 |
| **部门负责人** | ①警告 ②取消当期尚未发放的激励性绩效奖金相应评定资格（不得追溯扣减已形成的工资性收入） ③向管理层提交书面整改报告 |
| **签字人** | 暂停签字资格3~6个月，完成质量培训后方可恢复 |

### 3.3 三级事故（一般质量事故）

**第十三条** 三级事故包括：
1. 出具的底稿或成果存在**一般性错误**（格式不规范、索引错乱、笔误等不影响实质判断的错误）
2. 客户就服务质量提出**一般投诉**（按RC-BIZ-003定义的一般投诉），经查证属实的
3. 执业质量检查中发现底稿**缺陷**（底稿不完整、程序执行不充分等），但尚未影响结论的
4. 报告或成果文件的**形式瑕疵**（签字不全、盖章缺失、日期错误等）
5. 行业协会执业质量检查中发现**一般不符合项**的

**第十四条** 三级事故处理：

| 责任主体 | 处理措施 |
|---------|---------|
| **直接责任人** | ①警告 ②取消当期尚未发放的激励性绩效奖金相应评定资格（不得追溯扣减已形成的工资性收入） ③限期整改，提交书面整改报告 |
| **项目负责人** | ①诫勉谈话 ②取消当期尚未发放的激励性绩效奖金相应评定资格（不得追溯扣减已形成的工资性收入） ③加强后续项目质量管控 |
| **部门负责人** | 口头批评，督促加强管理 |

**第十五条** 累计3次三级事故的，按一次二级事故处理。

## 第四章 调查程序

**第十六条** 质量事故调查启动条件：
1. 客户书面投诉
2. 监管部门检查发现或通报
3. 内部复核或质量检查中发现
4. 员工报告或举报
5. 其他渠道反映的质量问题

**第十七条** 调查程序：

```
投诉/发现问题
  ↓
质控部门受理，初步评估
  ↓
不属于质量事故的 → 说明理由，转其他渠道处理
属于质量事故的 → 立案调查
  ↓
质控部门组织调查组（不少于2人）
  ↓
调阅底稿、访谈相关人员、收集证据
  ↓
听取当事人陈述和申辩（必须环节，不可省略）
  ↓
调查组出具《质量事故调查报告》
  ↓
提交管理层审议决定
  ↓
向当事人送达处理决定
```

**第十八条** 调查应遵循以下要求：
1. 调查组应在立案后10个工作日内完成调查报告
2. 当事人有权查阅与本人相关的调查材料
3. 当事人有权进行陈述和申辩，有权提交对自己有利的证据
4. 调查记录、陈述记录均应签字确认
5. 与当事人有利害关系的人员应回避，不得参与调查

**第十九条** 《质量事故调查报告》应包含：
1. 事故基本情况和发现经过
2. 涉及的项目、人员、底稿/成果文件
3. 事故性质认定和等级判定依据
4. 各责任人的过错程度和因果关系分析
5. 建议处理意见和法律依据
6. 改进建议，防止同类问题再次发生

## 第五章 申诉机制

**第二十条** 当事人对处理决定不服的，有权提出书面申诉。

**第二十一条** 申诉程序：
1. 当事人收到处理决定后**5个工作日**内，以书面形式向公司管理层提交申诉书
2. 管理层收到申诉后，在**10个工作日**内组织复核
3. 申诉复核应由未参与原调查的人员进行，必要时可聘请外部专家参与
4. 复核期间，原处理决定暂缓执行（解除劳动合同等重大处分除外）
5. 复核结论为最终处理决定，书面通知当事人

**第二十二条** 申诉可基于以下理由：
1. 事实认定有误
2. 事故等级判定不当
3. 处理措施与过错程度不匹配
4. 调查程序存在重大瑕疵
5. 有新证据可以证明当事人无过错或过错较轻

**第二十三条** 任何人不得因当事人提出申诉而加重处理或打击报复。

## 第六章 附则

**第二十四条** 本制度所涉及的经济处罚和绩效扣减，应在法律法规和劳动合同允许的范围内执行。具体罚金标准由管理层另行制定实施细则。

**第二十五条** 本制度与RC-HR-003《员工手册》中的奖惩条款互为补充，员工手册中有更具体规定的，参照执行。

**第二十六条** 本制度由质控部门会同人力资源管理部门负责制定和解释。

**第二十七条** 本制度自发布之日起施行。
