## 第一章 总则

**第一条** 为规范项目管理流程，保证项目质量，提高项目效率，防范执业风险，根据《中国注册会计师审计准则》《建设工程造价咨询规范》及公司实际情况，制定本规范。

**第二条** 本规范适用于公司承接的全部业务项目，包括：
- 审计类项目（政府审计、国企审计、专项审计等）
- 造价类项目（预算编制、财政评审、工程结算、全过程咨询等）
- 咨询类项目（管理咨询、内控咨询等）

**第三条** 项目管理基本原则：
1. **质量优先**：项目质量是事务所生命线，不因赶进度牺牲质量
2. **过程可控**：关键节点有检查、有记录、可追溯
3. **客户导向**：及时响应客户需求，保持专业沟通
4. **风险意识**：识别和防范执业风险，重大问题及时上报
5. **知识沉淀**：每个项目结束后总结经验，形成可复用知识

## 第二章 项目分类

**第四条** 项目按业务类型分为三大类：

### 2.1 审计类项目

| 子类 | 典型项目 | 特点 |
|------|---------|------|
| 财政审计 | 预算执行审计、专项资金审计、收支审计 | 政策性强，时效要求高 |
| 经责审计 | 领导干部经济责任审计 | 涉及面广，敏感度高 |
| 绩效评价 | 财政支出绩效评价、项目绩效评价 | 指标体系复杂，需现场调研 |
| 专项审计 | 专项债审计、竣工决算审计、补贴审计 | 专业性强，有特定规范 |
| 资产清查 | 行政事业单位资产清查、国企清产核资 | 工作量大，需现场盘点 |

### 2.2 造价类项目

| 子类 | 典型项目 | 特点 |
|------|---------|------|
| 预算编制 | 工程预算、招标控制价 | 需熟悉定额和市场价格 |
| 财政评审 | 财政支出项目评审 | 政策合规性要求高 |
| 工程结算 | 竣工结算审核 | 需现场核实，争议点多 |
| 全过程咨询 | 建设项目全过程造价管理 | 周期长，需驻场服务 |

### 2.3 咨询类项目

| 子类 | 典型项目 | 特点 |
|------|---------|------|
| 管理咨询 | 内控制度建设、财务管理优化 | 定制化程度高 |
| 专项咨询 | 投融资咨询、资产重组咨询 | 专业深度要求高 |

**第五条** 项目按规模分为三级：

| 等级 | 合同金额 | 人员配置 | 复核要求 |
|------|---------|---------|---------|
| A类（大型） | ≥50万元 | 项目经理+2名以上主审 | 三级复核+管理层审阅 |
| B类（中型） | 10~50万元 | 项目经理+1~2名主审 | 三级复核 |
| C类（小型） | <10万元 | 项目经理或高级审计员负责 | 二级复核 |

## 第三章 项目立项与任务分配

**第六条** 项目立项流程：

```
业务承接评估 → 合同审批 → 签订合同 → 项目编号 → 立项登记
```

**第七条** 业务承接评估：

承接新项目前，项目负责人应进行以下评估：

| 评估维度 | 评估内容 | 评估结论 |
|---------|---------|---------|
| 独立性 | 是否存在利益冲突、是否影响独立性 | 通过/不通过 |
| 专业胜任能力 | 团队是否具备相应专业能力和经验 | 具备/需外聘/不具备 |
| 风险评估 | 客户诚信、项目风险是否在可接受范围 | 低风险/中风险/高风险 |
| 资源匹配 | 人力、时间、技术资源是否满足 | 可满足/需协调/不满足 |

高风险项目须经管理层审批后方可承接。

**第八条** 合同签订：
1. 业务约定书/合同由项目负责人起草，部门负责人审核，管理层审批
2. 合同应明确：服务范围、时间要求、收费标准、双方责任、保密条款、争议解决
3. 合同签订后3个工作日内在合同台账登记

**第九条** 项目编号规则：

```
RC - [业务代码] - [年份] - [序号]

业务代码：
  AUD = 审计类
  CST = 造价类
  CON = 咨询类

示例：RC-AUD-2026-001 = 2026年第1个审计项目
```

**第十条** 项目任务分配：

1. 管理层根据项目类型、规模、紧急程度指定项目经理
2. 项目经理组建项目团队，确定成员分工
3. 任务分配应考虑：
   - 成员专业能力和经验
   - 在手项目负荷
   - 人才培养需要（老带新）
4. 项目团队配置表报部门负责人备案

## 第四章 项目进度管理

**第十一条** 项目里程碑节点：

### 审计类项目标准里程碑：

| 阶段 | 里程碑 | 时间节点（参考） | 交付物 |
|------|--------|---------------|--------|
| 计划阶段 | M1-项目启动 | T+0 | 项目计划书、团队分工表 |
| 计划阶段 | M2-进场准备 | T+3天 | 资料清单、调查问卷 |
| 实施阶段 | M3-现场工作 | T+5~15天 | 工作底稿、取证记录 |
| 实施阶段 | M4-初步发现 | T+20天 | 问题汇总表、初步审计发现 |
| 报告阶段 | M5-征求意见 | T+25天 | 征求意见稿 |
| 报告阶段 | M6-正式报告 | T+30天 | 正式审计报告 |
| 收尾阶段 | M7-归档完成 | T+45天 | 完整项目档案 |

### 造价类项目标准里程碑：

| 阶段 | 里程碑 | 时间节点（参考） | 交付物 |
|------|--------|---------------|--------|
| 准备阶段 | M1-项目启动 | T+0 | 项目计划书 |
| 准备阶段 | M2-资料收集 | T+3天 | 资料清单、完整性确认 |
| 实施阶段 | M3-初稿编制 | T+10~20天 | 成果初稿 |
| 实施阶段 | M4-内部复核 | T+25天 | 复核意见、修改记录 |
| 交付阶段 | M5-对账/核对 | T+30天 | 对账记录、争议处理 |
| 交付阶段 | M6-正式成果 | T+35天 | 正式成果文件 |
| 收尾阶段 | M7-归档完成 | T+50天 | 完整项目档案 |

**第十二条** 进度监控：
1. 项目经理每周更新项目进度，在项目管理台账中记录
2. 部门负责人每两周召开项目进度例会，审视在手项目进展
3. 项目延期超过里程碑节点5天以上的，项目经理须书面说明原因并提出赶工方案
4. 延期超过10天以上的，报管理层协调资源

**第十三条** 项目变更：
1. 因客户原因导致范围变更的，应及时签订补充协议
2. 因客观原因导致延期的，应书面告知客户并协商调整时间
3. 项目变更须经部门负责人审批，重大变更报管理层审批

## 第五章 项目质量控制

**第十四条** 公司实行三级复核制度：

```
第一级：项目经理复核（详细复核）
    ↓
第二级：部门负责人复核（重点复核）
    ↓
第三级：质量控制部复核（独立复核）
```

### 5.1 第一级复核（项目经理）

**第十五条** 项目经理对项目成果进行100%详细复核：

| 复核内容 | 复核要点 |
|---------|---------|
| 审计/造价程序 | 是否按准则和规范执行全部必要程序 |
| 工作底稿 | 是否完整、逻辑清晰、证据充分 |
| 数据准确性 | 金额计算是否正确、勾稽关系是否成立 |
| 法规引用 | 引用法规是否准确、是否现行有效 |
| 报告表述 | 事实描述是否准确、措辞是否恰当 |
| 建议意见 | 建议是否具有针对性和可操作性 |

**第十六条** 一级复核要求：
- 复核全部工作底稿（100%覆盖）
- 复核记录留痕（底稿上签字或系统留痕）
- 发现问题及时退回修改，修改后重新复核

### 5.2 第二级复核（部门负责人）

**第十七条** 部门负责人对重要事项进行重点复核：

| 复核内容 | 复核要点 |
|---------|---------|
| 重大风险领域 | 高风险领域的审计/造价程序是否充分 |
| 重大判断事项 | 重要判断和结论是否合理 |
| 客户沟通 | 与客户沟通的重大事项是否恰当 |
| 报告整体质量 | 报告结构、逻辑、表述的整体质量 |

**第十八条** 二级复核覆盖范围：
- A类项目：复核全部重要底稿和报告（覆盖率≥80%）
- B类项目：复核重要底稿和报告（覆盖率≥60%）
- C类项目：复核报告及重要底稿（覆盖率≥40%）

### 5.3 第三级复核（质量控制部）

**第十九条** 质量控制部独立复核：

| 复核内容 | 复核要点 |
|---------|---------|
| 程序合规性 | 是否按准则和公司制度执行 |
| 三级复核落实 | 一二级复核是否执行到位、问题是否修改 |
| 报告规范性 | 报告格式是否规范、要素是否齐全 |
| 风险把控 | 是否存在重大遗漏或执业风险 |

**第二十条** 三级复核覆盖范围：
- A类项目：100%复核
- B类项目：抽查复核（覆盖率≥50%）
- C类项目：抽查复核（覆盖率≥20%）

**第二十一条** 三级复核中发现问题的处理：
1. 退回项目经理修改，修改后重新提交复核
2. 重大分歧由部门负责人召集讨论决定
3. 仍有争议的，报管理层决定
4. 复核意见和修改情况全程留痕

## 第六章 项目成果交付与验收

**第二十二条** 成果交付标准：

| 成果类型 | 质量要求 |
|---------|---------|
| 审计报告 | 三级复核全部通过，格式规范，事实清楚，证据充分 |
| 造价成果 | 三级复核全部通过，计算准确，依据充分 |
| 咨询报告 | 二级复核通过，方案可行，逻辑清晰 |

**第二十三条** 成果交付流程：
1. 项目经理确认成果文件完成全部复核流程
2. 成果文件加盖公司印章
3. 正式交付客户（当面交付或邮寄，留存交付记录）
4. 客户签收确认

**第二十四条** 客户验收：
1. 成果交付后，项目经理应主动跟进客户反馈
2. 客户提出修改意见的，应区分情况处理：
   - 属于成果质量问题的：免费修改，并分析原因
   - 属于新增需求的：协商签订补充协议
   - 属于理解分歧的：充分沟通解释
3. 客户验收确认后，取得书面验收确认文件

## 第七章 项目回款管理

**第二十五条** 项目回款责任：
1. 项目经理是项目回款第一责任人
2. 部门负责人对本部门回款负管理责任
3. 财务部门负责回款统计和催收提醒

**第二十六条** 回款节点管理：

| 项目类型 | 常规收款节点 |
|---------|------------|
| 审计类 | 合同签订后30%→提交初稿40%→出具正式报告30% |
| 造价类 | 合同签订后30%→提交初稿40%→出具正式成果30% |
| 咨询类 | 合同签订后50%→提交报告50% |

具体比例在合同中约定。

**第二十七条** 回款催收：
1. 项目回款后，财务部门在3个工作日内通知项目经理
2. 超过合同约定付款日期30天未回款的，财务部门发出催收提醒
3. 超过60天未回款的，项目经理应主动联系客户了解原因
4. 超过90天未回款的，报部门负责人和管理层，制定催收方案
5. 超过180天未回款的，评估是否需要法律手段

**第二十八条** 项目奖金与回款挂钩：
- 项目回款率达到70%以上，方可发放项目奖金
- 回款率低于70%的，奖金按回款比例折算

## 第八章 项目档案归档

**第二十九条** 归档时限：
- 项目完成后30个工作日内完成归档
- 跨年项目，在最后一个报告年度的项目完成后统一归档

**第三十条** 归档内容：

### 审计类项目档案清单：

| 类别 | 内容 |
|------|------|
| 立项文件 | 业务约定书/合同、立项审批表、独立性声明 |
| 计划文件 | 项目计划书、团队分工表、重要性水平计算 |
| 工作底稿 | 全部审计工作底稿（含电子底稿） |
| 证据材料 | 取证记录、询证函回函、盘点记录等 |
| 报告文件 | 报告征求意见稿、正式报告、客户反馈意见 |
| 复核记录 | 三级复核记录、复核意见、修改记录 |
| 管理文件 | 进度记录、变更记录、回款记录 |

### 造价类项目档案清单：

| 类别 | 内容 |
|------|------|
| 立项文件 | 合同、立项审批表 |
| 基础资料 | 施工图纸、合同文件、变更签证、竣工图纸 |
| 计算文件 | 工程量计算书、套价文件、电子模型 |
| 成果文件 | 成果初稿、正式成果文件 |
| 核对记录 | 对账记录、争议处理记录、会议纪要 |
| 复核记录 | 三级复核记录 |

**第三十一条** 归档要求：
1. 纸质档案和电子档案同步归档
2. 档案目录清晰，便于检索
3. 电子档案使用公司统一命名规则
4. 归档交接单由归档人和档案管理员双方签字

**第三十二条** 档案保管期限：
- 审计类项目：自报告日起至少保存10年
- 造价类项目：自成果文件出具日起至少保存10年
- 咨询类项目：自报告日起至少保存5年

## 第九章 项目后评价

**第三十三条** 项目后评价目的：
1. 总结项目经验教训
2. 评估项目经济效益
3. 改进项目管理方法
4. 积累行业知识和案例

**第三十四条** 后评价内容：

| 评价维度 | 评价指标 |
|---------|---------|
| 质量评价 | 复核发现问题数量、客户满意度评分 |
| 效率评价 | 实际工时 vs 预算工时、实际周期 vs 计划周期 |
| 效益评价 | 项目实际利润率 = (收入-直接成本) / 收入 |
| 团队评价 | 团队协作评分、个人成长评估 |
| 风险评价 | 项目风险事件记录、处理效果 |

**第三十五条** 后评价流程：
1. 项目归档后15个工作日内，项目经理填写《项目后评价表》
2. 部门负责人审阅并提出改进建议
3. 典型经验或教训纳入公司知识库
4. 共性问题由管理层研究改进措施

**第三十六条** 知识沉淀：
1. 每个A类项目结束后，应形成项目案例摘要
2. 典型案例纳入公司培训教材
3. 行业数据、经验参数纳入公司知识库
