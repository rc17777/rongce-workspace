> **制度编号**：RC-ADM-001  
> **版本**：V1.0

## 第一章 总则

**第一条** 为规范公司办公场所管理，营造整洁、有序、安全、高效的办公环境，合理配置和使用办公资源，保障公司正常运营秩序，制定本制度。

**第二条** 本制度适用于公司全体员工（含试用期员工、实习生）及来访人员。

**第三条** 办公场所管理基本原则：
1. **统一管理**：由行政管理部门（以下简称"行政部"）统一负责办公场所的日常管理；
2. **合理配置**：工位和公共资源按需分配、动态调整；
3. **安全第一**：消防安全、财产安全和信息安全并重；
4. **共同维护**：全体员工均有维护办公环境的责任和义务。

**第四条** 行政部是办公场所管理的归口部门，具体职责包括：
1. 工位分配、调换及回收管理；
2. 会议室调度与设备维护；
3. 办公环境卫生检查；
4. 门禁、消防、安防管理；
5. 来访人员接待登记管理。


## 第二章 工位管理

**第五条** 工位分配原则：
1. 按部门集中分配，便于业务协作和内部沟通；
2. 项目经理及以上人员原则上分配独立工位或小办公室；
3. 审计助理、造价员等一般人员分配开放式工位；
4. 长期驻外或外勤人员（外勤天数占比≥60%）原则上不保留固定工位，实行共享工位（hot desk）。

**第六条** 新员工入职时，由用人部门提前三个工作日向行政部提交工位需求，行政部在入职当日完成工位分配，配置必要的办公设备（桌椅、电脑、电话等）。

**第七条** 工位调换：
1. 因部门调整、岗位变动或业务需要，由部门负责人向行政部提出工位调换申请；
2. 个人原因申请调换工位的，需经本部门负责人同意后报行政部审批；
3. 行政部在收到申请后三个工作日内完成调换安排。

**第八条** 员工离职时，应在一周内完成工位清理和物品交接：
1. 清空个人物品；
2. 归还公司固定资产（电脑、电话、文件柜钥匙等）；
3. 清理电子文件（按RC-ADM-005档案管理制度和RC-ADM-002信息安全制度执行）；
4. 行政部验收后回收工位。

**第九条** 工位使用规范：
1. 保持工位整洁，桌面物品摆放有序；
2. 下班后应将重要文件入柜上锁；
3. 不得在工位用餐（可到茶水间或休息区）；
4. 不得私自调换工位；
5. 工位内不得存放易燃易爆、违禁物品。


## 第三章 会议室使用

**第十条** 公司会议室按功能和容量分级管理：

| 会议室类型 | 容量 | 适用场景 | 预约权限 |
|-----------|------|---------|---------|
| 大会议室 | 15-20人 | 全员会议、培训、客户接待 | 部门负责人及以上 |
| 中会议室 | 8-12人 | 部门会议、项目研讨 | 项目经理及以上 |
| 小会议室/洽谈室 | 2-6人 | 面试、内部沟通、电话会议 | 全体员工 |

**第十一条** 会议室预约：
1. 通过公司OA系统或会议室预约表（纸质/电子）提前预约；
2. 预约需注明会议主题、时间、参会人数、所需设备；
3. 同一会议室每日预约原则上不超过4个时段（上午2个/下午2个），每个时段不超过2小时；
4. 取消预约应至少提前30分钟通知行政部释放资源。

**第十二条** 会议室使用优先级（同一时段冲突时）：
1. 客户接待 > 外部会议；
2. 外部会议 > 全员会议；
3. 全员会议 > 部门会议；
4. 部门会议 > 个人预约。

**第十三条** 会议室设备管理：
1. 会议室配备投影仪/大屏显示器、白板、视频会议设备等；
2. 使用前应提前测试设备，发现故障及时通知行政部；
3. 不得私自拆装、移动会议室设备；
4. 使用完毕后应关闭投影、空调、灯光等设备。

**第十四条** 会后整理：
1. 会议结束后，会议召集人负责组织整理会议室；
2. 擦除白板内容；
3. 归位桌椅，清理桌面垃圾；
4. 带走个人物品和会议材料；
5. 涉及保密信息的会议材料不得遗留在会议室。

**第十五条** 行政部每日上午和下午各巡检一次会议室，确保设备正常、环境整洁。对未按规定整理的使用者，首次提醒，二次及以上通报部门负责人。


## 第四章 办公环境管理

**第十六条** 卫生管理：
1. 公共区域（走廊、茶水间、卫生间、接待区）：由保洁员每日清扫两次（上班前和午休后）；
2. 个人工位：由员工自行保持整洁，行政部每周抽查；
3. 茶水间：水槽每日清理，冰箱每月清理一次，过期食品直接丢弃；
4. 公司每月开展一次全员大扫除（原则上月末最后一个周五下午）。

**第十七条** 绿植管理：
1. 公共区域绿植由行政部委托专业公司定期养护；
2. 个人工位绿植由员工自行养护，不得放置有异味或易滋生蚊虫的植物；
3. 绿植枯死后及时清理更换。

**第十八条** 温度管理：
1. 夏季空调温度设置不低于26℃，冬季不高于20℃（参照国家节能标准）；
2. 最后一个离开办公室的员工应关闭空调；
3. 禁止私自使用取暖器、冷风机等大功率电器。

**第十九条** 噪音控制：
1. 办公区域保持安静，交谈和接听电话控制音量；
2. 手机铃声调至震动或静音；
3. 会议室使用期间应关闭门以减少声音外溢；
4. 在开放式工位接听私人电话应到茶水间或走廊。

**第二十条** 禁烟管理：
1. 办公区域（含工位、会议室、茶水间、走廊）全面禁烟；
2. 吸烟请到指定吸烟区（如有）或楼下室外区域。


## 第五章 安全管理

**第二十一条** 门禁管理：
1. 公司大门采用门禁系统管理，员工凭门禁卡或指纹进入；
2. 门禁卡仅限本人使用，不得转借他人；
3. 门禁卡遗失应立即向行政部报告并办理挂失补办；
4. 离职员工应在离职当日交还门禁卡。

**第二十二条** 外来人员进入办公区域，须在前台登记，由被访员工到前台接待或行政部引导进入。外来人员不得单独进入工位区域或档案室。

**第二十三条** 消防管理：
1. 办公场所按消防规范配置灭火器和消防设施，行政部每月检查一次；
2. 消防通道、楼梯口、消防栓前不得堆放任何物品；
3. 全体员工须知晓消防通道位置和灭火器使用方法；
4. 公司每年组织至少一次消防演练（可与物业联合开展）；
5. 一旦发现火情，立即拨打119报警并启动消防应急预案，同时通知行政部和公司领导。

**第二十四条** 下班安全检查（"三关一锁"）：
1. **关门窗**：最后离开的员工负责检查并关闭所有窗户；
2. **关电源**：关闭个人电脑、显示器、打印机、饮水机等用电设备（服务器、监控设备等持续运行设备除外）；
3. **关空调**：确认所有空调已关闭；
4. **锁门**：确认公司大门已锁好。

行政部每日下班后抽查"三关一锁"落实情况，检查结果纳入部门安全考核。

**第二十五条** 应急物资：公司配备急救箱（行政部保管，定期检查药品有效期）、应急手电筒等物资。


## 第六章 来访接待管理

**第二十六条** 来访分类：

| 来访类型 | 接待流程 | 负责部门 |
|---------|---------|---------|
| 客户来访 | 预约→前台登记→接待人引导→洽谈/会议室 | 业务对接部门 |
| 政府检查/调研 | 预约→前台登记→行政部/负责人接待引导 | 行政部/公司领导 |
| 合作方/供应商 | 预约→前台登记→相关部门接待 | 相关部门 |
| 面试人员 | 预约→前台登记→HR接待引导 | 人力资源部 |
| 临时/未预约来访 | 前台登记→电话确认→接待或婉拒 | 行政部 |

**第二十七条** 预约来访：接待人应至少提前半个工作日通知行政部，说明来访单位、人数、时间、需准备的设备和资料。行政部提前准备接待区域。

**第二十八条** 前台接待规范：
1. 主动问候，询问来访目的和预约情况；
2. 请来访人员填写《来访登记表》（姓名、单位、联系电话、来访事由、被访人、到访/离开时间）；
3. 发放临时来访证（如需）；
4. 通知被访员工到前台引导，或由行政部引导至指定区域。

**第二十九条** 客户接待标准：
1. 重要客户来访，接待人应提前确认到访时间并在前台等候；
2. 会议室提前准备茶水（矿泉水/热茶）；
3. 必要时准备公司宣传资料或项目资料；
4. 来访结束后，接待人送客户至电梯口或一楼大厅。

**第三十条** 来访人员不得在办公区域随意走动、拍照或翻阅文件。涉及保密区域的，由接待人全程陪同。来访证在离开时交还前台。


## 第七章 公共设施管理

**第三十一条** 茶水间管理：
1. 茶水间提供饮水机（冷/热水）、微波炉、冰箱；
2. 茶叶、咖啡等消耗品由行政部统一采购补充，员工自行取用但不得浪费；
3. 微波炉使用后及时清洁，冰箱内物品标注姓名和存放日期，过期由行政部每周清理；
4. 茶渣倒入专用垃圾桶，不得倒入洗手池。

**第三十二条** 打印/复印区域管理：
1. 公用打印机、复印机由行政部管理，每日关机前检查纸张和墨粉余量；
2. 大批量打印（超过50页）或彩色打印需经部门负责人同意；
3. 双面打印优先（制度/报告类除外）；
4. 废纸统一放入碎纸机或保密废纸回收箱。

**第三十三条** 休息区/员工活动区管理：
1. 休息区供员工午休、短暂休息使用；
2. 保持安静整洁，午休时段（12:30-13:30）尤应注意控制声响；
3. 使用后清理个人物品，不在休息区长期堆放私人用品。


## 第八章 检查与违规处理

**第三十四条** 行政部每周至少一次对办公环境进行巡检，检查项目包括：
1. 工位整洁度；
2. 会议室整理情况；
3. 防火设施及安全出口；
4. 公共区域卫生状况；
5. "三关一锁"执行情况。

**第三十五条** 检查结果记录在案，每月汇总通报。对反复出现的问题，由行政部约谈相关部门负责人。

**第三十六条** 违规处理：

| 违规行为 | 处理措施 |
|---------|---------|
| 第一次轻微违规（如工位杂乱、会后未整理） | 口头提醒 |
| 第二次同类违规 | 书面提醒，抄送部门负责人 |
| 第三次或较严重违规（如私自转借门禁卡） | 通报批评，视情况罚款50-200元 |
| 严重违规（如损坏消防设施、窃取公司财物） | 赔偿损失，依据员工手册相关条款处理，情节严重者解除劳动关系 |


## 第九章 附则

**第三十七条** 本制度自发布之日起施行，有效期三年。期满前三个月由行政部组织修订评估。

**第三十八条** 本制度由行政部负责解释和修订，重大修订须报总经理审批。

**第三十九条** 如本制度与法律法规冲突，以法律法规为准。
