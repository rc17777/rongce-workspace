# 四川融策党建工作制度

> **制度编号**：RC-SPL-004  
> **版本**：V1.0  
> **编制日期**：2026年7月22日

> **优先级**：P2

## 第一章 总则

**第一条** 为加强公司党的建设，充分发挥党组织在非公有制企业中的政治核心作用和政治引领作用，根据《中国共产党章程》和有关规定，结合公司实际，制定本制度。

**第二条** 公司党建工作总体要求：
1. 坚持党的领导，确保公司发展符合党的路线方针政策和国家法律法规；
2. 引导和监督企业依法经营、诚信执业；
3. 团结凝聚职工群众，维护各方合法权益；
4. 建设先进企业文化，促进企业健康发展；
5. 组织党员发挥先锋模范作用，带领全体员工创先争优。

**第三条** 公司为党组织开展活动提供必要的场所、时间和经费支持。每年党建工作经费纳入公司预算管理，用于组织活动、学习教育、阵地建设等。


## 第二章 党组织设置

**第四条** 公司具备正式党员3人以上的，应当成立党支部。党员人数不足3人的，经上级党组织同意，可与邻近企业建立联合党支部。

**第五条** 党支部委员会设置：
1. 党员7人以上的党支部，设立支部委员会，委员3-5名，其中设书记1名；
2. 党员不足7人的党支部，设书记1名，必要时可设副书记1名；
3. 支部委员会由党员大会选举产生，每届任期3年。

**第六条** 党支部下设若干党小组。党小组按部门或业务线划分，每组3人以上，设党小组组长1名。党小组组长由本小组成员推选产生。

**第七条** 党组织工作职责：
1. 宣传和执行党的路线方针政策，贯彻上级党组织的决议；
2. 组织党员学习党章党规和党的理论、路线、方针、政策；
3. 对党员进行教育、管理、监督和服务；
4. 做好发展党员和党员管理工作；
5. 密切联系职工群众，做好思想政治工作；
6. 领导和支持工会、共青团等群团组织独立开展工作；
7. 参与公司重大决策的讨论和民主监督。

**第八条** 党支部委员会成员因工作变动或其他原因出现空缺时，应及时进行补选。党支部书记确因工作变动需调整的，应征得上级党组织同意。


## 第三章 党员教育管理

**第九条** "三会一课"制度：

### 3.1 支部党员大会

**第十条** 支部党员大会每季度至少召开1次。主要内容：
1. 传达学习党的路线方针政策和上级党组织的决议、指示；
2. 听取和审查支部委员会工作报告；
3. 讨论接收预备党员和预备党员转正；
4. 讨论决定对党员的表彰和纪律处分；
5. 选举支部委员会和出席上级党代会的代表。

### 3.2 支部委员会会议

**第十一条** 支部委员会会议每月至少召开1次。主要内容：
1. 研究制定支部工作计划和总结；
2. 分析党员和职工思想状况；
3. 讨论党员发展和教育管理事项；
4. 研究工会、共青团工作；
5. 需要提交党员大会讨论决定的事项。

### 3.3 党小组会议

**第十二条** 党小组会议每月至少召开1次。主要内容：
1. 组织党员学习；
2. 开展批评与自我批评；
3. 讨论执行支部决议的具体措施；
4. 谈心谈话，了解党员思想动态和工作情况；
5. 推荐入党积极分子。

### 3.4 党课

**第十三条** 党课每季度至少安排1次（可与主题党日结合开展）。党课由党支部书记或委员主讲，也可邀请上级党组织领导、党校教师或先进模范讲课。

**第十四条** 主题党日活动：每月相对固定1天作为主题党日（原则上每月最后一个周五下午），组织党员集中学习、过组织生活、进行民主议事和志愿服务等。

**第十五条** 党员组织生活管理：
1. 党员因故不能参加组织生活的，须向党支部书记请假；
2. 连续6个月不参加组织生活或不缴纳党费的，按党章规定处理；
3. 流动党员（组织关系不在本公司但在公司工作6个月以上的党员）应参加公司党组织活动。

**第十六条** 党员学习教育内容：
1. 习近平新时代中国特色社会主义思想；
2. 党章党规党纪；
3. 党的路线方针政策和决议；
4. 党的历史和优良传统；
5. 行业法律法规和职业道德教育（将党建与执业合规教育结合）。


## 第四章 党建与业务融合

**第十七条** 坚持"党建促业务、业务强党建"的工作方向，将党建工作融入公司经营管理。

**第十八条** 党员示范岗：在关键岗位设立"党员示范岗"，亮明党员身份，接受群众监督。示范岗党员要求：
1. 业务能力突出，在本职岗位发挥标杆作用；
2. 带头遵守公司制度和执业规范；
3. 主动帮助同事和客户解决实际问题；
4. 示范岗每年度评选一次，流动挂牌。

**第十九条** "党建+项目"工作机制：
1. 在重大审计项目或工程造价咨询项目中，项目组内有3名及以上党员的，可成立临时党小组；
2. 临时党小组在项目期间加强思想政治引领，确保项目团队严守职业道德；
3. 项目完成质量作为评价党员先锋作用的重要参考。

**第二十条** 党建与执业能力提升结合：
1. 将党员教育与执业继续教育相结合，党课可融入行业法规解读、职业道德案例分析等内容；
2. 鼓励党员参加行业技能竞赛、业务研讨和课题攻关；
3. 将党员参与党建活动和公益服务的表现纳入年度评优参考。

**第二十一条** 凝心聚力工程：
1. 支部定期收集员工意见和建议，通过组织渠道向管理层反馈；
2. 协调解决员工反映的合理诉求（如工作条件、福利保障等）；
3. 关心困难党员和职工，提供力所能及的帮助；
4. 组织文体活动（如读书会、运动会、团建等），增强团队凝聚力。


## 第五章 发展党员工作

**第二十二条** 发展党员坚持"控制总量、优化结构、提高质量、发挥作用"十六字总要求，严格按照《中国共产党发展党员工作细则》执行。

**第二十三条** 发展党员流程：

```
递交入党申请书 → 确定入党积极分子 → 培养教育考察（≥1年）
→ 确定发展对象 → 政治审查 → 短期集中培训 
→ 支部大会讨论接收预备党员 → 上级党组织审批 
→ 预备期考察（1年）→ 转正申请 → 支部大会讨论转正 
→ 上级党组织审批
```

### 5.1 入党积极分子阶段

**第二十四条** 申请入党条件：年满十八岁，承认党的纲领和章程，愿意参加党的一个组织并在其中积极工作、执行党的决议和按期缴纳党费的，可向党支部递交入党申请书。

**第二十五条** 党支部收到入党申请书后，在1个月内派人与申请人谈话，了解其入党动机和基本情况。

**第二十六条** 确定入党积极分子：经党小组推荐（党员推荐），支部委员会研究决定，将符合条件的申请人确定为入党积极分子。确定之日起纳入党组织培养教育，指定2名正式党员作为培养联系人。

**第二十七条** 培养教育考察期不少于1年。每季度至少填写1次《入党积极分子培养考察登记表》。

### 5.2 发展对象阶段

**第二十八条** 在入党积极分子经过1年以上培养教育考察后，基本具备党员条件的，经支部委员会讨论，可列为发展对象。

**第二十九条** 发展对象须经过政治审查（含本人对党的路线方针政策的态度、政治历史和在重大政治斗争中的表现、直系亲属主要社会关系的政治情况等），政治审查不合格的不能发展入党。

**第三十条** 发展对象须参加短期集中培训（不少于3天或24学时）。未经培训的，一般不能发展入党。

### 5.3 预备党员阶段

**第三十一条** 支部大会讨论接收预备党员：须有表决权的到会党员超过半数，采取无记名投票方式表决，赞成票超过应到会有表决权党员的半数方为通过。支部大会通过后报上级党组织审批。

**第三十二条** 预备党员预备期为1年。预备期内由入党介绍人继续教育考察，每季度填写1次预备党员考察记录。

**第三十三条** 预备期满，预备党员须书面提出转正申请。支部大会按期讨论其转正问题，表决程序同接收预备党员。具备党员条件的，按期转正；需要继续考察的，可延长预备期（不少于半年、不超过1年）；不履行党员义务、不具备党员条件的，取消预备党员资格。

**第三十四条** 发展党员比例：在保证质量的前提下，每年发展的新党员中，应注重从业务骨干和一线优秀员工中发展，注重在青年员工中发展。每年发展预备党员1-2名。


## 第六章 党风廉政建设

**第三十五条** 组织党员学习廉洁自律准则和纪律处分条例，开展党风廉政教育。

**第三十六条** 督促党员带头遵守公司各项规章制度和职业道德规范，重点在以下方面发挥表率作用：
1. 严守审计/造价执业准则，不弄虚作假；
2. 保守客户商业秘密和公司机密；
3. 不收受客户或供应商的礼品礼金；
4. 不利用职务之便谋取私利。

**第三十七条** 党内监督：党小组定期开展谈心谈话和批评与自我批评，及时发现和纠正苗头性问题。

**第三十八条** 每年开展民主评议党员工作：按照个人自评、党员互评、民主测评的程序，对党员进行评议。评议结果分为优秀、合格、基本合格、不合格四个等次。对评为优秀的予以表彰，对评为不合格的进行教育帮助或组织处置。


## 第七章 党建台账管理

**第三十九条** 党支部建立以下基础台账，做到准确、完整、及时更新：
1. **党员花名册**：含姓名、性别、出生日期、民族、学历、入党时间、转正时间、工作岗位、联系方式；
2. **入党积极分子名册**；
3. **党费收缴登记表**；
4. **三会一课记录本**：含时间、地点、参会人员、主题、主要内容摘要；
5. **党员组织生活记录**；
6. **党建工作计划和总结**（年度）。

**第四十条** 党建台账由党支部指定专人（组织委员或指定委员）负责保管和更新，接受上级党组织检查。


## 第八章 工会与群团工作

**第四十一条** 党支部领导和支持工会依章程独立开展工作：
1. 维护职工合法权益；
2. 组织文体活动和技能竞赛；
3. 开展职工慰问和困难帮扶。

**第四十二条** 公司按《工会法》规定计提工会经费并拨付工会使用。工会经费由工会委员会独立管理。

**第四十三条** 鼓励公司青年员工加入共青团组织。公司28岁以下青年员工3人以上的，可按程序申请设立团支部，在党支部领导下开展工作。


## 第九章 附则

**第四十四条** 本制度自发布之日起施行。

**第四十五条** 本制度由公司党支部负责解释和修订。重大修改须经支部委员会讨论通过。

**第四十六条** 本制度如与上级党组织新规定不一致，以上级规定为准。

**第四十七条** 本制度配套文件：
- 《党员发展流程图》
- 《入党申请书（参考模板）》
- 《党员年度民主评议表》
- 《三会一课记录本（模板）》

---

*本制度为四川融策公司内部管理制度。党建工作是非公企业健康发展的重要保障，全体党员应带头遵守、积极践行。*
