## 第一章 总则

**第一条** 为规范公司招聘与入职管理，确保人才引进质量，保障用人合规，依据《中华人民共和国劳动合同法》及四川省相关法规，结合公司实际，制定本制度。

**第二条** 本制度适用于四川融策会计师事务所有限公司（以下简称"事务所"）和四川融策工程咨询有限公司（以下简称"工程公司"）全体员工的招聘与入职管理。

**第三条** 招聘原则：

1. **按需设岗**：以业务发展和岗位需求为依据，不盲目扩编；
2. **公开公平**：招聘信息公开发布，择优录用，杜绝歧视；
3. **人岗匹配**：注重专业能力与岗位要求的匹配度；
4. **内部优先**：同等条件下优先考虑内部调配和内部推荐。

## 第二章 招聘需求与审批

**第四条** 各部门因业务发展或人员变动需补充人员时，应填写《招聘需求申请表》，载明：

1. 招聘岗位、人数；
2. 岗位职责及任职要求；
3. 到岗时间要求；
4. 薪资建议范围。

**第五条** 招聘需求审批流程：

```
部门负责人提交申请 → 综合管理部（HR）审核 → 总经理批准
```

1. **综合管理部审核**：核实编制情况、岗位必要性、薪资合理性，5个工作日内出具审核意见；
2. **总经理批准**：综合管理部审核通过后，报总经理审批。总经理3个工作日内作出决定。

**第六条** 年度招聘计划：各部门应于每年12月底前报送下一年度人员需求计划，由综合管理部汇总编制年度招聘计划，经总经理批准后执行。计划外招聘需单独审批并说明原因。

## 第三章 招聘渠道

**第七条** 公司招聘渠道包括：

| 渠道 | 适用情形 | 负责人 |
|------|---------|--------|
| **内部推荐** | 各类岗位，优先渠道 | 综合管理部 |
| **网络招聘** | 各类岗位 | 综合管理部 |
| **校园招聘** | 审计助理、造价助理等初级岗位 | 综合管理部+业务部门 |
| **猎头服务** | 高级项目经理及以上或稀缺专业岗位 | 综合管理部 |

**第八条** 内部推荐管理：

1. 公司员工可推荐外部候选人，推荐人应填写《内部推荐表》；
2. 被推荐人通过面试并入职后，推荐人可获得内部推荐奖金（具体标准由综合管理部另行制定）；
3. 被推荐人在公司工作不满一年离职的，推荐奖金不予发放或追回。

**第九条** 校园招聘：每年秋招（9-11月）和春招（3-4月）由综合管理部牵头，联合业务部门赴目标院校开展宣讲、笔试和面试。

**第十条** 猎头服务：仅用于高级项目经理及以上岗位或市场稀缺专业人才。猎头费用原则上不超过候选人首年年薪的20%，需经总经理批准。

## 第四章 面试流程

**第十一条** 面试实行分级制度：

### 一般岗位（审计员、造价员、行政人员等）

```
简历筛选 → HR初面 → 部门专业面试 → 录用决定
```

### 关键岗位（项目经理及以上、财务主管、部门负责人等）

```
简历筛选 → HR初面 → 部门专业面试 → 总经理终面 → 背景调查 → 录用决定
```

**第十二条** 各环节职责：

1. **简历筛选**：综合管理部根据岗位任职要求进行初筛，筛选通过率控制在20%-30%；
2. **HR初面**：综合管理部负责，考察基本素质、沟通能力、职业意向、薪资期望等，填写《面试评价表》；
3. **部门专业面试**：用人部门负责人或指定面试官负责，考察专业技能、项目经验、实操能力，可采用案例分析、实务操作等方式；
4. **总经理终面**（关键岗位）：总经理考察综合素质、价值观匹配度、发展潜力。

**第十三条** 面试评价实行量化评分，满分100分，各维度权重：

| 维度 | 权重 | 说明 |
|------|------|------|
| 专业知识 | 30% | 岗位所需专业技能 |
| 实操能力 | 25% | 案例分析/实务操作 |
| 沟通表达 | 15% | 语言组织、逻辑清晰 |
| 职业素养 | 15% | 责任心、团队协作 |
| 发展潜力 | 15% | 学习能力、成长空间 |

**第十四条** 录用标准：面试综合评分≥70分方可进入录用环节。关键岗位需≥80分。

## 第五章 背景调查

**第十五条** 以下岗位入职前须进行背景调查：

1. 项目经理及以上岗位；
2. 财务主管及以上岗位；
3. 部门负责人及以上岗位；
4. 涉及资金管理、合同签署的岗位。

**第十六条** 背景调查内容包括：

1. 学历学位真实性验证；
2. 执业资格证书验证（CPA、造价工程师等）；
3. 前雇主工作表现及离职原因（至少联系一家前雇主）；
4. 有无违法犯罪记录（需本人书面授权）；
5. 有无竞业限制义务。

**第十七条** 背景调查由综合管理部负责实施，可委托第三方机构进行。背景调查须在候选人书面授权后进行，未取得授权的不得开展。

**第十八条** 背景调查中发现以下情况的，原则上不予录用：

1. 学历、资格证书造假的；
2. 前雇主反映存在严重职业道德问题的；
3. 有经济犯罪记录的；
4. 存在未解除竞业限制义务的。

## 第六章 Offer发放与入职流程

**第十九条** 录用审批通过后，综合管理部应在2个工作日内向候选人发放《录用通知书》（Offer），载明：

1. 录用岗位、所属部门；
2. 薪酬待遇（基本工资+绩效+津贴，参照 RC-HR-001 薪酬管理制度）；
3. 报到时间、地点及联系人；
4. 需携带的入职材料清单；
5. Offer有效期（一般为5个工作日）。

**第二十条** 入职材料清单：

1. 身份证原件及复印件；
2. 学历学位证书原件及复印件；
3. 执业资格证书原件及复印件（如适用）；
4. 前单位离职证明（应届毕业生除外）；
5. 近期一寸免冠照片2张；
6. 银行卡信息（工资卡）；
7. 体检报告（近3个月内）；
8. 其他公司要求的材料。

**第二十一条** 入职当天办理事项：

1. 核验入职材料，填写《员工入职登记表》；
2. 签订《劳动合同》（一式两份，员工留存一份）；
3. 签订《保密协议》及《竞业限制协议》（如适用）；
4. 办理社保、公积金增员手续；
5. 领取办公用品、门禁卡、电脑等；
6. 开通企业微信、邮箱等系统账号；
7. 安排入职培训（参照 RC-HR-005 培训与发展管理制度）。

**第二十二条** 劳动合同签订要点：

1. 合同期限：首次签订一般为3年固定期限；
2. 试用期：按《劳动合同法》规定执行（详见第七章）；
3. 工作内容：明确岗位及职责范围；
4. 工作地点：成都市，因项目需要的出差条款；
5. 劳动报酬：按 RC-HR-001 薪酬管理制度执行；
6. 其他法定必备条款。

## 第七章 试用期管理

**第二十三条** 试用期按照《劳动合同法》规定执行：

| 劳动合同期限 | 试用期 |
|-------------|--------|
| 完成一定工作任务为期限 | 不得约定试用期 |
| 不满1年 | 不超过1个月 |
| 1年以上不满3年 | 不超过2个月 |
| 3年以上或无固定期限 | 不超过6个月 |

**第二十四条** 试用期工资不得低于转正工资的80%，且不得低于成都市最低工资标准。

**第二十五条** 试用期考核：

1. **月度跟踪**：直接上级每月与试用期员工进行一次面谈，了解适应情况，填写《试用期月度跟踪表》；
2. **转正考核**：试用期满前15天，由直接上级填写《试用期转正评估表》，从工作能力、工作态度、团队融入、学习成长四个维度进行评估；
3. **考核结果**：
   - 合格：按期转正；
   - 基本合格：可延长试用期（累计不超过法定上限），明确改进目标；
   - 不合格：依法解除劳动合同，需有书面考核记录证明"不符合录用条件"。

**第二十六条** 试用期解除劳动合同的，公司应当：

1. 有明确的录用条件并已书面告知员工；
2. 有书面的考核记录证明不符合录用条件；
3. 在试用期内作出解除决定并书面通知；
4. 说明解除理由。

## 第八章 入职引导与融入

**第二十七条** 新员工入职引导实行"导师制"：

1. 每位新员工指定一名入职引导人（一般为部门内资深员工）；
2. 引导人负责帮助新员工熟悉环境、了解流程、融入团队；
3. 引导期一般为1-3个月；
4. 引导人可获得适当的引导津贴（具体标准由综合管理部另行制定）。

**第二十八条** 入职培训内容（参照 RC-HR-005）：

1. 公司制度培训：企业文化、组织架构、规章制度；
2. 业务培训：业务流程、操作规范、工具使用；
3. 合规培训：保密要求、职业道德、信息安全。

---

## 第九章 附则

**第二十九条** 招聘过程中产生的费用（招聘网站年费、校园招聘差旅费、猎头费等）纳入年度人力资源预算。

**第三十条** 招聘工作相关档案（简历、面试评价表、背景调查资料、录用审批等）由综合管理部保存，保存期限不少于员工离职后两年。

**第三十一条** 本制度未尽事宜，依照《劳动合同法》及四川省相关法规执行。

**第三十二条** 本制度由综合管理部负责解释和修订，经总经理批准后施行。
