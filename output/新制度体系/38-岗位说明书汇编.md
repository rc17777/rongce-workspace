# RC-HR-JD-001 审计助理

> **岗位编号**：RC-HR-JD-001 | **所属部门**：审计部 | **岗位等级**：G1 | **版本**：V1.0 | **编制日期**：2026-07-22

---

## 一、岗位基本信息

| 项目 | 内容 |
|------|------|
| 岗位名称 | 审计助理 |
| 所属部门 | 审计部 |
| 岗位等级 | G1（岗位工资区间：2,000-3,000元/月） |
| 直接上级 | 审计员/高级审计员 |
| 直接下级 | 无 |
| 岗位编制 | 4-6人 |

## 二、岗位职责

1. 负责协助审计员完成审计底稿的编制、整理和归档工作
2. 负责审计证据的收集、复印、整理和分类保管
3. 参与被审计单位的现金盘点、固定资产盘点、存货监盘等现场工作
4. 负责审计数据的录入、核对和基础统计分析
5. 配合完成审计函证的收发、登记和回函跟踪
6. 参与政府采购项目、财政资金项目的现场审计辅助工作
7. 完成上级交办的其他审计相关工作

## 三、任职资格

| 维度 | 要求 |
|------|------|
| 学历 | 大专及以上 |
| 专业 | 会计学、审计学、财务管理及相关专业 |
| 工作经验 | 应届毕业生或1年以内审计/财务工作经验 |
| 执业资格 | 无硬性要求，通过初级会计职称考试者优先 |
| 核心能力 | ①基础会计实务操作能力；②熟练使用Excel等办公软件；③细致耐心，数据敏感度高；④良好的学习意愿和团队协作意识；⑤能适应出差和现场审计工作节奏 |
| 其他 | 熟悉政府会计制度、行政事业单位财务规则者优先 |

## 四、绩效考核要点

| 考核维度 | 权重 | 关键指标 |
|---------|------|---------|
| 项目质量 | 30% | 底稿一次通过率≥70%；审计程序执行完整率≥90% |
| 项目进度 | 25% | 里程碑按时完成率≥75%；平均超期≤5天 |
| 客户满意度 | 20% | 客户平均评分≥70分；有效投诉≤2次 |
| 专业能力 | 15% | 继续教育完成率≥80%；内部测试≥70分 |
| 团队协作 | 10% | 360度协作评分≥70分 |

## 五、职业发展

- 晋升路径：审计助理（G1）→ 审计员（G2）→ 高级审计员（G3）→ 审计项目经理（G4）
- 培训要求：每年不少于40学时继续教育（含内部培训和外部培训）

| 其他 | 有担任过省级以上重点项目造价负责人经历者优先；有造价行业专家库成员资格者优先 |

### 四、绩效考核要点
