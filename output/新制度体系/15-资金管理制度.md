## 第一章 总则

**第一条** 为加强公司资金管理，保障资金安全，提高资金使用效率，防范资金风险，依据《企业财务通则》《现金管理暂行条例》及相关法规，结合公司实际，制定本制度。

**第二条** 本制度适用于四川融策会计师事务所有限公司（以下简称"事务所"）和四川融策工程咨询有限公司（以下简称"工程公司"）的资金管理活动。

**第三条** 资金管理原则：

1. **安全优先**：资金安全是一切操作的前提；
2. **分级审批**：不同金额由不同层级审批，权责对等；
3. **不相容职务分离**：出纳与会计分离，审批与执行分离；
4. **日清月结**：现金日清月结，银行按月对账。

## 第二章 资金分级审批

**第四条** 公司资金支出实行分级审批制度：

| 审批层级 | 单笔金额 | 审批人 | 备注 |
|---------|---------|--------|------|
| 第一级 | ≤10,000元 | 部门负责人 | 日常办公、小额支出 |
| 第二级 | 10,000元＜金额≤50,000元 | 副总经理 | 较大支出 |
| 第三级 | 50,000元＜金额≤200,000元 | 总经理 | 重大支出 |
| 第四级 | ＞200,000元 | 股东会 | 特别重大支出 |

**第五条** 审批流程：

```
经办人填写付款申请 → 部门负责人审批（≤1万直接审批 / ＞1万签署意见后上报）
  → 副总经理审批（1-5万） → 总经理审批（5-20万） → 股东会审批（＞20万）
  → 财务部审核 → 出纳付款
```

**第六条** 审批要点：

1. 审批人应确认支出的真实性、合理性和必要性；
2. 审批人应确认该笔支出在预算范围内（参照 RC-FIN-003 预算管理制度）；
3. 财务部审核单据完整性、金额准确性、审批手续齐全性；
4. 手续不全的，财务部有权退回。

**第七条** 紧急付款：因特殊情况需紧急付款且审批人不在的，可电话/微信请示审批，事后24小时内补齐书面审批手续。紧急付款仍需财务部审核后方可执行。

## 第三章 银行账户管理

**第八条** 公司银行账户设置：

| 账户类型 | 用途 | 数量 | 说明 |
|---------|------|------|------|
| 基本存款账户 | 日常结算、工资发放、现金存取 | 每公司1个 | 唯一可提取现金的账户 |
| 一般存款账户 | 专项收付、贷款结算等 | 按需 | 不得提取现金 |

**第九条** 银行账户开立、变更、注销须经总经理审批，由财务部统一办理。任何部门和个人不得私自开立或使用公司银行账户。

**第十条** 网银管理：

1. **双人操作**：网银操作实行"录入-复核"双人制，录入人和复核人不得为同一人；
2. **权限分离**：
   - 录入员（出纳）：负责发起付款、查询余额；
   - 复核员（财务主管/指定人员）：负责审核付款、授权转账；
3. **U盾管理**：各操作人员U盾各自保管，不得互相借用或交予他人；
4. **密码管理**：网银密码不少于8位，含字母+数字，每3个月更换一次；
5. **限额设置**：单笔转账限额和日累计限额由总经理根据业务需要设定。

**第十一条** 银行对账：

1. 出纳每月5日前获取上月银行对账单；
2. 会计在10日前完成银行余额调节表编制；
3. 未达账项应及时查明原因并处理；
4. 银行余额调节表由财务主管审核签字。

## 第四章 备用金管理

**第十二条** 备用金是指因业务需要预支给员工的零星周转资金。

**第十三条** 备用金管理规则：

| 项目 | 规定 |
|------|------|
| 单人限额 | ≤5,000元 |
| 审批权限 | 部门负责人申请 → 财务部审核 → 总经理批准 |
| 使用范围 | 差旅备用、零星采购、紧急业务支出 |
| 结清期限 | 月度结清（每月25日前须结清或归还） |
| 前借后清 | 前次备用金未结清的，不得再次借支 |

**第十四条** 备用金借支流程：

```
填写《备用金借支单》（注明用途、金额、预计归还日期）
  → 部门负责人审批 → 财务部审核 → 总经理审批 → 出纳付款
```

**第十五条** 备用金归还：

1. 使用完毕后3个工作日内，凭有效票据报销并结清备用金；
2. 报销金额＜借支金额的，差额退回出纳；
3. 报销金额＞借支金额的，差额补付给员工；
4. 逾期未结清的，财务部发出催还通知；超过15天未归还的，从当月工资中扣回。

**第十六条** 年末（12月25日前）所有备用金必须全部结清，次年根据业务需要重新申请。

## 第五章 现金管理

**第十七条** 库存现金限额：公司库存现金不超过**10,000元**（壹万元整）。超过限额的现金应于当日存入银行。

**第十八条** 现金使用范围（依据《现金管理暂行条例》）：

1. 员工工资、津贴、奖金；
2. 个人劳务报酬；
3. 出差人员随身携带的差旅费；
4. 结算起点（1,000元）以下的零星支出；
5. 中国人民银行确定需要支付现金的其他支出。

**第十九条** 超过结算起点（1,000元）的支出，原则上应通过银行转账支付，不得使用现金。

**第二十条** 现金管理要求：

1. **日清月结**：出纳每日登记现金日记账，结出余额，与实际库存现金核对；
2. **不得坐支**：收到的现金应及时存入银行，不得直接用于支付（工资发放除外）；
3. **不得白条抵库**：任何未经审批的借据不得充当库存现金；
4. **保险柜管理**：库存现金存放于保险柜，钥匙由出纳保管，密码定期更换；
5. **不定期盘点**：财务主管每月至少进行一次现金突击盘点，编制《现金盘点表》。

**第二十一条** 现金盘点发现长短款的，应立即查明原因：

1. 短款：由责任人赔偿，无法确定责任人的由出纳承担；
2. 长款：查明原因后退还，无法查明原因的计入营业外收入。

## 第六章 票据管理

**第二十二条** 票据包括：支票（现金支票、转账支票）、银行汇票、银行本票等。

**第二十三条** 票据购买：空白票据由出纳向银行统一购买，财务部建立《票据登记簿》。

**第二十四条** 票据登记簿内容：

| 字段 | 说明 |
|------|------|
| 票据种类 | 支票/汇票/本票 |
| 票据号码 | 起止号码 |
| 购买日期 | — |
| 领用日期 | — |
| 领用人 | — |
| 用途 | — |
| 金额 | — |
| 状态 | 在用/已用/作废 |

**第二十五条** 票据签发要求：

1. 签发支票须有对应的付款审批手续；
2. 支票日期、金额、收款人名称不得更改，其他记载事项更改的须加盖预留印鉴；
3. 不得签发空头支票、远期支票；
4. 支票签发后应妥善保管，遗失应立即通知银行挂失。

**第二十六条** 作废票据处理：

1. 作废票据应加盖"作废"戳记；
2. 作废票据全套联次（存根联等）完整留存；
3. 作废票据纳入票据登记簿登记；
4. 作废票据定期装订归档，保存期限不少于五年。

## 第七章 资金安全管理

**第二十七条** 资金岗位分离：

| 不相容职务 | 分离要求 |
|-----------|---------|
| 出纳 vs 会计 | 出纳不得兼任稽核、会计档案保管、收入/支出/费用/债权债务账目登记 |
| 审批 vs 执行 | 审批人不得同时担任付款执行人 |
| 网银录入 vs 复核 | 不得为同一人 |

**第二十八条** 印鉴管理：

1. 财务专用章由财务主管保管；
2. 法人代表私章由总经理本人或其书面授权人保管；
3. 不得由同一人同时保管财务专用章和法人代表私章；
4. 使用印鉴须有审批手续，登记用印记录。

**第二十九条** 资金风险防控：

1. 严禁公款私存、私设小金库；
2. 严禁挪用资金、拆借资金；
3. 严禁未经审批对外担保；
4. 大额资金异动（单笔≥10万元）须总经理事先知晓并同意；
5. 发现资金异常（如不明扣款、余额异常等），应立即报告财务主管和总经理。

---

## 第八章 附则

**第三十条** 财务部应定期（至少每季度）向总经理报告资金状况，包括：

1. 银行存款余额及变动；
2. 现金库存情况；
3. 应收应付款项情况；
4. 资金风险预警。

**第三十一条** 违反本制度造成资金损失的，追究相关人员责任，情节严重的予以解除劳动合同并追究法律责任。

**第三十二条** 本制度未尽事宜，依照《现金管理暂行条例》《支付结算办法》及国家相关法规执行。

**第三十三条** 本制度由财务部负责解释和修订，经总经理批准后施行。
