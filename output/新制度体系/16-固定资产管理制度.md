## 第一章 总则

**第一条** 为规范公司固定资产管理，保障资产安全完整，提高资产使用效率，依据《企业会计准则》及相关法规，结合公司实际，制定本制度。

**第二条** 本制度适用于四川融策会计师事务所有限公司（以下简称"事务所"）和四川融策工程咨询有限公司（以下简称"工程公司"）的固定资产管理。

**第三条** 固定资产确认标准：

1. 单价在**2,000元（含）以上**；
2. 使用年限在**1年（含）以上**；
3. 在使用过程中保持原有实物形态。

不同时满足以上条件的，作为低值易耗品管理。

**第四条** 固定资产分类：

| 类别 | 折旧年限 | 残值率 | 典型资产 |
|------|---------|--------|---------|
| 电子设备 | 3年 | 5% | 电脑、打印机、投影仪、服务器 |
| 办公家具 | 5年 | 5% | 办公桌、椅子、文件柜、沙发 |
| 运输工具 | 4年 | 5% | 公务车辆 |
| 其他设备 | 5年 | 5% | 空调、饮水机等 |

## 第二章 采购与验收

**第五条** 固定资产采购实行分级审批：

| 审批层级 | 单件/批量金额 | 审批人 |
|---------|-------------|--------|
| 第一级 | ≤5,000元 | 部门负责人 |
| 第二级 | 5,000元＜金额≤20,000元 | 副总经理 |
| 第三级 | ＞20,000元 | 总经理 |

**第六条** 采购流程：

```
需求部门提交《固定资产采购申请》
  → 部门负责人审核（确认需求合理性）
  → 财务部审核（确认预算额度）
  → 相应层级审批
  → 综合管理部统一采购（或授权需求部门采购）
  → 到货验收
  → 入库登记
```

**第七条** 年度固定资产采购纳入年度预算（参照 RC-FIN-003 预算管理制度）。计划外采购需单独审批并说明原因。

**第八条** 验收要求：

1. 验收人员不少于2人（使用部门1人+综合管理部1人）；
2. 验收内容：品名、规格、数量、质量是否与采购申请一致；
3. 验收合格后填写《固定资产验收单》；
4. 验收不合格的，及时联系供应商退换。

## 第三章 登记与标识

**第九条** 固定资产验收后，综合管理部应在5个工作日内完成以下登记：

1. **资产编号**：按统一规则编制资产编号

   编号规则：`公司代码-类别代码-年份-序号`
   
   示例：`RC-ED-2026-001`（融策-电子设备-2026年-第001号）

   类别代码：ED=电子设备 / OF=办公家具 / VH=运输工具 / OT=其他设备

2. **台账登记**：建立《固定资产台账》，记录以下信息：

   | 字段 | 说明 |
   |------|------|
   | 资产编号 | 唯一标识 |
   | 资产名称 | — |
   | 规格型号 | — |
   | 购置日期 | — |
   | 购置金额 | — |
   | 供应商 | — |
   | 使用部门 | — |
   | 使用人 | — |
   | 存放地点 | — |
   | 折旧方法 | 年限平均法 |
   | 折旧年限 | 按分类 |
   | 月折旧额 | — |
   | 累计折旧 | — |
   | 净值 | — |
   | 资产状态 | 在用/闲置/维修/报废 |

3. **资产标签**：制作资产标签粘贴于资产显著位置，标签内容包括：
   - 资产编号；
   - 资产名称；
   - 购置日期；
   - 使用部门。

**第十条** 财务部同步建立固定资产财务台账（卡片），用于财务核算和折旧计提。

**第十一条** 综合管理部和财务部每半年核对一次台账，确保账实相符、账账相符。

## 第四章 使用与维护

**第十二条** 固定资产实行"谁使用、谁保管、谁负责"的原则。使用人为资产保管第一责任人。

**第十三条** 资产领用：

1. 使用人填写《固定资产领用单》，经部门负责人批准后领用；
2. 综合管理部更新台账中的使用人信息；
3. 领用人签字确认。

**第十四条** 资产调拨：

1. 部门间调拨需双方部门负责人同意，综合管理部审批；
2. 综合管理部更新台账中的使用部门和存放地点；
3. 两公司间调拨需双方总经理同意。

**第十五条** 资产维修：

1. 日常维修（单次≤1,000元）：使用部门自行处理，费用报销（参照 RC-FIN-001）；
2. 较大维修（单次＞1,000元）：需综合管理部评估并报批。

**第十六条** 资产闲置管理：

1. 连续30天以上不使用的资产，使用部门应退回综合管理部；
2. 综合管理部负责闲置资产的保管和调配；
3. 闲置资产优先在公司内部调配使用。

## 第五章 折旧管理

**第十七条** 固定资产折旧采用**年限平均法（直线法）**：

```
月折旧额 = (原值 - 预计净残值) ÷ 折旧年限 ÷ 12
预计净残值 = 原值 × 残值率（5%）
```

**第十八条** 折旧计提规则：

1. 当月增加的固定资产，次月开始计提折旧；
2. 当月减少的固定资产，当月仍计提折旧，次月停止；
3. 已提足折旧仍继续使用的，不再计提；
4. 提前报废的，不补提折旧。

**第十九条** 财务部按月计提折旧，编制《固定资产折旧计算表》，作为费用入账依据。

## 第六章 盘点

**第二十条** 固定资产盘点分为全面盘点和不定期抽查：

### 全面盘点

| 项目 | 要求 |
|------|------|
| 频次 | 每年一次（12月） |
| 组织 | 综合管理部牵头，财务部配合 |
| 范围 | 全部固定资产 |
| 方法 | 逐一核对实物与台账（编号、名称、数量、状态、存放地点） |
| 输出 | 《固定资产盘点报告》 |

### 不定期抽查

| 项目 | 要求 |
|------|------|
| 频次 | 每半年至少一次 |
| 组织 | 财务部牵头 |
| 范围 | 随机抽取（不低于资产总数的20%） |
| 方法 | 账对实、实对账双向核对 |

**第二十一条** 盘点结果处理：

1. **盘盈**（有实物无台账）：查明原因，补办入库手续，按重置价值入账；
2. **盘亏**（有台账无实物）：查明原因，分清责任：
   - 使用人保管不善造成的，由使用人赔偿（按净值计算）；
   - 非人为原因造成的，经审批后核销；
3. **毁损**：查明原因，按报废流程处理。

**第二十二条** 盘点报告经综合管理部和财务部联合签署后，报总经理审批。

---

## 第七章 报废与处置

**第二十三条** 固定资产符合以下条件之一的，可申请报废：

1. 已达到使用年限且无法继续使用的；
2. 技术落后、能耗过高，无维修价值的；
3. 损坏严重，维修费用超过原值50%的；
4. 因其他原因确需报废的。

**第二十四条** 报废审批流程：

```
使用部门提交《固定资产报废申请表》
  → 综合管理部技术评估（确认是否具备报废条件）
  → 财务部核实资产净值
  → 审批：
      单件净值≤5,000元：副总经理审批
      单件净值＞5,000元：总经理审批
      批量报废（≥5件或总值≥5万元）：总经理审批
  → 报废处理
  → 账务核销
```

**第二十五条** 报废资产处置方式：

1. **变卖**：有残值的，通过询价比价后变卖，收入上缴公司；
2. **回收**：电子废弃物等交由专业回收机构处理；
3. **销毁**：涉及保密信息的设备（如电脑硬盘），须先进行数据清除后再处置。

**第二十六条** 账务核销：

1. 财务部根据审批后的报废申请，进行固定资产减少的账务处理；
2. 更新固定资产台账和财务台账；
3. 收回资产标签。

---

## 第八章 附则

**第二十七条** 低值易耗品管理：

1. 单价＜2,000元或使用年限＜1年的物品，作为低值易耗品；
2. 低值易耗品采用一次摊销法，领用时一次性计入费用；
3. 低值易耗品建立备查簿，定期盘点。

**第二十八条** 员工离职时，须办理固定资产归还手续。未归还的，按资产净值从离职结算中扣回。

**第二十九条** 因管理不善造成固定资产丢失、损坏的，追究相关人员责任。

**第三十条** 本制度未尽事宜，依照《企业会计准则》及国家相关法规执行。

**第三十一条** 本制度由综合管理部（实物管理）和财务部（价值管理）共同负责解释和修订，经总经理批准后施行。
