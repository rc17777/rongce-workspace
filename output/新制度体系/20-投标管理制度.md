# 四川融策投标管理制度

> **制度编号**：RC-BIZ-005  
> **版本**：V1.0  
> **编制日期**：2026年7月22日  
> **适用范围**：四川融策会计师事务所有限公司、四川融策工程咨询有限公司  
> **优先级**：P1  
> **关联制度**：RC-HR-002《绩效考核管理制度》（投标成功率纳入市场部门绩效考核）

## 第一章 总则

**第一条** 为规范公司投标管理，提高投标中标率，控制投标风险，保障公司合法权益，根据《中华人民共和国招标投标法》《中华人民共和国政府采购法》及相关法律法规，结合公司实际情况，制定本制度。

**第二条** 本制度适用于公司全部业务的投标活动，包括公开招标、邀请招标、竞争性磋商、竞争性谈判、询价等政府采购方式和自主投标。

**第三条** 投标管理基本原则：

1. **依法投标**：严格遵守招标投标相关法律法规，不围标、不串标
2. **审慎决策**：不做陪跑式无效投标，每个投标项目都经过理性评估
3. **质量优先**：标书编制规范、内容完整、数据准确、美观专业
4. **时效管控**：严格按招标文件时间节点推进，杜绝逾期
5. **闭环管理**：中标与未中标都要总结，形成经验积累

## 第二章 投标决策

**第四条** 投标项目须经过评估和决策程序后方可立项：

```
获取招标信息
  ↓
项目评估（市场部门+相关业务部门）
  ↓
填写《投标项目评估表》
  ↓
投标决策会议（重大/争议项目）
  ↓
立项（批准后启动投标工作）
```

**第五条** 投标评估至少包含以下维度：

| 评估维度 | 评估内容 |
|---------|---------|
| **项目匹配度** | 是否属于公司核心业务范围，公司资质是否满足 |
| **客户分析** | 客户性质/预算情况/既往合作/招标习惯/是否存在明显倾向性 |
| **竞争分析** | 预计参与竞标的对手情况/公司竞争优势和劣势 |
| **成本预估** | 投标费用（标书制作/差旅/保函）/中标后执行成本 |
| **中标概率** | 综合评估中标可能性（高/中/低） |
| **利润空间** | 预计毛利率是否达到公司最低标准 |
| **风险分析** | 保证金占用/围标串标风险/履约难度/收款风险 |

**第六条** 以下情形原则上不参与投标：
1. 公司资质不满足招标文件要求
2. 项目预计亏损或利润率低于公司最低标准
3. 有明显围标串标嫌疑或客户已有内定供应商的迹象
4. 保证金过高且无法筹措，或占用时间过长影响正常经营
5. 存在法律合规风险或潜在纠纷
6. 项目与公司战略方向明显不符

**第七条** 重大投标项目（预计合同金额≥100万元或政府重大专项）须召开投标决策会议，由市场部门组织，相关业务部门、财务负责人、分管副总参加，总经理主持。会议形成《投标决策会议纪要》，作为立项依据。

## 第三章 投标保证金管理

**第八条** 投标保证金按金额分级审批：

| 保证金金额 | 审批人 | 备注 |
|-----------|--------|------|
| ≤5万元 | 分管副总 | 常规额度 |
| 5~20万元 | 总经理 | 需说明资金筹措方案 |
| >20万元 | 总经理+股东会知悉 | 大额资金占用，须有书面申请 |

**第九条** 投标保证金筹措方式：
1. 公司自有资金
2. 银行投标保函（优先推荐，减少资金占用）
3. 其他合法合规方式

**第十条** 投标保证金退还追踪：市场部门负责跟踪保证金退还进度。中标项目保证金转为履约保证金的，做好台账登记；未中标项目，跟踪保证金退还进度，超期30天未退还的，向客户/招标代理机构发函催收。

**第十一条** 财务部门建立《投标保证金台账》，记录每笔保证金的缴纳时间、金额、招标项目、预计退还时间、实际退还时间。每月核对一次，防止遗漏。

## 第四章 标书编制

**第十二条** 标书编制流程：

```
市场部门牵头，组建投标小组
  ↓
研读招标文件，编制《投标文件编制分工表》
  ↓
各参与部门按分工编制标书内容
  ↓
技术负责人审核技术部分
  ↓
市场部门整合，编制完整标书
  ↓
分管副总审批
  ↓
打印装订/电子上传
```

**第十三条** 分工原则：
- **商务部分**（资质、业绩、人员、报价等）：市场部门负责
- **技术部分**（技术方案、实施方案、质量控制措施等）：相关业务部门负责
- **综合审核**：分管副总或技术负责人把关整体质量

**第十四条** 标书编制质量控制要点：
1. **响应完整**：逐条对照招标文件的全部要求，不得遗漏
2. **资质有效**：所有资质证书、人员证书、业绩证明均在有效期内
3. **报价合规**：严格按照招标文件要求的报价方式和格式进行
4. **格式规范**：严格按招标文件规定的格式、装订方式、密封要求
5. **签字盖章**：所有需要签字盖章的位置全部完成，不得缺漏
6. **时间无误**：投标截止时间、开标时间、保证金缴纳截止时间等关键节点准确

**第十五条** 技术负责人审核重点：
1. 技术方案是否具有针对性（不能是万能模板）
2. 人员配置是否合理、资历是否达标
3. 类似业绩是否充实、分类是否准确
4. 质量控制措施是否具体可行
5. 有无明显的技术漏洞或逻辑矛盾

## 第五章 投标时效管理

**第十六条** 每个投标项目须建立《投标时效管理表》，明确以下关键时间节点：

| 节点 | 说明 | 责任人 |
|------|------|--------|
| 招标文件获取截止 | 购买/下载标书的最后时间 | 市场部门 |
| 答疑/澄清截止 | 提交质疑函的最后时间 | 投标小组 |
| 投标保证金缴纳截止 | 保证金到账最后时间 | 财务部门 |
| 标书编制完成 | 内部审核通过时间 | 投标小组 |
| 投标文件递交截止 | 不可逾越的红线 | 市场部门 |
| 开标时间 | 需派人参加 | 市场部门 |
| 保证金预计退还时间 | 中标后退还或未中标退款 | 财务部门 |

**第十七条** 时效管理的"铁律"：
1. 投标截止前48小时完成标书终稿，预留足够时间检查和修订
2. 投标截止前24小时完成投标保证金缴纳
3. 投标截止前4小时完成文件打印装订或电子上传
4. 投标截止前2小时出发（现场投标），预留交通拥堵时间

**第十八条** 因时效问题导致废标的，责任人承担相应责任，按RC-QC-004《执业责任追究制度》相关条款处理。

## 第六章 中标与未中标管理

### 6.1 中标管理

**第十九条** 中标后5个工作日内，市场部门完成以下工作：
1. 将中标通知书复印件交业务部门、财务部门备案
2. 通知投标保证金/履约保证金转换事宜
3. 整理投标期间的关键资料和报价逻辑，移交项目执行团队

**第二十条** 中标后合同签订：
1. 项目执行团队按中标条件起草合同
2. 按照RC-BIZ-002《业务承接与合同管理制度》规定的审批流程签订合同
3. 合同签订后，启动项目管理流程，详见RC-BIZ-001《项目管理规范》

**第二十一条** 中标项目转执行时，市场部门须与项目执行团队进行"交底"，内容包括：
1. 投标承诺的服务内容、人员配置、时间节点
2. 报价构成和利润空间
3. 客户的关键诉求和关注点
4. 投标过程中的重要约定和承诺

### 6.2 未中标管理

**第二十二条** 未中标后，投标小组应在10个工作日内完成《未中标原因分析表》，内容包括：
1. 中标单位是谁，与公司相比的优势何在
2. 公司在价格、技术、业绩、人员等方面的差距
3. 是否存在非竞争因素（如客户倾向性、长期合作关系等）
4. 经验教训总结和改进建议

**第二十三条** 未中标原因分析由市场部门归档，作为投标能力提升和投标策略优化的基础资料。每季度汇总一次投标得失分析，在部门会议上讨论。

**第二十四条** 投标成功率（中标项目数÷投标项目数）纳入市场部门年度绩效考核指标，具体考核标准参见RC-HR-002《绩效考核管理制度》。

## 第七章 投标资料归档

**第二十五条** 每个投标项目结束后（无论中标与否），投标小组应在15个工作日内完成投标资料归档。

**第二十六条** 投标归档资料清单：

| 类别 | 归档资料 |
|------|---------|
| **招标文件** | 招标公告、招标文件、补遗/澄清文件 |
| **投标文件** | 最终版标书（含电子版和纸质版各1份） |
| **过程文件** | 投标评估表、决策会议纪要、审核意见 |
| **报价文件** | 报价明细表、成本测算表 |
| **结果文件** | 中标通知书（如有）、未中标通知、未中标原因分析表 |
| **财务文件** | 投标保证金缴纳凭证、退还凭证、购买标书/保函费用凭证 |

**第二十七条** 归档要求：
1. 每个投标项目一个独立档案，按年份+序号编号管理
2. 电子版存入公司共享文件夹/投标管理系统，纸质版按RC-ADM-005《档案管理制度》归档
3. 中标项目的投标文件与项目执行档案联动，便于项目执行团队查阅投标承诺

**第二十八条** 投标资料是公司重要的商业秘密，查阅须经市场部门负责人批准。
