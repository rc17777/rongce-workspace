# 定量问卷AI工具在审计业务中的集成应用指南

> 基于：《我把定量问卷流程写成了两个用研 Skill》(2026-07-19入库)
> 适用：融策会计师事务所全部12条业务线
> 两个Skill：①问卷设计（自动生成结构/题目/逻辑） ②问卷数据分析（清洗→交叉→显著性→可视化）

---

## 一、为什么审计需要标准化问卷？

传统审计中的问卷场景长期被忽视——要么随便写几个问题，要么套用别人模板不适用。后果：

- 绩效评价满意度调查 → 问题无结构化 → 数据无法横向对比
- 经责审计民主测评 → 问题暗示性强 → 结果失真有法律风险
- 专项资金政策知晓率 → 样本偏差 → 结论不可靠
- 监督检查问题收集 → 自由文本 → 汇总靠人工，耗时且遗漏

**两个用研Skill解决的核心问题**：把"拍脑袋写问卷"变成"按SOP生成标准化问卷+AI自动分析"。

## 三、实操Prompt模板（直接复制套用）

### 3.1 绩效评价 — 受益群体满意度调查

```
[角色] 你是政府绩效评价专家，擅长设计结构化满意度问卷。

[任务] 为以下绩效评价项目设计一份满意度调查问卷。

[项目背景]
- 项目名称：（例如：2024年度养老服务体系建设专项资金）
- 评价对象：（例如：XX区民政局）
- 受益群体：（例如：享受居家养老服务的65岁以上老年人及其家属）
- 资金规模：（例如：1200万元）
- 服务内容：（例如：上门助餐、助浴、助洁、健康监测）

[问卷要求]
- 题量：15-20题（含3道开放题）
- 结构：基本信息(≤3题) → 服务知晓度(2-3题) → 服务满意度(5-7题,含Likert量表) → 改进建议(2-3题) → 总体评价(1题)
- 题型：单选+多选+Likert 5级量表+开放题
- 语言：适合老年人或其家属阅读，避免专业术语
- 逻辑跳转：未使用过某项服务的跳过该服务评价

[输出格式]
1. 完整问卷（含引导语、题干、选项、跳转逻辑）
2. 问卷发放说明（发放渠道、样本量建议、注意事项）
```

### 3.2 经济责任审计 — 民主测评问卷

```
[角色] 你是经济责任审计专家，精通领导干部民主测评问卷设计。

[任务] 为被审计领导干部设计一份民主测评问卷。

[被审计对象]
- 职务：（例如：XX局局长）
- 任期：（例如：2021.01-2024.12）
- 分管领域：（例如：财务、人事、重点项目）
- 下属单位数：（例如：5个科室、3个下属事业单位）

[问卷要求]
- 题量：12-18题
- 结构：基本信息(≤2题) → 履职业绩评价(4-6题) → 廉洁自律评价(2-3题) → 决策规范性评价(2-3题) → 综合评价(1题)
- 题型：Likert 5级量表 + 单选 + 开放题
- 匿名保证：卷首声明匿名原则和保密措施
- 禁止：暗示性问题、诱导性选项、可追溯身份的题项

[输出格式]
1. 完整问卷（含匿名声明、引导语、题干、选项）
2. 发放操作指南（匿名方式、回收流程、密封要求）
```

### 3.3 专项资金审计 — 资金使用效益调研

```
[角色] 你是专项资金绩效审计专家。

[任务] 为以下专项资金项目设计受益人调研问卷。

[项目背景]
- 专项资金名称：（例如：2024年营养改善计划专项资金）
- 资金规模：（例如：800万元）
- 受益群体：（例如：农村义务教育阶段学生及其家长）
- 实施单位：（例如：XX县教育局及下辖12所学校）
- 使用方向：（例如：食堂改造、食材采购、营养配餐）

[问卷要求]
- 题量：15-20题
- 结构：知情度(2题) → 使用体验(5-7题) → 效果感知(3-4题) → 改进建议(2-3题) → 开放意见(1-2题)
- 题型：单选+多选+Likert量表+开放题
- 区分度：能区分不同学校、不同年级的差异

[输出格式]
1. 完整问卷
2. 分层抽样方案（按学校规模/地理位置/年级）
3. 数据采集方式建议（纸质/线上/电话）
```

### 3.4 监督检查 — 结构化问题收集表

```
[角色] 你是财政监督检查专家。

[任务] 为批量向被检查单位收集信息设计结构化问题表。

[检查背景]
- 检查类型：（例如：财政资金安全专项检查）
- 涉及单位数：（例如：35家预算单位）
- 检查重点：（例如：资金存放、账户管理、大额支出审批）
- 检查期间：（例如：2024年度）

[问卷要求]
- 题量：20-30题
- 结构：按检查要点分组，每组3-5题
- 题型：以"是/否/不适用"为主 + 金额填空 + 文件编号填写
- 每条问题附法规依据
- 回复必须附证明材料编号

[输出格式]
1. 结构化问题表（问题→选项→法规依据→证明材料要求）
2. 填报说明（截止时间、材料提交方式、常见问题解答）
```

## 四、数据分析Prompt模板

### 4.1 通用交叉分析

```
[任务] 对以下问卷数据按指定维度进行交叉分析。

[数据] （粘贴清洗后的问卷数据CSV）

[交叉维度]
- 主要维度：（例如：按服务类型/按地区/按受益群体年龄段）
- 核心指标：各维度满意度均分、标准差、差异显著性

[输出要求]
1. 各维度描述性统计（均值/中位数/标准差/分布）
2. 组间差异显著性检验（p值）
3. 关键发现（≥3条，附数据支撑）
4. 可视化建议（推荐图表类型及维度选择）
```

### 4.2 经责审计民主测评分析

```
[任务] 对民主测评数据进行专业审计分析。

[数据] （粘贴匿名测评数据）

[分析维度]
- 按评价对象：不同分管领域的评价差异
- 按评价人：不同层级（中层/基层）的评价差异
- 按时间：如有多年度数据，分析变化趋势

[输出要求]
1. 综合评价得分汇总表
2. 弱项指标排序（得分最低的3项，附原始数据）
3. 评价一致性分析（高离散度题项→可能存在的争议领域）
4. 审计应关注的风险信号（低于3分的题项、异常分布的题项）
```

## 五、与传统方式对比

| 维度 | 传统做法 | AI问卷Skill |
|:--|:--|:--|
| 问卷设计时间 | 2-4小时/份（从零写） | 2分钟（粘贴项目背景→生成完整问卷） |
| 结构化程度 | 依赖个人经验，质量波动大 | SOP化输出，标准差小 |
| 逻辑跳转 | 手工设计，易遗漏 | 自动生成，覆盖完整 |
| 数据分析 | Excel手工透视，2-4小时 | AI自动清洗+分析+可视化，5分钟 |
| 显著性检验 | 多数人不会做 | 自动完成 |
| 结论可靠性 | 抽样无依据、统计不规范 | 有抽样方案+显著性支撑 |

## 七、质量红线

| 场景 | 红线 | 说明 |
|:--|:--|:--|
| 所有问卷 | 问题不得有暗示性 | "您是否满意XX部门的优质服务" → 违规（预设了"优质"） |
| 经责审计 | 必须匿名 | 可追溯回答者身份的题项（如工号>3位）必须删除 |
| 绩效评价 | 样本量≥30 | n<30不做统计推断，仅做描述性统计 |
| 资金审计 | 受益人与非受益人分层 | 不能只抽受益人，需对照抽样 |
| 所有场景 | 问卷作为间接证据 | 不单独用于关键定性，需与其他证据交叉验证 |
| 所有场景 | AI生成后人工审核 | AI生成的题目必须经业务人员审核：无歧义/无不适用/无逻辑漏洞 |
