# 广元市2025年度政府采购违法违规典型案例通报

> 来源：四川政府采购网 / 广元市财政局
> 发布时间：2025-12-31
> 入库日期：2026-07-09

---

为进一步规范政府采购行为，充分发挥典型案例的警示教育作用，有效遏制政府采购领域违法违规行为，现将广元市财政部门查处的2025年度政府采购领域部分违法违规典型案例予以通报。

---

## 案例一：串通投标案 — 陪标+授权代表混同 🔴🔴🔴

**项目**：广元市某单位新生儿高频呼吸机等一批医疗设备采购项目（2024年8月）

**事实**：成都A科技有限公司通过：
1. 让成都B科技有限公司「陪标」
2. 与B公司商定让B公司放弃中标
3. **B公司的授权代表为A公司员工** ⚡
4. **B公司放弃中标的资料均由A公司员工编制和递交** ⚡

**处罚**：A公司罚款4250元 + 没收违法所得20407.4元；B公司罚款4250元

### 🔍 审计逻辑分析

| 检测层级 | 信号 | 审计操作 |
|:--|:--|:--|
| **L8 工商关联穿透** | 授权代表混同 — B公司授权代表= A公司员工 | 调取投标文件中授权代表身份证号 → 比对社保缴纳单位 |
| **L11 伴随投标** | 放弃中标资料由竞争对手编制 → 必有历史绑定 | 查3年投标记录，看A/B是否频繁同场且B总是弃标/陪跑 |
| **L15 中标/陪标专业户** | B公司长期充当A公司陪标角色 | FP-growth分析A-B伴随模式 |

> **核心审计方法**：授权代表身份核查是串标检测的高效手段。调取授权代表的社保记录，若社保缴纳单位为另一方，直接构成串标铁证。这在L5元数据检测之外，是「人的维度」的突破口。

## 案例二：串通投标案 — 投标文件统一制作 🔴🔴

**项目**：广元市某单位更新公务用车采购项目（2025年10月）

**事实**：某汽车销售公司让某汽车贸易公司「陪标」，**投标文件统一由某汽车销售公司编制和上传**

**处罚**：两家各罚款1850元

### 🔍 审计逻辑分析

| 检测层级 | 信号 | 审计操作 |
|:--|:--|:--|
| **L2 IP/MAC** | 统一上传 → IP/MAC必然相同 | 调取代理后台上传日志 |
| **L3 TF-IDF** | 统一编制 → 两文件高度雷同 | 投标文件全文TF-IDF相似度分析 |
| **L5 元数据** | 同一人/同一电脑编制 | docx core.xml 检查创建者/修改者 |

> **注意**：罚款仅1850元，违法成本极低。审计发现问题后的移送价值远大于罚款本身——低价处罚反而说明监管部门查得「不够狠」，审计介入可以推动升级处理。

## 案例三：串通投标案 — 三家围标 🔴

**项目**：广元市利州区某单位临聘人员安全标志服采购项目（2021年8月）

**事实**：广元某服饰公司 + 绵阳某服装公司 + 四川某服饰公司，三家公司为谋求广元某服饰公司中标，相互恶意串通

**处罚**：主谋罚款3260元，陪标方各罚款1630元

### 🔍 审计逻辑分析

三家公司围标是典型的 **L15 中标专业户 + L11 FP-growth 伴随模式** 的组合检测场景：
- 三家公司横跨广元/绵阳/四川三地，地理分散是伪装
- 真正的关联需要穿透法人/股东/高管/地址/联系方式

## 案例四：差别歧视待遇 + 评审倾向性 🟡🔴

**项目**：旺苍县2024年度扶持发展新型农村集体经济项目（2024年10月）

**事实**：四川某招标代理有限公司：
1. 采购文件中设定**不合理资格条件**（差别歧视）
2. 在评审过程中对评审专家作**倾向性、误导性解释**，导致4家供应商资格审查未通过

**处罚**：警告

### 🔍 审计逻辑分析

| 检测维度 | 信号 | 审计操作 |
|:--|:--|:--|
| 采购文件审查 | 资格条件设置不合理 | 逐条检查资格条件与项目需求的关联性 |
| **L10 评标倾向性照顾** | 代理机构对专家作倾向性解释 → 4家被排除 | 调取评审现场监控/录音 | 
| 资格审查一致性 | 同一天评审，突然4家不通过 | 比对各供应商资格审查不通过的理由是否一致 |

> ⚠️ 仅处「警告」—— 这恰恰是审计需要深挖的地方。4家供应商被排除在外，中标方是谁？排除后是否只有特定供应商能满足条件？

## 案例五：规避政府采购案 🟡

**项目**：苍溪县某单位精神病残疾人寄宿托养服务（2022-2024年）

**事实**：未通过公开政府采购程序，**直接指定**某中心作为唯一承接机构，持续3年

**处罚**：警告

### 🔍 审计逻辑分析

- 连续3年直接指定 → 检查是否通过拆分金额规避招标门槛
- 核查该中心与采购单位是否存在人员/资金/利益关联
- 同类服务是否只有该中心一家能提供（单一来源采购的适用条件）

## 案例六：提供虚假材料案 🔴

**项目**：旺苍县2024年度扶持发展新型农村集体经济项目（2024年11月）

**事实**：广元某农机公司使用了第三方公司提供的**虚假信息**进行响应，且未核实真实性

**处罚**：罚款6230元

### 🔍 审计逻辑分析

- 「未尽审慎审查义务」≠ 主观故意——这是供应商常用的抗辩理由
- 审计应检查：第三方信息是否可公开验证 → 若可验证而未验证，推定主观放任

## 案例七/八：拒绝签订合同案

**案例七**：四川某科技公司主动放弃成交资格（罚款3940元）
**案例八**：四川某商贸公司因供货厂商漏报价格放弃（罚款3850元 + 不良记录 + 1年禁入）

### 🔍 审计逻辑分析

- 放弃中标 → 第二名递补 → 是否存在第一第二套利模式？
- 检查中标价格与第二名价格差 → 价差大可能是「战略性弃标」

---

## 案例九：违规收取代理服务费案

**项目**：广元市某学校学生床、桌凳等设备采购项目

**事实**：应收代理费36877.68元，实收44833元，**多收7955.32元**

**处罚**：限期整改+退还

### 🔍 审计逻辑分析

与四川省财政厅通报案例二（多收7956元）几乎是镜像案例，说明代理费超标收费是**普遍现象**。审计时可以按项目逐个计算应收费vs实收费，批量筛查。

## 广元案例总体审计逻辑框架

```
采购项目 → 
  ├─ 投标环节 → 授权代表社保核查 → 串标（案例一）
  ├─ 投标环节 → IP/MAC/TF-IDF → 串标（案例二、三）
  ├─ 采购文件 → 资格条件合理性 → 差别歧视（案例四）
  ├─ 评审环节 → 代理机构倾向性解释 → L10评标异常（案例四）
  ├─ 采购程序 → 是否规避公开招标 → 程序违规（案例五）
  ├─ 资质文件 → 第三方信息真实性核验 → 虚假材料（案例六）
  ├─ 定标环节 → 弃标+递补价格差分析 → 套利嫌疑（案例七/八）
  └─ 财务核算 → 代理费标准vs实收 → 乱收费（案例九）
```
