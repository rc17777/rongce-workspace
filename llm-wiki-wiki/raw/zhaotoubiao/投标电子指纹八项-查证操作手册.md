# 投标电子指纹八项：查证操作手册

> 来源：公众号「牛马混职场」| 入库：2026-07-19
> 适用：招投标审计、政府采购审计、工程招标合规检查
> 关联：`procurement-audit-models` L18层 | `融策电子招投标审计SOP-v1.0.md`
>
> ⚠️ 本文档提供每项指纹的 Windows 原生查看命令（无需第三方软件），用于审计现场快速取证。

---

## 总览

| # | 指纹类型 | 可变性 | 查看方式 | 铁证等级 |
|:--:|:--|:--|:--|:--:|
| 1 | IP地址 | 可更换（切热点/宽带） | 浏览器搜索"IP" + ipconfig | 🟡 |
| 2 | MAC地址 | 换网卡才变 | `ipconfig /all` | 🔴 |
| 3 | CPU ID | 永久不变 | `wmic cpu get processorid` | 🔴 |
| 4 | 硬盘序列号 | 永久不变 | `wmic diskdrive get serialnumber` | 🔴 |
| 5 | 主板序列号 | 永久不变 | `wmic baseboard get serialnumber` | 🔴 |
| 6 | 整机机器码 | 平台绑定生成 | 投标客户端→设备信息 | 🔴 |
| 7 | 文件GUID | 复制即携带 | 专业工具/记事本打开XML | 🔴 |
| 8 | 图片哈希 | AI比对 | 监管系统自动比对 | 🔴 |

> **核心判断逻辑**：3-6项任一中2项以上重合 = 同一制作终端 = 串标铁证。
> **最优先比对项**：整机机器码（第6项），监管系统默认第一比对项，一致可直接定性。

## 逐项详查

### 一、IP地址

**留痕位置**：交易平台操作日志（报名/下载招标文件/上传投标文件/CA解密全流程均记录公网IP）

| 查看方法 | 命令/操作 | 显示内容 |
|:--|:--|:--|
| 公网IP | 浏览器搜索"IP" | 对外出口IP |
| 内网IP | Win+R → cmd → `ipconfig` | IPv4地址（局域网IP） |

**审计注意**：IP可更换（换WiFi/手机热点），仅IP相同不能定案，但配合MAC等硬件指纹可闭环。

---

### 二、MAC地址（物理网卡地址）

**留痕位置**：平台上传日志、客户端设备采集日志（上传标书时自动读取网卡MAC上传后台）

```
Win+R → cmd → ipconfig /all
找到「物理地址」：XX-XX-XX-XX-XX-XX（12位十六进制）
```

- 有线网卡和无线网卡各有独立MAC
- 换宽带/换IP无法改变MAC，需更换网卡硬件

---

### 三、CPU序列号（CPU ID）

**留痕位置**：投标客户端、造价软件、标书加密包底层XML文件（制作标书时自动写入，永久留存）

```
Win+R → cmd → wmic cpu get processorid
```

- 每颗处理器全球唯一，终身不变
- 不受系统重装、换硬盘、换网络影响
- 即使换电脑，只要CPU没换，CPU ID就不变

---

### 四、硬盘序列号（SSD/HDD SN）

**留痕位置**：标书制作日志、计价XML元数据、投标客户端设备采集记录

```
Win+R → cmd → wmic diskdrive get serialnumber
```

- 内置硬盘、外接U盘、移动硬盘各有独立序列号
- 插入U盘可同步读取U盘序列号
- 注意：多台电脑共用同一U盘制作标书 → SN一致 → 同源判定

---

### 五、主板序列号

**留痕位置**：电子投标客户端设备指纹库、标书打包底层参数

```
Win+R → cmd → wmic baseboard get serialnumber
```

- 更换CPU、硬盘、网卡、系统均不改变
- 主板序列号 + CPU ID + 硬盘SN → 任中2项重合即可锁定同一制作终端
- 三项全中 = 100%同一台电脑 → 证据链闭环

---

### 六、整机文件制作机器码（⭐ 监管第一比对项）

**生成机制**：招投标平台/造价软件自动聚合 `CPU ID + 硬盘SN + 主板信息 + 设备特征` 生成专属机器码

**查看方式**（无系统命令，须通过投标客户端）：
1. 打开【新点/广联达/各地公共资源投标客户端】→ 系统设置 → 设备信息
2. 标书导出文件夹 → 设备日志/打包日志文件
3. 开标后 → 监管后台/交易平台后台直接抓取比对

> **监管优先比对此项**：不同投标人机器码一致 = 100%认定同一终端制作 = 无需其他佐证 = 可直接定性视同串标。

---

### 七、文件创建GUID / 创建标识码

**留痕位置**：所有投标文件底层二进制数据、XML清单、文档元数据（永久留存、不可清除）

**查看方式**（普通电脑无法直接可视化查看）：
1. 专业工具：解析Word/Excel/PDF底层元数据
2. 造价XML清单文件 → 记事本打开 → 检索 `GUID` 字段
3. 招投标监管系统后台自动抓取比对

**关键特性**：
- 修改文件名、另存为、删除内容、修改排版 → GUID不变
- 多份标书GUID一致 = 全部由同一源头文件复制修改而来
- 属于文件同源串标铁证

---

### 八、图片哈希特征码

**留痕位置**：标书内嵌图片底层数据（平台自动批量哈希比对、全网检索）

**AI抗干扰能力**：以下操作无效，AI仍能匹配原始哈希 →
- 裁剪图片
- 缩放尺寸
- 调整亮度/对比度
- 加水印
- 压缩大小
- 改格式（PNG→JPG）

> 多家标书出现大量同源图片哈希 → 直接判定素材共用、标书同源。

## 审计现场快速取证流程

### 被审计单位电脑检查清单

```
□ 1. ipconfig /all           → 记录MAC地址
□ 2. wmic cpu get processorid → 记录CPU ID
□ 3. wmic diskdrive get serialnumber → 记录硬盘SN
□ 4. wmic baseboard get serialnumber → 记录主板SN
□ 5. 截图保存（含时间戳）
```

### 投标文件电子痕迹取证清单

```
□ 1. 交易平台登录日志 → 提取IP地址
□ 2. 投标客户端设备信息页 → 提取机器码
□ 3. 标书文件 → 右键属性 → 详细信息 → 查看创建者/最后保存者
□ 4. 标书XML/元数据 → 提取GUID
□ 5. 标书内嵌图片 → 导出 → 记录文件名和数量
```
