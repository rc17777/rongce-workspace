为进一步规范政府采购行为，营造健康有序的政府采购市场秩序，现将全市查处的政府采购违法典型案例予以通报。

## 违法情形一：以不合理条件实行差别歧视 🟡

### 案例1：分包资质前置条款
**项目**：2021年X射线血液辐照仪及同位素辐照仪退役处置服务
**当事人**：巴中市中心血站 + 四川深启工程项目咨询有限公司
**事实**：采购文件要求「承诺将此项分包给有资质的单位，并在**签订合同前**提供分包商的以上证书复印件」作为**实质性条款**
**处罚**：警告（2023年1月）

### 🔍 审计逻辑
- 「签订合同前」提供分包商证书 → 变相排除没有现成分包商的供应商
- 法律规定：分包商资质应在**履约阶段**提供，而非投标阶段
- 审计检查：采购文件是否将履约阶段义务前置为投标资格条件

## 违法情形二：提供虚假材料谋取中标 🔴🔴

### 案例1：体系认证证书造假 ⚡
**项目**：巴中市中心医院南坝院区静脉用药调配中心装修（第四次）（2023年）
**当事人**：四川君诚绿建机电安装工程有限公司
**事实**：提供的**质量体系、环境管理体系和职业健康安全管理体系认证证书**有效性与实际不符
**处罚**：罚款2.44万元

### 🔍 审计逻辑 — 体系认证证书核验SOP
```
Step 1: 提取证书编号 + 认证机构名称
Step 2: 登录「全国认证认可信息公共服务平台」(cx.cnca.cn) 
Step 3: 输入证书编号 → 核查：
        - 获证组织名称是否与投标人一致
        - 证书状态（有效/暂停/撤销/注销）
        - 认证范围是否覆盖投标内容
Step 4: 三体系证书全部造假 → 恶意程度高，不仅是「未尽审慎义务」
```

### 案例2：产品检测报告造假
**项目**：巴州区环卫工人劳保采购（2023年）
**当事人**：中盾安全设备（成都）有限公司
**事实**：部分产品检测报告与实际不符
**处罚**：罚款2450元

### 案例3：肥料登记证造假 ⚡ 农业类采购典型
**项目**：南江县2022年高标准农田建设项目生物有机肥采购（2023年）
**当事人**：哈尔滨中上科技有限公司
**事实**：提供的肥料登记证上**有效菌种名称与实际不符**
**处罚**：罚款7192元 + 不良记录 + **2年内禁入**

### 🔍 审计逻辑
- 肥料登记证核验：农业农村部「肥料登记管理系统」
- **菌种名称不符**是农业类采购的典型造假手法——用已登记的菌种编号套用在未登记的菌种上
- 跨省供应商（哈尔滨→四川南江）→ 检查是否有本地代理商/中间人
- 2年禁入比通常的1年更重 → 说明情节恶劣

### 案例4：信用承诺函造假
**项目**：平昌县2021年电子商务进农村综合示范（第二包）（2023年）
**当事人**：平昌县东城物流有限公司
**事实**：提供的承诺函和**信用中国统计严重失信企业名单**与实际不符
**处罚**：罚款1.5万元

### 🔍 审计逻辑
- 信用中国核验极为简单（公开查询），虚假承诺被查出 → 说明该企业要么疏忽大意，要么故意隐瞒
- 审计操作：对中标供应商统一进行「信用中国」批量查询 → 交叉比对投标文件中的承诺函

## 巴中2023第一批审计框架

```
4类虚假材料 →
  ├─ 体系认证证书造假 → 全国认证认可平台核验 ⚡
  ├─ 产品检测报告造假 → 发证检测机构回函核实
  ├─ 肥料登记证菌种名不符 → 农业农村部肥料登记系统 ⚡
  └─ 信用中国承诺造假 → 信用中国公开查询
```
