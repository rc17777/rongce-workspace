## 违法情形一：提供虚假材料谋取中标、成交 🔴

### 案例1：虚假劳保产品响应
**项目**：巴州区环卫工人劳保采购（N5119022024000043）
**当事人**：四川美洲环境营造有限公司
**处罚**：罚款2000元（采购金额5‰）+ 不良记录 + 1年禁入

### 案例2：虚假材料谋取中标
**项目**：通江县中医医院应急备用电源采购（N5119212023000148）
**当事人**：四川龙邦机电设备有限公司
**处罚**：罚款1840元 + 不良记录 + 1年禁入

### 🔍 审计逻辑
| 切入点 | 方法 |
|:--|:--|
| 产品检测报告真实性 | 向出具报告的检测机构发函核实 |
| 资质证书有效期 | 在发证机构官网核验证书编号 |
| 批量筛查 | 同一供应商在多个项目中提供的同一类证书是否一致 |

## 违法情形二：中标后无正当理由拒不签订合同 🟡

### 案例1：拒签考场建设合同
**项目**：巴中市高级中学学校高清标准化考场建设项目
**当事人**：四川顺意诚德建设工程有限公司
**处罚**：罚款11667元（5‰）+ 不良信用 + 1年禁入

### 案例2：拒签执法车辆合同
**项目**：通江县公安局执法执勤车辆采购（N5119212024000086）
**当事人**：巴中圣达汽车销售服务有限责任公司
**处罚**：罚款4800元 + 不良记录 + 1年禁入

### 🔍 审计逻辑
- 弃标后谁递补中标？递补方价格与原中标方价格差多大？
- 弃标方与递补方之间是否存在关联关系？
- 「战略性弃标」模式：恶意低价中标 → 弃标 → 第二名高价递补

## 违法情形三：以不合理条件实行差别歧视 🟡

### 案例1：采购文件设置不合理条件
**项目**：2021年「你点我检」专项抽检采购（5119012021000245）
**当事人**：四川深启工程项目咨询有限公司（代理机构）
**处罚**：警告

### 案例2：以特定行业奖项作为加分条件
**项目**：平昌县2022年水稻玉米病虫害防治公共服务
**当事人**：平昌县农业农村局 + 四川恒嘉工程咨询有限公司
**处罚**：警告

### 🔍 审计逻辑
- 「特定行业奖项加分」是最常见的歧视性条款之一
- 审计批量筛查方法：提取所有采购文件中的加分项 → 检查是否指向特定行政区划/行业/品牌
- 新成立企业是否被排除在外（案例二中巴中2023第二批次也有同类问题）

## 违法情形五：未执行政府采购政策 🟡

### 案例1：未专门面向中小企业
**项目**：巴中莲山湖新区管理委员会宣传专题片制作（511902202100033）
**当事人**：巴中莲山湖新区管理委员会
**处罚**：警告

### 案例2：未明确中小企业发展政策
**项目**：红鱼洞水库及灌区工程竣工水土保持设施验收技术服务
**当事人**：巴中市红鱼洞水库运行保护中心 + 四川鑫浩招标代理有限公司
**处罚**：警告

### 🔍 审计逻辑
- 专门面向中小企业采购是法定要求，审计重点：采购计划是否标注「专门面向中小企业」
- 代理机构编制采购文件时是否遗漏中小企业声明函模板
- 规模化项目是否按规定预留份额给中小企业

## 巴中2024汇总审计框架

```
5类违法情形 →
  ├─ 虚假材料（L5元数据+资质核验） → 检测报告/证书编号/官网核验
  ├─ 拒签合同 → 弃标→递补价差分析 → 关联关系排查
  ├─ 差别歧视 → 加分项审查 → 指向特定供应商筛查
  ├─ 未备案 → 采购计划与备案记录比对
  └─ 未执行中小企业政策 → 采购文件政策条款检查
```
