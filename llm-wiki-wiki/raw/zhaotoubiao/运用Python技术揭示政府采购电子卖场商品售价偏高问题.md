# 运用 Python 技术揭示政府采购电子卖场商品售价偏高问题
——以N省公共资源交易领域专项审计调查为例

●罗日鹏 袁佳龙

政府采购电子卖场是指由政府主导建设或授权运营，通过互联网信息技术建立的数字化交易平台。近年来，全国各级政府机关建设了形式多样的电子卖场，通过网上直购、竞价、网上询价等方式，为使用财政资金的国家机关、事业单位采购依法制定的集中采购目录内或集中采购目录外、分散采购限额标准以下的货物和服务提供商品。政府采购电子卖场在规范采购行为、提高采购效率等方面发挥重要作用的同时，也衍生出商品价格虚高、上架商品参数不规范等问题。本文以N省公共资源交易领域专项审计调查为例，介绍基于Python技术构建价格偏离度分析体系，通过采集电子卖场商品型号和售价，对同类商品售价进行跨平台比对分析，揭示电子卖场商品标价偏高、售价不透明、商品信息不规范等问题，旨在促进供应商规范商品信息发布，助力维护公平公正的营商环境。

## 一、审计背景

在N省公共资源交易领域专项审计调查中，由于电子卖场成交量较大，入驻供应商及采购人数量较多，审计组将其作为重点关注领域。审计抽查发现，电子卖场部分上架商品价格明显偏高，同型号商品跨平台售价差异过大，部分上架商品无具体参数，导致部分采购商品成本偏高，造成财政资金损失浪费。基于这一发现，审计人员坚持问题导向，通过Python技术开展关联分析，对电子卖场上架商品和其他电商平台同类型商品价格进行偏离度测评，精准定位价格偏离异常商品线索，快速锁定违规供应商及违规商品清单，形成可重复使用的审计技术方法，为同类审计工作提供参考依据。

## 二、审计思路与方法

借助Python技术构建自动化数据采集与价格比对体系，通过分类采集电子卖场商品信息，科学设定价格偏离阈值，设计智能价格监测程序进行跨平台比对，实现异常价格自动预警，客观判断上架商品价格是否在合理范围内，形成“数据采集—分层抽样—阈值设定—跨平台比对—结果核实”的全流程分析体系。

### （一）采集样本数据，确定比较对象

按照计算机设备、办公设备、生活用电器等不同品类分类，采集电子卖场上架商品信息，生成包含供应商名称、商品名称、商品型号、规格参数、销售价格、采集时间等字段的样本明细表作为核心样本数据。具体操作方法如下。

步骤1：安装requests、selenium数据采集库，pandas、openpyxl数据存储与处理库，BeautifulSoup4（简称“bs4”）、lxml网页解析库，regex非结构化数据处理库，time、random、fake_useragent等反爬虫控制库。根据本地浏览器（Chrome/Edge）版本下载对应WebDriver（ChromeDriver/EdgeDriver），将驱动文件放入Python安装目录的Scripts文件夹，配置系统环境变量，或通过executable_path直接指定驱动本地路径，屏蔽Selenium自动化特征，配置随机用户代理。

步骤2：以电子卖场网页端为数据源，通过Python脚本自动化抓取电子卖场不同品目商品信息。初始化浏览器实例并完成扫码登录后，通过By定位器定位平台分类导航栏，按预设商品品目依次进入对应页面。针对每类商品页，通过循环遍历分页按钮实现全量抓取，通过driver.find_elements获取当前页面所有商品详情页链接，调用bs4结合lxml解析网页源码，精准定位供应商名称、商品型号、规格参数、销售价格等核心标签，运用regex处理规格参数等非结构化数据。添加try-except Exception as e异常捕获机制，对缺失字段统一标注为“无”并记录异常日志，同时使用randomrandint(3,8)秒随机休眠时间，对页面元素定位添加WebDriverWait等待逻辑，控制爬取速度避免平台拦截。

步骤3：使用pandas库将采集到的商品数据整理成DataFrame结构化数据，对规格参数做标准化处理，提取品牌、核心配置等关键信息，将提取的各类商品字段与样本明细表所需字段一一对应、按行批量插入。按“商品名称+型号+标准化规格参数”精准去重，确保数据唯一，通过df.to_excel导生成“样本明细表”。

（二）设置价格偏离阈值，做好提取准备

抽样选择部分电子卖场商品，跨平台采集同类型商品价格，结合抽样结果和价格偏离分布规律科学确定价格偏离阈值，对超出阈值的商品进行预警并记录，通过比对电子卖场商品售价和其他平台同类型商品售价，判断上架商品价格是否在合理范围内。具体操作步骤如下。

步骤1：依托pandas库实现“品目+价格”双层分层随机抽样，确保抽样结果可复现、有代表性。剔除无型号参数的无效商品以及价格为0的异常数据。将每类商品按销售价格通过pd.qcut等频分为低、中、高3个层级，新增“价格层级”字段，在每个“商品品目+价格层级”组合中随机抽取30个样本，剔除无效数据，生成包含抽样编号、商品品目、标准化规格参数等核心字段的“抽样商品明细表”。

步骤2：跨平台采集抽样商品价格数据（以某大型电商平台为参考平台）。沿用前述Selenium浏览器配置，针对不同平台调整反爬策略，读取“抽样商品明细表”，将“商品名称+核心型号+关键规格参数”拼接为精准搜索关键词，使用Selenium启动浏览器访问目标电商平台，定位搜索框输入关键词，通过WebDriverWait(driver,15)等待页面加载完成，运用bs4结合lxml解析搜索结果页，通过标签特征过滤广告、二手商品，提取品牌旗舰店或自营店的商品标题和日常标价，严格剔除促销价、优惠价等非日常价格。对单一样品采集到的多家有效售价，剔除畸高、畸低异常价格后，使用np.mean计算均价作为该平台参考价，未查询到有效价格则记录为“无”，形成多平台价格参考依据。

步骤3：科学计算价格偏离指数并设定阈值。将电子卖场售价与跨平台参考价整合至同一DataFrame，新增“跨平台平均参考价”，将电子卖场售价与跨平台参考价整合至同一DataFrame，新增“跨平台平均参考价”，将电子卖场售价与跨平台参考价整合至同一DataFrame，新增“跨平台平均参考价”。以（电子卖场售价－跨平台平均参考价）/跨平台参考价×100%为核心公式计算偏离指数，同时添加非零判断避免错误。使用describe函数获取均值、中位数、标准差等统计指标，结合matplotlib绘制分布直方图，全面掌握价格偏离分布规律，科学设定偏离阈值，为后续全量商品监测提供判定标准。

（三）跨平台监测比对，关注价格偏离情况

以实现样本数据读取、跨平台价格查询、数据清洗比对、生成预警记录、结果导出为目的，开展全量商品价格偏离分析。通过pandas快速读取样本明细表，过滤无型号、无价格等无效商品，对“商品型号”做标准化处理，按照“商品品牌+标准化型号+核心规格参数”完全一致的规则精准匹配，将多个平台参考价格统一整合至DataFrame。严格过滤无效数据，剔除跨平台有效参考价低于3个的商品，批量计算剩余商品价格偏离指数，并与预设阈值比对，自动化标注无参考价、价格偏高、价格偏低三种预警状态，生成包含商品唯一编号、偏离指数、预警状态、偏高金额等字段的“价格监测偏离表”。同时通过df.groupby分组统计，计算各品目异常商品数量、占比及平均偏高比率。

（四）核实分析结果，精准揭示问题

通过pandas按“商品品目分层＋预警状态随机”的方式，抽取10个核心品目共100个商品作为人工核实样本。同时，对电子卖场商品非价格类问题进行自动化筛查，精准定位价格不透明、参数不全、无型号等问题商品，生成“商品信息不规范问题清单”。通过人工核实，发现标价偏高商品占比达86%，高于参考价平均比率约78%。如抽取的某型号碎纸机，其他平台有效价格分别为1868元、1788元和1600元，经剔除异常值后平均参考价为1752元，N省电子卖场标价6000元，偏离指数达2424.47%。同时，核实发现6个样本商品价格不透明，针对不同采购方售价不同，明码标价流于表面，65个样本商品存在参数不全、商品无主图等信息不规范问题。

## 三、审计成效

审计人员通过上述分析方法，对电子卖场商品价格进行动态追踪，实现了电子卖场商品数据的自动化、标准化采集，解决了数据量大、人工采集效率低导致的数据处理困难问题。审计进一步发现，电子卖场存在部分商品标价偏高、售价透明度不足、上架信息不规范等问题。相关情况形成审计专报，并获得主要领导的批示。通过督促审计整改，相关主管部门出台完善《政府采购电子卖场商品价格动态监测规则》等制度文件4项，建立常态化动态监测机制并同步开展专项整治工作。整顿中对违规供应商实施了失信记录、信用扣分、暂停交易等惩戒措施，同时对价格偏高商品采取了调整价格或下架处理。这些举措有效规范了电子卖场的运营秩序，促使供应商规范商品信息发布，维护了市场公平竞争环境，为优化营商环境注入新动能。
