为进一步规范政府采购行为，营造健康有序的政府采购市场秩序，现将全市查处的政府采购违法典型案例予以通报。

## 违法情形一：以不合理条件实行差别歧视 🟡

### 案例1：核心参数指向特定供应商
**项目**：巴中市疾病控制中心实验室检测能力建设/提升项目
**事实**：采购文件**核心参数指向特定供应商或特定产品**，并导致相关供应商中标
**处罚**：警告（2023年1月）

### 案例2：业绩加分排除新成立企业
**项目**：南江县2020年居家养老服务项目
**事实**：评分标准「2018年以来每提供一个类似项目的得5分，最多15分，**对新成立单位的得分要求并无规定**」→ 变相排除新成立企业
**处罚**：南江县民政局 + 四川文欣工程项目管理有限公司 → 警告（2023年3月）

### 🔍 审计逻辑
| 发现 | 分析 |
|:--|:--|
| 核心参数精确匹配特定产品 | 将采购文件技术参数逐一比对市场主流产品 → 只有一家满足 = 定向采购 |
| 业绩限制新企业 | 成立时间+业绩要求 → 计算有多少供应商实际上能满足 |
| 关联信号 | 中标方是否就是被「定向」的那家 → 进一步检查招投标全流程 |

## 违法情形二：供应商提供虚假材料 🔴🔴

### 案例3：注册建造师证书已注销 ⚡ 重点
**项目**：巴中市恩阳区团结、金鼓岩水库除险加固项目（2023年）
**当事人**：山水鸿建设工程（成都）有限公司
**事实**：提供的项目负责人唐某**注册建造师证书已注销**。证书号川2512020202119018，专业水利水电工程
**处罚**：罚款3000元 + **1年内禁入政府采购**

### 🔍 审计逻辑 — 建造师证书核验SOP
```
Step 1: 提取投标文件中所有建造师证书编号
Step 2: 登录「全国建筑市场监管公共服务平台」(jzsc.mohurd.gov.cn) 逐号查询
Step 3: 比对：姓名 / 注册单位 / 专业 / 有效期 / 状态
Step 4: 已注销/已过期/注册单位不一致 → 虚假材料
```

> ⚠️ 此案与住建部通报案例二（四川安岳虚假造价师证）形成交叉印证：**建造师/造价师证书造假是工程类政府采购的常见舞弊手段**。

### 案例4：交安证书与事实不符 ⚡
**项目**：巴州区江北街道凤头山村至黄家坝村撤并建制村畅通工程（2023年）
**当事人**：四川省武青公路建设工程有限公司 + 四川锟锐建设工程有限公司
**事实**：两家公司提供的**「川交安B」证书与事实不符**
**处罚**：各罚款7586.24元 + 不良记录 + 1年禁入

### 🔍 审计逻辑
- 「川交安B」= 四川省交通运输厅颁发的安全生产B证
- 核验渠道：四川省交通运输厅官网 → 安管人员查询系统
- 两家公司**同时**提供虚假交安证 → 检查是否为同一人制作/同一第三方代办机构提供

## 违法情形三：未按规定方式实施采购 🟡

### 案例5：擅自变更采购计划
**项目**：南江县2022年商品粮大县奖励资金支持粮食产业发展肥料采购（第二次）
**事实**：南江县农业农村局擅自变更采购计划，将其中**76万元项目交由部分乡镇自行采购**，未进行政府采购
**处罚**：南江县农业农村局 → 警告

### 🔍 审计逻辑
- 拆分金额规避政府采购 → 常见于基层单位
- 检查方法：同一单位同期同类采购 → 是否多笔小额 → 合计金额是否超招标限额
- 76万元不是小数目 → 乡镇自行采购是否走规范程序？供应商如何确定？

## 巴中2023第二批审计框架

```
5个案例 →
  ├─ 差别歧视 →
  │   ├─ 技术参数定向（案例1） → 参数-产品匹配分析
  │   └─ 业绩排除新企业（案例2） → 供应商资格覆盖面计算
  ├─ 虚假材料（L5交叉核验） →
  │   ├─ 建造师证书已注销（案例3）⭐ → 四库一平台逐号核验
  │   └─ 交安证书不符（案例4）⭐ → 交通厅安管系统核验
  └─ 程序违规 →
      └─ 拆分项目规避采购（案例5） → 同期同类合并口径筛查
```
