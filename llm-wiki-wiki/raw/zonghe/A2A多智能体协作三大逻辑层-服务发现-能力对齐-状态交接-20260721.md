# A2A多智能体协作三大逻辑层：服务发现→能力对齐→状态交接

> 微信公众号「审天审地审空气」转技术文 | 2026-07-21
> 原文：https://mp.weixin.qq.com/s/zf7tLp29CnDfyykXDHOk-Q

## 背景

企业级AI正从单模型推理向多智能体协同转变。千级Agent大规模协同场景中，Agent需要自主探寻协作者、精准理解彼此的能力边界、实现任务上下文无缝移交、在严格的权限约束下安全执行。

A2A通信协议已演变成面向**高可靠性、可审计、可治理**的分布式AI系统的"社交协议"。

## 一、服务发现（Service Discovery）

A2A通信的协作起点。在成百上千个Agent的系统中，不能硬编码目标地址。

- Agent A广播查询："谁能执行订单查询，且拥有数据访问权限？"
- 符合条件的Agent B自动响应并注册自身服务能力
- 需支持：动态注册与注销、健康检查、负载感知
- 实例：报表Agent借助中央服务注册中心（如Consul），检索`capability: sql_exe`且`scope: busidata_read`的在线Agent

## 二、能力对齐（Capability Alignment）

用契约杜绝大模型幻觉传染。

**问题：** 自然语言交流中语义漂移和幻觉放大——Agent A模糊说"查去年营收"，Agent B可能忽略分红统计或误读时间范围。

**解法：** 引入能力对齐层——
1. Agent A发起**元协商（Meta-Negotiation）**：询问输入Schema、输出JSON Schema、错误码定义、SLA承诺
2. Agent B返回标准化**契约（Contract）**
3. 双方签署契约后才进入正式数据交换
4. 所有请求在进入LLM推理前必须通过JSON Schema验证器

**价值：** 将模糊的自然语言沟通提升为具有确定性的机器合约，从根源抑制跨Agent链路中的语义熵增。

## 三、状态交接（State Handover）

A2A核心价值：复杂任务跨Agent连续执行。移交的不仅是原始数据，还包括：

1. **任务目标（Goal）** — 精确表述当前任务目标
2. **共识上下文** — 已达成的共识（如已确认排除某子公司数据）
3. **个性化记忆快照** — 如用户偏好饼图

状态通常序列化为嵌入向量与键值对的混合结构，由协调者（Orchestrator）统一管理版本与生命周期，避免因Agent重启导致上下文丢失。

## 四、协议对比

| 协议 | 定位 | 层级 |
|:----|:----|:----|
| A2A | Agent间脑脑协作 | 高层协作与交互 |
| MCP | 模型调用工具 | 脑控手层级 |

## 五、两种A2A组网模式

| 模式 | 特点 | 代表框架 |
|:----|:----|:----|
| 中心化调度 | 存在协调器Agent统一转发，开发简单、易管控 | AutoGen, CrewAI, LangGraph |
| 去中心化P2P | Agent直连互发消息，无中间节点 | WebSocket/gRPC自研 |

## 六、代码示例

### LangGraph（State消息总线）

用全局State状态字典作为A2A消息中间件，Agent通过读写State完成跨实体通信：

```python
from langgraph.graph import StateGraph, MessagesState
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, AIMessage

llm = ChatOpenAI(model="gpt-4o", api_key="your-key")

def data_agent(state: MessagesState):
    msg = llm.invoke([HumanMessage("计算月度营收汇总")])
    state["messages"].append(AIMessage(content=f"【A2A消息-数据结果】{msg.content}", name="DataAgent"))
    return state

def report_agent(state: MessagesState):
    a2a_msg = state["messages"][-1]
    res = llm.invoke([HumanMessage(f"基于这条数据生成报告：{a2a_msg.content}")])
    state["messages"].append(AIMessage(content=res.content, name="ReportAgent"))
    return state

graph = StateGraph(MessagesState)
graph.add_node("data_agent", data_agent)
graph.add_node("report_agent", report_agent)
graph.add_edge("data_agent", "report_agent")
graph.set_entry_point("data_agent")
workflow = graph.compile()
result = workflow.invoke({"messages": [HumanMessage("启动月度财务分析")]})
```

### OpenAI Agents SDK（原生A2A）

```python
from openai import OpenAI
from openai.agents import Agent, Runner

client = OpenAI(api_key="your-key")

math_agent = Agent(name="MathAgent", instructions="计算数学统计指标", model="gpt-4o")
main_agent = Agent(
    name="MainAgent",
    instructions="遇到数学计算任务，调用MathAgent获取结果",
    model="gpt-4o",
    tools=[math_agent.as_tool()]
)

result = Runner.run_sync(main_agent, "计算1-100总和")
print(result.final_output)
```

## 八、结论

深刻理解AI系统从单体模型优化向组织化协同的转变，意味着从Prompt工程师跃迁为系统架构师。决定职业发展上限的关键因素：是否有能力让Agent高效协同——目标一致、指令清晰、权责分明、安全可控。
