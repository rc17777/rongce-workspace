## 一、三案逻辑骨架：一条共同的破案公式

三案看似分散（运输、促销、产能），但底层逻辑高度一致，可提炼为一个核心公式：

```
造假检测 = 业务物理铁律（应然） - 账面数据呈现（实然） ≠ 0 → 异常信号
```

| 案例 | 物理铁律（应然） | 账面数据（实然） | 矛盾 |
|------|-----------------|-----------------|------|
| GPS案 | 货车到达城市之前，客户不可能签收 | 签收日期早于GPS进入日期 | 时空倒挂 |
| 饭卡案 | 真实员工必有日常生活痕迹 | 促销员从不在食堂吃饭/只跟经理同步出现 | 行为真空 |
| 电表案 | 产能翻倍→用电量必然大幅增长 | 产能翻倍，电费反降 | 物理反比 |

**三者共同的底层逻辑：造假者可以伪造单据、合同、发票，但无法伪造物理学定律和人类行为的基本规律。**

## 二、五步脑洞审计法（方法论提炼）

### 第一步：确定"不可伪造的锚点"

每一个审计领域，都至少存在一个**业务物理变量**，它是造假者无法/极难操控的：

| 行业/场景 | 不可伪造锚点 | 数据类型 |
|-----------|-------------|----------|
| 物流运输 | GPS轨迹、ETC通行记录、加油记录 | 时空数据 |
| 人员费用 | 饭卡/门禁/考勤/WiFi登录/企业微信活跃度 | 行为数据 |
| 制造业 | 电表/水表/原材料消耗/废料产出 | 物理投入产出 |
| 建筑工程 | 混凝土方量/钢筋用量/土方运输车次 | 工程量物理指标 |
| 软件开发 | Git提交记录/IP活跃地址/服务器CPU | 数字痕迹 |
| 零售/服务 | POS流水与客流计数/水电与营业时间 | 商流匹配 |

### 第二步：建立"应然-实然"对照模型

```
应然值 = f(物理变量₁, 物理变量₂, ..., 行业基准)
实然值 = 账面/报表数据
偏差率 = |应然值 - 实然值| / 应然值
```

- 偏差率 > 行业合理波动区间 → 高风险信号
