## 核心方法论：角色扮演 + 结构化模板

每组合提示词包含固定的六段结构：

```
你是一位「[专业角色]」与「[辅助角色]」。
制作一张 [海报类型]。
主画面：[视觉主体描述]
构图：[空间布局描述]
色调：[配色方案]
风格：[英文风格标签]
海报文字：「[主标语]」
副标：[英文副标题]
字体：[字体设计描述]
[技术参数]
```

## 方法论提炼：六段式提示词模板

```
你是一位「[主专业角色]」与「[辅助角色]」。
制作一张 [作品类型]。
主画面：[视觉主体·环境·氛围·光影]
构图：[空间排布·留白策略·视觉焦点]
色调：[主调·点缀色·滤镜质感]
风格：[中英双语风格关键词，含专业术语]
海报文字：「[情感金句]」
副标：[英文副标题/品牌名]
字体：[字体风格·排版策略·设计级别]
[分辨率·比例·质感标签]
```

### 关键技巧

1. **角色赋予权威感**：先给 AI 一个"你是XX总监"的身份，比直接描述效果更稳定
2. **中英混杂风格标签**：中文描述氛围，英文给精确设计术语
3. **固定六段结构**：主画面→构图→色调→风格→文字→字体，不缺不溢
4. **文字自带金句**：提示词里直接写好标语和副标，AI 会把排版也做了
