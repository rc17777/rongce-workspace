# 技术方法

## 运用 SQL 查询分析技术识别以工代赈项目虚假用工问题
### ——以X区农业农村局主要领导干部经济责任审计为例
- 黄岩

以工代赈是指政府或公共机构组织受困难影响的群体，参与有报酬的基础设施建设劳动，从而代替直接发放现金或物资的无偿救济方式。2025年，国家发展改革委联合多部门印发《以工代赈加力扩围促进重点群体就业增收行动方案》，明确以工代赈项目劳务报酬占中央对项目投入资金的比重由30%以上提高至40%以上，尽可能增加群众务工收入。以工代赈政策通过最大限度挖掘项目用工岗位规模，吸纳当地困难群众参与建设并获得报酬，充分发挥“赈”的实效，在推进乡村振兴进程中发挥了积极作用。在此过程中，确保群众用工真实性是保障政策精准落地的关键，如何快速、精准识别虚假用工方面的问题是审计应关注的重点。本文以X区农业农村局主要领导干部经济责任审计为例，介绍如何运用SQL查询分析技术，快速识别以工代赈项目中虚假用工的问题。

### 一、审计背景

近年来，各级资金持续投入乡村振兴领域。在X区农业农村局主要领导干部经济责任审计中，审计组将乡村振兴政策落实情况作为审计重点，以工代赈项目作为落实乡村振兴政策的重要手段，亦被纳入重点审计范围。结合以工代赈项目务工人群数量多、人员结构复杂、用工管理难度大等特征，审计组聚焦虚假用工问题，将虚设务工岗位、虚构劳务关系、虚报工时、违规发放劳务报酬等违规情形列为重点审计内容。审计人员收集了近三年以工代赈项目涉及的相关数据资料，充分运用SQL查询分析技术，将务工人员信息与困难群众信息、社保信息、村组干部信息等数据进行关联比对分析，筛选虚假务工疑点线索，最后通过走访调查锁定关键证据，有效提升工作质效。

### 二、审计思路及方法

#### （一）关注项目建设情况，揭示未吸纳困难群众或吸纳困难群众比例较低的问题

吸纳困难群众参与务工并获取报酬是以工代赈项目的核心目标。审计人员紧扣该目标要求，联系相关部门采集困难群众的家庭人员信息。考虑到困难群众人员信息处于动态调整状态，审计人员首先采集了近三年各月度的困难群众家庭人员信息并进行标准化整理，统一规范表格要素与格式，通过union all命令合并多期数据，运用distinct命令剔除重复信息，接着使用select从句及join……on命令，以身份证号码字段连接困难群众家庭成员信息表和务工人员信息表，最后用between……and命令，对参与务工日期与困难户确认日期进行比对，筛选以工代赈项目吸纳困难群众参与务工的情况，进而发现未吸纳困难群众参与以工代赈项目建设或吸纳困难群众比例较低的疑点线索。

#### （二）关注工作完成情况，揭示未完成相应工作内容的问题

据前期审计调查了解，X区A以工代赈项目建设周期短、部分建设内容专业性要求高，核心建设内容集中于农村饮水安全提质改造及污水管网升级工程，包含大量饮用水管、污水管开挖铺设、接口安装及管道焊接等工作任务。此类工作不仅对施工有严格要求，还需要作业人员掌握专业工具操作技能，而参与的务工人员大部分为当地农民，普遍缺乏专业技能，难以胜任此类专业性较强的工作任务。审计组根据务工人员和对应的工作任务清单，通过case……end等命令，将管道接口安装、管道焊接等专业性强的任务定义为“高专业性任务”，用else命令将其他任务定义为“普通性任务”，再用where命令将工作不匹配的务工人员信息疑点筛选出来，最后通过实地走访及电话沟通等方式了解疑点人员是否真实参加务工，核实是否存在伪造名册虚假务工的情况。

#### （三）关注劳务报酬发放情况，揭示企业在职人员务工的问题

以工代赈项目对劳务报酬比例有严格的要求。经研究发现，部分地区为达到劳务报酬比例要求，将建设项目原材料贷款混入劳务报酬进行支付。在X区B以工代赈项目中，存在大量采购混凝土、沙石等原材料的情况，经对供货企业人员情况进行比对分析，发现供货企业在职人员参与务工。为进一步查清问题，审计组联系相关部门采集了企业参保人员的相关信息，用join……on命令，将企业参保人员的社会保障号码与务工人员的身份证号码进行连接，再用between……and命令查询务工人员在务工期间仍然在企业正常参保的情况，最后用order by命令对劳务报酬金额进行排序，选取报酬领取多的人员为重点关注对象，进一步赴企业走访调研，将企业人员考勤信息与以工代赈劳务出工登记情况进行双向比对，分析是否存在虚构劳务关系，通过虚报以工代赈劳务费支付原材料货款的情况。

#### （四）关注群众身边“微腐败”问题，揭示村组干部及工作人员虚假务工的问题

在近年来开展的集中整治群众身边不正之风和腐败问题工作中，村组干部廉洁纪律执行情况被明确为重点关注内容。审计组结合以工代赈项目实际，重点对以工代赈项目所在村（社区）村组干部参与务工情况进行审查。一是核查村组干部及家属骗取劳务报酬的情况。根据组织部门及乡镇（街道）提供的村组干部家庭人员情况表，用in命令，筛选村组干部家庭人员中参与务工人员的信息，通过走访同一批次实际参与务工的人员，核查是否存在村组干部利用职务之便，未实际参与务工，通过虚构本人及亲属的劳务关系，骗取劳务报酬的情况。二是核查在村内承担卫生清扫、护林防火等职责的工作人员多头领取报酬补贴的情况。根据相关主管部门提供的村（社区）工作人员名册，用join……on命令，通过身份证号码字段进行关联，将工作人员名册与务工人员信息表进行连接比对，筛选以工代赈务工人员中兼任职村（社区）卫生清扫、护林防火等职责，违规多头领取报酬，或未实际参与务工却虚领补助的疑点线索。

#### （五）关注困难群众参与务工情况，揭示虚构特殊人群参与务工的问题

依据以工代赈政策要求，需优先吸纳困难群众参与务工。经调研了解，困难群众中不乏因病、因残导致就业受限的人员。此次审计重点关注这部分人员参与务工的异常情况，并同步分析高龄、低龄人群参与务工的异常情况。一是关注重度残疾人、大病保险报销人及死亡人员等特殊人群参与务工的情况。根据相关部门提供的残疾人、大病保险报销人及死亡人员数据，用join……on命令，通过身份证号码字段进行关联，将以上特殊人群与务工人员信息表进行连接比对。其中，残疾人疑点使用where及or的指令对残疾等级是“一级”或者“二级”的人员情况进行筛选；大病保险疑点通过between……and命令，将发生大病前后3个月出现务工的情况筛选出来进行核查；死亡人员疑点通过in命令，将死亡时间与务工时间进行对比分析筛选异常情况。二是关注高龄、低龄人群参与务工的情况。审计人员根据以工代赈务工人员名册信息，用substring命令，从身份证号码字段的第7位开始截取8个字段作为务工人群的出生日期，用datediff命令计算每个务工人员的年龄，再用“≥”或“≤”将年龄在70周岁以上及16周岁以下的务工人员疑点筛选出来，通过走访调查核实是否存在虚构用工名册的情况。

### 三、审计成效

审计人员运用SQL查询分析技术筛查出以工代赈项目中虚假用工的疑点线索，通过对施工单位、原材料供应商、务工人员的实地走访及调查了解，并追踪劳务报酬发放资金流向，发现部分资金发放至冒领人员银行账户后，短时间内又回流至项目实施单位，存在虚构劳务关系、虚设岗位、虚报劳务报酬等问题。对核查确认的问题，X区农业农村局会同发展改革、财政、乡镇（街道）等单位研究整改措施，依法依规进行整改。同时，审计提出了强化以工代赈项目前期论证与全流程管理，重点考虑适合困难群众参与务工的项目类型，杜绝盲目立项审批，已立项的项目优先吸纳困难群众参与务工，健全完善项目绩效评价体系，加大监督问责力度等建议；并建议相关主管部门加强协作，建立务工人员联合审查机制，及时排查不匹配务工、挂名务工等情况。推动规范乡村以工代赈用工人员管理，助力以工代赈政策更好落地见效。

（作者单位：云南省玉溪市江川区审计局）
