# DRG推诿重症患者检测

## 政策背景
DRG付费下，同一病组内支付标准固定，重症/复杂患者同价但消耗资源更多→医院有动机推诿（不收、转院、或要求自费）。这是DRG改革的核心弊端。

## 审计问题
医疗机构是否故意拒收或转出重症/复杂/高成本患者，以规避DRG亏损风险？

## 核心逻辑
推诿重症的三条路径：
1. **拒收**：急诊收入院申请被拒，患者转院
2. **分解转院**：收住院后快速转出到下级医院
3. **诱导自费**：告知"医保不报销"让患者自费治疗

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 急诊就诊记录 | 急诊登记+转归 | HIS急诊 |
| 急诊收入院率 | 急诊转住院占比 | 计算 |
| 转院记录 | 住院患者转院登记 | HIS |
| 住院天数 | DRG组内住院日 | 结算 |
| DRG权重(RW) | 病组权重 | DRG目录 |
| 病例组合指数(CMI) | 医院平均CMI | 计算 |
| 自费比例 | 自费金额/总费用 | 结算 |
| 30天内再入院 | 同一患者30天再入院记录 | 医保结算 |

## 检测逻辑

### 子模型1：急诊拒收检测

```
Step 1: 计算每家医院的 急诊收入院率 = 急诊转住院人次 / 急诊总人次
Step 2: 按医院级别对比：
  规则1: 某三甲医院急诊收入院率 < 同级均值-1个标准差 → 过度拒收
  规则2: 急诊中明确诊断"急性心肌梗死/脑卒中"但未收入院 → 直接标记
  规则3: 急诊诊断含"危重/抢救"但当天转出到其他医院 → 疑似推诿
```

### 子模型2：住院短期转院检测

```
Step 1: 筛选住院天数 < DRG组平均住院日50% 且 转归=转院的记录
Step 2: 规则：
  规则4: 住院<48h即转院 + 诊断为重病（高RW组）→ 高度疑似推诿
  规则5: 某院高RW组(>1.5)转院率 > 同级2倍 → 系统性推诿重症
  规则6: 转入医院为同级或更高级 → 可能是合理转诊、需排除
```

### 子模型3：CMI下降检测

```
Step 1: 追踪医院CMI变化趋势
Step 2: 规则：
  规则7: CMI同比持续下降(连续3月↓) + 住院人次不降 → 在挑轻不挑重
  规则8: 某院某DRG组内，患者平均费用逐年下降但同级上升 → 该组内推诿复杂患者
```

### 子模型4：诱导自费检测

```
Step 1: 分析自费比例异常
Step 2: 规则：
  规则9: 某院某高值耗材自费比例 > 90%，同期同级平均自费30% → 诱导自费
  规则10: 某住院记录中，医保不报销项目费用 > 总费用60% → 可能以"医保不报"为由收自费
```

## 阈值/参数
- 急诊收入院率 < 同级均值-1σ → P1
- 危重诊断未入院 → P0
- 高RW组转院率 > 同级2倍 → P1
- CMI连续3月↓ + 人次不降 → P1
- 耗材自费 > 90%且远超同级 → P1

## 典型发现
- 某三甲医院急诊收入院率8.2%（同级均值22%）→ 过度推诿，大量患者被迫转院
- 某院急性心梗急诊55例，仅11例收入院，其余全部转院 → 系统性推诿
- CMI从1.35降至1.08（一年），但住院人次反增15% → 典型"挑轻不挑重"

## 局限性
- 合理转诊与推诿的边界难以精确区分（三级→二级转诊可能是分级诊疗要求）
- CMI下降可能受收治病种结构变化、新科室开设等正常因素影响
- 急诊收入院率受急诊科规模、周边医院配置等外部因素影响
- 诱导自费的取证难度高——需患者证言配合才能确认

## 与分解住院的区别
- 推诿方向：向外→其他医院
- 分解住院方向：向内→同一患者短间隔重复入院
- 推诿证据：急诊拒收率+转院率+CMI下降三线交叉
