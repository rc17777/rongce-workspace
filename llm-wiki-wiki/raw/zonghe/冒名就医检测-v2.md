# 冒名就医检测

## 法规依据
- **735号令第40条**：诱导、协助他人冒名或虚假就医购药 → 骗保（退回+2-5倍罚款+暂停+解除协议）
- **法发〔2024〕6号第5条第1款**：诱导协助冒名就医 → 以诈骗罪定罪
- **法发〔2024〕6号第6条第2款**：使用他人医保凭证冒名就医 → 以诈骗罪定罪

## 审计问题
是否存在非参保人冒用他人医保凭证就医购药、套取医保基金？

## 核心逻辑
冒名就医必然在多个维度留下不一致痕迹。一个人的就医行为应与本人身份信息自洽——年龄/性别与诊断不符、多人在同一地点短时间内使用不同医保卡、同一社保卡在不同地点几乎同时结算。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 身份证号 | 就医人医保凭证号 | 医保结算 |
| 出生日期 | 从身份证号提取 | 计算 |
| 性别 | 从身份证号提取 | 计算 |
| 就诊日期 | 就医日期 | 结算 |
| 就诊时间 | 精确到时分秒 | HIS |
| 主要诊断 | ICD编码 | 结算 |
| 医院编码 | 就诊医院 | 结算 |
| 医院GPS | 医院地理坐标 | 外部数据 |

## 检测逻辑

### 子模型1：性别/年龄与诊断冲突

```
Step 1: 从身份证号提取性别（第17位奇男偶女）和年龄
Step 2: 标记冲突规则：
  规则1: 性别=男 AND 诊断=妇科疾病（N70-N98）→ 性别冲突
  规则2: 性别=女 AND 诊断=前列腺疾病（N40-N42）→ 性别冲突
  规则3: 年龄≥60 AND 诊断=小儿疾病（特定ICD段）→ 年龄冲突
  规则4: 年龄<18 AND 诊断=老年病（特定ICD段）→ 年龄冲突
```

### 子模型2：时空不可能性检测

```
Step 1: 同一医保卡在不同医院的就诊时间差
Step 2: 计算两医院间的最短交通时间（地图API）
Step 3: 规则：
  规则5: 就诊时间差 < 最短交通时间 → 不可能同一人 → 冒名
  规则6: 同一医保卡同一小时内在不同药店刷卡 ≥3次 → 异常
```

### 子模型3：团体冒名检测（最隐蔽）

```
Step 1: 分析医疗机构就诊人员的身份证地址分布
Step 2: 标记规则：
  规则7: 某医院异地就医占比 > 80% → 可能有组织地收治异地冒名患者
  规则8: 同一地址（精确到门牌号）出现 ≥5个不同医保卡 → 冒名窝点
  规则9: 同一联系电话关联 ≥5个不同身份证 → 中介组织
```

### 子模型4：代刷卡检测

```
规则10: 同一社保卡在药店日刷卡 ≥3次 → 频繁代购
规则11: 个人账户年度消费 > 当地人均3倍 → 账户异常使用
```

## 阈值/参数
- 性别冲突 → P0（直接确认）
- 时空不可能 → P0（直接确认）
- 异地就医占比 > 80% → P1
- 同地址 ≥5卡 → P1
- 同电话 ≥5卡 → P0

## 典型发现
- 某男性身份证号就医记录诊断"子宫肌瘤" → 冒用妻子医保卡
- 某社保卡10:15在甲医院结算，10:28在15km外的乙药店结算 → 13分钟不可能赶到
- 某城中村出租屋地址关联了23张不同的医保卡 → 冒名就医窝点

## 局限性
- 需精确到时分秒的结算时间（部分系统只有日期）
- 跨省结算数据不互通 → 时空检测仅本省有效
- 家庭内部共用医保卡（夫妻/父子）难以区分
