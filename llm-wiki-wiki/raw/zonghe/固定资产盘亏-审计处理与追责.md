# 固定资产盘亏的会计处理与审计追责程序

> 融策知识库 | 2026-07-04 | 场景：国企审计/经责审计

---

## 一、固定资产盘亏的认定

### 1.1 盘亏类型
| 类型 | 定义 | 常见原因 |
|------|------|------|
| 实物盘亏 | 盘点时实物不存在 | 被盗/丢失/毁损/报废未销账 |
| 账面盘亏 | 账面有记录但无法确认实物 | 历史记账错误/已处置未下账 |
| 技术性盘亏 | 拆分/合并后原资产卡片未更新 | 资产重组/技术改造 |

### 1.2 认定依据
- 盘点表（含盘点人、监盘人签字）
- 资产台账（含入账日期、原值、累计折旧、净值）
- 差异对比表（盘点数 vs 账面数）
- 影像资料（盘点现场照片）

## 二、会计处理程序

### 2.1 行政事业单位（政府会计制度）
```
1. 发现盘亏 → 编制《资产盘点差异报告》
2. 报主管部门审批 → 取得《资产处置批复》
3. 待处理财产损溢科目过渡：
   借：待处理财产损溢
   贷：固定资产（原值）
4. 审批后：
   借：资产处置费用（净值）
       累计折旧
   贷：待处理财产损溢
```

### 2.2 国有企业（企业会计准则）
```
1. 发现盘亏 → 转入"待处理财产损溢"
   借：待处理财产损溢
       累计折旧
       固定资产减值准备
   贷：固定资产（原值）
2. 查明原因：
   - 管理不善 → 借：管理费用
   - 责任人赔偿 → 借：其他应收款-责任人
   - 自然灾害 → 借：营业外支出
   贷：待处理财产损溢
```

### 2.3 增值税处理
- 非正常损失的固定资产，进项税额需转出（视盘亏原因而定）
- 管理不善被盗/丢失/霉烂变质 → 进项转出
- 自然灾害 → 不需转出

## 三、追责程序（审计角度）

### 3.1 四步追责法

**第一步：定责 — 谁对资产安全负责？**
- 资产使用人是第一责任人
- 资产管理部门负管理责任
- 财务部门负核算监督责任
- 单位负责人负领导责任

**第二步：定性 — 盘亏的性质是什么？**
| 情形 | 性质 | 追责方向 |
|------|------|------|
| 正常报废未销账 | 管理疏忽 | 完善内控，不追个人 |
| 被盗 | 安保责任 | 追究安保责任人 + 报警 |
| 人为毁损 | 使用不当 | 追究使用人 + 赔偿 |
| 擅自处置 | 违规违纪 | 移送纪检 |
| 虚假盘亏 | 侵占/贪污 | 移送司法机关 |

**第三步：定量 — 损失金额是多少？**
- 资产净值 = 原值 - 累计折旧 - 已计提减值
- 追偿金额 = 损失金额（含相关税费损失）

**第四步：定措施 — 如何堵漏洞？**
- 完善资产定期盘点制度（至少每年一次）
- 建立资产变动审批制度
- 加强资产标签/条码管理
- 落实"谁使用、谁负责"责任制

## 四、审计取证要点

| 证据类型 | 内容 | 获取方式 |
|------|------|------|
| 盘点表 | 原始盘点记录+差异对比 | 要求被审计单位提供 |
| 资产台账 | 盘亏资产的入账记录 | 从资产管理系统导出 |
| 审批文件 | 资产处置/报废审批 | 调阅审批档案 |
| 报废依据 | 技术鉴定/损坏证明 | 实物核查+影像 |
| 账务处理 | 盘亏的会计凭证 | 序时账+凭证影像 |
| 追责记录 | 处理决定/赔偿收据 | 人力资源/纪检部门 |
| 保险理赔 | 保险赔付记录（如有） | 保险单据 |

## 五、常见问题与判断

| 问题 | 审计判断 | 建议 |
|------|------|------|
| 盘亏后长期挂账不处理 | 内控缺陷，资产信息失真 | 限期清查处理，完善制度 |
| 盘亏资产仍在折旧 | 虚增成本/费用 | 补提折旧冲销+调整 |
| 盘亏无审批无追责 | 管理严重失职 | 追究管理部门/领导责任 |
| 同一人既管资产又盘点 | 不相容职务未分离 | 整改岗位设置 |
| 盘亏后直接报废不查原因 | 掩盖管理问题 | 要求逐一说明盘亏原因 |
