# 融策 AI 模型路由参考

> 更新日期：2026-07-05
> 所有模型均通过 cbwxy.top 代理调用

---

## 一、模型档案

### 1. DeepSeek V4 Flash — `custom-cbwyy-top-v1/deepseek-v4-flash`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 直出模型（非推理） |
| **速度** | ⚡⚡⚡⚡⚡ 最快 |
| **费用** | 免费（cbwxy.top 免费通道） |
| **特长** | 日常对话、心跳任务、轻量查询、简单格式转换 |
| **适用** | 80% 日常场景 |
| **不宜** | 复杂逻辑推理、深度数据分析 |

### 2. DeepSeek V4 Pro — `custom-cbwyy-top-v1/deepseek-v4-pro`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 推理模型（reasoning） |
| **速度** | ⚡⚡⚡ 中等（含思考时间） |
| **费用** | 含 reasoning tokens，比 flash 贵 |
| **特长** | 链式推理、数据矛盾发现、逻辑验证、绩效评价分析 |
| **适用** | 审计疑点分析、财务异常检测、Benford定律、交叉验证 |
| **不宜** | 简单问答、日常聊天 |

> ⚠️ 所有 completion tokens 首先用于推理（reasoning_content），最后才输出可见 content。配置 max_tokens 时要给够余量。

### 3. GPT-5.5 — `custom-cbwyy-gpt55/gpt-5.5`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 多模态（文本+图片） |
| **速度** | ⚡⚡⚡⚡ 快 |
| **费用** | 中等 |
| **特长** | 报告润色、标书文案、公文修改、含图片分析 |
| **适用** | 文档加工、文案创作、图片理解 |
| **不宜** | 纯推理任务（不如 V4 Pro） |

### 4. Claude Sonnet 5 — `custom-cbwyy-claude/claude-sonnet-5`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 长上下文文本模型 |
| **速度** | ⚡⚡⚡ 中等 |
| **费用** | 中等 |
| **特长** | 超长文档分析、细腻文风、复杂指令遵循 |
| **适用** | 审计报告全文分析、政策法规理解、招投标书综述 |
| **不宜** | 短文本查询（杀鸡用牛刀） |

### 5. Claude Opus 4-8 — `custom-cbwyy-opus/claude-opus-4-8`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 最强推理 |
| **速度** | ⚡⚡ 慢 |
| **费用** | 💰💰💰💰 最高 |
| **特长** | 深度推理、多步复杂分析、重大研判 |
| **适用** | 串标围标最终决策、经责量化评价、报告复核最终把关 |
| **不宜** | 所有日常任务（纯浪费） |

### 6. Claude Fable 5 — `custom-cbwyy-fable/claude-fable-5`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 快速Claude |
| **速度** | ⚡⚡⚡⚡ 快 |
| **费用** | 低（99.6% cache命中率） |
| **特长** | 快速回复、缓存友好 |
| **适用** | Sonnet 不可用时的 fallback |
| **不宜** | 复杂任务（能力不如 Sonnet/Opus） |

### 7. Doubao Seed 2.0 Lite — `custom-cbwyy-doubao/doubao-seed-2.0-lite`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 国产文本模型 |
| **速度** | ⚡⚡⚡ 中等 |
| **费用** | 不确定 |
| **特长** | 中文原生、公文语感好、合规备选 |
| **适用** | 信创环境、政府项目国产化要求场景 |
| **不宜** | 复杂推理分析 |

### 8. GPT Image 2 — `custom-cbwyy-image/gpt-image-2`

| 项目 | 说明 |
|:-----|:------|
| **类型** | 图片生成 |
| **速度** | ⚡⚡⚡ 中等 |

| **特长** | 图片生成 |
| **适用** | 报告封面、PPT配图、宣传物料 |

## 二、场景路由

### 场景A：日常模式（默认）

```
用户消息
  └── DeepSeek V4 Flash（主模型）
        └── 失败 → DeepSeek V4 Pro
              └── 失败 → Claude Sonnet 5
```

**适用**：日常对话、心跳检查、信息查询、简单格式转换、轻量分析

**成本**：极低（免费模型为主）

---

### 场景B：审计分析模式

```
审计数据/疑点/绩效评价
  └── DeepSeek V4 Pro（推理引擎，分析主体）
        └── 复杂研判 → Claude Opus 4-8（最终把关）

审计长文档阅读
  └── Claude Sonnet 5（长上下文，吃透全文）
```

**适用**：
- 绩效评价数据分析
- 财务异常检测（Benford定律）
- 串标疑点研判
- 经责审计量化评价
- 审计底稿逻辑校验

**成本**：中高（推理模型消耗大）

---

### 场景C：报告/标书输出模式

```
报告润色/标书撰写
  └── GPT-5.5（润色+图文理解）
        └── 长文档全文 → Claude Sonnet 5

封面/配图
  └── GPT Image 2

最终质量复核
  └── Claude Opus 4-8 或 DeepSeek V4 Pro
```

**适用**：
- 审计报告撰写与润色
- 技术标/商务标编制
- 项目实施方案输出
- 汇报PPT文案

**成本**：中等（GPT为主，Opus只出最终质检）

---

### 场景D：交叉验证模式（最强配置）

```
同一任务 → 并行调用：
  ├── DeepSeek V4 Pro  → 推理链分析
  ├── GPT-5.5          → 语义理解+图片证据审查
  └── Claude Opus 4-8  → 综合判断
       ↓
      三个结果交叉比对 → 输出最终意见
```

**适用**：
- 重大审计发现最终认定
- 敏感性结论多方论证
- 涉及大额资金的关键判断
- 有可能被质疑的审计意见

**成本**：高，仅在关键节点使用

---

### 场景E：国产合规模式

```
政府项目有国产化要求
  └── DeepSeek V4 Flash（国内模型 ✅ 合规）
        └── 深度分析 → DeepSeek V4 Pro（国内模型 ✅ 合规）
              └── 轻量化 → Doubao Seed 2.0 Lite（国产备选）
```

**适用**：
- 涉密/敏感类政府审计项目
- 信创环境
- 对数据出境有严格要求

**成本**：低（国内模型免费或低价通道）

---

### 场景F：图片/PDF分析

```
用户/任务需要分析图片或PDF扫描件
  └── ⚠️ 必须询问用户确认
        └── qwen-vl-max（DashScope，需确认后调用）
```

**注意**：DashScope 的 qwen-vl-max 付费且需要用户明确同意，不能自动调用。

## 三、当前配置

**openclaw.json 中 agents.defaults.model：**
```
primary:  custom-cbwyy-top-v1/deepseek-v4-flash
fallback: [deepseek-v4-pro, claude-sonnet-5]
```

**建议：** 日常够用。需要切换场景时，手动在 UI 或 session 中切换 model override。

## 四、已知问题与应对

| 问题 | 表现 | 应对 |
|:-----|:-----|:-----|
| cbwxy.top 临时 403 | "This token has no access to model xxx" | 重试，通常数分钟到数小时恢复 |
| V4 Pro 空 content | 只返回 reasoning_content | 加大 max_tokens 给推理留空间 |
| 代理不稳定 | 偶发 timeout | 重试或切 fallback |
| V4 Flash 免费通道 | 无 SLA 保障 | 关键任务用 V4 Pro 兜底 |
