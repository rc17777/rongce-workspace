## 二、审计关键条款速查

### 🔴 会计核算办法（〔2025〕-43号）—— 资金沉淀核查依据

**适用日期：2025年春季学期起执行**（原若教发〔2012〕44号同时废止）

| 条款 | 内容 | 审计用途 |
|:--|:--|:--|
| 单独核算 | 食堂实行单独核算，年末并入学校报表并抵消内部交易 | 核查食堂是否独立建账 |
| 营养餐分账 | 既有营养餐又有非营养餐的，收入/费用/盈余分别按营养餐和非营养餐明细核算 | 核查营养餐资金是否被挪用 |
| 预拨款处理 | 收到预拨营养餐→借记银行存款、贷记"其他应付款—营养餐拨款"；期末按核准金额转入伙食收入 | **2024年沉淀58万的合规性判断依据** |
| 后拨款处理 | 按核准金额借记"其他应收款—营养餐拨款"、贷记伙食收入 | 核查跨年度拨款挂账 |
| 累计盈余 | 年末"本期盈余"转入"累计盈余"，需按营养餐/非营养餐分别反映 | 沉淀资金需明确标记 |
| 月报要求 | 每月编制资产负债表+收入费用表，一式三份 | 现场审计调阅依据 |
| 采购核算 | 随买随用生鲜食材验收合格后直接列费用；库存物品需出入库核算 | 核查出入库是否规范 |
| 库存盘点 | 每月至少盘点一次，盘盈盘亏通过"待处置财产损溢"处理 | 核查账实是否相符 |

**审计判断标准**：
- ✅ 预拨制下沉淀（累计盈余贷方余额）是正常结果——多拨少支的自然累积
- ❌ 沉淀资金不区分营养餐/非营养餐 → 违反分账核算要求
- ❌ 营养餐盈余被转入非营养餐使用 → 挪用专项资金

### 🔴 七部门联动机制（若委教组秘〔2025〕2号）—— 职责分工

| 部门 | 职责 | 审计切入点 |
|:--|:--|:--|
| **县财政局** | 加强膳食经费监管，发现和查处违反财经纪律行为 | 财政局有无做过检查？有无发现问题？ |
| **县审计局** | 适时对"校园餐"资金使用情况开展审计 | 审计局是否已审过？结论如何？ |
| 县发改局 | 指导学校伙食费标准 | 询价定价机制是否执行 |
| 县公安局 | 打击围标串标、食品安全违法犯罪 | 有无举报线索 |
| 县市场监管局 | 食品安全监督、经营主体准入许可 | 供应商资质是否完备 |
| 县卫健局/疾控中心 | 营养膳食指导、食品安全风险监测 | 营养改善效果评估 |

**运行规则**：每半年至少1次专题会议 + 联络员制度 + 每半年调度1次

### 🟡 询价定价制度（若委教组秘〔2025〕3号）—— 采购价格审计

| 要点 | 内容 |
|:--|:--|
| 询价组成 | 纪委监委+发改+市场监管+教育+2校教师+供应商+护航员2+家长2 = 11人/次 |
| 询价频率 | 猪肉/禽肉/蔬果/牦牛肉=每月1次；米面油干货调味品蛋奶=每年1次 |
| 定价规则 | 三家以上均价 × 响应文件下浮比例 = 最终结算价 |
| 公示要求 | 询价结果公示3天 |
| 调价机制 | 学校或供应商对价格不满可申请调价，需提前1-2天递交材料 |
| 询价地点 | 县农贸市场、新华联、浙商优选、佳和、家乐佳等超市 |

**审计切入点**：询价记录是否完整？实际结算价是否与询价结果一致？

### 🟡 膳食监督家长委员会 —— 监督覆盖

- 215名家长，覆盖28所学校+2所幼儿园
- **❌ 达扎寺小学校、民族寄宿制小学校 无家长委员会成员名单**
- 职责：监督食品安全/营养配餐/经费管理/收集意见
- 权限：列席采购会议、查阅明厨亮灶监控、实地检查、每月陪餐≥1次
- 每月1次专项检查（3-5名成员）、每月随机抽查≥1次

### 🟢 陪餐制度（若教发〔2024〕61号）

- 每餐有学校相关负责人与学生共同用餐
- 做好陪餐记录，及时发现问题

### 🟢 出入库管理（若教发〔2024〕99号）

- 食品及原料出入库须有完整记录
- 索证索票（每批次）
