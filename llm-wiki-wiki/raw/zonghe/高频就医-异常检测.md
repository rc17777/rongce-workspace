# 高频就医检测 — Z-Score异常检测

## 法规依据
- **735号令第41条**：个人利用医保待遇转卖药品、接受返还现金或实物 → 退回+暂停联网3-12月；以骗保为目的 → 2-5倍罚款
- **法发〔2024〕6号第6条第5款**：转卖药品套现 → 以诈骗罪定罪
- **法发〔2024〕6号第9条**：明知是骗保购买的药品而收购销售 → 掩饰、隐瞒犯罪所得罪

## 审计问题
是否存在个人异常高频就医，涉嫌套取医保基金或倒卖药品？

## 核心逻辑
统计每个参保人的年度就诊次数，用Z分法找出远高于正常人群的极端值。高频就医可能是真实的重病患者，也可能是套保的"药贩子"。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 身份证号 | 患者唯一标识 | 医保结算 |
| 年度 | 结算年度 | 医保结算 |
| 就诊次数 | 门诊+住院总次数 | 汇总计算 |
| 总费用 | 年度医保报销总额 | 汇总计算 |
| 就诊机构 | 涉及的就医机构列表 | 结算数据 |
| 疾病诊断 | 诊断列表 | 结算数据 |

## 检测逻辑

```
Step 1: 计算全人群 年均就诊次数、标准差

Step 2: 计算Z-Score
  规则1: Z-Score ≥ 3 → 异常高频（统计上概率<0.3%）
  规则2: Z-Score ≥ 4 → 极端异常

Step 3: 分层分析异常人群 — 区分重病患者 vs 药贩子
  规则3: 诊断集中（单一病种）+ 费用高 → 可能是真重病，需排除
  规则4: 诊断分散 + 多医院 + 药品种类多 → 药贩子嫌疑
  规则5: 费用/次数比 < 同龄组均值的30% → 低成本高频 → 套保嫌疑
  规则6: 就诊医院数 > 5家 + 药品种类 > 10种 → 高度疑似药贩子

Step 4: 年龄-性别分层校正
  规则7: 60岁以上自然高频需分层重算 → 排除老龄合理就医
  规则8: 30-50岁青壮年Z≥3 → 强烈可疑（非正常高频群体）

Step 5: 购买药品追溯（药贩子完整链条）
  规则9: 购药后短时间内（<7天）无后续就诊 → 药非自用 → 疑似转卖
```

## 阈值/参数
- Z-Score ≥ 3：异常高频（99.7%置信）
- Z-Score ≥ 4：极端异常
- 费用/次数比 < 均值的30%：低成本高频 → 套保嫌疑
- 就诊医院数 > 5 + 药品种类 > 10 → 药贩子 → P1
- 购药后7天内无复诊 → 药非自用 → P1

## 典型发现
- 某人年就医287次，Z=8.2 → 几乎每天看病，药贩子
- 分层后发现60岁以上人群Z正常，30-50岁有异常尖峰 → 青壮年套保群体
- 某参保人全年在12家医院就诊，购买32种慢性病药，但本人仅38岁且无慢性病史 → 职业药贩

## 局限性
- 需按年龄分层，老年人正常就医次数也高
- 异地就医数据可能不完整
- 真实重病患者（癌症、器官移植等）与药贩子的Z值可能重叠，需结合诊断深度分析
