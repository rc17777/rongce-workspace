# 重大经济决策合规性检测 — 关联规则

## 审计问题
领导干部任期内重大采购、重大投资、大额资金使用是否经过集体决策？是否存在拆分规避招标/审批的问题？

## 核心逻辑
将决策数据按"金额+决策方式+时间+供应商"做关联规则挖掘，发现"大额无集体决策""同一供应商多次小额"等异常组合。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 采购项目 | 采购内容 | 采购台账/合同 |
| 金额 | 单次合同金额 | 合同/序时账 |
| 决策方式 | 集体决策/招标/询价/直接委托 | 会议纪要/审批单 |
| 供应商 | 中标方 | 合同 |
| 日期 | 合同签订日期 | 合同 |
| 经办部门 | 发起部门 | 审批单 |

## 检测逻辑

```
Step 1: 标注"应集体决策"规则：
  金额 > 大额标准（如50万） → 必须集体决策
Step 2: 关联规则挖掘：
  规则1: 金额 > 阈值 AND 决策方式 ≠ 集体决策 → 违规大额
  规则2: 同一供应商 + 同月 + 多笔 = 拆分规避（累计 > 阈值）
  规则3: 同一部门 + 同供应商 + 间隔 < 30天 → 拆分嫌疑
Step 3: 交叉验证：关联规则发现的异常，与会议纪要对比确认
```

## 阈值/参数
- 大额标准：按当地财政规定（通常货物50万、服务30万、工程100万）
- 拆分检测窗口：30天内
- 单供应商年度累计 > 大额标准 × 3 → 严重依赖

## 典型发现
- 某局同一供应商30天内签3份合同，单份40万，累计120万 → 拆分规避招标
- 全年67%大额采购无集体决策记录 → 决策程序形同虚设

## 局限性
- 需会议纪要/审批单电子化或可查阅
- 紧急采购有豁免情形需单独判断
