# 运用 Python 技术分析通信费用支出合规性
——以某行政事业单位财政收支审计为例

## 一、审计背景

在行政事业单位日常运行中，通信费用包括固定电话账户费用、移动通讯费用、网络费用等，涉及服务项目繁杂、计费方式多样、管理链条长，易成为“看不见的浪费”高发区。在开展某行政事业单位财政收支审计中，审计人员发现该单位通信费用月支出金额较大，明显与该单位人员数量和业务规模不匹配。经进一步调查发现，该单位通信业务由信息化管理部门负责，经费支出由办公室负责，两部门未建立相应沟通协调机制。针对该单位通信费用隐蔽和分散特点，以及通信业务缺乏

近年来，随着过紧日子要求的深化落实，各单位严格预算管理，有效削减非必要、非刚性支出，严防各环节出现“跑冒滴漏”现象。通信费用是行政事业单位常见的一种公用经费，具有金额小、内容广、周期性和持续性强的特点，不易引起重视，一旦出现管理漏洞，长期积累将会造成浪费。本文以某行政事业单位财政收支审计为例，运用 Python 技术对通信费用支出进行分析，总结行政事业单位通信业务开展和支出管理的审计方法，以供参考。
