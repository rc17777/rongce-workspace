# 专项债挪用风险检测 — 关联规则

## 审计问题
专项债资金是否被挪用——流向非申报项目、用于经常性支出、偿还其他债务？

## 核心逻辑
将资金流水按"收款方+支出内容+项目编码"做关联规则挖掘，发现支出流向与申报项目不匹配的异常。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 债券项目编码 | 专项债唯一标识 | 申报材料 |
| 支出金额 | 每笔支出 | 专账/银行流水 |
| 收款方 | 收款单位名称 | 银行流水 |
| 支出内容 | 摘要/用途 | 凭证 |
| 申报建设内容 | 申报时承诺的建设内容 | 一案两书 |
| 合同台账 | 项目合同清单 | 合同台账 |

## 检测逻辑

```
Step 1: 建立"合规支出"字典：
  申报建设内容 → 可接受的收款方类型和支出内容
Step 2: 关联规则挖掘：
  规则1: 收款方不在合同台账中 AND 金额 > 50万 → 异常转移
  规则2: 支出内容包含"工资""办公""差旅""招待" → 经常性支出挪用
  规则3: 收款方为其他项目单位 → 跨项目挪用
  规则4: 同一收款方在多个债券项目中收款 → 资金归集嫌疑
Step 3: 金额阈值滤波（小额忽略），聚焦大额可疑交易
```

## 阈值/参数
- 大额阈值：50万（单笔）
- 经常性支出关键词：工资、办公、差旅、招待、水电
- 同一收款方跨3个以上项目收款 → 资金归集

## 典型发现
- 某棚改债券资金1.5亿中3000万汇入某商贸公司 → 追查发现用于偿还旧债
- 某项目专账中频繁出现"差旅费""招待费"，累计超过200万 → 经常性支出挪用

## 局限性
- 需完整的银行流水和合同台账
- 收款方与合同不一致不一定是挪用（如上级统一采购）
