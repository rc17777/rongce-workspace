# 高质量知识库完整技术链路

## 五步流程
1. **文档清洗与分片**：去掉页眉页脚/目录/版权信息，识别标题/段落/表格/列表，补充来源/时间/部门/产品线等元数据
2. **向量化**：通过 embedding 模型映射成高维向量
3. **用户提问向量化**：问题向量与文档向量计算相似度
4. **重排**：向量检索只"先广泛找一批"，再让重排模型根据精确匹配关系重新排序，只把 Top N 高质量上下文交给模型
5. **组装 Prompt 生成**：用户问题 + 检索结果 + 回答约束

## 关键认识
向量检索找的不是字面重复，而是语义接近。重排是效果提升的关键一步——直接决定了模型读到的材料是不是"又准又短"。

## 对审盾的价值
审盾当前 RAG 流程基本覆盖这五步，但缺少正式的重排环节。建议加入 Cross-encoder 重排模型提升检索质量。
