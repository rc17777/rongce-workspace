### 财税政策支持我国文化服务业的影响研究

#### 王梓源

**【摘 要】** 文化服务业是文化产业的核心增长引擎，也是提升国家文化软实力、推动文化传播与繁荣的关键载体。财税政策作为政府宏观调控的重要工具，在引导资源向文化服务业集聚、降低行业运营成本、激励业态创新与国际化发展等方面发挥着不可替代的作用。本文系统梳理我国财税政策支持文化服务业的发展现状与实施成效，深入剖析当前政策存在的精准性与适配性不足、执行与落地存在堵点、资金配置不均衡、国际竞争力薄弱等问题，并相应提出涵盖政策精准性提升、执行机制完善、财政资金优化、国际竞争力培育等维度的优化路径，为完善适配我国文化服务业高质量发展的财税政策体系提供理论参考与实践指引。

**【关键词】** 文化服务 财税政策 税收优惠 财政投入 文化强国

---

随着全球化进程加快和信息技术高速发展，文化服务业已成为国际竞争的重要领域，其高质量发展不仅关乎国家形象的塑造，还影响着国际话语权和综合竞争力。党的二十大报告明确提出“推进文化自信自强，铸就社会主义文化新辉煌”，强调要加强文化传播能力建设，促进优秀文化成果惠及全体人民、走向世界。同时，随着数字技术的快速发展，文化传播的载体、形式与路径发生深刻变革，数字文创、跨境文化服务等新业态不断涌现，对文化产业的发展提出了更高要求。财税政策作为国家宏观调控的重要工具，通过税收优惠、财政补贴、专项基金等多种形式，能够有效引导社会资源向文化服务业集聚，推动文化创新、实现文化传播落地、提升文化产业附加值。系统研究支持文化服务业的财税政策，对于完善国家文化治理体系、提升文化软实力，推动我国文化繁荣发展具有重要的理论价值与现实意义。

近年来，我国为促进文化服务业发展制定了一系列财税政策，并且获得了初步成效。然而，面对文化服务业的创新发展、区域发展的不均衡现状以及文化“走出去”的战略需求，现行财税政策仍存在诸多适配性不足的问题，亟需系统性优化。对此，本文结合文化服务业新业态发展特征，深入分析我国当前在文化传播方面的财税政策，并针对文化服务业轻资产、高人力成本、创新驱动的行业特殊性，提出了兼具针对性和可操作性的财税政策优化路径。

---

### 一、支持文化服务业的财税政策作用机理

#### （一）文化服务业发展具有显著的正外部性

文化服务业的正外部性集中体现在其社会总效益远超直接参与者的私人收益，为社会整体创造广泛而深刻的积极影响。作为文化传播与价值传递的核心载体，文化服务业通过教育、媒体、艺术创作、数字文创等渠道普及知识与人文精神，能系统性提升国民的认知水平、审美能力与道德素养，从而培育高素质人力资本，这种提升不仅惠及劳动力市场与创新体系，更促进了公共生活的良性参与（张新新和严思语, 2023）。同时，文化服务业通过传承中华优秀传统文化、传播主流价值观念，增强社会凝聚力与国家认同感，为构建稳定协作的社会环境提供无形支撑，降低社会治理成本。在经济层面，文化服务业作为创新驱动型产业，直接带动数字技术、创意设计、文旅融合等关联产业发展，通过塑造特色文化品牌优化投资环境，推动经济结构向创新驱动与高附加值转型，产生显著的产业联动效应。

**(二) 财政补贴支持文化服务业发展的作用机理分析**

财政补贴是财政政策实施的主要手段之一，其目的是为实现国家一定时期内的特定目标而向目标产业或企业给予的无偿补助，具有较强的灵活性和时效性（王曙光和白佳艳，2024），能够精准破解文化服务业发展的市场失灵问题。文化服务业中优质内容创作、公共文化服务供给、新业态创新研发等环节，存在创作周期长、社会效益突出但市场回报不确定的特征，许多具有重要文化价值的项目面临可持续发展困境。财政补贴能够直接弥补文化服务企业与机构的部分运营、创作和研发成本，降低其市场经营风险，有助于支持我国文化传承、价值引导、国际交流等公益性和实验性文化服务项目。

同时，财政政策及其杠杆效应在促进文创开发做大做强、增加效益的基础上，还有利于培养和吸引文创人才，提高产业的创新能力、竞争力，实现持续发展（李智勤，2024）。政府对文化服务业的财政补贴会向市场释放明确的政策支持信号，提升社会资本与投资者对文化服务业的信心，撬动更多社会资源参与文化服务领域的投资与运营，形成“财政引导+社会参与”的多元投入格局（唐霄，2022）。借助财政资金的合理分配，还能推动区域之间、城乡之间公共文化服务均等化发展，缓解公共文化服务分配不均的问题（马菊花，2023）。此外，获得补贴的文化服务主体可将资金用于提升内容创作质量、拓展传播渠道、创新服务形式，进一步增强文化服务业的服务深度与覆盖广度。

**(三) 税收优惠支持文化服务业发展的作用机理分析**

税收政策通过税收优惠、税收减免、调整税率等形式影响资金总量和流向的变动，引导社会主体的经济行为，推动资本、劳动力等要素的合理流动和优化配置，从而达到促进产业发展与壮大、产业结构合理

---

**化与高级化的目的，实现经济协调发展（任红梅和李香菊，2018）。核心路径是通过企业所得税减免、增值税即征即退、研发费用加计扣除等税收政策，直接降低文化服务企业与机构的税收负担，提高企业的税后利润与现金流用于内容创作、技术升级、人才培养与市场拓展，契合文化服务业高人力、高研发的投入特征。**

**税收优惠的差异化设计能够形成精准的产业引导机制，对数字化文化、跨境文化服务、非遗传承等文化服务业重点领域和新兴业态实施更大力度的税收优惠，实质上降低相关领域的投资成本与风险，引导社会资本与人力资源向国家文化发展战略支持的方向流动。同时，针对文化消费环节的税收优惠，能够降低文化服务产品的终端消费价格，刺激公众文化消费需求，从需求侧拉动文化服务业增长，形成供需良性互动。从更深层次来看，研发费用加计扣除、文化服务创新设备加速折旧等政策，政府应制定相关税收优惠政策减轻文化服务企业的创作风险，鼓励企业开展技术研发与内容原创，推动文化服务业向高附加值升级；而对文化服务出口实行的增值税退税政策，可以提升我国文化服务产品在国际市场的价格竞争力，助力文化服务业的国际化发展。**

**二、我国支持文化服务业的财税政策现状与成效**

**(一) 我国支持文化服务业的现行财税政策**

近年来，我国陆续出台了一系列针对性支持文化服务业发展的财税政策，涵盖财政专项资金、政府购买服务、转移支付、税收减免等多个维度，逐步构建起多渠道、多层次的政策支持体系，部分政策还通过专项文件明确实施标准与期限，政策落地性不断提升（详见下页表1）。

**(二) 公共文化服务提质增效**

文化服务业可清晰分为公共文化服务和市场化文化服务两大板块，尽管公共文化服务业在经济规模占比上极小，但它在文化服务业中的战略占比较高，是市场化文化服务业业态发展的基础。其中，文化馆、公共图书馆、博物馆是公共文化服务业的核心载体，是政府提供公共文化服务、保障公民基本文化权益的重要机构，其发展成效能够直观反映我国财税政策对公共文化服务业基础设施建设与服务供给的支撑作用。

(三)市场主体活力显著增强

财税政策通过税收减免、财政补贴等方式，有效降低了文化服务业市场主体的经营成本与市场准入门槛，激发了各类市场主体投身文化服务业的积极性，文化服务业法人单位数量呈现持续增长的态势，成为文化产业中市场主体扩张最快、活力最旺盛的领域。

从下页图1可以看出，在2014—2024年间我国文化服务业法人单位数量呈现出持续且强劲的增长态势，从2014年约1.8万个攀升至2024年4万多个，增幅超过1倍，反映出我国文化服务业市场主体活力显著增强。对应占比在2014—2017年期间快速由约40%提升至50%以上，2017年后进入高位平稳运行阶段并稳定在50%—53%区间，充分表明文化服务业已成为我国文化产业中市场主体最集中、占比最高的核心细分领域。由此可以看出，我国文化服务行业活力持续增强，在文化产业中的主体地位不断巩固，也印证了财税政策等大力支持措施对文化服务业市场主体培育的显著成效，不仅有效降低了企业经营成本与准入门槛，更进一步激发了各类市场主体投身文化服务业的积极性，推动文化服务业成为规模以上文化产业中法人单位扩张最快、活力最旺盛的领域，为文化产业整体发展注入了核心动力。

#### (四) 文化产品和服务贸易快速发展

财税政策对文化服务业的精准扶持，推动了该行业营业收入实现跨越式增长，文化服务业已成为文化产业的核心增长引擎。从图 2 可以看出，我国财税政策在促进文化服务业高质量发展方面成效显著，在 2014 年至 2024 年间我国文化服务业营业收入从 1.68 万亿元持续快速增长至 7.7 万亿元，2024 年全国文化及相关产业发展情况报告显示，文化新业态行业营业收入占全部文化产业营业收入的比重为 34.8%，比上年提高 1.6 个百分点，其对文化产业营业收入增长的贡献率为 57.9%。其中，互联网广告服务、互联网其他信息服务、多媒体游戏动漫和数字出版软件开发 3 个行业小类实现营业收入带动作用较为明显，拉动文化新业态行业营业收入增长 10.1 个百分点，这表明财税政策对创意设计、内容生产、数字文化等高附加值文化服务领域的扶持效果凸显。

#### (二) 政策执行与落地存在堵点

(三)财政资金配置不均衡，使用效益有待提高
在财政资金投入方面，存在重分配、轻绩效的倾向，资金配置不均衡，使用效益不高的问题较为突出，未能充分发挥财政资金的引导与杠杆效应。一方面，部分文化服务业专项资金的投向较为分散，对数字文化、跨境文化服务等新兴业态，以及中小微文化服务企业的聚焦不足，资金更多流向传统公共文化服务领域，对文化服务业创新发展的支持力度不足；另一方面，财政资金缺乏全生命周期的绩效评估与动态调整机制，部分地区政府通过贷款贴息、政府投资基金等方式支持文化服务企业时，资金使用的约束机制不完善，存在资金闲置、低效使用的情况，未能有效撬动社会资本参与文化服务业发展。

同时，税收优惠政策的效果评估存在短板，缺乏对减税降费资金流向、文化服务企业研发投入、业态创新成果、产业带动效应等核心指标的量化跟踪，难以精准评估政策对文化服务业高质量发展的实际贡献，不利于后续政策的优化与完善。此外，财政资金在区域配置上仍存在不均衡，东部发达地区文化服务业财政投入力度大，而中西部地区、农村地区的投入相对不足，进一步拉大了区域文化服务业发展差距。

(三)统筹财政资金投向，提升文化服务业扶持效能
针对当前我国文化服务业财政资金区域分布不均、投向零散、使用效率不高的现状，应当整合各种文化类专项补贴，优化资金投向结构，集中财力支持文化创新、数字文化、精品内容创作等核心业态和重点项目，明确资金分配标准，避免重复投入。文化服务业以创意研发、内容生产为核心，具有前期投入高、回报周期长、外部效益明显的特征，仅依靠市场配置容易出现资源分散、创新投入不足、重点领域支持薄弱等问题，而财政资金可在一定程度上弥补市场失灵、引导资源向关键领域集聚，这就要求财政资金必须集中发力，精准投放，整合功能相近、领域重叠的补贴项目，凝聚资金规模效应，减少制度性摩擦，让有限财力聚焦于文化创新、数字文化、精品创作等最具价值的核心环节，确保财政补贴等政策精准对接文化行业发展需求，切实提升我国文化服务业高质量发展效能。

(四)加大本土文化 IP 财税政策支持力度，提升文化服务业国际竞争力
本土文化 IP 是文化服务业高创意、高附加值的核心内容载体，其孵化与国际化输出直接影响文化服务产品出口竞争力，也是破解当前我国文化服务贸易逆差扩大、新兴业态出口短板突出问题的关键。结合文化服务业轻资产、重创意的行业特征，针对本土 IP 出海背后财税政策激励不足的痛点，建议制定专项财税政策精准助推优质本土文化 IP 出海，从内容端补齐新兴文化服务产品出口短板。比如对文化服务企业围绕中华优秀传统文化、非遗等打造原创本土 IP 的研发创作成本，提高研发费用加计扣除比例，对中小微企业实施超额加计扣除，降低 IP 原创孵化成本，夯实新兴文化服务产品出口内容基础。对 IP 开发为数字文创、跨境文化服务等出口产品的，提高此类 IP 衍生文化服务产品出口退税率，对标制造业退税率补充税率短板。对本土 IP 海外版权授权、跨境合作运营等无形文化资产出口收入，免征部分企业所得税，完善相关税收抵免配套规则，解决轻资产文化企业出海政策享受难题，通过构建全方位的财税政策赋能本土文化 IP 国际化，以优质 IP 提升新兴文化服务产品国际竞争力，助力缩小文化服务贸易逆差。
