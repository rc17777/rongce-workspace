# GPT Image2 融策业务配图设计框架

> 基于「GPT Image2 景观设计图纸全流程展示」的核心公式：
> **完整的图纸排版 ＋ 严谨的叙事逻辑 ＋ 高级的场景表现**
>
> 适配为工程咨询与政府审计两大业务线的 AI 配图生成体系。
> 融策配色：深蓝 #0A1F3F + 青绿 #1A5C6E + 铜金 #C5955C + 暖灰 #F5F2EC

---

### 三要素在实际业务中的映射

| 要素 | 工程咨询场景 | 政府审计场景 |
|------|-------------|-------------|
| **图纸排版** | 横道图/BIM剖面/造价分解图/工艺流程图 | 审计流程全景/证据链图谱/问题分类矩阵/风险热力图 |
| **叙事逻辑** | 立项→设计→招标→施工→验收的生命线 | 计划→调查→发现→取证→报告→整改的审计链 |
| **场景表现** | 工地实感/结构精密/地理空间/机械质感 | 数据密度/流程严谨/对比强烈/权威专业 |

## 一、工程咨询 · 叙事型配图（6 组）

### 场景一：项目总体鸟瞰叙事图

**叙事逻辑**：从"一片荒地"到"一座地标"的全景故事

**提示词**：

生成一张大型公共工程项目全生命周期叙事信息图。左侧为项目启动前的原始场地航拍意象（灰色调、荒地质感），向右逐渐过渡到施工中的塔吊林立场景（暖色调、活力感），最右侧为建成后的现代化建筑群落全景（青绿色调、生态融合）。三个阶段的过渡区域以深蓝色时间轴横贯底部，轴上标注立项→设计→招标→施工→验收五个关键节点，节点用铜金色菱形标记。画面顶部三分之一为暖灰色半透明遮罩区域，用于排版标题。风格：电影级叙事长图，史诗感，4K 细节，9:16 竖版。

### 场景二：工程进度双周对比看板

**叙事逻辑**："计划 vs 实际"的对抗张力

**提示词**：

生成一张工程进度双周对比分析看板。画面上下分为两个区域——上半区为"计划进度"，用深蓝色半透明进度条和虚线甘特图展示；下半区为"实际进度"，用铜金色实心进度条展示，偏差区域以青绿色高亮标注"超前完成"、暖灰标注"滞后预警"。背景为网格纸纹理，穿插半透明数据卡片标注关键节点完成率。配色：深蓝底+铜金实绩+青绿超前。风格：项目管理作战室白板质感，专业工程咨询汇报用，9:16 竖版。

### 场景三：全过程造价控制流程图

**叙事逻辑**：每一分钱从哪里来、到哪里去

**提示词**：

制作一张全过程工程造价控制流程信息图。主体为五阶段水平流程线——投资估算→设计概算→施工图预算→合同价→竣工结算，每阶段下方展开"控制要点"卡片（3-4个项目），用连接线串联。流程线上方悬浮柱状图对比（估算/实际），偏差用铜金色和青绿色区分。底部从左到右一条资金曲线折线图，展示累计投资变化趋势。配色：深蓝底、铜金流程线、青绿数据模块，暖灰辅助标注。风格：造价咨询专业汇报，精密数据感，9:16 竖版。

### 场景四：施工质量安全风险矩阵

**叙事逻辑**：风险从潜伏到爆发 → 从识别到管控

**提示词**：

生成一张施工质量安全风险矩阵信息图。主体为 5×5 热力矩阵网格，行标签为风险类型（结构安全、材料质量、施工工艺、人员操作、环境因素），列标签为工程部位（地基基础、主体结构、屋面、装饰装修、机电安装）。每个单元格用颜色深浅表示风险等级——深铜金=高风险、浅金=中风险、青绿=低风险。矩阵周围环绕"防控措施"标注卡片和检查频次指示器。配色：深蓝底、矩阵渐变金，标注青绿。风格：工程监理汇报、专业风险管控，9:16 竖版。

### 场景五：BIM 模型剖面结构图

**叙事逻辑**：从外到内逐层剥开，看清每一层构造

**提示词**：

生成一张建筑信息模型（BIM）等距剖面结构图。主体为一座公共建筑的 3D 等距剖切模型，从下到上展示 6 个构造层——桩基础（深蓝）、地下室（青绿）、主体框架（暖灰）、幕墙外立面（半透明金）、屋顶设备层（铜金）、室内管线综合（彩色分支）。剖面处标注各层材料名称和技术参数占位区。左侧竖向排列标高尺和结构说明卡片。风格：专业 BIM 汇报、工程级精密制图，9:16 竖版。

### 场景六：工程竣工验收全景看板

**叙事逻辑**：五个专项验收 → 一个结论 → 交付使用

**提示词**：

生成一张工程竣工验收全景信息看板。主体为五边形雷达图，五轴分别为：质量验收、安全验收、消防验收、环保验收、档案验收。每个轴标注完成百分比和关键指标。雷达图中心为"竣工验收通过"铜金色印章意象。五角外围悬浮各专项验收的"问题清单"卡片（预留占位区）。底部横排展示竣工资料清单和移交节点。配色：深蓝底、铜金雷达图、青绿达标区域。风格：工程验收汇报、权威专业，9:16 竖版。

## 二、政府审计 · 叙事型配图（6 组）

### 场景七：审计发现问题证据链图谱

**叙事逻辑**：一条问题 → 三条证据 → 一个定性

**提示词**：

生成一张审计发现问题证据链谱信息图。主体为横向展开的链式结构：左端为"审计疑点"红色标注模块，向右依次展开三条证据链分支——资金证据（银行流水+支付凭证）、业务证据（合同+验收单+台账）、法规证据（政策条文+制度文件），三条分支汇聚到右侧的"问题定性"结论模块（铜金色）。每段证据链上标注证据类型和取证状态。配色：深蓝底、红色疑点、铜金结论、青绿证据链。风格：审计工作底稿、法律级证据严谨感，9:16 竖版。

### 场景八：专项资金流向桑基图

**叙事逻辑**：财政资金从源头到末梢的完整河流

**提示词**：

生成一张专项资金流向桑基能量分流图（Sankey Diagram）。左侧起点为"财政拨款"总额模块（深蓝色），向右分三级展开——第一级为项目大类（3-4个分支，青绿色），第二级为具体项目（6-8个分支，铜金色），第三级为支出明细（12-15个分支，暖灰色），最终汇聚到右侧"形成资产/产生效益"模块（深蓝色）。每条分支的宽度对应资金规模。上下方悬浮"结余资金""挪用预警""滞留资金"标注卡片。配色：深蓝底+青绿→铜金→暖灰渐变分支。风格：财政审计汇报，资金追踪感，9:16 竖版。

### 场景九：经责审计评价雷达图

**叙事逻辑**：六维画像 → 综合得分 → 履职评价

**提示词**：

生成一张经济责任审计评价六维雷达图信息图。中心放置六边形雷达图，六轴分别为：财政财务管理、资产管理、内控制度、重点工作推进、廉政建设、以往问题整改。每个轴标注得分（铜金色填充区域），与"同类单位均值"（青绿色虚线区域）形成对比。雷达图外环环绕标注各项指标评分标准和得分明细卡片。顶部放置综合评价等级标签（好/较好/一般/较差）。配色：深蓝底、铜金得分区、青绿均值线。风格：经责审计报告配图，考评权威感，9:16 竖版。

### 场景十：审计整改跟踪闭环图

**叙事逻辑**：问题→整改→核验→销号，一个都不能少

**提示词**：

生成一张审计整改跟踪闭环管理信息图。主体为圆形闭环流程——从顶部"审计发现问题"顺时针依次经过"下达整改通知""制定整改方案""限期整改落实""整改结果验收""问题销号归档"，最后回到"后续跟踪复查"。每个环节用 3D 立体圆环卡片呈现，标注责任主体和时限。闭环内圈放置整改完成率仪表盘（铜金色指针）。闭环外圈标注"超期未整改"红色预警标签。配色：深蓝底、铜金闭环线、青绿完成状态。风格：审计整改管理专报，闭环管控感，9:16 竖版。

### 场景十一：采购招投标合规性审查图谱

**叙事逻辑**：从采购计划到合同履约，逐环节扫描风险点

**提示词**：

生成一张政府采购招投标合规性审查全流程信息图。主体为 8 阶段水平流程线——采购预算编制→采购方式确定→招标文件编制→公告发布→开标评标→中标公示→合同签订→履约验收。每个阶段下方标注该环节的"高风险点"红色标签和"检查要点"青绿色卡片。流程线上方以铜金色旗帜标注"合规通过"，红色旗帜标注"异常发现"。底部横排统计汇总：合规率、异常类型分布、整改建议。配色：深蓝底、铜金合规、红色风险。风格：招投标审计专题汇报，9:16 竖版。

### 场景十二：绩效评价指标达成对比图

**叙事逻辑**：目标 vs 实际 → 差距分析 → 改进建议

**提示词**：

生成一张预算绩效评价指标达成对比信息图。主体为左右双列对比布局：左列为"绩效目标值"（深蓝色柱状图+指标描述卡片），右列为"实际完成值"（铜金色柱状图+达成率标签）。两个柱子之间的差距区域用青绿色箭头标注偏差方向和幅度。指标分为三层——产出指标（数量/质量/时效）、效益指标（社会/经济/生态）、满意度指标。底部汇总"综合绩效得分"仪表盘。配色：深蓝底、铜金实际值、青绿偏差分析。风格：绩效评价报告配图，9:16 竖版。

## 三、通用排版设计规范

### 字体层级建议

| 层级 | 用途 | 推荐字体 | 字号 |
|------|------|---------|------|
| H1 | 图表主标题 | 微软雅黑 Bold | 36-44pt |
| H2 | 区域标题 | 微软雅黑 Regular | 24-28pt |
| H3 | 数据标签 | 微软雅黑 Light | 16-20pt |
| Body | 说明文字 | 宋体 | 12-14pt |
| Data | 数字/指标 | 微软雅黑 Bold | 18-24pt |

### 版式结构模板

```
┌──────────────────────────────────────┐
│           主标题区（10%高度）          │
│     深蓝底 + 铜金分隔线               │
├──────┬───────────────┬───────────────┤
│ 侧边 │               │               │
│ 标注 │   核心视觉区   │  数据面板区    │
│ 列   │  （55%面积）   │ （35%面积）    │
│15%宽 │               │               │
├──────┴───────────────┴───────────────┤
│          脚注/图例区（8%高度）         │
│     暖灰底 + 深蓝文字                 │
└──────────────────────────────────────┘
```

### 使用说明

- 所有提示词可直接粘贴至 ChatGPT / GPT Image2
- 提示词统一预置融策配色，如需调整颜色可修改关键词
- 9:16 竖版适合 PPT 全屏单页展示；如需 16:9 横版，修改末尾尺寸参数
- 提示词中的"占位区"故意留白，方便在 PPT 中叠加真实数据文本框
