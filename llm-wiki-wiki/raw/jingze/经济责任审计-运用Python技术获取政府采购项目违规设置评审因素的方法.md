# 运用 Python 技术获取政府采购项目违规设置评审因素的方法

## 审计背景

为优化营商环境，打造公平规范的市场环境，A 市审计局对某部门领导干部开展经济责任审计，该部门涉及政府采购项目多、资金量大。根据审前调查，该部门近三年超过 100 万元的单个政府采购项目近 100 项，金额近 3 亿元，因此，审计组将采购项目作为审计关注的重点。在此背景下，经综合分析，审计人员采用 Python 技术来审查评

---

政府采购作为政府财政支出的重要环节，其公正性直接关系到营商环境的优化和公众利益的保障。在实际操作中，部分采购项目存在评审因素设置不合理的现象，如违规将特定供应商的优势条件设为门槛或加分项，严重影响了其他潜在供应商的参与度，导致部门采购成本高昂，服务质量水平下降，最终损害了公众利益。本文基于 A 市某部门领导干部经济责任审计案例，详细讲述如何运用 Python 技术高效揭示政府采购项目中违规设置评审因素的问题，通过 Python 爬虫与自然语言处理算法，结合 pdfplumber 库、pandas 库和 asyncio 数据库分析，审计人员成功识别并核实多起违规设置评审因素问题线索，有效促进了政府采购活动的规范化与透明化。

---

审因素的合规性。审计人员通过 Python 进行自然语言处理，自动抓取近 100 个项目招标文件中包含技术部分和商务部分的“评审因素”章节信息，形成结构化数据表。再通过 Python 分析工具建立与《设置评审因素的负面清单》关联的可视化查询对话框，当数据库中的采购项目触发被查询的违规关键词时，自动形成疑点数据表，审计人员在综合分析后进行延伸核实取证。

---

## 数据分析步骤

收集违规设置评审因素，制作《常见评审因素负面清单》数据字典。收集财政部官网关于不适合设置评审因素的权威解答，以及人社部颁布的“国家职业资格退出目录”等信息，如常见的将 CMMI 设置为评审因素问题，在财政部官网解答中就明确了“CMMI/CMMI 认证等未经国家认监委认定的境外机构所出具的认证或资质不宜作为评审因素”，再结合以往审计项目中容易违规设置评审因素的案例，制作含关键词的《常见评审因素负面清单》数据字典。

通过 Python 工具异步提取招标文件的评审因素。第一步，将所有 PDF 版本的招标文件存储到指定文件夹。第二步，定义一个 `extract_tables_from_folder_async` 函数，使用 `pdfplumber` 库异步遍历指定文件夹下的所有 PDF 文件，调用 `extract_tables_pdfplumber_async` 函数对每个 PDF 文件进行处理。第三步，收集所有符合条件的表格并生成 Excel。

---

## 案例总结

本案例所展示的方法主要实现了从指定文件夹下的 PDF 文件中提取包含特定关键字的表格数据，并将相关信息整理成 Excel 文件的功能。通过 Python 异步编程的方式提高了处理多个 PDF 文件的效率，不仅在该审计项目中取得显著成效，还具有较高的推广价值。通过适当调整代码和算法，该框架可灵活应用于其他审计领域，有效提升审计工作的效率和精准度。
