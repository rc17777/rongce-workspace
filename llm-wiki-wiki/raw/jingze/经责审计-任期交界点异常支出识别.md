# 经责审计任期交界点异常支出识别清单

> 融策知识库 | 2026-07-04 | 场景：经济责任审计

---

## 一、什么是任期交界点

任期交界点有两个：

| 时间点 | 风险 | 取数要求 |
|--------|------|------|
| **上任前1年** | 前任突击花钱、突击审批、突击提拔 | 序时账 + 合同台账 + 人事任免 |
| **离任前3-6个月** | 现任突击采购、突击签合同、突击处置资产 | 序时账 + 合同台账 + 资产处置 |
| **任期前后各1年** | 跨任期挂账、前任烂账现任接着挂 | 往来款明细 + 账龄分析 |

## 二、异常支出识别清单

### 2.1 金额端异常

| 异常类型 | 识别标准 | 取数来源 |
|------|------|------|
| **单笔金额峰值** | 任期交界点前后3个月的单笔支出突然放大（>任期均值的3倍） | 序时账 |
| **集中支付** | 某月支出金额突然是其他月份的5倍以上 | 科目余额表（逐月） |
| **整数金额** | 大量支出金额为整数（5万/10万/20万/50万整） | 序时账 |
| **临界点金额** | 刚好卡在审批阈值的金额（如49.8万，因为50万需上会） | 序时账 + 审批制度 |

### 2.2 时间端异常

| 异常类型 | 识别标准 | 取数来源 |
|------|------|------|
| **年底突击花钱** | 11-12月支出占全年比例 > 30% | 逐月科目余额表 |
| **任期最后月密集支出** | 离任前最后一个月支出 > 月均值的2倍 | 序时账 |
| **跨年挂账** | 12月大量挂账，次年1月即冲销 | 往来款明细+序时账 |
| **反季节支出** | 季节性业务在非季节时间段集中发生（如冬季绿化工程） | 序时账摘要筛查 |

### 2.3 对象端异常

| 异常类型 | 识别标准 | 取数来源 |
|------|------|------|
| **新供应商大额交易** | 任期最后半年新增供应商且成交金额巨大 | 合同台账 |
| **单一供应商集中采购** | 同一供应商在短期内获得多个合同 | 合同台账+供应商分析 |
| **关联方交易** | 款项支付对象是单位内部人员/关联企业 | 供应商工商信息 |
| **收款方更换频繁** | 同一类支出频繁更换供应商（拆分规避招标） | 序时账对方科目 |

## 三、重点科目交叉分析

| 科目 | 关注事项 | 分析维度 |
|------|------|------|
| 办公费 | 复印纸/墨盒等大宗耗材在任期交界大量采购 | 金额 + 时间 + 供应商 |
| 维修费 | 离任前大规模维修（实为装修/改造） | 合同 vs 工程量 |
| 咨询费 | 离任前突击签咨询服务合同 | 合同内容 + 对方资质 |
| 差旅费 | 异常集中的差旅报销 | 时间 + 目的地 + 金额 |
| 会议费 | 大量会议在离任前召开 | 签到表 + 会议通知 |
| 培训费 | 离任前突击培训 | 培训内容 + 参训人员 |
| 固定资产 | 离任前大额资产采购/处置 | 资产台账 + 审批文件 |

---

## 四、审计操作步骤

```
Step 1: 取任期全周期序时账
Step 2: 按科目 + 按月汇总支出金额
Step 3: 计算月均支出和标准差
Step 4: 标记超出月均值+2个标准差的月份 → 异常月
Step 5: 重点关注异常月是否集中在任期交界点
Step 6: 对异常月的大额交易逐笔抽查凭证
```


## 五、典型异常信号总结

| 信号 | 可能问题 | 审计建议 |
|------|------|------|
| 12月支出超全年30% | 年底突击花钱 | 抽查12月全部大额凭证 |
| 任期最后3月合同猛增 | 突击签合同 | 逐份审查合同真实性 |
| 咨询费突然飙升 | 套取资金 | 追溯对方资质+成果 |
| 固定资产集中处置 | 变卖资产 | 评估价格+处置程序 |
| 应付账款突然增加 | 制造虚假负债 | 逐笔函证+账龄分析 |
| 招待费异常集中 | 变相发福利/送礼 | 逐笔审查接待清单 |
