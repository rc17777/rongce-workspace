# 行政事业单位 vs 国有企业经责审计差异对比

> 融策知识库 | 2026-07-04 | 场景：经济责任审计

---

## 一、核心差异总览

| 维度 | 行政事业单位 | 国有企业 |
|------|:-----------:|:------:|
| 会计制度 | 政府会计制度（双分录） | 企业会计准则 |
| 审计目标 | 履职尽责、预算合规 | 经营绩效、保值增值 |
| 核心指标 | 预算执行率、三公控制 | 净利润、ROE、EVA |
| 责任类型 | 行政责任为主 | 经营责任+经济责任 |
| 审计期限 | 任期（通常3-5年） | 任期（通常3年） |

---

## 二、取数范围差异

### 2.1 行政事业单位特有取数项

| 取数项 | 用途 |
|------|------|
| 预算批复与调整文件 | 验证预算执行合规性 |
| 三公经费明细（逐月逐笔） | 只减不增原则检查 |
| 非税收入票据 + 缴款凭证 | 是否坐支、是否足额上缴 |
| 结余结转资金明细 | 年底突击花钱检测 |
| 人员编制文件和实际在编人数 | 超编用人检查 |
| 党组/局长办公会纪要 | 三重一大执行情况 |
| 上级巡视/审计发现问题反馈 | 整改是否到位 |

### 2.2 国有企业特有取数项

| 取数项 | 用途 |
|------|------|
| 合并报表（含子公司） | 合并口径经营成果 |
| 国资委/出资人考核目标 | 业绩是否达标 |
| 关联交易台账（金额+定价依据） | 关联交易公允性 |
| 对外投资台账（含退出） | 投资决策合规+回报 |
| 高管薪酬明细 | 是否超标 |
| 董事会/监事会决议 | 治理规范性 |
| 产权登记证 + 评估报告 | 产权是否清晰 |
| 审计委员会/内审报告 | 内控有效性 |

### 2.3 共同需要的取数项

| 取数项 | 两者都需要 |
|------|:--:|
| 序时账（末级科目+辅助核算） | ✅ |
| 科目余额表（逐月） | ✅ |
| 合同台账（全量） | ✅ |
| 内控制度汇编 | ✅ |
| 资产台账（任期首尾时点） | ✅ |
| 招投标文件（如涉及采购） | ✅ |
| 往来款明细（含账龄） | ✅ |

## 三、审计重点差异

### 3.1 行政事业单位审计重点

**「花了没有多花，收了没有少收」**

| 审计重点 | 检查内容 |
|------|------|
| **预算执行率** | 预算批复 vs 实际支出，逐科目对比 |
| **三公经费** | 是否只减不增？公务接待有没有超标？ |
| **非税收入管理** | 是否全额上缴财政？有无坐支？ |
| **专项资金专款专用** | 有没有被挪用去发工资/日常运转？ |
| **政府采购** | 是否按规定走采购程序？ |
| **资产完整性** | 有没有账外资产？ |
| **编制管理** | 实际人数是否超编制？超编人员工资从哪出？ |
| **决策规范性** | 三重一大事项是否应上会未上会？ |

### 3.2 国有企业审计重点

**「钱有没有赚到，资产有没有保住」**

| 审计重点 | 检查内容 |
|------|------|
| **经营业绩** | 营业收入、利润、净资产收益率是否达标？ |
| **保值增值** | 任期初→任期未 国有资本是增值还是减值？ |
| **关联交易** | 定价是否公允？是否向大股东输送利益？ |
| **重大投资决策** | 可行性→董事会→执行→回报 全链条 |
| **薪酬管理** | 高管薪酬是否超过国资委批复标准？ |
| **产权管理** | 产权登记、评估、交易是否规范？ |
| **内控有效性** | 关键业务流程有没有控制漏洞？ |
| **信息披露** | （如上市公司）披露是否真实完整？ |
| **利润分配** | 利润分配方案是否经股东会批准？ |

## 四、责任界定差异

### 4.1 行政事业单位 — 以「合规性」为核心

| 责任类型 | 判断标准 |
|------|------|
| **直接责任** | 本人直接决定/批准/授意的违规行为 |
| **领导责任** | 分管领域发生问题，本人未发现或未制止 |
| **主管责任** | 主持工作期间本单位/本领域发生问题 |

**关键判断：** 决议是否为本人直接签批？会议纪要是否有反对意见记录？

### 4.2 国有企业 — 以「经营后果」为核心

| 责任类型 | 判断标准 |
|------|------|
| **直接责任** | 直接违反法律法规、造成重大损失 |
| **主管责任** | 对分管范围内的重大风险失察 |
| **领导责任** | 本企业发生重大损失或风险事件 |

**关键判断：** 投资是否经过充分论证？决策程序是否合规？损失是否可预见但未采取措施？

## 五、常见混淆点

### 混淆1：事业单位 vs 国企分不清
事业单位分三类：
- 全额拨款（参照行政单位审计）
- 差额拨款（关注事业收入+经营收入的合规性）
- 自收自支（参照国企审计，但用的仍是政府会计制度）

### 混淆2：党政机关下属企业
党政机关下属的企业化管理单位（培训中心/招待所/印刷厂），取数时要同时取党政机关的预算数据和企业的经营数据——因为人员、资金、资产可能混在一起。

### 混淆3：经济责任审计 ≠ 财务收支审计
- 经责审计关注的是「人」— 领导干了什么、没干什么
- 财务收支审计关注的是「账」— 收支是否合规完整
- 两者的取数有重叠但侧重点完全不同

## 六、审计报告差异

| 报告要素 | 行政事业单位 | 国有企业 |
|------|------|------|
| 评价核心 | 履职尽责情况 | 经营业绩和国资保值增值 |
| 问题分类 | 预算/三公/资产/决策 | 投资/经营/内控/薪酬 |
| 量化指标 | 预算执行率、三公降幅 | ROI、ROE、保值增值率 |
| 一票否决项 | 重大违法违纪 | 造成国有资产重大损失 |
| 任期追溯 | 前后各推1年 | 前后各推1年 + 跨年投资项目追溯 |
