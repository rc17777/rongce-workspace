# 往来款长期挂账检测 — 描述模型

## 审计问题
是否存在长期未清理的应收应付款项？是否有通过往来款隐匿收支的情况？

## 核心逻辑
正常往来款有合理周转周期。超过一定账龄仍未清理的挂账，要么是坏账未核销，要么是通过往来科目隐匿收支。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 对方单位 | 往来单位名称 | 往来明细账 |
| 科目 | 应收账款/应付账款/其他应收/其他应付/预付 | 科目余额表 |
| 金额 | 余额 | 科目余额表 |
| 发生日期 | 最后一笔发生时间 | 序时账 |
| 账龄 | 已挂账时长（天/月/年） | 计算字段 |
| 经办人 | 经办人（如有） | — |

## 检测逻辑

```
Step 1: 计算账龄 = 当前日期 - 最后一笔发生日期
Step 2: 分账龄段统计：<1年 / 1-2年 / 2-3年 / >3年
Step 3: 标记异常：
  - 账龄 > 3年 且 金额 > 5万元 → 重点关注
  - 其他应收款-个人 挂账 > 1年 → 公款私用嫌疑
  - 预付账款长期未核销 → 可能已形成支出但未入账
Step 4: 按账龄段生成分布图，直观展示坏账风险
```

## 阈值/参数
- 重点关注账龄：> 3年
- 金额阈值：> 5万元（可根据单位规模调整）
- 个人挂账阈值：> 1年

## 典型发现
- 某局其他应收款挂账50万，账龄5年，对方为已注销企业 → 实质坏账应核销
- 预付账款某供应商挂账2年未结算 → 可能工程已完工，支出需确认

## 局限性
- 需区分正常质保金（合理挂账）和异常挂账
- 账龄计算依赖准确的发生日期，手工记账单位可能数据不完整
