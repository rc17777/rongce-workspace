## 什么是空间维度

数据是在三维空间中产生的，除了数据本身外，至少还有**时间维度、空间维度**，还需要有**网络思维**。网络思维、时间维度和空间维度是形成数字化审计思维的重要基础，可以大大拓展数字化审计的边界。

空间维度最常见的是经纬度，简单理解为地图上的一个点。

## 空间维度的审计应用

**所有的交易行为都是在特定的空间发生的。**

应用场景（《数字化审计实务指南》）：
- **寻找不同行为主体在空间维度上的交集**：将投标邮件IP地址转换为经纬度，进行空间维度关系分析
- **利用空间地理资源数据进行疑点挖掘**：工程审计中基于遥感数据和三维重建计算土方量、绿化植株
- **时间维度和空间维度的结合**：利用百度迁徙大数据分析区域经济和复工情况

## 实现路径

两步关键：
1. 将地址信息转换为经纬度信息（百度地图地理编码API）
2. 将地点在地图上可视化标注出来（pyecharts）

### 核心代码

```python
import requests
from pyecharts import options as opts
from pyecharts.charts import Geo
from pyecharts.globals import GeoType

# 批量获取地址坐标
for info in infolist:
    curUrl = f'https://api.map.baidu.com/geocoding/v3/?address={info}&output=json&ak={ak}&city=上海市'
    res = requests.get(curUrl)
    resjson = res.json()
    if resjson['status'] == 0:
        posinfo.append((info, resjson['result']['location']['lng'], 
                        resjson['result']['location']['lat']))

# 在地图上标注
geo = Geo(is_ignore_nonexistent_coord=True)
geo.add_schema(maptype="上海")
for pos in posinfo:
    geo.add_coordinate(pos[0], pos[1], pos[2])
data_pair = [(x[0], 1) for x in posinfo]
geo.add('', data_pair, type_=GeoType.EFFECT_SCATTER, symbol_size=8)
geo.render('分布地图.html')
```
