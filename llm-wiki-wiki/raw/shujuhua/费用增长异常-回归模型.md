# 人均费用增长合理性检测 — 回归模型

## 审计问题
任期内管理费用、业务费用增长是否与人员规模、业务量增长匹配？

## 核心逻辑
费用应与业务驱动因素（人数、业务量、资产规模）有稳定关系。用回归建立"合理费用水平"基线，实际偏离即为异常。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 年度管理费用 | 管理类支出合计 | 决算表 |
| 年度业务费用 | 业务类支出合计 | 决算表 |
| 年末在职人数 | 在编+聘用 | 人事数据 |
| 年度业务量 | 核心业务量指标 | 业务台账 |
| 年度 | 任期及前2年 | — |

## 检测逻辑

```
Step 1: 建立回归模型：
  人均管理费 = a × 年度 + b（时间趋势）
  人均业务费 = c × 业务量 + d（业务量驱动）
Step 2: 检验任期内残差趋势：
  - 残差持续为正且递增 → 费用膨胀
  - 残差为正且R²低 → 费用与业务脱钩，管理失控
Step 3: 与同级别单位人均费用对比验证
```

## 阈值/参数
- 人均管理费年增长 > 10%（扣除通胀） → 异常
- R² < 0.5 → 费用与业务驱动因素严重脱钩
- 需至少4个年度数据点（任期2年前 + 任期2年）

## 典型发现
- 人数不变、业务量下降，人均管理费却年增15% → 铺张浪费
- 任期末人均费用是任期初的1.6倍，同级别仅1.1倍 → 管理失控

## 局限性
- 需合理选择业务驱动因素，不同单位核心指标不同
- 通胀调整需使用当地CPI
