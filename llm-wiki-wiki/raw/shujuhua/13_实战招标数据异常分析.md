## 将实例数据转换为cypher建表语句

在实例数据中，公司名称、人名等，在不同的记录行中都会重复出现，如果用逐行创建的话，会建立很多重复的NODE。为避免这种情况，可以采取循环实例数据中的所有行，对公司名称、人名等去重后，先建立NODE，然后根据ID，建立关系。

基本思路：循环实例数据，自动生成实体和关系创建代码，写入文本文件。

```python
# -*- coding: utf-8 -*-
import pandas as pd
import io
## Python 3 环境下运行
## 读取数据文件
df = pd.read_excel("投标公司信息.xlsx", dtype = {'联系电话':str}, encoding='gbk')
## 根据数据文件中的数据生成实体和关系
with io.open('建表语句.txt','w') as fp:
    fp.write("// 原始数据来源于投标公司信息.xlsx 创建72个节点，80条关系\n\n")
    for node in df['投标公司名称'].unique():
        fp.write("CREATE (%s:公司 {name: '%s'})\n"%(node,node))
    for node in df['联系人姓名'].unique():
        fp.write("CREATE (%s:联系人 {name: '%s'})\n"%(node,node))
    for node in df['联系电话'].unique():
        fp.write("CREATE (T%s:电话 {name: '%s'})\n"%(node,node))
    for node in df['银行账号'].unique():
        fp.write("CREATE (%s:账号 {name: '%s'})\n"%(node,node))
    for node in df['联系邮箱'].unique():
        fp.write("CREATE (%s:邮箱 {name: '%s'})\n"%(node.replace('@','_').replace('.','_'),node))
    for idx,row in df.iterrows():
        fp.write("CREATE (%s)-[:联系人]->(%s)\n"%(row['联系人姓名'],row['投标公司名称']))
        fp.write("CREATE (T%s)-[:联系电话]->(%s)\n"%(row['联系电话'],row['投标公司名称']))
        fp.write("CREATE (%s)-[:银行账号]->(%s)\n"%(row['银行账号'],row['投标公司名称']))
        fp.write("CREATE (%s)-[:联系邮箱]->(%s)\n"%(row['联系邮箱'].replace('@','_').replace('.','_'),row['投标公司名称']))
```

## 利用建表语句创建图数据

打开"建表语句.txt"，"全选-复制"到浏览器中打开的Neo4j Browser命令输入框中，点击右侧的运行按钮，即开始图数据自动创建。注意，需要一次性粘贴和运行。运行完毕，Neo4j Browser 出现结果画面：Added 72 labels, created 72 nodes, set 72 properties, created 80 relationships。

## 实战招标数据分析

### 1.模糊查询

```cypher
// 查询联系邮箱为gmail的公司
match (a:邮箱)-[r:联系邮箱]->(b:公司)
where a.name =~ '.*gmail.com.*'
return * limit 10
```

### 2.关联关系分析

```cypher
// 查询具有相同联系电话的公司
match (b2:公司)<-[r2:联系电话]-(a:电话)-[r1:联系电话]->(b1:公司)
return *
```

### 3.多关联关系分析

```cypher
// 具有共同联系电话和银行账号的公司
match (b2:公司)<-[r2:联系电话]-(a:电话)-[r1:联系电话]->(b1:公司)
with b1,b2,r1,r2
match (b2:公司)<-[r4:银行账号]-(a1:账号)-[r3:银行账号]->(b1:公司)
return *
```

### 4.找隐蔽控制人

```cypher
// 具有共同联系电话和银行账号的公司2层关系内的所有关系信息
match (b2:公司)<-[r2:联系电话]-(a:电话)-[r1:联系电话]->(b1:公司)
with b1,b2,r1,r2
match (b2:公司)<-[r4:银行账号]-(a1:账号)-[r3:银行账号]->(b1:公司)
with b1,b2
match (a3)-[r5*0..2]-(b3:公司) where (b3.name=b1.name or b3.name=b2.name)
return *
```

### 5.寻找关键点

```cypher
// 查询在3层关系内与指定的电话号码相关的公司
match p=shortestPath((a:电话)-[*0..3]-(b:公司))
where a.name='14583167129'
return *
```

### 6.查找任意关系

```cypher
// 查询给定的两个电话号码之间是否存在关系
match p=shortestPath((a:电话)-[*]-(b:电话))
where a.name='13306736765' and b.name='13919583545'
return *
```
