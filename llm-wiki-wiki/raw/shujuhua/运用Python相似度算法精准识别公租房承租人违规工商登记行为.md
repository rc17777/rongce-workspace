# 技术方法

## 运用 Python 相似度算法精准识别公租房承租人违规工商登记行为
——以H市住房建设领域专项审计调查为例

●饶忠兴 王琳

公租房是重要的民生工程，承载着住房困难群众 “住有所居” 的殷切期望。然而，部分人员违规将公租房用于办理工商登记、开展经营性活动，这种行为损害了住房困难群体的合法权益，更背离了公租房政策的初衷。当前，有些审计机关虽已初步构建起较为完善的公租房领域数据体系，但数据标准化还不高，影响了数据分析的精准度。本文以 H 市住房建设领域专项审计调查为例，介绍如何运用 Python 技术攻克地址表述差异化难题实现不同地址数据的精准匹配，进而识别公租房承租人违规工商登记行为，为同类型审计提供参考。

### 一、审计背景

在 H 市住房建设领域专项审计调查中，审计组在审前调查阶段梳理住房建设领域“接诉即办”平台投诉数据、群众信访举报线索，锁定公租房管理为本次审计重点。通过梳理以往相关审计项目，发现利用公租房违规经营的问题时有发生，但受限于人员配置、核查范围等客观因素，难以实现全量数据审查。为破解难题，审计组运用大数据审计方法，将公租房合同信息与工商登记信息进行比对，排查违规经

营行为。但公租房合同地址由市住房建设部门规范录入，为“市—区—街道—小区—栋—单元—房号”的完整层级结构，而工商登记地址由企业自主填报，存在核心词汇称谓不一、建筑标识用词混乱、行政层级信息缺失等问题，使用 SQL Server 数据库工具难以有效关联数据。对此，审计人员依托 Python 工具，引入自然语言处理、字符串相似度算法等技术，构建相似度比对模型，突破地址比对难题。

### 二、审计方法与具体操作步骤

#### （一）数据处理

审计组通过地址标准化与数据清洗优化完成了对数据的预处理，为后续相似度比对筑牢数据基础。

**地址标准化。** 一是清除特殊字符，通过 Python 字符串处理函数（replace）批量剔除“#”“-”“（）”等无关字符，如将“A路123-1号”规范为“A路1231号”；二是实现词汇归一化，将“大厦”“产业园”“公寓”等场所称谓统一归类为“区域”，把“栋”“幢”“号楼”等建筑表述统一为“栋”，如将“B产业园1号楼1单元1层101室”标准化为“B区

域1栋1单元1层101室”；三是补全层级结构，通过部署本地版地图地理编码 API，补全并校验两类地址市、区、街道等行政层级，确保地址层级结构一致。

**数据清洗优化。** 借助 Python 的 pandas 库，对标准化后的地址数据开展空值剔除、重复值清理等操作，剔除无效数据条目，保障输入相似度模型的数据质量，为后续算法运算提供数据支撑。

#### （二）模型构建与实施流程

审计人员采用序列相似度匹配算法（difflib.SequenceMatcher）构建地址相似度比对模型，通过逐字符分析两个地址的字符序列，精准统计匹配部分长度，最终生成范围在 0~1 之间的“相似度得分”，量化地址匹配程度。

**模型核心功能聚焦“地址比对与匹配判定”，通过预设的“相似度阈值”实现自动化筛选：** 审计人员可根据实际数据特性设定阈值，模型接收两个待比对地址后，先计算相似度得分，再将得分与阈值比对。若得分≥阈值，则判定为“地址匹配”，同步记录具体相似度数值；若得分＜阈值，则判定为“地址不匹配”，同样保留得分数据供后续核验。

**模型按照“全量遍历—逐条比对—阈值设定—匹配筛选—结果留存”的逻辑运行。** 首先，进行数据全量遍历。运用模型分别读取两类数据，提取每条数据的地址信息，确保两类地址数据全面覆盖。其次，进行逐条比对。针对每一条公租房合同地址，模型依次与相关数据进行比对，计算两组地址的相似度得分，形成全量地址比对的相似度数据。再次，设定并验证阈值，采用分层抽样法，选取不同区域、户型的 200 组公租房与相关信息对，结合实地核

查标注违规类型。从 0.5 至 0.95 分段设置阈值，测算不同阈值下模型的精准度与召回率，最终确定阈值为 0.8。此时模型精准度达 92%、召回率 88%，既能覆盖 90% 以上的真实违规案例，又能将无效核查线索控制在 15% 以内，实现精准度与召回率的最优平衡。接着，进行匹配筛选，运用该模型对预处理后的全量数据进行对比，模型自动将当前得分与预设的 0.8 阈值对比，判断两条地址是否符合“匹配标准”。最后，进行结果留存，若判定为“匹配”（得分≥0.8），模型会自动整合该条公租房地址的原始信息、工商登记地址信息及具体相似度得分，统一存入结果列表；若判定为“不匹配”，则不纳入结果列表，仅保留比对记录供后续追溯。

### 三、审计成果与应用

通过该模型生成疑点数据 31 条，经实地走访、调阅企业经营场所证明、询问承租人等审计程序核实后，23 人存在违规使用公租房从事经营活动的问题，相关问题形成的审计专报获市委主要领导同志签批，推动了住房建设部门对违规承租人作出退回公租房等处理，有效维护了保障性住房政策的严肃性与公平性。

此技术方法契合政策对公租房使用全流程监管的刚性要求，审计成果在违规行为识别精准度、技术方法创新性、行业推广适用性等方面表现突出，可推广至保障性租赁住房、人才公寓等其他保障房类型的审计场景，以及涉及地址相似度比对的税收征管、市场监管等跨领域的审计工作中，为数字化审计方法体系建设提供了可复制的技术路径。
