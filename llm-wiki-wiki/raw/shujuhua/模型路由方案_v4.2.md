## 错误代价六级路由图

```
错误代价 ~0     错误代价低      [咨询层]       错误代价中       错误代价高         错误代价致命
(错了重来)    (改两行)      (方向选错)     (重跑一遍)     (改半天)          (吊销执照)
      │             │              │               │               │                  │
   v4-flash    qwen3.7-plus     fable-5        v4-pro        claude-sonnet-5    claude-sonnet-5
                            ┌──────────────┤     + gemini        + gpt-5.5/5.6     + gpt-5.5/5.6
                            │ (长文档/大数据)│  (长文档推理)     + gemini(长文档)  + opus-4-8 终审
                          gemini预筛选      gemini批处理
```

核心理念：**错误代价不确定 → 向上一级，宁高勿低**。
文档 >128K token → 跳过中间层，直接走 **gemini**（1M+上下文独家）。

```
    └───────────────┼────────────┼─────────────┘
                    ▼            ▼
               审查意见汇总    gemini长文档报告
                    │
           低代价交付             高/致命代价交付
         (日常/常规报告)          (审计报告/标书/关键结论)
                │                        │
           qwen 修正               + opus-4-8 终审签字
                                  + gemini 交叉验证(超长)
```

## Fable-5 咨询层

- **定位**：独立顾问层，**不做执行/终审，只给建议**
- **触发时机**：做决策**之前**，不是"写完了复核"
- **升级规则**：建议分歧大/影响项目方向 → sonnet-5 正式判断
- **典型场景**：方案对比、架构选型、路线选择、风险影响评估
- **成本**：缓存命中率极高，重复评审场景几乎零成本

## Gemini 长文档层

- **定位**：1M+上下文专属通道，文档>128K token 或跨文档验证时触发
- **成本**：预览版（注意稳定性），正式结论仍需 sonnet/opus 交叉
- **降级策略**：gemini 403/404/超时 → 自动降级到 sonnet-5 分段读（每150K一段）

## 升级规则速查

| 触发信号 | 动作 |
|:--|:--|
| flash 结果存疑 | → qwen(中文) / v4-pro(推理) |
| v4-pro 推理链不完整 | → sonnet-5 / gemini(长文档) |
| 文档>128K token | → **直接走 gemini** |
| 结论将写入正式报告 | → sonnet-5 交叉验证 |
| 结论影响定案/行政处罚 | → sonnet-5 + opus-4-8 |
| 涉及法律/合规/重大资金 | → sonnet-5 起步，出具前 opus 签字 |
| 方案/架构/工具选择 | → fable-5 咨询层 |
| 长文档正式交付 | → gemini 初读 + sonnet 复核 + opus 终审 |
| 错误代价不确定 | → **向上一级，宁高勿低** |

## 数据合规红线

| 数据类型 | 模型策略 |
|:--|:--|
| 日常工作（方案/报告/投标/案例/知识库） | 海外模型为主，全14模型可用 |
| 常规审计项目数据 | 海外模型为主 |
| **敏感项目**（经责·县处级+/补贴/国企/纪检） | **仅国内模型**：deepseek、qwen、doubao |
| 极端敏感（涉密/纪检移交） | **离线模式**，不调任何云端模型 |
