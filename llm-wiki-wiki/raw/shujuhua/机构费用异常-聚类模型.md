# 医疗机构费用异常检测 — 聚类模型

## 法规依据
- **735号令第15条**：不得"过度诊疗、过度检查"
- **735号令第38条第2款**：过度诊疗/检查 → 退回+1-2倍罚款
- **735号令第38条第3款**：重复收费、超标准收费、分解项目收费 → 退回+1-2倍罚款
- **社会保险法第87条**：机构骗保 → 退回+2-5倍罚款 + 吊销执业资格

## 审计问题
哪些医疗机构存在人均费用异常、费用结构异常的问题？

## 核心逻辑
将医疗机构按"人均费用、人次、费用结构（药占比/检查占比）、增长率"多维度聚类，找出偏离正常群体的异常机构。

## 数据需求

| 字段 | 说明 | 来源 |
|------|------|------|
| 医院编码 | 机构唯一标识 | 医保结算 |
| 年结算人次 | 年度门诊+住院总人次 | 汇总 |
| 人均费用 | 总费用/人次 | 计算 |
| 药占比 | 药品费/总费用 | 计算 |
| 检查占比 | 检查费/总费用 | 计算 |
| 费用增长率 | 同比上年 | 计算 |
| 医院级别 | 三级/二级/一级/社区 | 机构信息 |

## 检测逻辑

```
Step 1: 标准化 — Z-Score转换
  人均费用、人次、药占比、检查占比、增长率 → Z-Score

Step 2: K-Means聚类（k=5），按医院级别分别聚类
  规则1: 一级/二级/三级/专科 分别聚类（不同级别费用结构不可比）

Step 3: 识别异常群 — 三类异常模式
  规则2: 人均费用 > 同级均值1.5倍 → 过度医疗嫌疑
  规则3: 药占比 > 同级均值+1.5个标准差（约>45%）→ 以药养医嫌疑
  规则4: 检查占比 > 同级均值+1.5个标准差 → 以检养医嫌疑
  规则5: 年增长率 > 30% 且无规模扩张解释 → 异常膨胀

Step 4: 多维度联合标记
  规则6: 人均费高 + 药占比高 → 过度用药+过度收费双重问题
  规则7: 人均费高 + 费用增长率高 → 趋势性恶化
  规则8: 单独一个维度异常（其他维度正常）→ 可能是专科特性 → 需排除

Step 5: 对异常群机构重点抽查病历，验证合理性
```

## 阈值/参数
- 聚类数 k=5，按级别分层
- 人均费用 > 同级均值1.5倍 → P1
- 药占比 > 45%（同级）→ P1（以药养医）
- 检查占比 > 同级均值+1.5σ → P1（以检养医）
- 年增长率 > 30% → P1（异常膨胀）
- 人均费用 > 同级均值2倍 → P0（严重异常）
- 专科医院（肿瘤/精神病/康复）需单独分组

## 典型发现
- 某一级医院人均费用高于三级医院均值 → 严重异常，抽查发现虚假住院
- 某机构药占比75%，同级均值35% → 以药养医的典型
- 某医院检查占比从28%飙升至51%（一年），同期人均费增长40% → 过度检查

## 局限性
- 专科医院（肿瘤/精神病）费用结构天然不同，需单独分组
- 需足够的同级机构数量（至少10家以上）聚类才有意义
- 聚类结果本身不构成违规证据，仅为筛查工具，必须延伸抽查病历
