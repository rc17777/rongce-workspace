# 运用 SQL、Python 技术构建固定资产投资项目管理数据分析模型
——以A市基本建设预算执行审计为例

● 王敬敏

基本建设预算执行审计中，政府固定资产投资项目储备、预算衔接与计划安排、工程建设管理、资金使用效益等事项是审计关注重点。采用人工抽样方式选取项目，难以全面反映问题。本文以政府投资项目全生命周期管理为出发点，运用 SQL、Python 等技术，在 A 市基本建设预算执行审计中建立数据分析模型，揭示项目管理中存在的问题。

## 一、审计背景

近年来，A 市持续加大固定资产投资力度，投资规模大，项目数量多，投资领域范围广。投资总量持续攀升，对审计监督的广度与深度提出更高要求。A 市基本建设预算执行审计作为每年必审项目，审前需加强对投资项目的分析研究，从不同维度抽查项目，单纯依靠传统审计抽查方式难以满足项目全覆盖审计的需求。为此，审计人员运用 SQL Server 数据库对重大投资项目储备库、政府投资计划、重点工程及政府投资项目在线监测数据进行关联比对分析，筛查疑点线索。现场核查过程中，审计人员编制调查标准表获取项目资金安排、使用及结存数据，运用 Python 编程绘制资金结存柱状图，直观、量化地锁定资金使用效益不高的项目。运用“总体分析、发现疑点、分散核实、系统研究”的数字化审计模式，实现非现场审计与现场审计资源的配置衔接，对审计过程进行还原，构建数据分析模型，逐步实现对政府固定资产投资项目全生命周期管理的全面“体检”。

## 二、审计思路和方法

审计人员以政府投资项目全生命周期管理为核心导向，结合《政府投资条例》等法规要求，针对项目储备管理、预算衔接与计划安排、工程建设管理、资金使用效益等审计重点，梳理形成相应的数据分析模型。

### （一）构建政府投资项目储备管理数据分析模型

政府投资项目实行储备制度，实施动态分类管理，未入库项目不得安排政府投资资金，对无法继续实施的项目应及时调出。审计人员从项目所处阶段、所属领域等维度分析储备项目的总量规模及动态变化情况，审查储备项目是否全面涵盖重大投资项目谋划储备领域，筛查未按规定进行储备管理的疑点项目。

1. **重大投资项目储备总量规模数据分析**

基于重大投资项目储备库，运用 SQL Server 数据库中的 COUNT 函数和 GROUP BY 子句从项目所处阶段、所属领域等维度统计储备项目总量，用 SUM 函数和 GROUP BY 子句汇总储备项目资金规模，对不同时间节点的储备数据进行分析，审查储备项目是否全面涵盖重大投资项目谋划储备领域。

2. **重大投资项目储备合规性数据分析**

基于重大投资项目储备库中的储备项目清单、出库项目清单及延伸调查标准表进行 JOIN 关联，通过 WHERE 子句筛查已列入政府投资计划未按照《重大投资项目储备管理办法》进行入库储备、出库管理的疑点项目。

经核查发现，被审计单位违规对个别未纳入重大投资项目储备库的项目安排政府投资计划；对调出重大投资项目储备库的两个项目未重新入库仍安排政府投资计划。

### （二）构建政府投资项目预算衔接及计划安排数据分析模型

应根据项目审批手续和工程建设进度，分批次安排政府投资，并与本级预算相衔接。经人大审议通过的年初批复项目全部列入当年投资计划。通过构建模型，审查政府投资计划是否与预算相衔接、是否合理安排等。

1. **政府投资计划与预算衔接数据分析**

基于政府投资计划数据、年初批复项目数据进行 JOIN 关联比对，生成二者资金对比表，审查政府投资计划是否与本级预算相衔接，筛查未按规定列入政府投资计划的疑点项目，用 WHERER 子句筛查年初批复项目是否纳入第一批投资计划并足额下达资金。

## 三、审计成效

审计中，通过运用 SQL、Python 等技术方法，推动疑点项目问题转化率大幅提升。通过延伸核查疑点项目，审计人员查实了问题。被审计单位积极整改，严格执行项目储备管理，推动政府投资计划与预算编制的有效衔接，督促项目单位提高成本管控水平，促进盘活存量资金。通过建立数据分析模型，可以推动部分常规审计事项管理更加系统化、标准化，实现从抽样核查向全量分析转变，显著提升审计精准度和效率。根据审计目标、审计重点的不同，完善数据分析模型，逐步实现对政府投资项目的全生命周期审计。
