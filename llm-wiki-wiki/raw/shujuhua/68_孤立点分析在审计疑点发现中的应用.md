## 核心思想

可疑数据往往是"孤立点"，隐藏在大量正常数据中。基于K-Means聚类的孤立点分析作为一种无监督方法，能自主发现审计疑点，兼顾海量数据总体分析，又作为审计经验补充。

## 分析步骤

1. **数据处理**：找到恰当的数据属性组合进行孤立点挖掘 → 数据清洗/集成/变换/归约
2. **孤立点检测**：通过模型区分正常与异常，可视化展示
3. **孤立点分析**：专业人员判断——异常≠问题，需结合函证法/复算法/审阅法等确认

## Python实现

### 数据预处理
```python
import pandas as pd
import numpy as np
from sklearn.cluster import KMeans

data = pd.ExcelFile('sales.xlsx', dtype='object')
data = data.parse('Sheet1', dtype='object')
data_zs = 1.0 * (data - data.mean()) / data.std()
```

### K-Means聚类 + 孤立点检测
```python
k = 5  # 聚类类别
threshold = 4.5  # 离散点阈值
model = KMeans(n_clusters=k, n_jobs=4, max_iter=10000)
model.fit(data_zs)

# 各簇到中心点的距离
r = pd.concat([data_zs, pd.Series(model.labels_, index=data.index)], axis=1)
norm = []
for i in range(k):
    norm_tmp = r[['数量','金额']][r['聚类类别']==i] - model.cluster_centers_[i]
    norm_tmp = norm_tmp.apply(np.linalg.norm, axis=1)
    norm.append(norm_tmp / norm_tmp.median())  # 相对距离
norm = pd.concat(norm)
discrete_points = norm[norm > threshold]  # 孤立点
```

## 案例验证

Y上市公司，12月20日虚构1000余件商品销售记录。K-Means聚类检测出4个孤立点：
- #7889 → 确认是背景案例中被发现的虚构销售（12月20日）
- #239 → 大额销售退回，可能是上年度虚构销售的本年冲销
- #3176 → 促销活动正常数据（假阳性）
- #4264 → 年末大额销售，需关注

**关键结论**：异常数据≠问题数据，算法结果仅作为参考缩小排查范围。"利用该方法分析出的异常数据未必都是问题数据，需要审计人员进一步分析排查。"
