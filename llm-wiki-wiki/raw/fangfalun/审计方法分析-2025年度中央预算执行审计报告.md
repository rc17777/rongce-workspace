# 审计方法分析：2025年度中央预算执行审计报告

> 来源：国务院《关于2025年度中央预算执行和其他财政收支的审计工作报告》
> 审计署审计长 侯凯，2026年6月23日提交全国人大常委会
> 分析日期：2026-06-24
> 分析者：融策右护卫

---

## 核心方法论总纲

本报告是**国家审计署最高层级审计成果**，其审计方法代表了当前财政审计的"天花板"标准。从报告中发现的问题反向推导，可以提炼出**8大审计领域、20+个审计方法模型**。

**总体审计逻辑**：

```
政策目标 → 制度设计 → 资金流转 → 执行结果 → 绩效产出
    ↑_________________________________________↓
              （逆向核查：结果偏离度）
```

即：从"党中央决策部署→财政资金安排→具体执行→民生获得感"全链条，反向核查每个环节是否出现**目标偏离、资金流失、权力寻租、绩效落空**四类问题。

## 一、财政收入审计方法

### 1.1 虚增财政收入审计

**审计目标**：核查是否存在"空转""调库"等虚增财政收入行为

**审计思路**：

```
[真实税源] → [征收行为] → [入库资金] → [财政报表]
    ↑                                    ↓
    └──── 是否存在"无源之水"？ ←─────────┘
```

**关键核查方法**：

| 核查点 | 数据来源 | 异常信号 |
|--------|----------|----------|
| 税收征收与税源匹配度 | 税务征收明细 + 企业纳税申报 | 征收额 > 应缴税额 |
| 国库资金调回 | 国库流水 + 财政专户往来 | 征收→入库→返还同一主体，闭环"空转" |
| 跨期调节 | 分月征收数据 + 年度预算缺口 | 年末突击征收、年初大量退库 |
| 违规开票 | 发票系统 + 银行流水 | 无真实交易的开票记录 |

**金额计算**：
- 虚增额 = 调回资金总额（21省市596.51亿元）
- 多征额 = 提前征收 + 超标准征收（404.27亿元）
- 偷逃额 = 违规开票 + 虚假出口（109.35亿元 + 4147万元）

**核心逻辑**：
> 财政收入的真实性 = 实际经济活动产生的税收 - 虚增部分（空转、调库） - 违规征收（多征、提前征） + 漏征部分（偷逃、漏缴）

---

### 1.2 偷逃税款审计

**审计方法**：交叉比对法

```
企业A申报收入  ──× 比对──  发票系统开票额
企业A出口数据  ──× 比对──  海关报关数据
企业A银行流水  ──× 比对──  申报收入
        ↓
    不一致 = 偷逃嫌疑
```

**关键数据**：
- 4976户企业违规开票，涉及109.35亿元
- 20户企业出口货物偷逃增值税4147万元

## 二、预算执行审计方法

### 2.1 零基预算执行审计

**审计目标**：核查零基预算改革试点是否真正落地

**审计逻辑**：

```
[零基预算要求] → 逐项审核必要性 → 取消无效项目
        ↓
[实际执行] → 沿用上年基数 → 项目继续存在
        ↓
[偏离度] = 未按零基审核的项目金额 / 试点部门预算总额
```

**发现**：9个试点部门10.73亿元未落实零基预算改革

**审计方法**：
1. 获取试点部门预算编制说明
2. 比对上年项目 vs 本年项目重合度
3. 检查是否有"预算编制论证记录"
4. 追踪取消/新增项目的审批痕迹

---

### 2.2 预算执行进度审计

**审计方法**：时间序列分析法

```
预算下达时间 ──→ 资金拨付时间 ──→ 实际支出时间
     │              │               │
     └──── 超进度安排？ ───→ 67.46亿元（国家发改委）
```

**异常信号**：
- 项目尚未启动，资金已全额拨付
- 预算批复时间早于项目立项时间
- 结转结余资金与超进度拨款并存

---

## 三、转移支付审计方法

### 3.1 转移支付清理整合审计

**审计方法**：清单比对法

```
国务院要求清理的转移支付项目清单
        ×
实际仍存在的转移支付项目清单
        ↓
    未清理项目 = 951.91亿元
```

**核查要点**：
1. 是否存在名称变更但实质未变的"换马甲"项目
2. 功能相近项目是否真正合并
3. 已完成政策目标的转移支付是否及时退出

---

### 3.2 转移支付区域政策落实审计

**审计方法**：地理围栏+政策匹配

```
[政策要求] → 特定区域（如革命老区、边疆地区）享受优惠
    ↓
[实际执行] → 分配系数是否体现区域倾斜？
    ↓
[偏离] = 245.79亿元未落实到特定区域
```

**关键核查**：
- 分配公式中是否包含区域系数
- 区域认定标准是否准确（如县级行政区划是否属于政策范围）
- 资金实际流向是否与政策目标区域一致

---

### 3.3 转移支付下达时效审计

**审计方法**：时间轴追踪法

```
法定下达时限 ──→ 实际下达日期 ──→ 资金到位日期
       │              │               │
       └──── 延迟天数 × 日均资金量 = 时间成本损失
```

**典型案例**：天津至潍坊高铁，超出时限185天，延迟下达19.44亿元

**审计要点**：
1. 获取《预算法》规定的各类转移支付法定时限
2. 从财政部系统提取每笔转移支付"制文日期""发文日期""地方收到日期"
3. 计算超期天数，按日均资金量计算机会成本
4. 追踪延迟对项目进度的实际影响

---

## 四、专项债券审计方法

### 4.1 专项债项目收益真实性审计

**审计方法**：收益测算穿透核查

```
项目申报收益测算
    ↓
[1] 收益来源是否真实存在？（如租金、收费、土地增值）
[2] 收益水平是否虚高？（与市场同类项目对比）
[3] 收益期限是否合理？（与项目生命周期匹配）
    ↓
    17县69个项目虚报收益121.74亿元
```

**关键核查手段**：
- 与周边同类项目收益水平横向对比
- 与市场公允价格纵向对比
- 实地核查收益来源资产是否存在（如土地是否已出让、收费权是否已质押）

---

### 4.2 专项债资金使用合规性审计

**审计方法**：资金流向追踪法

```
专项债资金 → 项目公司账户 → 实际用途
    ↓              ↓          ↓
 土地收储    偿还旧债    挪作他用
  93.17亿     28.33亿     其他
```

**核查要点**：
1. 资金是否专户管理
2. 支付对象是否与项目合同一致
3. 是否存在"以拨代支"（资金拨到项目单位即算支出，实际未使用）

---

### 4.3 专项债资产登记审计

**审计方法**：资产台账核查法

```
专项债形成的资产
    ↓
[1] 是否纳入政府资产台账？
[2] 资产权属是否清晰？（政府/平台/项目公司）
[3] 资产是否被重复抵押融资？
    ↓
    25县485个项目少登记资产663.75亿元
```

**核心逻辑**：专项债项目形成的资产是偿债的第一还款来源，资产不登记→偿债无保障→债务风险隐匿。

---

## 五、中央部门预算执行审计方法

### 5.1 依托行政资源谋利审计

**审计方法**：权力清单 vs 收费清单比对

```
行政职能（审批权、评审权、命名权）
    ↓
是否存在"搭车收费""署名费""让渡职能合作谋利"？
    ↓
    7部门16家单位搭车收费9201万元
    6部门13家单位收取署名费7894万元
```

**审计要点**：
1. 获取部门"行政权力清单"（行政许可、行政处罚、行政确认等）
2. 获取部门及所属单位全部收费项目（行政事业性收费、经营服务性收费、其他收入）
3. 交叉比对：收费项目是否依附于行政权力
4. 检查合作机构：是否存在"红顶中介"（与部门有隶属/关联关系的营利性机构）

---

### 5.2 公益性社会组织偏离定位审计

**审计方法**：章程宗旨 vs 实际行为比对

```
社会组织章程宗旨（公益、非营利）
    ×
实际经营行为（营利、收费、分红）
    ↓
    偏离度 = 营利收入 / 总收入
```

**发现**：
- 18家文化出版单位违反新闻宣传规定谋利3.84亿元
- 9家行业协会学会举办论坛不当获取收入2603万元

**核查要点**：
1. 查社会组织章程的"业务范围"和"非营利性"条款
2. 查实际收入结构（捐赠、政府购买服务、经营收入、会费比例）
3. 查关联交易（与主管部门、关联企业的交易）
4. 查"品牌授权""冠名权"等隐形收入

---

### 5.3 违反中央八项规定精神审计

**审计方法**：支出结构异常分析法

```
部门"三公"经费 + 会议费 + 培训费
    ↓
是否存在以下异常？
  - 巧立名目发奖金（如"评审费""辛苦费""项目奖"）
  - 超标准定制服装（工装、制服单价过高）
  - 违规租用办公用房（面积超标、闲置并存）
    ↓
    4部门47家单位不当支出6238万元
```

**关键核查手段**：
- 奖金发放名目与制度规定比对（是否有制度依据？）
- 服装采购标准与财政部规定比对（单价是否超标？）
- 办公用房面积与《党政机关办公用房建设标准》比对

---

## 六、重大政策落实审计方法

### 6.1 "两重""两新"工作审计

**审计方法**：全链条闭环核查

```
政策目标 → 资金安排 → 补贴发放 → 商家使用 → 消费者获益
    ↑                                              ↓
    └────── 是否形成闭环？是否达到目标？ ──────────┘
```

**发现**：
- 14省市8367商家刷单骗取补贴1.06亿元
- 12.92亿元被挤占挪用于弥补财力缺口

**审计方法**：
1. **补贴对象真实性**：交易记录 vs 银行流水 vs 物流单据（三单比对）
2. **补贴金额合理性**：补贴率是否在规定区间（如以旧换新补贴不超过售价的20%）
3. **政策目标达成度**：旧品回收量、新品销量、消费者满意度

---

### 6.2 城市地下管网重大项目审计

**审计方法**：工程量"三算"比对

```
项目概算（立项） → 施工图预算（招标） → 竣工结算（验收）
        ↓                ↓                  ↓
    118县"报大建小" = 概算 > 实际工程量
    47.72亿元资金被骗取套取
```

**关键核查手段**：
1. **报大建小**：设计图纸工程量 vs 实际施工工程量（现场测量）
2. **虚报进度**：形象进度报告 vs 监理日志 vs 实际现场
3. **质量问题**：材料进场验收记录 vs 检测报告 vs 实际材质

---

### 6.3 科技金融政策落实审计

**审计方法**：政策名实分离核查

```
政策名称（创新积分贷） → 实际执行（不看积分就放贷款）
    642.22亿元贷款未考虑积分

政策名称（知识产权质押贷） → 实际执行（已提供传统抵押物）
    101.09亿元已足额提供传统抵押物

政策名称（科技企业并购贷） → 实际执行（实为股权回购）
    54.37亿元实为股权回购
```

**核心逻辑**："政策套利"——利用政策名称获取低成本资金，实际不执行政策要求。

**审计方法**：
1. 获取政策文件规定的"准入条件"
2. 获取银行放贷台账（含贷款类型标注）
3. 逐笔比对：贷款是否满足准入条件？
4. 与纯商业贷款利率对比：是否存在因政策标签获得的利率优惠？

---

### 6.4 地方政府债务风险审计

**审计方法**："三化"风险识别模型

```
[1] 平台公司虚假退出
    退出条件：政府不再承担偿债责任、不再注入资产
    实际：9家平台不符合条件即退出

[2] 违规举债（绕道国企）
    15县通过国企举债41.97亿元
    核查：国企融资是否用于政府项目？还款来源是否财政资金？

[3] 虚假化债（数字游戏）
    4省通过国企贷款或系统删除66.82亿元
    核查：债务是否真实偿还？还是"新债还旧债"或"系统删除"？
```

**核心逻辑**：地方政府债务风险的审计不是"看数字"，而是"看实质"——债务是否真正偿还、偿还资金来源是否可持续、是否存在隐性债务转移。

## 七、民生资金审计方法

### 7.1 保障性安居工程审计

**审计方法**：供需匹配度分析

```
[供给侧] 住房存量 + 新建量
    ×
[需求侧] 应保人群（低保、低收入、新市民）
    ↓
    结构性失衡：成都2.35万套闲置，万人未保障
```

**关键核查**：
- 保障性住房位置 vs 需求人群就业分布（通勤距离）
- 户型结构 vs 家庭人口结构匹配度
- 入住率 vs 轮候名单等待时间
- 租金水平 vs 目标人群收入承受能力

---

### 7.2 工伤保险应保未保审计

**审计方法**：参保人群比对法

```
[应保人群] = 劳动关系 + 工伤风险
    ×
[实保人群] = 社保系统参保记录
    ↓
    未保人群 = 226万名农民工，涉及25.3亿元
```

**核查要点**：
1. 劳动关系：劳动合同 + 工资发放 + 考勤记录
2. 社保系统：参保名单 + 缴费基数 + 缴费比例
3. 未保人群识别：在劳动关系中但不在社保系统中
4. 降档参保：按低标准参保（如按"灵活就业"而非"职工"参保）

---

### 7.3 中药产销审计

**审计方法**：成本结构异常分析法

```
中药材采购成本
    ↓
[1] 虚增采购成本：伪造农户身份、虚构种植合同 → 22.81亿元
[2] 虚列销售费用：无真实业务支付第三方 → 22.5亿元
[3] 带金销售：套取资金用于商业贿赂 → 42.5亿元
```

**核心逻辑**：
> 中药成本 = 真实种植成本 + 虚增部分（虚假采购）
> 中药利润 = 正常销售利润 + 带金销售（回扣） + 虚列费用（洗钱）

**核查方法**：
1. 采购端：中药材产地溯源（GPS坐标、种植合同真伪）
2. 销售端：终端售价 vs 出厂价价差（是否存在异常高价→高回扣空间）
3. 费用端：销售费用率与行业均值对比（中药行业正常销售费用率15-20%，超过则异常）

---

### 7.4 强农惠农资金审计

**审计方法**："五联"核查法

```
[1] 联农带农：项目是否真正带动农民增收？
    175县1631个项目115.83亿元联农带农措施缺失

[2] 项目属性：是否偏离"土特产"定位？
    749个项目"不土、不特、不产"

[3] 资金分配：是否存在"平均主义"或"精英俘获"？
    51.73亿元分配不严，29.57亿元被骗取浪费

[4] 截留挪用：是否被用于还债、国企经营？
    56县279.48亿元被截留挪用

[5] 涉农贷款：是否包装非农项目套取贷款？
    28县270.56亿元包装非农项目
```

**核心逻辑**：
> 强农惠农资金审计 = 资金流向（是否到农民手里） + 项目效果（是否增加农民收入） + 风险控制（是否存在涉众风险）

## 八、国有资产审计方法

### 8.1 企业国有资产审计

**审计方法**："四表"勾稽分析法

```
资产负债表 ←── 虚增资产922.71亿、虚增负债1459.37亿
利润表     ←── 收入不实34.69亿
现金流量表 ←── 178.53亿元资金闲置
所有者权益变动表 ←── 权益虚增2325.52亿
    ↓
    7户央企会计信息严重不实
```

**核心逻辑**：
> 会计信息真实性 = 资产真实性 + 负债完整性 + 收入准确性 + 费用合理性
> 虚增资产 = 虚增负债 + 虚增权益（会计恒等式：资产 = 负债 + 权益）

**核查方法**：
1. **资产虚增**：固定资产实地盘点（存在性）、应收账款函证（真实性）、存货计价测试（准确性）
2. **负债低估**：银行借款全面函证（完整性）、或有负债审查（未决诉讼、担保）
3. **收入不实**：收入确认时点 vs 合同条款、收入与现金流匹配度

---

### 8.2 金融企业国有资产审计

**审计方法**：监管指标穿透核查

```
[存贷款虚增] 1.41万亿元（3户金融企业）
    → 核查：月末、季末冲时点 → 次月初转回

[债券业务虚增] 7569.59亿元
    → 核查：是否真实交易？是否跨境循环？

[掩盖不良资产] 634.41亿元
    → 核查：设置宽限期、下调利率、展期重组
        → 是否实质改变风险分类？
```

**关键监管指标**：
- 不良贷款率：是否通过展期、重组将"不良"调成"关注"？
- 存贷比：是否通过同业存款虚增存款？
- 资本充足率：是否通过结构化设计将风险加权资产出表？

---

### 8.3 行政事业性国有资产审计

**审计方法**：实物盘点 + 系统台账比对

```
[实物资产] 房产、土地、设备、专利
    ×
[财务台账] 资产管理系统、财务账
    ×
[使用状态] 自用、出租、出借、闲置、报废
    ↓
    未入账：1.24万㎡房产、30.15亩土地、1118项专利
    闲置：11.92万㎡房产、53.54亩土地、1.29亿元设备
    违规出租：7.27万㎡房产、27.33亩土地
```

**核查方法**：
1. 实物盘点：GPS定位房产、土地；拍照记录设备
2. 产权核查：房产证、土地证、专利证书是否齐全
3. 使用状态：现场查看是否实际使用、是否存在出租出借未入账

---

### 8.4 国有自然资源资产审计

**审计方法**：遥感监测 + 现场核查

```
[生态治理项目] 湿地保护、生态修复、污染治理
    ↓
[效果核查] 遥感影像对比（治理前后）+ 现场采样 + 环境监测数据
    ↓
    [1] 治理效果：安置房仅完成3期，搬迁不足
    [2] 数据真实性：人为干扰空气质量监测数据
    [3] 生态风险：21个化工园区缺失污水处理设施
    [4] 资源冲突：102户矿企违规占用保护区耕地林地2188.4亩
```

**核心逻辑**：
> 自然资源资产审计 = 数量核查（遥感/测量） + 质量核查（监测/采样） + 权属核查（确权登记） + 效益核查（生态服务价值评估）

## 九、审计方法总结：通用模型

### 9.1 "五维"审计分析框架

从本报告可以提炼出适用于各类财政审计的"五维"框架：

```
维度1：真实性（有没有虚增/隐瞒）
    → 财政收入、支出、资产、负债

维度2：合规性（是否违反制度）
    → 预算法、政府采购法、招投标法、八项规定

维度3：效率性（钱花得值不值）
    → 闲置资金、低效投资、重复建设

维度4：公平性（钱分到谁手里）
    → 转移支付区域倾斜、民生资金到人到户

维度5：安全性（风险控没控住）
    → 债务风险、金融风险、资产流失风险
```

### 9.2 "逆向"审计逻辑

```
[结果] 发现异常（如资金闲置、资产虚增）
    ↓
[追溯] 1. 资金来源（哪笔预算？谁批的？）
          2. 资金流转（经过哪些账户？谁经手的？）
          3. 资金用途（实际用在哪？有无凭证？）
          4. 绩效产出（达到什么效果？有无评估？）
    ↓
[责任] 谁决策？谁执行？谁受益？
```

### 9.3 数据审计"四比"法

```
[1] 纵向比：本期 vs 上期 vs 历史均值（趋势异常）
[2] 横向比：同类地区/同类单位/同类项目（同业异常）
[3] 结构比：组成结构 vs 标准结构（构成异常）
[4] 关联比：不同数据集之间的逻辑关系（勾稽异常）
```

## 十、对融策业务的启示

### 10.1 可直接借鉴的审计方向

| 报告领域 | 融策对应业务 | 可借鉴方法 |
|----------|------------|-----------|
| 专项债券审计 | 专项债申报、财政评审 | 收益测算穿透、资产台账核查、资金使用追踪 |
| 转移支付审计 | 预算执行审计、绩效评价 | 下达时效追踪、区域政策匹配、清理整合核查 |
| 民生资金审计 | 社保审计、农业审计、教育审计 | 应保未保比对、联农带农核查、资金流向追踪 |
| 国有资产审计 | 资产清查、国企审计 | 实物盘点、系统比对、产权核查 |
| 地方政府债务 | 债务风险审计 | 平台退出核查、违规举债识别、虚假化债检测 |
| 工程审计 | 全过程工程咨询、工程结算 | 工程量三算比对、进度虚报核查、质量检测 |

### 10.2 对融策的警示

> 审计署能查出中央层面的问题（虚增收入、违规举债、资金闲置），地方审计只会更严格。融策在承接政府审计项目时，应提前做好"自查自纠"，避免客户被审计署"点名"。
