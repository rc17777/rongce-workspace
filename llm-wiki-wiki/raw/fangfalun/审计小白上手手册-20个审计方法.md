> 来源：2025年度中央预算执行审计报告（审计署）

## 写在前面：什么是审计？一句话说清

**审计 = 看看钱应该去哪 → 实际去了哪 → 有没有被截胡**

就这么简单。不要想复杂了。下面的每个方法，都是围绕这个逻辑展开的具体查法。

---

## 准备工作：每次审计前先干这三件事

### 第一步：搞清楚"钱从哪来、到哪去"

画一张简单的图：

```
[预算] → [拨款] → [项目/单位] → [实际花出去] → [效果]
   ↑        ↑           ↑              ↑           ↑
 应该      实际       经手人        花在哪      花得值不值
```

审计就是逐层检查"应该"和"实际"是否一致。

### 第二步：准备三个工具

| 工具 | 用途 | 哪里搞 |
|------|------|--------|
| Excel | 数据比对、筛选、透视表 | 电脑上就有 |
| Python（可选） | 数据量大时自动化处理 | 装Anaconda，一键搞定 |
| 手机拍照 | 现场核查时留证据 | 手机自带 |

**小白建议**：先用Excel，能处理80%的场景。Excel搞不定的再学Python。

### 第三步：建立"数据清单"

每做一个审计项目，先把需要的数据列出来：

```
□ 预算文件（哪笔钱、多少钱、干什么用）
□ 拨款记录（什么时候拨的、拨给谁了）
□ 银行流水（钱实际怎么花的）
□ 项目台账（干了什么活、什么时候干的）
□ 合同/发票（花钱的凭证）
□ 验收报告（活干完了没有、质量如何）
□ 现场照片（亲眼看看）
```

**没有数据清单就进场 = 瞎子摸象**，先列清单，再一项项去要。

## 第一部分：财政收入审计（2个方法）

### 方法1：查"虚增财政收入"（钱是不是自己画出来的）

#### 啥叫虚增财政收入？

政府为了完成税收任务，让企业先把钱交进来（交税），然后马上通过各种名义把钱退回去（返还/补贴）。**钱转了一圈，账面上税收增加了，实际上一分钱没增加**。这叫"空转"。

#### 为什么要查？

虚增的财政收入会导致上级对地方财政实力误判，影响转移支付分配。简单说：**吹的泡泡越大，爆的时候越惨**。

#### 怎么查？三步走

**步骤1：找"同一天进又同一天出"的钱**

打开国库流水（或财政专户流水），按日期排序，找这种记录：

```
日期        收入/支出    金额      对方单位
2025-12-28  收入        1000万    A企业（缴税款）
2025-12-28  支出         980万    A企业（产业发展补贴）
```

**异常信号**：同一天，同一家企业，先进来1000万，又出去980万。

**Excel操作**：
1. 把国库流水导出为Excel
2. 按"日期+对方单位"排序
3. 筛选同一天、同一家单位既有"收入"又有"支出"的记录
4. 用条件格式把这类记录标红

**步骤2：算"空转率"**

```
空转金额 = 同一天同一家单位收入≈支出的金额
空转率 = 空转金额 / 当月总收入
```

**判断标准**：
- 空转率 > 5% → 黄灯（有问题苗头）
- 空转率 > 10% → 红灯（严重虚增）

**步骤3：追踪"退库"理由**

对找到的空转记录，查看支出用途：
- 如果是"税收返还""产业发展补贴""企业扶持资金" → 高度怀疑空转
- 如果是正常的政府采购付款、工程结算 → 可能是正常业务

**怎么核实**：
1. 找这笔支出的审批文件
2. 看有没有真实的业务合同支撑
3. 问财务人员："这笔钱退回去的原因是什么？"

#### 实操案例（审计报告中的数据）

> 21个省市虚增财政收入596.51亿元。
>
> 查法：找出这些省市2025年12月的国库流水，筛选"收入-支出"同一天闭环的记录，金额就是虚增的部分。

#### 常见问题

**Q：国库流水拿不到怎么办？**
A：这是政府内部数据，审计机关可以调取。如果是外部审计，可以从以下侧面验证：
- 对比税务局公布的税收收入和当地GDP增速（税收增速远高于GDP增速 = 异常）
- 对比企业纳税申报和实际经营情况（企业没赚钱但交了很多税 = 异常）

**Q：空转和正常的税收返还怎么区分？**
A：看"时间差"。正常的税收返还有政策依据、有固定周期（如季度返还、年度结算）。空转的特点是：**今天收明天退，或者月底收月初退，没有政策依据**。

### 方法2：查"偷逃税款"（企业该交的税没交）

#### 为啥要查？

企业偷逃税款 = 国家损失财政收入。常见手法：
- 开假发票（没有真实交易，但开了发票抵扣税款）
- 隐瞒收入（收了钱不入账，不交税）
- 虚假出口（伪造出口单据，骗取出口退税）

#### 怎么查？三步走

**步骤1：发票比对（三单比对）**

需要三个数据源：

```
[企业申报的收入]    ×    [发票系统开票金额]    ×    [银行流水收入]
       ↓                      ↓                        ↓
   如果三个数不一致     →    企业要么少报了收入，要么多开了发票
```

**Excel操作**：
1. 把三个数据源整理成三张表
2. 按"企业名称+月份"做VLOOKUP匹配
3. 计算差异：差异 = 银行流水收入 - 申报收入
4. 差异 > 10% → 标记异常

**步骤2：异常发票识别**

什么样的发票有问题？

| 异常特征 | 说明 | 怎么查 |
|---------|------|--------|
| 同一买家短期内大量采购 | 正常企业不会突然大量采购 | 筛选同一买家30天内发票金额 > 月均5倍 |
| 发票金额都是整数 | 真实交易很少是整数 | 筛选金额末尾为"000"或"00"的发票占比 |
| 开票时间集中在月末 | 月底冲业绩、虚增收入 | 统计每月25-31日的发票金额占比 |
| 购销双方地址相近 | 可能是关联公司互相开票 | 比对发票上的购销双方地址 |

**步骤3：出口骗税核查**

出口骗税的典型手法：
- 伪造出口报关单（货物没出国，但报了出口）
- 低值高报（价值100元的货物报1000元，多退税款）
- 循环出口（同一批货物反复报关出口，反复退税）

**怎么查**：
1. 获取海关出口数据（出口报关单）
2. 获取税务退税数据（出口退税申请）
3. 比对：出口报关单上的货物 → 是否真实运出？（查物流记录）
4. 比对：同一批货物是否多次报关？（查集装箱号、船名航次）

#### 实操案例

> 4976户企业违规开票，涉及109.35亿元。
>
> 查法：从发票系统导出这4976户企业的全部发票，统计"整数金额占比""月末开票占比""同一买家集中度"，三项指标都异常的 = 重点核查对象。

#### 小白提示

**Excel筛选发票异常的快捷公式**：

```excel
=IF(AND(发票金额/100=INT(发票金额/100), 开票日期>=DATE(2025,12,25)), "异常", "正常")
```

这个公式的意思是：如果发票金额是100的整数倍，且开票日期在12月25日之后，标记为"异常"。

## 第二部分：预算执行审计（2个方法）

### 方法3：查"零基预算有没有真落实"

#### 啥叫零基预算？

传统的预算编制："去年花了100万，今年也要100万，稍微涨一点"。

零基预算："今年的每一项支出，都要重新论证：这笔钱必须花吗？花多少合理？"

**零基预算没落实 = 该砍的项目没砍，该优化的没优化**。

#### 怎么查？三步走

**步骤1：拿两年的预算项目清单**

向被审计单位要：
- 2024年预算项目清单（项目名称、金额、用途）
- 2025年预算项目清单（项目名称、金额、用途）

**步骤2：比对"重合度"**

```
重合项目 = 2024年有、2025年也有的项目
重合度 = 重合项目金额 / 2025年总预算金额
```

**判断标准**：
- 重合度 > 80% → 零基预算没落实（几乎照搬上年）
- 重合度 60-80% → 部分落实（有一些新项目）
- 重合度 < 60% → 基本落实（大量项目重新论证）

**Excel操作**：
1. 把两年项目清单放在Excel的两张表里
2. 用VLOOKUP或COUNTIF匹配项目名称
3. 统计匹配上的项目金额和总金额

**步骤3：抽查"新论证痕迹"**

对2025年保留的2024年项目，抽查3-5个：
- 有没有重新论证的报告？（论证必要性、金额合理性）
- 论证报告有没有领导审批签字？
- 论证结论是不是"建议继续保留"？（如果所有项目都是"建议保留" = 走形式）

#### 实操案例

> 9个试点部门10.73亿元未落实零基预算改革。
>
> 查法：把这9个部门2024、2025年预算项目清单导出，计算重合度。发现重合度 > 90% = 没做零基预算。再抽查5个项目，发现没有重新论证报告 = 确认没落实。

#### 常见问题

**Q：零基预算和正常的预算延续怎么区分？**
A：看"论证痕迹"。正常的延续项目也有论证，但论证结论是"经评估，该项目仍有必要，金额合理"。零基预算没落实的表现是：**没有论证，直接复制上年数据**。

### 方法4：查"超进度拨款"（钱还没干活就先给了）

#### 啥叫超进度拨款？

项目还没启动，或者刚开始干，钱就拨过去了。结果是：钱躺在账上，或者被挪用了。

#### 怎么查？三步走

**步骤1：建立时间轴**

对每一笔资金，记录三个时间点：

```
时间轴：
 预算批复日 ───→ 拨款日 ───→ 项目启动日 ───→ 验收日
   2025-3-15     2025-4-1      2025-8-1        2026-6-30
```

**步骤2：识别"超进度"**

```
超进度 = 拨款日 < 项目启动日
或者 = 拨款金额 / 项目总预算 > 实际完成进度
```

**举例**：
- 项目总预算1000万，合同约定分三期付款：开工30%、中期30%、验收40%
- 但第一期款就拨了500万（50%）
- 实际项目还没开工
→ 超进度拨款

**Excel操作**：
1. 建立三列：预算批复日、拨款日、项目启动日
2. 计算：拨款日 - 项目启动日
3. 如果结果 < 0（拨款日更早）→ 标记超进度

**步骤3：追踪"钱去哪了"**

对超进度拨款的记录，查银行流水：
- 钱拨到项目单位后，多久被转走？
- 转给谁了？用途是什么？
- 如果是"偿还旧债""其他项目支出" → 挪用

#### 实操案例

> 国家发改委超进度安排中央预算内投资67.46亿元。
>
> 查法：把发改委2025年的全部拨款记录导出，逐笔比对拨款日和项目启动日。发现67.46亿元在项目启动前已拨付。

## 第三部分：转移支付审计（3个方法）

### 方法5：查"转移支付清理整合"（该取消的项目还在给钱）

#### 背景

国务院要求清理整合功能重复的转移支付项目，但实际操作中，很多项目"换了个名字继续存在"。

#### 怎么查？三步走

**步骤1：找"清理清单"**

从国务院文件中找到要求清理的转移支付项目清单。通常在以下文件中：
- 《国务院关于改革和完善中央对地方转移支付制度的意见》
- 年度预算执行报告中的"清理整合"部分
- 财政部的清理整合通知

**步骤2：对比"实际存在的项目"**

从财政系统中导出当前实际存在的转移支付项目清单，与清理清单比对：

```
清理清单要求取消的项目：A项目、B项目、C项目
实际存在的项目：A项目（ renamed to A1项目）、B项目、D项目

→ A项目换了个名字继续存在
→ B项目没清理
```

**Excel操作**：
1. 清理清单放A列，实际项目清单放B列
2. 用VLOOKUP匹配，看A列的项目在B列是否存在（或改名后存在）
3. 对匹配不上的，用Fuzzy Lookup（模糊匹配）识别改名项目

**步骤3：追踪"改名项目"的资金**

对发现"换马甲"的项目，查：
- 改名前后的资金用途是否一致？（如果一样 = 没真正整合）
- 资金分配对象是否一样？（如果一样 = 换汤不换药）

#### 实操案例

> 5项转移支付951.91亿元清理整合不到位。
>
> 查法：把国务院清理要求和实际转移支付项目清单做比对，发现5个项目改了名字但继续存在，资金用途未变，涉及951.91亿元。

### 方法6：查"转移支付区域政策落实"（该给穷地方的钱给了富地方）

#### 背景

很多转移支付有区域倾斜政策，比如"革命老区""边疆地区""民族地区"享受额外补助。但实际操作中，资金分配可能没有体现区域倾斜。

#### 怎么查？三步走

**步骤1：搞清楚"政策要求"**

从政策文件中找到：
- 哪些区域应该享受倾斜？（如国家级贫困县、革命老区县）
- 倾斜的比例是多少？（如基础金额+20%）

**步骤2：获取实际分配数据**

从财政系统中导出：
- 每个转移支付项目的资金分配明细
- 分配到的县/市名称
- 分配金额

**步骤3：比对"区域属性"**

```
应该享受倾斜的县：A县（贫困县）、B县（革命老区）
实际分配：
  A县：1000万（按政策应该是1200万，少了200万）
  C县（非贫困县）：800万（按政策不应该有额外补助，但给了）
```

**Excel操作**：
1. 建立"区域属性表"：县名 → 是否贫困县/革命老区/边疆县
2. 把资金分配表和区域属性表做VLOOKUP匹配
3. 计算：每个县实际分配 / 应该分配 = 偏离度
4. 偏离度 < 0.8 或 > 1.2 → 标记异常

#### 实操案例

> 6项转移支付245.79亿元未落实到特定区域。
>
> 查法：获取6项转移支付的分配明细，比对每个县的"区域属性"（是否属于政策规定的倾斜区域），发现245.79亿元分配给了不该给的地区，或少给了该给的地区。

### 方法7：查"转移支付下达时效"（钱该几时到、实际几时到）

#### 背景

《预算法》规定了转移支付必须在多少天内下达，但实际操作中经常拖延。拖延的后果：地方等钱下锅，项目进度滞后。

#### 怎么查？三步走

**步骤1：搞清楚"法定时限"**

不同类型的转移支付有不同的法定时限：

| 转移支付类型 | 法定时限 | 依据 |
|-------------|---------|------|
| 一般性转移支付 | 全国人大批准后30日内 | 《预算法》第52条 |
| 专项转移支付 | 全国人大批准后90日内 | 《预算法》第52条 |
| 救灾应急资金 | 接到通知后即时下达 | 特殊规定 |

**步骤2：记录"实际时间"**

从财政系统中提取：
- 预算批复日期（全国人大批准日期）
- 财政部制文日期（起草文件的日期）
- 财政部发文日期（正式发出文件的日期）
- 地方收到日期（地方财政确认收到的日期）

**步骤3：计算"延迟天数"**

```
延迟天数 = 实际下达日期 - 法定最迟下达日期
```

**判断标准**：
- 延迟 < 10天 → 可接受（流程正常耗时）
- 延迟 10-30天 → 偏慢（需要关注）
- 延迟 > 30天 → 严重拖延（影响项目进度）
- 延迟 > 90天 → 重大违规（严重影响项目执行）

**Excel操作**：
1. 建立三列：法定最迟日期、实际发文日期、实际收到日期
2. 计算两列延迟天数
3. 用条件格式：延迟 > 30天标红

**步骤4：追踪延迟的影响**

对延迟严重的记录，问：
- 这笔钱原计划用于什么项目？
- 项目因为等钱延误了多少天？
- 延误造成了什么后果？（如工程停工、农民工工资拖欠）

#### 实操案例

> 天津至潍坊高铁延迟下达19.44亿元，超出时限185天。
>
> 查法：获取这笔转移支付的法定时限（90天）、实际制文日期、实际收到日期。计算延迟天数 = 185天。再查项目进度：因为等钱，工程停工X天，增加成本X万元。

## 第四部分：专项债券审计（3个方法）

### 方法8：查"专项债项目收益真实性"（项目说的能赚钱，真能赚吗）

#### 背景

专项债券要求项目有"收益"，能还本付息。但实际操作中，很多项目虚报收益，把没有收益的项目包装成有收益，从而骗取专项债资金。

#### 怎么查？三步走

**步骤1：获取"项目收益测算表"**

从专项债申报文件中获取：
- 项目收益来源（如租金、收费、土地增值）
- 预计收益金额（每年多少）
- 收益测算依据（周边同类项目数据、市场调查）

**步骤2：验证收益来源的真实性**

| 收益类型 | 验证方法 | 需要的数据 |
|---------|---------|-----------|
| 租金收入 | 查周边同类房产租金水平 | 房产中介网站、租金指导价 |
| 收费收入 | 查收费标准和预期客流量 | 同类项目实际收费数据 |
| 土地增值 | 查土地出让记录和周边地价 | 国土局土地出让公告 |
| 项目自身收益 | 查项目可行性研究报告 | 市场调查数据、财务预测模型 |

**实操做法**：
1. 如果项目说"建成后年租金收入1000万"
2. 去查周边类似房产的实际租金：每平米每月X元
3. 计算：项目面积 × 周边租金 × 12个月 = 实际可能的租金收入
4. 如果实际计算 = 500万，但申报说1000万 → 虚报收益50%

**步骤3：实地核查收益来源资产**

对申报中的收益来源，实地看看是否存在：
- 说"土地增值" → 土地是否已经出让？有没有被抵押？
- 说"租金收入" → 房产是否已经建成？有没有租出去？
- 说"收费收入" → 收费设施是否已建？收费标准是否获批？

#### 实操案例

> 17县69个项目虚报收益121.74亿元。
>
> 查法：对每个项目，获取申报收益测算表，逐项验证收益来源的真实性。发现项目A说"土地增值收益10亿元"，但土地尚未出让且已被抵押 → 收益不存在。

#### 计算公式

```
收益虚报率 = (申报收益 - 实际验证收益) / 申报收益 × 100%

收益虚报率 > 30% → 严重虚报
收益虚报率 > 10% → 存在虚报
收益虚报率 < 10% → 测算偏差，可接受
```

### 方法9：查"专项债资金使用合规性"（钱有没有用到该用的地方）

#### 背景

专项债资金有明确用途（如修高铁、建医院），但经常被挪用于其他用途（如还债、发工资、搞开发）。

#### 怎么查？三步走

**步骤1：获取"资金用途清单"**

从专项债批复文件中获取：
- 资金应使用的项目
- 资金应使用的范围（如土建、设备采购、不可预见费）
- 资金禁止使用的范围（如土地收储、偿还旧债、日常运营）

**步骤2：追踪资金流向**

获取项目单位的银行流水，追踪每一笔专项债资金的用途：

```
专项债资金 → 项目公司账户 → 支付给谁？→ 用途是什么？
```

**Excel操作**：
1. 筛选银行流水中"来源 = 专项债资金"的记录
2. 对每一笔支出，记录：对方单位、用途、金额
3. 与"应使用范围"比对，超出范围的标记异常

**步骤3：识别典型违规用途**

| 违规用途 | 特征 | 怎么识别 |
|---------|------|---------|
| 土地收储 | 支付给国土局/土地储备中心 | 对方单位名称含"土储""国土" |
| 偿还旧债 | 支付给银行/信托公司 | 用途备注"还款""本金" |
| 挪作他用 | 支付给与项目无关的单位 | 对方单位与项目无关 |
| 以拨代支 | 钱拨到项目单位即算支出，实际未使用 | 钱在账上躺了半年以上 |

**"以拨代支"识别方法**：
1. 查看专项债资金到账日期
2. 查看第一笔支出日期
3. 如果间隔 > 6个月 → 疑似以拨代支
4. 如果到账后余额长期未动 → 确认以拨代支

#### 实操案例

> 4县违规使用专项债资金93.17亿元用于土地收储。
>
> 查法：获取这4县专项债资金的银行流水，筛选支付给"土地储备中心""国土局"的记录，金额合计93.17亿元。

### 方法10：查"专项债形成的资产"（修了东西，东西算谁的）

#### 背景

专项债项目会形成资产（如高铁、医院、桥梁）。这些资产是还债的"底气"——资产在，还不了债可以卖资产。但如果资产没登记、权属不清，债务就悬空了。

#### 怎么查？三步走

**步骤1：获取"应形成资产清单"**

从项目可研报告和竣工决算中获取：
- 项目应该形成什么资产？（如高铁线路、车站、设备）
- 资产价值多少？
- 资产位置在哪？

**步骤2：查资产台账**

从政府资产管理系统/项目单位财务账中获取：
- 这些资产是否已入账？
- 资产编号是什么？
- 资产分类是什么？（固定资产/无形资产/公共基础设施）

**比对方法**：
```
应形成资产：高铁线路100公里、车站5座、设备价值10亿
实际入账资产：高铁线路0公里、车站3座、设备价值5亿
→ 少登记资产：高铁线路未入账、2座车站未入账、设备少记5亿
```

**步骤3：查权属和抵押**

对入账的资产，进一步查：
- 资产权属归谁？（政府/项目公司/其他单位）
- 资产是否被抵押？（如果已抵押，再次抵押 = 重复抵押）
- 资产是否被占用？（如被其他单位无偿使用）

#### 实操案例

> 25县485个项目少登记资产663.75亿元。
>
> 查法：获取25县专项债项目的"应形成资产清单"和"实际资产台账"，比对差异。发现大量高铁、桥梁、医院未入账，涉及663.75亿元。

## 第五部分：中央部门预算执行审计（3个方法）

### 方法11：查"依托行政权力谋利"（审批权变成摇钱树）

#### 背景

政府部门有审批权、评审权、命名权，有些部门利用这些权力"搭车收费"：
- 你不交"评审费"，我不给你审批
- 你不交"署名费"，我不让你挂名
- 我搞个"合作机构"，把审批职能让渡给它，它收费我分成

#### 怎么查？三步走

**步骤1：获取"行政权力清单"**

从政府部门网站或编办获取：
- 该部门有哪些行政审批权？（如项目审批、资质认定、奖项评选）
- 哪些行政事业性收费是合法的？（如工本费、考试费）

**步骤2：获取"全部收费清单"**

从部门及所属单位的财务账中获取所有收入：
- 行政事业性收费（合法的）
- 经营服务性收费（市场化的）
- 其他收入（如培训费、评审费、咨询费）

**步骤3：交叉比对"权力依附性"**

```
收费项目：XX项目评审费
对应的权力：XX项目审批权
→ 如果不交评审费，就不给审批 → 权力依附性收费
```

**识别"红顶中介"**：
- 查收费单位的股权结构：是否与政府部门有隶属关系？
- 查收费单位的业务来源：是否主要来自该部门的"转介"？
- 查收费单位的资金流向：是否回流到政府部门？

#### 实操案例

> 7部门16家单位搭车收费9201万元，6部门13家单位收取署名费7894万元。
>
> 查法：获取7部门的行政权力清单和全部收费清单，比对"收费项目是否与行政权力挂钩"。发现"项目审批权"对应"项目评审费"、"资质认定权"对应"资质培训费"，存在依附关系。

---

### 方法12：查"社会组织偏离公益定位"（非营利组织在赚钱）

#### 背景

行业协会、基金会、文化单位等社会组织应该是"非营利""公益性"的。但实际操作中，有些社会组织在赚钱：
- 举办论坛收高额赞助费
- 搞评选、发证书收费
- 挪用捐赠资金

#### 怎么查？三步走

**步骤1：查"章程宗旨"**

从社会组织登记机关（民政局）获取：
- 组织章程中的"业务范围"
- "非营利性"条款
- 是否以"公益"为宗旨

**步骤2：查"收入结构"**

从社会组织的财务报告中获取：
- 会费收入（正常的）
- 捐赠收入（正常的）
- 政府购买服务收入（正常的）
- 经营服务收入（需要关注）
- 其他收入（需要关注）

**计算"营利偏离度"**：
```
营利偏离度 = (经营服务收入 + 其他收入) / 总收入 × 100%

偏离度 > 50% → 严重偏离公益定位
偏离度 > 30% → 存在偏离
偏离度 < 30% → 基本正常
```

**步骤3：查"关联交易"**

- 社会组织是否与主管部门有业务往来？（如主管部门把培训业务交给它做）
- 社会组织是否与领导亲属有关联？（查法人、理事的亲属关系）
- 社会组织是否把品牌/冠名权"授权"给营利性公司使用？

#### 实操案例

> 18家文化出版单位违反新闻宣传规定谋利3.84亿元，9家行业协会举办论坛不当获取收入2603万元。
>
> 查法：获取18家单位的财务报告，统计"经营收入占比"，发现超过50%。再查"关联交易"，发现主管部门把培训业务全部交给该单位做，涉嫌利益输送。

### 方法13：查"违反八项规定"（巧立名目发钱、超标消费）

#### 背景

中央八项规定要求厉行节约，但实际操作中常见：
- 巧立名目发奖金（"评审费""辛苦费""项目奖"）
- 超标准定制服装（工装单价过高）
- 违规租用办公用房（面积超标、闲置并存）

#### 怎么查？三步走

**步骤1：查奖金发放的"名目"**

从财务账中获取奖金发放记录：
- 发放名目是什么？（如"评审费""项目奖""绩效奖"）
- 发放标准是多少？（每人每次多少）
- 发放依据是什么？（制度文件？领导批示？）

**识别违规奖金**：
- 名目不在制度规定范围内 → 违规
- 发放标准高于制度规定 → 超标
- 没有领导审批签字 → 程序违规
- 发给不该发的人（如退休人员、编外人员） → 对象违规

**步骤2：查服装采购标准**

从采购记录中获取：
- 服装类型（工装、制服、防寒服）
- 单价（每套多少）
- 数量（做了多少套）
- 供应商

**与标准比对**：
```
财政部规定：一般工装单价不超过800元/套
实际采购：单价1500元/套
→ 超标87.5%
```

**步骤3：查办公用房面积**

实地测量 + 查租赁合同：
- 每个领导的办公室面积多少？
- 与《党政机关办公用房建设标准》比对：
  - 正部级：≤54㎡
  - 副部级：≤42㎡
  - 正处级：≤18㎡
  - 副处级：≤12㎡
  - 科级：≤9㎡

**同时查"闲置并存"**：
- 本单位有没有闲置房产？（面积、位置）
- 同时有没有租用外部房产？（租金、面积）
- 如果"有闲置还租外面" → 浪费财政资金

#### 实操案例

> 自然资源部2家单位巧立名目发奖金978.81万元，国资委1家单位超标准定制服装107.49万元，体育总局1家单位违规租用办公用房27.1万元（同时闲置864.52㎡）。
>
> 查法：获取财务账中的奖金、服装、房租支出记录，逐项与制度标准比对。发现"项目奖"不在制度规定范围内、服装单价超标、闲置房产与租用房产并存。



## 第六部分：重大政策落实审计（4个方法）

### 方法14：查"补贴政策全链条"（钱从国家到消费者手里，中间有没有被截留）

#### 背景

以旧换新、家电补贴等政策，钱从国家→商家→消费者。中间可能被截留：
- 商家"刷单"（虚假交易骗取补贴）
- 商家"涨价"（先涨价再补贴，消费者没省到钱）
- 地方"挪用"（把补贴资金用于其他支出）

#### 怎么查？三步走

**步骤1：建立全链条数据**

需要四个数据源：

```
[补贴发放记录]    [商家销售记录]    [消费者支付记录]    [物流/服务记录]
       ↓                ↓                  ↓                  ↓
  国家拨了X亿    商家卖了X台     消费者付了X元     物流送了X单
```

**步骤2：三单比对查"刷单"**

```
商家说：卖了1000台，申请补贴100万元
实际查：
  - 消费者支付记录：只有500笔
  - 物流记录：只有500单
→ 500单没有真实交易 = 刷单骗取补贴50万元
```

**Excel操作**：
1. 把补贴申请、销售记录、支付记录、物流记录放在四张表
2. 按"订单号/消费者手机号"做VLOOKUP匹配
3. 统计：四单都能对上的 = 真实交易；对不上的 = 疑似刷单

**步骤3：查"涨价套补贴"**

```
政策前价格：空调2000元
政策后价格：空调2300元（商家先涨价300，再补贴300）
消费者实际支付：2300 - 300 = 2000元（和没补贴一样）
→ 补贴被商家吞了，消费者没受益
```

**查法**：
1. 获取政策实施前后的价格数据（电商平台、实体店）
2. 计算：政策后价格 - 政策前价格
3. 如果涨价幅度 ≈ 补贴幅度 → 商家套补贴

#### 实操案例

> 14省市8367商家刷单骗取补贴1.06亿元，12.92亿元被挤占挪用于弥补财力缺口。
> 
> 查法：建立全链条数据（补贴发放记录+商家销售记录+消费者支付记录+物流记录），逐笔比对。发现5000多笔没有真实交易（补贴申请存在但消费者支付和物流记录缺失），即为刷单。

### 方法15：查"工程量三算比对"（报了1000万，实际只干了500万的活）

#### 背景

工程项目中常见"报大建小"：概算报1000万，实际只干了500万的活，但按1000万结算。差额500万被贪污或浪费。

#### 怎么查？三步走

**步骤1：获取"三算"数据**

```
[概算] = 项目立项时估算的总投资（可研报告）
[预算] = 招标时的预算控制价（招标文件）
[结算] = 竣工时的实际结算金额（竣工决算）
```

**步骤2：计算"偏离度"**

```
概算偏离度 = (概算 - 结算) / 概算 × 100%
预算偏离度 = (预算 - 结算) / 预算 × 100%

概算偏离度 > 30% → 严重偏离，可能存在报大建小
预算偏离度 > 20% → 需要关注，可能有虚报工程量
```

**Excel操作**：
1. 建立三列：概算、预算、结算
2. 计算两列偏离度
3. 用条件格式：偏离度 > 30% 标红

**步骤3：现场核查工程量**

对偏离度大的项目，现场测量：
- 道路工程：实际长度、宽度、厚度 vs 设计图纸
- 建筑工程：实际面积、层高 vs 设计图纸
- 管道工程：实际长度、管径 vs 设计图纸
- 绿化工程：实际种植面积、树种 vs 设计图纸

**测量方法**：
- GPS测距仪：测道路长度
- 卷尺：测宽度、厚度
- 无人机航拍：测面积、核实绿化

#### 实操案例

> 118县"报大建小"骗取套取资金47.72亿元。
> 
> 查法：获取118县工程项目的概算、预算、结算数据，计算偏离度。对偏离度 > 30%的项目，现场测量实际工程量。发现某道路工程概算1000万、结算950万，但实测长度只有设计的60% → 骗取资金约400万。

### 方法16：查"政策名实分离"（挂羊头卖狗肉）

#### 背景

很多政策资金有特定用途（如科技创新、绿色能源），但实际操作中"挂羊头卖狗肉"：
- 科技创新贷款 → 实际用于传统业务
- 知识产权质押贷款 → 实际已有传统抵押物
- 绿色能源补贴 → 实际用于高耗能项目

#### 怎么查？三步走

**步骤1：搞清楚"政策要求"**

从政策文件中获取准入条件：
- 申请贷款的企业必须是什么类型？（如"科技型企业""高新技术企业"）
- 贷款用途必须是什么？（如"研发""技改""绿色转型"）
- 是否需要提供特定条件？（如"创新积分""知识产权质押"）

**步骤2：获取实际贷款台账**

从银行获取：
- 每笔贷款的标注类型（如"创新积分贷""知识产权质押贷"）
- 借款企业名称、类型、资质
- 贷款用途（合同约定的用途）
- 实际资金流向（银行流水）

**步骤3：逐笔比对"名实是否一致"**

```
贷款标注："创新积分贷"
实际核查：
  - 企业是否有创新积分？→ 查积分系统
  - 贷款是否用于创新活动？→ 查资金用途
  - 积分在贷款审批中是否被考虑？→ 查审批记录
→ 如果"没有积分"或"积分未被考虑" → 名实分离
```

**常见"名实分离"模式**：

| 政策名称 | 名实分离表现 | 核查方法 |
|---------|-------------|---------|
| 创新积分贷 | 企业无积分或积分未被考虑 | 查积分系统记录 |
| 知识产权质押贷 | 企业已提供房产抵押，知识产权是附加 | 查抵押物清单 |
| 科技企业并购贷 | 实际是股权回购或股东借款 | 查并购协议、资金流向 |
| 绿色能源补贴 | 项目未使用新能源技术 | 查技术方案、设备清单 |

#### 实操案例

> 642.22亿元"创新积分贷"未考虑积分，101.09亿元"知识产权质押贷"已足额提供传统抵押物，54.37亿元"科技企业并购贷"实为股权回购。
> 
> 查法：获取银行全部科技金融贷款台账，逐笔比对：企业类型、资质条件、贷款用途、实际资金流向。发现大量标注"创新积分贷"的企业根本没有积分记录。

### 方法17：查"地方政府债务三化风险"（平台假退出、绕路借钱、数字游戏）

#### 背景

地方政府债务管控要求平台公司退出、违规举债清理。但实际操作中三种常见手法：
- **虚假退出**：平台公司不符合退出条件，但被"认定退出"
- **违规举债**：绕过平台公司，通过国企、事业单位借钱
- **虚假化债**：用新债还旧债，或系统里直接删除债务记录

#### 怎么查？三步走

**步骤1：查"平台虚假退出"**

平台公司退出的法定条件：
- 政府不再承担偿债责任
- 不再注入资产
- 不再提供担保
- 已市场化转型

**核查方法**：
1. 获取"已退出平台"名单
2. 对每家退出平台，查：
   - 政府是否仍为其债务提供担保？（查担保合同）
   - 政府是否仍在注入资产？（查资产划转记录）
   - 其债务是否仍由财政资金偿还？（查还款来源）
3. 如果"已退出"但政府仍在兜底 → 虚假退出

**步骤2：查"违规举债"（绕道国企）**

```
正常借钱：政府 → 平台公司 → 银行/债券市场
违规举债：政府 → 国企A → 银行借款 → 政府项目
          或：政府 → 事业单位 → 融资租赁 → 政府项目
```

**核查方法**：
1. 获取政府投资项目清单
2. 获取项目资金来源（银行借款、融资租赁、信托等）
3. 对每一笔借款，查：借款主体是谁？（政府/平台/国企/事业单位）
4. 如果借款主体是国企/事业单位，但资金用于政府项目 → 违规举债

**步骤3：查"虚假化债"**

```
真实化债：用财政资金/项目收益偿还债务
虚假化债：
  - 新债还旧债（借新还旧，债务总量未减少）
  - 系统删除（债务记录直接从系统中删除，但未实际偿还）
  - 国企贷款代偿（政府让国企贷款来还政府债务）
```

**核查方法**：
1. 获取债务台账（期初余额、本期新增、本期偿还、期末余额）
2. 对"本期偿还"的每一笔，查：
   - 偿还资金来源是什么？（财政资金/项目收益/新借款）
   - 如果是"新借款" → 虚假化债（债务总量未减少）
   - 如果是"系统删除" → 查实际还款凭证
3. 追踪偿还资金：如果最终来源是"银行借款" → 虚假化债

#### 实操案例

> 9家平台不符合条件即退出，15县绕道国企举债41.97亿元，4省通过国企贷款或系统删除虚假化债66.82亿元。
> 
> 查法：获取平台退出名单，逐一核查退出条件。获取政府投资项目资金来源清单，识别"国企借款用于政府项目"的记录。获取债务台账，追踪"偿还"资金的最终来源。

## 第七部分：民生资金审计（3个方法）

### 方法18：查"保障房供需匹配"（房子有但没人住，有人住但没房子）

#### 背景

保障性住房可能出现两种极端：
- 房源大量闲置（没人住）
- 应保人群轮候多年（没房子住）

#### 怎么查？三步走

**步骤1：获取"供给端"数据**

- 已建成的保障性住房数量（套数、面积）
- 已分配的保障性住房数量
- 正在轮候的申请人数量

**步骤2：获取"需求端"数据**

- 符合条件的低保家庭数量
- 符合条件的低收入家庭数量
- 新市民/青年人才数量

**步骤3：计算"供需匹配度"**

```
闲置率 = 闲置房源 / 总房源 × 100%
轮候率 = 轮候人数 / 符合条件总人数 × 100%

闲置率 > 10% → 供给过剩或分配不均
轮候率 > 30% → 供给不足
闲置率 > 10% 且 轮候率 > 30% → 结构性错配（有房子但不对口）
```

**Excel操作**：
1. 建立两列：区域、房源数量、已分配数量、轮候人数
2. 计算闲置率和轮候率
3. 用条件格式：闲置率 > 10% 标红，轮候率 > 30% 标黄

**进一步核查**：
- 闲置房源位置 vs 需求人群就业分布（通勤距离是否太远？）
- 户型结构 vs 家庭人口结构（大户型多但小家庭多？）
- 租金水平 vs 目标人群收入（租金太高住不起？）

#### 实操案例

> 成都2.35万套保障性住房闲置，同时万人轮候未保障。
> 
> 查法：获取成都保障房台账和轮候名单，计算闲置率和轮候率。发现闲置率高但轮候率也高 → 结构性错配。进一步核查：闲置房源在远郊区，轮候人群在主城区上班 → 通勤距离太远导致不愿住。

### 方法19：查"社保应保未保"（该参保的人没参保）

#### 背景

企业应该给员工缴纳社保（工伤保险、生育保险），但实际操作中：
- 农民工未参保（老板省钱不缴）
- 降档参保（按低标准缴，少缴保费）
- 虚构劳动关系骗保（没上班但挂名参保骗待遇）

#### 怎么查？三步走

**步骤1：获取"应保人群"**

从以下数据源获取：
- 劳动合同备案系统（签了合同的人）
- 工资发放记录（领了工资的人）
- 考勤记录（实际上班的人）
- 个人所得税申报（有工资收入的人）

**步骤2：获取"实保人群"**

从社保系统获取：
- 工伤保险参保名单
- 生育保险参保名单
- 缴费基数（按什么标准缴的）

**步骤3：比对"应保 vs 实保"**

```
应保未保 = 有劳动关系但无参保记录的人
降档参保 = 实际工资 > 缴费基数（按低标准缴）
虚构参保 = 有参保记录但无劳动关系/工资记录
```

**Excel操作**：
1. 建立两张表：应保人员表、实保人员表
2. 用VLOOKUP匹配：身份证号作为唯一键
3. 标记：在应保表但不在实保表 → 应保未保
4. 标记：在实保表但不在应保表 → 虚构参保

**降档参保识别**：
```
缴费基数 / 实际工资 < 0.8 → 降档参保（按低于实际工资的80%缴）
```

#### 实操案例

> 226万名农民工应保未保（涉及25.3亿元），170.6万名职工被降档参保，279家单位虚构劳动关系骗取生育补助5431万元。
> 
> 查法：获取劳动合同备案 + 工资发放记录 + 社保参保记录，三单比对。发现大量农民工签了合同、领了工资，但社保系统没有参保记录。进一步发现部分单位用"灵活就业"名义给全日制职工参保，缴费基数远低于实际工资。

### 方法20：查"成本结构异常"（不该花的钱花太多了）

#### 背景

企业成本结构中，某些费用异常偏高，可能意味着：
- 虚增成本（拿假发票冲账）
- 商业贿赂（"带金销售"）
- 利益输送（向关联方支付不合理费用）

#### 怎么查？三步走

**步骤1：计算"成本结构比例"**

从企业财务账中获取：
- 原材料成本
- 人工成本
- 销售费用
- 管理费用
- 财务费用

```
销售费用率 = 销售费用 / 营业收入 × 100%
管理费用率 = 管理费用 / 营业收入 × 100%
```

**步骤2：与行业均值对比**

| 行业 | 正常销售费用率 | 异常信号 |
|------|--------------|---------|
| 医药行业 | 15-25% | > 30% → 可能带金销售 |
| 中药行业 | 20-30% | > 40% → 可能商业贿赂 |
| 制造业 | 5-10% | > 15% → 可能虚增费用 |
| 软件行业 | 10-20% | > 25% → 可能虚增成本 |

**步骤3：追踪"异常费用"**

对销售费用率异常高的企业，进一步查：
- 销售费用支付给谁？（第三方公司、个人、关联方）
- 是否有真实业务支撑？（合同、发票、服务成果）
- 收款方是否与销售人员/管理层有关联？

**带金销售识别**：
```
特征：
  - 销售费用中"市场推广费""学术会议费"占比极高
  - 费用支付给大量个人或小额公司
  - 没有对应的市场活动证据（照片、签到表、会议资料）
```

#### 实操案例

> 9户中药企业虚增采购成本22.81亿元，虚列销售费用22.5亿元，带金销售42.5亿元。
> 
> 查法：获取9户中药企业财务数据，计算销售费用率（平均45%，远超行业正常水平）。进一步追踪销售费用支付对象，发现大量支付给个人和空壳公司，无真实业务支撑。

## 第八部分：国有资产审计（2个方法）

### 方法21：查"资产台账与实物"（账上有但现场没有，现场有但账上没有）

#### 背景

国有资产常见两种问题：
- 账上有、现场没有 → 资产流失或虚假入账
- 现场有、账上没有 → 资产未入账或权属不清

#### 怎么查？三步走

**步骤1：获取"台账"**

从财务系统/资产管理系统获取：
- 资产名称、规格型号、数量、价值
- 存放地点、使用部门、使用状态
- 入账日期、折旧情况

**步骤2：现场盘点**

带着台账去现场，逐一核对：
- 资产是否还存在？（实物还在不在）
- 资产状态是否正常？（能用还是报废）
- 资产位置是否与台账一致？（有没有被搬走）
- 资产标签是否完整？（有没有被撕掉）

**盘点方法**：
- 房产：GPS定位 + 拍照（外观、门牌号）
- 设备：拍铭牌（型号、编号） + 开机测试
- 车辆：拍车牌 + 行驶证 + 里程表
- 土地：GPS定位 + 查土地证

**步骤3：比对差异**

```
台账有、现场无 → 资产流失（查去向：卖了？报废？丢了？）
台账无、现场有 → 未入账资产（查来源：谁买的？谁在用？）
台账在、现场在但状态不同 → 台账未及时更新（如已报废未销账）
```

**Excel操作**：
1. 建立盘点表：资产编号、台账状态、现场状态、差异说明
2. 用COUNTIF统计差异数量
3. 计算差异率：差异资产 / 总资产 × 100%

#### 实操案例

> 11个部门1.24万㎡房产未入账、10个部门11.92万㎡房产闲置。
> 
> 查法：获取11个部门资产台账，现场逐一盘点房产。发现台账上没有的房产（现场有但账上无）→ 未入账。发现台账上有但实际闲置的房产 → 账实不符（应更新状态）。

### 方法22：查"遥感监测"（生态治理项目是真是假）

#### 背景

生态治理项目（如植树造林、湿地保护）面积大、分布广，现场核查成本高。遥感监测（卫星影像）可以高效识别"假治理"。

#### 怎么查？三步走

**步骤1：获取"治理前后影像"**

从卫星影像平台（如Google Earth、天地图）获取：
- 项目区域治理前的影像（如2020年）
- 项目区域治理后的影像（如2025年）
- 同比例尺、同季节的对比

**步骤2：目视对比变化**

```
治理前：荒山、裸露地、污水塘
治理后：应该变成 → 森林、草地、清水池

如果治理后还是荒山 → 没有种树
如果治理后变成建筑用地 → 被挪用了
```

**识别要点**：
- 颜色变化：荒山（黄褐色）→ 森林（深绿色）
- 纹理变化：裸露地（粗糙）→ 草地（均匀细腻）
- 边界变化：治理区域应该有清晰边界，与周边未治理区域对比

**步骤3：实地验证疑点**

对遥感影像发现的疑点区域，实地核查：
- 随机抽样：在治理区域内随机选3-5个点，实地查看
- 边界核查：治理区域边界是否与实际一致
- 质量核查：树木成活率、草地覆盖率、水质情况

**辅助工具**：
- QGIS（免费地理信息系统软件）：加载影像、标记坐标、测量面积
- 无人机：航拍高分辨率影像，验证卫星影像的精度

#### 实操案例

> 4省276.49万亩造林在缺水地区，青海6市县抽样仅0.91%验收合格。
> 
> 查法：获取4省造林项目的设计图纸和卫星影像。对比治理前后影像，发现"治理区域"在影像上仍是荒山。进一步分析：这些区域年均降水量 < 200mm，根本不适合种树 → 项目设计本身不合理。实地抽样核查，验收合格率极低。

### 常用审计Excel公式

```excel
; 1. 计算差异率
=(实际值-标准值)/标准值*100%

; 2. 标记异常（条件判断）
=IF(差异率>30%, "严重异常", IF(差异率>10%, "异常", "正常"))

; 3. 筛选重复值（同一天同单位收入+支出）
=COUNTIFS(日期列,日期,单位列,单位)

; 4. VLOOKUP匹配（两张表比对）
=VLOOKUP(查找值, 被查找表范围, 返回列号, FALSE)

; 5. 计算空转率
=SUMIFS(收入列, 日期列, 日期, 单位列, 单位) / 当月总收入

; 6. 判断金额是否为整数（100的倍数）
=IF(MOD(金额,100)=0, "整数", "非整数")

; 7. 计算延迟天数
=实际下达日期 - 法定最迟日期

; 8. 条件格式标红（选中单元格 → 条件格式 → 新建规则）
=单元格值 > 30  → 设置红色填充
```

## 附录：常见问题FAQ

**Q1：我没有政府内部数据，能做什么审计？**
A：可以从公开数据入手：
- 政府网站公开的预算、决算文件
- 政府采购网公开的采购信息
- 企业工商信息（天眼查、企查查）
- 卫星影像（Google Earth、天地图）
- 新闻报道、投诉举报

即使没有内部数据，通过**公开信息交叉比对**也能发现大量问题。

**Q2：Excel数据量太大（几十万行）跑不动怎么办？**
A：三个方案：
1. 分批处理：把数据切成若干块，分别处理后再合并
2. 用Access或SQLite：轻量级数据库，Excel级别的学习成本
3. 学Python：用pandas处理，百万行数据秒级处理

**Q3：被审计单位不配合给数据怎么办？**
A：
1. 先出示审计通知书/授权文件
2. 明确告知：拒绝提供数据属于违规行为，将被记录
3. 从其他渠道获取（如从上级部门、从银行、从第三方）
4. 如果数据无法获取，在审计报告中注明"因被审计单位拒绝提供数据，无法核实"

**Q4：发现了问题，但金额不大，要不要写进报告？**
A：参考审计署的做法——**无论金额大小，问题都要反映**。但报告撰写时可以：
- 金额大的 → 作为重点问题详细写
- 金额小的 → 作为"其他问题"汇总写
- 性质严重的（如涉及廉政）→ 即使金额小也要单独写

**Q5：新手审计员最容易犯的错是什么？**
A：三个常见错误：
1. **只看数字，不看实质**：账上平了不等于没问题，要看钱实际去哪了
2. **被表面合规迷惑**：文件齐全、签字完备不等于执行到位，要现场核实
3. **不敢问问题**：发现问题不好意思追问 = 问题被掩盖。审计的职责就是发现问题，问问题是本职工作
