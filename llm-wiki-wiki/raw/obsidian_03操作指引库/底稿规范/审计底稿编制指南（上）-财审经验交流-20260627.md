# 审计底稿编制指南（上）

## 来源

- 公众号：财审经验交流
- 原文：<https://mp.weixin.qq.com/s/Y1swCbnjrEh9LUam6ep-Jw>

## 核心观点

文章把审计底稿的本质概括为：记录审计师的工作过程和结论依据。底稿不是填表、抄账或凑厚度，而是未来复盘、复核、质疑应对乃至责任追溯时，能够说明“当时为什么得出这个结论”的专业证据。

好底稿的质量标准可以归纳为四句话：

1. 目标明确：每项程序要说明验证什么认定。
2. 过程清晰：写清样本如何选、测试如何做。
3. 结论有据：结论必须和证据逐项对应。
4. 索引完整：底稿、明细、凭证、合同、测算表之间能互相追踪。

文章特别强调，新人底稿常见三类问题：

1. 只有数字，没有说明。
2. 只有结论，没有依据。
3. 照抄上年底稿，不重新评估当年风险。

三级复核方面，文章将复核分为项目组内复核、项目质量控制复核、事务所层面独立复核。对新人而言，项目经理的复核意见是最直接的成长输入，被质询时应补程序、补证据、改表达，不能用解释代替证据。

## 对融策业务的有用点

### 1. 政府审计与绩效评价：把“判断过程”写进底稿

融策做绩效评价、专项资金、预算执行审计时，报告里的结论常常不是简单的会计数字，而是涉及“项目目标是否合理、资金绩效是否达成、结果应用是否充分”等判断。底稿如果只放评分表和汇总表，后续很难解释评分逻辑。

可落地做法：

- 每个评价指标底稿增加“评价目标、取数口径、判断标准、证据来源、结论说明”五栏。
- 对扣分项必须写清：事实是什么、依据是什么、影响是什么、是否与被评价单位确认。
- 对“未达标”“基本达标”等结论，必须链接到指标解释、原始数据或访谈记录。

### 2. 经济责任审计：底稿要能支撑责任认定

经责审计最容易出风险的是责任边界：直接责任、主管责任、领导责任、无责任。文章的“结论有据”和“过程清晰”可以直接转成经责底稿要求。

可落地做法：

- 每个问题底稿增加“事项发生时间、决策链条、职责依据、被审计人参与方式、证据编号、责任建议”。
- 对会议纪要、签批单、合同、付款凭证做索引闭环。
- 不能只写“管理不到位”，要说明“哪项制度要求谁做什么、实际谁没做、造成什么后果”。

### 3. 招投标审计：索引体系决定证据链强度

围标串标、评标异常、供应商关联等问题需要多证据交叉。文章强调索引完整，这对招投标审计很关键。

可落地做法：

- 报价异常、文本雷同、图片哈希、元数据、工商关联分别形成独立底稿。
- 每条疑点要索引到投标文件页码、开标表行号、评标表单元格、企业关系来源。
- “疑似串标”不能只靠单一相似度指标，要写明多层证据之间如何互相印证。

### 4. 专项资金和补贴审计：样本方法必须透明

专项资金审计常涉及抽样检查。文章提醒“样本怎么抽”必须写清，这可以降低抽样结论被质疑的风险。

可落地做法：

- 抽样底稿必须说明总体范围、抽样规则、抽样比例、覆盖金额、异常样本处理。
- 对高风险样本采用“大额优先 + 随机补充 + 异常补充”的组合，并写明理由。
- 对无法取得资料、资料不完整、对象不配合等情况单独记录限制事项。

### 5. 公司内部质控：可以转成新人底稿培训清单

文章适合作为融策新人培训和项目经理复核口径。它把“好底稿”讲得足够简单，可以直接固化成底稿自查表。

建议转化为融策内部底稿自查六问：

1. 我这张底稿验证的是哪项审计目标或认定？
2. 数据来源、样本选取和测试步骤写清楚了吗？
3. 每个关键数字都有来源吗？
4. 结论是否被证据支撑？
5. 异常事项是否说明处理过程？
6. 复核人能否不问我就看懂并追到原始证据？

## 融策可直接采用的底稿模板字段

| 字段 | 用途 |
|---|---|
| 审计目标/认定 | 说明本程序验证什么 |
| 风险点 | 说明为什么要做这项程序 |
| 数据来源 | 写明账套、台账、合同、凭证、访谈等来源 |
| 样本选取方法 | 说明抽样规则、覆盖金额、抽样理由 |
| 执行过程 | 记录具体核对、计算、访谈、观察步骤 |
| 发现事项 | 记录异常、差异或限制事项 |
| 证据索引 | 关联附件、凭证号、合同号、页码、表格行号 |
| 审计结论 | 结论必须对应证据，不写空泛判断 |
| 复核意见 | 记录复核问题、回复、补充程序 |

## 可用于 RAG 的问答种子

- 问：什么是好审计底稿？
  答：好底稿应当让复核人不再追问也能看懂审计目标、执行过程、证据来源、异常处理和结论依据。

- 问：新人编制底稿最常见的问题是什么？
  答：常见问题包括只有数字没有说明、只有结论没有依据、照抄上年而不重新评估当年风险。

- 问：政府审计底稿为什么要重视索引？
  答：政府审计结论常涉及责任认定、整改要求和报告披露，索引能把问题事实、政策依据、数据来源和原始证据串成可复核的证据链。
