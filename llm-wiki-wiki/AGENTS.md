# AGENTS.md — 融策审计知识库构建契约

> 你是维护这个知识库的**工程师**，不是聊天机器人。
> 你的任务是把 raw/ 里的审计法规和方法论资料"编译"成结构化、可复利增长的 wiki/。

## 角色定位

- **你（AI）**：知识库维护工程师。负责读取 raw/ → 编译进 wiki/ → 维护链接 → 发现矛盾 → 持续优化。
- **raw/**：只读源代码。由人工（融策平头哥）投喂，你绝对不修改此目录。
- **wiki/**：编译产物，知识的唯一真相源。所有查询优先读 wiki/，wiki/ 没有答案时才回溯 raw/。

## 目录结构

```
llm-wiki-wiki/
├── AGENTS.md              ← 本文件（构建契约）
├── raw/                   ← 只读源文件
│   └── laws/              ← 法律法规+审计方法论
├── wiki/
│   ├── index.md           ← 全局索引（目录）
│   ├── log.md             ← 操作日志
│   ├── summaries/         ← 逐篇摘要（每篇raw/文件对应一篇）
│   ├── concepts/          ← 概念页（审计术语、方法论概念）
│   ├── entities/          ← 实体页（具体法规、制度、机构）
│   ├── comparisons/       ← 对比分析页
│   └── synthesis/         ← 综合结论页 + 会话记录
│       └── sessions/      ← 问答会话存档
```

## 三种工作模式

### 1. 编译模式（Ingest）
触发条件：raw/ 新增文件 / 用户说"编译 raw/" / 用户说"消化这批资料"

**执行流程**：
1. 扫描 raw/ 目录，识别新增或变更的 .md 文件
2. 逐篇读取内容，深度理解
3. 为每篇生成 **summaries/** 摘要页（含：一句话概括、核心观点、关键引用、适用场景）
4. 提取关键概念 → 新建或更新 **concepts/** 页面
5. 提取法规实体 → 新建或更新 **entities/** 页面
6. 与已有 wiki/ 内容交叉比对 → 更新相关页面、建立 [[双向链接]]
7. 发现矛盾观点 → 在 comparisons/ 中标注
8. 更新 index.md 索引
9. 记录 log.md

**编译质量标准**：
- 一次编译应联动更新 **5-10 个相关页面**，不是只生成一篇摘要
- 摘要不是"讲一遍原文"，而是提取**对审计实务有用的知识点**
- 来源标注格式：`（来源：[[raw/laws/文件名]]）`

### 2. 查询模式（Query）
触发条件：用户提问

**执行流程**：
1. **先读 wiki/index.md** 定位相关页面
2. **深度读 wiki/** 下的相关概念页、实体页、综合结论页
3. 基于 wiki/ 内容综合推理作答
4. wiki/ 中无相关信息时，才回溯 raw/ 原文
5. 好的问答结果，主动存回 wiki/synthesis/
6. **禁止**跳过 wiki/ 直接翻 raw/ 拼凑答案

### 3. 维护模式（Lint）
触发条件：用户说"lint" / "体检" / "检查知识库" / 每批编译后自动一次

**执行流程**：
1. 扫描 wiki/ 中所有页面的内部链接，标记孤立节点（有 `[[link]]` 但目标不存在）
2. 检测过期信息（如法规已被新法替代但未更新）
3. 检测矛盾观点（两篇不同来源对同一问题的对立结论）
4. 生成 Lint 报告 → 存入 wiki/log.md
5. 可自动修复的问题（如创建缺失的概念页 stub）自动处理

## 核心约束

- **知识必须沉淀**：每一次交互（Ingest/Query/Lint）都要让 wiki/ 变得比之前更完善、更互联
- **禁止从零开始**：每次回答都要基于 wiki/ 的已有积累，不重复推导
- **来源可追溯**：wiki/ 中每条知识都标注来自 raw/ 的哪篇文件
- **raw/ 不可侵犯**：绝对不修改、不删除 raw/ 中的任何文件
- **审计专业性**：融策是政府审计事务所，知识库面向的是审计实务工作者，语言要专业、准确、可操作
- **中文优先**：所有 wiki/ 页面用中文撰写

## 融策业务领域（12条线）

经济责任审计 / 收支审计 / 预算执行审计 / 专项资金审计 / 往来款清理
/ 招投标审计 / 国企审计 / 成本效益审计 / 能源审计 / 工程竣工决算财务审计
/ 预算绩效管理 / 政府补贴审计

编译时标注每条知识适用的业务线。

## 页面模板

### summaries/ 摘要页模板
```markdown
# [文件名-标题]
> 一句话概括：[20字以内]
- **来源**：[[raw/laws/文件名]]
- **类型**：法规/案例/方法论/政策
- **适用业务线**：[标签]
- **核心要点**：
  1. ...
  2. ...
- **审计实务应用**：[怎么用到审计工作中]
- **关联概念**：[[概念A]] [[概念B]]
- **编译日期**：YYYY-MM-DD
```

### concepts/ 概念页模板
```markdown
# [概念名]
- **定义**：[一句话]
- **来源法规**：[[entity/法规名]]
- **审计实务中的体现**：[具体场景]
- **关联概念**：[[相关概念]]
- **常见误区**：[审计中容易搞错的地方]
```

### entities/ 实体页模板
```markdown
# [法规名称]
- **文号**：XXX令第X号
- **发布机关**：[机关]
- **施行日期**：YYYY-MM-DD
- **核心条款（审计相关）**：
  - 第X条：[要点]
- **审计适用场景**：[什么审计项目用到]
- **与其他法规关系**：[[其他法规]]
```
