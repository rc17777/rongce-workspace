# 直接责任 vs 领导责任

> 经责审计中两种责任形态的核心区分——定责错了，整个审计结论站不住。

| 维度 | 直接责任 | 领导责任 |
|:--|:--|:--|
| **行为模式** | 个人直接违规/授意指使/独断专行 | 参与集体决策/疏于监管/未发表反对意见 |
| **决策背景** | 未经民主程序或多数人不同意时强行决定 | 民主决策多数人同意，但决策不当/失误 |
| **法律依据** | 经责审计规定第15条（6种情形） | 经责审计规定第16条（5种情形） |
| **典型场景** | 直接批准违规支出、授意篡改账目 | 主持会议通过不当决策、未发现下级违规 |
| **处分后果** | 较重（直接违规者） | 相对较轻（监管不力者） |

## 定责八对界限

| 界限 | 说明 |
|:--|:--|
| 集体决策 vs 个人主张 | 集体决策多数同意→领导责任；个人强行决定→直接责任 |
| 决策 vs 监管 | 做出错误决策→直接责任；未发现执行中的问题→领导责任 |
| 决策失误 vs 管理不力 | 决策本身错误→直接责任；执行管理不到位→领导责任 |
| 决策责任 vs 执行责任 | 决定做错→决策责任；执行走样→执行责任 |
| 工作失职 vs 工作失误 | 主观故意/重大过失→直接责任；客观制约/无意过失→领导责任或免于定责 |
| 主观故意 vs 客观制约 | 明知故犯→直接责任；条件限制→减轻 |
| 党委 vs 行政 | 党政分工，各自职权内定责 |
| 前任 vs 后任 | 历史遗留→分清时期，不能混算 |

## 审计实务警示

- 认定直接责任必须"由事及人"进行说理性表述，不能简单以"主持会议"或"签批文件"为标准
- "三个区分开来"原则：区分探索失误与明知故犯/无明确限制与明令禁止/推动发展中的无意过失与谋取私利
- 后果≠显性损失：隐性后果（影响可持续发展、损害公信力）同样需定责
