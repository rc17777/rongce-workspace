# GB/T 47950—2026 资产管理　数据资产登记指南

## 摘要
本标准由财政部资产管理司与中国标准化研究院起草，2026年7月2日发布，2026年9月1日实施。确立了数据资产登记的总体原则（安全性、合规性、可追溯性），提供了登记实施方、登记内容、登记流程和登记系统的指导。

## 核心内容

### 1. 总体原则
- **安全性** — 全过程符合数据安全、网络安全要求
- **合规性** — 来源、应用及登记活动全流程合规
- **可追溯性** — 全生命周期可追溯

### 2. 登记实施方
- 采购/生产/运营/使用部门 → 提供登记要素信息
- 资产管理部门 → 登记信息卡、管理台账
- 财务部门 → 登记会计凭证和账簿
- 数据技术和信息化部门 → 合规审查

### 3. 登记内容（双轨制）
- **资产台账登记**：通过数据资产信息卡，登记新增/使用/处置信息
- **会计账簿登记**：按会计准则登记凭证和账簿

### 4. 登记流程
- **初始登记** → 判断确认条件 → 信息卡 → 台账 → 账簿
- **变更登记** → 信息变动 → 信息卡变更 → 台账更新
- **注销登记** → 终止确认 → 信息卡注销 → 台账注销

### 5. 登记系统
- 宜使用数字化工具
- 信息要点：基本/财务/使用/授权/处置五大类
