## 🧠 核心概念速查

### [[concepts/经济责任]]
> 领导干部对管辖范围内公共资金、国有资产、资源的管理和风险防控职责。

**审计对象**：党委政府正职 / 党政部门正职 / 国企主要领导 / 实际分管副职

**审计内容七项**：政策执行→发展规划→重大决策→财政管理+风险防控→廉政建设→整改情况

### [[concepts/直接责任vs领导责任]]
> 经责审计的灵魂——定责错 = 整个结论站不住。

**直接责任六种情形**（第15条）：
1. 直接违规
2. 授意指使
3. 贯彻不力造成损失
4. 第一责任人未完成
5. 独断专行造成损失
6. 决定性作用的其他行为

**领导责任五种情形**（第16条）：
1. 民主决策失误
2. 违反内部规定
3. 未发表反对意见
4. 疏于监管
5. 其他应承担责任

### [[concepts/审计评价]]
> 三性标准：真实性 / 合法性 / 效益性

- ✅ 必须围绕审计目标，未涉及不得评价
- ❌ 不得评价党建、人事等超越审计职责范围事项
- ❌ 避免主观词汇："全心全意""千方百计"

### [[concepts/审计证据]]
> 两性标准：适当性（质量）+ 充分性（数量）

- 大数据筛选信息未经核实取证不得定性
- 取证单必须要素齐全、签章完备

## ⚠️ 七个常见雷区

| # | 雷区 | 正确做法 |
|:--|:--|:--|
| 1 | **定责时简单以"主持会议"为标准** | 须"由事及人"说理性表述，区分决策与执行/失职与失误 |
| 2 | **审计评价越界到党建、人事** | 评价只限经济责任，超出审计职权的一律不评 |
| 3 | **同类问题不同定性** | 不同项目间同样问题须保持一致性 |
| 4 | **没有显性损失就不定责** | 隐性后果（可持续发展影响、公信力损害）同样构成责任 |
| 5 | **定性依据和处罚依据混用** | 定性用审计法/预算法；处罚引用财政违法行为条例 |
| 6 | **证据未经被审计单位确认就定性** | 大数据筛选的信息须核实取证并签证 |
| 7 | **审计建议写成"遵守财经纪律"** | 建议须针对具体问题，可操作，3-5条为宜 |

## 📋 工作流清单

### 前期准备
- [ ] 调取被审计领导干部任期内所有经济决策会议纪要
- [ ] 调取预算批复、决算、专项资金分配文件
- [ ] 调取以往审计报告和整改情况
- [ ] 确定审计重点（对照第10-12条七项内容选重点）

### 现场实施
- [ ] 编制审计实施方案（审计准则第24-26条）
- [ ] 编制底稿：一事一稿、一问题一稿（底稿指南"四有"原则）
- [ ] 取证：书面证据+访谈记录+数据分析三维覆盖
- [ ] 三级复核：基础完整性→证据充分性→重大风险

### 报告撰写
- [ ] 审计评价（定性+定量）
- [ ] 问题定性+事实表述（时间/地点/起因/经过/结果/人员六要素）
- [ ] 法规依据引用（层次从高到低）
- [ ] 责任认定（对照第15-16条，附八对界限分析）
- [ ] 处理处罚意见（限于审计法第45条种类）
- [ ] 审计建议（3-5条，可操作）

### 征求意见
- [ ] 书面征求被审计领导干部及所在单位意见
- [ ] 合理意见应采纳，无理由不采纳须说明
- [ ] 审计报告+审计结果报告→报批→出具
