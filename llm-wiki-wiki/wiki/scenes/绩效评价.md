## 🧠 核心概念速查

### [[concepts/预算绩效管理]]

**四阶段全周期**：
```
目标设置 → 事前评估 → 事中监控 → 事后评价
```

**四维评价框架**：
- 经济性（花得省不省）
- 效率性（花得值不值）
- 效果性（目标达成了没）
- 公平性（受益面广不广）

**法律依据链**：预算法第57条→第36条→审计法第2条→审计准则第6条

### [[concepts/审计评价]]
> 绩效评价的核心输出——三性标准（真实性/合法性/效益性）

- 定性+定量结合，避免纯主观评价
- 充分考虑投入产出"滞后性"和"打基础利长远"的复杂性
- 不得用单个事实或几个指标评价整体情况

### [[concepts/审计证据]]
> 绩效评价的证据特殊要求

- 绩效指标数据必须有取数来源和计算过程
- 目标完成度的认定需要多维度证据（不光看数据，还要看质量）
- 大数据分析结果须经核实才能作为评价依据

### [[concepts/内部控制]]
> 内控有效性是绩效评价的重要内容

- 预算编制是否科学合理（内控规范第12条）
- 支出审批是否严格
- 资产使用是否有效

## ⚠️ 六个常见雷区

| # | 雷区 | 正确做法 |
|:--|:--|:--|
| 1 | **预算执行率低=绩效差** | 需区分客观原因（政策调整/项目延期）和主观原因（管理不善/资金闲置） |
| 2 | **只用财务指标衡量绩效** | 须涵盖四维：经济性/效率性/效果性/公平性 |
| 3 | **用当前标准衡量过去决策** | 评价应以决策时的政策环境和信息条件为参照 |
| 4 | **评价证据不可验证** | 所有指标必须可量化、可比较、可验证，杜绝"全心全意"式评价 |
| 5 | **评价结论前后矛盾** | 审计评价不得与审计发现的问题前后矛盾 |
| 6 | **用审计建议代替问题揭示** | "建议完善绩效管理制度"不能替代对具体问题的定性和处罚 |

## 📋 工作流清单

### 绩效目标审核
- [ ] 目标是否具体、可量化？（不能是"提高管理水平"这种虚的）
- [ ] 指标值是否合理？（不宜过高或过低）
- [ ] 资金测算是否有依据？
- [ ] 目标与部门职责是否匹配？

### 事前绩效评估
- [ ] 项目立项必要性（是否重复投入/是否市场已解决）
- [ ] 投入经济性（成本是否合理）
- [ ] 绩效目标合理性
- [ ] 实施方案可行性
- [ ] 筹资合规性

### 事中绩效监控
- [ ] 预算执行进度 vs 目标完成进度是否匹配？
- [ ] 资金使用是否合规？（对照预算法第57、63条）
- [ ] 是否存在偏离原定目标的情况？
- [ ] 需不需要调整预算或目标？

### 事后绩效评价
- [ ] 目标完成度（量化+定性）
- [ ] 资金使用效率（投入产出比）
- [ ] 项目管理制度执行情况
- [ ] 内控有效性评价
- [ ] 社会效益/可持续影响评估
- [ ] 发现问题→定性→依据→建议

### 报告撰写
- [ ] 评价方法明确（成本效益法/比较法/因素分析法/公众评判法等）
- [ ] 评价指标体系完整（一级/二级/三级指标+权重+评分标准）
- [ ] 每项结论有证据支撑
- [ ] 问题分级（P0/P1/P2）
- [ ] 建议可操作、有明确整改时限
