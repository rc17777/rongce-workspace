## 🧠 核心概念速查

### [[concepts/串通投标]]

**"属于"串标**（条例第39条，5种）— 有主观意图
- 协商报价 / 约定中标人 / 约定弃标 / 协同投标 / 其他联合行动

**"视为"串标**（条例第40条，6种）— 客观证据即可推断
- 文件同源 / 委托同人 / 成员相同 / 异常一致 / 文件混装 / 保证金同源

### [[concepts/政府采购方式]]
| 方式 | 适用条件 | 审计必查 |
|:--|:--|:--|
| 公开招标 | 达到省级数额标准（首选） | 是否化整为零规避？ |
| 邀请招标 | 特殊性强/公开招标费用占比大 | 条件是否真实？ |
| 竞争性谈判 | 无合格标/技术复杂/紧急/价不确定 | 紧急是否真紧急？ |
| 单一来源 | 唯一供应商/紧急/配套添购≤10% | 唯一性是否经得起查？ |

## 🔧 方法工具

### 三阶段全流程 → [[summaries/招投标三阶段]]

| 阶段 | 审计重点 | 方法 |
|:--|:--|:--|
| **标前** | 该不该招、能不能招 | 核立项→查招标方式→审招标文件（歧视条款/暗箱评分/不合理限价） |
| **标中** | 防围标串标、程序违规 | 核开标记录→查评委组成→技术手段比对投标文件（IP/MAC/报价/雷同/挂靠） |
| **标后** | 防阴阳合同、履约失控 | 比对合同vs招标文件→查转包分包→核资金支付→验验收资料真实性 |

## ⚠️ 七个常见雷区

| # | 雷区 | 正确做法 |
|:--|:--|:--|
| 1 | **IP一致直接认定为串标** | 7种电子信号未被条例直接纳入串标认定，须结合其他证据+给予澄清机会 |
| 2 | **招标文件自行扩大串标认定范围** | 招标文件超越上位法纳入7种电子信号→存在违法风险 |
| 3 | **政府工程项目引用政府采购法** | 工程类走招标投标法，货物服务类走政府采购法——双轨制不可混 |
| 4 | **只看标中，不管标前标后** | 标前"化整为零"和标后"阴阳合同"同样致命 |
| 5 | **采购方式变更未经审批** | 公开招标→其他方式须设区市级以上财政部门批准 |
| 6 | **补充合同超过10%硬红线** | 政府采购法第49条，超过即违规 |
| 7 | **只查纸质文件，不查电子痕迹** | 现代串标证据大量在电子层面（IP/MAC/文件元数据） |

## 📋 工作流清单

### 标前审计
- [ ] 项目是否属于强制招标范围？（招投标法第3条 / 采购法数额标准）
- [ ] 是否拆分为多个小项目规避招标？
- [ ] 招标方式选择是否合规？非公开招标是否经审批？
- [ ] 招标文件是否含有歧视性条款、排他性资质、暗箱评分标准？
- [ ] 标底/最高限价是否合理？

### 标中审计
- [ ] 开标时间、地点、记录是否完整、公开？
- [ ] 评标委员会组成是否合规（≥5人单数，专家≥2/3，有回避）？
- [ ] 评分是否严格按招标文件执行？有无倾向性打分？
- [ ] 技术手段比对：IP/MAC/报价规律/文本雷同/社保挂靠
- [ ] 投标人之间是否存在关联关系？

### 标后审计
- [ ] 合同是否背离招标文件实质性条款？（价款/工期/质量）
- [ ] 是否存在转包、违法分包？
- [ ] 项目变更是否合规？有无虚增金额？
- [ ] 工程款支付是否按合同？有无提前付、超额付？
- [ ] 验收资料是否真实？竣工验收是否按时完成？
