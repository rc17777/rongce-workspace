# 数据资产登记流程

## 流程图结构
初始登记 → 变更登记 → 注销登记

## 初始登记步骤
1. 判断数据资源是否符合确认条件
   - 符合 → 正式登记
   - 不符合 → 先入备查簿
2. 业务部门提供登记内容及证明材料
3. 资产管理部门核实并建立信息卡
4. 财务部门核查并登记凭证和账簿
5. 数据技术部门合规审查

## 变更登记步骤
1. 业务部门提供变更内容及证明材料
2. 资产管理部门核实并变更信息卡
3. 财务部门核查并按需更新账簿
4. 数据技术部门合规审查

## 注销登记步骤
1. 业务部门提供注销证明材料
2. 资产管理部门核实并注销信息卡
3. 财务部门核查并注销账簿
4. 数据技术部门合规审查
