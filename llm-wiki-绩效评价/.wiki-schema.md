# Wiki 结构规范

语言：中文

## 目录结构
- raw/ — 原始素材（不可变，分类存放）
  - articles/ — 网页文章
  - tweets/ — 社交媒体
  - wechat/ — 微信公众号
  - pdfs/ — PDF文件
  - notes/ — 手写笔记/便签
  - assets/ — 图片、附件
- wiki/ — 编译后的知识页面
  - entities/ — 实体页（概念、方法、法规、案例）
  - topics/ — 主题页（跨实体的深度分析）
  - sources/ — 素材摘要页（每篇源素材的摘要）
  - comparisons/ — 对比分析页
  - queries/ — 查询结果页
- purpose.md — 知识库方向（why）
- .wiki-schema.md — 结构规范（how）
- index.md — 页面索引
- log.md — 操作日志

## 页面规范

### YAML frontmatter 必填字段
```yaml
---
title: "页面标题"
type: "entity|topic|source|comparison"  # 页面类型
confidence: "EXTRACTED|INFERRED|AMBIGUOUS|UNVERIFIED"  # 置信度
source: "来源标识"  # 原始来源引用
tags: [标签1, 标签2]  # 分类标签
---
```

### 置信度标注规则
- EXTRACTED — 直接从原文提取，可信度高
- INFERRED — 基于已有知识推导，需验证
- AMBIGUOUS — 存在歧义或不一致，需人工判断
- UNVERIFIED — 未经验证，谨慎使用

### 交叉引用
- 使用 `[[双向链接]]` 语法关联相关页面
- 每页至少引用 2 个其他页面（避免孤立页）
- 引用格式：`[[页面标题]]` 或 `[[页面标题|显示文本]]`

## 审计领域实体类型
- regulation: 法规/政策/标准
- method: 方法/技术/模型
- case: 案例/项目
- concept: 概念/术语
- organization: 机构/单位
- indicator: 指标/标准
- report: 报告/文件
- person: 人物/专家

## 绩效评价特有字段
- 评价方法: 成本效益分析/平衡计分卡/DEA/SROI/比较法/因素分析法
- 评价类型: 事前评估/事中监控/事后评价/部门整体/政策评价
- 适用领域: 教育/卫生/社保/环保/农业/科技/基建/乡村振兴
- 数据来源: 统计数据/问卷调查/实地调研/信息系统
- 指标层次: 投入/过程/产出/效果/影响力
