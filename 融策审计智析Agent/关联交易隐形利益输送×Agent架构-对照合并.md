## 二、新增增强方案（3项）

### 增强1（P1）：关联交易定性模板库（1天）
**定位**：交互层——扩展v8翻凭证模板库，新增CHARACTERIZATION类别
**内容**：
- 4套定性模板（影子公司/非公允价格/无偿输送/虚假贸易）
- 每套含：适用条件→标准表述→引用法条→证据要求
- 自动匹配：Agent检测到对应风险→推荐对应定性模板
- 差异化表述：无确凿证据用"涉嫌"、有确凿证据用"认定"

### 增强2（P1）：三流合一交叉验证器（3天）
**定位**：数据分析层——新工具
**内容**：
- 输入：合同数据+发票数据+物流数据+资金流水
- 四流比对：合同流-发票流-货物流-资金流
- 输出：四流不一致的交易列表 + 不一致类型（时间/金额/数量/对手方）
- 与v4 contract_field_extract联动：合同字段→自动匹配对应的发票/物流/流水
- 虚假贸易评分：四流一致=0分，一流不一致=+1分，四流全不一致=4分

### 增强3（P2）：决策程序审计追踪（5天）
**定位**：数据分析层——新工具
**内容**：
- 输入：决策文件（董事会纪要/总办会纪要/审批单）
- 检测：越权审批/未回避表决/化整为零规避/紧急采购无理由/签字不全
- 输出：决策程序违规点+对应责任岗位
- 与v4 hotword联动：纪要热词→异常决策模式检测

## 四、独特增量

1. **首次来自内审一线老兵**（vs.数审视界偏学术/工具视角）
2. **补上了"查出问题后怎么表述"的完整闭环**：v8翻凭证→查证，v11定性模板→表述→追责
3. **"三流合一"是可编程的核心审计逻辑**：货物流+资金流+票据流的交叉比对是最具实操价值的自动化方向
4. **避坑红线的Agent映射**："无确凿证据不定性舞弊"=Agent输出约束层，"穿透留痕"=证据追溯链，"合规瑕疵vs利益输送区分"=风险等级分界
