## 二、与v7的独特差异

| 维度 | v7（采购数据模型） | v9（围标串标检测） |

| 分析对象 | 合同金额、供应商、付款时间 | 投标IP、报价、保证金、投标文件、提交时间 |
| 分析层次 | 数据分析层（事后审计） | 数据采集层（交易行为数据） |

## 三、新增增强方案（5项）

### 增强1（P1）：围标串标多维检测引擎（8天）
**定位**：数据分析Agent 新增独立工具模块
**内容**：
- 5个检测器对应5大数据特征
- 检测器1（IP/设备聚类）：IP C段匹配 + MAC前缀匹配 + CA证书签发分析 + 工商关联图
- 检测器2（报价规律）：报价尾数分布 + 整数位一致性 + 差额稳定性 + 贴边检测（限价% / 基准价%）
- 检测器3（保证金同源）：银行账号匹配 + 转账时间聚类 + 摘要文本相似度
- 检测器4（投标文件基因）：SimHash/MinHash/向量相似度 + 行业基准值加权 + 马甲关联推断
- 检测器5（时间扎堆）：提交时间间隔聚类 + 最后N分钟比例 + 秒级批量检测
- 输出：每个标段 0-5分 围标风险评分（每特征1分，交叉加权）

### 增强2（P1）：证据链图谱生成器（5天）
**定位**：报告输出层 新增可视化模块
**内容**：
- 证据节点：5大特征检测结果 + 中标结果 + 关联方关系 + 金额异常
- 图谱布局：力导向图（Force-Directed），节点大小=风险权重，边=关联强度
- 输出格式：HTML交互式图谱（D3.js/ECharts）+ PDF静态报告
- 引用模板：自动生成"证据链说明"文字段落（可直接嵌入审计报告）
- 关键功能：一键生成 "证据摘要卡片"（A4一页纸），含图谱缩略图+文字结论+数据表格

### 增强3（P2）：围标串标专项SQL/Python脚本模板库（3天）
**定位**：v6 DSG数据脚本生成器 扩展包
**内容**：
- 5个特征各提供3套脚本（MySQL/PostgreSQL/Pandas），共15个模板
- 参数化设计：表名/字段名可配置
- 含注释：每行SQL/代码标注对应审计含义
- 数据脱敏模板：案例数据脱敏后可直接运行验证

### 增强4（P2）：特征命中率统计与组合优化器（3天）
**定位**：数据分析Agent 辅助工具
**内容**：
- 各特征独立命中率统计（基于标段样本）
- 特征组合命中率矩阵（2特征→5特征，P(命中|特征A∧特征B)）
- 最优特征组合推荐（ROC/AUC，最大化TPR且控制FPR）
- 自学习：新标段确认结果反馈→更新命中率

### 增强5（P2）：脱敏测试数据集（2天）
**定位**：测试基础设施
**内容**：
- 从文章案例反推构造脱敏测试数据
- 包含正例（已知围标）和负例（正常投标）各50个标段
- 5大特征的完整字段（IP/MAC、报价、保证金流水、文件摘要、时间戳）
- 用于工具开发阶段的回归测试和命中率验证

## 六、关键洞察

1. **填补最大空白——数据采集层**：v3-v8覆盖了分析加工层和报告输出层，v9首次触及数据采集层的交易行为数据（投标IP/MAC/CA证书/提交时间戳），这些数据在传统审计中极少被关注

2. **从"单点检测"到"多维交叉"的范式跃升**：v4/v7工具都是单特征独立检测（文本相似度/报价分布/时滞），v9的5特征交叉验证+证据链闭环是方法论层级的升级——恰好对应架构中辩论引擎的"多Agent并行推演"

3. **证据链图谱=审计报告的"最后一公里"**：v8解决了"人怎么跟AI说话"（交互层），v9解决"AI的结论怎么让人信服"（可信层）——业务部门"模型不一定准"的质疑，本质上不是模型不准，是输出不够直观

4. **命中率数据化是独特资产**：5个特征各有19%-38%的独立命中率基准，这不是经验判断，是3万标段跑出来的数据——可以直接转化为Agent的风险评分模型的先验概率

5. **与v7形成"采购全链条"覆盖**：v7覆盖采购事后（合同金额/供应商/付款），v9覆盖采购事前+事中（投标行为/文件/保证金）——两者合并=招标采购全生命周期审计
