## 二、新增增强方案（3项）

### 增强1（P1）：司法解释KB注入（1天）
**定位**：知识库层——直接注入工程审计Agent和公司审计Agent系统提示
**内容**：
- 将本文23条核心内容提炼为5组KB条目（围标串标/资质出借/转包分包/审计结论/法院移送）
- 注入到 `_KB_SNIPPETS["工程审计准则"]` 中
- 每条KB条目含：法条原文 + 审计关注点 + 裁判后果
- 在Agent输出中自动引用对应法条编号（如"依据法释〔2026〕12号第二条"）

### 增强2（P2）：审计结论时效监控（3天）
**定位**：工具层——国家审计Agent的新功能
**内容**：
- 监控"审计结果确定工程价款"类合同的审计期限（≤1年）
- 自动提醒：距提交竣工结算文件N天，剩余时间（365-N）天
- 对超期未出具审计结论的项目标记"法律风险：可能被承包人申请司法鉴定"
- 与contract_field_extract联动：提取合同中的"审计结论确定价款"条款

### 增强3（P2）：司法-审计协同线索接口（5天）
**定位**：外部接口层——法院→审计的数据通道
**内容**：
- 设计"法院移送违法线索"的标准数据格式（JSON Schema）
- 与建设行政主管部门的违法线索接收接口对接
- Agent自动生成"建议移送"标记：当围标/转包/挂靠风险评分≥4.0时，提示"可移送建设行政主管部门"
- 输出格式兼容第二十二条的"相关情况、问题线索、证据"三要素

## 三、与v9的衔接关系

```
v9（围标串标检测）
  ↓ 检出高风险标段
v10（司法解释KB注入）
  ↓ 自动匹配法律后果
Agent输出示例：
  "标段SEG-001围标风险评分4.5/5.0，命中4/5特征。
   依据法释〔2026〕12号第二条，中标合同应认定无效。
   建议：1.审计取证固化 2.移送建设行政主管部门 3.追回已支付工程款中的虚高部分"
```

**核心增量**：v9告诉你"谁在围标" → v10告诉你"围标了会怎样（合同无效+移送追责）"

## 四、对融策业务的特殊价值

1. **政府审计最直接的司法解释**：第十三条直接规定"审计结论与工程价款"的关系——融策作为政府审计服务机构，这是每天要面对的场景
2. **围标串标审计报告的法律背书**：此前审计发现围标串标只能"建议处理"，现可明确写上"依最高法司法解释第二条，中标合同无效"
3. **审计期限的硬约束**：第十三条第一款"不得超过一年"的期限要求，是审计项目管理的硬约束——超期=面临司法鉴定推翻
4. **审计-司法协同的契机**：第二十二条开辟了法院→建设行政主管部门的线索移送通道，审计机关可作为常设接收端
