## 第一部分：5大隐形利益输送套路

### 套路1：影子公司+代持控股（最主流）
- **操作**：高管通过亲友代持注册空壳公司→国企高毛利业务定向给影子公司→高买低卖/加价分成/虚假服务截留利润
- **特征**：成立短、注册资本低、无资质、无实际办公地、100%依赖国企业务；工商股权无直接关联，实际控制人可穿透追溯

### 套路2：公允价"外衣"+变相让利（最隐蔽）
- **操作**：定价接近市场价但偏离合理区间（10%-30%灰色地带）→附加超长账期/零保证金/坏账兜底→质次产品/虚增数量/额外服务费
- **特征**：价格差在灰色区间难以直接定性；合同条款"看似中性实则倾斜"；交易金额大频次高长期稳定

### 套路3：无偿输送+象征性收费（最易忽视）
- **操作**：资金拆借零利息/1元年租金/无偿技术品牌渠道→无偿担保违规兜底
- **特征**：无对价或远低于成本；长期挂账不结算不催收；无合理商业理由

### 套路4：虚假贸易+空转走单（最易伪装）
- **操作**：无真实货物交割→合同发票资金闭环→"国企→关联方→第三方→回流国企"→通过价差佣金返利截留
- **特征**：货物流、资金流、票据流、合同流"四流不一"；无商业实质；交易对手多为贸易公司空壳

### 套路5：资产处置+低价转让（最易造成大额流失）
- **操作**：改制/混改→低评估→低价转让→高估民营资产、低估国有资产→变相稀释国有股权
- **特征**：评估机构"量身定制"参数；未进场交易未公开竞价；决策程序"走过场"

## 第二部分：4步穿透核查方法

### 第一步：穿透关联方，揪出"影子控制人"
- 全量清单梳理：高管+中层+关键岗位+近亲属→工商/企查查/税务/社保/征信→全口径关联方清单
- 股权穿透核查：逐层穿透→代持协议/隐名股东/一致行动人→频繁变更/亲友股东/无实际经营
- 异常交易锁定：金额大/频次高/毛利异常/合作短/无商业背景→优先核查

### 第二步：多维比对，验证"价格公允性"
- 市场价格比对：同地区/同规格/同质量→偏离度≥10%即需重点核查
- 成本倒算核查：采购→关联方成本+合理利润；销售→国企成本+必要费用+合理利润
- 历史价格比对：同一对手同一标的→突然大幅涨跌/无理由偏离历史区间

### 第三步：三流合一追踪，核查"交易真实性" ⭐核心
- 资金流全链路：逐笔追踪→回流个人账户/资金闭环/拆分转账/现金支取
- 货物流实地：盘点库存→物流单据→是否真实交付→服务类核查成果/工时/照片
- 票据流交叉：合同/发票/出库单/入库单/物流单/回单→日期金额数量规格完全一致

> **核心判断**：三流不一致+无真实货物流转+资金闭环回流 = 虚假交易+利益输送

### 第四步：程序追溯+决策核查，锁定"责任链"
- 决策文件全量调取：董事会纪要/总办会纪要/党委会纪要/采购审批/合同审批/立项/评估/招投标
- 回避制度核查：关联董事股东是否回避；审批流程中关联岗位是否回避
- 异常决策追溯：无立项/无招投标/化整为零规避/紧急采购无理由/审批短/签字不全

## 第三部分：精准定性（可直接套用）

### 3大法律依据

| 法条 | 内容 |
|------|------|
| 《企业国有资产法》第43条 | 关联方不得利用交易谋取不当利益，损害国家出资企业利益 |
| 《企业国有资产法》第44条 | 国有独资/控股公司不得无偿向关联方提供资金/商品/服务/资产，不得以不公平价格交易 |
| 《公司法》第21条 | 控股股东/实控人/董监高不得利用关联关系损害公司利益，违者赔偿 |
| 《国企领导人员廉洁从业若干规定》第7条 | 不得利用职权接受关联方财物、谋取公司商业机会、自营同类业务 |

### 4套定性模板

**（1）影子公司+代持**：
"某某利用职务便利，通过亲友代持设立某某公司（影子公司），与本公司发生关联交易。该交易未履行审批及回避程序，交易对手实际控制人为本公司利害关系人，属于隐性关联交易；通过高买低卖/虚增服务费等方式，变相转移国有资产、输送利益，违反《企业国有资产法》第43、44条。"

**（2）非公允价格**：
"该交易价格偏离同期同类型非关联交易公允价格XX%，无合理商业理由；交易条款明显倾斜于关联方，实质为变相让利、利益输送；未履行公允价格评估及审批程序，违反《企业国有资产法》第44条。"

**（3）无偿/象征性收费**：
"无偿/以1元象征性价格向关联方提供资金拆借/房产租赁，未收取合理对价、未签规范合同、未履行审批程序；直接违反《企业国有资产法》第44条禁止性规定。"

**（4）虚假贸易+空转走单**：
"无真实货物交割，货物流、资金流、票据流不一致，属于虚假贸易空转走单；通过资金闭环、虚开发票套取国有资金；违反《企业国有资产法》第43条、《公司法》第21条。"

## 第四部分：4大避坑红线

1. **无确凿证据，绝不定性"舞弊/贪腐"**：未拿到代持协议+资金闭环+利益分成+谈话承认→只定性"违规关联交易、涉嫌利益输送"，不用"舞弊/贪腐/侵占/挪用"
2. **穿透核查必须留痕、证据闭环**：工商截图+流水明细+价格对比表+会议纪要复印件+谈话记录→"每个结论都有证据、每份证据都可追溯"
3. **严格区分"合规瑕疵"与"利益输送"**：偶尔/小金额/无利益流向/轻微瑕疵→"管理不规范"；长期/大额/单向流出/人为操纵/程序严重违规→"涉嫌利益输送"
4. **终身追责意识**：今天的报告定性可能十年后被追溯→不妥协不通融不隐瞒不简化
