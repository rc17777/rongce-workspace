# 经济责任审计 — 取数深度指南

> 融策多Agent审计平台 | 2026-06-21 | 场景拆解第1篇

---

## 一、先搞清楚审计对象

经责审计取数范围取决于两个变量：

| 变量 | 问题 | 影响 |
|------|------|------|
| 被审计单位性质 | 行政单位 / 事业单位 / 国有企业？ | 决定了用哪个会计制度、看哪些特殊科目 |
| 审计类型 | 任中审计 / 离任审计？ | 决定了时间范围 |
| 任期长度 | 干了几年？ | 3年→3套账；5年→5套账 |
| 有无下属单位 | 一级预算单位还是含二级？ | 决定了要不要合并取数 |

**取数前必须确认的四件事：**
1. 任用文件（确认任期起止日期精确到日）
2. 单位三定方案（确认职责范围，才知道什么该管什么不该管）
3. 适用的会计制度（行政单位会计制度 / 事业单位会计制度 / 企业会计准则）
4. 下属单位清单（含自收自支事业单位、企业化管理单位、协会学会等）

## 二、财务数据：取哪些，取到什么层级

### 2.1 序时账（最核心，必须取）

**取数范围：** 任期全周期 + 前后各推1年

```
例：2019.03 — 2024.03 任期
→ 取 2018.01 — 2025.03 共7年3个月的序时账
```

**为什么前后各推1年？** 很多问题藏在任期交界的"时间窗口"——
- 上任前突击花钱然后交接时账面好看
- 离任前突击审批、突击采购、突击提拔
- 跨任期挂账——上一任留下的烂账到这一任继续挂着

**科目层级要求：**

| 报表类型 | 层级 | 说明 |
|----------|:--:|------|
| 序时账 | **末级科目**（最细） | 至少到末级，含辅助核算。只看一级科目等于没看 |
| 科目余额表 | **末级科目** | 逐月！不是年末一个数。逐月才能看波动 |
| 辅助账 | 按辅助核算展开 | 供应商/客户/项目/部门/个人 五个维度 |
| 总账 | 一级科目汇总 | 辅助参考，用于跟报表勾稽 |
| 明细账 | 末级科目逐笔 | 如果序时账不含摘要，明细账必须有摘要 |

**银行明细账要不要？** 分情况：

```
必须取：往来款专项检查、专项资金审查、大额现金收支多
可不取：如果序时账+银行对账单已经能勾稽上
```

**实操建议：** 先要序时账跑一遍，如果发现大量大额现金收支、或者银行存款科目借贷方跟银行对账单对不上，再补要银行明细账。

### 2.2 科目余额表

**取数要求：**

```
格式：逐月！逐月！逐月！（见过太多被审计单位只给12月31日一个数）
范围：任期全周期 + 前后各1年
层级：末级科目，含辅助核算维度
```

**为什么必须逐月？** 三个审计动作依赖月度数据：

| 审计动作 | 数据要求 | 没有逐月数据怎么办 |
|----------|---------|-------------------|
| 波动分析 | 逐月才能算标准差、找异常月份 | 做不了，只能看趋势 |
| 挂账检测 | 连续N月余额不变的科目=挂账 | 年末数看不出 |
| 突击花钱 | 某月科目余额突增突减 | 只能看到结果看不到过程 |

### 2.3 总账、明细账、日记账

| 账簿 | 是否必须 | 用途 | 替代方案 |
|------|:--:|------|------|
| **总账** | 🟡 辅助 | 与报表勾稽，验证数据完整性 | 可用科目余额表+报表替代 |
| **明细账** | 🔴 序时账无摘要时必取 | 看每笔业务具体内容 | 序时账有摘要可不取 |
| **现金日记账** | 🟡 现金收支多时必取 | 逐笔复核现金流水 | 银行流水替代 |
| **银行日记账** | 🟡 银行存款交易多时取 | 与银行对账单逐笔勾稽 | 序时账银行存款科目+对账单 |

### 2.4 报表

```
必取：资产负债表 + 收入费用表（或利润表）+ 净资产变动表 + 预算执行情况表
范围：任期内每年
层级：全口径（含合并报表如适用）
```

**注意：** 行政事业单位看的是"预算执行情况表"+ "资产负债表"；国企看的是四表一注。不一样，别混。

### 2.5 三公经费及会议费

```
必取：三公经费预算批复 + 三公经费执行明细（逐笔逐月）
范围：任期内每年
格式：含预算数、执行数、差异
层级：因公出国/公务用车/公务接待 三项分开
另加：会议费、培训费明细（类款项级）
```

### 2.6 资产台账

```
必取：固定资产台账（含入账日期、原值、折旧、净值、使用部门、存放地点）
范围：任期起始日和终止日两个时点
格式：.xlsx，含资产分类代码
```

**为什么要两个时点？** 任期初→任期未的资产变化=本期增减，用来计算保值增值率。

### 2.7 往来款明细

```
必取：应收账款/应付账款/其他应收款/其他应付款/预付账款 明细表
范围：任期末全量 + 账龄分析
层级：按对方单位展开，含挂账日期和事由
```

**经责审计的往来款特别关注：**
- 挂账3年以上的——前任留下的还是现任新增的？
- 挂账方是关联单位/个人的——利益输送高危
- 大额预付长期不核销——资金占用

## 三、文本数据：取哪些，格式要求

### 3.1 制度文件

| 文件类型 | 必须取 | 优先格式 | 用途 |
|----------|:--:|:--:|------|
| 内控制度汇编 | ✅ | .pdf / .docx | 法规Agent对照基准 |
| 财务管理制度 | ✅ | .pdf / .docx | 经费使用合规性 |
| 采购管理办法 | ✅ | .pdf / .docx | 判断采购程序是否违规 |
| 资产管理制度 | ✅ | .pdf / .docx | 资产处置合规性 |
| 三重一大决策制度 | ✅ | .pdf / .docx | 判断是否应上会未上会 |
| 差旅费/会议费/培训费办法 | 🟡 | .pdf / .docx | 三公经费审计 |
| 专项资金管理办法 | 🟡 | .pdf / .docx | 有专项资金的必须取 |

**格式要求：** 文字版优先，扫描件需要OCR后Agent才能读。如果制度文件是扫描图片——Agent法规检查能力下降50%。

### 3.2 合同台账

```
必取：任期内全部合同台账（含合同编号、对方单位、签订日期、金额、履约状态）
范围：任期全周期
格式：.xlsx
关键列：合同编号 | 合同名称 | 对方单位 | 签订日期 | 合同金额 | 已付金额 | 标的 | 履约状态 | 验收日期
```

**经责审计合同取数特殊关注：**
- 任期交界点前后3个月签的大额合同（前任突签/现任突签）
- 单一来源采购的合同（为什么没招标？）
- 合同方是关联单位/人员的（利益输送）
- 服务类合同——尤其咨询服务、法律服务，最容易被用来套钱

### 3.3 重大事项决策记录

```
必取：
  - 党组/党委会议纪要（任期内全量）
  - 局长/主任办公会议纪要（任期内全量）
  - 三重一大上会清单（含上会日期、议题、表决结果）
  
格式：.pdf / .docx
用途：法规检察官逐条对照→该上会的上了没？上了的按程序走了没？
```

### 3.4 上级来文与批复

```
必取：
  - 上级下达的预算批复文件
  - 上级下达的资金拨付文件
  - 上级审计/巡视/督查发现问题的反馈意见
  - 同级财政的预算批复和调整批复
  - 纪检监察移送/处理的文件

范围：任期全量
格式：.pdf
```

**这部分数据的重要性常被忽略。** 它回答了一个关键问题：党委书记/局长任期内，上级发现了哪些问题？他整改了没？没整改的还在吗？

## 四、招投标数据（如果涉及采购）

### 4.1 要不要取招投标数据？

```
必须取的情形：
  ✅ 被审计单位任期内有工程建设项目（修楼/修路/改造）
  ✅ 被审计单位任期内有大额设备采购（超过分散采购限额）
  ✅ 被审计单位任期内有服务外包（物业/信息化/咨询）
  ✅ 经责审计中发现大额支出异常 → 追溯其采购程序

可以不取：
  ❌ 纯行政运转的小额采购（办公用品/耗材）
  ❌ 单位没有采购权限（由上级统一采购）
```

### 4.2 取什么

| 数据 | 格式 | 说明 |
|------|:--:|------|
| 招标文件 | .pdf | 提取评标办法、限价、资格条件 |
| 各投标人投标文件 | **.docx优先**，次选.pdf | 围标检测核心数据源 |
| 开标一览表 | .xlsx | 所有投标人报价 |
| 评标报告 | .pdf | 评审过程记录 |
| 中标通知书 | .pdf | 中标金额→跟合同金额对照 |
| 政府采购备案表 | .pdf | 验证是否按规定程序采购 |

## 五、专项资金（单位有专项资金怎么办）

### 5.1 经责审计中的专项资金不是独立的审计类型

它是经责审计的一个子集——被审计领导任期内涉及多少专项资金、每笔的合规性。

### 5.2 取数清单

```
Step 1: 先搞清楚任期内有多少笔专项资金
  → 向被审计单位要：任期内专项资金收支明细表
  → 包含：专项资金名称、资金来源、下达金额、下达时间、支出金额、结余金额

Step 2: 逐笔取数
  每笔专项资金取：
  ├── 资金下达文件（上级拨款依据）
  ├── 专项资金管理办法（使用规则）
  ├── 项目实施方案（钱花在哪的）
  ├── 序时账（对应专项资金科目）
  ├── 支出凭证（大额抽查）
  ├── 验收报告（项目完成没）
  └── 如有采购：招投标+合同全部资料
```

### 5.3 专项资金在经责审计中的三个特殊关注点

| 关注点 | 问题 | 取数要求 |
|--------|------|----------|
| **挤占挪用** | 专项资金是否被挪去发工资/报销/日常运转？ | 序时账专项资金科目借贷方，逐笔追踪对方科目 |
| **闲置沉淀** | 钱拨下来了但几年没动？ | 专项资金科目余额表逐月→连续多月不变=闲置 |
| **配套资金** | 上级拨100万要求地方配套100万，配套到位了没？ | 财政配套资金拨付凭证+配套部分序时账 |

## 六、不同单位性质的差异

### 6.1 行政单位（局/委/办）

```
会计制度：政府会计制度（双分录：预算会计+财务会计）
特殊关注：
  - 预算执行率（预算批复 vs 实际支出）
  - 三公经费控制（只减不增原则）
  - 非税收入管理（有没有坐支？）
  - 结余结转资金（年底突击花钱？）
  
特殊取数项：
  + 预算批复与调整文件
  + 财经纪律检查报告（如有）
  + 绩效自评报告（财政要求）
```

### 6.2 事业单位（学校/医院/科研院所）

```
会计制度：政府会计制度
特殊关注：
  - 事业收入和经营收入（有没有乱收费？）
  - 对外投资（事业单位能不能搞投资？投了有没有批？）
  - 人员经费（超编人员工资从哪出的？）
  
特殊取数项：
  + 事业收入明细（收费项目+标准+收入金额）
  + 经营收入明细（经营活动合规性）
  + 人员编制文件和实际在编人数
```

### 6.3 国有企业

```
会计制度：企业会计准则
特殊关注：
  - 经营业绩考核目标完成情况
  - 重大投资决策（可行性→董事会→执行→回报）
  - 关联交易（公允性、披露完整性）
  - 薪酬管理（高管薪酬是不是超标？）
  - 产权管理（国有资产有没有流失？）
  
特殊取数项：
  + 董事会/监事会决议 + 会议记录
  + 经营业绩考核文件 + 指标完成数据
  + 企业产权登记表
  + 关联方清单 + 关联交易台账
  + 高管薪酬方案 + 实际发放明细
  + 对外投资台账（投了哪些公司？持股比例？分红情况？）
```

### 6.4 含下属单位的情况

```
一级预算单位含二级单位时：
  取数范围 = 本级 + 全部下属单位（含自收自支、企业化管理）

特别提醒：
  ⚠️ 协会学会挂靠——是不是单位出资养着的？人员工资从哪出的？
  ⚠️ 自收自支事业单位——钱没进财政专户？经营收入去向？
  ⚠️ 企业化管理单位——国有资产有没有流失？
```

## 八、数据到位后的Agent衔接

数据按目录放好后，经责审计自动匹配6个Agent：

```
raw_data/            Agent自动读取
├── 财务/           → data_scout 读取
│   ├── 序时账.xlsx
│   ├── 科目余额表.xlsx
│   ├── 往来明细.xlsx
│   └── 资产台账.xlsx
├── 合同/           → contract_hound 读取
│   └── 合同台账.xlsx
├── 制度/           → law_inspector 读取
│   └── *.pdf
├── 决策记录/       → law_inspector 读取
│   └── *.pdf
├── 招投标/         → bid_hunter 读取（如有）
│   └── *.docx
└── 专项/           → data_scout + contract_hound 读取（如有）
    └── *.xlsx

产出：findings → collision → workpapers → report → review
```

## 九、常见踩坑与应对

| 坑 | 描述 | 应对 |
|----|------|------|
| **坑1** | 被审计单位说"序时账没有摘要" | 改要明细账，虽然慢但至少有摘要 |
| **坑2** | 科目余额表只给年末数不给逐月 | 退回重要——没有逐月数据做不了波动分析 |
| **坑3** | 合同台账缺失——说"合同没归档" | 从序时账反查：找出对方的应付账款/预付账款科目→扒出交易对手→推断合同 |
| **坑4** | 制度文件是扫描图片 | 要求提供文字版。拿不到的自己OCR，但要降Agent置信度 |
| **坑5** | 专项资金科目编码不统一 | 先汇集所有资金下达文件→反查资金名称→在序时账中按名称搜索 |
| **坑6** | 领导班子说"会议纪要丢了/没做" | 已经是内控缺陷了——记下来，本身就是一条发现 |
| **坑7** | 离任审计——人已经走了，问不到 | 从序时账+银行流水反推。钱在哪里，人的行踪就在哪里 |
| **坑8** | 下属单位不配合（说"跟我们无关"） | 如果一级预算单位对下属有管理责任——不提供的本身也是问题 |
