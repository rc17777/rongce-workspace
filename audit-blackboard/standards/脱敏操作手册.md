## 不同审计场景的脱敏要点

### 场景1：专项资金审计（如社保补贴、营养餐）

**高风险字段**：
- 受益人姓名、身份证号、银行卡号、手机号
- 发放金额、家庭住址

**操作要点**：
1. 受益人名单表必须全量脱敏
2. 金额可区间化（仍可分析"同一人多次领取""超标准发放"）
3. 地址保留到区县（仍可分析区域分布合理性）

**示例**：

```python
# 自定义规则：营养餐项目
custom_rules = {
    "学生姓名": "name",
    "家长电话": "phone",
    "身份证号": "id_card",
    "补贴金额": "amount",
    "学校名称": "company_name",  # 学校名称轻度脱敏
    "家庭地址": "address"
}
```

### 场景2：招投标审计

**高风险字段**：
- 投标企业名称、统一社会信用代码、法定代表人
- 专家姓名（评标专家）
- 报价金额

**操作要点**：
1. 专家姓名脱敏为"专家A/B/C"（评标过程仍需分析，但对外不可暴露）
2. 企业名称保留行政区划+行业（仍可分析"同地区企业围标"）
3. 报价金额区间化（仍可分析"报价规律性""异常低价/高价"）

### 场景3：经济责任审计

**高风险字段**：
- 被审计领导姓名、亲属信息
- 个人财产、房产、投资信息
- 敏感职务任免信息

**操作要点**：
1. 被审计领导姓名替换为"某同志"或"被审计对象"
2. 亲属信息全部替换为"亲属A/B/C"
3. 个人财产金额区间化（仍可分析"资产异常增长"）
4. 此类项目脱敏后建议标为**L4绝密级**，不上传任何在线工具

### 场景4：工程审计

**高风险字段**：
- 合同金额、分包商信息、工程地址
- 项目负责人、监理人员

**操作要点**：
1. 合同金额区间化（仍可分析"合同变更异常""超付"）
2. 工程地址保留到区县（仍可分析"选址合理性"）
3. 分包商名称轻度脱敏（仍可分析"关联分包"）

## 脱敏质量检查（5分钟自检）

每批次脱敏后，数据专员必须执行以下检查：

### 检查清单

- [ ] **抽查10%数据**：随机打开脱敏文件，检查关键字段是否正确脱敏
- [ ] **检查隐藏数据**：Excel是否有隐藏Sheet？PDF是否有隐藏图层？
- [ ] **检查公式**：Excel中是否还有引用原始数据的公式？
- [ ] **检查元数据**：文件属性中是否还包含作者、公司名等敏感信息？
- [ ] **检查文件命名**：是否已加 `_脱敏` 后缀？
- [ ] **确认分级**：是否为L3/L4级数据？（不确定就高不就低）
- [ ] **主审确认**：项目主审已签字确认脱敏结果

### 快速抽查脚本

```python
# 抽查脱敏结果
df = pd.read_excel("脱敏数据.xlsx")

# 检查是否有身份证号残留（18位数字）
for col in df.columns:
    if df[col].astype(str).str.match(r'^\d{17}[\dXx]$').any():
        print(f"⚠️ 列 [{col}] 发现未脱敏身份证号！")

# 检查是否有手机号残留（11位数字开头）
for col in df.columns:
    if df[col].astype(str).str.match(r'^1\d{10}$').any():
        print(f"⚠️ 列 [{col}] 发现未脱敏手机号！")

# 检查是否有精确金额（非区间化）
# 如果金额列有精确到小数点后两位的数字，说明未区间化
```

## 常见问题

### Q1：脱敏后还能做数据分析吗？

**可以**。脱敏只是隐藏精确值，不影响分析维度：
- 金额区间化 → 仍可分析"大额/小额/异常区间"
- 姓名脱敏 → 仍可分析"同一人多次出现"
- 地址保留到区县 → 仍可分析"区域集中度"

### Q2：Excel有多个Sheet，都能脱敏吗？

**可以**。脚本会自动处理所有Sheet，每个Sheet独立脱敏。

### Q3：脱敏后的数据能还原吗？

**不能**。脱敏是单向操作，原始数据需单独加密保存。脱敏前务必备份。

### Q4：有些字段列名很奇怪，脚本识别不到怎么办？

使用 `--rules` 参数传入自定义规则JSON文件，指定列名→脱敏类型的映射。

### Q5：金额区间化后，怎么做精确金额统计？

**脱敏仅用于上传AI/共享/归档**。如需精确金额统计：
1. 在本地安全环境用原始数据计算
2. 计算结果脱敏后输出
3. 永远不要把精确金额上传到在线AI
