# Wiki 结构规范

语言：中文

## 目录结构
- raw/ — 原始素材（不可变）
- wiki/ — 编译后的知识页面
- purpose.md — 知识库方向
- index.md — 页面索引
- log.md — 操作日志

## 页面规范
- 每页必须有 YAML frontmatter
- 使用 [[wikilink]] 做交叉引用
- 置信度标注：EXTRACTED / INFERRED / AMBIGUOUS / UNVERIFIED

## 实体类型
- regulation: 法规/标准
- method: 方法/技术
- case: 案例
- concept: 概念
- organization: 机构
