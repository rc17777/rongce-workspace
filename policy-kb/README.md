# 政策资料库（Policy KB）

> 融策会计师事务所 · 融策工程咨询公司
> 覆盖行政事业单位、国有企业、交叉领域的政策法规知识库

## 目录结构

```
policy-kb/
├── README.md                   ← 本文件
├── 行政事业单位/               ← 13 个领域
├── 国有企业/                   ← 15 个领域
├── 交叉领域/                   ← 7 个领域
├── templates/                  ← 文档模板
└── .index/                     ← 机器可读索引
```

## 使用方式

### 1. 按领域检索
直接进入对应领域的子目录，每个目录下有 `README.md` 索引文件，列出该领域的核心法规清单。

### 2. 政策文件命名规范
```
领域编号-法规简称_发布日期.txt
示例: 03-政府采购法实施条例_2015-03-01.txt
```

### 3. 单个政策文档格式
参见 `templates/policy-template.txt` 模板。
