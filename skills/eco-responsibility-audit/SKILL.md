# 经济责任审计技能

## 概述

本技能基于《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》
及相关实务经验，为审计人员提供全流程AI辅助。

## 快速开始

根据用户需求，匹配以下任务类型并按对应流程执行：

| 任务 | 用户可能的说法 | 操作 |
|------|--------------|------|
| 审计重点清单 | "帮我列一下审计重点"、"关注事项" | → 参见 [references/audit-focus.md](references/audit-focus.md) |
| 审计报告 | "写个报告初稿"、"报告怎么写" | → 参见 [references/audit-report.md](references/audit-report.md) |
| 问题定性 | "这个问题怎么定性"、"依据什么法规" | → 参见 [references/issue-classification.md](references/issue-classification.md) |
| 审计底稿 | "底稿模板"、"工作记录" | → 参见 [references/working-papers.md](references/working-papers.md) |
| 整改建议 | "提整改建议"、"管理建议" | → 参见 [references/rectification.md](references/rectification.md) |
| 全链SOP | "从政策法规到数据归档怎么做"、"全流程实操指南" | → 参见 [references/full-chain-sop.md](references/full-chain-sop.md) |
| 审计方案 | "做个审计方案"、"怎么安排" | → 参见 [references/audit-plan.md](references/audit-plan.md) |
| 访谈提纲 | "访谈问什么"、"谈话提纲" | → 参见 [references/interview-guide.md](references/interview-guide.md) |

## 通用要求

1. **法规引用**：优先引用现行有效法规，注明条款号。常用法规清单见 [references/laws-index.md](references/laws-index.md)
2. **格式规范**：使用审计行业通用术语，金额保留两位小数，日期格式 YYYY年MM月DD日
3. **用户信息**：如用户提供了被审计单位、人员、任期等信息，直接代入模板；如缺失，先询问再输出
4. **脱敏提醒**：涉及真实案例时提醒用户注意脱敏

## 工作流

1. 确认用户意图（哪个任务类型）
2. 收集必要信息（单位类型、人员职务、任期、预算规模等）
3. 读取对应 references 文件获取模板和指引
4. **如涉及数字化/智慧审计场景，查阅 [digital-eca.md](references/digital-eca.md)**
5. 生成输出，标注需要人工复核的判断点

## 高校领导经济责任审计7环节深度分析

> 来源：楠惪湖途《高校领导经济责任审计，别只盯着"钱"》（审计实践公众号）
> 适配场景：高校校长/党委书记经责审计、任期审计、离任审计

### 核心理念
经济责任审计审的不是账，是人；不是钱花没花错，是事干没干好。
财务审计看钱花得对不对，经责审计看事干得怎么样。

### 环节一：重大经济决策（防"一言堂"）
**审计范围**：新校区建设、大额设备采购、对外投资、合作办学、资产处置、薪酬分配

**审计方法**：
- 翻会议纪要，看是否有党委会/校长办公会的讨论记录
- 查决策文件，看是否有签字、是否有不同意见
- 访谈班子成员，验证决策过程是否充分讨论
- 对比决策依据，可行性研究、专家论证报告是否齐全
- 评估决策效果，项目是否达到预期目标

**典型案例**：某高校校长个人决定投资产业园项目，未经党委会讨论、无可行性研究，项目烂尾损失3000万。

**法规依据**：《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》

### 环节二：预算执行（看钱花得值不值）
**审计范围**：财政拨款、学费收入、设备采购、三公经费

**审计方法**：
- 对比预算和决算，计算偏差率
- 分析资金支付进度，关注年底突击花钱
- 抽查大额采购，验证设备是否在用、使用效益
- 检查预算编制是否虚报、漏报
- 评估资金使用有效性，闲置浪费情况

**典型案例**：某高校设备采购预算5000万实际只花2000万，剩余3000万年底突击花完买了一批用不上的设备。

**法规依据**：《预算法》、《高校财务制度》

### 环节三：基本建设（高校审计"重灾区"）
**审计范围**：新校区建设、改扩建工程、大型修缮

**审计方法**：
- 查立项文件，审批手续是否齐全
- 查招投标记录，是否存在围标串标、关联关系
- 查工程变更签证，变更比例是否合理（正常应在10%以内）
- 查工程款支付，是否超付、虚付
- 去现场比对，图纸和实际是否一致
- 查竣工验收，是否未批先建、未验先用

**典型案例**：某高校新校区建设：无施工许可证开工；施工单位为校领导亲戚企业；工程变更高达30%；部分工程未验收已投入使用。

**法规依据**：教育部《关于加强直属高校基本建设管理工作的意见》

**技能联动**：bid-collusion-audit（招投标检测）

### 环节四：招生录取（教育公平"生命线"）
**审计范围**：招生计划分配、录取程序、特殊类型招生（艺术类/体育类/自主招生）

**审计方法**：
- 调取招生录取数据，分析分数分布是否异常
- 抽查考生档案，排查不该录的/该录没录的
- 查特殊类型招生，评委打分一致性分析
- 访谈招生工作人员，了解实际流程与制度是否一致
- 查点招线索，内部指标、赞助费等

**典型案例**：某高校艺术类专业招生，个别评委打分离谱，高分落榜低分录取。调查发现评委收家长好处费。

**法规依据**：教育部《高校招生工作"十严禁"》

### 环节五：科研经费（成果导向审计）
**审计范围**：科研项目申报、经费使用、成果验收

**审计方法**：
- 核对科研项目清单与成果清单，是否匹配
- 抽查大额支出，验证是否真实发生
- 访谈科研人员，了解项目实际进展
- 核查论文/专利，真实性验证（代写/买论文）
- 验收环节，是否走过场

**典型案例**：某项目结题报告称发表论文5篇，审计发现3篇是花钱买的、2篇是学生代写的，项目负责人套取经费50多万。

**法规依据**：科技部、教育部《关于加强高等学校科研经费管理的意见》

**技能联动**：audit-anomaly-detect（费用异常筛查）

### 环节六：校办企业（防"小金库"）
**审计范围**：产权关系、经营效益、利润分配、领导兼职取酬

**审计方法**：
- 查工商登记，产权归属是否与学校清晰分离
- 查财务报表，真实盈亏
- 查高管薪酬，是否与效益匹配、有无违规
- 查费用报销，有无提款机现象
- 访谈企业员工，了解实际经营状况

**典型案例**：校办企业连年亏损但高管年薪百万，费用报销随意，利润被吃掉。

**法规依据**：教育部《关于进一步加强高校校办企业管理的意见》

### 环节七：内部控制（制度管不管用）
**审计范围**：制度健全性、执行到位度、监督有效性

**审计方法**：
- 抽取业务样本，测试是否按制度执行
- 访谈关键岗位，了解制度执行的真实情况
- 测试控制节点，能否被绕过
- 查特批记录，领导签字绕过制度的频率
- 风险评估，是否存在内控盲区

**典型案例**：某高校财务制度健全但执行全是例外——领导签字就能绕过制度。结论：制度形同虚设。

**法规依据**：教育部《关于进一步加强高等学校内部控制建设的指导意见》

### 7环节逻辑链（总链）

```
审计方案(权力关系图+资金流向图+关联方图)
→ 进点查三样(银行对账单/工商信息/合同台账)
→ 7环节逐个开检(决策→预算→基建→招生→科研→校办→内控)
  ├→ 环节1: 会议纪要审查 → 个人决定vs集体决策
  ├→ 环节2: 预算决算偏差>30% → 突击花钱 → 设备闲置
  ├→ 环节3: 无证开工/亲戚中标/变更>30% → 现场比对
  ├→ 环节4: 录取分数异常 → 评委打分一致性分析
  ├→ 环节5: 论文清单vs发表记录 → 代写/买论文取证
  ├→ 环节6: 工商查询 → 产权归属 → 高管薪酬匹配度
  └→ 环节7: 制度文本vs操作痕迹 → 签字绕过频次统计
→ 疑点清单(按P0/P1/P2分级) → 核实取证 → 定责 → 报告
```

### 五个必审清单
| # | 必审项 | 核心检查要点 |
|---|--------|-------------|
| 1 | 重大决策 | 程序合规？集体研究？效果评价？ |
| 2 | 预算执行 | 钱花对？效益好？浪费否？ |
| 3 | 基本建设 | 手续全？招标规范？变更合理？ |
| 4 | 招生录取 | 计划公平？程序规范？违规操作？ |
| 5 | 科研经费 | 申报真实？使用合规？成果真伪？ |

### 核心原则
别只盯着钱，要盯着人；别只盯着账，要盯着事；别只盯着过去，要盯着未来。

## 经济责任审计"审、定、评、用"全链条方法论

> 来源：周巍、屠瑜、张涯《领导干部经济责任审计"审、定、评、用"全链条实现路径研究》
> （浙江省绍兴市审计局，《中国审计》2024年第5期）
> 对接：本技能7环节+172项法规库解决"审什么"，本节解决"定责、评价、运用"

### 一、审有靶心 — 审计内容清单化

将审计内容细化为可操作的具体事项清单：

**共性必查事项**：对照《规定》第17-19条逐项分解。例如"贯彻执行经济方针政策"可细化为：
- 上级重大经济方针政策贯彻执行情况
- 上级规划/计划类文件明确的重大工作安排落实情况
- 上级领导指示批示精神贯彻落实情况
- 上级下达的年度工作目标任务完成情况

**个性必查事项**：结合被审计单位职能特色和领导干部个性特点添加

**产出物**：审计项目完整的事项查核清单（共性+个性）

### 二、定有链条 — 定责取证明晰化

**三条权责匹配原则：**

| 原则 | 要点 |
|------|------|
| 任期权责匹配 | 任期内的行为；前任遗留问题现任未有效制止也要追责 |
| 管辖范围匹配 | 本级及下一级；三级以下的普遍性问题也应关注 |
| 履职情形匹配 | 兼任下级正职的，仅对所兼任职务的经济责任负责 |

**定责取证双链模型：**

**形式要件链**（5项取证内容）：
1. 领导干部职责分工情况
2. 会议纪要、记录、批示、文件、合同等资料
3. 谈话问询结果
4. 对前任乱作为/不作为事项是否制止或改进
5. 对前任工作是否接续开展

**实质要件链**（过程→性质→后果三维度）：

| 维度 | 分类 | 具体情形 |
|------|------|---------|
| 过程(6类) | 未经民主决策 | 直接决定、批准、组织实施重大经济事项 |
|  | 多数不同意 | 民主决策时在多数人不同意情况下直接决定 |
|  | 多数同意 | 民主决策时在多数人同意情况下决定 |
|  | 授意指使 | 授意、指使、强令、纵容、包庇下属人员 |
|  | 未发表反对 | 参与决策时没有发表明确的反对意见 |
|  | 疏于监管 | 未及时发现和处理管辖范围内的问题 |
| 性质(6类) | 违反法规 | 违反党内法规、法律法规、政策规定 |
|  | 贯彻不力 | 贯彻方针政策不坚决不全面不到位 |
|  | 未完成任务 | 未完成第一责任人事项 |
|  | 违内规 | 违反部门/单位内部管理规定 |
|  | 决策失误 | 决策不当或决策失误 |
|  | 其他 | 其他不履行/不正确履行职责 |
| 后果(2类) | 有后果 | 造成实际损失/不良影响 |
|  | 无后果 | 未造成后果 |

**定责公式**：形式要件 + 实质要件(过程+性质+后果) → 对照《规定》第40-41条 → 直接责任/领导责任

**三个区分开来（容错免责）**：
- 符合容错情形的，可视情况不予定责
- 贯彻不坚决但未造成后果的 → 不定责
- 贯彻不坚决且造成后果的 → 可定直接责任

### 三、评有标准 — 评价结果定性规范化

**评价三原则**：
1. 客观公正：以事实为准绳，充分证据支撑
2. 重要性：重要岗位/职责/决策重点关注
3. 全面性：覆盖所有责任范围，不片面不遗漏

**定量评价模型**：
综合考虑以下因素生成量化评价口径：
- 审计反映问题数量
- 定责问题及直接责任问题占比
- 严重问题及较严重问题数量及占比
- 是否存在触碰"红线""底线"问题
- 履职成效（经济指标改善、内控加强等）

**可评价为"好"的条件**（同时满足）：
- 不存在违反《规定》第40条所列问题
- 不存在本人违纪违规问题
- 满足以下至少一项：
  - 主要经济指标有特别大改观
  - 内控管理有质的改观
  - 解决了前任遗留的老大难问题
  - 创新型经验被省部级及以上肯定推广

### 四、用有成效 — 结果运用机制化

**融入干部"选育管用"全链条**：
1. 成效会商研判：审计+组织部门联合研判，结果作为考核任免奖惩依据
2. 容错免责机制：以"三个区分开来"为导向，明确免责情形和程序
3. 全周期一本账：构建以经责审计为主体的干部职业生涯审计监督体系

**融入全面从严治党**：
1. 重大审情报告平台：建立健全常态化报送和重要审计情况报告机制
2. 问题线索移送机制：移送前精准研判→移送中沟通跟进→移送后跟踪问效
3. 完善党风廉政考核：审计结果纳入党风廉政建设责任制考核

**融入国家治理**：
1. 以审促改：分析问题原因→出具建议→深挖政策制定层面问题
2. 以审促防：构建风险预警体系，点上问题面上预警，发挥"审计一点、规范一片"
3. 以审促治：发现资源配置问题→优化决策→为党委政府顶层设计提供参考

### 全链条速记口诀

> 审有靶心清单化，定有双链权责明；
> 评有三原则量结合，用有成效机制化；
> 定性定量不偏废，容错免责要分清；
> 审评定用四贯通，经责审计上水平。

## 扩展场景：经责审计与自然资源资产离任审计相结合

> 来源：周敦祥《对领导干部自然资源资产离任审计与经济责任审计相结合的一点思考》
> （审计署驻南京特派办，《中国审计报》）
> 用途：当审计对象涉及资源环境管理职责（地方党政主要领导）时参考

### 两者结合的四大可行性

| 维度 | 说明 |
|------|------|
| 目标一致 | 都促进正确政绩观，贯彻新发展理念 |
| 对象重叠 | 都是地方党政主要领导和资源环境部门主要领导 |
| 内容互补 | 资源环境管理本就是《经责审计规定》中的重要内容 |
| 方式相似 | 都"上审下"，程序和方法相同 |

### 五同步实施格局

**1. 项目计划统筹**
组织部门同步安排经责和资审，避免同一年经责下一年资审

**2. 现场同步实施**
一次进点，一个审计组设两个小组（经责组+资审组），统筹协作信息共享

**3. 定责证据兼取**
- 按"一项决策一条线、一个项目全过程"要求取证
- 对重大决策和项目，获取充分定责证据
- 界定领导干部应当承担的经济责任

**4. 数据统筹分析**
统一采集数据，融合分析，通过总体分析确定核查重点

**5. 结果同步运用**
一次审计两个报告，分别报送；联席会议同步运用

### 三大风险防控

| 风险 | 防控方法 |
|------|---------|
| 范围选取不当 | 经责突出经济责任，资审抓主要资源，依当地实际情况选重点 |
| 定责不准确 | 综合考虑多因性/滞后性/系统性/跨区域性，落实"三个区分开来" |
| 评价结论矛盾 | 两报告数据一致、逻辑一致、结论相互印证 |

### 经责审计与资审结合的部分重点领域

- 调整经济结构、转变发展方式（是否考虑环境与可持续发展）
- 重点自然资源开发利用和保护（水/土地/矿产/森林/草原等）
- 生态环保资金使用和政策落实
- 资源环境目标责任制完成情况
- 资源环境项目建设运行

## 操作规范参考：深圳市经济责任审计操作规程（8章76条）

> 来源：《深圳市审计局经济责任审计操作规程》（经济责任审计从这里说起公众号）
> 用途：对标深圳标准，规范操作流程。提供从计划到结果运用的全链条实操指引

### 一、审计计划（第6-11条）

**审计对象分类**：
- 区政府区长、新区党工委书记及主任
- 市委市政府工作部门正职、市属事业单位/法定机构正职
- 国有企业法定代表人（含党委书记、董事长、总经理）

**计划原则**：任中审计为主，优先审计任职时间长的
- 任职不满2年或离任超过1年原则上不安排

**制定程序**（3步）：
1. 组织部/国资委提出建议名单
2. 市纪委监委等征求意见
3. 审计委员会审议决定

### 二、审计准备（第12-23条）

**审计组构成**：
- 组长（处级以上）→ 副组长（可选）→ 主审 → 成员
- 成员应包含：重大政策落实、财政财务、自然资源资产、投资、大数据等专业人员

**调查了解（9项内容）**：
1. 被审计单位性质、组织结构、经营范围
2. 内部控制制度建立及执行
3. 财政财务相关情况
4. 领导干部职责范围
5. 任期内重大经济事项决策
6. 重大投资项目决策
7. 大额资金使用
8. 廉洁从政情况
9. 初步判断可能存在问题的领域

**审计通知书**：实施前3日送达（不含送达日、进点日和节假日）

### 三、审计实施（第24-43条）

**进点会**：审计局领导+审计组+被审计单位领导班子+内设机构负责人
- 议程: 宣读通知书→介绍安排→述职报告→领导提要求

**资料清单（13类必收）**：
1. 述职报告
2. 单位总体情况介绍
3. 职责分工和机构编制
4. 工作计划总结与考核结果
5. 重大决策制度、会议纪要、批示记录
6. 基建项目全过程资料（立项→验收）
7. 财政财务收支资料（预决算→账簿→凭证→债务）
8. 重要经济合同、业务档案、内控制度
9. 国有资产使用处置资料
10. 自然资源和生态环保资料
11. 财务/业务/管理信息系统电子数据及技术文档
12. 以往审计整改情况、内审报告
13. 审计组要求提供的其他资料

**承诺书**：被审计单位负责人+财务负责人对资料真实性书面承诺

**9大类审计内容（第32条）**：
1. 贯彻执行经济方针政策（时间表+路线图+阶段性目标）
2. 重要发展战略规划制定执行效果
3. 重大经济事项"三重一大"决策执行效果（含决策事项清单梳理）
4. 财政财务管理和经济风险防控（含政府性债务+隐形债务）
5. 企业法人治理结构和内控（含党组织/董事会/监事会/经理层）
6. 民生保障和生态环境保护
7. 党风廉政建设和廉洁从业（八项规定+四风问题）
8. 以往审计发现问题整改（新官理旧账）
9. 其他需要审计的内容

**取证要求**（第37条）：
- 围绕权力运行轨迹：决策权+管理权+监督权全过程
- 证据三要素：批示+签发文件+会议记录+会议纪要+合同协议+经办人证词
- 不少于2名审计人员签字确认

### 四、审计报告（第44-65条）

**报告结构**：
1. 被审计单位基本情况
2. 总体评价（定性+定量结合）
3. 主要业绩
4. 审计发现的主要问题和责任认定
5. 审计建议

**评价三原则**（第47条）：
1. 客观公正：有依据，依法规
2. 实事求是：审什么评什么，审计证据不充分不评价
3. 三个区分开来：先行先试失误 vs 明知故犯；探索性失误 vs 明令禁止；无意过失 vs 谋取私利

**直接责任6种**（第50条）：
1. 个人直接决定或通过会议起决定性作用且违反法规
2. 授意指使强令纵容包庇下属违规
3. 贯彻方针政策不坚决不全面不到位造成损失
4. 未完成第一责任人事项造成损失
5. 未经民主决策或在多数人不同意时决定造成损失
6. 不履行或不正确履行职责起决定性作用

**领导责任5种**（第51条）：
1. 多数人同意但决策不当造成损失
2. 违反内部管理规定造成损失
3. 参与决策未发表反对意见造成损失
4. 疏于监管未及时发现处理问题造成损失
5. 直接责任外不履行或不正确履行职责

**报告编审流程**：审计组讨论 → 征求意见稿 → 送达被审计单位（10个工作日反馈）→ 核实修改 → 业务部门复核 → 审理部门审理 → 审计业务会审定 → 修改完善 → 主要负责人签发

**附件系统（28个标准表格）**：
本操作规程附有28个标准表格模板，涵盖从审计通知书到审计结果反馈的全流程。包括但不限于：
- 调查了解记录、审计实施方案及调整表
- 审计通知书、审计公示、审计工作现场标识
- 进点会会议议程、审计承诺书
- 审计谈话提纲和记录
- 审计取证单、审计工作底稿
- 审计报告（征求意见稿）、意见回复单
- 审计组讨论起草报告记录
- 审计组对反馈意见采纳情况的说明
- 审计报告、审计结果报告
- 审计决定书、审计移送处理书
- 业务部门复核意见书、审计事项完成情况审核单
- 审理资料交接清单、审理意见采纳情况说明
- 提请审计业务会议审定文书说明、审计业务会议纪要
- 审计结果反馈会议程
- 审计报告决定书采纳执行情况回复单
- 报送经济责任审计结果的报告

### 五、审计结果反馈（第66-70条）

- 反馈会：审计局分管领导+业务部门+审计组+被审计单位领导班子
- 整改检查：**送达之日起90日内**检查问题整改和处罚执行情况
- 申诉权：被审计领导干部对审计报告有异议的，30日内可向审计办申诉

### 六、审计结果运用（第71-73条）

- 抄送：审计委员会+组织部+纪委+联席会议成员单位
- 归档：审计结果报告+整改报告归入干部本人档案
- 年度分析：每年分析审计结果，发现普遍性倾向性问题，以专题报告/审计要情/审计信息形式报领导
