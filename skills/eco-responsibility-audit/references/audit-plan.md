# 审计方案编制指引

## 使用场景
用户需要为经济责任审计项目编制审计方案。

## 前置信息（如缺失需先询问）
- 审计依据（授权文件/年度审计计划）
- 被审计单位名称、类型
- 被审计人姓名、职务、任期
- 审计组人员配置
- 审计时间安排

## 审计方案模板

### 一、审计依据
根据《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》
及XXX（授权依据），制定本方案。

### 二、被审计对象基本情况
- 单位名称、性质、主要职能
- 被审计人姓名、职务、任职时间
- 单位组织架构、人员编制
- 年度预算/营收规模
- 下属单位情况

### 三、审计目标
对XXX同志任职期间履行经济责任情况作出客观评价，重点关注：
1. 贯彻执行党和国家经济方针政策情况
2. 重大经济决策的合法合规性和效益性
3. 财务管理和资金使用的真实性、合法性
4. 内部控制制度的建立健全和执行情况
5. 个人廉洁从政（从业）情况

### 四、审计范围和重点

#### 审计范围
- 时间范围：XXXX年XX月至XXXX年XX月
- 资金范围：全部财政财务收支及有关经济活动
- 必要时追溯到以前年度或延伸到相关单位

#### 审计重点
根据单位类型选择重点事项（参见 [audit-focus.md](audit-focus.md)）

### 五、审计内容及分工

| 序号 | 审计事项 | 审计人员 | 计划工时 | 主要程序 |
|------|---------|---------|---------|---------|
| 1    | 重大经济决策 |         | X天     |         |
| 2    | 预算执行    |         | X天     |         |
| 3    | 财务收支    |         | X天     |         |
| 4    | 政府采购    |         | X天     |         |
| 5    | 国有资产    |         | X天     |         |
| 6    | 专项资金    |         | X天     |         |
| 7    | 内部控制    |         | X天     |         |
| 8    | 廉政建设    |         | X天     |         |

### 六、时间安排

| 阶段 | 时间 | 工作内容 |
|------|------|---------|
| 准备阶段 | X天 | 下发通知书、收集资料、了解情况 |
| 实施阶段 | X天 | 现场审计、取证、编制底稿 |
| 报告阶段 | X天 | 撰写报告、征求意见、出具报告 |

### 七、审计方法
- 账目审查法
- 抽样审计法
- 分析性复核
- 实地盘点
- 访谈调查
- 大数据分析（如条件具备）

### 八、审计要求
1. 严格执行审计准则和审计"八不准"工作纪律
2. 重要事项及时报告
3. 审计证据充分、适当
4. 做好审计保密工作

## 注意事项
- 方案应在审计进点前完成并经审批
- 实施过程中可根据实际情况调整方案
- 重大调整须报审计机关负责人批准
