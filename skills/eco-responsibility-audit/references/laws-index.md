# 经济责任审计常用法规索引

> 引用法规时请核实时效性。本索引基于截至2026年的现行法规。

## 核心法规
- **《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》**（2019年）
  - 经济责任审计的根本依据，明确审计对象、内容、评价、结果运用

## 财政财务类
- **《中华人民共和国预算法》**（2014年修正）
- **《预算法实施条例》**（2020年修订）
- **《财政违法行为处罚处分条例》**（2004年，2011年修订）
- **《行政单位财务规则》**（2012年）
- **《事业单位财务规则》**（2012年，2022年修订）

## 政府采购与招标类

- **《政府采购法实施条例》**（2015年）
- **《中华人民共和国招标投标法》**（2017年修正）
- **《招标投标法实施条例》**（2019年修订）
- **《必须招标的工程项目规定》**（国家发改委令第16号）

## 地方性补充
各地可能有补充规定，如：
- 省级经济责任审计实施办法
- 地方党政领导干部经济责任审计评价办法
- 各级审计机关的操作指南

> 提示：建议事务所建立本地法规库，收集所在省市的补充规定。
