# 审计报告撰写指引

## 使用场景
用户需要撰写经济责任审计报告初稿或报告中的某一部分。

## 前置信息（如缺失需先询问）
- 被审计人、职务、任期
- 单位名称及类型
- 审计发现的主要问题（用户需提供或由AI根据审计证据生成）
- 审计时间范围

## 报告结构模板

### 一、基本情况
```
根据《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》
及XX（授权文件/年度计划），XX审计组于XXXX年XX月XX日至XXXX年XX月XX日，
对XXX同志担任XXX（单位）XXX（职务）期间（XXXX年XX月至XXXX年XX月）
履行经济责任情况进行了审计。
```

### 二、履行经济责任情况及评价
按以下维度逐一评价，每项给出"较好/一般/较差"的定性判断及依据：

1. 贯彻执行党和国家经济方针政策、决策部署情况
2. 重大经济决策情况
3. 重大投资项目管理情况
4. 财政财务管理情况
5. 国有资产管理情况
6. 内部控制制度建设及执行情况
7. 廉政建设情况

### 三、审计发现的主要问题

每个问题按以下格式撰写：

```
（一）问题标题

问题描述：XXXX年X月至XXXX年X月，XXX单位存在……问题，
涉及金额XX万元。

违反规定：上述行为违反了《XXX办法》第X条"……"的规定。

责任界定：该问题发生在XXX同志任职期间，XXX同志作为XXX（职务），
应负主管/直接/领导责任。
```

### 四、审计建议
针对每个问题提出具体整改建议，参见 [rectification.md](rectification.md)

### 五、需要说明的事项
- 审计范围受限情况
- 其他需要说明的问题

## 撰写要点
- 事实清楚、证据确凿、定性准确、处理恰当
- 问题描述遵循"5W1H"：何时、何地、何人、何事、何因、何果
- 金额精确到元，引用法规注明到条款
- 责任界定区分：直接责任、主管责任、领导责任
- 语言客观中性，避免主观情绪化表述
