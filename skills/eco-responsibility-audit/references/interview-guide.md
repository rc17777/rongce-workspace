# 访谈提纲生成指引

## 使用场景
用户需要为经济责任审计准备访谈/谈话提纲。

## 访谈对象及关注重点

### 对象一：被审计人本人
关注点：任期内重大决策、履职思路、自我评价

示例问题：
1. 请介绍一下您任期内的主要工作思路和重点举措？
2. 任期内有哪些重大经济决策？决策过程是怎样的？
3. 您认为任期内在经济管理方面做得较好的方面和不足的方面分别是什么？
4. 任期内是否接受过审计或检查？整改情况如何？
5. 单位内部控制制度建设情况如何？执行中遇到哪些困难？
6. 对下属单位/部门的财务监管是怎么做的？
7. 任期内是否有对外投资、资产处置等事项？程序是怎样的？
8. 个人有关经济事项报告是否按规定执行？

### 对象二：财务负责人
关注点：财务管理实操、制度执行、异常事项

示例问题：
1. 单位财务管理的组织架构和审批流程是怎样的？
2. 预算编制和执行过程中有哪些主要问题？
3. 有无预算外资金收支？具体情况如何？
4. 专项资金是否专账管理？使用中有无调整用途的情况？
5. 政府采购项目的流程是怎样的？有无投诉或纠纷？
6. 固定资产多久盘点一次？有无账实不符的情况？
7. 往来款项长期挂账的情况是否存在？主要原因是什么？
8. 财务人员配置是否满足不相容职务分离要求？

### 对象三：分管领导/班子成员
关注点：集体决策、分工协作、问题反映

示例问题：
1. 重大事项的决策机制是怎样的？您参与了哪些决策？
2. 您分管领域内有无发现经济管理方面的问题？
3. 班子成员之间的分工协作情况如何？
4. 对单位内控制度的评价如何？
5. 有无发现或反映过经济方面的违规问题？

### 对象四：业务部门负责人
关注点：项目管理、采购需求、资产管理

示例问题：
1. 部门年度项目的立项和资金申请流程是怎样的？
2. 项目实施过程中有无重大变更？变更程序如何？
3. 采购需求如何提出？有无指定品牌或供应商的情况？
4. 部门使用的固定资产是否定期清查？
5. 有无发现管理制度与实际操作脱节的情况？

### 对象五：下属单位负责人（如有延伸审计）
关注点：资金拨付、监督管理

示例问题：
1. 上级拨付资金是否及时足额到位？
2. 上级单位对你们的监督管理方式有哪些？
3. 有无被要求承担上级单位的费用支出？
4. 重大事项是否需要向上级报批？执行情况如何？

## 访谈注意事项
1. 访谈前应熟悉被访谈人基本情况和职责范围
2. 准备好需核实的具体事项，有针对性地提问
3. 访谈记录须经被访谈人确认签字
4. 注意交叉印证——不同对象的回答相互比对
5. 对敏感问题注意提问方式，避免诱导性提问
6. 访谈可作为审计线索来源，但不能替代审计证据
