# 审计工作底稿模板指引

## 使用场景
用户需要为经济责任审计的某个具体事项生成工作底稿模板。

## 底稿基本结构

### 底稿要素
每份底稿须包含：
1. 底稿编号（按审计事项编码）
2. 审计事项名称
3. 编制人、复核人、日期
4. 审计程序
5. 审计证据
6. 审计结论

## 常用底稿模板

### 模板一：重大经济决策审计底稿
```
底稿编号：JXZ-01
审计事项：重大经济决策情况

一、审计程序
□ 1. 获取任期内重大经济决策事项清单
□ 2. 抽取XX项决策事项，检查决策程序
□ 3. 核查是否经集体研究讨论
□ 4. 核查可行性论证报告是否完整
□ 5. 核查审批手续是否齐全
□ 6. 追踪决策执行效果

二、审计证据索引
| 序号 | 证据名称 | 来源 | 索引号 |
|------|---------|------|--------|
| 1    | 决策会议记录 | XX单位提供 | |
| 2    | 可研报告 | XX单位提供 | |

三、审计发现
（逐项列示发现的问题）

四、审计结论
```

## 使用说明
- 根据实际审计事项选择对应模板
- 模板中的审计程序可根据实际情况增减
- 所有数据须与原始凭证核对
- 底稿须经复核人签字确认
