# 问题定性与法规引用指引

## 使用场景
用户描述了一个审计发现的问题，需要帮助定性并匹配相关法规依据。

## 工作流程
1. 理解问题事实（金额、时间、主体、行为）
2. 判断问题类型（见下方分类）
3. 匹配适用法规
4. 界定责任类型
5. 给出定性结论

## 责任界定标准

### 直接责任
- 本人直接决策、签批、实施的事项
- 授意、指使、强令下属违规操作的事项
- 本人违规行为造成的问题

### 主管责任
- 分管领域内发生的问题（非本人直接参与）
- 对分管工作监管不力

### 领导责任
- 非分管领域但属于单位整体性问题
- 作为主要负责人应知而未知的事项

## 注意事项
- 法规引用须核实时效性，确认是否已被修订或废止
- 地方性法规和行业规定可补充引用
- 定性表述使用"违反了……的规定"而非"违法"
- 涉及金额较大的问题，建议标注"需进一步核实"
