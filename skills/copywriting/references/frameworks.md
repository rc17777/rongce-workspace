# Copywriting Frameworks & Templates

## AIDA Model

| 阶段 | 目的 | 技术 |
|:----|:----|:-----|
| Attention | 抓住注意力 | 数据钩子、反常识陈述、问题开门见山 |
| Interest | 激发兴趣 | 场景代入、痛点共鸣、"你可能不知道" |
| Desire | 创造渴望 | 3个核心利益、客户证言、对比数据 |
| Action | 驱动行动 | 明确CTA、降低门槛、时间限定 |

### 示例：审计服务

**Attention:** "你的停车场数据，有一个你忽略的16.7%"
**Interest:** "不是技术问题，是对账逻辑问题。月租车被重复标记为临时车，一笔就几十块。一个月几百笔呢？"
**Desire:** "XX用我们的清洗方案后，追回率从60%提升到92%，一年多追回XX万"
**Action:** "现在发数据过来，免费预检 → 24h出报告"

## PAS Model

| 阶段 | 目的 |
|:----|:-----|
| Problem | 指出用户意识到或没意识到的痛点 |
| Agitate | 放大痛点的影响（成本、风险、效率损失） |
| Solution | 提供你的方案，直接降低痛点 |

### 示例：工程咨询

**P:** 预算编制靠Excel手工汇总？一个公式错误，整个预算差几十万
**A:** 还不是最严重的——复核时发现不了，施工时才发现，变更费用翻几倍
**S:** 我们做全过程咨询，从预算→评审→结算，数据系统化管理，一个版本贯穿到底

## FAB Model

| 要素 | 定义 | 示例 |
|:----|:----|:-----|
| Feature | 产品有什么 | "全量数据清洗脚本" |
| Advantage | 好在哪里 | "从62,035条中自动识别10,330条异常" |
| Benefit | 对你有什么好处 | "你不用一行行翻Excel，3分钟拿到异常清单" |

### 快速FAB生成
1. 列出3个Features
2. 每个写2个Advantages
3. 最终浓缩成1个Benefit

## 审计行业常用句式

### 开场/钩子
- "我分析了XX条记录，有一个数字很扎眼："
- "你的XX业务，有一个藏在数据里的漏洞"
- "不绕弯子，直说三个发现："

### 数据呈现
- "经核查，XX指标异常率为XX%，远超行业阈值XX%"
- "对比XX期数据，XX项偏差合计XX万元"
- "在XX条样本中，识别出XX条异常，占比XX%"

### CTA
- "建议步骤：3天内启动数据预检"
- "需要一份完整的异常清单？发数据过来"
- "下一步：现场核实 + 追回测算"
