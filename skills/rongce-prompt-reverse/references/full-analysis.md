# 完整十步分析反推指令

> 复制以下全部内容，连同参考图一起发给 ChatGPT 或 GPT Image2。

---

请分析我发给你的这张图，帮我反推出一段可以直接用于 AI 生图工具的 prompt。
你的目标不是简单描述图片，而是还原这张图在工程咨询/政府审计专业场景下的视觉要素。

请在内部完成完整分析，但不要展示分析过程。
最终只输出可直接复制到生图工具里的结果。

---

## 一、判断用途类型

判断这张图属于：标书封面 / 审计报告封面 / 工程方案图 / PPT标题页 / 数据分析看板 / 政府公文内页 / 宣传海报 / 企业品牌展示 / 培训教材配图 / 其他

---

## 二、判断媒介与风格

判断：写实摄影 / 3D渲染 / 建筑效果图 / 手绘线稿 / 数据可视化 / 信息图 / 混合媒介 / 其他

最终 Prompt 必须明确媒介边界。例如：如果是3D渲染，排除real photo；如果是数据可视化，排除artistic illustration。

---

## 三、技法层分析

请在内部按以下维度分析，不要展示分析过程：

### 构图
- 主体位置和占比
- 前景/中景/背景层次
- 留白区域和面积
- 画幅比例（A4竖版/16:9横版/9:16竖版等）
- 构图类型：中心构图、三分法、对称、对角线、框架式、S型、放射线等
- 视觉动线：视线从哪里开始，如何移动

### 镜头与视角
- 平视/俯视/仰视/鸟瞰
- 特写/中景/远景
- 透视关系：近大远小/平行透视/等距透视
- 广角感或压缩感

### 光线
- 主光方向和类型（顺光/逆光/侧光/顶光/环境光）
- 硬光/柔光
- 高光和阴影区域
- 整体冷暖倾向
- 光线造成的情绪

### 色调
- 主色、辅助色、点缀色（尽可能给出接近的色值描述）
- 冷暖倾向和饱和度
- 配色体系：单色调/互补色/邻近色/高级灰/商业清透色
- 色彩如何突出主体

### 材质
- 主体表面质感
- 背景材质（纸张纹理/金属/玻璃/布料/磨砂/光滑等）
- 最关键的质感记忆点

### 景深与背景
- 背景清晰度（清晰/轻微虚化/中度虚化/强虚化）
- 背景几何结构（横线/竖线/网格/圆形光斑/渐变色块/山脉轮廓/建筑线条）
- 背景是叙事信息还是氛围衬托
- 是否有前景虚化/光斑/雾气/渐变/阴影

### 后期与画质
- 精修程度（商业级精修/轻度修饰/原始质感）
- 特效：颗粒/辉光/暗角/锐化/柔焦/胶片感
- 画面清晰度和细节密度

---

## 四、内容层分析

- 主体是什么（建筑/数据图表/文字排版/地图/流程图/抽象图形/多主体组合）
- 主体的外观特征、位置、朝向、状态
- 辅助元素（装饰线条/图标/色块/水印/边框/页码）
- 场景地点和时间感（如有）
- 整体情绪，以及由哪些视觉细节体现
- 如果有文字：分析排版层级、字体风格、位置关系，最终不要求AI生成可读文字

---

## 五、IP/Logo/品牌/文字处理

- 分析时理解其作用
- 最终 Prompt 不依赖具体机构名和Logo
- Logo转写为外观特征（"左上角放置深蓝色机构标识"）
- 不要求生成清晰可读文字

---

## 六、提炼复现关键要素

在内部提炼这张图最不能丢的 3-5 个视觉锚点。优先选择：构图/主体特征/光线/材质/色彩关系/空间层次/关键情绪。

正向 Prompt 的前 1/3 必须优先写入这 3-5 个要素。

---

## 七、生成 Negative Prompt

英文负面词，8-15 条，覆盖：
- 错误媒介
- 多余主体
- 杂乱背景
- 低质画面
- 乱码文字
- 水印/Logo

---

## 八、最终自检

输出前自行检查正向 Prompt 是否包含：主体/构图/镜头/光线/色彩/材质/背景/景深或空间层次/情绪/后期风格/媒介边界/3-5个关键要素。有遗漏则补全。

---

## 观察纪律

- 能直接看到的→描述视觉结果
- 只能推断的→描述视觉效果而非断言技术参数
- 写"柔和圆形光斑"而非"f/1.8"
- 写"呈现3D渲染质感"而非断言具体软件
- 写"类似上午自然光效果"而非断言真实拍摄时间

---

## 最终输出格式

严格只输出以下两项，不要任何分析过程和解释：

```
正向 Prompt：[300-500字中文连续自然语言，非关键词列表]
Negative Prompt：[8-15条英文负面词，逗号分隔]
```

正向 Prompt 要求：
1. 连续自然语言，不要关键词列表
2. 必须包含：主体/构图/镜头/光线/色彩/材质/背景/空间层次/情绪/媒介边界
3. 优先描述最影响相似度的视觉锚点
4. 不要写"高级感、电影感"空泛词，写出这些感觉由什么视觉元素构成
5. 看不清楚的地方，描述视觉效果，不编造事实
6. 不要加入图中没有的新元素
7. 融策业务相关图片优先使用深蓝(#0A1F3F)/青绿(#1A5C6E)/铜金(#C5955C)/暖灰(#F5F2EC)配色关键词
