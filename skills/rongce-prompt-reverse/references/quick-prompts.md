# 场景专用精简反推指令

> 以下三个指令为精简版，适用于对应场景的快速反推。直接复制对应场景的指令，连同参考图发给 AI 即可。

---

## A. 标书/报告封面专用

```
分析这张标书或报告封面图，反推出可直接用于 AI 生图的 Prompt。

重点分析：
- 构图方式（居中对称/左对齐/上下分割/全幅等）
- 配色方案（标注主色/辅色/点缀色，给出接近的色值描述）
- 图文排布关系（标题区位置/主视觉区位置/信息区位置）
- 图形元素类型（建筑线稿/数据折线/抽象几何/地图轮廓/国风水墨/照片混合等）
- 装饰元素（分隔线/色带/图标/水印/边框）
- 整体风格倾向（政务庄重/科技现代/国风典雅/极简留白/商业专业）

最终只输出：
正向 Prompt：[300-500字中文]
Negative Prompt：[8-15条英文]
```

---

## B. 工程方案图/施工图专用

```
分析这张工程方案或施工图，反推出可直接用于 AI 生图的 Prompt。

重点分析：
- 图纸类型（总平面布置/剖面图/效果图/流程图/横道图/管线综合图等）
- 视角和透视（等距/鸟瞰/平视/剖面）
- 标注体系（尺寸标注/标高/图例/说明文字的位置和样式）
- 色彩编码规则（不同元素用哪些颜色区分）
- 空间层次和信息密度
- 专业符号和图例使用

最终只输出：
正向 Prompt：[300-500字中文]
Negative Prompt：[8-15条英文]
```

---

## C. 数据看板/审计图表专用

```
分析这张数据可视化或审计图表，反推出可直接用于 AI 生图的 Prompt。

重点分析：
- 图表类型（柱状/折线/饼图/雷达/桑基/流程/矩阵/仪表盘/复合图表）
- 配色与数据映射关系
- 信息层级（标题→主图表→辅助数据→脚注）
- 标注方式（数据标签/百分比/箭头/差值标注）
- 版式结构（是否多面板/是否卡片式布局）
- 数据密度和留白比例
- 整体风格（BI仪表盘/培训教材/报告内页/信息图海报）

最终只输出：
正向 Prompt：[300-500字中文]
Negative Prompt：[8-15条英文]
```
