# 融策 Prompt 反推工具

> 上传参考图 → 调用定制版十步分析指令 → 输出可直接复制的正向 Prompt + Negative Prompt

## 工作流程

用户提供一张参考图（标书封面/报告封面/工程方案图/审计图表/数据看板/PPT标题页 等），执行以下流程：

### Step 1: 确认图片类型

先确认用户上传的图片属于哪种融策业务场景：

| 类型 | 示例 |
|------|------|
| 标书封面 | 工程咨询/审计服务/政府项目标书封面 |
| 报告封面 | 绩效评价/经责审计/竣工决算报告封面 |
| 工程方案图 | 施工总平图/进度横道图/BIM剖面/造价分解图 |
| 审计图表 | 数据看板/流程图/资金流向图/风险矩阵 |
| PPT标题页 | 审计进点会/项目汇报/培训课件标题页 |
| 其他 | 宣传册/证书/名片/会议物料 |

### Step 2: 选择对应的反推指令

根据图片类型，从 references 中选择对应的指令模板：

- **全能型（默认）**：`references/full-analysis.md` — 完整十步分析，适用于任何融策场景的图片
- **精简型**：`references/quick-prompts.md` — 标书封面 / 工程方案图 / 数据看板三个场景的快速反推

默认使用全能型，用户明确要求"快速"时使用精简型。

### Step 3: 告知用户使用方法

反推指令不能直接在当前对话中执行（当前模型不支持图片视觉识别），需要用户将图片+指令粘贴到 GPT Image2 或支持图片输入的 ChatGPT 中。

向用户输出结果时按以下格式：

```
### 📋 反推指令（直接复制）

[粘贴选择的反推指令全文]

---

### 🎯 使用方法

1. 打开 ChatGPT 或 GPT Image2
2. 上传你的参考图
3. 粘贴上述指令
4. AI 会输出正向 Prompt + Negative Prompt
5. 将得到的 Prompt 拿回来，我可以帮你进一步适配融策配色/排版
```

### Step 4: 辅助优化反推结果

用户拿到反推结果后，可能进一步请求：

- **配色适配**：将 Prompt 中的配色替换为融策标准色（深蓝 #0A1F3F + 青绿 #1A5C6E + 铜金 #C5955C + 暖灰 #F5F2EC）
- **场景适配**：将 Prompt 改造为标书封面/报告封面/PPT配图等具体用途
- **融策品牌注入**：在 Prompt 中加入四川融策的业务特征（审计/工程咨询属性）
- **Prompt 质量检查**：评估反推结果是否包含核心要素（主体/构图/光线/色彩/材质/背景/情绪/媒介边界），缺失则补全

## 反推结果评级

| 评级 | 标准 | 处理 |
|:----:|------|------|
| ⭐⭐⭐ | 450字以上，包含全部要素，主体专项分析精准 | 直接使用 |
| ⭐⭐ | 300-400字，缺少2-3项要素 | 手动补全后使用 |
| ⭐ | 少于300字，只有简单描述 | 重新上传更高清图重试 |
| ❌ | 乱码/编造事实/无视关键视觉元素 | 换图或加文字描述补充 |
