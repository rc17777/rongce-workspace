## 字段说明

### 必填字段

| 字段 | 说明 |
|------|------|
| id | 唯一标识，格式 COT-YYYYMMDD-NNN |
| 场景.审计类型 | 从枚举中选择 |
| 场景.具体环节 | 具体审计环节描述 |
| 思维链（5个步骤） | 每个步骤的"内容"字段必填 |
| 关键发现 | 一句话洞察 |
| 置信度 | 高/中/低 |

### 思维链五步骤详解

**步骤1：事实检查** — 不是描述"应该查什么"，而是"实际查了什么、发现了什么"。要具体、可操作。

> ✅ 好："对比了2024年第三季度的三笔设备采购付款记录与对应的验收单日期，发现第三次付款日期（2024-09-28）距离验收单日期（2024-09-25）仅3天，而合同约定验收后30个工作日内付款"
>
> ❌ 差："检查了资金支付情况"

**步骤2：风险评估** — 为什么觉得这个现象有风险？凭经验还是凭数据？

> ✅ 好："3天内付款远快于合同约定的30个工作日，且该笔付款金额（85万）为本季度最大单笔。经验上，政府项目年底突击付款常伴有验收走过场或不具备付款条件即付款的风险"

**步骤3：排除干扰** — 这是最容易被忽略但最有价值的步骤。记录了被排除的替代解释。

> ✅ 好："考虑了以下替代解释：(1) 可能项目确实提前完成验收→排除，因为查看了监理日志，实际完工日期为9月30日，验收日期9月25日早于完工日期；(2) 可能是财政年底要求提前支付→排除，经查财政部门未发年底提前支付通知"

**步骤4：专业判断** — 综合后的结论。

**步骤5：问题定性** — 将发现归入标准审计问题分类。

### 置信度说明

| 级别 | 含义 | 使用场景 |
|------|------|---------|
| 高 | 推理链完整，证据充分，可以复制到类似场景 | 成熟案例 |
| 中 | 推理链基本完整，部分环节依赖经验判断 | 典型但非常规 |
| 低 | 推理链有跳跃，或高度依赖特定领域经验 | 探索性发现 |
