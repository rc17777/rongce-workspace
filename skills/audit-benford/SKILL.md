# Benford定律异常检测

基于Benford定律（首位数字分布规律），对财务数据进行数字化异常检测。适用于大额支出、采购价格、费用报销等场景。使用卡方检验判断偏离显著性。

## 适用场景

- 怀疑财务数据造假、需要检测数字分布异常

## 执行步骤

### 步骤 1
提供待检测的数值列（如发票金额、报销金额、采购价格）

### 步骤 2
自动计算1-9位数字的实际分布 vs 理论分布

### 步骤 3
卡方检验判断偏离是否显著（p<0.05为异常）

### 步骤 4
输出：分布直方图 + 异常程度评级 + 建议重点核查的方向


## 输出格式

```
【分布偏差】首位数字3出现频率35%（理论12.5%），偏差+22.5%
【卡方检验】χ²=48.3, p<0.001
【结论】数据分布存在显著异常，建议重点核查含3开头的金额记录
【疑似问题】可能存在人为干预数据（如大量以3000元为报销阈值）
```
