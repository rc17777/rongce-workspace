# Copy Editing Skill

## Workflow

### Step 1: 通读了解核心内容

Read the full text first. Don't start editing until you understand what it's trying to say.

### Step 2: 分层修订

Apply edits in this order:

#### 1. 结构层面
- 段落是否按逻辑顺序排列？
- 核心论点是否在开头？
- 有没有重复/冗长的段落可以合并？
- 段落长度是否一致（特别是中英文混排时）？

#### 2. 句子层面
- 长句能否拆分成2-3个短句？
- 被动语态能否改为主动？
- "的"字是否过多？
- 主语是否明确？

#### 3. 措辞层面
- 模糊词 → 精确词（"大量"→"16.7%"）
- 行业黑话 → 易懂表达（如果受众不是业内）
- 陈词滥调 → 具体描述
- 中文"的字结构"过度 → 更简洁的表达

#### 4. 微观层
- 标点符号（中文用全角、英文用半角）
- 中英文间空格
- 书名号/引号规范
- 错别字
- 单位符号统一

### Step 3: 输出格式

```markdown
## 修改摘要
- 结构调整: 2处段落重排
- 句法优化: 7处长句拆分
- 措辞升级: 5处模糊词→精确数据
- 格式修正: 3处中英文标点

## 逐段修改

### §1 原文
[原文内容]

### §1 修改后
[修改后内容]

### §1 修改说明
- [具体修改1]: 原因
- [具体修改2]: 原因
```

## Chinese Copy Editing Guidelines

| 问题 | 错误示例 | 正确示例 |
|:----|:---------|:---------|
| 冗余修饰 | "非常极其重要" | "至关重要" |
| 被动滥用 | "数据被我们清洗了一下" | "我们完成了数据清洗" |
| 模糊表述 | "很多异常数据" | "10,330条异常数据（16.7%）" |
| 标题虚词 | "关于XX问题的思考" | "XX问题：根因分析与整改建议" |
| 长句不换气 | 一行超过60字 | 拆成2-3句 |
| 中英混排空格 | "数据是JSON格式" | "数据是 JSON 格式" |
| 全角数字 | "数据显示３．２%" | "数据显示 3.2%" |
