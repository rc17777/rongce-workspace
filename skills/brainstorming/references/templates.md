# Brainstorming Templates & Techniques

## 基础发散模板

### 1. SWOT 分析
```
              Strengths（优势）          Weaknesses（劣势）
              ┌──────────────────┐       ┌──────────────────┐
              │                  │       │                  │
              │  内部优势因素     │       │  内部劣势因素     │
              │                  │       │                  │
              └──────────────────┘       └──────────────────┘

              ┌──────────────────┐       ┌──────────────────┐
              │                  │       │                  │
              │  外部机会因素     │       │  外部威胁因素     │
              │                  │       │                  │
              └──────────────────┘       └──────────────────┘
    Opportunities（机会）          Threats（威胁）
```

**用法**: 先填内部（S/W）、再填外部（O/T），然后交叉分析：
- SO策略：用优势抓住机会
- WO策略：利用机会改善劣势
- ST策略：用优势抵御威胁
- WT策略：最小化劣势和威胁

### 2. 六顶思考帽 (Six Thinking Hats)

| 帽子 | 颜色 | 任务 | 典型问题 |
|:----|:----|:-----|:---------|
| 🎩 白帽 | 事实 | 客观数据和信息 | "我们有什么数据？缺什么信息？" |
| 🎩 红帽 | 直觉 | 情感和直觉 | "你直接感觉怎么样？" |
| 🎩 黑帽 | 谨慎 | 风险和问题 | "哪里可能出问题？风险在哪？" |
| 🎩 黄帽 | 积极 | 价值和好处 | "这个方案好在哪里？机会在哪？" |
| 🎩 绿帽 | 创造 | 新想法和替代方案 | "还有什么其他方式？" |
| 🎩 蓝帽 | 控制 | 过程和组织 | "我们讨论到哪了？下一步要什么？" |

**用法**: 团队按帽子顺序轮流思考，一次只戴一顶帽子。个人用可以快速切换视角。

### 3. SCAMPER 创意激发

| 字母 | 含义 | 提示问题 |
|:----|:-----|:---------|
| S | Substitute 替代 | "能不能用别的替代？" |
| C | Combine 组合 | "能不能和别的合并？" |
| A | Adapt 适应 | "能不能借鉴别的领域的做法？" |
| M | Modify 修改 | "能不能改大/改小/改形状？" |
| P | Put to other uses 其他用途 | "还能做什么用？" |
| E | Eliminate 精简 | "能不能去掉什么？" |
| R | Reverse/Rearrange 反向/重组 | "反过来会怎样？重新排列？" |

## 收敛筛选模板

### 4. 影响-努力矩阵 (Impact-Effort Matrix)

```
              ┌─────────────────────────────┐
              │      高影响                   │
              │  ┌────────────────┐          │
              │  │   快速胜利      │ 主要项目  │
              │  │  (高影响低努力)  │(高影响高) │
              │  └────────────────┘  ┌─────┐  │
              │                      │█████│  │
    影响       │  ┌────────────────┐  │█████│  │
              │  │  填坑任务       ││█████│  │
              │  │  (低影响低努力)  │ 放弃   │  │
              │  └────────────────┘  └─────┘  │
              │                       │        │
              └─────────────────────────────┘
              低努力 ────────────── 高努力
```

**用法**: 将每个想法放入四个象限，先做"快速胜利"再考虑"主要项目"。

### 5. 二乘二矩阵 (2×2 Prioritization)

| 维度 | 低 | 高 |
|:----|:--|:---|
| **用户价值** | 低价值-容易做 → 顺手做 | 高价值-容易做 → 优先做 |
| | 低价值-难做 → 放弃 | 高价值-难做 → 规划好再做 |
| **实现难度** | | |

### 6. Kano 模型分类

| 类型 | 说明 | 审计行业示例 |
|:----|:-----|:------------|
| 基本需求 | 不做会不满，做了不会特别满意 | "数据准确、报告格式规范" |
| 期望需求 | 做了会满意，不做会不满 | "现场支持、快速响应" |
| 兴奋需求 | 不做不会不满，做了会很惊喜 | "AI自动异常检测、可视化仪表盘" |

## 审计咨询场景的 brainstorming 范例

### 场景: 审计业务创新

**问题**: "停车场审计怎么做新意？"

**白帽（事实）**: 现有62,035条数据，16.7%异常率，停车场月租台账50%无缴费记录

**绿帽（创造）**:
1. 自动对账机器人 → 每月自动跑一次清洗脚本
2. 风险热力图仪表盘 → 实时可视化营收风险
3. 月租车信用分系统 → 与物业联动催缴
4. 第三方数据交叉验证 → 引入ETCP/ETC数据

**黑帽（风险）**:
- 自动脚本需要维护，客户不一定有技术人员
- 仪表盘需要开发成本

**黄帽（价值）**:
- 方案1最低成本见效最快
- 方案2可以作为增值服务溢价

**蓝帽（决策）**: 先方案1验证，再方案2扩展

### 场景: 公司管理优化

**问题**: "怎么提升融策的审计效率？"

**发散清单**:
1. 标准化底稿模板（每个项目减少3小时）
2. AI辅助数据清洗（62,035条→3分钟出异常清单）
3. 内部知识库（积累历年审计经验）
4. 员工培训体系（新人上手快50%）
5. 项目管理工具（进度透明、分工清晰）
6. 客户自检工具（客户提前填数据，节省现场时间）

**收敛选择**:
- 快速胜利: 标准化底稿 + 知识库
- 主要项目: AI辅助数据清洗
- 长期: 项目管理工具 + 客户自检
