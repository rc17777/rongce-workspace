# 政府补助/补贴资金穿透式审计

> 政府补助类业务（特别国债、以旧换新、涉农补贴、设备更新等）的穿透审计方法论。

## 适用业务

超长期特别国债 / 消费品以旧换新补贴 / 涉农补贴 / 设备更新补贴 / 财政金融协同促内需专项资金（贷款贴息·融资担保·风险补偿）/ 化债资金 / 消费券 / 新能源补贴 等各类政府补助资金的审计。

> 📌 2026年7月30日政治局会议后，下半年审计重点是：**债券资金使用进度、"三保"底线、财政金融协同促内需（1000亿专项资金）、一揽子化债方案**，详见 [references/politburo-h2-2026-policy.md](references/politburo-h2-2026-policy.md)（含1000亿专项资金穿透审计要点）。

## 核心方法论：穿透式审计四步闭环

```
①数据建模引路 → ②异常线索锁定 → ③线上线下交叉验证 → ④资金链条闭环追踪
```

### 第一步：数据建模（四条模型，按需组合）

详见 [references/data-models.md](references/data-models.md)

| 模型 | 逻辑 | 适用场景 |
|:---|:---|:---|
| **价格异常模型** | 申报价 vs 实际售价差异分析 | 有政府指导价/最高限价的补贴 |
| **消费行为模型** | 消费者购买模式异常检测 | 面向终端消费者的补贴 |
| **SN码/唯一标识模型** | 设备唯一标识重复/伪造核验 | 涉及设备/实物发放的补贴 |
| **真实性验证模型** | 图片/文档/签名的真实性比对 | 需要上传凭证的补贴 |

### 第二步：异常线索锁定

对模型输出的异常数据进行分层标记：
- **P0（高风险）**：SN码重复 + 价格异常 + 行为异常 三重命中
- **P1（中风险）**：任一模型命中且金额>阈值
- **P2（低风险）**：单一模型轻微异常

### 第三步：线上线下交叉验证

- **线上**：向生产厂家发函核验SN码/序列号；调取平台交易日志与申报数据比对
- **线下**：实地核查——到企业查台账、到农户/消费者家中走访、现场勘查设备实物
- **关键验证点**：有申报 → 有实物 → 有安装/使用 → 金额匹配

### 第四步：资金链条闭环追踪

追踪模式：**虚假支付 → 公户入账 → 私户转出（"备用金""返利"名义）→ 全额回流**

追查方法：
1. 获取补贴收款方银行流水
2. 筛查补贴到账后短期内的大额转出
3. 追踪资金最终去向（是否回流消费者/关联方）
4. 形成完整资金闭环→定案

## 审计实施流程

### 阶段一：审前准备

1. 收集补贴政策文件，明确**补贴标准、申领条件、发放流程、监管要求**
2. 获取全量补贴申领数据（含申领人信息、设备SN码、发票、安装照片、支付凭证）
3. 搭建数据环境，导入数据，建立分析模型

### 阶段二：数据筛查

按优先级运行四模型：
1. **SN码身份模型**优先——一条SN码重复=铁证
2. **消费行为模型**次之——行为模式异常指向系统性造假
3. **价格异常模型**补充——锁定套利行为
4. **真实性验证模型**收尾——确认伪造证据

### 阶段三：现场核查

对P0/P1线索逐条核查：
- 企业端：台账、库存、进销存系统
- 消费者端：入户走访、实物盘点
- 关联方：银行流水、物流单据

### 阶段四：定案与整改

1. 形成完整证据链→移送
2. 推动制度修复：统一SN码数据库、扫码核验、重复图片识别、跨部门数据共享

## 常见骗补模式识别

| 模式 | 特征 | 首选模型 |
|:---|:---|:---|
| 虚假交易 | 有申报无实物 | SN码 + 真实性验证 |
| 刷单套补 | 批量统一金额、短期密集购买 | 消费行为 |
| 价格套利 | 按最高限价申报、低价实际销售 | 价格异常 |
| 重复申领 | 同一设备多地/多次申报 | SN码身份 |
| 摆拍造假 | 安装照片场景雷同 | 真实性验证 |
| 资金回流 | 补贴到账后私户转出 | 资金链条追踪 |

## 审计要点

1. **别只盯账本**——造假在业务逻辑里，不在凭证上。走出办公室，到现场。
2. **数据能力是基本功**——百万级数据量，人工查不过来。至少能看懂数据模型、提出分析需求。
3. **整改比查问题重要**——盯到问题改了、漏洞堵了、制度建了才算完。
4. **省市之间、政企之间数据不共享是最大障碍**——推动跨部门信息共享本身就是审计价值。
