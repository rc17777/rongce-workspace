# 数据模型参考：政府补助骗补识别四模型

## 模型一：价格异常模型

### 逻辑
将企业申报补贴的销售价格与实际市场售价进行比对，识别价格差异套利行为。

### 数据需求
- 企业申报价格（补贴申请表中的销售单价）
- 实际销售价格（发票、收据、POS机流水）
- 平台/政府最高限价

### 异常规则
- 申报价 = 最高限价 且 实际售价 < 申报价的80%
- 同一企业同类产品申报价持续等于最高限价
- 申报价与同期市场均价偏离超过2个标准差

### 发现示例
> 某企业严格按平台最高限价申报补贴，但实际卖给消费者的价格远低于申报价。差价部分被企业套走。

## 模型二：消费行为模型

### 逻辑
分析消费者购买行为的统计特征，识别不符合正常消费规律的批量刷单行为。

### 数据需求
- 消费者ID、购买时间、购买品类、购买数量、购买金额
- 消费者地理位置（县/区级）

### 异常规则
- **金额一致性**：同一地区N个消费者购买金额完全一致（N>50）
- **品类集中度**：单个消费者一次性购买5类以上家电（正常家庭不可能）
- **时间集中度**：同一地区在短时间内（1-3天）出现爆发式购买
- **频次异常**：同一消费者短期内多次购买同类产品

### 发现示例
> 某县2000多名消费者的购买金额完全一致；近5000人一次性买了5类以上家电。

## 模型三：SN码/唯一标识身份模型

### 逻辑
每台设备有唯一机身序列号（SN码），通过核验SN码的唯一性和真实性发现伪造。

### 数据需求
- 补贴申领数据中的SN码
- 生产厂家官方SN码数据库（发函获取）
- 跨地区补贴申领数据（用于跨地区重复检测）

### 异常规则
- **重复SN码**：同一SN码在系统中出现超过1次
- **格式异常**：SN码不符合厂家标准格式（长度、字符集、校验位）
- **跨地区复用**：同一SN码在不同省市同时申领补贴
- **批量伪造**：某企业申报的SN码中伪造比例>10%
- **厂家核验不通过**：向厂家发函核验，SN码不存在或已销售时间/地点不匹配

### 发现示例
> 部分企业申报的SN码伪造比例高达20%以上。审计组向生产厂家发函核验SN码，发现大量订单的SN码要么重复、要么格式不对、要么同一个码在不同地区反复使用。

## 模型四：安装/交付真实性验证模型

### 逻辑
通过比对安装照片、物流单据等凭证的真实性，识别摆拍、伪造行为。

### 数据需求
- 申领时上传的安装照片
- 物流配送记录（快递单号、签收记录）
- 安装工单（安装人员、安装时间、安装地址）

### 异常规则
- **照片雷同**：不同订单上传的安装照片场景完全相同（背景、光线、家具一致）
- **EXIF异常**：照片拍摄时间早于购买时间
- **GPS不匹配**：照片GPS位置与申领地址不一致
- **无物流记录**：有安装照片但无对应物流配送记录
- **同一安装人员异常高频**：同一安装人员短期内安装量远超正常水平

### 发现示例
> 不同订单上传的安装照片，场景一模一样——同样的墙壁、同样的地板、同样的光线角度。典型摆拍。

## 模型组合策略

### 策略一：SN码优先（铁证型）
适用于有唯一设备标识的补贴（家电、汽车、设备）
```
SN码异常 → 锁定 → 向厂家核验 → 确认伪造 → 资金追踪 → 定案
```

### 策略二：行为+真实性交叉（推断型）
适用于无唯一标识的补贴（消费券、服务券）
```
行为异常 + 照片雷同 → 锁定 → 现场走访 → 确认虚假 → 资金追踪 → 定案
```

### 策略三：价格+资金全链路（套利型）
适用于有价格标准的补贴
```
价格异常 → 锁定 → 银行流水追踪 → 资金回流确认 → 定案
```
