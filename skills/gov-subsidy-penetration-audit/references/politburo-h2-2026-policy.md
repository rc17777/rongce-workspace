# 2026年7月30日政治局会议：下半年审计重点政策依据

> 来源：新华社《中共中央政治局召开会议》通稿（2026-07-30）；公众号"审天审地审空气"《政治局会议部署下半年经济工作，审计人要盯紧这几件事》（2026-08-06）
>
> 核心逻辑：政治局会议定总基调 → 财政的钱往哪花 → 审计目光往哪跟。

---

## 四大明线（审计必盯）

### ① 债券资金使用进度（超长期特别国债 + 地方专项债）

会议原话："加快财政支出和债券资金使用进度，有力推进'两重'建设和'两新'工作。"

- 背景：下半年国债和专项债发行、拨付、使用明显提速；审计署已将"管好用好超长期国债资金"定为"十五五"审计工作主线。
- 审计三问：
  - 资金下达快不快？有没有"钱等项目"？
  - 项目推进快不快？有没有"资金到位了、工程没开工"？
  - 用得对不对？有没有把国债资金挪去干别的？
- 铁律：资金使用进度越快，"跑冒滴漏"风险越大。审计目标是"快而不乱"，不是拖慢进度。

### ② "三保"底线（保基本民生、保工资、保运转）

会议原话："兜牢基层'三保'底线。"

- 典型违规：地方财政紧张，把中央转移支付"调剂"去还债、发工资——表面"保"了，专项用途被改变。已有县级截留惠农补贴还债的案例。
- 审计要点：转移支付资金专款专用核验；"三保"资金挤占挪用筛查；重点县（财政困难县）穿透。

### ③ 财政金融协同促内需专项资金（1000亿元，新增审计热点）

会议原话："优化实施财政金融协同促内需政策。"

- 背景：2026年中央设立 **1000亿元财政金融协同促内需专项资金**，组合运用 **贷款贴息、融资担保、风险补偿** 三种工具，财政资金撬动金融资金支持扩大内需。
- 审计三问：
  - 贴息的钱有没有真贴到符合条件的项目上？
  - 融资担保的风险补偿有没有被"套利"？
  - 财政资金撬动的信贷规模，数据是真的吗？
- 原则："四两拨千斤"的机制，要盯住杠杆支点有没有放歪。详见下方专项审计要点。

### ④ 一揽子化债方案

会议原话："实施好一揽子化债方案。"

- 审计三查：
  - 有没有"真化债"？还是借新还旧、"数字化解债"？
  - 有没有"虚假化债"？债务挪表外、换马甲？
  - 化债过程中有没有**新增隐性债务**？（最隐蔽最严重）
- 定位：化债审计本质是给地方政府债务"做体检"，查病根、防复发。

## 两条暗线

### 暗线一：基础研究资金

会议原话："加强对基础研究的长期稳定支持。"

- 风险：周期长、见效慢、难量化 → 低效使用、套取挪用重灾区。
- 审计思路：不看论文数量，看研究平台真实运行、实验设备真实使用率、科研人员真实投入。

### 暗线二："人工智能+"行动

会议原话："深入实施'人工智能+'行动。"

- 双重含义：
  1. AI成为审计工具（大数据建模、智能识别、自动预警）；
  2. 算力中心、大模型项目、智能工厂改造等上亿级新基建成为政府投资审计新战场。

## 附：1000亿财政金融协同促内需专项资金——穿透审计要点（新增）

### 资金链路

```
中央专项资金 → 财政部门/主管部门 → 金融机构（贴息/担保/补偿） → 项目主体/消费者
```

三种工具的资金流各不相同，必须分别建模：

| 工具 | 资金流向 | 主要风险 |
|:---|:---|:---|
| 贷款贴息 | 财政→银行→贴息冲减企业利息 | 贴息对象不符、重复贴息、银行截留 |
| 融资担保 | 财政→担保机构→代偿/保费补贴 | 虚假担保、代偿套利、关联担保 |
| 风险补偿 | 财政→银行/担保→不良贷款补偿 | 虚增不良、人为制造违约、补偿资金回流 |

### 审计要点

1. **贴息类**：
   - 申贷项目是否符合支持目录（行业、规模、区域）
   - 贴息金额 = 贷款本金 × 期限 × 贴息率 复算，防重复贴息/超范围贴息
   - 银行实际执行利率 vs 申报利率比对（防虚高利率套贴息）
   - 贷款是否真实投放（防"过桥"空转后立即归还）

2. **担保类**：
   - 担保费率是否合规，保费补贴是否被担保机构全额截留
   - 被担保企业与担保机构、银行之间关联关系核查
   - 代偿是否真实（防"假代偿、真转移"）

3. **风险补偿类**：
   - 不良认定是否真实（防正常贷款"包装"成不良骗补偿）
   - 补偿资金去向追踪（防回流借款人或中介）
   - 撬动倍数测算：实际新增信贷规模 / 财政投入 — 数据真实性核验（防虚报撬动规模）

4. **共性穿透**：
   - 申贷企业工商信息、实控人、关联企业图谱
   - 同一主体跨工具套利（既拿贴息又拿补偿）
   - 资金闭环：补偿/贴息到账后 → 追踪流向是否回流

### 建模建议（对接四模型）

- 价格异常模型 → 贴息申报利率 vs 实际利率
- 消费行为模型 → 贴息贷款短期集中申请、集中归还
- 真实性验证模型 → 项目申报材料、担保合同真实性
- 资金链条追踪 → 补偿/贴息资金闭环
