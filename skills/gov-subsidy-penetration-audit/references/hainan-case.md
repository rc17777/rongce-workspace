# 海南以旧换新补贴穿透审计案例

> 来源：审天审地审空气《国债护航记》| 场景：超长期特别国债家电以旧换新补贴

## 背景

- **政策**：超长期特别国债支持消费品以旧换新，消费者购买新家电可获补贴
- **规模**：400余万台补贴家电、近20亿元资金、全链条碎片化数据
- **数据孤岛**：省市之间、政企之间的数据不共享

## 审计过程

### Step 1：搭建数据模型

| 模型 | 发现 |
|:---|:---|
| 价格异常 | 企业按最高限价申报，实际售价远低于申报价 |
| 消费行为 | 某县2000+人金额完全一致；5000人一次性买5类以上家电 |
| SN码身份 | SN码重复/格式不对/跨地区复用；伪造比例高达20%+ |
| 安装真实性 | 不同订单安装照片场景一模一样（摆拍） |

### Step 2：现场核查

- **企业端**：查台账 → 大量订单"有申报、无实物、无安装"
- **厂家端**：发函核验SN码 → 伪造比例确认为20%+
- **消费者端**：入户走访 → 申报7台家电，现场只有2台电视+1台洗衣机，空调室外机都没有

### Step 3：资金追踪

```
消费者平台支付 → 企业公户收款 → 当天/次日以"备用金""返利"名义私户全额转回消费者
```

**完整骗补链**：虚假支付 — 公户入账 — 私户转出 — 全额回流

### Step 4：定案与整改

- **定案**：数十条线索移送公安，抓获嫌疑人数十名，追缴近千万元
- **制度修复**：
  - 建立全省统一家电SN码数据库
  - 推行扫码核验机制
  - 真伪联网校验功能
  - 重复图片智能识别系统

## 关键启示

1. **假数据很难在所有环节保持一致性** — 这就是大数据审计的威力
2. **SN码是铁证** — 每台设备一个身份证，伪造无法逃过厂家数据库核验
3. **数据孤岛是骗补的温床** — 打破信息壁垒本身就是审计价值
4. **查一个案子，堵一串漏洞，规范一个行业** — 这才是穿透审计的最终目的
