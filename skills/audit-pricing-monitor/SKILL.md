# 补贴价格备案监控

基于两重两新项目实战发现的「高备案低成交」问题，将价格备案检查系统化。参考 Gangtise data API 的思路，将价格比对标准化为自动化检查流程。输入备案价格表和实际销售数据，自动计算：①偏离度（备案价-成交价）/备案价 ②同品同日的价格离散度 ③备案价是否在政策要求的价格区间内 ④偏离度超阈值自动标注风险等级。

## 适用场景

- 两新补贴审计中需要系统化检查商家价格备案真实性

## 执行步骤

### 步骤 1
导入数据：商家备案价格表（含商品编码、品名、备案价、备案日期）+ 实际销售记录（含商品编码、销售日期、销售价、销量）

### 步骤 2
逐品计算偏离度 = abs(备案价-成交价均值)/备案价。偏离度>20%:黄色预警；>30%:橙色预警；>50%:红色预警

### 步骤 3
同品同日价格离散度检查：同一天同一商品不同笔交易的价格标准差。标准差>备案价*10%:标记异常

### 步骤 4
备案价格时效检查：备案日期距今>6个月标记过期

### 步骤 5
输出：逐商品异常清单 + 问题商家Top N + 整改建议模板


## 输出格式

```
【价格备案监控报告】
---
【总体情况】
检查商品：XX个 | 异常商品：XX个（异常率XX%）
问题商家：XX家

【红色预警（偏离度>50%）】
荣耀畅玩50m 8GB+256GB | 金川晨贵通讯城
备案价：1899元 | 成交均价：1380元 | 偏离度：27.3%
同日价格离散：800-1760元（标准差342元）
→ 建议：暂停该商家补贴资格，核实备案价真实性

【备案过期（>6个月）】
金川福英全友家俱店 | 床垫6977861028075
备案日期：2024.8.21 | 距今：275天
→ 建议：要求商家重新提交6个月内的佐证材料

【法规依据】《价格法》第7条 | 《实施细则》第八章
```
