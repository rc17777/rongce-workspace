# 审计法规速查

内置《审计法》《政府采购法》《财政违法行为处罚条例》三部核心法规的条款检索。输入违规行为描述，自动匹配对应法规条款及处罚规定。

## 适用场景

- 检查某项行为是否违反审计/财政法规、需要快速查法规依据

## 执行步骤

### 步骤 1
输入被审计单位的具体行为描述（时间、主体、行为、金额）

### 步骤 2
系统自动匹配最相关的法规条款（含法规全称+条款号+原文）

### 步骤 3
输出：适用法规条款 + 违规定性 + 处罚依据

### 步骤 4
如涉及多部法规交叉，自动标注法律竞合关系


## 输出格式

```
【法规依据】
1.《审计法》第X条：...
2.《政府采购法》第X条：...
【定性】该行为构成XX违规
【处罚】依据XX规定，应XX
```
