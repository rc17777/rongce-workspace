# 审计红线智能哨兵

融合融策法规RAG库+两新两重项目实战经验+审计署公告案例。输入具体行为描述，自动：①匹配最相关的红线条款 ②给出违规定性+处罚依据 ③关联同类历史案例 ④标注风险等级（红/橙/黄/蓝）。参考 Gangtise buffett-perspective 的「专家视角」思路，但替换为「审计红线视角」。

## 适用场景

- 审计过程中需要快速判断某个行为是否触碰审计红线、涉及哪个法规

## 执行步骤

### 步骤 1
输入行为描述（自然语言，如：商家备案发票是8个月前的，但是活动要求6个月内）

### 步骤 2
红线匹配：在法规库中检索最匹配的条款（自动返回法规全称+条款号+原文）

### 步骤 3
案例关联：在历史项目知识库中查找同类问题及处理口径

### 步骤 4
风险评估：红（触犯法律+资金安全）/ 橙（严重违规）/ 黄（程序不规范）/ 蓝（信息瑕疵）

### 步骤 5
输出：红线速报（一句话定性+法规条款+案例+风险等级+建议动作）


## 输出格式

```
【审计红线速报】
行为：商家备案发票日期距录入时间已超6个月

【红线匹配】🟠 橙色预警
法规：《四川省2025年家电以旧换新和数码产品购新补贴实施细则》第八章
条款原文：将参加本次活动商品的商品条码、商品相关信息及实物照片、活动控制价格（提供该价格近6个月内的销售发票、销售凭据、公开资料等作为印证资料）等上传到服务平台商品信息库。

【同类案例】LX-001（金川福英全友家俱店，2025.3.19录入，发票日期2024.8.21，超近6个月）
→ 处理口径：限期补交有效期内佐证材料，纳入商家信用评价

【建议动作】
1. 出具取证单，固定事实证据
2. 要求被审计单位说明审核把关不严的原因
3. 建议整改：建立备案资料有效期自动校验机制
```

## 小金库新型态速查（五类）

> 来源：《审计实践》公众号 | 逻辑：三推手→三化→五型→三转变

### 逻辑链（标准格式）

```
现金管控趋严(移动支付+大额监管+公务卡)
+ 发票监管趋严(电子发票+查验平台+税务大数据)
+ 财务核算趋严(共享中心+资金集中+银企直连)
→ 三化: 资金载体虚拟化 + 套取手段业务化 + 存放方式账内化
→ 五类新型小金库(假费用/关联套现/隐形资产/账内蓄水/数字化隐匿)
→ 破局: 工商穿透+业务痕迹+资金闭环+系统日志
→ 本质: "小金库审的不是钱，是权力的透明度"
```

### 五类新型小金库速查表

#### 1. 虚假费用报销型

| 特征 | 传统 | 新型 |
|------|------|------|
| 发票 | 假发票 | **真发票+假业务** |
| 手法 | 买假票套现 | 虚构咨询/临聘/采购 |
| 半真半假 | 不存在 | 真酒店开票，但消费人≠出差人 |

**破局三步**：
- ① 供应商工商信息 ↔ 公司内部人员关联比对
- ② 费用后面有没有业务痕迹（会议纪要/交付报告/工作产出）
- ③ 同一开票方+同一金额+同一报销人+不同事由 → 高危信号

#### 2. 关联企业套现型

| 信号 | 说明 |
|------|------|
| 内部人实控外部公司 | 隐蔽控股，工商穿透可见 |
| 合规交易留返利 | 合同金额外的约定留成 |
| 低价处置资产 | 卖后从受让方拿回扣 |

**破局**：
- 大额供应商 → 穿透实控人 → 比对内部关键岗位人员
- 被剥离资产 → 追踪交易后实际运营者和利益流向

#### 3. 隐形资产与权益型

| 资产类型 | 变现方式 |
|---------|---------|
| 场地/设备 | 违规转租，租金入小金库 |
| 排他性渠道名额 | 私下转售 |
| 酒店积分/航空里程 | 公务消费累积→个人使用 |
| **隐藏权益** | 合同中要求供应商额外免费开发→形成账外资产 |

**破局**：
- 闲置资产的实际占用情况
- 积分/权益/增值服务的实际归属
- 长期未实际交易的合同为何续约

#### 4. 账内蓄水池型

| 手法 | 表现 |
|------|------|
| 虚假核算藏结余 | 项目结余不入账，形成灰色资金 |
| 专项款长期沉淀 | 拨款到位但改用途 |
| 往来款反复挂账 | 其他应付款→随意开支通道 |

**破局**：
- 长期未动账的应付款项
- 专项资金拨付时间 vs 实际支出节奏 → 不匹配=异常
- 跨级次、跨单位大额往来款逐笔穿透

#### 5. 数字化隐匿型（2025-2026最新）

| 手法 | 原理 |
|------|------|
| 优惠券/虚拟金兑现 | 平台返利指定的个人账户 |
| 虚增虚拟账户套奖励 | 批量注册参与促销套取 |
| 第三方支付截留 | 行政事业收入→个人账户→赚时间差收益 |

**破局**：
- 虚拟账户数量 vs 实际业务规模 → 不匹配
- 高频次规律性领取大额优惠券的操作人员
- 所有收款通道是否纳入对公结算

### 思维转变（三转）

| 传统三板斧 | 新型三板斧 |
|-----------|-----------|
| 翻现金 | → **审业务**（验证是否真实发生） |
| 对银行账 | → **查信用**（饭卡/积分/虚拟账户） |
| 盘实物 | → **看系统**（日志/行为数据比凭证可靠） |

### 审计原则

> 小金库审计的本质不是追回几笔钱，而是让每一分钱都有来处、有去处、有责任人。
> 
> 一项业务如果在物理世界找不到真实的对应痕迹，它就是小金库的搬运通道。
