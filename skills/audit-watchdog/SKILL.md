# 审计红线智能哨兵

融合融策法规RAG库+两新两重项目实战经验+审计署公告案例。输入具体行为描述，自动：①匹配最相关的红线条款 ②给出违规定性+处罚依据 ③关联同类历史案例 ④标注风险等级（红/橙/黄/蓝）。参考 Gangtise buffett-perspective 的「专家视角」思路，但替换为「审计红线视角」。

## 适用场景

- 审计过程中需要快速判断某个行为是否触碰审计红线、涉及哪个法规

## 执行步骤

### 步骤 1
输入行为描述（自然语言，如：商家备案发票是8个月前的，但是活动要求6个月内）

### 步骤 2
红线匹配：在法规库中检索最匹配的条款（自动返回法规全称+条款号+原文）

### 步骤 3
案例关联：在历史项目知识库中查找同类问题及处理口径

### 步骤 4
风险评估：红（触犯法律+资金安全）/ 橙（严重违规）/ 黄（程序不规范）/ 蓝（信息瑕疵）

### 步骤 5
输出：红线速报（一句话定性+法规条款+案例+风险等级+建议动作）


## 输出格式

```
【审计红线速报】
行为：商家备案发票日期距录入时间已超6个月

【红线匹配】🟠 橙色预警
法规：《四川省2025年家电以旧换新和数码产品购新补贴实施细则》第八章
条款原文：将参加本次活动商品的商品条码、商品相关信息及实物照片、活动控制价格（提供该价格近6个月内的销售发票、销售凭据、公开资料等作为印证资料）等上传到服务平台商品信息库。

【同类案例】LX-001（金川福英全友家俱店，2025.3.19录入，发票日期2024.8.21，超近6个月）
→ 处理口径：限期补交有效期内佐证材料，纳入商家信用评价

【建议动作】
1. 出具取证单，固定事实证据
2. 要求被审计单位说明审核把关不严的原因
3. 建议整改：建立备案资料有效期自动校验机制
```

## 设计理念

本技能参考以下方法论：
- **Gangtise投研Skill**：证据等级标注体系（F1法规/F2数据/M1物证/C1人证/H1官方公告）
- **科研15 Skill**：工作流拆解（每个环节一个专用Skill）
- **book-skill-generator**：知识资产→方法论→可执行Skill的转化框架
