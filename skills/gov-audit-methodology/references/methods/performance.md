# 绩效评价方法

## 政策跟踪审计三维视角（#54）

### 形式维度 — 审部署
- 相关政策文件是否齐全？
- 会议部署和会议纪要是否到位？
- 组织领导架构是否建立健全？
- 配套制度/实施细则是否出台？
- 执行程序是否规范？

### 事实维度 — 审落实
- 项目进度是否达到计划节点？
- 资金拨付/使用是否符合规定？
- 过程管理是否规范？
- 有无虚报冒领/挪用资金？
- 项目质量是否达标？

### 价值维度 — 审效果
- 经济效益：是否达到预期经济目标？
- 社会效益：服务对象满意度如何？
- 是否解决了原政策要解决的问题？
- 有无负面外部效应？

## 政策清单法（浙江经验）

1. 编制政策措施清单（涵盖所有本级出台的政策）
2. 编制政策跟踪审计五年规划
3. 年度计划与专项审计/经济责任审计结合
4. 避免重复审计，节约资源

## 绩效指标五维框架（#54引用王帆2019）

从五个维度设计绩效评估指标：
1. **政策维度**：政策目标的达成度
2. **资金维度**：资金使用效率/合规性
3. **项目维度**：项目产出/质量/时效
4. **体制机制维度**：制度建设/执行效果
5. **履责维度**：各主体履职情况

## 报告撰写要点（#57）

- 区分"事实现象"和"审计问题"
- 审计问题 = 事实 + 原因分析 + 管理根因
- 建议要可执行、效果可评估
- 从数字化角度提出改进方案（如系统自动监控替代人工抽查）
