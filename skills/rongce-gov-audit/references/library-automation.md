### 网络自动抓取方案

#### 方案A：法规原文自动下载

抓取来源：政府网站公开可得的法规原文

```bash
# 立法网站
https://flk.npc.gov.cn/          → 免费查询法律法规
# 司法部行政法规库
https://www.moj.gov.cn/           → 行政法规原文
# 审计署政策法规库
https://www.audit.gov.cn/n6/n39/  → 审计署法规/案例发文
# 中国政府网法规数据库
https://www.gov.cn/               → 公开法规
```

**操作步骤**（半自动：人工选法规→AI抓取→自动存入）：

| 步骤 | 操作 | 工具 |
|------|------|------|
| 1 | 打开 flk.npc.gov.cn，搜索核心里的审计法规 | browser工具 |
| 2 | 获取法规正文页URL | 浏览器 |
| 3 | 使用 web-content-fetcher 抓取全文 | `curl -s "https://r.jina.ai/{法规原文URL}"` |
| 4 | 用AI提取法规结构（章/条/款） | OpenClaw分析 |
| 5 | 按模板格式化存入 `raw/laws/{法规名称}.md` | 文件写入 |

**预期产出**：每个法规独立一个md文件，内部结构：
```markdown
# {法规全称}

> 施行日期：YYYY-MM-DD
> 修订日期：YYYY-MM-DD（最新版）
> 来源：{URL}

## 第一章 总则
**第X条** ...（全文引用）

## 第二章 ...
**第X条** ...

...
```

#### 方案B：审计署发文定期采集（设置cron）

```bash
# 抓取审计署 "各地动态" 栏目最新文章列表
curl -s "https://r.jina.ai/https://www.audit.gov.cn/n4/n20/n524/"
# 提取文章标题+链接+发布时间
# 比对上次采集时间 → 只取新文章
# 下载新文章 → 存入 raw/laws/ 或 raw/projects/
```

**cron任务设计**：

```json
{
  "name": "审计署最新发文抓取",
  "schedule": { "kind": "cron", "expr": "0 9 * * 1", "tz": "Asia/Shanghai" },
  "sessionTarget": "isolated",
  "payload": {
    "kind": "agentTurn",
    "message": "请访问 https://r.jina.ai/https://www.audit.gov.cn/n4/n20/n524/，获取最新的审计政策、法规或案例文章。对比上次采集记录，如有新文章则抓取正文，提取关键信息，按分类存入 AuditKB 对应位置: 法规→raw/laws/，案例→wiki/cases/，规则更新→通知人工处理。上次采集记录存储在 AuditKB/raw/last-fetch-record.md。"
  }
}
```

## 二、库③操作指引库：不适合纯自动抓取 🟡

### 核心原因

操作指引库的本质是**团队自己的经验沉淀**，不是能从公开网络直接复制的。济南的操作指引库也是自己写的。

### 可以半自动化的部分

| 可抓取 | 来源 | 自动/半自动 |
|--------|------|------------|
| ① 审计署发布的"操作指南"标准 | 审计署网站 | ✅ 自动下载+整理 |
| ② 公开的审计流程图/模板 | 百度文库/道客巴巴 | ⚠️ 需人工筛选+改编 |
| ③ 中国内部审计协会的操作规范 | 公众号/官网 | ✅ 自动抓取+结构化 |
| ④ 各行业审计SOP公开资料 | 审计论坛/知识库 | ⚠️ 可信度需人工判断 |
| **不能自动**的：融策自己的底稿模板/检查清单/经验总结 | — | ❌ 只能项目沉淀 |

### 操作示范：抓取一份公开审计操作指南

```bash
# 抓取审计署网站的政策解读
curl -s "https://r.jina.ai/https://www.audit.gov.cn/n6/n39/"
# → 提取"审计操作指南"类文章
# → 结构化提取关键步骤
# → 存入操作指引库，标记来源与可信度
```

### 真正要补的3种操作模板（人工）

| 模板 | 说明 | 工作量 |
|------|------|--------|
| 取证单模板 | 审计取证的标准格式 | 0.5天 |
| 征求意见函模板 | 送被审计单位征求意见的正式函件 | 0.5天 |
| 审计决定书模板 | 下达结论和处罚决定的正式文书 | 0.5天 |

这3种模板没法从网上直接抄到好用的（各地格式不同），但可以在网上找几个样本参考后再自己写。

## 三、自动化采集系统架构

把两个库的抓取统一管理：

```
cron定时任务（每周一9:00）
    │
    ├── 任务①：审计署最新发文抓取
    │   → r.jina.ai → 审计署"各地动态"栏目
    │   → 比对上次 → 新文章下载
    │   → 存入 raw/laws/ 或 raw/projects/
    │   → 更新 last-fetch-record.md
    │
    ├── 任务②：财政部、审计法规更新监控
    │   → r.jina.ai → flk.npc.gov.cn 法规库
    │   → 检查常用法规是否有修订
    │   → 如有修订，更新 raw/laws/ 中对应文件
    │
    └── 任务③：中国内审协会公众号文章采集
        → 微信公众号抓取 → 内审协会最新文章
        → 提取操作性内容 → 存入操作指引库参考区
```
