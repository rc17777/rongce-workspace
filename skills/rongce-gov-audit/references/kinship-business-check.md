# 领导干部亲属关联企业工商索引检查表

> 适用：经济责任审计、预算执行审计（涉及大额采购/工程项目时）
> 坐标系：社会关系
> 用时：审前进点前2天内完成
> 关联脚本：本表为手动核查流程，非自动脚本

---

## 使用步骤

### 第一步：建立人员名单（审计通知书发出后立即收集）

从被审计单位获取以下名单（Excel格式）：

| 角色 | 字段要求 |
|------|---------|
| 被审计领导本人 | 姓名、身份证号（可选）、任职起止时间 |
| 班子成员 | 姓名、职务、分管领域 |
| 关键岗位人员 | 财务负责人、采购经办人、项目负责人 |
| 前述人员的配偶 | 姓名 |
| 前述人员的子女（成年） | 姓名 |

> ⚠️ 注意：家属信息可从领导干部个人事项报告获取（经责审计时可要求提供），或通过谈话侧面了解。

### 第二步：提取供应商/乙方名单（进点第一天）

从被审计单位获取：

| 数据来源 | 提取内容 |
|---------|---------|
| 供应商台账 | 近3年所有供应商名称 + 交易金额 |
| 工程项目台账 | 施工方/监理方/设计方名称 |
| 服务外包合同 | 服务提供方名称 |
| 房租/物业/租赁合同 | 出租方/承租方名称 |

### 第三步：交叉索引（逐条查工商）

**方法A：手动查（免费）**

1. 打开 [天眼查](https://www.tianyancha.com) 或 [企查查](https://www.qcc.com)
2. 逐个输入供应商名称 → 查看"股东信息""主要人员"
3. 将股东/法人/高管的姓名与第一步的名单交叉比对

## 重点检查信号

以下情况一出现，立即标记为🔴高风险：

| 信号 | 说明 |
|------|------|
| 领导本人兼任供应商企业法人/股东 | 丁某案的破局点 |
| 配偶/子女在供应商企业持股>30% | 利益输送高风险 |
| 领导兼职的下属企业恰好是本单位主要供应商 | 权力闭环 |
| 供应商法人变更时间恰好在该领导上任后6个月内 | 上任后布局 |
| 多家供应商的法人/股东存在同乡/同学/前同事关系 | 关系网操控 |

## 后续动作

| 风险等级 | 动作 |
|---------|------|
| 🔴 高 | 立即调取该供应商的全部采购档案（招标文件+合同+验收+付款）；追溯领导是否参与该供应商的选择和审批 |
| 🟡 中 | 在疑点清单中标注，与合同三对照、报价分析交叉验证后再决定是否深挖 |
| 🟢 低 | 记录到工作底稿，如无其他异常信号可暂不展开 |
