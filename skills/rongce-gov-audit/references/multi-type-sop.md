# 8环节全链条SOP（多审计类型通用版）

> 来源：宁津8环节全链条 + 河南农商银行"3+6"体系
> 通用化改造：在经责审计SOP基础上，适配预算执行/专项资金/绩效/采购审计
> 创建时间：2026-05-31

---

## 一、通用8环节框架（任何审计类型都可用）

```
①政策法规 → ②审计方法 → ③数据采集 → ④数据分析 → ⑤疑点核查 → ⑥问题落实 → ⑦问题反馈 → ⑧数据归档
```

以下按审计类型展开每个环节的差异化内容。

---

## 二、经济责任审计（已有完整SOP）

**文件**：`eco-responsibility-audit/references/full-chain-sop.md`

**各环节重点**：

| 环节 | 关键差异 |
|------|---------|
| ①政策法规 | 重点：《党政主要领导干部和国有企事业单位主要领导人员经济责任审计规定》 |
| ②审计方法 | 聚焦：任期经济决策、预算执行、资产管理、个人廉洁 |
| ③数据采集 | 财务+业务+会议纪要+决策文件 |
| ④数据分析 | 规则：RULE-301~306（预算偏离/三公超标/资产流失/决策程序/往来挂账/资金挪用） |
| ⑤疑点核查 | 双主审模式：数据主审分析+业务主审现场核查 |
| ⑥问题落实 | 责任认定：直接/主管/领导责任 |
| ⑦问题反馈 | 审计报告+经济责任评价+整改要求清单 |
| ⑧数据归档 | 经责审计案例沉淀 |

## 三、预算执行审计

### 各环节重点

| 环节 | 重点 |
|------|------|
| ①政策法规 | 《预算法》《预算法实施条例》《财政违法行为处罚处分条例》 |
| ②审计方法 | 部门预算vs决算的逐项比对；重点关注：预算编制准确性、执行严肃性、结余资金管理 |
| ③数据采集 | 预算批复表、决算报表、用款计划、国库支付台账、单位财务账套 |
| ④数据分析 | 规则：RULE-301预算偏离度、RULE-302三公超标 + 预算科目串户、无预算支出、超预算支出 |
| ⑤疑点核查 | 逐笔核对预算批复vs实际执行；询问预算编制依据 |
| ⑥问题落实 | 定性：无预算支出/超预算支出/预算调整不合规/虚列支出 |
| ⑦问题反馈 | 审计报告+整改要求+预算编制优化建议 |
| ⑧数据归档 | 沉淀：典型预算违规案例+异常支出检测模型 |

### 数据分析规则集

| 规则 | 检测内容 | 阈值 | 脚本状态 |
|------|---------|------|---------|
| 预算执行偏离度 | 决算/预算比例 | >120%或<60%标红 | ✅ 可写 |
| 三公经费超额 | 实际vs预算 | 超预算批复标红 | ✅ 可写 |
| 无预算支出 | 支出不在预算范围内 | 科目不存在 | ✅ 可写 |
| 预算科目串户 | 支出落到错误科目 | 科目名称不一致 | ⬜ 待写 |
| 年末突击支出 | 12月支出/全年支出 | >30%标红 | ✅ 可写 |
| 结余资金长期挂账 | 连续2年+结余不缴回 | 挂账>2年 | ⬜ 待写 |
| 转移支付未及时下达 | 上级支付到县级的时间 | >30天标红 | ⬜ 待写 |

## 四、专项资金审计

### 各环节重点

| 环节 | 重点 |
|------|------|
| ①政策法规 | 专项资金管理办法 + 财政转移支付资金管理办法 |
| ②审计方法 | 资金流向：拨付→使用→验收全链条追踪 |
| ③数据采集 | 资金拨付文件、银行回单、项目实施凭证、验收报告、受益对象名单 |
| ④数据分析 | 规则：RULE-306资金挪用 + 资金滞留、受益对象重复、项目验收造假 |
| ⑤疑点核查 | 电话/实地核查受益对象真实性；核对项目产出与资金使用匹配度 |
| ⑥问题落实 | 定性：挪用/截留/虚报冒领/闲置浪费/扩大开支范围 |
| ⑦问题反馈 | 审计报告+追回资金建议+制度完善建议 |
| ⑧数据归档 | 沉淀：专项资金审计案例+资金流向追踪模板 |

### 数据分析规则集

| 规则 | 检测内容 | 阈值 | 脚本状态 |
|------|---------|------|---------|
| 资金闲置/滞留 | 拨付后长期未使用 | 超过6个月 | ✅ 可写 |
| 受益对象重复 | 同名/同身份证多次享受补贴 | 同一人2次+ | ⬜ 待写（参考分解住院思路） |
| 资金流向异常 | 资金到账后短期内转出 | 到账后3天内转走 | ✅ 可写 |
| 项目虚假 | 项目验收日期早于实施开始日期 | 逻辑矛盾 | ⬜ 待写 |
| 受益对象非目标人群 | 身份证号不符合目标区域/条件 | 地址/年龄/身份不符 | ⬜ 待写 |

## 五、绩效审计

### 各环节重点

| 环节 | 重点 |
|------|------|
| ①政策法规 | 项目绩效目标批复 + 绩效评价管理办法 |
| ②审计方法 | 投入产出分析、目标完成率比对、效果可持续性评估 |
| ③数据采集 | 绩效目标申报表、自评报告、第三方评价报告、项目实施过程数据 |
| ④数据分析 | 完成率vs计划、投入vs产出比、同类项目横向对比 |
| ⑤疑点核查 | 核实自评报告的准确性；检查目标完成是否"纸上达标" |
| ⑥问题落实 | 定性：目标未完成/效果不达标/资金低效/投入产出不匹配 |
| ⑦问题反馈 | 审计报告+项目管理建议+绩效指标体系优化意见 |
| ⑧数据归档 | 沉淀：绩效审计案例+指标库 |

### 数据分析规则集

| 规则 | 检测内容 | 阈值 | 脚本状态 |
|------|---------|------|---------|
| 目标完成率 | 实际/计划产出 | <60%标红 | ✅ 可写 |
| 资金执行率 | 实际支出/预算安排 | <50%标红 | ✅ 可写 |
| 自评vs他评分差 | 自评得分/第三方评价得分 | >20分差标红 | ⬜ 待写 |
| 同类项目产出差异 | 同一项目不同区域的产出对比 | 偏差>50%标红 | ⬜ 待写 |
| 效果可持续性 | 项目结束后的效果/成果是否持续 | 3个月后无维护记录 | ⬜ 待写 |

## 六、采购审计

### 各环节重点

| 环节 | 重点 |
|------|------|
| ①政策法规 | 《政府采购法》《招标投标法》《政府采购法实施条例》 |
| ②审计方法 | 采购全流程：需求→参数→招标→开标→评标→签约→验收→付款 |
| ③数据采集 | 招标文件、投标文件、评标记录、合同、验收单、付款凭证 |
| ④数据分析 | bid-collusion-audit 九步法 + 标准/参数指向性 + 评标打分偏差 |
| ⑤疑点核查 | 核实招标参数合理性；核查评标专家与投标方关联 |
| ⑥问题落实 | 定性：串标/围标/参数指向/拆分采购/未公开招标/验收造假 |
| ⑦问题反馈 | 审计报告+采购制度完善建议+涉嫌违法的移送建议 |
| ⑧数据归档 | 沉淀：串标案例+评标专家行为分析模型 |

### 数据分析规则集

| 规则 | 检测内容 | 阈值 | 脚本状态 |
|------|---------|------|---------|
| 串标检测（8+指标） | 人员/Author/报价/时间/相似度 | bid-collusion-audit | ✅ 已有 |
| 评标专家打分偏差 | 同一专家给不同投标方打分差异 | 标准差>30%标红 | ⬜ 待写 |
| 参数指向性 | 技术参数是否为特定品牌定制 | 唯一品牌可满足 | ⬜ 待写 |
| 拆分采购 | 同一类采购多次不达标 | 金额<招标限额多次出现 | ⬜ 待写 |
| 中标方频繁中标 | 同一投标人一定周期内中标次数 | 3年内中标>3次 | ✅ 可写 |

## 七、统一输出模板

### 审计类型速查表

项目启动时，直接用这个表确定各环节要点：

| 项目类型 | 核心法规包 | 关键数据源 | 核心规则 | 问题定性依据 |
|---------|-----------|-----------|---------|------------|
| □ 经济责任 | 经责审计规定+预算法 | 财务+会议纪要+资产台账 | RULE-301~306 | 经责规定+违法行为处罚 |
| □ 预算执行 | 预算法+预算法实施条例 | 预算批复+决算+国库支付 | 预算偏离+科目串户+突击支出 | 预算法+违法行为处罚 |
| □ 专项资金 | 专项资金管理办法+转移支付办法 | 拨付凭证+项目资料+受益名单 | 挪用+滞留+受益重复 | 专项资金管理办法 |
| □ 绩效审计 | 绩效管理办法+项目目标批复 | 绩效申报+自评+第三方评价 | 完成率+执行率+自评差距 | 绩效管理办法 |
| □ 采购审计 | 政府采购法+招标投标法 | 招标+投标+评标+合同 | 串标+参数+拆分+专家打分 | 采购法+招标法 |
| □ 投资审计 | 投资管理条例+招标法 | 立项+招标+施工+决算 | 中标价偏差+结算虚报+变更签证 | 投资管理条例 |

### 各类型共性要求

| 环节 | 共性要求（所有类型通用） |
|------|------------------------|
| ①政策法规 | 法规包必须标注"红线条款"（违反即追责的条款） |
| ②审计方法 | 数据需求清单必须精确到"表名+字段+时间范围" |
| ③数据采集 | 原始版+清洗版分开存储，数据质量报告必出 |
| ④数据分析 | 运用规则库+异常检测+关联比对三步走 |
| ⑤疑点核查 | 每个疑点须有明确的确认/排除结论 |
| ⑥问题落实 | 定性精确到法规条款号，金额精确到元 |
| ⑦问题反馈 | 报告+整改要求清单同时送达 |
| ⑧数据归档 | 7个工作日内完成，规则/案例/方法三张检查表全过一遍 |

## 第八部分：跨类型复合审计场景

政府审计中经常遇到**一个项目涉及多种审计类型**。对照场景处理方式：

| 复合场景 | 主导类型 | 辅助类型 | 处理方式 |
|---------|---------|---------|---------|
| 专项资金+绩效 | 专项资金 | 绩效 | 先查资金合规性，再评价资金使用效果 |
| 预算执行+经济责任 | 经济责任 | 预算执行 | 预算执行偏离度作为经责评价的一个子维度 |
| 采购+投资审计 | 投资审计 | 采购 | 投资审计中的招投标环节直接调用bid-collusion-audit |
| 专项资金+采购 | 专项资金 | 采购 | 专项资金的设备采购部分单独走采购审计规则 |

**原则**：主类型走完整8环节，辅助类型只走数据分析+问题落实两个核心环节，避免重复劳动。
