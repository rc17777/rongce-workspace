# 常用法规数据库

## 概述

本文档列出政府审计中高频引用的法规，供AI在生成审计报告/底稿时引用。
优先使用现行有效版本，标注常用条款。

## 使用说明

1. 根据审计发现的问题类型，从上述数据库中匹配对应的法规和条款
2. 引用时采用格式：`《法规名称》第X条"……（关键内容摘要）"`
3. 如同一问题涉及多部法规，优先引用法律层级最高的
4. 注意法规的修订情况，确保引用现行有效版本
5. 如有地方性法规或单位内部规定，优先引用与审计对象最直接相关的
