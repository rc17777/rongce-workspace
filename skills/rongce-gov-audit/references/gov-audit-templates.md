# 政府审计底稿模板库

## 概述

本文件包含四类政府审计的底稿模板和生成规范。所有模板输出为可编辑的Word文档。

## 一、预算执行审计底稿

### 模板结构
1. 审计底稿封面（项目名称、被审计单位、审计期间、编制人、复核人、日期）
2. 审计程序表（审计目标 → 审计程序 → 审计证据 → 审计结论）
3. 数据采集清单（预算批复文件、决算报表、科目余额表、序时账、采购合同台账、资产台账）
4. 关键科目检查表

### 必查科目和检查要点

| 科目 | 检查要点 | 常见问题 |
|------|---------|---------|
| 财政收入 | 是否全额入账、有无截留挪用 | 收入不入账、转入往来款 |
| 预算支出 | 是否超预算、审批是否合规 | 无预算支出、超标准支出 |
| 三公经费 | 是否超控制数、审批手续 | 隐形三公消费、转嫁支出 |
| 政府采购 | 是否履行采购程序、合同执行 | 规避招标、拆分合同 |
| 往来款项 | 长期挂账原因、清理情况 | 私人借款、账外资金 |
| 固定资产 | 账实相符、处置程序 | 资产流失、低价处置 |

### 底稿生成指令

用户提供以下信息后生成底稿：
- 被审计单位全称
- 审计期间（起止日期）
- 预算总额
- 单位性质（行政/事业/国企）
- 特别关注领域（如有）

生成规则：
- 每个检查科目含：审计目标、审计程序（3-5步）、取证要求、判断标准、留痕区
- 数据采集清单需注明数据来源和格式要求
- 底稿底部标注"AI辅助生成，编制人：____ 复核人：____ 日期：____"

## 二、经济责任审计底稿

> 详细模板参见 eco-responsibility-audit Skill 的 references/working-papers.md

### 融策补充模板

基于融策所的实践经验，补充以下高频模板：

#### 2.1 重大经济决策检查表
| 检查项 | 检查方法 | 常见问题 |
|--------|---------|---------|
| 决策程序合规性 | 查阅党组会议纪要、三重一大记录 | 个人拍板、以签批代决策 |
| 决策执行情况 | 比对决策决议与实际执行 | 执行偏差、擅自变更 |
| 决策效果评估 | 分析项目效益、资金使用效率 | 决策失误造成损失 |

#### 2.2 廉洁从业检查表
- 个人收入申报与实发比对
- 公务消费合理性分析
- 关联方交易筛查
- 职务消费合规性检查

## 三、专项资金审计底稿

### 模板结构
1. 专项资金基本情况表（资金来源、金额、用途、批复文件）
2. 资金流向追踪表（拨付→使用→结余，逐笔追踪）
3. 项目管理检查表（立项、招投标、合同、验收、决算）
4. 受益对象核实表（如涉及民生资金）

### 关键检查点
- 资金是否专款专用（防挪用）
- 拨付是否及时（防截留）
- 配套资金是否到位（防虚假配套）
- 项目是否真实（防虚报冒领）
- 验收是否规范（防走过场）

---

## 四、绩效审计底稿

### 模板结构
1. 绩效目标确认表（目标合理性、指标科学性）
2. 绩效数据采集表（定量指标数据来源、定性指标评价方法）
3. 绩效分析矩阵（目标vs实际、投入vs产出）
4. 问题与建议汇总表

---

## 通用底稿生成注意事项

1. **可编辑性**：所有底稿必须是真实的Word表格，不是图片/截图
2. **留痕设计**：每个检查项预留"审计记录"和"复核意见"两个空白区
3. **法规引用**：每个检查要点附带对应的法规条款（参见 regulations-database.md）
4. **模板复用**：生成后提醒用户"此模板可保存为贵所标准模板，下次直接使用"
