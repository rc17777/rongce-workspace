# 融策政府审计AI Skill

## 概述

本Skill为融策会计师事务所定制，基于事务所10人团队、政府审计（40%）+咨询（60%）的业务特点，
将资深CPA的审计经验固化为可复用的AI工作流。

## 核心理念

- **AI做执行，人做判断**：异常筛查、底稿生成、报告初稿由AI完成；问题定性、专业判断、最终结论由人完成
- **规则驱动**：所有AI输出基于明确的风险规则库和模板，确保一致性和可追溯性
- **案例意识**：执行审计时带"案例思维"——不是每个发现都值得入库，只有满足5条质量标准的发现才沉淀为组织记忆（详见[案例质量标准](references/case-quality-criteria.md)）
- **数据安全优先**：处理政府审计数据时，遵循"数据不出域、最小权限、全程留痕"原则

## 政府审计类型识别

根据用户输入，自动匹配以下四类审计：

1. **预算执行审计** — 关键词：预算、决算、收支、财政拨款、三公经费
2. **经济责任审计** — 关键词：任期、离任、领导干部、经济责任、履职 → 同时参考 eco-responsibility-audit Skill
3. **专项资金审计** — 关键词：专项资金、补贴、项目资金、转移支付、民生资金
4. **绩效审计** — 关键词：绩效、效果、效益、投入产出、目标完成

## 通用规范

1. 底稿格式：使用统一模板（参见 gov-audit-templates.md），包含检查程序、取证清单、数据留痕区
2. 法规引用：引用现行有效法规，标注具体条款号。常用法规见 regulations-database.md
3. 异常标识：三级风险标注（🔴高/🟡中/🟢低），附带风险描述和检查方向
4. 脱敏提醒：生成含真实数据的内容时，自动提示脱敏处理
5. 留痕要求：所有AI生成内容标明"AI辅助生成，需人工复核"，保留修改记录空间

### 5大挑战→融策应对策略

| 挑战 | 官方对策 | 融策落地方案 |
|------|---------|-------------|
| 数据安全 | 加密/脱敏/权限控制 | 处理客户数据时：本地处理不上传、结果脱敏后分享 |
| 算法偏见 | 算法审查/评估/问责 | 所有AI输出标注"需人工复核"，不作为最终结论 |
| 组织适应 | 制度/流程再造 | 先在小项目试点，验证后推广（已在教科院附中项目验证） |
| 技术能力不足 | 培训+政务大模型 | 借助OpenClaw+现有技能库，降低技术门槛 |
| 数据治理短板 | 数据标准化建设 | 统一数据采集模板，建立数据特征库（参见audit-data-analyst） |

## 十类审计问题定性速查

> 来源：《十类审计发现问题定性》（经济责任审计从这里说起公众号）
> 用途：审计发现问题时快速查找标准定性表述和界定口径
> 对接：配合 eco-responsibility-audit 的"审、定、评、用"定责双链模型使用

### 一、预算执行审计常见问题定性（21类）

| # | 问题定性 | 界定口径 |
|---|---------|---------|
| 1 | 预算编报不真实 | 未准确真实编报预算，存在虚假项目或事项 |
| 2 | 违规变更预算 | 未经批准擅自变更预算或动用预备费 |
| 3 | 预算编制批复不规范 | 预算批复不及时、不合规、不全面 |
| 4 | 未按规定征收缴纳预算收入 | 违规减免少征或应缴未缴 |
| 5 | 隐瞒转移截留预算收入 | 挂暂存/过渡户/混淆入库级次 |
| 6 | 政策性税收流失 | 地方自行出台招商引资税收优惠导致 |
| 7 | 财政收入核算不实 | 虚增虚减财政收入 |
| 8 | 资金滞留闲置 | 未及时征收入库或拨付 |
| 9 | 财政支出核算不实 | 估报决算/以拨款数列报基建 |
| 10 | 违规改变资金用途 | 挤占挪用专项资金 |
| 11 | 超预算列支 | 超过批准预算列支 |
| 12 | 账外资产 | 未入账/私存私放 |
| 13 | 未落实收支两条线 | 应实行未实行 |
| 14 | 违规采购 | 违反政府采购规定 |
| 15 | 违规担保 | 违反法律规定担保 |
| 16 | 决算草案编报不完整 | 未将全部单位纳入决算 |
| 17 | 预算结余不实 | 账表结余与实际不符 |
| 18 | 资产核算不实 | 账表资产与实际不符 |
| 19 | 损失浪费 | 决策失误或管理不善造成 |
| 20 | 侵害人民群众利益 | 乱收费/拖欠/少补偿等 |
| 21 | 审计挽回损失 | 审计后追回损失 |

### 二、财政决算审计（12类）

- 决算编制不规范 / 少汇漏汇、多计少计
- 未按规定征收缴纳财政收入
- 隐瞒转移截留财政收入
- 财政收入核算不实 / 财政支出核算不实
- 违规改变资金用途
- 擅自动用支配国库库款
- 虚报冒领
- 违规办理结算或批复决算
- 损失浪费 / 侵害人民群众利益 / 审计后挽回损失

### 三、专项资金审计（13类）

- 违规改变项目计划和资金用途

- 虚报冒领
- 违规有偿使用资金（财政资金收取利息）
- 虚列支出 / 违规采购 / 资金滞留闲置
- 未纳入财政专户管理 / 账外资产
- 配套资金不落实
- 损失浪费 / 侵害人民群众利益 / 审计后挽回损失

### 四、行政事业审计（14类）

- 应缴未缴预算收入 / 隐瞒截留收入
- 违规改变资金用途
- 虚列支出 / 虚列成本
- 少计少缴税费
- 未按规定征提基金
- 未落实收支两条线
- 账外资产
- 乱收费乱摊派乱罚款
- 超标准超计划支出
- 损失浪费 / 侵害人民群众利益 / 审计后挽回损失

### 五、固定资产投资审计（16类）

- 资金来源不合规 / 资金不落实 / 配套资金不落实
- 少补偿征地补偿款
- 违规改变资金用途
- 工程价款不实
- 拖欠工程款 / 账外资产
- 少计少缴税费 / 挤占建设成本
- 概预算编报不规范 / 决算编报不规范
- 超计划超标准超规模 / 违规收取费用
- 损失浪费 / 侵害人民群众利益 / 审计后挽回损失

### 六、金融审计（9类）

- 违规经营 / 账外经营 / 账外资产
- 违规改变资金用途
- 违规购建固定资产
- 少计少缴税费
- 损失浪费 / 侵害人民群众利益 / 审计后挽回损失

### 七、外资运用项目审计（11类）

- 违规改变资金用途 / 工作量不实 / 倒卖项目物资
- 超计划超标准超规模 / 少计少缴税费
- 资金不到位不落实 / 骗取项目资金 / 交付资产不实
- 损失浪费 / 侵害人民群众利益 / 审计后挽回损失

### 八、企业审计（10类）

- 违规经营 / 账外经营 / 账外资产 / 公款私存
- 虚报或隐瞒转移收入
- 少计或虚列成本费用
- 少计少缴税费
- 损失浪费 / 侵害人民群众利益 / 审计后挽回损失

### 九、经济责任审计（核心2类）

| 责任类型 | 定性口径 |
|---------|---------|
| 直接责任 | (1)直接违反法规制度 (2)授意指使强令纵容包庇 (3)失职渎职 (4)其他违反法规制度 |
| 主管责任 | 直接责任以外的领导和管理责任 |

> 注：具体定责应配合"审、定、评、用"定责双链模型（过程6类+性质6类+后果2类）使用

### 十、效益审计（非金额+金额）

**金额类**：
- 损失浪费、违规改变资金用途、账外资产
- 资金滞留闲置、虚报冒领、高风险对外投资/担保

**非金额类（计数型）**：
- 总体可行性研究有重大缺陷
- 总体目标不明确或无考核标准
- 建设未按时达到总体目标
- 使用运营未达到总体设计目标
- 内部控制有重大缺陷
- 虚假立项 / 违规立项
- 违规招投标
- 未进行环境影响评价
- 未按规定进行结算或竣工决算

### 使用建议

1. 发现具体问题 → 按审计类型查找对应定性表述
2. 撰写审计报告 → 用标准化定性名称替换模糊描述
3. 问题定性与定额 → 区分"侵害人民群众利益""损失浪费"等量化的口径
4. 经济责任定责 → 配合 eco-responsibility-audit 的定责双链模型使用

## 典型案例精析

### 案例1：假合同、实挪用——县旅发委原主任丁某挪用公款1800万案

> 来源：修水县审计局，经责审计公众号整理
> 审计类型：县旅游局经责审计
> 核心手法：虚假合同列支 + 利用关联公司账户 + 未入账银行流水

#### 案件事实
A县审计局对县旅发委原主任丁某任期经责审计，查出：
- 虚假合同列支专项资金（游客接待中心工程款15.2万，合同21.86万→开票19.65万→实付15.2万，无具体施工地点）
- 利用担任董事长的融资公司账户，挪用公款1800万元转至女儿男朋友个人账户
- 为女儿完成揽储任务和理财，占用资金9-38天不等

#### 审计突破点（方法论）
| 步骤 | 操作 | 关键发现 |
|------|------|---------|
| 1 | SQL筛选异常支付摘要 | 发现"支付游客接待中心工程款"科目异常 |
| 2 | 调阅原始凭证对比 | 合同主体不合法+合同/税票/实付金额不一致+无施工地点 |
| 3 | 查银行对账单 | 发现大额支出转入XX公司，该公司董事长为丁某本人 |
| 4 | 延伸审计关联公司 | 发现该公司仅用于融资，无实质业务 |
| 5 | SQL比对明细账vs银行流水 | 发现10笔未入账流水，全部转入个人账户 |
| 6 | 出具审计要情 | 县领导批示，纪委立案 |

#### 可复用的审计技巧
1. **合同三对照**：合同金额 vs 发票金额 vs 实付金额，不一致必查
2. **银行对账单底线思维**：账外资金只有比对银行流水才能发现
3. **延伸关联单位**：发现账上支付的对方单位——查其隶属关系
4. **明细账vs流水差异分析**：未入账的银行流水往往是账外操作的线索
5. **个人账户穿透**：公司→个人→核实关系人（本案为女儿男朋友）

#### 关联技能
- audit-sql-patterns（SQL比对明细账与银行流水）
- audit-data-analyst（合同三对照标准化模板）
- eco-responsibility-audit（定责：直接责任/领导责任界定）


#### 逻辑链（标准格式）

```
合同三不一致(21.86万≠19.65万≠15.2万)
→ 追问真实性(无施工地点 → 经办人支支吾吾)
→ 银行流水节点(大额支出转入旅投公司)
→ 工商查询人物关联(董事长=丁某本人)
→ 银行流水SQL比对(10笔未入账,全部转入王某个人账户)
→ 询问笔录+银行打印件+合同复印件
→ 挪用公款1800万+DATEDIFF(9~38天)+追索关系人(女儿男朋友)
```

#### 深度分析（6维度）

**维度一：审计方法论复盘**

| 阶段 | 做法 | 可迁移原则 |
|------|------|-----------|
| 疑点发现 | SQL筛选摘要中关键词"支付……工程款" | 建立高频异常关键词库（如"工程款""咨询费""服务费"） |
| 线索深挖 | 合同三对照发现金额不一致 | 任何合同必须核查金额一致性：合同价≠发票价≠实付价 |
| 主体怀疑 | 副主任代签合同无授权书 | 关注签字越权行为——代签=可能有隐情 |
| 关联识别 | 收款方董事长正是丁某本人 | 建立"账上交易对手→工商信息→领导干部交叉索引"检查表 |
| 证据突破 | 银行流水 vs 明细账 SQL 比对 | 明细账和银行流水必须交叉比对，差异=必查项 |
| 成果转化 | 审计要情直接报送县主要领导 | 重大问题不走常规报告流程，直报一把手的快速通道 |

**维度二：内控缺陷根因分析**

| 缺陷层级 | 具体问题 | 整改方向 |
|---------|---------|---------|
| 岗位制衡 | 丁某兼旅发委主任+旅投公司董事长+重大项目决策人 | 一把手不得兼任下属企业负责人；决策权与执行权分离 |
| 资金管控 | 公司账户由副主任兼出纳一人操作 | 出纳与会计分设；大额资金双签制度；定期网银对账 |
| 审计监督 | 旅投公司成立后从未接受审计 | 所有关联企业纳入审计范围；新设企业满一年必审 |
| 银行对账 | 代理记账未附银行对账单 | 强制规定：每月银行对账单必须附在凭证后，审计时对照 |
| 票据管理 | 虚假合同+无具体施工地点仍能支付 | 大额支付前必须实地验证；合同附施工地点实景照片 |

**维度三：法律定性与责任划分**

| 主体 | 行为定性 | 法律依据 | 责任类型 |
|------|---------|---------|---------|
| 丁某 | 利用职务便利，指使下属将公款转个人账户，为女儿揽储理财 | 《刑法》第384条挪用公款罪 | 直接责任 |
| 朱某 | 明知违规仍执行，未抵制未报告（副主任兼出纳） | 从犯，免于刑事处罚 | 领导责任（执行层面） |
| 邱某 | 违规代签合同（副主任） | 未追究刑事责任 | 管理责任 |

**维度四：同类风险扩展检查清单**

以下场景可复用本案的审计思路进行检查：

| 场景 | 检查方法 | 对应技能 |
|------|---------|---------|
| 领导兼任下属企业负责人 | 查工商登记信息，看是否有交叉任职 | rongce-gov-audit |
| 账上大额支付给关联公司 | 查收款方工商信息，追溯实际控制人 | audit-data-analyst |
| 银行流水与明细账不一致 | SQL比对，关注未入账流水 | audit-sql-patterns |

| 代理记账未附银行对账单 | 强制索要对账单原件/电子版 | audit-data-quality |

**维度五：审计要情写作要点（本案产出物）**

本案中审计组写出了高质量的《审计要情》直接报送县主要领导，获得批示。审计要情写作要点：
1. **标题直击**："丁某涉嫌严重违纪违规线索的报告"
2. **事实清晰**：时间、金额、账户、人员、过程，不主观推测
3. **证据链完整**：虚假合同复印件+银行流水+比对结果+询问笔录
4. **定性明确**：涉嫌挪用公款1800万元
5. **建议具体**：转纪委依纪核查

## 审计思路从头梳理方法论

> 以丁某挪用公款案为参照模板，适用于经责审计/专项资金审计/部门预算审计等类似项目

### 第一步：审前——先把"雷"画出来

**不要等进场才想查什么，进点前画好三个图。**

**图1：权力关系图**
```
审前必画：
被审计单位   →  领导岗位   →  同时兼任哪些下属企业职务？
下属企业     →  法人代表是谁？   →  出纳会计是谁？
关联企业     →  工商信息核实   →  实际控制人是谁？
```
丁某案的教训：丁某兼旅发委主任+旅投公司董事长，审前没有画出这个权力交叉，差点漏掉1800万。

**图2：资金流向图**
```
财政拨款 → 旅发委账户 → 支付给谁？ → 对方工商信息？ → 是否有关联？
融资资金 → 旅投公司账户 → 转给谁？ → 是否回流？ → 利息计了没有？
```
凡是发现"钱从A出去→进了B→B和A有关联"，这条线必须拉到底。

**图3：关联方关系图**
```
被审计领导
├── 亲属任职/持股的企业（工商查配偶/子女/父母）
├── 同学/老乡/前同事任法定代表人的企业
├── 本人兼任董事/监事的企业
└── 领导人签字审批的合同供应商
```
丁某案：王某是女儿男朋友，审讯前查工商看不出来，但"同一个收款账户反复出现"就是信号。

### 第二步：进点——先看这三样东西

不要一上来就翻凭证。按顺序做：

**第一样：银行对账单（要原件）**
- 不是财务给的那份，是自己去银行打印或网银核对的
- 重点关注：大额支出是否有记账凭证对应？
- 丁某案破局点：发现10笔银行流水在会计账上没有记录

**第二样：工商登记信息（查交叉任职）**
- 单位对外支付的所有对方单位，查工商信息
- 重点：法人代表/高管/股东是否和被审计单位领导同名或有关系
- 丁某案：支付给旅投公司，一查工商，董事长=丁某

**第三样：合同台账（建三对照表）**
```
建立速查表：
合同名称 | 合同金额 | 发票金额 | 实付金额 | 差额 | 异常判断
游客接待中心 | 21.86万 | 19.65万 | 15.20万 | 6.66万 | 三方不一致
```

### 第三步：实施——用"三线一底"框架推进

**线1：资金轨迹线**
```
起点：财政拨款/上级补助 → 终点：最终收款人
中间每经过一个账户都要停下来问：
- 这个账户是单位的还是个人的？
- 收款方和单位是什么关系？
- 款有没有回流？
```
丁某案轨迹：旅投公司账户→王某（女儿男朋友）个人账户→回款。如果审计人员看到"公司→个人"这条线时停下来追问，早就发现问题了。

**线2：合同真实性线**
```
问四个问题就能验证合同真伪：
1. 合同标的存在吗？（去现场看）
2. 合同价款合理吗？（市场询价比对）
3. 合同执行真实吗？（问经办人、问施工方）
4. 合同签字合规吗？（一把手签了没有？代签有授权吗？）
```
丁某案：合同说"游客接待中心场地建设"→去现场看→说不出具体地点→合同假。

**线3：决策程序线**
```
每一步决策问三个问题：
- 有没有上会？（会议纪要）
- 有没有签字？（审批记录）
- 有没有记录？（书面留痕）
凡是"应该有但没有"的，就是沉默证据——重点查。
```

**底：银行对账单底核**
```
无论账上看起来多干净，必须做这件事：
明细账（财务系统导出） vs 银行流水（银行打印）
SQL 关联比对，查出：
- 有账无流水（虚列支出）
- 有流水无账（账外资金） ← 丁某案关键发现
```

### 第四步：判断——发现异常后怎么做

| 异常信号 | 怀疑方向 | 下一步操作 |
|---------|---------|-----------|
| 合同三不一致 | 虚假合同套取资金 | 去现场验证、查银行流水去向 |
| 账支付给关联公司 | 利益输送 | 查工商信息、查法人关联关系 |
| 流水有但账上没有 | 账外资金/小金库 | 追资金去向、查授权人 |
| 一把手兼职下属企业 | 权力集中风险 | 查该企业所有资金往来的审批签字 |
| 大额资金转个人账户 | 挪用/贪污 | 核实收款人和领导的关系 |
| 领导签字全是大额支出 | 权力滥用 | 查每一项是否经集体决策 |

### 第五步：收尾——成果转化三个层次

**第一层：问题**（就事论事）
> 丁某挪用公款1800万元
→ 写进审计报告

**第二层：线索**（连点成线）
> 一把手兼任下属企业负责人→资金管控缺失→大额资金一人操作
→ 写进审计要情

**第三层：制度建议**（举一反三）
> 建议：建立一把手不兼任下属企业负责人制度、大额资金双签制度、关联企业定期审计制度
→ 写进审计建议

### 速记口诀

> 审前画三图（权力+资金+关联），进点先看三样（对账单+工商+合同）；
> 推进三线一底（资金线+合同线+决策线+对账单底），异常五步推；
> 成果三层转（问题+线索+建议），制度堵漏洞。

|------|-----------|

### 阶段二：进点前准备（2天）

**动作**：发出审计通知书后、进点前完成

**产出物3：资料清单（13类，一次性发）**

用这个模板直接发函，缺什么让被审计单位提前备好：

```
关于提供XXX局长任期经济责任审计资料的函

1. 述职报告（局长签字）
2. 单位机构设置和职责分工文件
3. 近X年工作总结和考核结果
4. 会议纪要（党委会/局长办公会，全套）
5. 近X年预算批复和决算报告
6. 银行开户清单及所有账户对账单（原件）
7. 大额合同台账（≥50万元）
8. 基建项目台账（含立项→验收全过程）
9. 固定资产台账
10. 以前审计整改报告
11. 内控制度汇编
12. 人员编制和薪酬发放表
13. 关联企业清单（下属单位/投资企业/挂靠企业）
```

**产出物4：SQL预检脚本**（如有电子数据）
```sql
-- 进点前就跑一遍，找信号
SELECT 摘要, SUM(金额) 
FROM 支出明细 
WHERE 摘要 LIKE '%工程%' OR 摘要 LIKE '%咨询%' OR 摘要 LIKE '%服务%'
GROUP BY 摘要 
ORDER BY SUM(金额) DESC;

-- 查大额转个人
SELECT * FROM 支出明细 
WHERE 收款方 LIKE '%个人%' OR LEN(收款方) < 8
ORDER BY 金额 DESC;
```

**用时**：2天。发资料清单的同时自己查工商、跑SQL预检。

**产出物7：疑点清单模板**
```
| 序号 | 疑点描述 | 涉及金额 | 发现方式 | 怀疑方向 | 优先级 |
|------|---------|---------|---------|---------|-------|
| 1 | 支付XX工程款无合同 | 50万 | SQL摘要 | 虚假支出 | P0 |
| 2 | XX账户流水未入账 | 200万 | 流水比对 | 账外资金 | P0 |
| 3 | 收款方工商查无此人 | 30万 | 工商核实 | 虚假供应商 | P1 |
```

**优先级标准**：P0=可能犯罪（立刻行动）、P1=可能违规（当周核实）、P2=管理不规范（写入报告）

**用时**：第1周集中火力。

### 阶段四：疑点深挖（第2-3周）

**动作**：针对疑点清单逐个深挖

**三个必做动作（不管疑点大小）：**

**动作1：延伸访谈模板**
```
访谈对象：经办人/财务/项目负责人
问题清单（必问7个）：
1. 这个项目你参与了吗？
2. 领导是怎么交代的？
3. 决策过程是怎样的？有没有会议？
4. 验收是谁签的字？
5. 你有没有觉得哪里不对劲？
6. 以前审计有没有指出过类似问题？
7. 你有没有什么想补充的？
```

**动作2：证据固定清单**
```
每个问题必须固定以下证据（缺一不可）：
□ 原始凭证复印件
□ 合同相关页复印件
□ 银行流水打印件
□ 会议纪要相关页
□ 询问笔录（当事人签字）
□ 被审计单位说明（盖章）
□ 数据比对结果截图
```

**动作3：要情报送判断标准**
```
满足以下任一条，立即出要情（不走常规报告流程）：
- 涉及金额超100万元
- 涉及个人账户
- 涉及领导干部本人或亲属
- 可能构成犯罪
- 可能产生重大社会影响
```

**用时**：第2-3周。P0先挖，P1随后，P2最后。

### 阶段五：报告撰写（第3-4周）

**动作**：边挖边写，不等人催

**产出物8：报告分块模板**
```
第一部分：基本情况（半页写完）
├── 单位性质、编制人数
├── 局长任期、职责分工
└── 近X年预算规模

第二部分：总体评价（一页写完）
├── 局长履职主要情况（实事求是，不虚夸）
├── 未发现本人在廉洁从政方面的问题（如有）
└── 审计发现问题见下文

第三部分：审计发现（核心，逐项列）
├── 按问题重要性排序
├── 每个问题：事实+证据+定性+定责
└── 问题用序号标注（对应疑点清单编号）

第四部分：责任界定
├── 直接责任（本人签字决策/授意指使/失职）
├── 领导责任（疏于监管/制度不健全）
└── 依据：《规定》第40-41条

第五部分：审计建议
├── 针对具体问题（整改）
├── 针对制度漏洞（完善制度）
└── 针对同类风险（举一反三）
```

**产出物9：要情模板**（如发现重大问题）
```
审计要情
标题：关于XX局长涉嫌XX问题的报告

一、基本情况（一段话）
二、发现的主要问题（逐项列，有时间有人物有金额）
三、已采取的措施（已经核实的证据）
四、建议（转纪委/移送/立案）

附件：证据材料清单
```

**用时**：第3-4周。报告初稿在第3周出，留1周征求意见和修改。

### 阶段六：收尾归档（第4周-90天）

**动作**：报告出具后90日内跟踪整改

**产出物10：整改跟踪表**
```
| 问题 | 整改建议 | 责任单位 | 完成时限 | 完成情况 | 未完成原因 |
|------|---------|---------|---------|---------|-----------|
| XX | XX | XX局 | XX.XX | 已完成/进行中 | 说明 |
```

### 最低配置（如果只有1-2个人）

不要贪多，三个最低要求：

2. **进点第1天要银行对账单** → 自己查，不给别人看的机会
