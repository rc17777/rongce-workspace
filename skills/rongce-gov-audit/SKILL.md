# 融策政府审计AI Skill

## 概述

本Skill为融策会计师事务所定制，基于事务所10人团队、政府审计（40%）+咨询（60%）的业务特点，
将资深CPA的审计经验固化为可复用的AI工作流。

## 核心理念

- **AI做执行，人做判断**：异常筛查、底稿生成、报告初稿由AI完成；问题定性、专业判断、最终结论由人完成
- **规则驱动**：所有AI输出基于明确的风险规则库和模板，确保一致性和可追溯性
- **数据安全优先**：处理政府审计数据时，遵循"数据不出域、最小权限、全程留痕"原则

## 政府审计类型识别

根据用户输入，自动匹配以下四类审计：

1. **预算执行审计** — 关键词：预算、决算、收支、财政拨款、三公经费
2. **经济责任审计** — 关键词：任期、离任、领导干部、经济责任、履职 → 同时参考 eco-responsibility-audit Skill
3. **专项资金审计** — 关键词：专项资金、补贴、项目资金、转移支付、民生资金
4. **绩效审计** — 关键词：绩效、效果、效益、投入产出、目标完成

## 通用规范

1. 底稿格式：使用统一模板（参见 gov-audit-templates.md），包含检查程序、取证清单、数据留痕区
2. 法规引用：引用现行有效法规，标注具体条款号。常用法规见 regulations-database.md
3. 异常标识：三级风险标注（🔴高/🟡中/🟢低），附带风险描述和检查方向
4. 脱敏提醒：生成含真实数据的内容时，自动提示脱敏处理
5. 留痕要求：所有AI生成内容标明"AI辅助生成，需人工复核"，保留修改记录空间

### 5大挑战→融策应对策略

| 挑战 | 官方对策 | 融策落地方案 |
|------|---------|-------------|
| 数据安全 | 加密/脱敏/权限控制 | 处理客户数据时：本地处理不上传、结果脱敏后分享 |
| 算法偏见 | 算法审查/评估/问责 | 所有AI输出标注"需人工复核"，不作为最终结论 |
| 组织适应 | 制度/流程再造 | 先在小项目试点，验证后推广（已在教科院附中项目验证） |
| 技术能力不足 | 培训+政务大模型 | 借助OpenClaw+现有技能库，降低技术门槛 |
| 数据治理短板 | 数据标准化建设 | 统一数据采集模板，建立数据特征库（参见audit-data-analyst） |

## 工作流

1. 确认审计类型和被审计单位信息
2. 加载对应 references 文件中的模板和规则
3. **新增：如涉及AI审计场景，先查阅 [ai-audit-landscape.md](references/ai-audit-landscape.md) 匹配适用技术**
4. 执行分析/生成任务
5. 标注需要人工复核的关键判断点
6. 输出可编辑的Word/Excel文档

|---|---------|---------|
| 1 | 预算编报不真实 | 未准确真实编报预算，存在虚假项目或事项 |

| 12 | 账外资产 | 未入账/私存私放 |
| 13 | 未落实收支两条线 | 应实行未实行 |
| 14 | 违规采购 | 违反政府采购规定 |
| 15 | 违规担保 | 违反法律规定担保 |
| 16 | 决算草案编报不完整 | 未将全部单位纳入决算 |

> 注：具体定责应配合"审、定、评、用"定责双链模型（过程6类+性质6类+后果2类）使用

### 十、效益审计（非金额+金额）

**金额类**：
- 损失浪费、违规改变资金用途、账外资产
- 资金滞留闲置、虚报冒领、高风险对外投资/担保

**非金额类（计数型）**：
- 总体可行性研究有重大缺陷
- 总体目标不明确或无考核标准
- 建设未按时达到总体目标
- 使用运营未达到总体设计目标
- 内部控制有重大缺陷
- 虚假立项 / 违规立项
- 违规招投标
- 未进行环境影响评价
- 未按规定进行结算或竣工决算

### 使用建议

1. 发现具体问题 → 按审计类型查找对应定性表述
2. 撰写审计报告 → 用标准化定性名称替换模糊描述
3. 问题定性与定额 → 区分"侵害人民群众利益""损失浪费"等量化的口径
4. 经济责任定责 → 配合 eco-responsibility-audit 的定责双链模型使用

## 典型案例精析

### 案例1：假合同、实挪用——县旅发委原主任丁某挪用公款1800万案

> 来源：修水县审计局，经责审计公众号整理
> 审计类型：县旅游局经责审计
> 核心手法：虚假合同列支 + 利用关联公司账户 + 未入账银行流水

#### 案件事实
A县审计局对县旅发委原主任丁某任期经责审计，查出：
- 虚假合同列支专项资金（游客接待中心工程款15.2万，合同21.86万→开票19.65万→实付15.2万，无具体施工地点）
- 利用担任董事长的融资公司账户，挪用公款1800万元转至女儿男朋友个人账户
- 为女儿完成揽储任务和理财，占用资金9-38天不等

#### 审计突破点（方法论）
| 步骤 | 操作 | 关键发现 |
|------|------|---------|
| 1 | SQL筛选异常支付摘要 | 发现"支付游客接待中心工程款"科目异常 |

| 4 | 延伸审计关联公司 | 发现该公司仅用于融资，无实质业务 |

| 6 | 出具审计要情 | 县领导批示，纪委立案 |

#### 可复用的审计技巧
1. **合同三对照**：合同金额 vs 发票金额 vs 实付金额，不一致必查
2. **银行对账单底线思维**：账外资金只有比对银行流水才能发现
3. **延伸关联单位**：发现账上支付的对方单位——查其隶属关系
4. **明细账vs流水差异分析**：未入账的银行流水往往是账外操作的线索
5. **个人账户穿透**：公司→个人→核实关系人（本案为女儿男朋友）
