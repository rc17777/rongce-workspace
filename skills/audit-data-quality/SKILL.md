# 数据质量审计

对审计获取的数据进行全面质量检查：完整性（缺失率）、一致性（格式规范）、准确性（逻辑校验）、唯一性（重复检查）、时效性（时间范围）。自动生成数据质量报告。

## 适用场景

- 审计数据质量检查、数据清洗前评估

## 执行步骤

### 步骤 1
提供待检查的数据文件（CSV/Excel）

### 步骤 2
逐列扫描：缺失值比例、数据类型一致性、取值范围合理性、重复记录比例、时间字段时效

### 步骤 3
对每列打分（0-100），标记不合格字段（<60分）

### 步骤 4
输出：数据质量总评 + 逐列评分 + 修复建议


## 输出格式

```
【总体评分】72/100
【不合格字段】
1.'收货地址'列: 45分—缺失率15%，格式不统一（含'金川县'/具体门牌）
2.'发票日期'列: 52分—29.3%记录超出20天时限
【修复建议】地址列需补全具体门牌或标注'自提'；超期发票需逐条核查原因
```
