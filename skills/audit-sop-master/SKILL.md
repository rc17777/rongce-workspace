# 底稿填写规范SOP导航

快速检索'两重两新项目审计底稿填写规范SOP'中的任何规范条目。覆盖8个Sheet、50+字段的填写标准、正反示例和常见错误。

## 适用场景

- 不确定底稿某字段该怎么填、需要查SOP规范

## 执行步骤

### 步骤 1
输入要查询的Sheet名称或字段名（如'Sheet2审计内容与操作步骤'、'问题描述三段式'）

### 步骤 2
系统返回该字段的填写规范（含字数要求、正反示例、常见错误）

### 步骤 3
如需完整SOP，可选择下载或在线预览


## 输出格式

```
【字段】Sheet2—审计内容与操作步骤
【要求】须包含三要素：①做什么（动词+对象）②怎么做的（工具/方法）③查了多少（范围/数量）
【正确示例】对1595条交易记录全量筛查：按发票开具时间与交易完成时间的间隔（datediff>20天）筛选超期记录，使用Excel数据透视表+条件格式实现
【错误示例】查了发票（过于简略，无工具和范围）
【字数】50-200字
```
