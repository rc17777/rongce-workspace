# 深度研究工作流（三档自适应）

> 核心理念：**AI = 初级分析师**——快、知识面广，但直觉没训练过，会想当然、会编数字、会把估算说成事实。
> 解决方案：**铺轨道，不是让它更聪明**。严谨不是靠提醒，是靠写进结构。

---

## 触发条件

用户需要**超越简单查询的分析性工作**时使用：

- 审计项目根因分析（不只列问题，而是追问为什么）
- 行业/竞品对标研究（横向对比 + 可比性声明）
- 决策推演（多情景剧本 → 触发条件 → 可观察信号）
- 系统性调研报告（从采集到洞察的完整链条）
- 复杂问题拆解（把模糊需求转化为可执行的研究步骤）

---

## 三档模式（启动时让用户选一档）

| 档位 | 产出 | 步骤 | 图 | 时长 | 适用 |
|------|------|------|-----|------|------|
| **light** | 5页决策备忘 | 6步 | 无 | <30min | 快决策、内部备忘 |
| **medium** | 10-15页主题分析 | 8步 | 3-8张 | 1-2h | 部门汇报、专题研究 |
| **heavy** | 1.5万字旗舰报告 | 11步 | 20+ | 半天+ | 战略规划、对外发布 |

**关键设计**: skill 只加载选中那一档的工作流——小项目不背重流程，不浪费 context。

## 四条不可妥协的原则

### 1. 来源可追溯
任何数字必须追到原始来源。追不到就**标存疑并剔除**，绝不写进结论。
宁可写「未公开」，也不给看似合理的猜测。

### 2. 三态标注（措辞不混）
| 类型 | 措辞 | 示例 |
|------|------|------|
| 事实 | "数据显示" / "根据XX" | "根据国家统计局，2024年GDP增长5.2%" |
| 估算 | "估算" / "推算" + 方法 | "基于XX方法估算，市场规模约200亿" |
| 推断 | "推测" / "可能" / "倾向于" | "综合多来源信息，推测其市场份额在15-20%" |

### 3. AI 副驾不主驾
- 假设（research question）、scope、最终签字 → **人决定**
- 检索、取数、出图、初稿 → AI 执行
- 关键节点写死停点，AI 不能越过

### 4. 持续迭代
每个项目以复盘收尾，经验证的经验回流进本 skill。

## 工作流详情

### Light 模式（6步，无图，快速产出）

```
① 锁定假设〔人工〕
② 快速检索（2-3个关键源）
③ 要点摘要
④ 交叉验证（1轮）
⑤ 输出5页备忘
⑥ 确认〔人工〕
```

### Medium 模式（8步，3-8张图）

```
① 锁定假设〔人工〕
   一句话研究问题，检索前定死，全程跟着走
② 广谱检索
   五类来源：官方统计/多边机构/央行/卖方研报/公司原始披露
   PDF整篇下，不只看摘要
③ 提纲 + 配图规划〔人工确认〕
   结构和配图先给人过目
④ 取数 + 出图
   每张图一组 CSV + 脚本，标题数字必须和图上数据对得上
⑤ 一气呵成写初稿
   单 LLM 从头写到尾，边写边标引用，绝不写完再补
⑥ 自我批评 6 维度〔质量门〕
   事实/单位/引用/连贯/论证/语言，查三轮，不过关→回第5步
⑦ 独立核验〔质量门〕
   每个撑结论的数字交叉核对，核不过标存疑或删除
⑧ 定稿签字 + 派生〔人工〕
   人读完整篇签字，再派生公众号/HTML/Word
```

### Heavy 模式（11步，20+图，可选多LLM）

在 Medium 8 步基础上增加：
```
⑨ 多 LLM 分工校验（见下方 Multi-LLM 策略）
⑩ 外部专家/同行审视模拟
⑪ 全量证据台账 + 可复现声明
```

---

## 质量门6维度（第6步自查清单）

| 维度 | 检查项 |
|------|--------|
| 事实 | 每个数字有原始来源吗？追过PDF原文了吗？ |
| 单位 | 百分比、金额、人次，单位统一了吗？换算对吗？ |
| 引用 | 引用格式一致吗？没有遗漏来源标注？ |
| 连贯 | 段落之间逻辑通吗？前后没有矛盾？ |
| 论证 | 从数据到结论的推理链完整吗？有没有跳步？ |
| 语言 | 三态标注正确吗？没有把估算写成事实？ |

## 多LLM分工（Heavy模式可选）

| LLM | 角色 | 职责 |
|-----|------|------|
| **Claude** | 主笔+编排 | 英文IB级写作、搭结构、端到端流程 |
| **GPT-5** | 外部批评者 | 数值精度、单位一致、事实核验、语言红线 |
| **DeepSeek** | 中文润色 | 中文表达优化（已提炼为风格指南，可由Claude套用） |

---

## 〔人工〕和〔质量门〕执行规则

这两个标记是**写死的停点**，AI 不能越过：

- **[人工]** → 必须等人回复"确认"或给出修改意见，绝不能自己编假设、自己签 scope
- **[质量门]** → 完成自查后，输出自查结果并等待人确认，不过关就回滚
