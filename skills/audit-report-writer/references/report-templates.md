# 审计报告模板库

## 模板一：专项审计报告

适用于：采购项目审计、专项资金审计、特定事项审计

```
一、基本情况
  1.1 审计依据（委托书/通知书）
  1.2 审计范围（时间/业务/金额范围）
  1.3 审计方法（抽查/全查/抽样比例）
  1.4 被审计单位基本情况

二、审计发现
  问题1：[标题]
    - 问题描述：（事实）
    - 涉及金额/范围：（量化）
    - 违反规定：（法规+条款）
    - 原因分析：（根因）
    - 风险等级：🔴/🟡/🟢

  问题2：...

三、审计结论
  3.1 总体评价（1段）
  3.2 主要问题汇总（表格式）

四、整改建议
  4.1 立即整改事项
  4.2 限期整改事项
  4.3 持续改进建议

五、附件
  - 附件1：问题清单（编号/问题/金额/法规/建议/责任部门/整改期限）
  - 附件2：审计组成员及分工
  - 附件3：被审计单位反馈意见
```

## 模板二：经济责任审计报告

适用于：领导干部经济责任审计

```
一、基本情况
  1.1 审计依据
  1.2 被审计领导干部及任期
  1.3 审计范围与方法

二、履行经济责任情况
  2.1 重大经济决策情况
  2.2 财政财务收支情况
  2.3 国有资产（资源）管理情况
  2.4 内部控制制度建立与执行情况
  2.5 廉政规定执行情况

三、审计发现的主要问题
  问题1：...
  （每个问题注明：责任归属 → 直接责任/主管责任/领导责任）

四、审计评价
  4.1 总体评价
  4.2 分项评价

五、整改建议

六、附件
```

## 模板三：管理咨询报告

适用于：管理建议书、内控评价、流程优化咨询

```
一、项目背景
  1.1 委托事项
  1.2 咨询范围
  1.3 工作方法

二、现状评估
  2.1 管理现状描述
  2.2 对标分析（行业最佳实践）
  2.3 差距识别

三、问题分析
  问题1：[标题]
    - 现状描述
    - 行业对标
    - 影响分析（量化）
    - 根因分析

四、改进建议
  建议1：[标题]
    - 目标状态
    - 实施步骤
    - 预期效果（量化）
    - 投入估算
    - 优先级与时间表

五、实施路线图
  第一阶段（1-3个月）：...
  第二阶段（3-6个月）：...
  第三阶段（6-12个月）：...

六、附件
```

## 模板四：工程审计报告

适用于：工程结算审计、工程跟踪审计

```
一、项目概况
  1.1 工程基本信息
  1.2 审计范围（标段/合同/变更）
  1.3 送审金额

二、审计结果
  2.1 审定金额
  2.2 核减金额及核减率
  2.3 核增金额

三、主要核减/核增事项
  事项1：[标题]
    - 送审情况
    - 审计调整
    - 调整依据
    - 调整金额

四、发现的管理问题
  （同专项审计格式）

五、审计建议

六、附件
  - 附件1：工程结算审核对比表
  - 附件2：审定明细表
```
