# 审计报告写作25条铁律

> 借鉴Nature期刊写作严谨性标准，适配审计/咨询报告场景。

## 一、语言精准（Rules 1-8）

### Rule 1: 消灭模糊量词
- ❌ "存在较大问题" / "部分项目" / "一定程度上"
- ✅ "抽查的15个项目中，有8个项目（53%）存在..."
- **原则：** 能用数字就不用形容词

### Rule 2: 消灭听说式表达
- ❌ "据了解" / "据悉" / "据了解情况的人士透露"
- ✅ "审计抽查发现" / "根据XX文件显示" / "查阅XX台账发现"

### Rule 3: 结论必须有三要素
每个审计结论必须同时具备：
1. **事实依据**（什么问题，涉及多少）
2. **法规依据**（违反了什么，第几条）
3. **责任主体**（谁的问题，哪个环节）

缺一不可。

### Rule 4: 建议必须可执行
- ❌ "建议加强管理" / "建议引起重视" / "建议进一步规范"
- ✅ "建议XX部门在X月X日前完成XX，由XX负责验收，并将整改报告报送XX"
- **三要素：** 谁做 + 做什么 + 何时做完 + 如何验证

### Rule 5: 区分事实与判断
- 事实用过去时/完成时："审计发现，2024年度有3个项目未进行公开招标"
- 判断用明确标记："审计认为，该做法可能导致..." / "根据XX规定，该行为属于..."

### Rule 6: 不用双重否定
- ❌ "不能说不存在问题" / "并非没有风险"
- ✅ "存在以下问题" / "存在以下风险"

### Rule 7: 不用被动语态隐藏责任主体
- ❌ "招标程序未被严格执行"
- ✅ "采购部门未严格执行招标程序"

### Rule 8: 数字精确
- ❌ "约100多万" / "大概30%左右"
- ✅ "1,234,567.89元" / "30.2%（45/149）"

## 二、结构规范（Rules 9-15）

### Rule 9: 沙漏结构
每章按"总→分→总"排列：
- 开头：本章核心结论（1-2句）
- 中间：发现+证据+分析
- 结尾：本章小结+建议

### Rule 10: 问题按风险排序
- 高风险问题（金额大/性质严重/涉及面广）排在前面
- 同级别按业务环节排序（立项→采购→合同→验收→支付）
- 不要按发现时间排序

### Rule 11: 每个问题独立编号
- 使用"问题1""问题2"或"发现事项一""发现事项二"
- 方便后续整改跟踪和逐条销号
- 在问题清单中使用相同编号

### Rule 12: 引用法规必须完整
- ❌ "根据相关规定"
- ✅ "根据《中华人民共和国政府采购法》（2014年修正）第三十条"
- 包含：法规全称 + 版本/修正年份 + 具体条款

### Rule 13: 数据来源标注
- 关键数据标注来源："根据财务系统导出数据" / "根据合同台账统计"
- 抽样说明："本次审计抽查了2024年度金额50万元以上的采购项目共15个"

### Rule 14: 对比数据要有可比性
- 同期对比要说明口径是否一致
- 不同单位对比要说明业务规模是否可比
- 标注数据时间范围

### Rule 15: 审计范围说明
- 报告必须说明审计的时间范围、业务范围、抽样方法
- 明确"未纳入本次审计范围"的内容

## 三、合规与严谨（Rules 16-20）

### Rule 16: 区分"违反"与"不规范"
- 违反法律法规 → 用"违反""违规"
- 不符合内部制度 → 用"不符合XX规定""未按XX执行"
- 不够优化但合法 → 用"存在改进空间"
- 用词不当可能引发法律风险

### Rule 17: 定性必须准确
- ❌ "涉嫌贪污"（审计无权定性犯罪）
- ✅ "存在资金管理不规范问题，涉嫌违反《XX法》第X条，建议移送XX机关进一步核查"

### Rule 18: 整改建议分级
- **立即整改：** 涉及违法违规，必须马上停止
- **限期整改：** 有明确截止日期
- **持续改进：** 长期机制建设类建议
- 每级标注时限和验收标准

### Rule 19: 敏感信息脱敏
- 涉及个人隐私的信息（身份证号、银行账号）部分遮蔽
- 涉密信息按保密规定处理
- 报告分密级版本（内部版/公开版）

### Rule 20: 审计证据链完整性
报告中的每个发现必须能追溯到底稿：
- 报告结论 → 问题清单 → 审计底稿 → 原始凭证
- 确保"报告中没有一句无依据的话"

## 四、报告品质（Rules 21-25）

### Rule 21: 避免情绪化表达
- ❌ "令人震惊的是" / "触目惊心" / "竟然"
- ✅ 中性、客观、专业的表述

### Rule 22: 不预设立场
- ❌ "该单位管理混乱"
- ✅ "审计发现该单位在XX、XX、XX三个领域存在管理漏洞"

### Rule 23: 被审计单位意见空间
- 报告征求意见稿必须留给被审计单位反馈时间
- 对反馈意见的采纳与否需要逐条说明理由
- 体现审计的公正性

### Rule 24: 图表自明性
- 每张图/表有标题、单位、数据来源
- 不看正文也能理解图表含义
- 使用统一的语义色板

### Rule 25: 终稿三审
- **一审：** 事实与数据（与底稿交叉核对）
- **二审：** 法规引用与定性准确性
- **三审：** 语言、格式、逻辑一致性
