# 三法交叉异常检测

采用Z分数+IQR+孤立森林三种方法交叉验证异常检测。三种方法同时标记为异常的数据点具有极高可信度，减少误报。适用于补贴发放、采购金额、工程计量等场景。

## 适用场景

- 需要从大量数据中自动发现异常值

## 执行步骤

### 步骤 1
提供待分析的数值列（CSV/Excel格式）

### 步骤 2
分别执行Z分数法（|Z|>3为异常）、IQR法（Q1-1.5*IQR ~ Q3+1.5*IQR外为异常）、孤立森林法（contamination=0.1）

### 步骤 3
三种方法结果取交集作为高置信度异常

### 步骤 4
输出：异常明细表 + 各方法标记对照 + 推荐核查优先级


## 输出格式

```
【异常总数】Z分数:23条 | IQR:31条 | 孤立森林:28条
【高置信度异常（三法确认）】12条
【中置信度异常（两法确认）】15条
【Top3建议核查】
1. 记录ID#452: 金额50000元（Z=5.2, IQR异常, IF异常）
2. 记录ID#891: 金额32000元（Z=4.8, IQR异常, IF异常）
...
```
