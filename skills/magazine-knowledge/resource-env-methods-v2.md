## 一、可复用审计方法

### 1.1 政策法规对照分析法
**适用场景：** 专项资金审计、政策执行审计、自然资源资产离任审计

**核心步骤：**
- 梳理政策"支持范围—补贴标准—申报条件—审批流程"完整链条
- 将项目实际情况逐项对照政策条款
- 识别"符合条件但未享受"（应享未享）和"不符合条件但已享受"（违规享受）两类问题

**操作方法：**
```
1. 建立政策清单：收集所有相关资金管理办法、实施细则、补助标准文件
2. 构建对照矩阵：项目名称 × 政策条件（主体资格/投资规模/技术标准/流程合规）
3. 逐项勾稽：申报材料 vs 政策要求 → 发现不匹配项
```

### 1.2 ArcGIS+奥维地图双平台交叉验证
**适用场景：** 矿产资源审计、耕地保护审计、生态红线审计、征占地审计

**核心步骤：**
- 获取自然资源部门矢量数据（生态红线、基本农田、矿区范围、用地审批等）
- 导入ArcGIS进行空间叠加分析
- 用奥维地图进行历史影像对比（不同年份卫星图对比）
- 双平台交叉验证，穿透私挖乱采、违法占地等问题

**技术路径：**
```
数据准备 → 国土三调数据 + 历年卫星影像 + 矿业权范围 + 审批地块范围
    ↓
ArcGIS处理 → 叠加分析(Intersect/Erase) → 识别重叠/越界区域
    ↓
奥维地图 → 历史影像对比(不同年份) → 发现新增/变化区域
    ↓
疑点核实 → 无人机航拍取证 → 现场核查
```

### 1.3 GIS+无人机航测融合审计
**适用场景：** 自然资源资产审计、生态环境审计、大规模土地核查

**核心步骤：**
- **预分析阶段：** GIS数据筛选疑点区域（面积变化、用途变更、越界区域）
- **航测阶段：** 无人机按规划航线自动飞行，生成正射影像（DOM）和三维模型
- **内业分析：** 航测成果与GIS图斑叠加，自动计算差异面积、识别地类变化
- **成果输出：** 生成疑点图斑清单+影像证据

### 1.4 合同-资金-业务三流穿透核查
**适用场景：** 专项资金补贴审计、土壤污染防治资金审计

**核心方法：**
- 合同流：合同签订日期 vs 项目实际开工日期 → 虚假合同（先签后补）
- 资金流：补贴资金到账→支出→最终去向 → 资金挪用/截留
- 业务流：申报投资额 vs 实际投资额（审计核实） → 虚报投资套取补贴

**典型案例识别模式：** 合同金额大→发票齐全→但现场核查发现设备未到位/工程量不足

### 1.5 省级疑点下发核查法
**适用场景：** 矿产资源审计、自然资源资产审计

**核心步骤：**
- 接收省级审计机关下发的遥感/图斑疑点数据
- 不要停留于表面：结合现场核查+拉家常式访谈+历史影像对比
- 从单个疑点扩展到同类问题排查

### 1.6 矿业权"旋转门"交易审计
**适用场景：** 矿业权审批审计、国有资产审计

**识别要点：**
- 矿权评估价与交易价严重偏离（如200万评估→3亿交易）
- 交易前后实际控制人未变（"左手倒右手"）
- 审批环节关键人物与受让方存在关联关系
- 转让时点恰在矿产品价格上涨前夕

## 二、SQL/Python分析模板

### 2.1 耕地占补平衡异常检测SQL
```sql
-- 检测补充耕地项目虚报面积
SELECT 
    a.项目名称,
    a.申报补充耕地面积 AS 申报面积,
    b.实测面积,
    ROUND((a.申报补充耕地面积 - b.实测面积)/a.申报补充耕地面积*100,2) AS 差异率,
    a.补助金额,
    CASE 
        WHEN (a.申报补充耕地面积 - b.实测面积)/a.申报补充耕地面积 > 0.15 
        THEN '高-虚报面积' 
        WHEN (a.申报补充耕地面积 - b.实测面积)/a.申报补充耕地面积 > 0.05 
        THEN '中-面积偏差'
        ELSE '正常'
    END AS 风险等级
FROM 补充耕地项目表 a
LEFT JOIN 实测面积表 b ON a.项目编号 = b.项目编号
WHERE a.验收年度 >= 2020
ORDER BY 差异率 DESC;
```

### 2.2 专项资金补贴合规性筛查SQL
```sql
-- 检测不符合条件的补贴领取
SELECT 
    a.企业名称,
    a.项目名称,
    a.补贴金额,
    a.申报投资额,
    b.核实投资额,
    ROUND(b.核实投资额/a.申报投资额*100,2) AS 投资完成率,
    a.补贴金额/a.申报投资额 AS 补贴比例,
    CASE 
        WHEN b.核实投资额/a.申报投资额 < 0.5 THEN '严重-投资额虚报'
        WHEN a.补贴金额/a.申报投资额 > 0.33 THEN '高-补贴比例超标'
        WHEN b.核实投资额 < 100 THEN '高-小额补贴可疑'
        ELSE '需关注'
    END AS 风险标签
FROM 专项资金补贴表 a
LEFT JOIN 投资额核实表 b ON a.项目编号 = b.项目编号
WHERE a.补贴年度 = 2024
ORDER BY 投资完成率 ASC;
```

```python
    # 2. 转让方与受让方关联检测（简化版：名称相似度）
    # 实际应用中需结合工商股权穿透
    
    # 3. 交易集中度分析
    buyer_count = df.groupby('受让方').size().reset_index(name='受让次数')
    frequent_buyers = buyer_count[buyer_count['受让次数'] >= 3]
    
    # 4. 时间异常：短期内密集转让
```

### 2.5 无人机航测土方量估算Python脚本思路
```python
# 基于无人机航测正射影像和DEM的土方量变化检测
# 工具链：Pix4D/ContextCapture生成DSM → Python对比计算

"""
import rasterio
import numpy as np

def calculate_earthwork_change(dsm_before, dsm_after, boundary_shp):
    '''
    对比两期DSM，计算土方量变化
    dsm_before: 前期数字表面模型 (tif)
    dsm_after:  后期数字表面模型 (tif)
    boundary_shp: 分析范围 polygon shapefile
    '''
    with rasterio.open(dsm_before) as src_before:
        data_before = src_before.read(1)
        transform = src_before.transform
        
    with rasterio.open(dsm_after) as src_after:
        data_after = src_after.read(1)
    
    # 计算高程变化
    diff = data_after - data_before
    
    # 开挖区域（高程降低）= 盗采/非法开采
    excavation_mask = diff < -1.0  # 降低超过1米
    excavation_volume = abs(diff[excavation_mask].sum()) * transform[0] * transform[0]
    
    # 堆积区域（高程增加）= 违规填埋
    fill_mask = diff > 1.0
    fill_volume = diff[fill_mask].sum() * transform[0] * transform[0]
    
    return {
        '开挖量(m³)': excavation_volume,
        '堆积量(m³)': fill_volume,
        '开挖面积(m²)': excavation_mask.sum() * transform[0] * transform[0]
    }
"""
```

## 三、违规模式清单

| 序号 | 违规模式 | 典型表现 | 涉及领域 |
|------|----------|----------|----------|
| 1 | **虚假合同套取补贴** | 合同与发票齐全但现场无实际投入；合同日期在开工之后（后补合同） | 专项资金 |
| 2 | **非法采矿/私挖乱采** | 无证开采、越界开采、以生态修复名义盗采砂石 | 矿产资源 |
| 3 | **矿业权"旋转门"交易** | 评估价极低（200万），短期内高价转让（3亿）；实际控制人未变 | 矿业权审批 |
| 4 | **耕地占补平衡造假** | 将林地/坑塘冒充耕地补充；补充耕地面积虚报；补充后撂荒 | 耕地保护 |
| 5 | **生态红线内违规开发** | 在生态保护红线内批准或建设矿产开发/房地产等项目 | 生态保护 |
| 6 | **基本农田"非农化""非粮化"** | 基本农田上建设厂房、种植经济林木、挖塘养鱼 | 耕地保护 |
| 7 | **专项资金挪用/截留** | 补贴资金到账后转入关联方账户、用于非项目支出 | 专项资金 |
| 8 | **项目投资额虚报** | 申报投资额远超核实的实际投资，套取更高比例补贴 | 专项资金 |
| 9 | **补充耕地后期管护缺失** | 验收通过后无人管护，耕地质量下降甚至撂荒 | 耕地保护 |
| 10 | **领导干部自然资源资产离任失真** | 约束性指标数据造假、重大资源环境问题瞒报漏报 | 经责审计 |

## 五、快速检查清单

### 专项资金补贴审计6步法
```
□ 第1步：政策梳理 → 明确支持范围、补贴标准、申报条件、审批流程
□ 第2步：申报资料审阅 → 申报主体资格、项目内容、投资规模是否真实
□ 第3步：资金流追查 → 补贴资金到账→支出→最终去向（银行流水追踪）
□ 第4步：业务流核查 → 合同vs发票vs实物（现场核查）
□ 第5步：政策执行效果 → 资金使用效益、项目目标达成情况
□ 第6步：问题定性 → 虚报/挪用/截留/骗取 → 提出追回/整改建议
```

### 矿产资源审计GIS核查6步法
```
□ 第1步：数据收集 → 国土三调/矿业权范围/生态红线/基本农田
□ 第2步：ArcGIS叠加 → 矿业权vs生态红线/基本农田 → 识别越界
□ 第3步：奥维历史影像 → 不同年份卫星图对比 → 发现新增采掘点
□ 第4步：省级疑点核查 → 接收并核实上级下发遥感图斑
□ 第5步：无人机航拍 → 对疑点区域航测取证
□ 第6步：现场核实 → 实地踏勘+访谈 → 固定证据
```
