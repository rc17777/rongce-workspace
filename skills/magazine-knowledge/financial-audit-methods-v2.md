## 一、可复用审计方法

### 1.1 全链条穿透式数据分析法（村镇银行审计）
**适用场景：** 银行审计、金融机构审计、信贷业务审计

**核心步骤：**
- **总体分析：** 全面摸底银行资产规模、信贷结构、不良率、集中度等关键指标
- **模型构建：** 针对具体风险领域建立数据分析模型（关联交易、集中度、不良资产等）
- **疑点锁定：** 模型跑批 → 异常数据筛查 → 重点账户追踪
- **穿透核查：** 从异常交易 → 关联方 → 实际受益人 → 最终资金流向

**关键模型维度：**
```
1. 关联方交易模型：借款人vs银行股东/高管 → 关联贷款
2. 贷款集中度模型：单一客户/集团贷款占比超10% → 集中度风险
3. 不良贷款偏离模型：五级分类正常但逾期超90天 → 分类不实
4. 资金流向模型：贷款资金→关联企业→回流借款人 → 以贷还贷
5. 异常交易模型：大额/整数/快进快出 → 洗钱/利益输送
```

### 1.2 政策性农业保险专项审计
**适用场景：** 农业保险审计、涉农资金审计、惠农政策执行审计

**核心方法：**

**保单真实性核查：**
- "零理赔"保单排查：有投保但从未理赔，且承保标的不符实际
- 投保数量与养殖/种植规模比对
- 投保人身份核实（是否本人知情投保）

**虚假投保识别路径：**
```
保单数据 → 筛选"零理赔+大保额" → 核对标的物(如生猪存栏量) 
→ 入户走访核实投保人是否知情 → 追溯保费来源(自缴or垫付)
→ 锁定保险业务员虚假投保/误导投保行为
```

**保费流向追踪：**
- 财政补贴保费 → 保险公司 → 业务员 → 是否有截留/返点
- 自缴保费 → 是否由业务员垫付（虚假投保特征）

### 1.3 国有企业融资合规性审计
**适用场景：** 国有企业审计、经责审计、债务风险审计

**核心方法：**

**"总体分析→发现疑点→系统研究→重点突破"四步法：**
```
总体分析：摸底企业融资总规模、融资结构（银行贷款/债券/非标/租赁）、融资成本分布
    ↓
发现疑点：筛选高息融资、非标融资、关联方融资、异常担保
    ↓
系统研究：穿透融资合同→资金用途→实际受益人
    ↓
重点突破：锁定问题融资 → 谈话询问 → 外部查询 → 资料交互验证
```

**非标高息融资识别要点：**
- 融资成本明显高于同期市场利率（如银行贷款4% vs 非标融资12%）
- 以"咨询费""财务顾问费"名义掩盖高息
- 融资中介与用款企业存在关联关系
- 明股实债/抽屉协议

**违规担保审计：**
- 国有企业对民企/关联方提供担保
- 担保未履行内部决策程序和国资审批
- 担保余额超净资产比例限制
- 互保/联保形成担保圈风险

## 二、SQL/Python分析模板

### 2.1 村镇银行贷款异常检测SQL
```sql
-- 模型1：关联方贷款检测（借款人地址/电话与银行员工重合）
SELECT DISTINCT
    a.借款人名称,
    a.贷款金额,
    a.贷款日期,
    b.员工姓名,
    b.员工岗位,
    '疑似关联方贷款-信息重合' AS 风险类型
FROM 贷款明细表 a
JOIN 银行员工表 b 
    ON (a.联系电话 = b.联系电话 
        OR a.联系地址 = b.家庭地址
        OR a.借款人名称 LIKE CONCAT('%', b.员工姓名, '%'))
WHERE a.贷款余额 > 0;

-- 模型2：贷款集中度检测
SELECT 
    借款人名称,
    COUNT(*) AS 贷款笔数,
    SUM(贷款金额) AS 贷款总额,
    ROUND(SUM(贷款金额)/(SELECT SUM(贷款金额) FROM 贷款明细表)*100,2) AS 集中度占比,
    CASE WHEN SUM(贷款金额)/(SELECT SUM(贷款金额) FROM 贷款明细表)*100 > 10 
         THEN '超过10%监管红线' ELSE '正常' END AS 预警
FROM 贷款明细表
WHERE 贷款余额 > 0
GROUP BY 借款人名称
HAVING SUM(贷款金额)/(SELECT SUM(贷款金额) FROM 贷款明细表)*100 > 5
ORDER BY 集中度占比 DESC;

-- 模型3：不良贷款分类不实检测
SELECT 
    贷款编号,
    借款人名称,
    贷款余额,
    五级分类,
    逾期天数,
    CASE 
        WHEN 逾期天数 > 90 AND 五级分类 = '正常' THEN '分类不实-应调为不良'
        WHEN 逾期天数 > 60 AND 五级分类 IN ('正常','关注') THEN '分类存疑'
        ELSE '匹配' 
    END AS 分类核查结论
FROM 贷款明细表
WHERE 逾期天数 > 60 AND 五级分类 IN ('正常','关注')
ORDER BY 逾期天数 DESC;

-- 模型4：借新还旧/以贷还贷检测
SELECT 
    a.借款人名称,
    a.贷款编号 AS 新贷款编号,
    a.贷款日期 AS 新贷款发放日,
    a.贷款金额 AS 新贷款金额,
    b.贷款编号 AS 旧贷款编号,
    b.贷款日期 AS 旧贷款发放日,
    b.贷款金额 AS 旧贷款金额,
    b.到期日期 AS 旧贷款到期日,
    '疑似借新还旧-时间连续' AS 风险类型
FROM 贷款明细表 a
JOIN 贷款明细表 b 
    ON a.借款人名称 = b.借款人名称 
    AND a.贷款编号 != b.贷款编号
WHERE a.贷款日期 BETWEEN b.到期日期 AND DATE_ADD(b.到期日期, INTERVAL 30 DAY)
    AND a.贷款金额 >= b.贷款金额 * 0.8
ORDER BY a.贷款日期 DESC;
```

### 2.2 农业保险虚假投保检测SQL
```sql
-- 检测"零理赔+异常大保额"可疑保单
SELECT 
    a.保单号,
    a.投保人名称,
    a.被保险人,
    a.保险标的,
    a.投保数量,
    a.保额,
    a.保费,
    a.财政补贴金额,
    b.理赔次数,
    b.理赔总额,
    c.实际养殖规模,
    c.实际种植面积,
    ROUND(a.投保数量/NULLIF(c.实际养殖规模,0),2) AS 投保规模比,
    CASE 
        WHEN b.理赔次数 = 0 AND a.投保数量/NULLIF(c.实际养殖规模,0) > 1.5 
        THEN '高-零理赔+超实际规模'
        WHEN b.理赔次数 = 0 AND a.保费 > 10000 THEN '中-零理赔+大额保费'
        WHEN a.投保数量/NULLIF(c.实际养殖规模,0) > 2 THEN '高-投保远超实际规模'
        ELSE '需关注'
    END AS 风险等级
FROM 农业保险保单表 a
LEFT JOIN (
    SELECT 保单号, COUNT(*) AS 理赔次数, SUM(理赔金额) AS 理赔总额
    FROM 保险理赔表
    GROUP BY 保单号
) b ON a.保单号 = b.保单号
LEFT JOIN 农户实际种养规模表 c ON a.投保人ID = c.农户ID
ORDER BY 风险等级 DESC;
```

### 2.3 国有企业高息融资检测Python脚本
```python
import pandas as pd
import numpy as np
from datetime import datetime

def detect_high_cost_financing(financing_df, market_rate=0.04):
    """
    检测国有企业高息融资
    financing_df 需包含: 融资编号,融资类型,融资金额,年化利率,融资方, 
                       中介机构,中介费用,担保方,担保费率
    market_rate: 同期银行贷款基准利率（默认4%）
    """
    df = financing_df.copy()
    
    # 1. 融资成本分类
    df['利差'] = df['年化利率'] - market_rate
    df['成本等级'] = pd.cut(df['年化利率'], 
                          bins=[0, 0.04, 0.06, 0.08, 0.12, float('inf')],
                          labels=['正常-银行贷款', '关注', '高-非标', '严重-民间借贷', '极高'])
    
    # 2. 隐含费用检测
    df['综合成本率'] = df['年化利率'] + df['中介费用']/df['融资金额']
    df['费用异常'] = df['中介费用']/df['融资金额'] > 0.03  # 中介费超融资额3%
    
    # 3. 融资集中度
    provider_conc = df.groupby('融资方').agg(
        融资金额合计=('融资金额', 'sum'),
        融资笔数=('融资编号', 'count'),
        最高利率=('年化利率', 'max')
    ).sort_values('融资金额合计', ascending=False)
    
    # 4. 异常担保
    df['担保费率异常'] = df['担保费率'] > 0.03  # 担保费率超3%
    df['互保风险'] = df['担保方'].isin(df['融资方'])  # 融资方之间互保
    
    # 输出
    results = {
        '高息融资清单': df[df['年化利率'] > 0.06][['融资编号','融资类型','融资金额','年化利率','利差','成本等级']],
        '费用异常融资': df[df['费用异常']][['融资编号','中介费用','融资金额','综合成本率']],
        '融资集中度TOP5': provider_conc.head(),
        '异常担保': df[df['担保费率异常'] | df['互保风险']][['融资编号','担保方','担保费率','互保风险']]
    }
    
    return results

# 使用示例

# print(result['高息融资清单'])
```

### 2.4 保费财政补贴合规性检测SQL
```sql
-- 检测财政保费补贴流向异常
SELECT 
    a.保单号,
    a.投保人名称,
    a.保险公司,
    a.保费总额,
    a.财政补贴比例,
    a.财政补贴金额,
    a.农户自缴金额,
    a.经办业务员,
    b.业务员收款账户,
    b.业务员名下保单数,
    -- 检测业务员代缴模式
    CASE 
        WHEN a.农户自缴金额 = 0 THEN '农户零缴费-疑似业务员垫付'
        WHEN b.业务员名下保单数 > 50 THEN '业务员保单数异常偏高'
        ELSE '需关注'
    END AS 异常标签
FROM 农业保险保单表 a
LEFT JOIN (
    SELECT 经办业务员, 
           COUNT(*) AS 业务员名下保单数,
           MAX(收款账户) AS 业务员收款账户
    FROM 农业保险保单表
    GROUP BY 经办业务员
) b ON a.经办业务员 = b.经办业务员
WHERE a.农户自缴金额 = 0 
   OR b.业务员名下保单数 > 50
ORDER BY b.业务员名下保单数 DESC;
```

## 三、违规模式清单

| 序号 | 违规模式 | 典型表现 | 涉及领域 |
|------|----------|----------|----------|
| 1 | **村镇银行关联方违规贷款** | 向股东/高管/员工关联企业发放贷款、贷款条件优于市场 | 村镇银行 |
| 2 | **贷款集中度超标** | 单一客户/集团贷款占资本净额超10%、行业集中度过高 | 银行信贷 |
| 3 | **不良贷款分类不实** | 逾期超90天仍列正常类、通过借新还旧隐藏不良 | 资产质量 |
| 4 | **以贷还贷/借新还旧** | 新贷款资金直接或间接用于偿还旧贷款本息 | 信贷管理 |
| 5 | **农业保险虚假投保** | 业务员垫付保费、编造投保标的、零理赔大保额 | 农业保险 |
| 6 | **保险业务员职务侵占** | 截留理赔款、骗取保费补贴、误导农民投保 | 农业保险 |
| 7 | **国有企业非标高息融资** | 以咨询费/财务顾问费名义掩盖高息、融资中介利益输送 | 国企融资 |
| 8 | **国有企业违规担保** | 对民企/关联方担保、担保超净资产比例、互保形成风险 | 国企担保 |
| 9 | **明股实债/抽屉协议** | 表面股权投资实际约定固定回报+到期回购 | 国企融资 |
| 10 | **融资资金挪用** | 贷款资金→关联企业→转回借款人→挪用于非申报用途 | 银行信贷 |

## 五、快速检查清单

### 农业保险审计5步法
```
□ 第1步：保单数据筛查 → 导出全部保单 → 筛选零理赔+大额保单
□ 第2步：标的核实 → 投保标的数量vs实际种养规模 → 入户走访
□ 第3步：保费溯源 → 农户自缴保费缴费记录 → 是否本人缴费
□ 第4步：理赔核查 → 理赔案件抽样 → 核实出险真实性
□ 第5步：资金追查 → 财政补贴资金流向 → 保险公司→业务员→农户
```

### 国有企业融资审计检查清单
```
□ 融资台账完整性 → 所有融资合同是否入账管理
□ 融资成本合理性 → 利率是否明显偏离市场水平
□ 融资中介合规性 → 中介费用是否合理、中介方是否关联
□ 担保合规性 → 担保是否经内部决策/国资审批、担保比率
□ 资金用途真实性 → 融资资金是否按申报用途使用
□ 明股实债排查 → 股权投资合同中是否含固定回报/回购条款
□ 融资集中度 → 单一来源融资是否过于集中
```
