## 一、招投标审计方法

### 1.1 跨年度投标资料真实性审查

**适用场景**：同类型周期性招标项目（如信息化运维、物业外包），陪标单位跨年度套用同一套投标材料。

**审计三步法**：

| 步骤 | 方法 | 判断标准 |
|------|------|----------|
| **步骤1：文本相似度比对** | 用NLP/文本比对工具（如TF-IDF、Levenshtein Distance）计算不同年度不同投标单位的服务方案相似度 | 相似度≥90%→判定造假嫌疑 |
| **步骤2：基本信息一致性核查** | 以统一社会信用代码为锚，比对同一投标单位跨年度的注册资金、营业执照更新情况 | 跨年度无变化且与工商登记不一致→提供虚假信息 |
| **步骤3：错别字位置匹配** | 用分词库分割文本，定位不同单位方案中的错别字/漏字位置，交叉比对 | 错误位置100%吻合→直接判定造假 |

**关键法条**：《招标投标法实施条例》第42条——投标人弄虚作假，评标委员会应当否决其投标。

### 1.2 五大典型问题分析模型

| 问题类型 | 分析模型 | 核心技术 |
|----------|----------|----------|
| **投标人伪造材料** | "投标人伪造投标材料"模型 | 工商信息库+全国建筑市场监管平台+Python批量查询 |
| **招标人规避招标** | "招标人规避招标"模型 | 字符串匹配度函数（阈值0.8）+ 政府采购/限额以下平台交叉比对 |
| **围标串标** | "无介质围标相似度"图数据库模型 | 杰卡德相似系数（>0.7）+ Neo4j/I2可视化集群分析 |
| **招标文件设置壁垒** | "招标文件排他性条款智能识别"模型 | NLP提取资格条件/技术参数 → 筛查"量身定做"条款 |
| **评标不公正** | 评标过程回溯+专家评分偏离度分析 | 评分异常波动检测 |

**法定必须招标规模标准**：
- 工程类：采购预算≥400万元
- 货物类：采购预算≥200万元
- 服务类（勘察/设计/监理）：采购预算≥100万元

### 1.3 围标串标大数据检测

**特征码四维分析**：

| 特征码 | 含义 | 唯一性 | 审计价值 |
|--------|------|--------|----------|
| IP地址 | 互联网协议地址 | 可人为更改 | 辅助参考 |
| 文件制作机器码 | 制作投标文件的电脑硬件编码 | **唯一** | 同一电脑制作多份标书→串标 |
| 文件创建标识码 | 文档编辑软件嵌入的唯一编码 | **唯一** | 三码一致→同一单位编制 |
| 造价锁编码 | 工程量清单制作软件的加密锁编码 | **唯一** | 同一造价锁做多家清单→围标 |

**工具链**：
1. **I2集群分析**：导入项目基础表 → 设定阈值3 → 可视化关系网 → 识别常中标+常陪标组合
2. **RPA技术**：UIBOT自动查询天眼查/企查查 → 穿透陪标供应商工商关系 → 发现"超短"关系链
3. **标书雷同检测**：UltraCompare（二进制比对）+ Beyond Compare（内容定位）+ To check（总体相似度）

### 1.4 招标文件管理审计

**三个维度**：

| 维度 | 审计要点 | 方法 |
|------|----------|------|
| **计价原则** | 是否规避地方财评文件强制性条款 | 政策比对机制 + 计价差额测算 |
| **变更结算原则** | 是否仅"单下浮"未结合中标价；EPC"交钥匙"是否明确全流程边界 | "内容—边界—限额"三维核查 |
| **全流程管理** | 是否经专业团队论证/三重一大程序 | 追溯条款制定流程 |

**典型案例**：PPP项目招标文件排除财评原则文件适用（规避政策强制性下浮条款）→ 投资失控。

## 二、工程造价审计要点

### 2.1 土方工程量审核（GIS遥感法）

**核心痛点**：线性工程空间范围广、取土/弃土位置时空交叉，传统手段难以核实实际土方量。

**三步骤法**：

```
步骤1：变化检测筛查
  ├─ 导入shp格式设计图+红线矢量图层
  ├─ 叠加时序遥感影像（开工前/建设中/完工后）
  ├─ 使用"分屏对比"+"地图动画"功能
  └─ 判断施工进度与计量支付是否一致

步骤2：挖填方平衡分析
  ├─ 取土场：遥感影像测绘开挖面积 × 现场核实开挖深度 → 计算实际取土量
  ├─ 弃土场：手机应用"轨迹记录"绕行勘测 → DEM三维建模 → "三维计算"弃土量
  └─ 对比：实际挖填方量 vs 计量资料上报量

步骤3：现场踏勘印证
  ├─ 疑点图斑同步至手机应用 → 导航核查
  ├─ "拍照"功能获取坐标+时间水印
  └─ 遥感解译+现场勘测+工程资料三源印证
```

**工具**：在线地理信息工具（支持shp/kml导入、分屏对比、地图动画、轨迹记录、数据同步、三维计算）

**典型发现**：设计取土场开挖面积<5000㎡但填筑20万m³→推算挖深>10m，现场核实地下水位高仅能挖4m→实际取土量远低于设计量→未按设计施工。

### 2.2 无价材料管理审计

**问题根源**：材料选择权与定价权分离 → 承包商掌握供应商信息 → 建设单位失去定价权。

**审计发现**：某工程900余种材料审批，抽查100余种→超过70种批价超过采购价100%以上→**平均批价为采购价3倍**。

**审计建议**：
1. **建立询价制衡机制**："背对背"询价（询价权与使用权分离、定价权与审核权分离）
2. **多轮询价**：剥离品牌后首样评审
3. **转分包管理费穿透**：追踪各级中间商管理费累积 → 防止层层加价计入建设成本

### 2.3 信息化项目造价审计（功能点法）

**适用**：软件开发类项目，核心是验证功能点计费的合理性。

**功能点识别原则**："逻辑独立性"+"用户业务价值"——同一业务目的且处理逻辑指向同一ILF的多个数据项应合并为一个。

**三类费用审查**：

| 费用类型 | 审查要点 | 常见违规 |
|----------|----------|----------|
| **定制开发软件费** | 功能点是否虚增：人为拆分模块（同一数据表、同一处理逻辑拆为多个接口→虚增功能点） | 7类传感器数据同表同逻辑，拆为7个接口→虚增6个ILF |
| **系统集成费** | ①外部设备安装费≠系统集成费（不得重复计取）；②集成工作是否与软件开发工作量重复 | 将外场设备安装费+内部开发接口工作重复计入集成费 |
| **数据建设费** | 辨析"独立数据资产"vs"附属数据"：仅为支撑软件运行的初始化/基础数据录入→不应单独计费 | 基础数据采集建库列为"数据建设费"→实质为开发附属工作 |

**审计成果示例**：某2400万元信息化项目，揭示虚增造价213.38万元（含47处功能点虚增问题、系统集成费80.78万元全部不应计取）。

### 2.4 竣工结算造价审核

**审前预判指标**：每平方米造价指标横向对比 → 高于同类项目→重点核查。

**审核要点**：

| 审核项 | 常见问题 | 审查方法 |
|--------|----------|----------|
| **工程量清单** | 漏项（拖拉管/桥面铺装钢筋）、重复编制（沉降缝已含于挡墙却单列）、特征值矛盾（15cm碎石标20cm厚） | 清单逐项比对设计图+计量规则 |
| **竣工图与现场** | 竣工图绘制与现场实际不一致（路口未按图纸施工但竣工图标为已建） | 携带图纸现场逐段核对+拍照取证 |
| **签证工程量** | 虚报量、重复计算（挡墙工程量一半被重复计入） | 重新逐项复核计算式 + 多源数据印证 |
| **变更洽商** | 变更理由不充分、变更金额过大 | 追溯变更审批流程+现场核实必要性 |

## 四、竣工决算审计

### 4.1 总体框架

```
竣工决算审计 = 工程造价审核 + 财务决算审核 + 建设管理合规性审查
```

### 4.2 现场踏勘方法论

| 步骤 | 操作 | 产出 |
|------|------|------|
| **准备** | 熟悉图纸、携带测量工具（卷尺/测距仪/GPS）、提前通知各方到场 | 踏勘清单 |
| **执行** | 逐段核对竣工图与现场、拍照留证（带坐标水印）、现场测量关键尺寸 | 踏勘记录+照片 |
| **记录** | 现场发现的口头承诺/解释→要求书面确认 | 会议纪要/确认函 |
| **复核** | 踏勘后回归工程量计算式逐项复核→多算/漏算/重算逐一标注 | 审核初稿 |

### 4.3 常见竣工决算问题

1. **虚报工程量**：进度计量80%但遥感显示仅小部分区域施工
2. **重复计算**：同一工程量在不同计算式中重复列支
3. **签证不实**：签证据称3000+m³但审计核实仅几百m³
4. **竣工图与实际不符**：竣工图标注的工程内容实际未施工
5. **变更未经审批**：重大变更未履行设计变更程序即先行施工

## 五、违规模式库

### 5.1 招投标违规模式

| 编号 | 违规模式 | 识别特征 | 取证方法 |
|------|----------|----------|----------|
| ZB-01 | **伪造资质材料** | 营业执照/资质证书与工商/住建平台信息不一致 | 工商信息库+全国建筑市场监管平台交叉验证 |
| ZB-02 | **跨年度虚假投标** | 不同年度不同单位服务方案相似度≥90%、错别字位置100%吻合 | 文本相似度比对+错字位置匹配 |
| ZB-03 | **规避招标（化整为零）** | 同一建设单位同一年度内多个同类标段，各标段金额均低于法定标准 | 字符串匹配度函数（>0.8）匹配建设单位名称+标段时间间隔<1年 |
| ZB-04 | **围标串标（特征码一致）** | 不同投标人MAC地址/文件制作机器码/造价锁编码一致 | 电子评标系统特征码提取+四码比对 |
| ZB-05 | **围标串标（无介质协同）** | 经常性固定组合投标（>10次），MAC等硬件不同但项目重合度>0.7 | 杰卡德相似系数+I2集群分析图 |
| ZB-06 | **招标文件"量身定做"** | 资格条件/技术参数设置歧视性条款 | NLP提取关键条款+行业标准比对 |
| ZB-07 | **计价条款规避政策** | 招标文件排除地方财评原则文件适用 | 政策比对+计价差额测算 |
| ZB-08 | **陪标（工商关联）** | 中标方与陪标方存在同一法人/股东/注册地址 | RPA自动查询天眼查/企查查→工商关系穿透 |

### 5.2 工程造价违规模式

| 编号 | 违规模式 | 识别特征 | 取证方法 |
|------|----------|----------|----------|
| ZJ-01 | **虚报土方工程量** | 计量进度与遥感变化检测进度不一致 | 在线GIS工具+时序遥感影像+DEM三维计算 |
| ZJ-02 | **取土位置偷换** | 指定取土场实际开挖量与设计量悬殊（地下水位限制） | 现场踏勘核实深度+面积遥感测绘 |
| ZJ-03 | **弃土量虚报** | 不同项目弃土混堆、无弃土前后测绘数据 | GPS轨迹测量+DEM高程模型 → 三维计算 |
| ZJ-04 | **材料批价虚高** | 批价超过采购价100%以上 | 发票信息抽查+市场询价比对 |
| ZJ-05 | **功能点虚增** | 同一数据表+同一处理逻辑被拆分为多个功能点（功能点独立性违规） | 数据流与业务逻辑穿透分析 |
| ZJ-06 | **费用重复计取** | 同一开发任务在"软件费"和"集成费"中重复列支 | 合同条款范围比对+功能点明细交叉分析 |
| ZJ-07 | **附属数据冒充独立资产** | 将系统初始化数据录入列为"数据建设费" | 来源与用途关联分析：是否采购外部数据/产出独立数据产品 |
| ZJ-08 | **工程量清单错误** | 漏项/重复编制/特征值矛盾/计量单位错误 | 清单逐项比对设计图纸 |
| ZJ-09 | **竣工图造假** | 竣工图标为已建但现场未施工 | 现场逐段踏勘+图纸比对+拍照留证 |
| ZJ-10 | **签证虚报** | 签证工程量远超实际、计算式重复计入 | 重新逐项计算+多源印证 |

### 5.3 违规严重程度速查

| 严重程度 | 典型表现 | 涉及金额参考 | 处理建议 |
|----------|----------|-------------|----------|
| 🔴 严重 | 围标串标、伪造资质、系统性虚报工程量 | 涉案金额大/涉及多方串通 | 移送纪检监察/追究刑责 |
| 🟠 较重 | 规避招标、批价虚高3倍以上、重大虚报 | 涉及金额数十万至百万 | 责令整改+追缴资金+行政处罚 |
| 🟡 一般 | 清单编制错误、竣工图不一致、变更程序不规范 | 涉及金额较小 | 责令改正+扣减工程款 |
| 🔵 管理缺陷 | 无价材料管理制度缺失、询价流程不规范 | 无直接金额损失 | 建议完善制度 |

## 六、审计检查清单

### 6.1 招投标阶段检查清单

- [ ] 项目是否达到法定必须招标规模标准
- [ ] 是否存在化整为零规避招标（同建设单位同年度同类项目拆分为多标段）
- [ ] 招标公告/文件发布是否符合法定时间和媒介要求
- [ ] **招标文件计价原则**：是否与地方财评原则文件/计价指导意见一致
- [ ] **资格条件设置**：是否存在歧视性/排他性条款（NLP筛查）
- [ ] **技术规格**：是否指定特定品牌/型号
- [ ] 投标单位资质真实性：营业执照/建筑资质/安全生产许可证
- [ ] 投标单位财务数据真实性（跨年度比对资产负债表/利润表变化）
- [ ] **陪标识别**：未中标单位之间是否存在关联关系
- [ ] **围标串标**：四码（IP/机器码/标识码/造价锁）是否雷同
- [ ] 评标委员会组成是否合规、专家是否回避
- [ ] 评标分数是否存在异常偏离
- [ ] 中标结果与招标文件规定的评标办法是否一致

### 6.2 工程造价检查清单

- [ ] **工程量计算**：计算式是否准确、是否存在重复/漏项
- [ ] 工程量清单与设计图纸是否一致
- [ ] **土方工程**：挖填方是否平衡、取/弃土场实际量是否与计量一致
- [ ] **现场踏勘**：竣工图与现场实际情况是否相符
- [ ] **变更签证**：变更理由是否充分、审批程序是否完备、签证量是否真实
- [ ] **材料价格**：无价材料定价是否经过规范询价程序、批价是否虚高
- [ ] **定额套用**：套用定额是否合适、换算是否正确
- [ ] **取费标准**：管理费/利润/规费/税金取费是否正确
- [ ] **信息化项目**：功能点识别是否合理、是否存在拆分/重复/虚增
- [ ] **信息化项目**：系统集成费是否真实存在集成场景、是否与软件开发费重复
- [ ] **信息化项目**：数据建设费是否属于独立数据资产而非附属初始化工作
- [ ] **转分包**：各级管理费是否逐级累积虚增建设成本

### 6.3 竣工决算检查清单

- [ ] 竣工决算资料是否完整（竣工图/结算书/合同/变更/签证/验收报告）
- [ ] 竣工图是否经各方确认、是否与实际一致
- [ ] 结算金额是否超合同金额（分析超支原因）
- [ ] **变更结算原则**：是否按合同约定执行、是否结合中标价
- [ ] 工程进度款支付与形象进度是否匹配
- [ ] 质量保证金/履约保证金扣留是否符合合同约定
- [ ] 竣工财务决算报表编制是否规范
- [ ] 待摊投资分摊是否合理
- [ ] 交付使用资产价值是否准确

### 6.4 技术工具清单

| 场景 | 工具 | 用途 |
