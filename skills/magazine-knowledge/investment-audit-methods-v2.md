## 一、可复用审计方法

### 1.1 "穿透式"审计方法
**适用场景：** 政府投资项目价款结算、竣工决算审计

**核心步骤：**
- 从项目立项→概算批复→招标控制价→合同价→进度款→结算价→决算价，纵向穿透全链条数据
- 关键节点对照：概算 vs 合同、合同 vs 结算、设计图纸 vs 竣工图
- 重点关注做地主体项目（非财政资金项目），因审计监督覆盖不足易成盲区

**操作方法：**
```
1. 收集全链条资料：立项批文→可研报告→初设概算→招标文件→投标文件→合同→进度款申请→监理日志→竣工图→结算书→决算报告
2. 纵向比对：概算金额 vs 合同金额 vs 结算金额，差异率>10%为重点
3. 横向比对：同类项目单方造价、主要材料用量
```

### 1.2 现场实证+数据穿透双轨核查
**适用场景：** 工程结算审计、跟踪审计

**核心步骤：**
- 现场踏勘 + 图纸动态比对
- 工程量计算式逐项反查
- 竣工图与现场实际对照核实
- 隐蔽工程工序审计（通过施工日志、监理日志、影像资料交叉验证）

### 1.3 大数据围标串标检测
**适用场景：** 招投标专项审计、工程审计

**核心方法：**
- **特征码检测：** 比对不同投标文件的MAC地址、IP地址、硬盘序列号、CPU序列号
- **文本相似度检测：** 投标文件内容相似度（技术标雷同、错别字相同）
- **关系图谱分析：** 投标人之间股权关联、高管交叉任职
- **报价模式分析：** 多家投标人报价规律性差异（如均按控制价下浮固定比例）

### 1.4 地理信息技术(GIS)+无人机审计
**适用场景：** 征地拆迁审计、工程量核实

**核心方法：**
- 历史影像对比：征地前后不同时期卫星/航拍图叠加对比
- 无人机航测：生成正射影像+三维模型，自动计算土方量
- GIS叠加分析：征地红线 vs 实际拆迁范围 vs 补偿发放清单
- 奥维地图+ArcGIS双平台交叉验证

### 1.5 招标文件管理审计
**适用场景：** 政府投资项目全过程审计

**审查要点：**
- 招标条件设置是否合理（是否存在"萝卜坑"条款）
- 评标办法是否公平（技术分/商务分权重是否倾向特定投标人）
- 招标控制价编制依据是否充分
- 招标文件是否与概算批复一致

## 二、SQL/Python分析模板

### 2.1 围标串标检测SQL（多投标人MAC/IP相同）
```sql
-- 检测不同投标人投标文件制作机器码相同
SELECT 
    a.投标人名称 AS 投标人A,
    b.投标人名称 AS 投标人B,
    a.项目编号,
    a.MAC地址,
    a.IP地址,
    a.投标时间
FROM 投标记录表 a
JOIN 投标记录表 b 
    ON a.项目编号 = b.项目编号 
    AND a.投标人ID < b.投标人ID
WHERE (a.MAC地址 = b.MAC地址 OR a.IP地址 = b.IP地址)
ORDER BY a.项目编号;
```

### 2.2 投标报价规律性差异检测SQL
```sql
-- 检测同一项目多家投标人报价规律性差异
SELECT 
    项目编号,
    COUNT(*) AS 投标人数,
    MAX(投标报价) AS 最高报价,
    MIN(投标报价) AS 最低报价,
    ROUND(AVG(投标报价),2) AS 平均报价,
    ROUND((MAX(投标报价)-MIN(投标报价))/控制价*100,2) AS 价差率
FROM 投标记录表
GROUP BY 项目编号, 控制价
HAVING COUNT(*) >= 3 AND ROUND((MAX(投标报价)-MIN(投标报价))/控制价*100,2) < 2
-- 多家投标人报价极为接近，疑似围标
ORDER BY 价差率 ASC;
```

### 2.3 工程量偏差检测Python脚本
```python
import pandas as pd
import numpy as np

def check_quantity_deviation(contract_qty, settlement_qty, threshold=0.10):
    """
    检测工程量结算偏差
    contract_qty: 合同工程量 Series
    settlement_qty: 结算工程量 Series
    threshold: 偏差阈值（默认10%）
    """
    df = pd.DataFrame({
        '合同工程量': contract_qty,
        '结算工程量': settlement_qty
    })
    df['偏差率'] = (df['结算工程量'] - df['合同工程量']) / df['合同工程量']
    df['偏差金额'] = df['偏差率'] * df['合同工程量']  # 假设单价为1，实际需乘单价
    
    abnormal = df[abs(df['偏差率']) > threshold].copy()
    abnormal['风险等级'] = abnormal['偏差率'].apply(
        lambda x: '高' if abs(x) > 0.30 else ('中' if abs(x) > 0.20 else '低')
    )
    return abnormal.sort_values('偏差率', ascending=False)
```

## 三、违规模式清单

| 序号 | 违规模式 | 预警信号 | 涉及环节 |
|------|----------|----------|----------|
| 1 | **围标串标** | 多家投标人MAC/IP相同、报价规律性接近、投标文件内容雷同 | 招投标 |
| 2 | **虚增工程量** | 竣工图与现场不符、隐蔽工程无影像资料、监理日志与施工日志矛盾 | 工程计量 |
| 3 | **高估冒算** | 结算价远超合同价且无变更签证、材料单价明显高于信息价、定额套用错误 | 价款结算 |
| 4 | **虚假签证** | 签证前后矛盾、签字不全、时间逻辑错误（后补签证）、签证内容与施工日志不符 | 变更管理 |
| 5 | **虚报征拆** | 补偿对象不在红线内、面积远超实测、一户多补、征拆后仍存建筑 | 征地拆迁 |
| 6 | **招标文件设租** | 资质条件明显倾向特定投标人、技术评分项与项目无关、控制价泄露 | 招标管理 |
| 7 | **材料以次充好** | 关键材料缺少检测报告、品牌与合同不符、质保资料不全 | 材料管理 |
| 8 | **超概不报批** | 实际投资超概算10%以上未履行调概程序 | 投资控制 |
| 9 | **财务监理失职** | 监理未发现明显问题、审价报告与审计结果差异巨大 | 第三方管理 |
| 10 | **隐蔽工程造假** | 预压地基工序记录不全、桩基检测报告与施工记录矛盾 | 地基基础 |

## 四、融策业务匹配

### 直接匹配

## 五、快速检查清单

### 工程结算审计5步法
```
□ 第1步：项目合规性 → 立项批文/可研/初设/概算/用地规划/环评是否齐全
□ 第2步：招投标合规性 → 招标方式/文件/评标/中标是否合规，有无围串标迹象
□ 第3步：合同管理 → 合同与招标文件/中标文件是否一致，有无实质性变更
□ 第4步：工程计量 → 竣工图vs现场、签证vs监理日志、结算量vs合同量
□ 第5步：价款结算 → 单价vs信息价/合同价、取费/税金、超概情况
```
