# 图表类型参考

## 1. 流程图 (Flow Chart)

| 特征 | 说明 |
|------|------|
| 适用场景 | 审计程序、审批流程、业务流程 |
| 工具 | Mermaid / draw.io / Python diagrams |
| 推荐尺寸 | 横版16:9 |
| 配色规范 | 开始/结束=绿色圆角矩形；判定=菱形黄色；操作=矩形蓝色；文档=卷角矩形 |

## 2. 风险热力图 (Risk Heatmap)

| 特征 | 说明 |
|------|------|
| 适用场景 | 审计重点、风险评估 |
| 工具 | Python matplotlib / Excel |
| 推荐尺寸 | 竖版或正方形 |
| 配色规范 | 🔴高=#D32F2F 🟡中=#FBC02D 🟢低=#388E3C |
| 数据格式 | 矩阵：行=风险项，列=评估维度 |

## 3. 甘特图/时间线 (Gantt Chart)

| 特征 | 说明 |
|------|------|
| 适用场景 | 项目计划、人员时间安排 |
| 工具 | Mermaid gantt / Excel |
| 推荐尺寸 | 横版宽幅 |

## 4. 柱状图/条形图 (Bar Chart)

| 特征 | 说明 |
|------|------|
| 适用场景 | 金额对比、数量对比、预算vs实际 |
| 工具 | Python matplotlib / Excel |
| 推荐配色 | 主色=#1A237E(深蓝) 辅色=#26A69A(青) |
| 对比色 | 预算=#1565C0 实际=#E65100 |

## 5. 饼图/环形图 (Pie/Donut Chart)

| 适用场景 | 费用构成、人员分布、问题分类占比 |
| 工具 | Python matplotlib / Excel |
| 注意 | 不超过6个切片，否则用条形图替代 |

## 6. 组织结构图 (Org Chart)

| 适用场景 | 组织架构、人员分工、责任体系 |
| 工具 | Mermaid graph / PPT |

## 7. 表格着色 (Colored Table)

| 适用场景 | 合规性问题清单、底稿审查结果 |
| 做法 | 表格+条件着色：🔴=不合规 🟡=部分合规 🟢=合规 |

## 8. 折线图/面积图 (Line Chart)

| 适用场景 | 财务指标趋势、问题数量趋势 |
| 配色 | 主趋势线=深蓝 辅助线=灰色虚线 |
