# 合同合规分析

使用jieba分词+关键词匹配，自动识别合同中的风险条款、缺失条款和异常条款。覆盖招标合同、采购合同、租赁合同等类型。内置50+审计关注关键词库。

## 适用场景

- 分析招投标合同/采购合同的合规性

## 执行步骤

### 步骤 1
上传合同文本（支持docx/txt）或粘贴合同关键条款

### 步骤 2
自动分词并匹配：价格条款、支付条款、违约责任、验收标准、质保条款、保密条款、知识产权、争议解决

### 步骤 3
标记：缺失的关键条款（黄色预警）、风险措辞（红色预警）、金额不一致（红色预警）

### 步骤 4
输出：条款完整性评分 + 风险条款清单 + 建议修改方向


## 输出格式

```
【完整性评分】65/100
【缺失条款】验收标准、质保期限、违约责任上限
【风险条款】
1. 第5.3条：'付款后不退货'—违反公平原则
2. 第8.1条：违约金为合同总额30%—超出法定上限
【建议】补充验收标准条款，调整违约金为合同总额20%以下
```
