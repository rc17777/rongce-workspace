## 知识体系

### L1: 数据查询层

**参考文章**：SQL实战5场景 / SQL常踩5坑 / 数字技能修炼入门篇(一)(二)

**核心能力**：
1. **5类审计高频SQL场景**
   - 关联比对：供应商vs合同、发票vs付款 → JOIN / 子查询
   - 异常值识别：金额异常、阈值卡位 → GROUP BY + HAVING + 窗口函数
   - 时间序列：突击支出、季度末集中付款 → DATE函数 + CASE WHEN
   - 重复检测：重复报销、重复合同 → COUNT + GROUP BY
   - Top-N排名：大额供应商、费用最高月份 → ORDER BY + RANK/DENSE_RANK

2. **SQL避坑指南**
   - 空值处理不当导致遗漏疑点 → 用COALESCE/IS NULL检查
   - JOIN条件不完整导致重复计算 → 用DISTINCT或明确关联键
   - 日期格式不统一 → 统一用DATE_TRUNC标准化

### L2: 数据分析层

**参考文章**：传统审计效率翻10倍 / Python异常交易 / 数字技能修炼进阶篇

**核心能力**：
1. **审计数据分析4步法**：数据获取→清洗→分析→输出
2. **3种异常检测方法**
   - Z-score：正态分布数据的极端值检测
   - IQR四分位距：高度偏斜数据的异常检测
   - Benford法则：数据人为篡改检测（大样本>500条时适用）
3. **效率对比量化**：传统抽样vs全量分析（覆盖率从<1%到100%，效率提升10-100倍）

### L3: 机器学习层

**参考文章**：大数据审计实战3个ML案例 / 数字技能修炼高阶篇

**核心能力**：
1. **聚类分析**（KMeans）：将交易按金额/频率/时间分组，发现孤立模式
2. **异常森林**（Isolation Forest）：高维数据的异常检测
3. **分类模型**（XGBoost/RF）：基于标注数据预测风险等级

### L4: AI赋能层

**参考文章**：大模型赋能国家审计 / RAG实战指南 / Agent开发系列

**核心能力**：
1. **大模型应用**：合同智能审查、报告生成、法规匹配
2. **RAG知识库**：审计法规/合同/案例的语义检索
3. **审计Agent**：多Agent协同完成审计任务
