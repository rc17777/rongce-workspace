# 审计报告多轮打磨模板

## S0-S4 框架阶段（不出正文，先定骨架）

### 框架模板

```
报告标题：[被审计单位] [审计期间] [审计类型] 审计报告

一、基本情况
  - 被审计单位：[名称]
  - 审计期间：[YYYY年MM月-YYYY年MM月]
  - 审计范围：[具体范围]
  - 审计方式：[就地/送达/专项]

二、审计发现概况
  - 共发现问题[X]项
  - 其中重大问题[X]项，一般问题[X]项
  - 问题金额合计：[XX]万元
  - 涉及违规行为：[简述]

三、问题清单（按风险等级排序）
  问题1：[一句话描述]
    性质：[重大/一般]
    金额：[XX万元]
    依据：[具体法规条款]
  
  问题2：...

四、管理建议
  建议1：...
  建议2：...

五、附录
  附件1：问题明细表
  附件2：法规依据汇总
```

### 框架确认清单

在进入S5之前，先确认以下问题：

- [ ] 报告阅读者是谁？（决定详略程度）
- [ ] 核心发现是什么？（决定排序优先级）
- [ ] 问题金额量级是否清晰？
- [ ] 每条问题是否都有法规依据？
- [ ] 建议是否具体可操作？
- [ ] 有没有需要提前沟通的敏感问题？

---

## S5-S6 正文撰写阶段

### 问题描述标准格式

每条问题按以下结构撰写：

```
【问题N】[问题标题]

（一）问题描述
[用"何时何地因何原因发生何事"的句式描述事实，避免主观评价]

（二）审计依据
- 法规依据：[具体条款]
- 制度依据：[相关内部制度]

（三）影响分析
- 直接影响：[金额/损失/风险]
- 间接影响：[内控缺陷/管理漏洞]

（四）整改建议
- 立即整改：[本月内可完成]
- 机制完善：[制度层面解决]
- 责任追究：[是否需要]
```

### 推理链自检

每个问题必须同时满足：
1. **事实链**：有数据/文件支撑（证据编号）
2. **分析链**：从数据到问题的推理过程清晰
3. **定性链**：引用了具体的法规或制度条款
4. **建议链**：整改建议与问题一一对应

---

## S7 定稿阶段检查清单

### 内容检查

- [ ] 每个问题都附有证据编号
- [ ] 法规引用准确（文号、年份、条款）
- [ ] 金额计算有过程（不是拍脑袋数字）
- [ ] 问题排序符合风险优先原则
- [ ] 建议具体（有时间节点、责任主体、操作步骤）

### 格式检查

- [ ] 标题层级一致
- [ ] 表格有表头有单位
- [ ] 附件顺序与正文引用一致
- [ ] 页眉页脚规范
- [ ] 总字数在合理范围（审计报告通常3000-8000字）

### 沟通检查

- [ ] 敏感问题已与被审计单位充分沟通
- [ ] 不同意见已记录在案
- [ ] 最终版本各方签字确认
