# 审计场景多轮设计应用指南

## 合同审计多轮设计示例

### S0 启动

**任务边界确认：**
- 审计范围：2023-2025年所有租金类合同（共XX份）
- 审计重点：签订程序、履行情况、租金收缴
- 交付要求：问题清单 + 整改建议 + 典型案例
- 时间要求：10个工作日

### S1 输入

| 材料类型 | 具体内容 |
|---------|---------|
| 合同文本 | PDF扫描件XX份 + Excel台账1份 |
| 财务数据 | 租金收缴明细、应收账款账龄 |
| 管理制度 | 招商管理办法、合同审批流程 |
| 历史记录 | 上一轮审计问题台账 |

### S2 诊断

**三维诊断矩阵：**

| 维度 | 判断 | 依据 |
|-----|------|-----|
| 问题类型 | 租金收缴 + 履约管理 | 应收款账龄显示逾期严重 |
| 风险等级 | 高（逾期金额>XX万） | 占年度租金收入XX% |
| 目标受众 | 管理层 + 业务部门 | 需要整改落地 |

**核心问题假设：**
- H1：部分租户长期欠租但未启动合同终止程序
- H2：租金减免审批缺乏统一标准
- H3：合同变更未重新履行审批流程

### S3 候选（4个分析方向）

```
方向A：金额异常分析
- 假设：租金水平显著偏离市场或内部定价标准
- 数据：合同租金 vs 市场指导价对比
- 预期发现：疑似低于市价出租的合同清单
- 验证难度：中

方向B：欠租催收分析
- 假设：存在长期欠租但未采取法律措施的情况
- 数据：欠租时长、欠租金额、催收记录
- 预期发现：重点关注超6个月欠租户
- 验证难度：低

方向C：合同变更合规性分析
- 假设：补充协议/变更审批简化或缺失
- 数据：合同变更记录 vs 原审批流程
- 预期发现：越权审批或事后补签问题
- 验证难度：中

方向D：招商流程分析
- 假设：部分合同签订未走公开竞价程序
- 数据：招商方式统计（公开/邀请/单一来源）
- 预期发现：应公开未公开的招商项目
- 验证难度：低
```

### S4 筛选

**筛选标准：**
1. 问题真实性（证据是否充分）
2. 金额重大性（涉及金额量级）
3. 整改可行性（被审计单位能否落实）
4. 类比扩展性（一例能发现多少同类）

**排序：**
1. **方向B（欠租催收）** — 验证难度低、金额重大、整改直接
2. **方向C（变更合规）** — 问题普遍、性质严重
3. **方向A（价格偏离）** — 需补充市场数据
4. **方向D（招商流程）** — 证据收集周期长

### S5-S7 执行路径

选定方向后，按以下路径深入：

```
欠租催收深入分析：
Step 1：按欠租时长分层（<3月/3-6月/6-12月/>12月）
Step 2：筛选>6月欠租户，逐份核对合同条款
Step 3：检查是否有书面催收记录、法律函件
Step 4：核实管理层审批情况（特批缓交？）
Step 5：汇总问题，提出分类整改建议
```

## 经济责任审计多轮设计示例

### 决策合规性审查工作流

```
S0：确认审计范围 — 任期内重大决策（>50万或影响经营）
S1：收集决策文件 — 党委会/办公会纪要、签报、批复
S2：三维诊断
    - 程序合规：是否履行"三重一大"程序
    - 实体合规：决策依据是否充分合理
    - 文档合规：决策过程是否有完整记录
S3：候选问题方向
    - 程序缺失（未上会先执行）
    - 材料不全（仅有结果无过程）
    - 越权决策（超授权范围）
    - 利益冲突（未回避）
S4：按金额+性质双重筛选
S5：逐项核实，形成问题轨迹图
S6：与被审计人充分沟通确认
S7：定稿，问题定性+责任认定
```

## 财务审计多轮设计示例

### 收入完整性多维验证

```
S3 候选方向（按验证路径）：
方向1：银行流水 vs 收入入账（从银行到账逆推）
方向2：销售数据 vs 开票系统（从订单到发票）
方向3：合同金额 vs 确认收入（从合同到确认）
方向4：预算目标 vs 实际完成（趋势合理性）

S4 筛选：方向1+2优先（证据链最直接），方向3补充，方向4验证合理性

S5 细化：
候选维度交叉验证表：
              银行有账   银行无账
开票系统有    正常       疑似截留
开票系统无    疑似体外   正常/漏记
```
