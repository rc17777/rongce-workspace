# 审计空间分析（Spatial Audit Analysis）

## 概述

审计对象的活动都是在特定空间发生的。空间关系是行为主体重要的关系类型。本技能基于开源GIS工具QGIS，提供空间维度的聚类分析和疑点提取方法。来源：「数据化审计」公众号 #79 + #70。

## 适用场景

| 审计类型 | 空间分析场景 |
|---------|------------|
| **专项债审计** | 项目点位空间聚类 → 发现异常聚集或飞地项目 |
| **补贴/扶贫审计** | 受益对象地理分布 → 合理性判断 |
| **资产清查** | 资产分布空间分析 → 发现闲置/异常资产 |
| **工程审计** | 供应商/承包商地址聚类 → 发现围标串标线索 |
| **政策跟踪审计** | 政策覆盖区域分析 → 服务半径可达性验证 |
| **财务审计** | 发票交易对手区域聚集 → 交易背景真实性判断 |
| **银行审计** | 授信客户区域分布 → 隐蔽关联关系发现 |
| **轨迹审计** | GPS/位置轨迹分析 → 行为特征与伴随关系 |

## 标准工作流程（6步）

### 步骤1：地址 → 经纬度
```python
# 使用百度地图API进行地理编码（示例思路）
import requests

def geocode_baidu(address, ak):
    url = "http://api.map.baidu.com/geocoding/v3/"
    params = {"address": address, "ak": ak, "output": "json"}
    resp = requests.get(url, params=params)
    data = resp.json()
    if data["status"] == 0:
        loc = data["result"]["location"]
        return loc["lng"], loc["lat"]
    return None, None
```

使用QGIS插件GeocodeCN可更便捷地批量转换。

### 步骤2：导入数据创建图层
QGIS菜单：**图层 → 添加图层 → 添加文本数据图层**

选择CSV文件（UTF-8编码），字段包含：名称、纬度、经度。

### 步骤3：K-Means聚类分析
工具箱 → **矢量分析 → K-Means聚类**

参数：
- 输入图层：选择导入的点图层
- 聚类个数：根据业务场景确定（通常3-10个）
- 运行后自动生成临时图层"聚类"

### 步骤4：可视化聚类显示
1. 右键"聚类"图层 → 属性
2. 符号化 → 类别选择"分类"
3. 值选择"CLUSTER_ID"
4. 颜色渐变选择"Spectral"
5. 点击"分类" → 应用

不同颜色自动标识不同聚类，一目了然。

### 步骤5：分类数据浏览
- **F6**：打开属性表，查看每个聚类的具体点
- **右键 → 显示要素数目**：查看各分类包含的数量
- 勾选/取消勾选分类可控制显示

### 步骤6：提取疑点清单
工具箱 → **矢量选择 → 按属性提取**

```
输入图层：聚类
选择属性：CLUSTER_ID
操作符：不等于（≠）
值：最大分类的ID
保存到文件：可疑清单.xlsx（Excel格式）
```

## 高级分析技巧

### 孤立点检测
聚类个数设为较大值（如10-15），样本量极少的类即为孤立点 → 异常交易、异常点位。

### 伴随关系分析
将两个主体的轨迹数据分别导入，观察空间上的伴随模式 → 发现围标串标的"共同行动"证据。

### 服务半径验证
以服务网点为中心建立缓冲区，统计覆盖范围内的对象占比 → 评估政策覆盖/服务可达性。

### 距离异常检测
计算每个点到其他点的平均距离，Z分法标记异常→ 发现"舍近求远"的可疑客户。
