# 政府审计问题定性标准库

内置政府审计常见问题分类体系（资金安全/程序合规/信息真实性/资产流失等10+大类），每类含典型表现+法规依据+标准处理建议。可从两新/两重项目经验持续更新。

## 适用场景

- 需要将审计发现归类到标准问题类型、需要参考同类问题的处理口径

## 执行步骤

### 步骤 1
输入审计发现的问题描述（含主体+时间+行为+金额+数据）

### 步骤 2
自动匹配最相似的问题类别（基于已积累的问题库）

### 步骤 3
输出该类别下的：典型法规依据、标准定性表述、建议整改措施、同类问题历史处理口径

### 步骤 4
如问题类别不明确，提示人工判断并记录为新类别


## 输出格式

```
【匹配类别】资金安全—补贴资金多拨/少拨（相似度92%）
【法规依据】《实施细则》第X条第X款
【标准定性】补贴资金发放金额不准确，存在多拨/少拨问题
【建议整改】限期清退多拨资金/补拨差额，完善资金拨付双人复核机制
【同类案例】XX项目2024年类似问题，处理口径：清退+制度完善
```
