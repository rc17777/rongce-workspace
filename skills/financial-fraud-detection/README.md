# Benford定律与财务造假检测

## 原理

Benford定律（本福特定律）指出，自然生成的数据集中，首位数字为1的出现概率约为30%，为2的约17%，依次递减到9的约5%。**人为伪造的数据往往不符合这个分布**。

审计抄作业的公司账目、虚假发票、虚列支出等，金额首位数字往往更均匀分布（即人
为倾向让各个数字出现频率差不多）。

## 用法

```bash
cd scripts/

# 基础用法（自动检测金额列）
python benford_detector.py --input 凭证明细.xlsx --output ./result/

# 指定金额列
python benford_detector.py --input 差旅费明细.xlsx --amount-col 报销金额

# 带数据集名称
python benford_detector.py --input 采购发票.xlsx --name "XX国企2025年采购发票"
```

## 输出

| 文件 | 说明 |
|:----|:-----|
| `Benford分布分析.xlsx` | 9个数字的实际 vs 理论分布 + 偏差 |
| `疑点_圆整交易.xlsx` | 千元倍数的圆整交易（可能人为构造） |
| `分析_金额末位分布.xlsx` | 末位数字分布（过多的0或5为异常） |

## 判断标准

- **p < 0.05**: 统计显著 ≠ Benford分布，**可能存在人为操纵**
- **末位0占比 > 30%**: 人为构造痕迹
- **圆整交易占比 > 15%**: 需进一步核查

## 适用场景

- 国企年度凭证抽查 → 差旅费/办公费/会议费
- 政府采购发票核验 → 大额采购是否存在虚开发票
- 专项资金支付审计 → 是否人为干预付款金额
- 医保基金支付 → 是否存在虚假诊疗/虚假用药
