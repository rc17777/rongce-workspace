# 审计提示词资产管理 (Prompt Librarian)

把散落在聊天记录、个人笔记里的好Prompt，变成可检索、可评分、可迭代的团队公共资产。

## 核心理念

> 文章五大基石之四：激励那些主动探索AI落地场景、沉淀优秀Prompt并将其转化为团队公共资产的员工。

Prompt不是一次性的对话开场白——它是团队的"数字审计经验"，和底稿模板、审计程序一样需要版本管理和持续优化。

## 工作流

### 1. 入库

当发现一个好用的Prompt时：

```
/prompt:add
场景：绩效评价-资金使用合规性检查
Prompt内容：
[粘贴完整Prompt]
效果评价（1-5）：4
备注：准确率很高，但对复杂嵌套判断有时遗漏
```

入库后自动分配ID、记录时间戳、打标签。

### 2. 检索

```
/prompt:search 绩效评价 资金合规
```

或按标签浏览：
```
/prompt:list 标签=绩效评价
/prompt:list 评分>=4
/prompt:list 最近7天
```

### 3. 评分与迭代

每次使用后更新评分：
```
/prompt:rate prompt-042 4.5
备注：这次用了v2.1版本，嵌套判断问题已修复
```

### 4. 导出分享

```
/prompt:export prompt-042  → 生成可分享的Markdown卡片
/prompt:export-all 绩效评价 → 导出该场景下所有Prompt
```

## 数据格式

每条Prompt记录：

```yaml
id: prompt-042
标题: 绩效评价-专项资金使用合规性检查
场景: 绩效评价
具体环节: 专项资金使用合规性检查
标签: [绩效评价, 资金合规, 专项资金, 合规检查]

prompt: |
  你是一位政府审计专家，具有10年以上专项资金审计经验。
  请分析以下资金使用记录，重点关注：
  1. 付款时间是否与合同约定一致
  2. ...

效果评分: 4.5/5
使用次数: 23
版本历史:
  - v1.0: 初始版本，评分3.5
  - v2.0: 增加嵌套判断逻辑，评分4.2
  - v2.1: 修复嵌套判断遗漏，评分4.5
当前版本: v2.1

提交人: 张三
提交日期: 2026-05-26
最后使用: 2026-06-15

模型适配:
  - deepseek-v4-pro: ✅ 效果好
  - deepseek-chat: ⚠️ 有时遗漏细节

使用注意事项: 需配合被审计单位的合同台账和付款凭证一起使用
```

详见 [prompt-format.md](references/prompt-format.md)。

## 检索能力

| 检索方式 | 示例 |
|---------|------|
| 按场景 | `绩效评价` `采购审计` |
| 按标签 | `资金合规` `合同检查` `疑点排查` |
| 按评分 | `>=4` `最新` `最常用` |
| 按提交人 | `张三` |
| 按日期 | `最近7天` `本月` |
| 模糊搜索 | 在Prompt内容中搜索关键词 |

## 与 cot-capture 的协同

| cot-capture | prompt-librarian |
|-------------|-----------------|
| 沉淀专家的**思维过程** | 沉淀高效的**AI交互方式** |
| 产出 CoT 数据集 | 产出 Prompt 资产库 |
| 用于训练/微调 | 用于日常使用/新人上手 |

两者互补：一个优秀的审计Prompt往往源自对专家CoT的深刻理解。
