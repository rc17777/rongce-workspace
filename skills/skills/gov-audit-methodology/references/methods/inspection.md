# 监督检查方法

## 审计问题四步定性法（#57）

### 常见错误：镜像式问题
❌ "XX客户证照过期仍有交易发生" → 这是现象，不是问题
✅ "系统缺乏临期自动提醒功能，导致客户经理在管户超载情况下未能及时发现并处理证照过期"

### 四步法

**1. 跳出拟态环境**
- 不要凭印象判断，先搞清楚实际工作流程
- 防止"刻板印象"错误

**2. 从常识和逻辑出发**
穷举可能原因：
- 不知道（培训不到位/制度宣导不足）
- 没做（履职不到位/诚信问题）
- 还没排到（管户超载/资源配置不足）
- 临期（正常时间间隔内的过期）

**3. 提出正确的问题**
- 培训宣导不到位
- 客户经理履职不到位
- 内控资源承载力不足
- 系统缺乏提醒功能

**4. 数字化思维建议**
- 系统自动监测并推送提醒
- GPS轨迹匹配减少人工录入
- 风险分级差异化推送

## 内控资源承载力评估（#52）

### 判断框架
如果业务规模 > 内控资源承载力 → 必然有环节出现偷工减料

### 评估要点
1. 梳理业务每个环节需要的内控资源（人力/系统/时间）
2. 对比机构实际资源配置
3. 识别承载超限的环节 → 重点监控

## 屡查屡犯的正确处理

同样的现象 ≠ 同样的原因
- 第一年：系统没有提醒功能
- 第二年：系统有提醒但漏报 → 这不是"屡查屡犯"，是新问题

每次都要重新分析场景变化！

## 数字化手段

- **NLP文本分析**：关键词提取、文本相似度计算、企业名称模糊匹配
- **非结构化数据**：互联网舆论/评论关键词挖掘作为绩效评价补充维度
- **机器学习**：模型评估政策措施执行前后指标变化趋势
