# 资产清查方法

## 计算机视觉盘点（#72）

### 方案一：条码识别（有条码资产）
```
手机拍照 → pyzbar识别条码 → 自动录入清单 → 与账面比对
```
适用：电脑、打印机、扫描仪等有条码的固定资产

### 方案二：轮廓检测计数（无条码资产）
```
拍照 → 灰度化 → 二值化 → 边缘检测 → 轮廓检测 → 自动计数
```
适用：办公桌椅、文件柜等同类型物件批量盘点

### 方案三：OCR信息采集
```
拍照 → OpenCV裁剪 → Tesseract/EasyOCR识别 → 自动录入
```
适用：资产标签上的文字信息批量采集

## 孤立点分析（#68）

### K-Means聚类异常检测
```python
from sklearn.cluster import KMeans
kmeans = KMeans(n_clusters=3).fit(资产数据)
# 距离聚类中心最远的点 = 异常资产
```

适用场景：
- 同类型资产价值异常（同型号设备入账价格差异大）
- 资产分布异常（某部门资产量远超同类部门）
- 折旧异常（折旧年限/残值率偏离行业均值）

## 实务操作建议

1. **事前准备**：获取资产台账电子版，按部门/类型分类
2. **现场作业**：手机拍照+条码扫描，实时比对台账
3. **异常汇总**：拍照资产vs账面资产交叉比对
4. **报告输出**：资产实盘清单 + 差异分析 + 盘盈盘亏原因
