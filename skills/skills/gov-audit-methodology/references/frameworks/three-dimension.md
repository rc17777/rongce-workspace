# 政策审计三维视角

> 来源：#54「重大政策措施落实情况跟踪审计」

## 核心框架

韩雪琳, 李雪（2016）提出"形式、事实与价值"三维审计模式。

| 维度 | 审计内容 | 数据来源 | 对应绩效评价 |
|------|---------|---------|-------------|
| **形式** | 政策文件/会议部署/组织领导/制度规划/执行程序/配套政策 | 公文系统/会议纪要 | 决策→合规性 |
| **事实** | 项目进度/资金使用/项目管理 | 财务系统/项目台账 | 过程→产出 |
| **价值** | 经济价值+社会价值/是否达预期目标/群众满意度 | 问卷调查/统计数据/舆情 | 效果→效益 |

## 三维之间的逻辑关系

> "形式上的落实必将促进事实和价值的实现。"
> "形式和事实无论多么完美，如果没有价值实现，一切都是徒劳无功的。"

```
形式(部署)→ 事实(执行)→ 价值(效果)
  ↑_________↓___________↓
    边审计、边整改、边规范、边提高
```

## 各维度操作清单

### 形式维度检查清单

- [ ] 是否出台了贯彻政策的文件/通知？
- [ ] 是否有专项会议部署？会议纪要有无？
- [ ] 是否成立了领导小组/工作专班？
- [ ] 是否制定了实施细则/配套制度？
- [ ] 是否有明确的时间节点和责任分工？

### 事实维度检查清单

- [ ] 项目实际进度 vs 计划进度？
- [ ] 资金拨付率/使用率？
- [ ] 资金使用是否合规（挪用/闲置）？
- [ ] 项目管理是否规范（招投标/合同/验收）？
- [ ] 有无虚报/冒领/重复申报？

### 价值维度检查清单

- [ ] 是否达到政策预期目标？
- [ ] 经济效益：投入产出比/拉动效应？
- [ ] 社会效益：受益人数/覆盖面/满意度？
- [ ] 有无负面外部效应？
- [ ] 是否可持续？

## 使用建议

1. **绩效评价报告按三维组织**：形式→事实→价值，逐层展开
2. **进场前先做形式维度**：快速判断政策落实的重视程度
3. **事实维度是主体**：数据密集，适合数字化分析手段
4. **价值维度最被忽略**：却是区分"走过场"和"真落实"的关键

## 与其他框架配合

- 三维视角 + 四步定性法 = 高质量审计报告
- 形式维度 + 业务穿透三层 = 完整制度流程画像
- 价值维度 + 内控资源承载力 = 可持续性评估
