# 审计问题四步定性法

> 来源：#57「如何提出有价值的审计问题」

## 问题分级

海森堡："提出正确的问题，往往等于解决了问题的大半。"

| 层级 | 内容 | 价值 |
|:--|:-----|:-----|
| **现象/事实** | XX客户证照过期仍有交易 | 无价值，只是"镜像" |
| **直接原因** | 客户经理未回访 | 低价值，指向个人 |
| **管理根因** | 系统缺乏临期提醒+管户超载 | **高价值**，指向系统和机制 |
| **数字化方案** | 自动监测+GPS匹配+差异化推送 | **最高价值**，可落地改进 |

## 四步法详解

### Step 1: 跳出拟态环境
- 先搞清楚实际工作流程、工作要求
- 防止"刻板印象" → 不要觉得"不就是XX没做吗"
- 做法：访谈一线人员、查看系统操作、收集工作日志

### Step 2: 从常识和逻辑出发穷举原因
用排除法穷举所有可能：
1. **不知道**：培训/宣导/制度传达不到位
2. **没做**：履职不到位/诚信问题/故意规避
3. **还没排到**：资源配置不足/管户超载/排期滞后
4. **系统缺陷**：无提醒/无预警/数据孤岛不可见
5. **正常范围**：在合理的时间窗口内，本身不应认定为问题

### Step 3: 提出正确的问题
对照穷举的原因，逐一核实佐证：
- 问制度：文件是否下达？培训是否有记录？
- 问系统：有无提醒功能？有无监控报表？
- 问资源：客户经理管户量？日常工作量？
- 问数据：同类问题的发生率？时间分布？

最后确定的审计问题应当是**管理根因**而非表面现象。

### Step 4: 数字化思维建议
建议要满足三个条件：**可执行 + 有边界 + 效果可评估**

从低到高：
- 低：加强管理、提高意识（空洞）
- 中：增加培训、定期检查（有动作但难评估）
- **高**：系统自动监测推送 / GPS取证 / 风险分级差异化处理

## 屡查屡犯的正确判断

❌ 错误做法：看到同样现象 → 直接结论"屡查屡犯"
✅ 正确做法：

```
第N年发现同样现象
  → 确认场景是否变化（系统改进了吗？流程调整了吗？）
    → 场景未变 → 真屡查屡犯（管理失效）
    → 场景已变 → 新问题（系统改进但漏报 / 新流程的缺陷）
```

> "一眼看到的原因往往不是真正的原因。"
