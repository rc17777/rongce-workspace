# 审计报告配色方案

## 主色板

```
深蓝    #1A237E  — 标题、表头、主图表
中蓝    #1565C0  — 次要元素、数据列
浅蓝    #42A5F5  — 辅助线、背景元素
青色    #26A69A  — 对比数据列
橙色    #E65100  — 对比/强调数据列
红色    #D32F2F  — 高风险、预警
黄色    #FBC02D  — 中风险、关注
绿色    #388E3C  — 低风险、正常
灰色    #757575  — 图注、辅助文字
浅灰    #BDBDBD  — 边框、表格线
浅蓝灰  #E8EAF6  — 表格隔行底色
```

## 图表配色组合

### 柱状图配色（4色以内）
```
#1A237E  #1565C0  #42A5F5  #90CAF9
```

### 对比图配色（2组对比）
```
组1: #1A237E（预算/计划）
组2: #E65100（实际/执行）
```

### 饼图配色（顺时针）
```
#1A237E → #1565C0 → #42A5F5 → #26A69A → #E65100 → #D32F2F
```
