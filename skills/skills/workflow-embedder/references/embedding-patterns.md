# AI嵌入模式参考

## 六种经典嵌入模式

### 模式1：文件到达触发 (File-Arrival Trigger)

**场景**：被审计单位通过系统报送资料。

```
触发：新文件到达监控目录/系统
    ↓
Agent自动执行：
  1. 文件类型识别 + 内容提取（OCR/文本提取）
  2. 关键信息提取（金额/日期/合同号/供应商等）
  3. 与政策库比对 → 高亮疑似违规条款
  4. 与历史数据比对 → 标记异常变化
    ↓
输出：在原文件旁以批注/高亮形式呈现
```

**适用**：政策文件解读、证据材料分析、合同审查
**人工Gate**：不需要（仅标注，不定性）

---

### 模式2：数据刷新触发 (Data-Refresh Trigger)

**场景**：财务系统/业务系统的数据定时同步到审计数据仓库。

```
触发：数据ETL任务完成
    ↓
Agent自动执行：
  1. 数据质量检查（agent-data-standard）
  2. 描述性统计更新（总量/分布/趋势）
  3. 异常检测（基于历史基线的偏离度）
  4. 生成数据简报
    ↓
输出：数据看板更新 + 异常指标推送
```

**适用**：持续审计、定期数据分析、绩效监控
**人工Gate**：不需要（异常标记为"待确认"）

---

### 模式3：上下文感知触发 (Context-Aware Trigger)

**场景**：审计人员在作业系统中查看某条记录时，Agent感知上下文自动提供相关信息。

```
触发：审计人员点开/搜索某条记录（如某笔付款）
    ↓
Agent自动执行：
  1. 识别当前查看的实体（供应商/项目/合同）
  2. 关联查询：同一供应商的其他付款、同类项目的对比数据
  3. 风险评估：该供应商的风险标签、历史问题
  4. 政策匹配：该业务类型涉及的政策要求
    ↓
输出：侧边栏信息卡片
```

**适用**：审计作业过程中的即时信息辅助
**人工Gate**：不需要（补充信息，不做判断）

---

### 模式4：定时巡检触发 (Scheduled Patrol Trigger)

**场景**：按固定周期自动扫描全量数据，发现新异常主动推送。

```
触发：每日/每周定时
    ↓
Agent自动执行：
  1. 全量数据扫描
  2. 多维度异常检测
  3. 与上期对比 → 新增异常列表
  4. 按风险等级排序
    ↓
输出：推送"本周新增异常TOP10"
```

**适用**：持续审计监控、绩效指标跟踪
**人工Gate**：不需要（推送，非强制执行）

---

### 模式5：里程碑触发 (Milestone Trigger)

**场景**：审计项目进入关键节点时自动触发相应AI能力。

```
触发：项目状态变更（如"数据收集完毕"→"进入分析阶段"）
    ↓
Agent自动执行：
  1. 读取项目上下文（CLAUDE.md中的政策库+审计方案）
  2. 生成数据分析方案建议
  3. 预加载相关Skill和数据
    ↓
输出：下一阶段的工作建议 + 数据准备检查清单
```

**适用**：审计阶段切换、关键决策点
**人工Gate**：推荐+确认

---

### 模式6：异常事件触发 (Anomaly-Event Trigger)

**场景**：Agent在后台持续监控，发现高风险异常时主动告警。

```
触发：风险评分超过阈值 或 命中关键规则
    ↓
Agent自动执行：
  1. 异常详情整合
  2. 关联证据链组装
  3. 影响范围评估
  4. 建议行动方案
    ↓
输出：即时告警通知 + 一键跳转到详情页
```

**适用**：高风险异常、疑似舞弊、重大违规
**人工Gate**：告警后需人工确认，但通知本身自动

---

## 嵌入设计决策树

```
能否从上下文中自动判断触发时机？
  ├── 是 → 能否自动获取所需数据？
  │        ├── 是 → AI输出是否需要人工确认？
  │        │        ├── 是 → 🟡 推荐+确认
  │        │        └── 否 → 🟢 全自动
  │        └── 否 → 🔴 仅提示（需人工提供数据）
  └── 否 → 能定时触发吗？
           ├── 是 → 🟡 定时+人工审核结果
           └── 否 → 🔴 仅提示（需人工发起）
```

## 融策现状评估

| 审计项目类型 | 数据可得性 | 流程标准化程度 | 嵌入可行性 |
|-------------|-----------|---------------|-----------|
| 绩效评价 | 🟢 高（财务+业务数据齐全） | 🟢 高（评价指标体系成熟） | ⭐⭐⭐⭐⭐ |
| 资产清查 | 🟡 中（资产台账+盘点表） | 🟢 高（资产清单+核查流程） | ⭐⭐⭐⭐ |
| 专项债申报 | 🟡 中（项目可研+财务测算） | 🟡 中（各地要求不一） | ⭐⭐⭐ |
| 监督检查 | 🟢 高（对接财政系统数据） | 🟡 中（检查范围因项目而异） | ⭐⭐⭐⭐ |
| 工程结算 | 🟡 中（图纸+量单+合同） | 🟢 高（工程量计算+定额套用） | ⭐⭐⭐⭐ |
