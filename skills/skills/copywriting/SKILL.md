# Copywriting Skill

## Core Frameworks

### AIDA（认知→兴趣→欲望→行动）
```
Attention  → 破标题/数据钩子
Interest   → 痛点放大/场景代入
Desire     → 解决方案价值
Action     → 清晰CTA
```

### PAS（问题→放大→方案）
```
Problem    → "你的停车场每月跑单多少？"
Agitate    → "人工核对4小时，还漏30%..."
Solution   → "自动对账系统，3分钟搞定"
```

### FAB（特征→优势→利益）
```
Feature    → "我们支持实时对账"
Advantage  → "比手工快20倍"
Benefit    → "你每月省80小时，还能100%追回"
```

## Templates

### 审计服务介绍文案
```markdown
[标题] 你离一个审计死角，只有一次对账的距离

[正文]
- 痛点: 停车场数据每月跑单10%+，人工根本查不完
- 方案: 批量SQL清洗 + 交叉验证脚本，不遗漏一笔
- 数据: 上个月查出12万异常，追回率提高40%
- 信任: 已服务XX家单位，零差评

[CTA] 免费数据预检 → 15分钟出报告
```

### 提案/汇报开头
```markdown
[钩子] 我们分析了62,035条停车记录，发现16.7%是0费用

[核心] 这意味着（利益点/风险点）

[结构] 本文将分三部分：发现 → 原因 → 建议
```

## Tone Settings

| 场景 | 语气 | 示例 |
|:----|:----|:-----|
| 政府审计报告 | 专业、严谨、数据说话 | "经核查，差异率为16.7%，属异常区间" |
| 客户沟通函 | 礼貌、清晰、有理有据 | "基于上述数据，建议追加以下审计程序" |
| 营销推文 | 简洁、有力、带钩子 | "停车场一年跑单XX万？我们3分钟查清" |
| 内部汇报 | 直接、总结性、行动导向 | "结论：异常率16.7%，建议：3项整改" |
