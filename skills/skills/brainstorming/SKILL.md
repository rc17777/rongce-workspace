# Brainstorming Skill

## Core Principle

Before creating or designing anything, fully explore the problem space. Never jump to the first idea.

## Workflow

### Phase 1: Context Clarification

Ask clarifying questions to establish:
- **目标**: 最终要达成什么？（具体、可衡量）
- **约束**: 时间、预算、资源、技术限制？
- **受众/用户**: 谁会用？谁看结果？
- **已有基础**: 现有系统、数据、人员？
- **痛点**: 当前方案为什么不够好？

Only ask 2-3 questions at a time. Don't overwhelm.

### Phase 2: Divergent Thinking

Generate 3-5 distinct approaches, each from a different angle:

```
方案A — 最直接路径（保守/低成本）
方案B — 最大效果路径（激进/高投入）
方案C — 折中方案（平衡）
方案D — 非常规思路（创新/颠覆式）
```

For each approach, describe:
- **核心逻辑**: 一句话说清楚
- **优点**: 2-3个
- **风险**: 1-2个
- **投入估算**: 时间/人力/资金级别
- **可行性**: 高/中/低

### Phase 3: Convergent Selection

Help the user evaluate trade-offs using:
- **影响-努力矩阵**: 哪个方案投入产出比最高？
- **风险-回报评估**: 哪个方案在可接受风险下有最高回报？
- **快速验证**: 选1-2个方案做最小验证（MVP、原型、数据验证）

### Phase 4: Actionable Output

```markdown
## 选定的方向

**方案B: [名称]**
- 核心目标: ...
- 实施路线: 3个关键里程碑
- 下一步: ...
- 风险预案: ...

## 其他选项（备胎）
- 方案A: 保底，如果B不行立即切换
- 方案C: 长期方向，第二阶段再考虑
```
