# DeepSeek AI画图表 — 6种零代码方法

## 概述

不需要写代码，用大白话告诉DeepSeek你要什么图，它生成代码，你复制到对应工具就能出图。来源：CDA数据分析师公众号。

## 通用四步骤

1. 用大白话说清楚：什么图 + 什么数据
2. DeepSeek生成代码
3. 复制代码到对应的在线工具或浏览器
4. 导出为PNG/SVG/HTML

## 6种方法速查

```
方法           工具              难度    最佳场景
──────────────────────────────────────────────────
Mermaid       mermaid.live       ⭐      流程图、架构图
ECharts       浏览器/HTML        ⭐⭐     专业数据图表
Python        本地环境           ⭐⭐⭐   精准数据分析
Napkin AI     napkin.ai          ⭐      手绘风创意图
AI工作流      Coze/Dify          ⭐⭐⭐⭐  自动化周报
MD+Xmind      Xmind              ⭐      思维导图
```

## 一、Mermaid：流程图和架构图

### 最佳场景
审计流程、系统架构、组织架构、审批流

### 操作步骤
```
1. 告诉DeepSeek：描述流程 → 强调用Mermaid语法 → 代码原样返回
2. 复制生成的代码（以graph、sequenceDiagram、flowchart开头）
3. 打开 mermaid.live → 粘贴到左侧 → 右侧自动渲染
4. 导出PNG/SVG
```

### 提示词模板
```
请用Mermaid语法画一个流程图，描述以下流程：
[流程步骤1] → [流程步骤2] → [流程步骤3] → ...
要求：用不同的节点形状表示不同环节，请直接返回Mermaid代码。
```

### 审计应用
- 审计项目流程图
- 风险控制矩阵的可视化
- 问题整改流程
- 招投标审批流程

## 二、ECharts：专业数据图表

### 最佳场景
绩效指标可视化、财务数据图、审计报告统计图

### 操作步骤
```
1. 上传Excel/CSV数据文件给DeepSeek
2. 描述图表类型和需求
3. DeepSeek返回完整HTML代码
4. 在聊天界面点"运行HTML"预览，或存为.html文件
```

### 提示词模板
```
根据我上传的数据，帮我生成一个交互式[图表类型：柱状图/饼图/折线图/旭日图/热力图]。
要求：
- 标题为"[标题]"
- X轴为[字段]，Y轴为[字段]
- 值标签居中显示
- 使用渐变色/企业配色
```

### 图表类型速查
| 图表类型 | 适用场景 | ECharts系列名 |
|---------|---------|--------------|
| 柱状图 | 各审计对象对比 | bar |
| 饼图 | 问题类型占比 | pie |
| 折线图 | 趋势变化 | line |
| 旭日图 | 层级结构 | sunburst |
| 散点图 | 相关性查看 | scatter |
| 仪表盘 | 完成率 | gauge |

## 三、Python绘图：精准数据分析

### 最佳场景
需要本地环境运行，适合做深度数据分析后再出图

### 操作步骤
```
1. 上传CSV/Excel数据
2. 说明需求："帮我绘制[指标]与[指标]的趋势折线图，用matplotlib/plotly"
3. 复制代码到Jupyter Notebook或PyCharm运行
```

### 常用库提示
- matplotlib：基础统计图
- plotly：交互式图表
- seaborn：统计图表（热力图、箱线图）

## 四、Napkin AI：手绘风创意图表

### 最佳场景
概念说明、培训材料、快速出草图、非精确数据表达

### 操作步骤
```
1. DeepSeek：用大白话描述 → 让它整理成箭头连接的文本
2. 复制生成的文本（带 →、↓、换行和简单符号）
3. 打开 napkin.ai → 粘贴 → 自动生成多种手绘风格
4. 选风格 → 下载PNG/SVG
```

### 特点
- 免费无水印，不用注册
- 不擅长精确数值图表
- 擅长趋势和关系表达
- 文本越结构化出图越准

## 五、AI工作流：自动化出图

### 最佳场景
每周自动拉数据、出图表的场景（需要一定技术基础）

### Coze/Dify工作流搭建
```
开始节点(接收Excel) → 读取Excel插件 → 大模型节点(DeepSeek，整理为JSON)
→ 生成图表插件 → 输出
```

### 审计自动化场景
- 月度审计数据自动化简报
- 财务指标趋势自动监控看板

## 六、Markdown + Xmind：思维导图

### 最佳场景
审计问题分类、项目架构梳理、头脑风暴、读书笔记

### 操作步骤
```
1. DeepSeek：用大纲形式描述内容 → 转为Markdown多级列表
2. 复制Markdown文本（用#和-和缩进表示层级）
3. 打开Xmind → 新建空白导图 → 粘贴/从Markdown导入
4. 自动生成导图 → 导出图片或PDF
```

### 提示词模板
```
帮我整理一份[主题]的大纲，
一级是[A、B、C]，每级下面分2-3个具体项目。
用Markdown格式，用#表示层级。
```

### 注意
- 缩进和列表符号(- 或 *)要清楚
- Xmind版本不支持Markdown导入时，用Markmap（markmap.js.org）在线预览后截图

## 核心提醒

1. **从Mermaid开始**：最简单的入门方式
2. **数据先准备好**：DeepSeek出图质量取决于数据完整度和需求清晰度
3. **不满意就迭代**："把标题改大"、"换成蓝色"、"加上数据标签" → 重新生成
4. **你负责想，AI负责写代码**
