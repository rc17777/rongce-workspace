Abstract：As sentence semantic similarity algorithms based on HowNet ignore the weight that different words have
different contribution to the sentence similarity value, the similarity result is not reasonable based on these algo -
rithms. In order to solve this problem, the paper improves the traditional semantic similarity algorithm by adding a
frequent function of words in corpus as a weight factor into the final sentence semantic similarity algorithm, this
function can decrease the proportion that high frequence words devote to high sentence similarity value and improve
the accuracy. In aspect of algorithm application, it is known that audit methods summarized by auditing administra -
tion are always reduplicated and not clear, in order to reuse these audit methods, this paper builds an audit rule base
according to the audit methods. On this basis, it adopts the improved semantic similarity algorithm to calculate the
similarity value between user input and rules in audit rule base. It will return the corresponding audit methods of the
audit rules whose similarity value satisfy the given threshold, auditors can pick the most appropriate audit method to
audit the programme. The application shows the algorithm improves the audit efficiency.
Key words ：semantic similarity; audit method; audit rule base; rule matching

审计方法[4]是指审计人员为了行使审计职能 、完
成审计任务 、达到审计目标所采取的方式 、手段和技
术的总称 ，而审计署总结的审计方法存在着散 、乱、
重复等现象 ，其原因是因为审计方法并不是一个单
独的人或机构提出的 ，而是由分布在全国各地的审
计人员根据不同的审计对象 ，对个体性经验的总结 ，
缺少向一般性规律的升华[5]。所以，对于相同或相似
的待审计项目 ，如何合理有效地利用已有的审计方
法，进行当前审计项目和已有审计方法的匹配 ，为审
计人员提供一个与待审计项目相关度最大的审计方
法作为参考是本文的研究重点 ，因此本文的主要工
作是将改进的语句语义相似度算法应用在审计规则
匹配过程中 ，以期找到相似度最高的审计方法 。
2改进的语句语义相似度算法
本文中的语义相似度算法主要研究语句之间的
语义相似度计算 ，并对算法进行适当的改进 。该算
法将 HowNet作为语义词典库 ，以HowNet的义原树
状结构为基础 ，研究了义原之间 、概念之间 、词语之
间的相似度计算 。在算法改进时 ，将词语在语料库
中的频率函数作为权重值引入至语句语义相似度计
算公式中 ，词语在语料库中出现的频率越大 ，对语句
之间相似度值的贡献度越小 。

3.2审计规则匹配流程
3.1节介绍了审计规则库的表结构设计以及审计
规则的表示形式 ，本节将把 2.1中改进的语句语义相
似度算法应用到审计规则匹配过程中 ，并将满足阈
值条件的审计方法按照语义相似度值由大到小的顺
序返回，供审计人员参考使用 。
审计规则库建立好之后 ，根据以下步骤进行规
则匹配。
（1）初始化，i=0，methodlist =NULL，threshold =
0.7，len=0。
（2）用户在输入界面上选择审计类别 ，输入关键词 。
（3）根据用户选择的类别 ，在AuditRules 表中查
询出该类别对应的所有审计条件 rules，len=rules.size 。
（4）将关键字组成短句 ，利用语句语义相似度算
法，计算该短句与 （3）中审计条件之间的语义相似度
值，i自加 1。
（5）将（4）中的相似度值与阈值 threshold 比较，
如果大于等于阈值 ，就根据该审计条件的 Audit -
MethodID 字段，查询 AuditMethods 表中 ID=’Audit -
MethodID ’的审计方法 AuditMethodName ，加入到返
回结果 methodlist 中。
（6）如果 i<len，转（4） ，否则转（7） 。
（7）如果 methodlist.size >0，输出 methodlist ，结束；
否则，提示用户重新选择审计类别或更改关键词 ，转（3） 。
3.3审计规则匹配结果分析
本文中采用召回率和精确率对匹配结果进行客
观评价。召回率衡量检索的查全率 ，精确率衡量检
索的查准率 。在此实验中 ，设定相似度阈值为 0.7，将
规则库中 100个审计规则作为测试数据集 ，这些规则
中，有彼此相关的 ，有不相关的 。对于用户输入的一
个关键词短句 ，采用三种相似度计算方法来计算语
句相似度值 ，并返回满足阈值条件的审计方法 ，同时
计算每种方法的召回率和精确率 。在实验中更改用
户输入的关键词短句 ，进行多次实验，对每种方法的多组召回率和精确率值进行算术加权平均 ，得到各
自方法最终的召回率和精确率 ，结果如表 5所示。
方法 1是在计算词语的相似度时 ，仅使用了
HowNet概念描述式中的第一基本义原的方法 。方
法2[8]为刘群的基于知网的相似度计算方法 ，方法 3是
本文中改进的语义相似度计算方法 。
由表 5的第 3行可知，本文中经过改进的方法 3，
其精确率比方法 1和方法 2高。因此，从标准的评价
值来看，本文中改进的语句语义相似度计算方法在
进行审计规则匹配时能够取得更好的效果 ，匹配结
果更合理 ，精确度更高 。
下述柱状图 2中的精确率图显示了在三种不同
相似度算法下进行规则匹配的精确率 ，图中可知 ，本
文中经过改进的方法 3精确率更高 。同时，本文利用
上述三种方法重复执行 100次规则匹配过程 ，并记录
了每种方法所需要的时间 ，时间柱状图的纵轴以秒
为单位，方法 3执行 100次匹配只需 3.252秒，很好地
降低了匹配所需的时间 ，提高了效率 。

匹配中，从匹配的实验结果可知 ，改进的语义相似度

5结论
本文首先研究了改进的语句语义相似度算法 ，
然后介绍了审计方法的规则库建立 ，包括规则库表
结构设计 ，审计规则的表式形式 。在此基础上 ，将改
进的语句语义相似度算法应用到审计规则匹配过程
中，当用户输入的关键词短句与规则库中规则的语
义相似度值满足一定的阈值条件时 ，就将该规则对
应的审计方法作为匹配结果返回 。用户可以参考匹
配出来的审计方法 ，选择其中最合适的一个方法指
导项目审计工作 。实验证明 ，改进后的语义相似度算法在进行规则匹配时 ，能够取得更高的精确率与
时间匹配效率 。
