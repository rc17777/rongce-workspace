数据挖掘算法在行政审计中的应用
摘 要
数据挖掘是指从大量数据中提取隐含、事先未知并且潜在有用知识的技术，是
目前国际上数据库和信息决策领域最前沿的研究方向之一。数据挖掘技术已经被广
泛用于各个领域，这些领域都具有各自的特点。
本文研究了行政审计数据挖掘应用中的数据挖掘算法，提出数据挖掘方法必须
与领域相结合的观点。文中介绍了行政审计数据挖掘中采用的关联规则、异常挖掘
等方法，并提出了解决实际问题的方案。其研究成果已经得到了实现，并在实践中
加以应用。
本文的主要工作如下：
提出了用 CRISP-DM 方法解决实际挖掘问题。定义了一种基于 XML 的数据挖
掘应用建模平台，用于描述挖掘流程的各阶段。
确定了行政审计数据挖掘应用中的用户需求，使用审计数据多维关联规则挖掘
算法（MulitDim-Adm）、审计数据异常挖掘算法（SAOM）两类算法解决了具体的
数据挖掘问题，同时利用实际数据展示了相应的实验结果。
实现了一个数据挖掘系统。该系统按照数据挖掘的一般过程，将数据挖掘任务
划分为数据集成、数据准备、数据探索、挖掘算法和结果展示等模块。该系统的各
模块之间用先进的XML技术进行参数传递，具有高度的可扩展性。
关键词：数据挖掘；多维关联规则；异常挖掘；行政审计；

THE APPLICATION OF DATA MINING ALGORITHM
TO ADMINISTRATIVE AUDIT
ABSTRACT
Data mining extracts implicit， previously unknown and usable knowledge from
large amounts of data. It is one of the frontiers of research in the fields of database and
DSS. The data mining technique has been widely used in various fields recently.
This paper mainly studies the application of data mining algorithm to administrative
audit and puts forward a viewpoint that the data mining method should be combined with
the concrete application field. Besides, the paper introduces the association rule method
and outliers mining and proposes a solution to the practical problem. So far, the results of
the research have been applied in practice.
The work is briefly summarized as follows:
Set forth the CRISP-DM mining methods to solve practical problems. Define a
XML-based data mining application modeling platform to describe the phases of the
process Module.
Determine the user requirement in the administrative audit data miner. Apply Multi-
dimensional association rule audit data mining method （MulitDim-Adm）and outliers
audit data mining method（SAOM） to solve the practical problems and display the
corresponding experimental results with the actual data.
Realize a useful data mining system. According to the general process of the data
miner， the system divides the whole data mining task into five parts， including data
integration， data preparation， data exploration， mining algorithm and result exhibition.
The five parts associates with each other through the parameters with the help of the
advanced XML technique. The system is highly expansible.
KEY WORDS: Data Mining；Multi-dimensional association rule；Outliers
miner；Administrative audit

1 绪论
1.1 课题研究背景
目前，通信、计算机和网络技术的飞速发展和应用，正改变着整个人类的生活
方式，使我们生活在一个网络化的信息时代。大量信息的存在，给人们提供诸多方
便的同时，也带来了一系列问题。如：信息过量，信息的真假难以辨识，难以有效
利用；信息的保存和表现形式不一致，难以统一处理。“丰富的数据（rich data）和
贫乏的知识（knowledge poor）”问题日益突出。据统计20世纪80年代，每20个月
全球信息量就增加一倍。到 90 年代，全球的数据量从 1993 年约两千 TB，迅速增
长到 2000 年约三百万 TB[1]。面对极度膨胀的数据量，人们受到“信息爆炸”，“混
沌数据空间”和“数据过剩”的巨大压力。
随着数据库技术的迅速发展以及数据库管理系统的广泛应用，许多企业和政府
部门积累了海量的、以不同形式存储的数据资源，这些海量数据收集、存放在大型
数据库中。由于缺乏有效的工具，直接理解这些海量的数据已经远远超出了人们的
能力。它们成了难以有效使用的数据档案。但是在激增的数据背后隐藏着许多重要
的信息，决策者需要基于这些数据资源进行更高层次的分析，以便更好地利用这些
数据，为决策提供有效的支持。数据挖掘（Data Mining）技术是目前最有效的数据
分析工具，是从大量的、不完全的、有噪声的、模糊的、随机的实际应用数据中，
提取隐含在其中的、人们事先不知道的、但又是潜在有用的信息和知识的过程[2]。
它把人们对数据的应用从低层次的简单查询，提升到从数据中挖掘知识，辅助人们
进行决策判断。数据挖掘是一个多学科交叉领域，涉及数据库技术、机器学习、统
计学、等诸多领域，并在工业、商务、财经、通信等众多行业得到了广泛的应用。
随着审计领域中数据的积累，数据挖掘技术引入到审计信息分析中。审计信息
数据挖掘的应用实现了由单一的事后审计转变为事后审计与事中审计相结合，并使
得静态审计转变为静态审计与动态审计相结合，还能做到现场审计与远程审计相结
合。对大规模的审计数据采用数据挖掘技术将推动审计方法的改变，实现了对被审
计单位的账目逐笔审计，最终提高审计质量，降低审计风险。因此，基于数据挖掘

1.2 国内外现状分析
1.2.1 数据挖掘研究现状
数据挖掘技术是人们长期对数据库技术进行研究和开发的结果。起初各种商业
数据是存储在计算机数据库中的，然后发展到可对数据库进行查询和访问，进而发
展到对数据库的即时遍历。现在，数据挖掘技术使数据库技术进入了一个更高级的
阶段，它不仅能对过去的数据进行查询和遍历，并且能够找出过去数据之间的潜在
关系，从而促进信息的传递。
数据挖掘的发展已经历了十几年的发展，W. H. Inmon 等人，于1993年提出了
数据仓库(Data Warehouse，DW)的概念，解决数据挖掘的前期数据准备问题[3]；
Friedman 等人在1997年列出了支持数据挖掘的四个主要技术[4]； Jiaweihan等人在
2000年全面介绍了数据挖掘的相关内容等[2]。
从啤酒尿布的故事应用于沃尔玛销售数据分析系统的关联分析，到银行信用度
的分类分析，再到“物以类聚”的聚类分析，到网络入侵检测的异常分析，各个领
域行业都离不开数据挖掘技术。并且这些领域的应用推动了数据挖掘技术的发展。
为适应更大量的、类别更丰富的数据分析需求，数据挖掘算法也在伸缩性、可用性
和结果的可解释性等各方面不断进行改进，力求寻找高效的解决方案。数据挖掘算
法经过多年的发展也已经成为一种成熟、稳定、且易于理解和操作的技术。
在关联分析方面，1993 年 Agarawal 等人首先提出基于 Apriori 性质的 Apriori
关联规则挖掘算法[5][6][7]，认为任何频繁项集的子集一定是频繁的，是一种有候选生
成的频繁项集发现算法；之后，Han 等人提出了一种基于模式增长的无候选生成的
FP-Growth算法，在一定程度改进了Apriori算法的不足；最初这些算法都是基于交
易数据库提出的，随着各个领域数据的积累，数据的特征也变得更加复杂，如丛简
单的布尔属性值，到连续性的量化属性值，从单维的数据分析到多维情况，因此，
对于更加复杂的应用中的数据特点设计合适的关联规则挖掘算法时非常有意义的。
在分类分析方面，引入 ID3、C4.5 等决策树挖掘算法，构造分类器，用于识别未知
类别的对象所属类别，此外，机器学习中的神经网络、遗传算法等也被用于分类分
析。在聚类分析方面，主要是传统的层次聚类和基于划分的聚类，这些聚类方法在
低维空间中取得较好的结果，但是在高维空间中，这些方法难以满足，研究者提出
了子空间聚类算法，但是，高维聚类问题仍是目前研究的热点和难点。此外，在股

市、销售等领域中，关于数据趋势的研究日益增多，因此，演变分析也是重要的数
据挖掘技术之一，并在不断的发展。银行的欺诈行为发现、网络入侵检测需要异常
挖掘，从简单的偏差分析，到局部异常挖掘算法LOF。但异常挖掘还存在许多未解

国内，也已开展大量的数据挖掘研究，并取得了相当的研究成果。郑泽芝、高
峰修正了经典的Apriori 算法，提高了关联规则挖掘的效率；熊肖华讨论了模糊理论
在关联规则挖掘中的应用；刘夫涛等将变量聚类和样本聚类结合起来，使分类性能
有了较大提高[8][9][10]；中国人民大学统计学系数据挖掘中心则集中讨沦决策树技术
的概念和应用；复旦大学数据挖掘讨论组在数据挖掘基本原理和算法改进以及各类
应用的研究中已提出许多新的观点，并成功在生物、智能交通、web 中得到实施和
应用。
在数据挖掘系统的开发方面，目前在世界上比较有影响的通用的数据挖掘工具
主要有：SAS公司的 Enterprise Miner，IBM 公司的Intelligent Miner， Sybase公司
的 Warehouse Studio， Hyperion公司的ESSBASE，还有DBMiner 等[11]，国内复旦
德门开发了国内著名的数据挖掘工具集 DMiner[12]，包括关联规则、时间序列、序
列模式、预测模型等多个方面。

2 数据挖掘技术
数据挖掘是数据库系统和新的数据库应用的一个前沿，是数据库研究、开发和
应用最活跃的分支之一。它不只是对数据进行简单的查询，而是想从大量的数据中
找出更多有用的知识，因此，数据挖掘的过程又称为知识发现的过程。从某种意义
上讲，数据挖掘从大量的数据中自主地寻找有意义的知识，使得计算机具有一定的
“智能”，可以实现许多人力所无法完成的事情，使计算机对人的决策有强大的辅助
的功能，信息资源也得到更大的利用。
2.1 数据挖掘研究内容
数据挖掘的目的是发现知识，知识要通过一定的模式给出。可用于数据挖掘系
统的知识表示模式是丰富的，通过对数据挖掘中知识表示模式及其所采用方法的分
析，可以更清楚地了解数据挖掘系统的特点。虽然关于数据挖掘的理论基础问题仍
然没有到完全成熟的地步，但是分析它的发展可以使我们对数据挖掘的概念更清楚。
坚实的理论是我们研究、开发、评价数据挖掘方法的基石。经过十几年的探索，一
些重要的理论框架己经形成，并且吸引着众多的研究和开发者为此进一步工作，向
着更深入的方向发展。
数据挖掘方法可以是基于数学理论的，也可以是非数学的；可以是演绎的，也
可以是归纳的。从研究的历史看，它们可能是数据库、人工智能、数理统计、计算
机科学以及其它方面的学者和工程技术人员，在数据挖掘的探讨性研究过程中创立
的理论体系。结合最新的研究成果，目前数据挖掘的主要研究内容包括：
1．关联规则挖掘[5] [6] [7]
关联知识(Association)反映一个事件和其它事件之间的依赖或关联。数据库中的
数据关联是现实世界中事物联系的表现。数据库作为一种结构化的数据组织形式，
利用其依附的数据模型可能刻画了数据间的关联(如关系数据库的主键和外键)。但
是，数据之间的关联是复杂的，不仅是上面所说的依附在数据模型中的关联，大部
分是蕴藏的。关联知识挖掘的目的就是找出数据库中隐藏的关联信息。关联可分为
– 6 –

简单关联、时序(Time Series)关联、因果关联、数量关联等。这些关联并不总是事先
知道的，而是通过数据库中数据的关联分析获得的，因而对商业决策具有新价值。
关联规则挖掘是关联知识发现的最常用方法。最为著名的是 Agrawal 等提出的
Apriori 及其改进算法。为了发现出有意义的关联规则，需要给定两个阈值:最小支持
度(Minimum Support)和最小可信度(Minimum Confidence)。挖掘出的关联规则必须
满足用户规定的最小支持度，它表示了一组项目关联在一起需要满足的最低联系程
度。挖掘出的关联规则也必须满足用户规定的最小可信度，它反映了一个关联规则
的最低可靠度。在这个意义上，数据挖掘系统的目的就是从源数据库中挖掘出满足
最小支持度和最小可信度的关联规则。关联规则的研究和应用是数据挖掘中最活跃
和比较深入的分支，许多关联规则挖掘的理论和算法已经被提出。
2．聚类挖掘[14] [15] [16]
聚类是把一组个体按照相似性归成若 l 类别，它的目的是使得属于同一类别的
个体之间的差别尽可能的小，而不同类别上的个体间的差别尽可能的人。数据挖掘
的目标之一是进行聚类分析。通过聚类技术可以对源数据库中的记录划分为一系列
有意义的子集，进而实现对数据的分析。例如，一个商业销售企业，可能关心哪些(同
类)客户对指定的促销策略更感兴趣。聚类和分类技术不同，前者总是在特定的类标
识下寻求新元素属于哪个类，而后者则是通过对数据的分析比较生成新的类标识。
聚类分析生成的类标识(可能以某种容易理解的形式展示给用户)刻画了数据所蕴涵
的类知识。当然，数据挖掘中的分类和聚类技术都是在已有的技术基础上发展起来
的，它们互有交叉和补充。
3．分类挖掘[17] [18] [19] [20]
分类是数据挖掘中的一个重要的目标和任务，目前的研究和在商业上应用最多。
分类的目的是学会一个分类模型(称作分类器)，该模型能把数据库中的数据项映射
到给定类别中。要构造分类器，需要有一个训练样本数据集作为输入。由于数据挖
掘是从源数据集中挖掘知识的过程，这种类知识也必须来自于源数据，应该是对源
数据的过滤、抽取(抽样)、压缩以及概念提取等。从机器学习的观点，分类技术是
一种有指导的学习(Supervised Learning)，即每个训练样本的数据对象已经有类标识，
通过学习可以形成表达数据对象与类标识间对应的知识。从这个意义上说，数据挖
掘的目标就是根据样本数据形成的类知识并对源数据进行分类、进而也可以预测未
来数据的归类。用于分类的类知识可以用分类规则、概念树，也可能以一种学习后
的分类网络等形式表示出来。
– 7 –

4．演变分析[21]
演变分析是指由历史的和当前的数据产生的并能推测未来数据趋势。统计学中
的回归方法等可以通过历史数据直接产生对未来数据预测的连续值。因而这些预测
型知识已经蕴藏在诸如趋势曲线等输出形式中。
5．异常挖掘[22] [23]
异常是源数据中所蕴涵的极端特例或明显区别于其它数据的知识，它揭示了事
物偏离常规的异常规律。数据库中的数据常有一些异常记录，从数据库中检测出这
些数据所蕴涵的特异知识是很有意义。例如，在 Web站点发现那些区别于正常登录
行为的用户特点可以防止非法入侵。异常分析可以和其它数据挖掘技术结合起来，
在挖掘普通知识的同时进一步获得特异知识。例如，分类中的反常实例、不满足普
通规则的特例、观测结果与模型预测值的偏差、数据聚类外的异常值等等。
2.2 数据挖掘过程及标准 CRISP-DM [25]
简单地说，数据挖掘是从大量数据中提取或 “挖掘”知识，也称数据库中的知
识发现(KDD)，是指从大型数据库或数据仓库中提取人们感兴趣的知识，这些知识
是隐含的、事先未知的潜在有用的信息，提取的知识一般可表示为概念(Concepts)，
规则(Rules)、规律(Regularities)、模式(Patterns)等形式从知识发现的角度，可以把数
据挖掘视为数据库中知识发现过程的一个基本步骤。一般知识发现的过程[24]包括以
下几个步骤：
(1)数据清理 消除噪声或不一致数据。
(2)数据集成 多种数据源可以组合在一起。
(3)数据选择 从数据库中检索、分析与任务相关的数据。
(4)数据变换 将数据通过汇总或聚集操作变换成适合挖掘的形式。
(5)数据挖掘 使用智能方法提取数据模式。
(6)模式评估 根据某种模式度量，识别真正感兴趣的模式。
(7)知识发现 使用可视化和知识表示技术，向用户提供挖掘的知识。
尽管大多数人都同意数据挖掘是知识发现过程的一个步骤。然而，在产业界、
媒体和数据库研究界，术语 “数据挖掘”比术语 “数据库中知识发现”更流行。
因此，数据挖掘有一个更为广泛的概念:数据挖掘是从存放在数据库、数据仓库或其
他信息库中的大量数据中挖掘有兴趣知识的过程。
– 8 –

CRISP-DM（CRoss-Industry Standard Process Model for Data Mining）是由NCR、
DaimlerChrysler、SPSS、OHRA……等世界知名公司根据其实务经验与理论基础共
同制定的数据挖掘标准，目的是为数据挖掘应用提供方法性的过程指导。
CRISP-DM 的目的是帮助人们利用数据挖掘技术解决业务中的问题，它定义了
一个数据挖掘过程，以使数据挖掘项目更加快速、高效、可靠和便于管理[26]。
CRISP-DM 分为以下 6 个阶段：业务理解、数据理解、数据预处理、创建模型、模
型评估和模型部署，如下图所示：

就业务的角度而言，数据挖掘是一种新的信息处理技术，其主要特点是对数据

定义 3.1（关联规则）：关联规则是形如 X=>Y 的蕴涵式，其中 X⊂I，Y⊂I，并
且 X∩Y=Φ，（X 称为输入或左部，Y 称为输出或右部）。即当 X 事件发生的时候，
Y事件会伴随发生，称为一种X与Y的关联关系。例如，可以将X事件定义为“管
理不规范金额>100000”，而将 Y 定义为“经济责任有疑点”，那么 X=>Y 不难理解
为当金额>100000 时，该负责人经济责任存在异常。
关联关系是在一定概率约束下才有意义的。一般用支持度和置信度作为关联规
则的兴趣度度量。（除此之外的兴趣度度量还有提升度、期望可信度等等）。
定义 3.2（支持度 Support）：关联规则 X⇒Y 在交易数据集 D 中的支持度是指
交易数据集中包含 X 和 Y 的交易数与所有交易数之比，记为 support(X⇒Y)。它是
对关联规则重要性的衡量。计算方法：
support(X⇒Y) = P(X∪Y)
定义 3.3（置信度Confidence）：关联规则X⇒Y在交易数据集 D中的置信度是
指交易数据集中包含 X 和 Y 的交易数与包含 X 的交易数之比，记为
confidence(X⇒Y)。它是对关联规则准确度的衡量。计算方法：
confidence(X⇒Y) = P(Y∣X)
为了发现符合特定应用和用户感兴趣的关联规则，需要给每个度量指定一个可
以由用户控制的阈值。常用的是最小置信度阈值(min_conf)和最小支持度阈值
(min_supp)。阈值的设置常常根据领域专家的建议和实际情况来综合决定。
定义 3.4（强关联规则）：是指同时满足用户定义的最小支持度阈值和最小置信
度阈值的关联规则。
给定一个交易数据集 D，挖掘关联规则问题就是产生支持度和置信度分别大于
用户给定的最小支持度阈值和最小置信度阈值的强关联规则。

4 基于审计数据的异常挖掘算法
4.1 异常和异常挖掘
异常检测是数据挖掘中一个重要方面，被用来发现小的模式(相对于聚类)，即
数据集中间显著不同于其它数据的对象。Hawkins 中给出了异常的本质性的定义：
异常是在数据集中与众不同的数据，使人怀疑这些数据并非随机偏差，而是产生于
完全不同的机制。对异常的检测可以描述为一个从n个样本中选 k个与其它数据显
著不同、例外或不相一致的样本的过程。定义异常点的问题是异常分析过程的关键
问题，尤其是在高维空间中。异常挖掘算法大体可以分为基于统计的算法、基于深
度的算法、基于距离的算法、基于密度的算法，以及面向高维数据的算法等[27]。
1． 基于统计的方法。从80年代起，异常检测问题就在统计学领域里得到广泛
研究，通常用户用某个统计分布对数据点进行建摸，再以假定的模型，根
据点的分布来确定是否异常。这类算法依赖于数据分布状况、数据分布参
数、异常数据数量、异常数据类型。基于统计的异常检测的优点就是模型
一旦建立经测试正确后它的理论指导意义是非常大的，因为这些建模的先
验知识都是该问题领域专家经过多年研究实践中摸索出来的，其次就是其
算法计算要求低，因为它有一定的数学模型作为挖掘的指导，省略了用大
量的数据训练模型的过程。但这些方法也存在着比较大的缺陷：在许多情
况下，用户并不知道这些的数据分布情况，而且对于更为复杂的情况，现
实数据很难匹配到任何一种理想状态的数学分布。
2． Ruts 和 Rousseeuw 提出了基于深度的算法，根据算法，每一个数据被映射
到一个k维数据空间上的点。并且每个点被赋予一个特定定义的 “深度”，
并根据不同的深度将数据划分成不同层次。
3． 基于距离的方法，它可以排除统计方法的一些局限性。两者最重要的区别
在于这种方法可用于多维样本，而统计分析仅仅用于一维的或个别的几维
样本。这种算法的基本计算复杂性在于估计 n 维数据集中所有样本间的测
量距离.如果样本 S中至少有一部分数量为 P的样本到s 的距离比d大，那

4． 基于偏差的技术。它定义样本集的基本特征，所有背离这些特征的样本都
是异常样本。序列异常技术是一种基于相异度函数的可行方法。对一个有 n

余集的相异度函数。用这种方法找异常点非常复杂，在理论上定义为难非

5． 基于密度的异常监测方法：聚类算法 Clarans、Dbscan、Birch 等都具有一

Breunig 和 Kriegel 作了将基于密度的聚类算法 OPTICS 与异常检测合并到
一起的研究。这些研究奠定了基于密度的异常概念的产生。Breunig~Kriegel
提出局部异常因子的概念，定义了对象的局部异常因子表示其异常程度。
6． 高维数据空间的异常挖掘方法：Aggarwal 和 Yu 提出了一个针对高维数据
集进行降维异常检测的新思路，并利用遗传算法优化性能。

4.3.4 SAOM 算法复杂度
SAOM 算法实现：
第一步采用FindAllOutM 算法[ 32]，时间复杂度为O ( Hd +N) ，其中N 为数据
库记录数，H约等于每个维度的单元数；
第二步知识集挖掘的时间复杂度为O ( dNn)，n 为异常点的数量，n〈〈N ；
第三步的时间复杂度由序列长度决定，由于序列长度〈〈 N，整个模式发现的
时间复杂度为O ( Cd + dN )，在实际应用中具有较好的性能。
4.3.5 实验效果
审计数据是高维的，在全空间高维异常数据中，欧氏距离难以得到两个高维记
录之间的相似性，而导致全空间异常数据的相似性较难发现。因此针对高维数据的
异常监测，本文基于自动子空间聚类算法（CLIQUE）思想设计一种有效的异常挖
掘算法SAOM（Subspace-based Audit Data Outlier Mining）。通过选择特定维度的子
空间来找到相似的异常点集合，进而推出异常模式。该方法为分析审计异常数据提
供了新思路。
为了验证该模型的有效性和可行性，以固定资产投资审计中 2006 年(共 12 ×
105条记录) 的固定资产账户收支数据集为实验样本做实验， 实验平台为IBM 小型
机、AIX 操作系统，内存4G byte。
经预处理的数据记录形式如下：标识子空间I ={审计项目}，观测子空间O = {时
间维度}。状态子空间C={账户的开户银行，本次交易同上次交易间的时间间隔，交
易金额，账户累计金额}。以构成长度为60的观测序列，模式长度阈值为10 ，α=
0. 75，β= 0. 7，δ= 25，r =40，n = 1731。首先，在各个观测窗口的数据上使用加
权欧氏距离算法得到异常点。然后，对每个异常点挖掘出其对应的知识集。最后输
出满足阈值的异常模式。通过该挖掘模型，得到某固定资产投资项目长度为 12 ，
15 ，17 的异常模式。结合数据库分析其知识集，其语义表明某固定资产投资项目
在某段时间内陆续有 70 万左右的大额资金高频流出，将异常模式中记录的账户提
交有关部门进行链接分析，可为固定资产审计提供有用的线索。若令标志子空间I =
(领导行政级别 ) 或I =( 固定资产投资规模)，看是否能发现以领导行政级别或固定
资产投资规模为分析对象的异常模式。
审计人员运用异常点挖掘算法预测可能出现问题的审计数据，采取相应措施，
达到事前监督预警的效果。

国内的数据分析软件集中在对数据进行统计和报表生成方面，不能分析复杂数

5.2.1 XML简介
XML(Extensible Markup Language)又称为可扩展性标记语言，是由 W3C提出的
标准通用标记语言 SGML 的一个子集[33]。XML 是面向内容的，具有更多的结构和
语义，适用于Web上的数据交换。与HTML相比，XML具有很多优点[34]：
1．可与多种数据类型交互，适于作为数据交换的标准。分析数据具有各自不同
的复杂格式，应用程序在收到数据后可能需要在不同数据库间进行传递，由
此利用XML解决了数据的统一接口问题。
2．简单明了，具有良好开放性和平台独立性。SUN正在将基于XML技术的标
准扩展加入下一个版本的Enterprise JavaBeans架构，以响应客户对提高EJB
组件的适用性要求，Java 与XML一起使得跨平台数据交换具有广泛前景。
3．XML 是一个标准语言，被业界广泛支持。在市场上有许多成熟的软件可用
来帮助编写、管理 XML。如微软在.NET 开发平台中提供了 XML DOM 对
象，以便应用程序用XML进行数据和进程交互。其他公司，如SUN、IBM、
Oracle、Novell等公司也正在开发将XML和Java 一起使用的产品和技术。
4．XML能够直接用于Internet。大多数网页浏览器内部都封装了能够解析和存
取XML文件的组件，而且可以直接将XML数据转换成 Web显示内容，如
利用XSL和XSLT技术将XML数据映射成HTML文件。

6 总结和展望
我国经济的迅猛发展给审计工作带来巨大的挑战。在缺乏经验的情况下，审计
人员要从数据库系统的海量数据中找出有用的审计信息变得越来越困难。我们利用
数据挖掘技术在处理数据方面的优势，试图将这种新方法应用于审计实践当中，通
过在海量数据中有效地运用数据挖掘技术查找问题并发现一些超出审计经验的规律
性问题。审计数据的处理与信息提取是数据挖掘与审计业务在海量数据条件下的有
机结合，也是未来计算机审计的主攻方向。多维关联规则发现的数据挖掘技术应用
到具有多属性特征的审计数据分析中，不仅减轻审计人员的负担，而且提高了审计
管理的质量，并具有一定的预测功能。对审计数据的分类、聚类以及演变分析、异
常检测等数据挖掘技术都能为审计工作提供有用信息，提高审计效率。
本文通过使用数据挖掘技术应用于审计分析系统中的方法如下：
1．建立多维数据仓库，确定需要分析挖掘的数据维度。
2．分析数据中的特点，对数据进行清洗，得到有效数据。
3．通过 Apriori 算法，按照审计行业专家提供的支持度阈值和置信度阈值，找
到频繁项集。根据频繁项集，生成最终的审计规则。
4．通过异常挖掘算法，对镇（街道、新区、工业开发区）、委办局、事业单位、
区管企业、政府投融资项目的真实、合法、效益进行全方位的业务信息监控。
5．通过审计应用系统，将最终的结果展现给用户。
通过使用多维关联规则挖掘算法对审计数据进行挖掘，在2006年嘉定审计局重
点审计的五十多个项目、数百亿审计资金中，查出审计疑点三百多个，查实管理不
规范金额一百多万，收缴投资金额三千多万元。审计人员在嘉定区审计系统中运用
这些多维关联规则预测可能出现问题的审计数据，采取相应措施，达到事前监督与
事后审计有机结合的目标。验证了算法的可靠性。
总之，我们将在以后的审计实践中充分利用数据仓库中包含的信息，用数据挖
掘技术解决审计人员原先没有涉及的问题，在对数据集合全面而深刻认识的基础上，
对数据内在和本质的高度抽象与概括，也是对数据从理性认识到感性认识升华的过
程。所以把数据挖掘技术应用于审计数据分析中去很有必要也非常紧迫。可以预见
