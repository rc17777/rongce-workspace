# 政府领导审计汇报风格（袁家军式）

## 核心特征

| 维度 | 特征 | 审计报告应对 |
|------|------|-------------|
| 决策框架 | 系统工程思维×数据驱动 | 每页必须有可量化的成效数据 |
| 注意力 | 前3页必须看到核心成效和亮点 | 第1页用大数字冲击，第2页用对比，第3页用案例 |
| 否决触发 | 只说问题不讲抓手 | 整改建议必须有"具体的、可操作的"工程/项目 |
| 表达偏好 | 先总后分，结论先行 | 每页标题必须是观点，不是"背景"或"问题描述" |
| 数据要求 | 数据必须闭环可追溯 | 每个数字必须标注来源和口径 |
| 风险态度 | 必须讲挑战和应对 | 不能只报喜不报忧，必须有"我们发现了问题，并采取了措施" |

## 审计报告专用的袁家军式检查清单

### 第1页（封面/总览）
- [ ] 是否有核心数字（大违规金额/大问题数/大整改率）
- [ ] 是否说清了审计范围和期间
- [ ] 标题是否是观点型（不是"审计报告"）

### 第2页（数据冲击页）
- [ ] 3个大数字是否覆盖了领导最关心的维度
- [ ] 数字是否有对比（同比/环比/目标vs实际）
- [ ] 是否有"抓手"级别的整改成效展示

### 第3-5页（问题概览）
- [ ] 问题分类是否与领导关注维度一致
- [ ] 是否有证据支撑（案例、数据）
- [ ] 是否提到了制度层面的问题（不只是个人行为）

### 整改建议页
- [ ] 每条建议是否具体到"哪个单位、做什么、什么时候完成"
- [ ] 是否展示了机制创新（不只是个案整改）
- [ ] 是否说明了可复制推广性

## 禁用词（领导最反感的表达）

- ❌ "可能存在" → ✅ "经审计核实，存在"
- ❌ "大概" → ✅ 具体数字
- ❌ "有待进一步核实" → ✅ 已核实的问题 + 待核实的问题（分开说）
- ❌ "建议加强管理" → ✅ "制定《XX制度》，明确……责任"
- ❌ "个别现象" → ✅ 说明覆盖范围和抽样方法
- ❌ "总体可控" → ✅ 具体数字：已整改X%，正在整改X%
