# 审计报告标准页型详解（9种核心页型）

## T01 封面页
**用途**：标题+副标题+汇报人+审计期间

**规范**：
- 标题：观点型，一句话点出核心发现
- 副标题：审计期间 + 审计类型
- 汇报人：单位+姓名+日期
- 背景：深蓝渐变 + 简约图标

**审计报告示例**：
```
标题：2025年度某区财政收支审计发现X个问题，金额XXX万元
副标题：某区审计局 | 审计期间：2025年1月-12月
汇报人：XXX（某区审计局局长）
```

---

## T02 目录页
**用途**：整体结构概览

**结构建议**（政府汇报常用）：
```
一、审计工作开展情况
二、主要发现（按问题类型分3类）
三、问题成因深度分析
四、审计建议
五、下一步计划
```

---

## T06 对比页
**用途**：改革前vs改革后 / 目标vs实际 / 制度vs执行

**规范**：
- 左右分栏，左灰（问题）右蓝（整改/成效）
- 每边3个要点，一一对应
- 底部加数据对比（如整改前后数字）

**审计报告示例**：
```
左侧（问题）：
- 制度执行率：45%（2024年）
- 预算调整率：28%（2024年）

右侧（整改成效）：
- 制度执行率：82%（2025年，+37%）
- 预算调整率：12%（2025年，-16%）
```

---

## T07 证据链页
**用途**：资金流向 / 审批流程 / 操作链条

**规范**：
- 流程图形态，从左到右或从上到下
- 每个节点标注时间、金额、责任主体
- 红色标注违规环节
- 底部标注法规依据

---

## T10 数字突出页
**用途**：1-3个大数字，冲击力强

**规范**：
- 数字用大字体（48-72pt），加粗
- 数字下方小字说明（口径、来源）
- 用颜色区分：橙色（警示）、绿色（整改成效）、红色（严重问题）

**审计报告示例**：
```
三个数据点：
1. 违规金额 856.3万（红色）
   - 口径：重点抽查X个单位，发现Y笔违规
2. 制度执行率 45%（橙色）
   - 来源：抽查X项制度，执行率未达标
3. 问题整改率 68%（绿色，正在整改）
   - 截止时间：2025年12月31日
```

---

## T14 问题清单页
**用途**：并列事项罗列

**规范**：
- 问题分类：财政预算类 / 收支管理类 / 资产管理类 / 其他类
- 每类问题简述（不超过3行）
- 底部汇总：问题总数/金额/覆盖范围

---

## T16 时间轴页
**用途**：审计工作时间线 / 违规行为时间线

**规范**：
- 横向时间轴，节点标注关键事件
- 审计工作时间轴：审前准备→进点→审计→报告→整改
- 违规行为时间轴：问题开始时间→持续期间→审计发现时间→整改时间

---

## T17 整改建议页
**用途**：结论+下一步+责任单位+完成时限

**规范**：
- 每条建议：问题→整改方向→责任单位→完成时限
- 用P0/P1/P2优先级标注
- 底部留"下一步计划"（跟踪整改/专项审计/上报）

**审计报告示例**：
```
P0：关于违规发放津补贴问题
  → 清退违规金额XXX万元
  → 责任单位：某局
  → 完成时限：2026年3月31日前

P1：关于预算编制不精细问题
  → 建立预算编制模板，明确科室内审机制
  → 责任单位：财政局
  → 完成时限：2026年6月30日前
```
