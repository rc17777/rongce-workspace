# 若尔盖校园餐审计 · 试点 README

## 这是什么

融策「审计方法论升级」落地方案的第一步试点项目。以若尔盖校园餐（营养改善计划）专项审计为实验对象，跑通"审前数据三件套 + 四层穿透"的全流程。

## 试点目标

| 目标 | 衡量标准 |
|:--|:--|
| 1. 审前进场时手握疑点清单 | 进场前完成Step 1-8，产出≥10条有置信度的疑点 |
| 2. 穿透升级判断表全员使用 | 每个主要发现都填写了穿透表 |
| 3. 至少1个发现穿透到L3-L4 | 报告中有后果叙事，而非泛泛建议 |
| 4. 试后复盘 | 项目结束后花半天复盘：什么有用、什么没用、缺什么数据 |

## 执行流程（5步）

```
Step 0: 审前准备（今天）
  □ 把这3个文件打印/发给审计组
  □ 从「数据需求清单」中勾选本项目能获取的数据项
  □ 确定数据对接人，发出数据请求

Step 1: 拿到数据→跑分析（进场前1-2天）
  □ 清洗数据（Step 1）
  □ 资金勾稽（Step 2）
  □ 人均餐费分析（Step 3）
  □ 价格对标（Step 4）
  □ 供应商检测（Step 5）
  □ 补助精准性（Step 6）
  □ 生成疑点清单（Step 8）
  → 产出：一张≥10条的疑点清单

Step 2: 进场核实（审计现场）
  □ 拿着疑点清单逐条核实
  □ 对每个重要发现填写「穿透升级判断表」
  □ 确保证据链完整（支撑后续L4叙事）

Step 3: 报告撰写
  □ 使用「后果叙事话术库」改写关键发现
  □ 确保至少1个发现做到L3-L4级表述
  □ 区分：管理建议/制度建议/政策建议

Step 4: 复盘（项目结束后）
  □ 哪些模型有用、哪些没用？
  □ 缺了什么数据导致某些分析跑不了？
  □ 穿透升级判断表是否流畅使用？
  □ 话术库是不是真的好用？
  □ → 反馈给我，我迭代模板
```

## 若尔盖特有注意事项

1. **高原牧区因素**：运输成本高、食材价格天然高于平原，价格对标时需设地区调整系数
2. **寄宿制学校**：若尔盖很多牧区学校是寄宿制，三餐都在学校吃，人均餐费计算逻辑不同
3. **季节性因素**：冬季大雪封路时食材运输困难，采购价格可能季节性暴涨
4. **双语/民族因素**：部分学校可能有藏汉双语供餐、民族饮食习惯（如清真等）
5. **数据获取难度**：牧区学校信息化程度可能较低，消费刷卡系统不一定有
