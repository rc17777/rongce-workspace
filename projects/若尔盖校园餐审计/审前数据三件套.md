## 套件2：审前分析操作指引

> 拿到数据后，按以下顺序执行。标注"必做"的进场前必须完成。

### Step 1: 数据清洗（必做）⏱ 20分钟

```
检查清单：
□ 日期格式是否统一（YYYY-MM-DD）
□ 金额列是否全是数字（无文本/特殊字符）
□ 供应商名称是否用全称（无简称/别名混用）
□ 食材品名是否统一（同一食材不能有多个名称）
□ 学校名称是否统一（与花名册一致）
□ 缺失值检查：关键字段（金额/日期/供应商）不能为空
```

### Step 2: 资金总量勾稽（必做）⏱ 10分钟

```
核对逻辑：
  上级拨付总额 = Σ各学校收到金额 + 教育局留存（如有）
  各学校收到金额 vs 各学校食堂支出金额
  差异率 > 5% → 标记为重点关注

检查要点：
  - 是否存在拨付后长期未使用的沉淀资金
  - 是否存在支出>拨付（学校垫付或挪用其他资金）
  - 拨付时间与开学时间是否匹配
```

### Step 3: 人均餐费合理性分析（必做）⏱ 10分钟

```
计算逻辑：
  人均日餐费 = 当月食堂食材支出总额 / (就餐人数 × 就餐天数)
  
异常判定：
  - 人均日餐费 < 补助标准的80% → 可能存在截留
  - 人均日餐费 > 补助标准的120% → 可能存在虚列支出或超标
  - 各学校之间人均餐费差异 > 50% → 需核实是否合理

※ 注意：若尔盖是高海拔牧区，部分学校海拔高/运输远，
   生均餐费可能天然高于平原地区，需考虑地区调整系数
```

### Step 4: 食材采购价格对标（必做）⏱ 20分钟

```
方法（参考莆田审计局+中学食堂净菜案例）：
1. 选取采购频率最高的6-10种食材（米/面/油/肉/蛋/蔬菜）
2. 统计每种食材的各供应商加权平均供货价
3. 与以下价格做对比：
   a. 若尔盖县发改局民生商品价格监测数据（如有）
   b. 阿坝州同期同类食材市场均价
   c. 省内其他同类地区营养餐食材采购价
4. 价格偏离 > 20% → 标记疑点

常见问题模式：
  - 某供应商所有品类价格系统性地高于其他供应商 → 关联交易嫌疑
  - 某品类价格突然在某月开始大幅上涨 → 可能虚列或利益输送
  - 净菜价格高于毛菜但未提供加工成本测算依据 → 参照中学食堂案例
```

### Step 5: 供应商异常检测（必做）⏱ 15分钟

```
检测维度：
□ 同一学校长期只从1-2家供应商采购 → 竞争不充分
□ 供应商注册地址相近/相同 → 可能关联
□ 供应商名称相似（同一老板多家公司） → 围标/陪标嫌疑
□ 供应商成立时间晚于首次供货时间 → 先供货后注册
□ 供应商经营范围与所供食材不匹配 → 壳公司嫌疑
□ 多家供应商联系电话/邮箱/法人相同 → 关联交易
□ 供应商注册地在若尔盖以外但无合理的物流解释 → 异常

※ 若尔盖特殊考虑：高原牧区本地供应商可能较少，
   外地供应商有合理物流成本的需单独评估
```

### Step 6: 营养餐补助精准性分析（建议做）⏱ 15分钟

```
方法（参照莆田审计局SQL案例）：
1. 将营养餐补助名单 vs 在校学生花名册 做全量比对
2. 统计：
   - 应补未补：在校但不在补助名单中的学生
   - 不应补已补：已转学/毕业但仍在补助名单中的学生
3. 如有食堂消费数据：
   - 按学生汇总餐均消费
   - 筛选餐均消费远低于平均水平的学生 → 可能存在困难学生未识别
   - 交叉比对建档立卡贫困户/低保户名单
```

### Step 7: 采购程序合规检查（选做）⏱ 15分钟

```
检查点：
□ 单次采购金额 > 招标限额的是否履行招标程序
□ 是否存在拆分采购规避招标的行为
  例：同一供应商同一时期有多笔小额合同，合计数超限额
□ 评标记录是否完整（评委签字、评分表）
□ 中标供应商与评标专家是否存在关联
```

### Step 8: 生成疑点清单（必做）⏱ 10分钟

```
将Step 2-7产出的所有疑点汇总到「疑点清单模板」
按「高/中/低」置信度分级，标注建议核实方法
```
