# 校园餐审计数据比对工具 — 使用说明

## 工具定位

进点拿到数据后，一键计算三大核心指标 + 筛查疑点，输出带颜色标注的 Excel 分析报告。

## 三步走

### 第一步：生成数据模板
```bash
cd scripts
python -X utf8 校园餐数据比对.py --init
```
在 `raw_data/` 生成 3 张空模板：
- `01_申报数据.xlsx` — 上报人数天数 vs 实际人数天数
- `02_支出数据.xlsx` — 营养餐支出 + 需扣除的非营养餐支出
- `03_采购价格.xlsx` — 采购价 vs 市场价

### 第二步：填数据
把从教育局/财政局/学校调取的真实数据填进模板（删掉"示例"行）。

**关键字段说明**：
- 申报数据：**在校天数**注意是否沿用190天固定值（脚本会自动预警）
- 支出数据：**食堂人员工资/水电/配送**等要单独列出（净餐标计算要扣除）
- 采购价格：**同期市场价**尽量取3家以上均价或发改委监控价

### 第三步：跑分析
```bash
# 全部分析 + 出报告
python -X utf8 校园餐数据比对.py --run

# 或单项
python -X utf8 校园餐数据比对.py --meal-standard   # 只算餐标
python -X utf8 校园餐数据比对.py --false-report     # 只筛虚报
python -X utf8 校园餐数据比对.py --price-check       # 只比价格
```

## 输出

- **控制台**：疑点汇总（红色🔴标注问题项）
- **Excel**：`analysis/校园餐审计分析_时间戳.xlsx`，三个Sheet分色标注
  - 🔴 红：疑点/未达标/价格虚高(>30%)
  - 🟡 黄：偏高(>10%)/190天预警
  - 🟢 绿：正常/达标

## 三大核心指标公式

| 指标 | 公式 | 判定 |
|------|------|------|
| 净餐标 | (营养餐支出 − 非营养餐扣除) ÷ 人数 ÷ 天数 | < 5元未达标 |
| 虚报套取 | 上报人数×天数×标准 − 实际人数×天数×标准 | >0 疑点 |
| 价格溢价率 | (采购价 − 市场价) ÷ 市场价 × 100% | >30%虚高 |

## ⚠️ 复核铁律

脚本输出是**辅助计算**，不是最终结论。出报告前必须：
1. 逐条核对原始凭证
2. 在审计底稿注明数据来源 + 计算方法
3. 交叉验证（系统数据 vs 学籍 vs 财务账）
