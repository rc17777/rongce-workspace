# 若尔盖县校园餐审计 — 深度解读与进点手册

> **项目**: 若尔盖县校园餐突出问题专项审计调查  
> **进点时间**: 2026年7月15日  
> **编制时间**: 2026年7月14日  
> **依据**: 中央纪委国家监委第八督导组要求 + 省纪委监委部署

---

## 一、项目定位：这不是普通审计

### 1.1 政治背景

"校园餐"专项整治是**中央纪委国家监委直督**事项，省厅明确要求：

- **12月中旬前取得明显整改成效**
- **市州、县市区审计机关再向纪检监察机关移送一批问题线索**
- **驻审计厅纪检监察组12月初专项检查**，对"零移送"市县重点督导

**关键信号**：这不是走过场，是要**见人见事见线索**的硬仗。

### 1.2 审计范围（根据下发文件）

| 维度 | 范围 |
|------|------|
| **时间** | 2022年秋季学期以来（重点2024年） |
| **对象** | 全县中小学、幼儿园食堂 |
| **模式** | 食堂供餐 + 校外供餐（配餐）全覆盖 |
| **重点** | 资金管理 + 食品安全 + 招标采购 + 责任落实 |

### 1.3 若尔盖特殊性

- **民族地区**：藏族聚居区，饮食结构特殊（糌粑、酥油茶等）
- **高海拔偏远**：物流成本高，食材配送难度大
- **营养改善计划重点县**：中央膳食补助资金5元/生/天
- **供餐模式复杂**：部分学校食堂自办，部分依赖校外配餐

## 二、核心政策框架（审计依据）

### 2.1 国家级政策

| 文件 | 核心要求 |
|------|----------|
| **国办发〔2011〕54号** | 营养改善计划启动，中央补助3元→5元/生/天 |
| **教财〔2022〕2号** | 资金管理办法：专账核算、专款专用、据实结算 |
| **教育部等三部门通知** | 食堂不得对外承包、不得营利、食品安全校长负责制 |

### 2.2 四川省级政策

| 文件 | 核心要求 |
|------|----------|
| **川教〔2024〕106号**（八部门方案） | 15条长效机制：资金四级审核、资金清算、专账核算、审计监督、统一采购、同餐制、满意度测评 |
| **校园餐工作动态（第二期）** | 12月中旬前整改见效、移送线索、配合纪检检查 |

### 2.3 审计署业务指引（署发简报核心要点）

#### 简报01：营养改善计划审计共性问题答复（一）

**核心口径**：
- 膳食补助资金**不得**用于补贴学校公用经费、支付食堂聘用人员工资
- 食堂结余**不得超过**年度收入的2%，超出部分应退还学生
- 教师用餐应**据实收取**餐费，不得挤占学生膳食补助

#### 简报02：非食堂供餐审计重点

**校外配餐重点关注**：
- 配餐企业准入程序是否合规
- 配送价格是否虚高（对比当地市场价）
- 是否存在"转包分包"
- 食品质量与合同约定是否一致

#### 简报03：营养改善计划审计重点问题指引

**四大审计重点**：
1. **资金管理**：虚报冒领、截留挪用、挤占贪污
2. **采购管理**：规避招标、虚假验收、价格虚高
3. **供餐管理**：克扣分量、降低标准、以次充好
4. **责任落实**：校长负责制虚化、监管缺位

#### 简报04：营养改善计划审计共性问题答复（二）

**高频问题清单**：
- 虚报就餐人数套取资金
- 食堂结余长期挂账未清退
- 食材采购未执行集中招标
- 验收流于形式、出入库台账造假
- 食堂从业人员工资从膳食补助列支
- 教师与学生同餐未付费

## 三、审计重点与检查方法

### 3.1 资金管理（核心中的核心）

#### 3.1.1 虚报冒领

| 检查方法 | 具体操作 |
|----------|----------|
| **数据比对** | 营养改善计划系统人数 vs 学籍系统人数 vs 实际就餐人数 |
| **现场核实** | 随机抽查3-5所学校，当日清点就餐人数 |
| **资金测算** | 补助资金总量 ÷ 补助标准 ÷ 天数 = 应有受益人数，与实际对比 |
| **异常筛查** | 寒暑假、节假日仍有资金支出的学校 |

**若尔盖关注点**：
- 寄宿制学校周末留校学生人数是否单独核算
- 偏远教学点是否存在"纸面就餐"

#### 3.1.2 截留挪用

| 检查方法 | 具体操作 |
|----------|----------|
| **账户追踪** | 膳食补助资金专户流水，追踪最终去向 |
| **科目审查** | 学校财务账中"其他应付款""暂存款"长期挂账 |
| **用途核查** | 食堂支出是否用于非营养改善计划支出（如招待费、福利） |
| **结余分析** | 年度结余超过2%收入的，要求说明原因 |

**若尔盖关注点**：
- 县级教育部门是否存在统筹调剂资金
- 学校食堂是否替其他支出"买单"

#### 3.1.3 贪污侵占

| 检查方法 | 具体操作 |
|----------|----------|
| **现金核查** | 食堂现金收支是否日清月结、账实相符 |
| **个人关联** | 食堂采购员、验收员与供应商是否存在亲属关系 |
| **价格比对** | 同批次食材采购价 vs 当地市场价（至少3家对比） |
| **举报线索** | 向纪检监察部门调取相关举报信 |

### 3.2 采购管理（利益输送高发区）

#### 3.2.1 规避招标

| 检查方法 | 具体操作 |
|----------|----------|
| **合同审查** | 食材供应商是否经过公开招标/竞争性磋商 |
| **拆分核查** | 是否存在将大额合同拆分为多个小额合同规避招标 |
| **单一来源** | 单一来源采购理由是否充分、程序是否合规 |
| **关联关系** | 中标供应商与教育系统人员是否存在关联 |

**若尔盖关注点**：
- 大宗食材（米面油肉蛋奶）是否统一招标
- 本地供应商是否存在"关系户"问题

#### 3.2.2 虚假验收

| 检查方法 | 具体操作 |
|----------|----------|
| **台账核对** | 入库台账 vs 采购合同 vs 发票数量是否一致 |
| **现场盘点** | 突击检查食堂库存，与台账对比 |
| **质量抽查** | 食材保质期、感官检查、索证索票 |
| **视频监控** | 调取验收环节监控（如有） |

**若尔盖关注点**：
- 偏远学校配送频次低，是否存在"一次配送、多次入账"
- 牦牛肉等本地特色食材的质量标准是否明确

### 3.3 供餐管理（学生获得感）

#### 3.3.1 克扣分量

| 检查方法 | 具体操作 |
|----------|----------|
| **食谱核查** | 实际供餐 vs 公示食谱是否一致 |
| **学生访谈** | 随机访谈学生"吃饱了吗""每天都有肉吗" |
| **留样检查** | 48小时留样是否规范、留样量是否足够 |
| **满意度调查** | 无记名问卷调查学生满意度 |

#### 3.3.2 降低标准

| 检查方法 | 具体操作 |
|----------|----------|
| **成本核算** | 每餐实际成本 vs 补助标准（5元/天） |
| **菜品检查** | 是否用廉价食材替代（如用鸡肉替代牛肉） |
| **营养评估** | 是否达到营养配餐要求 |

**若尔盖关注点**：
- 高寒地区学生热量需求更高，供餐标准是否足够
- 是否考虑藏族饮食习惯（如提供酥油茶、糌粑）

### 3.4 责任落实（追责依据）

#### 3.4.1 校长负责制

| 检查方法 | 具体操作 |
|----------|----------|
| **制度检查** | 是否建立食品安全校长负责制、陪餐制度 |
| **陪餐记录** | 校长陪餐记录是否真实、是否付费 |
| **责任追究** | 发生食品安全问题是否追责 |

#### 3.4.2 部门监管

| 检查方法 | 具体操作 |
|----------|----------|
| **检查记录** | 教育局、市场监管局日常检查记录 |
| **问题整改** | 历次检查发现问题是否整改到位 |
| **信息共享** | 部门之间是否建立信息共享机制 |

## 四、若尔盖特色风险点

### 4.1 地理环境带来的特殊风险

| 风险点 | 具体表现 |
|--------|----------|
| **物流成本高** | 食材配送费用虚高、配送企业垄断定价 |
| **配送频次低** | 偏远学校一周配送1-2次，食材新鲜度难保证 |
| **本地采购难** | 本地种养殖规模小，大宗食材依赖外购 |
| **监管成本高** | 学校分散，监管部门检查覆盖难 |

### 4.2 民族文化带来的特殊考量

| 考量点 | 建议 |
|--------|------|
| **饮食习惯** | 尊重藏族饮食传统，审计标准不宜一刀切 |
| **语言沟通** | 访谈学生需配备翻译（如需要） |
| **宗教因素** | 注意清真食品等特殊需求 |

### 4.3 资金规模测算（供参考）

假设若尔盖县约有：
- 中小学+幼儿园：约30-40所
- 受益学生：约8000-12000人
- 年度膳食补助：10000人 × 5元 × 200天 = **1000万元/年**
- 三年资金量：**3000万元+**

**审计重要性水平**：按1%计，30万元以上问题应重点关注

## 七、审计方法与技巧

### 7.1 数据分析"四步法"

```
第一步：数据采集
  ↓ 营养改善计划系统 + 学籍系统 + 财务系统 + 采购系统
第二步：数据清洗
  ↓ 统一口径、剔除异常、补全缺失
第三步：关联比对
  ↓ 人数比对 + 资金比对 + 价格比对 + 时间比对
第四步：疑点生成
  ↓ 异常学校清单 + 异常供应商清单 + 异常交易清单
```

### 7.2 现场核查"望闻问切"

| 方法 | 操作要点 |
|------|----------|
| **望** | 看食堂卫生、看库存条件、看学生餐盘 |
| **闻** | 闻厨房气味、听学生反馈、听教师评价 |
| **问** | 问食堂工人、问采购员、问校长、问家长 |
| **切** | 查账本、查台账、查合同、查发票 |

### 7.3 突破技巧

**技巧1：从边缘突破**
- 先查食堂从业人员工资发放（易突破）
- 再查供应商关联关系（顺藤摸瓜）
- 最后查资金流向（锁定证据）

**技巧2：从举报入手**
- 向纪检监察部门调取举报信
- 从举报线索切入，精准打击

**技巧3：从数据异常入手**
- 人数异常的学校重点查
- 价格异常的交易重点查
- 时间异常（寒暑假支出）重点查

## 八、报告撰写要点

### 8.1 报告结构

```
一、基本情况
   （一）政策背景
   （二）实施现状（学校数、学生数、资金规模、供餐模式）
   （三）取得的成效

二、审计发现的主要问题
   （一）资金管理方面
       1. 虚报冒领膳食补助资金
       2. 截留挪用膳食补助资金
       3. 食堂结余长期未清退
   （二）采购管理方面
       1. 规避招标确定供应商
       2. 虚假验收、以次充好
       3. 采购价格虚高
   （三）供餐管理方面
       1. 克扣学生分量、降低供餐标准
       2. 食品安全管理不到位
       3. 校长负责制落实不力
   （四）部门监管方面
       1. 教育局监管缺位
       2. 市场监管局检查流于形式
       3. 部门协同机制不健全

三、问题产生的原因分析

四、审计建议

五、移送处理事项
```

### 8.2 问题表述规范

**错误示例**：
> "某学校食堂管理不规范，存在资金问题。"

**正确示例**：
> "2023年，若尔盖县XX小学通过虚报就餐人数的方式，套取营养改善计划膳食补助资金12.6万元，用于支付食堂从业人员工资。该校校长张某某对此负有直接责任。"

**要素齐全**：
- 时间（2023年）
- 主体（XX小学）
- 行为（虚报就餐人数）
- 金额（12.6万元）
- 用途（支付食堂从业人员工资）
- 责任人（校长张某某）

| 数据造假 | 多系统比对 + 现场核实 |
| 串供 | 分别谈话 + 隔离询问 |
| 威胁恐吓 | 两人以上同行 + 及时报告 |
| 安全隐患 | 注意交通安全 + 高原反应预防 |

### 9.2 廉政风险

- **严禁**接受被审计单位宴请、礼品
- **严禁**泄露审计秘密
- **严禁**私下接触被审计对象
- 严格执行审计"四严禁"工作要求和"八不准"工作纪律

## 结语

若尔盖校园餐审计是一项**政治性、政策性、专业性**都很强的任务。

**核心目标**：
1. 守住资金安全底线（不让学生的"口粮钱"被贪占）
2. 守住食品安全底线（不让问题食品上桌）
3. 移送一批问题线索（给纪检监察机关提供"炮弹"）

**工作原则**：
- 查深查透、见人见事
- 依法依规、程序规范
- 边审边改、立行立改
- 协同配合、形成合力
