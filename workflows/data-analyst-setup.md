### 场景2️⃣：财政评审 — 预算编制数据对比

**痛点**：多个项目预算数据需要逐一对比，手工操作容易出错

**工作流**：
```
读取送审预算.xlsx + 财政评审标准.xlsx
    │
    ▼
数据清洗 → 统一编码、去重
    │
    ▼
对比分析：
  - 单价偏离度检测（Z-score）
  - 工程量差异对比
  - 定额套用合理性检查
    │
    ▼
生成《财政评审对比分析表》
    │
    ▼
异常项标注 → 推送企业微信
```

**实施步骤**：
1. 把送审预算和评审标准放在 `data/财政评审/`
2. 对我说：`对比 data/财政评审/送审预算.xlsx 和 评审标准.xlsx，按Z-score标注偏离超过2σ的项目，生成对比报告`

**Python脚本示例**（单价偏离检测）：
```python
import pandas as pd
import numpy as np
from scipy import stats

# 读取数据
budget = pd.read_excel('data/财政评审/送审预算.xlsx')
standard = pd.read_excel('data/财政评审/评审标准.xlsx')

# 合并对比
merged = budget.merge(standard, on='项目编码', suffixes=('_送审', '_标准'))
merged['单价偏离率'] = (merged['单价_送审'] - merged['单价_标准']) / merged['单价_标准'] * 100

# Z-score异常检测
merged['Z值'] = np.abs(stats.zscore(merged['单价偏离率'].fillna(0)))
abnormal = merged[merged['Z值'] > 2].sort_values('Z值', ascending=False)

print(f"异常项目数：{len(abnormal)}/{len(merged)}")
print(abnormal[['项目名称', '单价_送审', '单价_标准', '单价偏离率', 'Z值']])
```

### 场景4️⃣：工程结算审计 — 异常交易自动检测

**痛点**：结算数据量大，人工逐一核验效率低，容易遗漏

**工作流**：
```
读取结算明细.xlsx
    │
    ▼
多维度分析：
  ├─ Benford定律 → 数字分布是否正常
  ├─ 单价偏离度 → Z-score > 2 标注
  ├─ 工程量异常 → IQR检测
  ├─ 时间序列 → 结算金额月度趋势
  └─ 供应商聚类 → 高风险分群
    │
    ▼
生成《工程结算审计疑点清单》
    │
    ▼
可视化图表 + 推送企业微信
```

**实施步骤**：
1. 对我说：`用Benford定律检测 data/结算/2025工程结算.xlsx 的金额列，同时用IQR法检测工程量异常，生成疑点清单`

**关键分析命令**：
```bash
# 描述性统计
node scripts/index.js 01 --input data/结算/2025工程结算.xlsx --column 结算金额

# 异常检测（Z-score）
node scripts/index.js 05 --input data/结算/2025工程结算.xlsx --column 结算金额 --method zscore

# 供应商聚类
node scripts/index.js 04 --input data/结算/供应商表.xlsx --clusters 4
```

## 三、数据分析师人设（SOUL.md）

如果你希望有一个"专属数据分析师"子代理，可以创建：

```markdown
# SOUL.md — 融策数据分析师

## 身份
你叫「数据小融」，是融策会计师事务所的专属数据分析师。

## 职责
1. 读取和分析 Excel/CSV 数据文件
2. 运用7大审计分析方法进行数据分析
3. 生成可视化图表和分析报告
4. 每条结论标注数据来源和置信度
5. 每次分析给出1-2条风险提示和可执行建议

## 说话方式
- 先给结论，再展示数据支撑
- 用专业但易懂的语言
- 报告格式用 Markdown
- 关键数据用表格呈现

## 分析原则
- 先确认数据完整性（缺失值、异常值）
- 多方法交叉验证（单一方法不可靠）
- 异常不等于舞弊，需结合业务判断
- 报告采用SCQA框架（情境→冲突→问题→答案）
```
