# 审计法律法规体系

## 一、审计法框架（7章54条）

### 章节结构
1. **总则** — 审计监督制度的基本原则
2. **审计机关和审计人员** — 机构设置、人员资格
3. **审计职责** — 审计范围、权限
4. **审计权限** — 检查权、调查权、处理权
5. **审计程序** — 从计划到报告的全流程
6. **法律责任** — 违法违规行为的处理
7. **附则** — 其他规定

### 核心条款速查

| 条款 | 内容要点 |
|:----|:---------|
| 第2条 | 国务院和县级以上政府设立审计机关 |
| 第3条 | 审计机关依法独立行使审计监督权 |
| 第16条 | 审计机关对本级各部门和下级政府预算执行审计 |
| 第20条 | 审计机关对国有金融机构的资产/负债/损益审计 |
| 第21条 | 审计机关对国家事业组织财务收支审计 |
| 第22条 | 审计机关对国有企业的资产/负债/损益审计 |
| 第31条 | 被审计单位应提供相关资料（不得拒绝/拖延/谎报）|
| 第32条 | 审计机关有权检查被审计单位的会计资料 |
| 第36条 | 审计结果可向社会公布（保守秘密除外）|
| 第45条 | 审计机关的处理权（责令限期缴纳/追还/停止等）|
| 第46条 | 审计机关的处罚权（警告/通报批评/罚款等）|

## 二、内部审计准则体系

### 结构：1个基本准则 + 22个具体准则 + 5个实务指南

#### 基本准则（统领）
- 内部审计的定义、目标、原则
- 内部审计人员的职业道德要求
- 审计计划、实施、报告、后续审计的基本程序

#### 具体准则（22个）
- **通用类**：审计计划、审计通知书、审计证据、审计工作底稿、审计报告
- **专项类**：后续审计、审计抽样、内部控制审计、风险管理审计
- **技术类**：信息系统审计、数据分析、审计评价等

#### 实务指南（5个）
- 建设项目审计
- 物资采购审计
- 经济责任审计
- 风险管理审计
- 绩效审计

## 三、审计准则演进

### 国家审计准则体系（2010年修订版）
- 总则 → 审计机关和审计人员 → 审计质量控制 → 审计计划 → 审计实施 → 审计报告 → 附则
- **核心变化**：从"程序导向"转向"风险导向"

### 内部审计准则演变
| 版本 | 时间 | 主要变化 |
|:----|:----|:---------|
| 第1版 | 2003年 | 建立基本框架 |
| 第2版 | 2013年 | 与COSO框架衔接 |
| 第3版 | 2020年 | 强化风险导向和数字化审计 |
