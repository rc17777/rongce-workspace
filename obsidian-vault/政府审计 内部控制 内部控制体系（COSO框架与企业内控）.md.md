# 政府采购法规与实务

## 一、采购方式体系

| 采购方式 | 适用条件 |
|:---------|:---------|
| **公开招标** | 达到公开招标数额标准的项目（主渠道）|
| **邀请招标** | ①具有特殊性只能从有限范围供应商采购 ②采用公开招标费用过大 |
| **竞争性谈判** | ①招标后无合格供应商 ②技术复杂无法确定详细规格 ③时间紧急 |
| **单一来源** | ①只能从唯一供应商处采购 ②发生不可预见紧急情况 ③须保证原有项目一致性 |
| **询价** | 货物规格/标准统一、现货充足、价格变化小 |

## 二、审计红线（应重点关注）

### 🔴 采购方式红线
- **应招未招** — 达到公开招标数额标准未进行公开招标
- **化整为零** — 将项目拆分规避公开招标（预算额度内分次采购）
- **虚假招标** — 明招暗定、先施工后招标
- **违规变更采购方式** — 未经批准擅自变更

### 🔴 供应商红线
- **围标串标** — 多家供应商串通投标
- **挂靠投标** — 借用他人资质投标
- **利益关联** — 供应商与采购人存在利益关系（利害关系未回避）

### 🟡 评审红线
- 评审专家与供应商有利害关系未回避
- 评审标准未按招标文件规定执行
- 评审过程存在倾向性评分

## 三、条例核心改革方向

1. **强化结果导向** — 改变"重程序、轻结果"的倾向
2. **提高透明度** — 采购预算、过程、结果、合同全公开
3. **源头管理** — 科学确定采购需求 + 履约验收
4. **政策功能** — 节能环保产品优先 / 扶持中小企业 / 不发达地区

## 四、行政事业单位财政监督检查重点

| 风险点 | 表现 | 防范 |
|:-------|:-----|:-----|
| 🔴 公务接待费超预算 | 将接待费列入其他科目 | 严格预算约束 |
| 🔴 超预算列往来 | 超支部分列入往来待以后年度化解 | 预算刚性执行 |
| 🔴 虚列支出 | 年终经费有结余虚列支出 | 实报实销 |
| 🔴 专项资金挪用 | 截留、挪用财政资金 | 专款专用 |
| 🔴 违规发放津补贴 | 超范围、超标准发放 | 严格执行规定 |
| 🟡 资产不入账 | 购置资产不入固定资产账 | 全面资产清查 |
