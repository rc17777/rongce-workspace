# 政府补贴审计

> 状态：🟡 建设中

## 概述

政府补贴审计是对各级政府各类补贴资金的申请、审批、发放和使用过程的审计监督。

## 审计重点

- 补贴申请的真实性
- 审批程序的合规性
- 补贴发放的及时性
- 资金使用的专款专用
- 骗取补贴行为识别
