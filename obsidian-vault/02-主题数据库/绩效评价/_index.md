# 绩效评价

> 状态：🟡 建设中

## 概述

绩效评价是对财政资金使用效益、效率和效果进行综合评价的审计活动。

## 评价重点

- 项目立项合规性
- 资金使用效率
- 项目产出与效果
- 绩效目标达成度
- 社会经济效益
