# 预算绩效评价体系

> 来源：王金秀教授讲座（中南财经政法大学）

## 一、绩效评价维度演进
```
3E体系 → 4E体系 → 5E体系
```
| 维度 | 英文 | 含义 | 评价重点 |
|:----|:-----|:-----|:---------|
| **经济性** | Economy | 投入是否节约 | 成本控制、节约率 |
| **效率** | Efficiency | 投入产出比 | 产出/投入比率、完成率 |
| **有效性** | Effectiveness | 目标达成度 | 目标实现程度、社会效益 |
| **公平性** | Equity | 受益分配公平 | 受益覆盖面、群众满意度 |
| **环境性** | Environment | 可持续发展 | 环境影响、绿色指标 |

## 二、绩效管理"三全"体系

### 1. 全方位
- 政府预算绩效管理
- 部门和单位预算绩效管理
- 政策和项目预算绩效管理

### 2. 全过程
```
事前绩效评估 → 绩效目标管理 → 绩效运行监控 → 绩效评价实施 → 评价结果应用
```
### 3. 全覆盖（四本预算）
- 一般公共预算
- 政府性基金预算
- 国有资本经营预算
- 社会保险基金预算

**扩展范围**：PPP项目、政府采购、政府债务

## 三、绩效评价类型

| 分类维度 | 类型 | 要点 |
|:---------|:-----|:-----|
| 评价主体 | 单位自评 | 项目实施单位自行评价 |
| | 部门评价 | 主管部门组织评价 |
| | 财政评价 | 财政部门组织重点评价 |
| 评价时序 | 事前评价 | 评估项目立项必要性/投入经济性 |
| | 事中评价 | 监控执行进度和偏差 |
| | 事后评价 | 评价产出效果和可持续性 |
| 评价范围 | 项目评价 | 单个项目 |
| | 部门整体评价 | 部门整体支出 |
| | 政策评价 | 重大政策实施效果 |

## 四、绩效指标设计原则（SMART）

| 原则 | 含义 | 示例 |
|:-----|:-----|:-----|
| **S**pecific | 具体明确 | "培训满意度≥90%"而非"满意度高" |
| **M**easurable | 可量化 | 有数据来源、可采集 |
| **A**chievable | 可达成 | 目标值合理可行 |
| **R**elevant | 相关性 | 与项目目标直接相关 |
| **T**ime-bound | 有时限 | 明确完成时间节点 |

## 五、常用绩效指标库速查

### 产出指标
| 类型 | 示例 |
|:-----|:------|
| 数量指标 | 培训人次、设备台数、验收面积 |
| 质量指标 | 验收合格率、投诉率、覆盖率 |
| 时效指标 | 完成及时率、工期符合率 |
| 成本指标 | 单位成本、预算执行率、节约率 |

### 效益指标
| 类型 | 示例 |
|:-----|:------|
| 经济效益 | 收入增长、成本降低、资金增值率 |
| 社会效益 | 受益人数、满意度、就业带动 |
| 生态效益 | 节能减排、绿色覆盖率 |
| 可持续影响 | 长效机制、后续运维保障 |
