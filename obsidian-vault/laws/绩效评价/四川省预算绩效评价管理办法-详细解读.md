# 四川省预算绩效评价管理办法（川财绩〔2025〕5号）

## 一、文件基本信息
- **发文机关**：四川省财政厅
- **文号**：川财绩〔2025〕5号
- **发布日期**：2025年3月17日
- **施行日期**：2025年3月17日
- **有效期**：5年
- **废止文件**：《四川省省级项目支出绩效管理办法》（川财绩〔2019〕14号）

## 二、适用范围
全省各级财政部门、主管部门及所属单位开展的：
- 部门预算绩效评价
- 专项项目绩效评价
- 支出政策绩效评价

政府预算绩效评价按市（州）有关规定执行。

## 三、三级评价体系

### 第一级：单位自评（第二章）
| 项目 | 内容 |
|:----|:----|
| **定义** | 单位对本部门预算项目绩效目标完成情况的自我评价 |
| **频率** | 预算年度常态化全覆盖 |
| **实施主体** | 单位自行开展（不得委托第三方） |
| **组织方式** | 内设财务机构组织，项目实施主体开展 |
| **产出物** | 单位预算项目评价表及评价得分（附件1） |
| **决策程序** | 集体决策 |
| **报送时限** | 每年2月底前报主管部门 |

### 第二级：部门评价（第三章）
| 项目 | 内容 |
|:----|:----|
| **定义** | 主管部门对本部门预算、专项项目、支出政策的自我评价 |
| **频率** | 部门预算/专项项目年度全覆盖；支出政策按需开展 |
| **实施主体** | 内设财务机构牵头+业务机构组建评价工作组 |
| **方式** | 实地踏勘→定量定性分析→评价打分 |
| **可引入第三方** | 是（对下属单位/专项项目/支出政策重点评价） |
| **产出物** | 部门评价结果（附件1-4） |
| **决策程序** | 党组（委）会议/办公会集体决策 |
| **报送时限** | 每年3月15日前报同级财政部门 |

### 第三级：财政评价（第四章）
| 项目 | 内容 |
|:----|:----|
| **定义** | 财政部门对部门预算/专项项目/支出政策实施效果的绩效评价 |
| **范围** | 本级部门+下级政府 |
| **实施主体** | 绩效管理机构牵头+支出管理处室+评审机构+主管部门+第三方 |
| **部门预算选取** | 五年全覆盖，每年20%左右 |
| **专项项目选取** | 部门评价为"优"→当年全部纳入；"良"→抽20%；连续两年"中及以下"→第三年必评 |
| **支出政策选取** | 按省委省政府重点工作选 |
| **产出物** | 财政评价初步结果→参考部门评价→最终结果（附件5-7） |

### 关键机制：部门评价与财政评价联动
财政评价与部门评价差异大且降档时，最终结果打折：
- 降一档：×90%
- 降两档：×80%
- 降三档：×70%

**目的**：倒逼部门提高自评质量。

## 四、绩效评价基本原则
1. **全面覆盖、突出重点**：财政资金全覆盖+聚焦重点资金/重大项目/重要政策
2. **客观公正、科学规范**：流程严格+方法科学+指标细化量化可比可测
3. **责任明晰、协调联动**：单位自评→部门评价→财政评价有机衔接

## 五、绩效评价主要依据（7类）
1. 国家法律法规和规章制度
2. 党中央国务院、省委省政府重大决策部署
3. 部门职能职责相关规定
4. 行业政策、行业标准及专业技术规范
5. 预算管理制度、会计制度、三管三必须要求、项目及资金管理办法
6. 人大审查报告、审计报告、财政监督检查报告
7. 其他政策依据

## 六、评价指标与标准
### 指标体系（按评价对象分类）
- 政府预算评价指标（另发）
- 部门绩效评价指标（附件8）
- 专项项目绩效评价指标（附件9）
- 支出政策绩效评价指标（附件10）

### 评价标准（6类）
国家标准 / 行业标准 / 地方标准 / 申报标准 / 历史均值 / 样本均值

## 七、结果应用（第六章）
### 部门评价结果应用
- ↔ 下属单位预算控制数挂钩
- ↔ 内设机构/下属单位绩效考核挂钩
- → 资金分配/政策调整的参考因素

### 财政评价结果应用
- ↔ 预算安排挂钩
- ↔ 转移支付规模及分配挂钩
- → 政策调整完善的重要因素
- 被评价单位：主要负责人审签→党组会集体决策整改→按时报财政

### 信息公开
- 财政部门：人大批准决算后20日内公开重大政策和重点项目评价结果
- 主管部门：财政批复部门决算后20日内公开
- 单位：主管部门批复单位决算后20日内公开

## 八、第三方机构管理
- 严格实行委托事项负面清单管理
- 依托信用管理平台跟踪执业质量
- 制定质量评定办法
- 依法依规从严从紧管理经费

## 九、评分等级
| 等级 | 分数区间 |
|:----|:--------|
| 优 | 90-100 |
| 良 | 80-90 |
| 中 | 70-80 |
| 差 | 70以下 |

## 十、与旧办法对比
| 维度 | 旧办法（2019） | 新办法（2025） |
|:----|:------------|:------------|
| 名称 | 省级项目支出绩效管理办法 | 预算绩效评价管理办法 |
| 范围 | 仅省级项目支出 | 全省各级/部门预算+专项+政策 |
| 层级 | 两级（单位+财政） | 三级（单位+部门+财政） |
| 部门评价 | 未明确 | 独立成章，制度化 |
| 自评质量 | 无约束 | 与财政评价差异触发打折机制 |
| 结果应用 | 原则性 | 具体挂钩+信息公开时限 |
| 禁止委托 | 无 | 单位自评不得委托第三方 |
