# 郫都区2025年度预算执行情况绩效自评通知

## 一、文件基本信息
- **发文机关**：成都市郫都区财政局
- **文号**：郫财函〔2026〕11号
- **日期**：2026年2月24日
- **依据**：预算法 + 省市要求 + "三管三必须"

## 二、自评范围（4类全覆盖）
1. 所有特定目标类项目
2. 所有财政专项资金（政策）
3. 所有部门（单位）整体支出
4. 国有资本经营预算

## 三、自评工作流程

### Step 1：部门（单位）自评
```
预算单位完成自评表 → 撰写自评报告 → 主管部门复核
```

#### 1.1 特定目标类项目自评
- 从一体化系统导出《部门预算项目支出绩效自评表（2025年度）》（附件1）
- 线下填报完成
- 地方债项目：用专项债指标体系（附件5-1建设期/5-2运营期）+ 附件6报告模板

#### 1.2 财政专项资金（政策）自评
- 业务主管部门牵头
- 汇总各项目实施单位自评
- 使用附件2指标体系打分 + 附件6报告模板

#### 1.3 部门整体支出自评
- 从一体化系统导出绩效目标
- 使用附件3（部门整体指标体系）+ 附件4（国有资产指标体系）
- 参考附件7报告模板

#### 1.4 国有资本经营预算自评
- 主管部门+国企监管部门组织
- 使用附件2指标体系 + 附件6报告模板

### Step 2：财政抽查复核
- 支出业务科室复核：≥200万特定目标类+所有专项资金+所有部门整体+国有资本经营预算
- 第三方机构现场复核：重点绩效评价涉及的预算单位
- 使用附件8复核表

### Step 3：报送
- 预算单位→财政局：2026年3月16日前
- 支出业务科室复核完成：2026年3月31日前

## 五、关键要求

### 自评质量要求
- "谁使用资金，谁实施自评"
- 财务部门牵头，业务部门+项目实施单位具体实施
- 主管部门对下属单位自评全面复核，不合格驳回

### 分析要求
- 预算执行率<90%：逐条原因分析
- 绩效指标未完成或完成>130%：逐条原因分析
- 年中预算调整：单独说明理由

### 结果应用
- 评价结果与下属单位/内设机构预算安排挂钩
- 绩效低下项目（政策）及时清理退出
- 问题整改情况复查追踪
- 各部门在财政批复决算后20日内公开自评结果

### 考核
- 自评工作完成质效纳入区委、区政府目标绩效考评
