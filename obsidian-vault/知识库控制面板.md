## 🔍 快速检索

### 方式一：RAG Web 界面
→ [打开 RAG 知识库](http://localhost:5000) `🌐 浏览器打开`

### 方式二：命令行检索
```bash
# 在终端中直接搜索
python scripts/rag_query.py "围标串标检测方法"
python scripts/rag_bridge.py "政府采购审计要点"
```

### 方式三：Shell Commands 插件（推荐）
> 如果你安装了 Obsidian Shell Commands 插件：
> 1. 设置 → Shell Commands → New command
> 2. 命令：`python scripts/rag_bridge.py "{{selection}}" `
> 3. 输出：Insert after current line
> 4. 快捷键：`Ctrl+Shift+K`

选中文本 → `Ctrl+Shift+K` → RAG 结果直接插入当前笔记。

## 🛠️ 维护工具

### 内容清理
```bash
python scripts/prune_knowledge.py            # 预览僵尸文件
python scripts/prune_knowledge.py --archive  # 归档僵尸文件
```

### 双向链接
```bash
python scripts/build_links.py        # 扫描并生成链接映射
python scripts/build_links.py write  # 写入 frontmatter
```

### 索引重建
```bash
python scripts/rag_rebuild.py        # 重建 RAG 索引
```

或在桌面双击 `更新知识库.bat`
