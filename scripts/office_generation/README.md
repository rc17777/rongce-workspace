# Office 生成脚本

用途：Word、Excel、PPT、图表、模板、报告成果生成。

脚本来源较杂，包含：

- 报告/底稿/清单 Excel 生成。
- PPT 模板迁移与页面生成。
- Word 报告、演讲稿、案例文档生成。
- 项目型成果脚本和旧版本脚本。

注意：这类脚本最容易写死模板路径、字体、输出目录和历史项目数据。复用前先检查：

1. 输入文件路径。
2. 输出目录。
3. 字体和模板依赖。
4. 是否为最终版本。
5. 是否绑定具体项目。

后续建议再细分为：`excel/`、`word/`、`ppt/`、`project_specific/`、`legacy_versions/`。
