## 2026-05-25 · 知识管理体系搭建

### 决策：采用三层架构管理上下文
基于 PyClaw 上下文工程文章的原理，建立：
- **Frozen 层**：`USER.md` `SOUL.md` `AGENTS.md` — 每次启动必读，永不变或极少变
- **Dynamic 层**：`INDEX.md` — 指针索引，快速定位文件
- **Memory 层**：`MEMORY.md` + `memory/*.md` — 长期记忆，按需搜索读取
- 核心原则：**给指针不给全文，信息密度 > 完整性**

## 经验教训

### OfficeCLI 操作备忘
- 含 `=` 的文件路径需双引号包裹
- `officecli view` 不支持 `--sheet`，用路径语法 `/sheetName/Range`
- 修改依赖单元格后公式不会自动刷新，需重新 set 公式
- UTF-16LE JSON 需 `-Encoding Unicode`
