## 二、业务边界

### 审计 vs 工程 分界线

```
工程竣工财务决算审核 → 融策审计
   ├─ "花了多少钱、合不合规" → 审计自己查
   └─ 疑点涉及算量/定额 → 发消息调融策工程咨询

财政评审 vs 竣工决算审核：
   ├─ 财政评审（预算/结算阶段）→ 融策工程咨询
   └─ 竣工决算审核（财务关闭阶段）→ 融策审计

司法审计：
   └─ 全归融策工程咨询（核心是造价技术鉴定，不是合规性审计）

专项债申报：
   └─ 融策审计（资金合规性审查）
```

### 消息协作规则

- Agent间通信仅通过统一消息队列，不直接调用
- 请求格式：`{"from": "rongce-audit", "to": "rongce-engineering", "task": "...", "data": {...}}`
- 融策监督可监听所有Agent间消息（不干预，仅评分用）
- 融策知识向所有Agent推送KB更新（广播模式）
